口径

  • tokens = prompt + completion。Jev 只对 prompt 收费 ($0.042/M)，completion 免费，所以花费 ≈ prompt tokens × $0.042/M
  • 每次决策约 3.3k tokens (9/22：276B ÷ 83.6M 次)，其中 prompt 约 2.9k，比外部文章常说的 1k 高
  • 全平台分母来自 OpenRouter rankings 接口的日口径 (约 560 个模型加总)。该接口只给最近一个完整日，漏抓的日子无法补，只能用估算
  • WoW 用同一星期几比，避开周末波动；需要满 8 天数据
  • 日期是 UTC，SGT 早 6 点跑时 UTC 前一天刚结束，当天那行是未完成的

要盯的信号

  • 爬坡是否停：9/21→9/22 requests +1.5%、tokens −4%，若连续一周横盘，说明首批接入的需求已经放完
  • tokens/request 变化：上升说明用户往 Jev 塞更长的上下文，用法在变重
  • 头部 app 消失：先查是停用还是转直连 TypeSafe，后者不代表需求下降
  • 新版本上线：新版本是新 permaslug，要加总，否则曲线断档
