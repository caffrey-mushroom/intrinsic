  • 政策和成本压力
  1. 政策变化、环保约束及基础设施建设限制提高了客户项目的不确定性。

  3. 客户原有预算无法覆盖相同采购数量，需要重新审批预算或调整合同结构。

2. 企业客户预算与采购量调整

a) 企业客户是否因AI预算不足而停止采购硬件？

  • 企业客户并非没有AI预算，而是采购成本上涨导致原预算能够覆盖的硬件数量减少。
  • 大中型企业通常会提前确认预算，例如在Q3已经能够初步估算下一年度预算。
  • 当采购价格上升后，预算金额可能保持不变，但实际采购量会下降，客户需要重新申请增量预算。

b) 价格上涨如何影响企业客户的采购结构？

  • 典型案例
  1. 假设客户原计划采购8万台，并已为此安排预算。
  2. 成本和售价上涨后，原预算可能只能支持采购6万台。
  3. 客户会先签署6万台的年度框架协议。
  4. 剩余2万台需重新审批预算，并通过追加合同单独协商价格。
  • 合同结构变化
  1. 部分客户希望降低年度框架合同中的承诺采购量。
  2. 后续增量需求更多通过补充合同或追加订单完成。
  3. 追加合同可独立定价，不一定沿用年度框架协议价格。
  4. 这种方式有助于客户降低短期预算压力，但采购确定性会相应下降。

c) 未采购的剩余配额是否会保留给原客户？

  • 未采购配额不会长期为原客户保留，资源分配主动权在HPE一方。
  • 在市场供不应求的情况下，谁能更快完成商务谈判、签约及付款，配额就优先给谁。
  • HPE可以在合理范围内对涨价幅度作出让步，但不会为了原客户而积压可销售资源。
  • 若其他客户愿意整体承接剩余订单并具备付款能力，HPE会优先向其释放配额。
  • 对剩余订单的承接规模有最低要求，原则上至少需要消化该笔剩余数量的30%，不会将大额配额拆分为大量零散小单。

3. New Cloud客户风险与回款保障

a) HPE如何看待New Cloud客户的融资和违约风险？

  • New Cloud客户普遍采用重资产算力租赁模式，前期资本开支较大，投资回收周期较长。
  • 行业平均资金覆盖率已超过80%，在高利率环境下，追加预算难度较大。
  • 部分客户已与下游签订固定租金的长期合同，采购成本上涨后无法同步提高租金，可能压缩项目IRR和现金流安全垫。
  • HPE承认该领域存在延期交付、融资不足甚至潜在违约风险，因此会按照头部、中型和长尾客户分层管理。

b) 不同类型New Cloud客户采用什么付款和风控方式？

  • 长尾小型New Cloud
  1. 年采购金额低于500万美元。
  2. 必须通过严格信用审核。
  3. 要求100%预付货款后才启动排产。
  4. 因此基本不存在订单无法兑现的风险。
  • 中型New Cloud
  1. 主要风险是再融资成本上升导致交付延后。
  2. 通常要求支付30%预付款。
  3. 同时需要提供银行兜底保函。
  4. 当前更多表现为延后1至2个季度，尚未出现大规模订单直接作废。
  • 头部New Cloud
  1. 通常与微软、OpenAI等头部科技公司存在长期合作。
  2. 客户可提供下游长期照付协议，即Take-or-Pay合同，作为现金流保障。
  3. 在提供相关合同并支付预付款后，HPE按照约定节奏安排交付。
  4. HPE还会采用阶梯预付款、银行保函及分阶段配额释放等机制控制风险。

c) HPE当前的订单分配原则是什么？

  • 现阶段优先目标是将产品及时交付给具备付款能力的客户。
  • 只要客户能够签约、款项正常到账，且价格让步不超过合理范围，HPE可以提供相应数量。
  • 不会因为未来可能出现更高报价，就违背已经签署并进入执行阶段的订单。
  • 核心原则是“资金确定性优先、签约速度优先、订单执行优先”。

d) AI系统订单是否已经收到客户付款？

  • 订单登记口径通常包括已到账款项和在途款项。
  • 在途款项指客户已发起大额支付，或即将完成付款确认，通常预计可以到账。
  • 从合同签署、转账到最终确认，一般需要一周以上。
  • 因此，披露的订单并不一定全部完成最终收入确认，但通常已经进入付款或付款确认阶段。

4. 主权客户及美国政府订单变化

a) DOE国家实验室及政府类项目是否出现砍单？

  • 现有核心订单
  1. Los Alamos等国家实验室的超算项目主要采用Robin平台。
  2. 相关订单的交付时间已签至2027年底或2028年第一季度。
  3. Argonne国家实验室的Aurora系统及AI系统项目，交付时间也主要集中在2027年底至2028年。
  4. 现有核心订单继续保留，整体履约未受到明显影响。
  • 追加订单
  1. 现有合同基本继续执行。
  2. 后续追加订单目前普遍被取消或暂停。
  3. 非核心、小规模的地方科研AI试点项目，已出现较大范围延期或取消。

b) 美国政府AI基础设施预算是否面临削减？

  • Genesis等国家AI战略具有两党共识，涉及国防及关键基础设施预算，政策优先级较高。
  • 美国2027财年相关AI基础设施拨款已通过众议院审议，因此目前缺乏全面削减核心AI预算的政治基础。
  • 2028及2029财年预算目前尚无法讨论，政府端也未提供明确指引。
  • 后续新项目是否削减、削减幅度多大，仍取决于财政拨款政策。
  • 专家判断，地方和非核心项目受影响较大，但不会显著改变主权AI业务的整体发展方向。

5. 成本上涨与定价机制

a) 本轮AI服务器成本上涨的核心来源是什么？

  • 本轮成本压力主要来自PCB、高速连接器、内存等通用组件。
  • GPU和HBM通常通过长期协议锁定配额及部分价格，风险相对可控。
  • PCB、高速互联及内存属于公开流通的大宗组件，难以长期锁定固定价格。
  • 相关供给约束预计持续到2027年，属于结构性、持续性通胀，而非短期小幅波动。
  • 若继续采用6至9个月固定价格合同，HPE将独自承担成本单边上涨风险，可能突破毛利率底线。

b) 成本上涨由HPE还是客户承担？

  • 成本不会简单地全部转嫁给客户，也不会全部由HPE承担。
  • HPE会根据客户类型、合同结构、商业模式和战略优先级进行差异化分担。
  • 最新合同模板已标准化加入大宗商品调价条款，包括：
  1. 调价触发阈值；
  2. 涨幅上限；
  3. 调价频次限制；
  4. 成本联动机制。
  • 当成本涨幅极高时，HPE会承担一部分；未超过约定阈值时，相关成本主要由客户承担。

c) 主权客户和头部Hyperscaler采用什么定价方式？

  • 主权客户、DOE国家实验室及头部Hyperscaler属于低弹性、高战略优先级客户，占Backlog的大部分。
  • 这类客户订单周期长、预算确定性高，也是HPE优先保障GPU配额和交付的客户。
  • 通常采用多年框架长单和混合定价结构：
  1. GPU、HBM部分继续锁定配额和价格；
  2. PCB、内存等大宗组件采用成本联动调价；
  3. 对涨幅设置上限和触发条件。
  • 部分顶级Hyperscaler可以接受Cost Plus模式，即HPE获得固定加工或集成毛利，大宗商品成本随上游价格变化。
  • 该模式可以保护毛利额，但不一定提升毛利率。

d) 行业企业客户的报价策略如何调整？

  • 行业企业客户的预算通常属于一次性审批的CapEx预算，对交付时突然涨价较为敏感。
  • 新签项目的报价有效期已从90天缩短至30至40天。
  • 报价单会明确说明大宗商品价格随市场行情调整，不再提供隐性长期锁价承诺。
  • HPE还会采用分阶段交付，降低单笔大合同的成本风险敞口。
  • 渠道分销和中小企业客户全部采用短周期报价、现货排产及BOM实时调价模式。

e) 存量订单如何应对成本上涨？

HPE为已签署的存量订单提供3种解决方案：

  1. 追加预付款：客户增加预付款，由HPE向上游锁定内存现货，从而尽量维持原价。
  2. 调整配置：降低单节点内存容量或替换部分规格，使项目在原预算内落地。
  3. 分批交付：拉长交付周期，通过分批采购和交付对冲短期现货高价。

f) New Cloud客户的成本风险如何处理？

  • HPE不再接受低预付款、长周期、固定价格的New Cloud合同。
  • 新订单至少要求30%预付款，大额订单需附加银行保函。
  • 合同中必须明确大宗商品调价条款。
  • 若客户对下游采用固定租金，涨价风险由客户项目主体承担。
  • HPE不会为了保住订单而吸收全部大宗商品涨价，也不会为客户算力租赁项目的商业回报兜底。
  • 客户未来与下游签订算力租赁合同时，需要同步加入租金调价机制，避免采购端与租赁端价格错配。
  • HPE还会引导部分高算力需求向内存成本压力较低的Helios第二架构迁移。

6. 订单统计口径与收入确认

a) 30亿美元订单与业绩会披露数据为何存在差异？

  • 访谈中提到的接近30亿美元，主要是合同签订口径。
  • 公司对外披露的数据可能采用款项到账、结算或交付确认口径。
  • 不同统计口径之间通常存在5%至8%的波动，前后可能相差约1亿美元。
  • 因此，合同签订金额不能直接等同于当季确认收入。

b) 合同签订、交付和回款之间有什么时间差？

  • 年度框架合同通常集中在年底或财年初签署，但主要交付可能发生在Q3。
  • Q3交付的订单很可能来自Q1签订的合同。
  • 也可能存在Q2交付、Q3付款的情况。
  • Q3新签订单通常至少需要间隔一个季度才能交付。
  • 因此，政策或市场事件首先影响的是本季度新增订单，而不是此前已签署并进入履约阶段的订单。
  • 收入确认和款项到账通常会较合同签订延后1至2个季度。

7. 库存与生产策略

a) HPE的AI服务器是否采用零库存模式？

  • HPE存在库存，但不是无客户需求的投机性库存。
  • 库存主要对应已经签署的长期履约订单，是为了保障后续季度稳定交付而提前生产。
  • 对于赔付金额较高、订单规模较大的项目，HPE会主动提前备货。

b) 通常会提前生产多少订单？

  • 正常情况下，在Q1结束前可能已完成Q2订单量的约30%。
  • 到Q2时，会提前生产Q3约30%的订单量。
  • 若后续订单规模特别大，提前生产比例可能提高至35%。
  • 这些库存均对应明确客户和长期订单，不会在没有需求的情况下超额生产。

c) 价格适度让步是否意味着需要消化积压库存？

  • 价格让步主要是为了提升订单执行效率、优先向具备资金能力的客户释放配额。
  • HPE不存在先生产大量无主产品、再降价清库存的模式。
  • 相关库存本质上属于已签订单的提前生产，不代表订单需求弱于预期。

8. 2028年业务展望与增长方向

a) 主权客户业务未来如何发展？

  • 主权客户预算预计不会继续显著增长。
  • 在此前投入持续扩大的背景下，预算不增长实质上已经相当于收缩。
  • 主权客户采购额预计进入相对稳定阶段，难以继续贡献高增量。
  • 核心项目仍具备较高确定性，但非核心及新增项目将面临更严格审批。

b) Hyperscaler和New Cloud业务增长如何？

  • Hyperscaler和New Cloud仍是HPE重点维稳的客户群体。
  • 客户并非没有预算，而是成本上涨超出已审批预算预期。
  • 明年客户可能增加部分预算，但受融资成本、杠杆水平和风险偏好影响，预算增幅不会很高。
  • 两类客户的采购量预计仅小幅增长。
  • 由于价格上涨，营收可能出现相对可观的增长，但毛利和利润增量不会特别明显。

c) 2028年最具潜力的新增长点是什么？

  • 金融、制造、医疗等行业企业的私有云预计成为2028年最重要的新增市场。
  • 当前该领域订单规模仍较小。
  • 随着企业AI基础设施本地化及私有化部署需求提升，行业私有云有望成为新的订单增长来源。
  • 未来业务结构将从主权客户和大型云客户主导，逐步增加行业企业客户的贡献。

9. 2026财年收入情况

a) 2026财年AI服务器收入预计是多少？

  • AI服务器及相关整机收入预计约57.5亿至57.8亿美元。
  • 该口径不包括传统通用服务器及其对应整机收入。
  • 由于部分订单交付和款项到账延后，当前口径低于正常业务水平。
  • 若按正常交付和确认节奏，AI服务器收入预计可超过60亿美元，合理水平约为63亿至65亿美元。

b) 传统服务器业务收入预计是多少？

  • 根据9月份的内部估算，传统服务器业务收入约165亿美元。
  • 将传统服务器与AI服务器业务简单合计，相关服务器业务规模约222.5亿美元。
  • 该数值属于访谈中的粗略业务口径，不等同于严格会计口径下的HPE全公司合并收入。

c) AI系统收入低于订单规模的原因是什么？

  • 合同签订、产品交付、款项到账和收入确认之间存在时间差。
  • 收入确认通常会延后1至2个季度。
  • 部分客户延后交付后，相应款项到账和收入确认也会同步延后。
  • 因此，当前收入数据并不能完全反映已签订单和Backlog规模。
