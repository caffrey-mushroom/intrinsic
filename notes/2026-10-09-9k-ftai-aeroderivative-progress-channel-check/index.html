专家访谈纪要：FTI Mod 1航改燃机项目进展、量产能力与供应链分析

1. 项目参与程度、当前阶段与首次交付定义

a) 专家在Mod 1项目中的参与程度如何？

  • 专家直接参与了Mod 1项目的多个核心环节，包括：
  1. 发动机配置，确保设备在配置层面正常运行
  2. 部分设计工作
  3. 原型机测试及测试问题排查
  4. 硬件选择和工程决策
  • 除市场推广和最终包装环节参与较少外，专家基本接触了项目的各个技术环节。
  • 专家来自蒙特利尔工厂，并持续与发动机及零部件团队合作，对制造、返厂维护和测试进展较为熟悉。

b) Mod 1目前处于什么阶段？

  • 当前仍处于测试、运行包线定义和控制参数微调阶段。
  • 首台Mod 1正在蒙特利尔工厂制造，相关测试仍在佛罗里达州Medley/迈阿密测试设施进行。
  • 项目已经完成主要设计验证，不再处于可能全面推翻设计的早期阶段。
  • 当前工作的重点包括：
  1. 确定发动机可行运行范围
  2. 微调瞬态运行参数和控制逻辑
  3. 开展耐久性和长时间连续运行验证
  4. 为设计最终定型及扩大生产做准备

c) 管理层所称“2026年第四季度首次交付”具体指什么？

  • “首次交付”主要指发动机具备投入运行的能力。
  • 这一节点不一定意味着整套设备已经完成最终拖车式封装，并在客户现场完成全部验收。
  • 其实际定义介于以下两种状态之间：
  1. 产品已达到可以运行、基本准备就绪的状态
  2. 产品已经完成客户验收并交付至客户现场
  • 因此，管理层的首次交付口径更接近“发动机或核心设备具备商业运行条件”，而非严格意义上的整套系统最终现场验收。

d) 2026年第四季度首次交付目标是否仍然可行？

  • 专家认为目前没有已知的重大重新设计事项会影响2026年第四季度首次交付。
  • 第一次迭代版本的主体设计已经得到验证，目前主要是在确定并微调运行包线。
  • 项目已经远离“测试结果可能全部失效、需要推倒重来”的阶段。
  • 早期VBV控制问题已在数月前完成主要攻关，目前不会对现有原型机和首次交付时间表构成明显影响。
  • 综合判断，2026年第四季度首次交付目标仍然具备可实现性。

2. CFM56改造成Mod 1的技术路径

a) CFM56改造成Mod 1需要进行哪些改动？

  • Mod 1约90%的CFM56发动机部件可以重复使用。
  • 除燃烧部分和少量细节调整外，核心机周边的大部分结构基本保持不变。
  • 第1代Mod 1中，低压涡轮（LPT）基本不变，主要改造集中在发动机前端和燃烧部分。
  • 核心改动包括：
  1. 重新设计风扇盘
  2. 重新设计并制造风扇叶片
  3. 在增压级前增加进口导向叶片，以调节气流
  4. 重新设计增压器相关叶片和外侧罩环
  5. 取消或弱化与涵道气流、航空推力相关的功能
  6. 调整燃油喷嘴、燃油歧管和燃烧室衬套
  7. 增加发电应用所需的仪器设备
  8. 拆除原本服务于短舱和飞机附件的部分线束
  9. 重新开发与进气变化相匹配的控制逻辑

b) 哪些部件是重新设计和验证的重点？

  • 发动机前端是重新设计和重新制造工作最集中的区域，主要包括：
  1. 风扇盘
  2. 风扇叶片
  3. 增压器进口导向叶片
  4. 增压器一级或二级叶片
  • 风扇盘在航空应用中属于寿命限制件，通常需要严格测试、分析和寿命计算。
  • 在发电应用中，项目更关注蠕变问题，而不是航空发动机频繁起降所导致的循环寿命，因此可以采用不同设计规范，并保留更高工程裕度。
  • 发动机热端的主要改造对象包括：
  1. 燃油喷嘴
  2. 燃油歧管
  3. 燃烧室衬套
  • 整体来看，增压器和燃烧系统是Mod 1最主要的两大改造区域。

c) 为什么90%的原有部件可以继续使用？

  • CFM56核心机及主要结构已经经过长期航空应用验证，具备成熟的可靠性基础。
  • 对于保持不变的部分，维护和维修可以基本沿用OEM指导规范。
  • Mod 1不需要满足完整航空适航要求，因此部分原本服务于航空推力和适航维修性的标准可以重新评估。
  • 例如，动力发动机不依赖涵道气流产生航空推力，因此部分导向叶片不必保持与航空应用相同的可维修性标准。

d) Mod 1是否全部采用全新零部件制造？

  • 不会。Mod 1主要采用以下组合方式：
  1. 对现有CFM56发动机进行改装
  2. 使用可修复和再制造零部件
  3. 对关键改造件采用新制造零部件
  4. 从OEM或PMA供应商采购缺口部件
  • 项目并不是以全新零部件重新制造一台发动机，而是通过改装、再制造和供应链采购相结合的方式完成组装。
  • 这一模式是Mod 1成本、交付速度和产能可行性的基础。

3. 测试进展、运行包线与关键工程问题

a) 当前测试硬件与最终商业产品有多接近？

  • 当前测试设备已经非常接近Mod 1第一次商业化迭代版本。
  • 现阶段不存在可能导致项目全面重做的重大设计事项。
  • 主要工作已从“验证设计是否可行”转向：
  1. 确定运行极限
  2. 微调运行包线
  3. 优化控制参数
  4. 验证长时间连续运行能力
  5. 提升效率并降低排放
  • 后续第2次和第3次迭代主要侧重效率和排放优化，而不是证明基础架构能否运行。

b) 目前有多少台原型机，累计进行了多少测试？

  • 具体原型机数量未披露，但项目拥有多台原型机，并通过轮换方式开展测试。
  • 原型机停机期间会进行拆解、维护和检查，以验证其表现是否符合仿真结果和设计预期。
  • 专家深度参与过其中一台原型机的测试。
  • 在专家参与期间，单次最长连续运行时间约为4至5小时，但并非全程处于峰值负荷。
  • 测试需要覆盖不同负荷、加减速状态和运行包线，因此不会一直维持最大功率。

c) 下一阶段最重要的测试里程碑是什么？

  • 下一项关键里程碑是连续运行一周的耐久性测试。
  • 一周连续运行后，团队将拆解和分析发动机，重点检查此前可能未充分暴露的额外蠕变问题。
  • 主要观察部件包括：
  1. 低压涡轮第2级叶片
  2. 高压涡轮叶片
  • 项目团队希望通过试验和计算确认：
  1. 发动机能够在预期工况下长时间运行
  2. 设备可以连续运行更长时间，例如一个月，而无须计划外停机
  3. 关键热端部件能够达到预期全生命周期要求
  • 访谈中并未确认已经完成一周全天候连续运行；连续一周运行仍是近期测试目标。

d) 测试中最主要的故障排查问题是什么？

  • 测试期间最主要的问题集中在VBV可变放气阀系统及其控制逻辑。
  • VBV阀门硬件继续采用OEM零部件，变化主要来自控制系统和逻辑参数。
  • 由于Mod 1采用不同的增压级和进口导向叶片设计，进气流发生变化，进而影响：
  1. N1低压转子响应
  2. N2核心机响应
  3. 燃油输入量
  4. 发动机启动、加速和减速过程
  • 如果燃油输入过多，而VBV控制未正确匹配，核心机可能失速；如果控制系统识别到异常，也可能要求发动机停机。
  • 该问题本质上是复杂的PID控制和运行逻辑匹配问题，需要通过反复测试界定不同转速、加速度和燃油输入之间的关系。

e) VBV问题是否会影响首次交付时间表？

  • 不会构成当前时间表的主要风险。
  • 相关集中测试持续约2.5周，主要工作已在数月前完成。
  • 团队已经明确不可进入的运行区域和主要运行极限。
  • 目前剩余工作主要是微调运行包线，使发动机在效率基准和运行指引内工作，并控制燃油喷射量、超调、堵塞和供给不足等问题。
  • 因此，VBV问题已经从关键技术障碍转变为参数优化工作。

f) 当前最主要的耐久性风险是什么？

  • 当前最主要的潜在耐久性风险是蠕变和高周疲劳。
  • 低周疲劳主要由热循环驱动，可以根据循环次数和运行规则进行管理。
  • 团队重点关注低压涡轮第2级叶片，因为：
  1. 该部件长期处于高温环境
  2. 原设计并非单晶材料
  3. 虽有防蠕变和扭转变形涂层，但仍需进一步确认全生命周期表现
  • 当前采取的措施包括：
  1. 将低压涡轮第2级叶片更换为新品，建立测试基准
  2. 开发单晶叶片替代方案
  3. 检查高压涡轮叶片是否存在蠕变裂纹扩展
  • 目前尚未发现随机开裂或失效迹象，但这两类叶片仍是后续测试重点。

4. 性能、效率与排放情况

a) Mod 1当前实际输出功率是多少？

  • 管理层目标为至少25MW。
  • 在燃烧室尚未进一步优化、VBV调度也未充分优化的情况下，首台原型机已经实现约21MW的总输出功率。
  • 专家预计实际商业产品输出将接近25MW，至少高于20MW。
  • 当前测试为完整动力链测试，覆盖：
  1. 发动机
  2. PTO轴
  3. 齿轮箱
  4. 发电机
  • 因此，21MW并非单纯发动机轴功率，而是完整系统测试中的总输出结果。

b) 25MW目标是否合理？

  • 专家认为25MW是合理且可实现的目标。
  • 当前测试地点位于迈阿密，高温和高湿度属于较不利运行条件。
  • 在低温、干燥环境下，发动机具备更高的EGT裕度，可以在相同排气温度约束下以更高转速或更高负荷运行。
  • 因此，在优于迈阿密的环境条件下，设备输出可能进一步提高。
  • 最终产品竞争力不只取决于能否达到25MW，还取决于：
  1. 达到25MW所需的燃料量
  2. 热耗率和系统效率
  3. 排放水平
  4. 连续运行可靠性

c) 当前效率和热耗率表现如何？

  • 当前发动机热耗率和效率总体符合预期。
  • PTO轴、齿轮箱和发电机等部件会带来一定效率损失，但整体仍在项目目标范围内。
  • 访谈未披露具体热耗率或效率数值。
  • 后续迭代将继续提升整体效率并降低单位发电燃料消耗。

d) 当前排放控制方案是否已经定型？

  • 排放控制的核心在燃烧系统。
  • 目前考虑的方案包括：
  1. 双喷射
  2. 水冷或喷水方案
  3. 燃烧室进一步迭代
  4. 外部SCR系统
  • 当前燃烧室采用第一次迭代设计，其排放水平接近CFM技术插入型发动机中效率较高的版本。
  • 第一次迭代的主要目标是证明航改燃机可以稳定运行并达到25MW。
  • 第2次和第3次迭代将进一步优化效率和排放。
  • 燃烧室排放约束是最可能造成后续迭代延误的因素，但预计不会导致整体生产计划推迟6个月。

e) 噪声与认证风险如何？

  • 主要监管和认证关注点包括：
  1. 排放
  2. 噪声
  3. 比油耗或SFC
  • 原型机过去数月一直在迈阿密进行测试，基础原型状态已经基本满足当地城市噪声标准。
  • 专家认为噪声达标风险较低，在美国西部工业区域等应用场景中应更容易满足要求。
  • 对具体排放法规和认证要求，专家参与有限，无法给出确定判断。
  • 若CFM56技术插入型发动机的排放可以配合SCR满足要求，Mod 1预计能够达到相同或更低排放水平。

5. 2027年100台产能目标与工厂资源分配

a) 2027年生产100台Mod 1是否可行？

  • 专家认为该目标具有挑战性，但总体可行。
  • 蒙特利尔工厂每季度大约处理130个主要气动模块。
  • 扣除约30至40个单独销售模块后，其余模块大致相当于每季度约30台发动机，即每年约120台。
  • 这一估算尚未计入：
  1. 迈阿密工厂每季度约15台的潜在处理能力
  2. 罗马设施每季度约10台的潜在处理能力
  • 虽然维修与制造、改装的具体流程不同，但现有处理规模表明公司具备实现年产100台的基础能力。

b) 实现100台目标的关键条件是什么？

  • 主要条件包括：
  1. 建立严格、标准化且高效的发动机改装流程
  2. 建立稳定的拆解线和再制造体系
  3. 保证可修复零部件的供应
  4. 补足OEM、PMA和新制造零部件的缺口
  5. 合理配置人力和设备
  6. 协调航空业务和发电业务之间的资源
  • 公司正在采购部分发动机用于拆解，并利用不可用材料或剩余寿命较低的材料重建发动机。
  • 真正的挑战不是单纯装配能力，而是建立高效的物料吞吐和转换体系。

c) 传统航空业务与发电业务将如何分配产能？

  • 蒙特利尔工厂目前拥有两条主要装配线，其中较新的装配线主要服务于发电业务。
  • 发电业务在爬坡阶段仍会占用部分航空业务的人员、供应链和设施资源。
  • 专家预计未来6个月内，蒙特利尔工厂的业务分配可能逐步接近50/50。
  • 已签订的发动机交付合同会获得较高优先级。
  • 发电业务利润率更高，公司在确定资源优先级时预计会向发电业务重新分配资源。

d) 发电业务是否会挤压航空业务产能？

  • 航空业务产出量可能不会维持原有水平，但进入车间的发动机投入量可能持平甚至增加。
  • 部分航空发动机因核心机需要较大修复，可能成为账面沉淀资产，但其前端、风扇框架和低压涡轮仍具备较高利用价值。
  • 发电业务能够承受更高的核心机修复成本，因此可以将这类发动机拆解、修复并转用于Mod 1。
  • 未来车间中可能出现更多专门用于拆解和发电业务转换的发动机。

6. 零部件供应链与叶片瓶颈

a) 新设计零部件的交付周期如何？

  • 新设计的风扇盘、风扇叶片和增压级叶片已开始到货。
  • 风扇盘约在6个月前完成设计，现场已持有多件产品。
  • 在供应商已经掌握全部图纸和规格的情况下，订单交付周期约为2至3周。
  • 单件制造及交付周期约为2周，相关供应商产能约为每周2套。
  • 供应商已承诺在11月中旬达到既定产出水平。

b) 为什么此前市场认为交付周期需要2至3个月？

  • 交付周期取决于项目所处阶段。
  • 在设计尚未定型、供应商尚未配置产能时，迭代件交付可能需要更长时间。
  • 一旦满足以下条件，交付周期可以明显缩短：
  1. 设计完成最终定型
  2. 测试包线得到验证
  3. 供应商预期会持续获得重复订单
  4. 供应商提前配置人力和生产能力
  • 因此，2至3周主要是量产准备完成后的重复订单交付周期，而不是所有开发阶段的统一周期。

c) 风扇叶片和增压级叶片是否会制约2027年爬坡？

  • 专家判断，风扇叶片和增压级叶片目前不构成主要瓶颈。
  • 两类零部件都已取得实物，供应商计划在11月中旬达到既定产量。
  • 风扇叶片将采用新制造产品，不会直接使用旧叶片。
  • 当前需要持续关注的部件是低压涡轮第2级叶片，但其市场需求较低，可以直接从OEM采购新品，短期采购难度不大。
  • 长期替代方案是采用单晶低压涡轮第2级叶片，但暂未确定完成时间。

d) FTI如何规避航空行业常见的叶片供应瓶颈？

  • 航空公司通常受既定维修规范限制，部分航空公司拒绝使用任何PMA叶片，因此只能进入OEM等待名单。
  • FTI在发电业务中具有更高灵活性，可以同时使用：
  1. OEM零部件
  2. PMA零部件
  3. 内部维修件
  4. 再制造件
  • 公司与OEM签有MCPS协议，可以获得较优价格，并在部分叶片套件释放时获得一定优先权。
  • PMA合作方包括：
  1. Pacific Aero
  2. Chromalloy
  3. Heico
  • 公司已收购Pacific Aero，增强了内部叶片生产和维修能力。
  • 因此，翼型件供应基本得到落实，风扇叶片供应也预计在11月中旬到位。

e) 哪些零部件仍然存在较强供应限制？

  • 真正供应紧张的部件主要是：
  1. 高压涡轮叶片
  2. 寿命限制件（LLP）
  • 这类部件的制造流程严格，涉及专有工艺、材料控制和寿命验证。
  • CFM供应仍有较长等待名单，部分套件每3至4周只能满足约30%的需求。
  • 第三方很难迅速建立寿命限制件制造能力，因为制造工艺变化会直接影响零部件寿命。
  • Chromalloy获得高压涡轮叶片FAA批准约耗时4至5年，表明新进入者难以在2至3年内快速形成成熟供应能力。

7. 单机成本、PMA降本与经济性

a) 一台Mod 1的发动机及系统成本大约是多少？

  • 专家仅能估算发动机和主要设备成本，无法确认整套封装系统的准确成本。
  • 初步成本拆分如下：
  1. 适合发电应用的二手CFM56发动机采购成本：约400万美元
  2. 核心机维修和修复成本：约300万美元
  3. 机组附件和QEC：约100万美元
  4. PTO轴、发电机、齿轮箱及封装等：暂估约200万美元
  • 按上述估算，单套Mod 1总成本约为1,000万美元。
  • 相比之下，状态较好、航空应用价值较高的CFM56发动机价格约为1,000万至1,200万美元。

b) 为什么发电应用可以采购更便宜的发动机？

  • 航空应用更重视剩余循环次数和低周疲劳寿命。
  • 发电应用以长期连续运行为主，更关注蠕变而不是频繁起降导致的循环疲劳。
  • 因此，Mod 1可以采购循环次数较多、航空价值较低但适合连续发电的发动机。
  • 公司可以将节省的采购成本投入核心机修复和关键零部件更换，同时保持更高利润率。

c) 使用PMA零部件可以降低多少成本？

  • 不同零部件的降本幅度差异较大。
  • 以VBV系统滚珠丝杠作动器为例：
  1. OEM认证翻修件约1万美元
  2. PMA翻修件约2,000至3,000美元
  • 对高压涡轮叶片等昂贵部件，PMA与OEM的价格差距虽没有上述案例悬殊，但仍然显著。
  • 若整套HPT叶片价格约为200万美元，采用PMA方案可能节省接近100万美元。
  • 对部分高价值部件，PMA价格相较OEM可获得约40%至50%的折扣。
  • 寿命限制件不会轻易偏离原有标准，相关部件仍将保持更严格的OEM或合规要求。

8. 客户验证、商业接受度与市场竞争

a) 客户接受Mod 1前需要看到哪些验证结果？

  • 保守客户可能同时要求：
  1. 完整工厂测试结果
  2. 更长时间的现场连续运行数据
  • 客户重点关注：
  1. 设备能否连续运行至少一周
  2. 是否可通过计算和数据证明连续运行一个月而无须停机
  3. 发动机监测是否方便
  4. 持续运行和维护是否可控
  5. 产品是否容易与现场系统集成
  • 当前基础工厂测试和气动部分验证已取得实质进展，长时间动力运行测试将是下一阶段重点。

b) 现有客户是否参与测试？

  • 已有部分对产品感兴趣的客户参与测试，其中包括已确认订购并为首批设备投入资金的客户。
  • 让客户现场了解测试程序，有助于展示：
  1. 公司对关键参数的控制能力
  2. 测试流程的严谨性
  3. 在规定时间内交付最小可行产品的能力
  4. 发生问题后的排查和修复机制
  • 对于新产品而言，仅凭测试报告难以完全证明长期可靠性，通常需要1至2年的实际运行数据才能充分验证其市场适配性。

c) Mod 1对客户的核心吸引力是什么？

  • 当前成熟大型燃机的交付周期普遍较长，采购西门子等成熟产品可能需要至少2年。
  • 对迫切需要新增电力吞吐能力的客户而言，主要选择是：
  1. 等待2年获得成熟、可靠的传统产品
  2. 在未来数月内获得Mod 1并提前满足能源需求
  • 即使Mod 1初期在效率、支持服务或吞吐能力方面未完全达到客户预期，客户仍可在等待传统产品期间使用该设备。
  • 若Mod 1在价格、效率和模块化方面表现超预期，客户则可能继续追加订单。

d) Mod 1相较潜在新进入者有何优势？

  • FTI已经具备：
  1. 可供改装的CFM56产品基础
  2. 对发动机限制条件的深入了解
  3. 3至4个测试设施
  4. 大量历史测试数据
  5. 发动机维修、拆解和再制造能力
  • 从零开发航改燃机的最大难点不一定是硬件，而是控制系统和运行包线。
  • 如果不了解发动机在不同转速、负荷和瞬态状态下的运行特性，很难快速建立稳定产品。
  • 因此，即使埃隆·马斯克等潜在竞争者计划自研航改燃机，也很难在未来1.5至2年内迅速建立完整零部件、控制系统和量产体系。

e) 新进入者能否通过自制叶片快速解决供应问题？

  • 普通翼型件市场已有多家PMA供应商，新进入者即使形成能力，也可能只是新增一家PMA供应商。
  • 真正短缺的是高压涡轮叶片和寿命限制件。
  • 非型号合格证持有人需要向FAA证明产品符合持续适航要求，认证过程复杂。
  • 以Chromalloy为例，高压涡轮叶片获得FAA批准约耗时4至5年。
  • 因此，新进入者很难在2至3年内建立可与OEM相当的高价值关键件制造能力。

9. FTI与Jera的职责分工

a) FTI和Jera分别负责哪些工作？

  • FTI负责：
  1. 在蒙特利尔生产和组装发动机
  2. 在迈阿密将发动机与PTO、发电机和齿轮箱结合测试
  3. 最终系统测试
  4. 测试问题排查与修复
  • Jera负责：
  1. 将设备集成并封装为移动式拖车发动机系统
  2. 完成外部壳体和拖车式结构
  • 整体流程为：
  1. 蒙特利尔制造发动机
  2. 迈阿密进行动力链测试
  3. 运送至Jera进行最终封装
  4. 再运回FTI完成最终系统测试

b) Jera是否能够支持2027年100台产能目标？

  • 专家对Jera封装环节的参与有限，但目前了解的进展符合预期。
  • 当前主要工作是准备驱动装配线所需的材料。
  • 封装工作尚未正式大规模开始，因此Jera仍有时间调整流程和配置能力。
  • Jera在封装流程调整方面效率较高，现有工厂能力基本符合FTI要求。
  • 当前没有证据显示Jera会成为2027年100台目标的主要瓶颈。

10. 项目延期风险与替代能源竞争

a) 如果首次交付或产能爬坡推迟6个月，最可能的原因是什么？

  • 造成6个月严重延期的最可能原因，是此前未预见的重大蠕变失效。
  • 这类问题可能要求：
  1. 重新设计关键热端部件
  2. 重新制造零部件
  3. 重新开展长时间耐久性测试
  4. 重新定义运行包线
  • 由于项目已经进入最终定型阶段，只有重大重新设计才可能导致6个月级别延期。
  • 专家认为发生这种情况的概率较低。

b) 更现实的延期因素是什么？

  • 更可能造成局部延期的是燃烧室排放约束。
  • 其影响更可能表现为：
  1. 第2次或第3次迭代推迟数月
  2. 效率优化进度放缓
  3. 排放控制方案需要更多测试
  • 第1次迭代仍可用于证明航改燃机能够稳定运行并达到25MW，因此燃烧室优化不太可能使整个生产计划推迟6个月。

c) Crusoe取消Boom订单对Mod 1有何启示？

  • 客户对交付时间高度敏感。
  • 如果供应商无法按照客户预期时间提供产品，客户会迅速寻找替代方案。
  • Mod 1的主要优势之一，是相较其他航改燃机方案具备更快的交付速度。
  • 潜在风险除交付速度外，还包括：
  1. 实际效率不及预期
  2. 现场支持不足
  3. 长期可靠性验证不足
  4. 出现成本更低的新型能源方案

d) 氢能等替代能源是否构成重大风险？

  • 当前氢能的能量密度和产业成熟度尚未达到与航改燃机同等水平，短期内不构成直接重大威胁。
  • 长期而言，大型能源用户可能采用混合能源方案，包括：
  1. 航改燃机
  2. 太阳能
  3. 电池储能
  4. 氢能
  5. 煤炭或其他传统能源
  • 客户并不执着于某一种技术路线，核心需求是快速、可靠、低成本地获得电力。
  • Mod 1长期竞争力将取决于交付速度、可靠性、效率和总体能源成本。

11. 传统航空业务中的PMA零部件趋势

a) 航空客户对PMA零部件的接受度如何变化？

  • CFM56正逐步进入生命周期后期，客户对低成本维修方案的需求持续上升。
  • 随着OEM减少相关零部件生产或供应，航空公司不得不寻找PMA替代方案。
  • 过去一年，航空公司对PMA零部件的态度明显改善。
  • 部分过去从不考虑PMA的航空公司，已经开始采购配置全套PMA零部件的发动机。
  • 已有航空公司采购包含以下PMA部件的发动机：
  1. HPT NGV
  2. HPT叶片
  3. LPT第1级NGV
  4. HPT护环
  5. 压气机叶片等其他部件

b) 航空公司如何逐步验证PMA零部件？

  • 航空公司通常会先将采用PMA零部件的发动机作为机队先导样本。
  • 其核心是观察该发动机能否达到与其他发动机相同的可靠性。
  • 若先导发动机表现稳定，航空公司对PMA高价值零部件的接受度可能进一步提升。
  • 当前部分航空公司仍倾向先采用重要性相对较低的PMA件，例如起动机，再逐步扩展至核心热端部件。

c) 为什么PMA在航改燃机领域更具吸引力？

  • 航空公司对PMA的主要顾虑来自飞行安全和既定维修规范。
  • 工业发电和航改燃机不用于飞行，因此对适航和飞行安全的限制明显较少。
  • 在航改燃机领域，PMA可以带来：
  1. 更低采购成本
  2. 更短交付周期
  3. 更灵活的供应商选择
  4. 更高维修和改装利润率
  • 因此，PMA零部件在Mod 1项目中的应用吸引力明显高于传统航空场景。
