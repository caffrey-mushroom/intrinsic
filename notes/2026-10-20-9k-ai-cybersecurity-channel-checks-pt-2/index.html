2. Palo Alto Networks业务表现与增长展望

a) Palo Alto主要代理哪些产品？

  • 专家覆盖Palo Alto全部主要产品，包括：
  1. Strata
  2. Prisma Access
  3. Prisma SD-WAN
  4. Prisma Cloud
  5. Cortex XDR
  6. Cortex XSIAM
  7. Cortex XSOAR
  8. AI Runtime Security
  • 此外还跟踪CyberArk、QRadar、PAN-OS及操作系统订阅、Unit 42等业务。
  • CyberArk在被收购前已由专家所在机构代理，收购后仍作为独立子业务进行跟踪。

b) 本季度Palo Alto新增客户ACV表现如何？

  • 新增客户平均ACV约为50万至80万美元。
  • 新增客户合计ACV约为6,800万至8,300万美元。
  • 上述金额完全来自新增客户，不包含现有客户扩张。

c) Palo Alto增长主要来自新增客户还是现有客户？

  • 新增客户通常贡献约25%的业务。
  • 现有客户贡献约75%，是Palo Alto业务增长的主要来源。
  • 现有客户增长主要依靠平台化战略，即客户持续增加新的产品功能和安全能力。
  • 过去9至12个月，Palo Alto业务同比增速基本维持在14.6%至15.2%，季度环比表现总体稳定。

d) 2027年Q1的增速预计如何？

  • 预计2027年Q1增速小幅加快至15%左右，更具体的预测区间为15.2%至15.6%。
  • 主要增长动力包括：
  1. Prisma Access持续渗透。
  2. Cortex全系列产品采用率提升。
  3. 硬件防火墙需求在过去约3个半月明显增强。
  4. 防火墙更新换代过程中，客户逐步转向SD-WAN和软件定义架构。
  5. AI部署增加了企业对网络边缘控制的重视。
  6. AI相关微分段、网络分段需求持续提升。

e) 为什么硬件防火墙需求重新增强？

  • 前沿AI实验和AI部署引发新的安全担忧，客户希望加强对整个网络生态，尤其是网络边缘的控制。
  • AI工作负载推动微分段和网络分段需求上升。
  • 防火墙替换周期本身也在提供需求支撑，但需求并非单纯来自设备更新。

3. CrowdStrike业务表现与产品增长结构

a) CrowdStrike主要代理哪些产品？

  • 专家覆盖CrowdStrike Falcon Complete相关全部产品，主要包括：
  1. 终端安全
  2. 云安全
  3. LogScale下一代SIEM
  4. AI安全
  5. 身份安全
  6. MDR及其他Falcon平台能力

b) 本季度新客户和现有客户分别贡献多少？

  • 新客户ACV合计约为3,300万至4,500万/4,600万美元。
  • 目前新客户贡献略高于30%，现有客户贡献约2/3至70%。
  • 去年同期，新客户收入贡献比例曾超过40%至42%，目前已下降至约30%。
  • 新客户占比下降，一方面反映业务基数扩大，另一方面说明现有客户扩张正在成为更重要的增长来源。

c) CrowdStrike本季度整体增速是多少？

  • 2026年Q3，专家负责的CrowdStrike业务同比增速约为27.3%。
  • 当前增速高于CrowdStrike原有计划水平。

d) 2027年Q1增速会加快还是放缓？

  • 预计2027年Q1增速将小幅放缓至25.8%至26.4%。
  • 相比当前27%以上的增速，预计下降约0.5个百分点，最多可能下降约0.7个百分点。
  • 尽管增速边际放缓，CrowdStrike仍将维持较高的同比增长水平。

e) CrowdStrike哪些产品增长最快？

  • 增长较快的前三类业务包括：
  1. LogScale/下一代SIEM
  • 正在成为Splunk客户的替代选择。
  • 即使不能完全替代Splunk，也可在数据处理、数据保留和数据存储等环节实现部分替代。
  • 过去近15个月保持强劲增长。
  1. MDR服务
  • 企业对端点威胁的认知持续提高。
  • CrowdStrike架构以端点为中心，Falcon MDR具备较强的自然延展能力。
  • 若将MDR视为XDR的子集，其增长逻辑更加清晰。
  1. 云安全
  • 产品竞争力较强。
  • 与Falcon整体平台集成良好，可受益于平台化销售和交叉销售。

4. Zscaler业务表现、竞争压力与产品分化

a) Zscaler主要代理哪些产品？

  • 专家覆盖Zscaler完整产品组合，包括：
  1. Zero Trust
  2. ZPA、ZIA
  3. Data Security
  4. DSPM
  5. DLP
  6. CASB
  7. SecOps
  8. Security for AI
  • 专家所在机构近期还启动了MSP项目，由合作伙伴接管客户许可证并提供托管服务，但该服务不属于Zscaler自身产品组合。

b) 本季度Zscaler新增客户ACV情况如何？

  • 新增客户ACV约为1,400万至2,100万/2,300万美元。
  • 本季度新增客户接近40家。
  • 2026年以来，新客户贡献比例基本维持在20%左右，并因竞争加剧而继续下降。
  • 超过80%的业务收入来自现有客户，现有客户扩张是核心增长来源。

c) Zscaler本季度整体增速是多少？

  • 2026年第三自然季度同比增速约为24.6%，基本符合计划。
  • 现有客户仍在持续扩张，主要增加ZPA、ZIA、零信任、CASB、DLP、数据安全及AI安全等能力。

d) 2027年Q1增速预计如何？

  • 预计增速将明显放缓。
  • 到2027年Q1末，增速可能较当前下降1.5至2个百分点，更准确的判断约为22%。
  • 预计2027年上半年增长目标可能下调至19%至22%，低于当前23%至25%的目标区间。

e) Zscaler增速放缓的主要原因是什么？

  • SSE、SASE和SD-WAN市场竞争持续加剧。
  • 主要竞争对手包括：
  1. Palo Alto Networks
  2. Fortinet
  3. Netskope
  4. Cato Networks
  5. Cloudflare，尤其是Cloudflare One
  • Zscaler收入仍较集中于SSE和零信任产品，产品结构相对单一。
  • 与Palo Alto及一定程度上的CrowdStrike相比，Zscaler尚未形成同等完整的端到端安全产品体系。

f) Zscaler各产品线的增速如何分化？

  • 零信任和SSE
  1. 是未来增速放缓最明显的产品领域。
  2. 增速预计从当前10%以上区间高位至20%以上区间初段，下降至10%以上区间中段。
  • DSPM
  1. 预计同比增长超过40%，约为42%。
  2. 增长较快但基数较小。
  3. 是Zscaler推动平台化的重要切入点，但当前能力仍相对有限。
  • CASB和DLP
  1. 预计同比增速均在30%左右。
  2. 两者仅因增长预期接近而放在一起讨论，并非技术上属于同一产品。
  • AI安全
  1. 需求将继续增长，但当前基数很小。
  2. Zscaler正在加大投资并通过收购补充能力。
  3. 预计未来6至9个月内尚不足以形成显著规模化增长。

5. Cloudflare安全业务与Developer Cloud表现

a) 专家覆盖Cloudflare哪些业务？

  • 专家覆盖Cloudflare全部产品，不仅包括安全业务，也包括Developer Cloud。
  • Developer Cloud是当前Cloudflare增长较快的业务板块之一。

b) Cloudflare安全业务本季度增速是多少？

  • 2026年Q3，Cloudflare安全业务ACV同比增速处于20%低段至中段。
  • 统计范围包括API安全、CASB、SWG、ZTNA，以及部分CDN性能服务。

c) 2027年Q1，CDN和安全业务的增速分别如何？

  • CDN及性能服务
  1. 产品基础已较为成熟。
  2. 预计2027年Q1同比增速为中高个位数。
  • 安全产品
  1. 已成为Cloudflare的主要增长引擎。
  2. 预计2027年Q1同比增速为27%至32%。
  3. API安全、浏览器隔离及Cloudflare One等产品将提供主要推动力。

d) Cloudflare哪些安全产品增长较快？

  • API安全及API安全态势管理
  1. 是增长最快的产品之一。
  2. AI应用带来大量API密集型部署，推动API安全需求。
  3. API安全态势管理正在持续获得客户认可。
  • CASB
  1. 受益于应用现代化、云迁移和SaaS使用增加。
  2. 企业对云环境治理的需求随之上升。
  • DLP
  1. 企业对数据治理、数据泄露管理和控制的需求持续增加。
  2. 部分地区的监管要求进一步推动DLP采购。
  • Cloudflare One
  1. 正在成为Zscaler面临的前三大挑战之一。
  2. 不仅能够替代传统VPN，还可以帮助客户整合多个单点安全产品。
  3. Cloudflare拥有广泛的物理接入点覆盖，可靠性和网络基础设施是其核心竞争优势。

e) Cloudflare哪些产品增长相对较慢？

  • 机器人管理
  1. 同比增速仍在百分之十几的中段。
  2. 由于Cloudflare整体业务增速已超过26%至27%，该业务相对较慢。
  3. 产品已经较广泛应用，独立新增需求弱于API安全和CASB。
  • DDoS
  1. 属于Cloudflare旗舰产品，但市场成熟度和渗透率较高。
  2. 同比增速约为7%至12%，处于中个位数至低双位数。
  3. 市场主要参与者包括Cloudflare、Akamai及Fastly。
  • WAF
  1. 安装基础较大，增长趋于饱和。
  2. 当前仍保持百分之十几前段的合理增长。

f) Cloudflare客户留存情况如何？

  • 专家称Cloudflare客户留存率通常在94%以上。
  • 客户流失率通常低于5%。
  • 该回答更接近客户续约或留存率，并非严格意义上包含扩张收入的NRR，因此不宜直接将94%视为标准净收入留存率。

g) Developer Cloud本季度增长如何？

  • Developer Cloud本季度消费额同比增速约为40%至46%/47%，平均约40%。
  • 统计范围包括：
  1. Workers
  2. Durable相关产品
  3. Vectorize
  4. AI Gateway
  5. 其他开发者云产品
  • 部分AI客户群体的消费增速高于业务平均水平。
  • Developer Cloud已成为Cloudflare增长最快的业务板块之一。

6. Okta增长、产品短板与客户留存

a) Okta本季度ACV增速是多少？

  • 2026年Q3，Okta ACV同比增长10.8%。
  • 整体增长区间约为9.6%至11%。

b) 2027年Q1增速预计如何？

  • 预计保持相对稳定，增速区间约为10.5%至11.2%。
  • Okta在身份验证和授权领域仍具备较强竞争力。
  • 中小企业市场表现仍然良好，但尚未有效突破大型企业高端市场。

c) Okta在大型企业市场面临哪些问题？

  • 大型企业对身份治理和管理的需求日益复杂，主要包括：
  1. 精细化权限控制
  2. 证书管理
  3. JML，即员工入职、调岗、离职全生命周期管理
  4. 自动化治理
  • Okta通过OIG提供身份治理产品，但在治理深度和精细化程度方面弱于SailPoint和Saviynt。
  • 自动化功能的直观性和易用性仍有不足。
  • Okta过去3个月推出了面向AI智能体的新产品，方向积极，但尚未对大型客户交易产生显著影响。

d) Okta的NRR大约是多少？

  • 专家给出的估计约为88%。
  • 原始表述同时出现“低于80”和“约88%”，存在内部矛盾；结合最终数字，纪要以约88%记录。
  • 相对较低的净留存表现与Okta在治理和管理能力上的短板有关。

7. 合同期限与签约季节性

a) CrowdStrike合同期限如何分布？

  • CrowdStrike合同期限整体偏长，平均期限约为3年以上。
  • 具体构成大致为：
  1. 3年及以上合同约占65%，约为全部合同的2/3。
  2. 2年期合同约占20%至22%。
  3. 1年期合同通常低于10%。
  • 2年及3年以上合同合计约占85%至87%，长期合同是主流。

b) 网络安全合同签订是否存在季节性？

  • Q4通常是全年最强的签约季度。
  • Q4集中了较多长期合同、高ACV合同和高TCV合同，主要原因包括：
  1. 企业在年度结账前仍有预算可供使用。
  2. 网络安全已从可选支出转为必要支出。
  3. CFO和CIO的剩余预算更容易流向网络安全项目。
  4. 采购部门通常要求在年底前完成交易。
  • 相关需求通常在Q3末开始显现，并在Q4集中落地。
  • 访谈未提供Q1至Q4各季度ACV占全年的具体比例。

8. 网络安全整体预算与2027年行业展望

a) 2026年网络安全预算表现如何？

  • 专家负责的整体网络安全业务预计在2026年增长16%至18%。
  • 这一表现明显高于年初12%至14%的预期。
  • 客户网络安全预算整体处于上升状态，未出现明显削减。
  • AI预算虽然逐步独立核算，但同时产生下游安全需求，进一步推动网络安全预算增长。

b) 2027年网络安全市场增速预计如何？

  • 预计2027年整体网络安全业务增长17%至19%，较2026年进一步加快。
  • 主要驱动因素包括：
  1. 市场对安全态势管理的认知提升。
  2. 数据安全投资增加。
  3. 身份安全需求提升。
  4. 终端保护和网络安全持续受到重视。
  5. 云迁移和应用现代化持续推进。
  6. AI及智能体部署带来新的治理、权限和数据安全需求。

c) 为什么AI部署会推动安全预算增加？

  • 企业通常在部署AI工作流和智能体后，才意识到自身存在以下问题：
  1. 缺乏有效治理。
  2. 没有完整的AI资产或智能体清单。
  3. 无法掌握不同智能体正在执行的任务。
  4. 无法清晰识别智能体拥有的访问权限。
  • 上述问题将直接利好数据治理、身份安全、特权访问管理和安全态势管理厂商。

9. AI及智能体带来的新增安全采购

a) AI安全投入是在挤占原有预算，还是形成新增预算？

  • 在专家负责的客户群体中，超过2/3、接近70%的客户已经为AI投资设置独立预算科目。
  • 去年年底至今年年初，AI投入主要被归类为创新预算，资金来源包括：
  1. CFO掌握的灵活预算
  2. CTO或CIO预算
  3. 各业务线预算
  • 当前越来越多企业将AI安全设置为独立预算科目，与基础设施、企业平台和订阅预算并列。
  • 因此，AI安全更多是在形成新增预算，而非简单挤占原有网络安全支出。

b) 企业部署AI智能体后，哪些安全能力成为刚性需求？

  • 无论智能体是自治、半自治或非自治，只要以智能体形式访问企业资源，就会直接推动以下安全采购：
  1. 身份治理：识别智能体身份、权限及生命周期。
  2. 特权访问管理（PAM）：控制智能体对高权限系统和关键资源的访问。
  3. 机密、密码和凭证管理：保护智能体使用的密钥、令牌、密码及其他敏感凭证。
  4. 智能体治理和访问治理：监控智能体执行任务、访问范围和行为边界。
  • 智能体安全的核心问题是“谁在访问什么、以何种权限访问、执行了哪些操作”，因此身份和访问治理是最直接的受益领域。
  • 会议最后进一步提出Copilot推广、数据湖等AI投资可能带来的其他安全需求，但原始记录未包含后续回答。
