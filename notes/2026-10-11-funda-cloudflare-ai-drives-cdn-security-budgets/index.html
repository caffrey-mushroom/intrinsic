原标题：Cloudflare — AI 驱动下的内容分发与安全预算增长

#security #networking

Funda · 2026-10-11

FSLY, NET, AKAM, AMZN, GOOGL, FFIV, PANW, CRWD, Content Delivery Network

Expert · Senior Account Manager, Top global cloud security provider Wooding, Stella

摘要

  • 取决于统计范围的预算增速 — 据该行业专家估计，2026 年纯内容分发网络预算增长约 10%-15%，而内容分发网络应用、安全和性能合计预算增长 20%-30%。对于 2027 年，其先估计纯内容分发网络增长 10%-20%，随后又称实际增速可能更高；包含网络安全的更广泛预算预计增长 30%-40%。
  • AI 驱动的安全需求 — 该行业专家估计，客户安全预算增长 20%-30%；若非在大语言模型供应商处投入大量 token 费用，增速可能更高。AI 使用是采购的主要驱动因素，包括对 AI Gateway 护栏和模型级限流功能的需求。
  • 安全附加产品的合同增量 — 据该行业专家估计，单独购买 API 接口安全和机器人管理产品通常可使现有合同金额增加 20%-30%。在另一个粗略的 API Shield 示例中，约产生 10 亿次请求的大客户每月合同增量约为 1 万-2 万美元。
  • 内容分发网络的高安全产品附加率 — 该行业专家表示，由于 Cloudflare 为托管网站免费提供不限用量的分布式拒绝服务防护，仅购买内容分发网络的情况很少。其估计，70%-80% 的内容分发网络客户会以某种形式使用网络应用防火墙。
  • 超额用量变现 — 据该行业专家在其本人经手的合同中观察，2026 年所见合同条款对超出约定额度的用量明确约定了计费安排。在超过额度的客户中，用量通常比合同约定水平高 10%-20%。
  • Fastly 在所观察地区的出现频率有限 — 该行业专家在其负责的佛罗里达地区约每 10 笔交易遇到 Fastly 1 次，在接近两年内合计仅遇到 3-4 次，其中 2026 年为 1-2 次。其明确承认带有偏向性的个人估计是，Cloudflare 在正面竞争中的胜率为 60%-70%，Fastly 为 30%-40%。
  • 价格差距被竞争性折扣削弱 — 该行业专家认同，在同类方案比较中，Fastly 可能比 Cloudflare 便宜 20%-25%。不过，其回忆称，在多家供应商同时竞标的竞争性交易中，折扣幅度可达公开标价的 90%，具体视交易情况而定。
  • 多内容分发网络架构增强韧性 — 据该行业专家观察，大客户通常会使用 3-4 家而非仅 2 家内容分发网络供应商。服务中断提升了客户对备用供应商的需求，也使多内容分发网络架构更加普遍。
  • 自助服务优势与转化阻力 — Fastly 同样提供自助服务，但该行业专家认为 Cloudflare 的自助方案提供了明显更多的价值。客户每年支付 250 美元即可获得基本所需的全部功能，这既能成为进入客户账户的切入点，有时也会降低客户升级到企业方案的意愿。
  • 活跃的平台整合需求 — 该行业专家估计，其经手交易中有 30%-40% 包含将其他供应商流量或工具进行整合的内容。其表示，Cloudflare 可利用折扣空间增加收入，同时降低客户的总体成本。
  • 广泛的网络安全投入重点 — 身份管理、智能体安全、数据防泄露、应用安全和数据安全被列为客户重点关注领域。该行业专家还观察到对 AI 网关的需求，这类产品可分析或拦截提示词，并保护与大语言模型的交互。

关键要点

  • 预算增长强劲但预测精度有限 — 该行业专家将 2026 年纯内容分发网络 10%-15% 的增速，与内容分发网络、安全和性能合计 20%-30% 的增速进行了区分。其在回答过程中将 2027 年纯内容分发网络增速从 10%-20% 上调为可能更高，因此该判断更适合作为方向性估计，而非精确预测。
  • 安全产品扩大内容分发网络客户支出 — 据该受访专家本人负责客户的观察，约 70%-80% 的网络应用防火墙附加率、API 接口安全或机器人管理产品带来的 20%-30% 单独增量，以及客户 10%-20% 的超额用量，为基础内容分发网络支出之外提供了多条扩张路径。
  • AI 既是需求催化剂也是预算约束 — AI 使用提升了客户对模型护栏等安全控制的需求，但在大语言模型供应商处的 token 支出也限制了客户可进一步分配给安全产品的预算。
  • Fastly 带来的挑战不仅是定价，更在于交易出现频率 — 尽管同类方案被认为便宜 20%-25%，Fastly 在该行业专家负责的佛罗里达地区仍仅约每 10 笔交易出现 1 次。不过，对 Fastly 的既有熟悉度及本地客户团队与决策者的距离仍可能决定单笔交易结果。
  • 韧性需求支撑多供应商支出 — 客户通常使用 3-4 家内容分发网络供应商，并希望通过备用供应商应对服务中断，表明即使某一家供应商获得最大流量份额，客户架构也并非赢家通吃。
  • Cloudflare 的分销模式以转化阻力换取覆盖面 — 每年约 250 美元的自助服务形成低成本获客入口，但该行业专家表示，其较高价值也可能使客户不愿升级至企业方案。
  • 整合已成为重要销售路径 — 据该行业专家估计，其经手交易中有 30%-40% 包含整合内容，平台广度和折扣灵活性因此成为 Cloudflare 竞争方式中的常见要素。

内容防火墙是 Cloudflare 去年推出的功能，最初名为 Pay-per-crawl（按抓取付费）。这是机器人管理内嵌的一项功能，客户可以启用它。如果有大型网络爬虫（例如 OpenAI、Google 或 Anthropic 的爬虫）为了获取内容而抓取网站，网站方即内容所有者就可以对访问其网站内容的行为进行收费。这正在改变我们如今所理解的互联网模式，因为以往的模式很大程度上依赖流量，并通过广告来获取收入。但现在人们不一定会亲自访问实际的网站，而是在自己的 ChatGPT 或 Gemini 窗口中直接查看弹出的所有内容，导致内容公司损失了大量的广告收入。
