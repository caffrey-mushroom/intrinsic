摘要

以下观点来自行业资深专家：1.在产品出货方面，立式加工中心和车床是国内外市场出货量最高的品类，其次是龙门加工中心，再次是镗床和卧式加工中心。2.海外市场可以分为几个梯队。第一梯队是东南亚地区，如越南、马来西亚、泰国和印度，这些市场目前最为活跃。第二梯队是东欧国家，如波兰。3.下游应用领域中，汽车行业是第一大板块，包括新能源汽车和传统燃油车及其相关产业链，约占业务的50%。其次是工程机械领域，涵盖阀门、轴承以及悬臂、叶轮等通用机械零部件的加工。

1.请介绍一下纽威数控的基本情况。

纽威数控成立于1997年，之前是纽威集团旗下的事业部，2021年已在科创板上市。纽威数控专注中高档数控机床的研发、生产与销售，产品覆盖七大系列：数控卧式/立式车床、立式/卧式加工中心、龙门加工中心、数控铣镗床等，还可提供定制化专门机床及加工自动线。纽威数控现有员工约2000人。

2.当前出货量较高的产品品类及其大致占比？

纽威数控专注于金属切削机床领域，目前已推出七大系列产品，平均每个系列约有200个机型。

在产品出货方面，立式加工中心和车床是国内外市场出货量最高的品类，其次是龙门加工中心，再次是镗床和卧式加工中心。

以公司年产约5,000台机床的规模来看，立式加工中心和卧式车床的年产量各约1,000台，龙门加工中心约800台。其他品类的产量则不固定，受项目类订单影响较大，例如某个品类在常规年份可能销售200台，但一个大项目就可能使其年销量增至300台。

3.在纽威数控的7个主要产品系列中，具体哪些型号或类型的机床市场表现较好？

各产品系列中市场表现较好的机型分布如下：

立式车床：各尺寸机型销售情况较为平均。小型立车中，工作台直径800mm（80系列）的纯车床和车削中心，以及60系列、100系列和40系列均有不错的销量。中型立车中，125系列是销量最好的，无论是纯车削还是车铣复合功能都受欢迎。大型立车中，工作台直径2.5米（250系列）和4米（400系列）的机型销售良好；近期已向西班牙客户交付了一台工作台直径5米的立车，向国内客户交付了一台6.3米的机型。

立式加工中心：从小到大，工作台尺寸从750mm x 420mm到1.2m x 600mm的机型，无论是皮带主轴、直连主轴还是电主轴配置，都非常畅销。尺寸更大的机型，如1.7m x 800mm和1.8m x 800mm，配备齿轮箱以实现高扭矩重切削的型号，销售情况也尚可。硬轨机床在国外市场更受欢迎。五轴立加方面，国内外市场需求均较多，其中工作台尺寸450mm和650mm的机型因通用性强而销量最大。

龙门加工中心：HC、HP和HA系列在国内市场较为畅销，基本能满足大部分客户需求。重切削能力更强的HZ和SC系列则更多面向有特定需求的国外客户。五轴龙门机床（U系列）销售情况良好，其中自制五轴头的机型因价格和交期优势，比外购Kessler头的机型更受市场青睐。

镗床：主要分为HB（十字滑台）、PB（抱台式）和FB（落地式）三个系列。其中PB系列销量最好，HB系列因在加工效率和价格上与PB系列重合度高，已趋于淘汰。PB系列中的线轨、硬轨、包主轴箱式和包滑枕式机型均销售良好，2026年至今已售出200多台。FB落地式镗床对客户的厂房和工件有较高要求，2026年至今已售出二三十台。

卧式车床：小型机床中，NL251型号（包括带铣功能的车铣中心）销量最好；中型机床中，50系列和63系列是销量最高的，无论是纯车削还是带动力刀塔的车铣中心都非常受欢迎；大型机床中，125系列（最大加工直径1.25米，加工长度可达3米）较为畅销，适用于大型轴承类零件加工。此外，平床身机床也可选配动力刀塔实现车铣复合功能。

卧式加工中心：高速型HE系列和重切型HM系列均有不错的市场表现。HE系列中，工作台尺寸为500mm x 500mm、630mm x 630mm和800mm x 800mm的机型销量很好，主要以项目形式销售，例如一个汽车零部件项目曾采购100多台HE800机型。HM系列中，630mm x 630mm和1.25m x 1.25m的机型较为畅销。卧加产品线同样提供五轴机型。

自动化产线：截至2026年9月，已售出近200条自动化产线，预计全年销量可达250条。

磨床：作为2026年新推出的产品，主要包括立磨和螺纹磨，目前已在国内市场实现销售。

4.目前纽威数控的国内外收入占比情况如何？未来有何展望？

当前纽威数控的收入结构为国内市场占70%，国外市场占30%。未来将延续以国内为核心市场的格局，因为国内市场始终是最大的用户群体。未来目标是希望将国内外收入占比调整至六四开，即国外市场提升至40%，但实现这一目标存在较大挑战。纽威数控通过海外代理商覆盖大多数区域市场，同时组建专属直销团队直接服务海外大型工业客户，配套建立本地化销售服务商激励体系，快速拓展市场份额。

5.在海外市场中，哪些区域是当前的重点市场？

海外市场可以分为几个梯队。第一梯队是东南亚地区，如越南、马来西亚、泰国和印度，这些市场目前最为活跃。第二梯队是东欧国家，如波兰，得益于前期的市场布局，2026年实现了快速增长。之后是南美和中东市场。西欧市场，如法国、德国、意大利，由于是传统工业强国，本土品牌竞争激烈，市场开拓难度较大。

6.纽威数控产品主要面向的下游应用领域有哪些？

纽威数控的下游应用领域中，汽车行业是第一大板块，包括新能源汽车和传统燃油车及其相关产业链，约占业务的50%。其次是工程机械领域，涵盖阀门、轴承以及悬臂、叶轮等通用机械零部件的加工。此外，模具、风电和半导体也是公司的下游应用领域，但占比较小。

7.2026年各下游行业的景气度如何？

从下游行业来看，汽车行业的需求表现较为坚挺。得益于纽威自有阀门业务的支撑，阀门行业的需求也保持稳定。相比之下，模具和航空航天行业的需求表现则不甚理想。

8.纽威数控当前的产能规模及利用率情况如何？

纽威数控的所有厂区均集中在苏州高新区，2025年，纽威数控一、二、三期工厂的合计产能为5,000台。2026年，随着四期工厂顺利投产，主要聚焦高端五轴联动加工中心、精密功能部件的智能化量产，预计全年产能可达到6,000台左右。

目前产能利用率难以精确计算，主要受制于数控系统和丝杠等核心部件的供应。数控系统供应量决定了实际产量，当前数控系统供应非常紧张，导致生产排期紧凑，装配工作已扩展至仓库空间。此外，纽威数控五期工厂预计将于2027年3月建成并开始排产。该厂区将专门聚焦数控立车、精密磨床、专用机床及核心功能部件的研发生产。

9.目前在纽威数控的交付周期情况如何？

当前机床产品的交付周期非常不稳定，这是行业普遍面临的难题，主要原因是受到发那科、西门子、华中、新代等品牌数控系统的供应限制。以NL63车床为例，以往的交付周期约为1.5个月，而现在由于系统供应问题，交付周期延长至3个月，几乎翻倍。这并非由装配能力不足导致，而是因为缺少系统和电机无法完成生产。

10.2026年以来产品价格有何变化？背后的原因是什么？

2026年相较于2025年，产品价格进行了微调。卧式车床价格基本保持不变，立式加工中心价格稳定。立式车床、龙门加工中心（部分型号）、卧式加工中心以及镗床的价格则有小幅下调。部分产品的价格下调主要原因是国内同行业竞争激烈，为保持市场竞争力，必须通过优化自身结构和供应链来降低成本。若不降价，面对国内部分厂商的低价策略，产品将丧失价格优势，这在国内和国际市场都是主要考量因素。

11.纽威数控的核心竞争力体现在哪些方面？

纽威数控的核心竞争力主要体现在三个方面。第一，拥有全国最完整的产品矩阵，能够为客户提供整套、完整的自动化生产线解决方案。从普通中小零件铣削，到航空航天大跨度复杂曲面加工，都能提供对应的机型。

第二，核心部件自研能力强，包括电主轴、五轴转台、摆头、刀架、主轴箱、主轴乃至平面磨床的平衡盘等均可自主生产。这些部件完全针对整机特性定制设计，整机匹配度远高于外购部件，大幅降低了生产成本，以平衡盘为例，自制产品报价10万元人民币，而欧洲品牌价格高达70万元，成本优势显著。

第三，建立了广泛的国内外售后服务网络，国内几乎每个城市都能实现24小时内配件发货，售后仓库备件估值较高。同时，正在逐步建设海外售后网点，如在伊斯坦布尔、新德里和河内等地。

12.目前零部件的国产化率水平如何？

零部件国产化率难以用一个固定比例来衡量，因为这主要取决于客户的选配需求。以数控系统为例，客户可以在华中和西门子等品牌中自由选择。同样，刀塔也可以选用自研产品、德国肖特或台湾六星的产品。纽威数控具备实现百分之百国产化的能力，甚至可以自主生产螺丝等基础部件，并采购华中或广数的数控系统。因此数控机床的配置具有高度的灵活性和可选性，与汽车等标准化产品不同。

13.纽威数控未来的研发方向是什么？

纽威数控正在进行机器人相关机床的研发，主要聚焦于人形机器人关节的连接部位模具。这可能是公司下一步的发展方向，对于其他机床产品，目前正致力于拓宽磨床产品线，以补全产品矩阵的短板。同时，滚齿机床的研发也已提上日程。此外会根据销售端，特别是外销团队提出的市场需求，进行新机型的研发，例如近期已开始生产的平床身带动力刀塔的机型，就是根据外部需求反馈而开发的产品。

14.如何看待当前国内机床行业的竞争格局？

国内机床行业的竞争格局因机型而异。对于技术门槛较低的三轴立式加工中心和两轴车床等产品，市场参与者众多，竞争主要体现在价格层面，包括纽威、海天、创世纪、乔峰在内的厂商都在进行价格竞争。而对于技术要求较高的五轴重切削龙门加工中心，国内具备生产能力的厂商较少，市场开始逐步用国产品牌替代进口旧设备，竞争格局相对较好。在龙门产品领域，主要竞争对手包括海天、精雕、科德，以及国外的马扎克、德玛吉和斗山。在镗床领域，国内厂商不多，主要是齐齐哈尔和昆明机床，但纽威的产品线更全，竞争压力相对较小。卧式加工中心和立式车床的主要竞争对手也基本是海天、创世纪等企业。在自动化生产线领域，各个厂商则没有太多可比性。
