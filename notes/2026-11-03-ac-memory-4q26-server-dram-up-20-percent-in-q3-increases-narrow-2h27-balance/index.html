核心摘要

  1. 专家称Q3 DRAM均价约+12%、NAND约+9%，预计Q4 DRAM涨幅收窄到约10%、NAND约7–8%。
  2. Q3服务器DRAM涨约20%，服务器和车用涨幅高于平均7–8个百分点，手机、PC和利基产品低5–6个百分点。
  3. 涨幅收窄的原因是今年DRAM约释放13万片/月、NAND约15万片/月产能(主要靠加设备和制程升级)，以及部分客户前期囤货。
  4. 新建洁净室需一年到一年半，2027年中以后才释放；专家预计2027年新增产能释放可能在2H27推动供需平衡和价格拐点。
  5. eSSD与普通SSD共用晶圆，一片V8 236层晶圆最多挑出约35%的eSSD Die，无法单独扩产，这是eSSD短缺的根源。
  6. QLC渗透率已达35–40%，2027年有望超过70%；NAND厂商更多、品类更分散，涨价幅度比DRAM低3–4个百分点、周期更长。

摘要

  • DRAM与NAND价格走势及不同应用领域需求；
  • 2027年DRAM/NAND供需格局及产能扩张；
  • NAND产品结构及技术发展。

以下是专家观点：

今年（2026年）下半年，DRAM/NAND的一些价格情况？包括服务器的DDR5，PC的DDR5，以及LPDDR5，还有NAND的eSSD，TLC、QLC的情况。

到目前为止，存储领域，包括DRAM和NAND，仍处于上行周期。Q3、Q4期间，DRAM和NAND的价格绝对值持续上涨，但自Q2以来，价格增幅逐步减弱。Q3刚刚结束，DRAM价格平均上涨约12%，NAND约9%。预计Q4，DRAM涨幅将减弱至10%，NAND约7%到8%。这主要由两个原因导致。第一，DRAM和NAND产能端有部分释放。今年DRAM约有13万片/月的产能释放，NAND约15万片，均为近期释放。产能释放方式有三种：一是新建厂房和洁净室，周期较长，需一年到一年半，预计明年中旬后才能释放，对今年产能无贡献。因此，今年释放的13万片DRAM和15万片NAND，主要通过后两种方式实现。第二种方式是在现有厂房增加设备，挤压空间，周期较短，约5到6个月。第三种方式是在现有产能基础上进行技改或代际升级，如将D1Y、D1Z的DRAM升级到D1α、D1β，或将V6、V7的128层和176层NAND升级到V8、V9的236层和296层NAND。这种升级方式周期更短，约3到4个月即可完成。因此，通过后两种方式，今年实现了13万片DRAM和15万片NAND的产能释放。第二个原因是部分客户前期持续囤货，库存量有所提升。虽然价格绝对值仍在上涨，因供给端尚未完全满足需求，但供需差距逐步缩小，价格增幅减弱。细分领域来看，DRAM和NAND可分为服务器、手机、PC、Notebook和利基型产品五大需求领域。服务器和汽车电子的涨幅均高于平均值5%~6%，服务器甚至高达8%左右。Q3期间，DRAM平均涨幅为12%，服务器领域约20%。主要原因是存储领域的主力需求来自AI场景，包括训练、推理和端侧应用。汽车电子涨幅也较高，但其在整体需求中的占比仅12%，影响有限。手机（LPDDR）、PC/Notebook（DDR）及利基型产品表现相对较弱。手机在今年一季度、3月前表现尚可，3月后随着存储涨价，价格接近理论上限，终端客户难以接受，需求量减弱。PC、Notebook同样如此，利基型产品上半年表现尚可，下半年也呈减弱态势。总体来看，服务器和汽车电子领域涨幅比平均值高7%~8%，消费级PC、Notebook、手机及利基型产品则低5%~6%。这是DRAM的情况。

NAND同样分为五大领域：服务器、手机、PC、Notebook、利基和车载。服务器eSSD场景增速较快，各大云服务器厂商对eSSD需求旺盛。但eSSD无法单独生产或扩产，因为eSSD与普通SSD共用产线和Wafer，仅在Wafer上挑选更优质的Die作为eSSD产品。一片V8 236层晶圆最多可挑出35%的eSSD Die，存在理论上限。若增加eSSD产量，普通SSD产量也会同步提升，形成产能矛盾。目前eSSD短缺正源于此，无法通过专门扩产或新建产线解决。关于TLC和QLC，QLC渗透率逐步提升，主流算力场景已采用QLC。QLC存储密度高于TLC，速度略低，但整体渗透率已达35%~40%，明年有望突破70%。目前NAND涨价对TLC和QLC影响幅度一致。整体来看，NAND涨价幅度较DRAM低3~4个百分点。三季度DRAM涨幅为12%，NAND仅8%~9%。主要原因是DRAM厂商较少，仅三星、海力士、美光及国内CX，而NAND厂商更多，包括三星、海力士、美光、铠侠、闪迪和YMTC等。厂商数量多，涨价或降价需各方趋势一致且幅度统一，周期更长。NAND产品类别多，涵盖UFS、eMMC、SSD、eSSD等，需求多样，各领域产品通用性不强。例如服务器eSSD与PC/Notebook用SSD无法通用，因其为挑选逻辑。因此，NAND涨价幅度和周期性均较DRAM更弱、更长。

DRAM中HBM有特殊情况。目前出现传统DRAM价格或毛利率高于HBM的现象，属于价格倒挂。主要原因是传统DRAM涨幅过高，以及HBM因签订一年期LTA长协，锁量锁价，未能涨价。LTA预计今年11月、12月到期，届时需重新议价，预计HBM价格将上涨60%~70%。HBM作为特例，未来涨价幅度较大，但每次签约后又会锁价一年，整体来看，HBM价格每次签约均呈上升趋势。产能端方面，原厂严格控制HBM扩产节奏，需求端则非常紧迫，对HBM性能和颗粒数要求高。HBM产品类别始终存在特殊需求。海外HBM3E基准价格约22~23美元/GB，与Google、NVIDIA、AMD等企业签订。而国内HBM3价格已达40~50美元/GB，主要因国内无法签订协议，只能通过第三方代理商采购，需加价。明年形势更严峻，国内将升级至3E水准，与海外主流企业竞争同一世代产品，难度加大。综上，HBM价格将持续上涨。

结合海力士刚发的财报，Q3的DRAM和NAND季度价格涨幅都超过20%，为什么公司的表现似乎低于海力士？

Q3的基准大约在20%左右，这一基准主要针对特定领域。海力士在服务器端的销售占比较高，而在消费电子端则有逐步退出的趋势。因此，服务器端的占比比普通产品类别平均值高出8到9个百分点，基本能达到20%。但如果将消费电子端纳入计算，整体占比就没有这么高。

公司在服务器、消费电子等不同领域的占比情况大致如何？在服务器表现良好、价格上涨的情况下，产品结构是否会调整？

目前服务器的占比已经提升至约40%，年初或去年仅为30%左右，提升了10个百分点。手机端占比约25%，PC端约18%，汽车电子约12%，利基性产品约10%，总计约100%。整体趋势是服务器占比持续提升，产品结构已发生调整。

服务器端价格涨幅每季度可达20%以上，但综合DRAM和NAND的平均涨幅只有10%左右，这是否偏低？

综合Q3来看，平均涨幅在12%至13%左右。服务器占比40%，其他领域占60%，平均下来涨幅就在这个范围。如果只看服务器端，确实有20%以上的涨幅。

预计Q4的涨幅情况如何？

Q4涨幅可能略低，预计会再下降两到三个百分点，目前整体趋势如此。

Q4服务器端，尤其AI相关的占比会继续提升吗？

目前服务器端占比已处于较高水平，预计只会提升一到两个百分点，整体基本持平。

AI领域的价格趋势如何？

AI领域的价格涨幅预计仍有20%左右，可能在19%至20%之间。

明年（2027年）三星规划中，AI领域占比基本维持在40%，不会再有调整吗？

预计到明年中旬以后，存储价格将达到顶峰并维持一段时间，随后进入下行周期。AI需求也会达到高峰，不会持续上涨。虽然有“AI泡沫”或“封顶”逻辑，但实际不会出现泡沫，需求会趋于稳定。明年扩产主要通过新建产能和洁净室，预计释放35万片DRAM和4 0万片NAND产能。新产能释放将带来供需关系的平衡，届时整体水位将持平或进入下行周期。

明年（2027年）NAND新建洁净室带来的产能释放情况如何？

明年预计新增40万片产能，其中YMTC约10万片，铠侠和闪迪十几万片，其他厂商扩产比例类似。

明年（2027年）价格拐点可能出现吗？

目前预计明年会出现价格拐点。

分产品来看，分别什么时候可能出现拐点？

NAND拐点预计在明年中旬七八月份出现，DRAM稍晚一两个月，约在九、十月份。HBM则持续上涨，不受影响。从供需关系来看，当前判断如此。

明年（2027年）下半年供需关系会趋于平衡吗？

预计明年供给端释放的产能与需求基本匹配，达到平衡。虽然原厂努力控制扩产节奏，但各家都希望提升市占率，整体匹配性将在明年实现平衡。

明年（2027年）各家新增产能情况，以及传统领域和整体供给缺口如何？

明年预计新增32万片产能，CX约9至10万片，其他厂商六七万片，三星、海力士、美光等企业规模相近。DRAM bit growth约15%，晶圆层面增长约20%。预计明年中旬至下旬，DRAM供给能弥补大部分产能缺口，但DDR5仍略有不足，约缺五六万片。市场通常会提前预判，接近平衡点时价格会提前下行。HBM是特例，目前月产32.6万片，三星14万片，海力士15万片，美光3.6万片。明年扩产15万片/月，三星、海力士各扩产4万片，美光扩产7万片，达到47.6万片/月。虽然扩产近40%，但GPU旁边的HBM颗粒数和堆叠层数都在增加。按平均每GPU放6颗HBM、每颗8层计算，全年可对应1800至1900万张板卡，预计明年需求超过2000万张，HBM仍处于紧缺状态。

明年（2027年）HBM扩产具体何时能达到目标？每季度或每月投片量与实际差距如何？

HBM投片量预计在明年8月份左右全部释放，4、5月开始陆续释放，历时四五个月，到八九月完成。下半年月产能可达47.6万片，但全年平均月产约42至43万片，无法达到47.6万片的平均水平。

DRAM和NAND的需求更多的是AI需求所推动，展望明年（2027年）的话，国内存储厂商扩产预计对AI领域需求有多大贡献？

实际上他们俩的贡献很少。虽然两家扩产的规模都在8到10万片左右，无论是DRAM还是NAND，但从技术角度来看，他们与海外厂商存在1.5到2代的差距。比如cx目前只能做D1z，15.8纳米，而三星、海力士、美光的主流产品已经到达D1beta，甚至向D1gamma推进，中间还差一个D1alpha。DRAM基本上差了两到两代半。NAND方面，ymtc能做V8，而其他厂商如三星、海力士、美光、铠侠、闪迪已能做V9、V10。因此至少也差了1.5到2代。基于这种情况，他们在AI服务器上的应用很难实现，主要还是集中在中低端市场，尤其是消费电子领域。在服务器市场，包括通用服务器，他们的市占率都很低，应该不到6%。所以对于AI需求的紧迫性，主要还是由三星、海力士、美光、铠侠、闪迪这些企业来满足。

展望明年（2027年），NAND实际能够增加出来的量，用于AI部分的能有多少？

总量大约是40万片NAND，其中约33%适用于AI场景，包括eSSD和高级SSD等通用型SSD。因此大约有13到14万片NAND可以用于AI服务器场景。现在各家都在签订大量LTA长协，库存也在增加。整体需求虽然持续增长，但增幅在减弱。双重作用下，供需关系会趋于平衡。价格一般会在接近平衡时提前做出判断，真正达到平衡可能要到明年（2027年）11月、12月左右。价格的拐点会提前感知并做出判断。

明年（2027年）需求增长情况预计如何？

明年（2027年）需求，除了AI需求仍然较多，预计增长幅度在17%-18%左右。普通消费级和利基性产品预计增长幅度为个位数。整体需求不会像今年（2026年）那样旺盛，肯定达不到今年的水平。公司目前的大客户主要是主流云服务器厂商，如AWS、G oogle、Microsoft、Meta，以及手机厂商如三星、苹果、vivo、OPPO、小米、荣耀等。订单预判情况是基于这些企业的需求。

明年（2027年）的长协有锁定价格吗？

长协是“锁量又锁价”的，并且有预付款机制。锁价是一个幅度范围，比如以当前季度或上季度的合约价为上限，以上个季度合约价的60%为下限。最终价格还要根据每年的市场情况谈判，并不是锁定一个固定价，而是锁定一个价格区间。

现在看明年（2027年）的这个价格范围预期是在说DRAM、NAND每GB大概是多少价钱？

上半年DRAM价格预计还能达到17-19美金/GB的高峰，下半年则会逐步下降，每季度减少6%到7%左右。NAND目前大约是0.4美元/GB，明年（2027年）上半年可能增加到接近0.5美元，下半年也会逐步下降。

北美云厂商对DRAM和NAND具体的需求情况预计分别如何？可以展开讲讲吗？

以DRAM和NAND为例，主流服务器和云服务器厂商如AWS、Meta、Google、Microsoft，今年（2026年）每月DRAM订单接近6万片，NAND订单约6.2到6.3万片。AWS和Google大致在这个范围，Meta和Micro soft稍低，这是今年的高峰。现在这些云服务厂商在传统DRAM和NAND上都大量采购。到明年（2027年），预计每季度订单不会再增长，基本维持在今年的水平。供给端也有产能释放，明年供需关系会趋于平衡。

明年（2027年）DRAM整体的Bit Growth，如果去掉HBM这块的占用，明年（2027年）预计增长幅度大概是多少？

Bit Growth增长预计在17-18%左右。

如果看2028年的情况呢？

2028年预计仍处于下行周期，但不会像2022年、2023年那样跌到地板价。2027年下半年到2028年，每季度价格下降约5%到6%。2028年下半年可能出现震荡，价格有涨有跌，但整体趋势仍是下行。

2028年客户需求如何展望？

目前判断客户需求即使增长，幅度也不及产能增加速度和位元数增长幅度。

2028年整体产能扩产的情况，跟客户需求现在应该已经有一定的能见度了，因为好多签了两到三年的长协。客户需求能见度跟产能扩产情况具体是什么样的？

从位元数角度看，2028年位元数增加幅度基本在17%、18%左右，客户需求增加幅度约15%。位元数增加将超过客户需求增长，但晶圆片数变化不大。

从需求角度来看，AI推动带来的SSD需求，包括DRAM需求，逻辑上不是应该越来越多吗？

AI场景的绝对需求确实在持续增长，但目前AI场景在整体市场中的占比已经达到约40%的高点。未来进一步提升的空间有限，因为消费级、汽车级和利基型产品市场的基数依然很大，AI要进一步扩展面临限制。而且这些领域的市场增长较弱，甚至可能出现负增长。例如，手机端市场已经难以承受，中端产品价格上涨，甚至出现减配现象。

作为存储厂商，为什么不更多地转向AI相关产品？

这是一个关键问题。将部分消费级产品转向AI领域是可行的，但这种转型是有代价的。三星、海力士等企业普遍预计到2027年底、2028年左右，AI的发展将遇到瓶颈。如果现在大规模转向AI，未来还需要再转回消费级市场。虽然消费电子市场增长有限，但基数庞大，不希望因产能转移而丢失市场份额。因此，企业需要同步兼顾多个市场，因为这些市场本身具有周期性，不能只看到AI的短期优势而忽视整体周期变化。

QLC的渗透率提升到70%以上，这一数据是指公司还是整个市场？

这是指整个市场，当前市场整体正向QLC方向发展。

公司在QLC方面的现状如何？

情况与市场平均水平一致，基本代表行业平均水平。计划与市场趋势匹配。

QLC与TLC的价格差距如何？

以1TB容量为例，目前QLC价格为26美元，TLC为29美元。为推动QLC行业发展，QLC产品价格更具优势。

原厂在生产高阶存储芯片时产生的残次品如何处理？这些残次品是堆积在厂内还是作为消费级产品出售？

具体情况要看产品类型。以SSD的NAND Flash为例，会进行分Bin处理，低等级产品用于普通消费级SSD，高等级用于企业级SSD，性能稍差的残次品会用于消费级市场，更差的则用于低端3C产品。DRAM则很少有分Bin的做法，因为DRAM对纳米制程要求高，一旦性能不达标，如延迟、ECC能力、传输速度下降，即使是低端产品也无法满足要求。因此，NAND存在残次品分流，DRAM基本没有残次品再利用的逻辑。
