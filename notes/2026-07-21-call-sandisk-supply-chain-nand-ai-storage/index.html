纪要总结

NAND行业供需、产品结构与AI存储需求专家访谈纪要

1. NAND行业供需格局与消费电子需求

1. 当前NAND市场的整体供需情况如何？

  • 从供给端看，三星、美光、海力士、铠侠、闪迪等原厂均以利润最大化为导向，持续将产能和资源向盈利能力更高的AI及企业级市场倾斜。
  • AI市场对NAND产能的吸引力显著增强，PC、智能手机等消费电子领域可获得的NAND产能将进一步收紧。
  • 按全年宏观口径，NAND需求预计增长约20%，供给增长约15%，市场存在约5个百分点的供需缺口。
  • 随着原厂与云服务商（CSP）签署长期协议（LTA），AI领域的需求确定性进一步增强，原厂会优先保障AI客户的供给。
  • 在消费电子等非AI领域，原厂关注度和供给优先级相对下降，供需缺口及价格波动可能更明显。

2. NAND原厂是否会持续将产能从消费端转向企业端？

  • 是。NAND新增供给较为线性，难以在短期内快速扩充，因此产能结构调整主要依靠在不同产品之间重新分配资源。
  • 企业级SSD尤其是AI相关产品的利润率和需求确定性更高，整体产能将逐步向Enterprise端倾斜。
  • 相应地，消费级SSD、手机和PC等领域的供货比例将被压缩。
  • 客户自身也在调整产品结构：
  1. 智能手机需求逐步向高端机型集中。
  2. PC需求逐步向AI PC集中。
  3. 普通及低端产品需求相对较弱，供货资源分配比例持续下降。

3. 手机低端机降配是否会导致消费级NAND需求和价格坍塌？

  • 低端手机因存储涨价而降配是不可避免的，消费者也可能因终端涨价而延迟换机，从而影响消费级NAND需求。
  • 但高端手机仍处于配置升级和出货增长阶段，消费电子需求并非全面下滑，而是呈现明显的结构分化。
  • 更大的短期价格风险来自现货市场：
  1. 现货商在供应紧张、价格上涨阶段大量囤货。
  2. 若终端涨价抑制消费者换机需求，现货商可能对库存产生恐慌。
  3. 在库存集中出售时，消费级NAND现货价格可能出现阶段性回调。
  • 因此，消费级市场存在波动风险，但这并不代表整个NAND市场或企业级产品价格会结构性坍塌。

4. 未来一年NAND供需缺口是否会缓解？

  • 预计明年行业仍将存在约5个百分点的供需缺口。
  • 各家目前主要通过提高堆叠层数改善单位晶圆产出，尚未看到明显的大规模新增产能释放。
  • 技术进步带来的产能增量仍不足以覆盖AI需求增长。
  • 当前没有看到明年供需格局会显著恶化，但供不应求的状态预计仍会延续。
  • QLC NAND需求将进一步增长，但其良率和工艺瓶颈也会限制有效供给。

2. 闪迪产品结构与战略转型

1. 闪迪过去和现在的产品战略有何变化？

  • 过去闪迪的优势主要集中在GSSD等消费级产品，Enterprise SSD则以定制化产品为主。
  • 企业级定制产品通常针对特定客户开发，例如为Microsoft设计的产品可能无法直接适配其他客户，通用性较弱。
  • 过去公司的策略是有限开展企业级定制业务，多数供给仍面向GSSD市场。
  • 今年随着公司与多家客户签署新的业务合作，公司战略发生了明显转向，资源开始全面向eSSD市场倾斜。
  • 按目前内部政策：
  1. GSSD市场可能仅对惠普维持重点保供。
  2. 其他消费级市场的供应将逐步收紧。
  3. 包括任天堂、Switch 2等消费产品在内，若要继续拓展相关业务，需要获得CFO批准。
  4. 公司整体资源将优先投向企业级SSD和AI存储市场。

2. 闪迪消费级与企业级SSD的出货结构将如何变化？

  • 按访谈提供的规划数据，闪迪的ESD/eSSD出货量将快速增长，CSD/cSSD出货量则持续下降。
  • 在规划期第一个季度，CSD出货量约为8.1亿bit，ESD约为4.5亿bit，消费级产品仍占优势。
  • 到第二个季度，CSD降至5.2亿bit，ESD提升至7亿bit，企业级产品实现反超。
  • 到第三个季度，CSD约为5.6亿bit，ESD将达到12.5亿bit，差距进一步扩大。
  • 第四个季度，CSD约为5.9亿bit，ESD将升至14亿bit。
  • 到下一年度第一季度，CSD将降至3.7亿bit，相比此前第一季度缩水一半以上；ESD则将达到15.4亿bit。
  • 后续季度中，ESD预计继续增长至17.6亿bit和19.3亿bit，CSD则维持在3.6亿至4.9亿bit的较低水平。
  • 以上数据体现的核心趋势是：闪迪正从消费级SSD供应商加速转向以企业级SSD为主的产品结构。

3. ESD按bit口径大幅增长，是否意味着产品数量同步大幅增加？

  • 不一定。按bit计算，ESD出货量增长非常明显，但按产品数量计算，变化可能没有bit口径那么大。
  • CSD单颗或单盘容量较低，因此产品数量与bit出货量之间的关系更直接。
  • ESD单盘容量和存储密度更高，在晶圆消耗或产品数量变化有限的情况下，也可以实现bit出货量显著增长。
  • 因此，未来增长更多体现为产品密度、单盘容量和产品结构提升，而非简单的产品件数扩张。

4. 闪迪转向eSSD后，低等级或冗余NAND将如何处理？

  • 部分NAND可能无法满足eSSD产品要求，这些冗余NAND不会继续大量投入低利润的cSSD市场。
  • 公司可以将其直接销售给第三方组装厂。
  • 该类第三方销售业务的盈利水平实际可能高于传统cSSD业务。
  • 因此，即便缩减消费级自有产品供给，也不代表所有相关NAND都会形成低价库存压力。

3. NAND价格趋势与客户合同模式

1. 在供需偏紧和产品结构升级的情况下，NAND价格如何判断？

  • 整体价格趋势仍然偏乐观，至少暂未看到持续下跌的基础。
  • 从公司财报收入测算的ASP预计将持续上升，核心原因包括：
  1. 市场供需仍存在缺口。
  2. 产品结构持续向高ASP的eSSD倾斜。
  3. 企业级产品本身定价和盈利能力高于消费级产品。
  4. 低利润cSSD业务占比下降。
  • NAND市场整体价格仍处于上行趋势，但消费级现货价格可能因囤货和去库存出现阶段性波动。

2. 现货市场价格波动是否会影响CSP客户？

  • 对CSP客户的影响相对有限。
  • 供应给CSP客户的NAND不会流入现货市场，产品价格主要由原厂销售团队与CSP客户直接协商。
  • 现货价格显著高于合同价格，也为合同价格提供了一定的缓冲空间。
  • 消费级现货市场即便发生价格回调，也不一定会直接传导至企业级长期合同。

3. 闪迪与CSP客户的新业务模式如何运作？

  • 新业务模式不再简单约定某一具体产品的采购数量，而是约定未来一年采购多少EB容量。
  • 客户并不特别限定供应商必须提供哪一种产品，核心要求是原厂在一年内完成约定的总EB交付量。
  • 该模式对原厂形成两方面激励：
  1. 鼓励扩充有效产能，确保完成容量承诺。
  2. 鼓励加快技术迭代，提高单盘容量。
  • 例如，从128TB升级到256TB后，公司可以用更少的产品数量、更快完成EB容量承诺。
  • 该模式有利于高容量eSSD产品加速导入，也提升了原厂技术升级的商业回报。

4. 新业务模式是否设有价格上下限或联动机制？

  • 访谈未披露明确的价格上下限条款。
  • 已知机制是以某一基准价格作为定价基础，再根据不同产品确定具体价格。
  • 产品价格可能与NAND市场价格或相关指数联动，同时结合不同产品需要维持的利润率进行计算。
  • 因此，该模式并非完全固定价格，而是兼顾市场波动、产品结构和利润率目标。

4. 企业级SSD竞争格局与客户关系

1. 闪迪和铠侠在企业级SSD市场的份额如何？

  • 铠侠长期以来在企业级SSD市场的份额高于闪迪，并非因为苹果业务而更加偏向消费端。
  • 2025年，闪迪在整体ESD市场的份额不足5%，铠侠约为10%至13%。
  • 目前闪迪的ESD市场份额已增长至约10%，铠侠预计仍在13%至15%之间。
  • 闪迪正在快速追赶，但铠侠目前仍保持一定领先优势。
  • 苹果属于消费端客户，其业务不计入企业级SSD范畴。

2. 不同NAND厂商是否与特定Hyperscaler存在绑定关系？

  • 过去不同云客户确实对不同供应商和产品有所偏好。
  • 闪迪过去与Microsoft的关系相对紧密，主要因为双方长期合作开发定制化产品。
  • 随着AI业务扩张，Hyperscaler对存储容量的需求快速增加，客户对单一供应商的偏好正在减弱。
  • 当前客户更重视两项能力：
  1. 能否稳定保障供货。
  2. 能否提供更高容量的产品。
  • 只要供应商具备供货能力和高容量产品，主要云厂商普遍愿意开展合作，市场逐渐从“特定供应商绑定”转向“多供应商保障供给”。

5. NAND技术路线、堆叠层数与QLC瓶颈

1. 各家NAND厂商是否已经出现明显的技术代差？

  • 当前各家主要竞争方向仍是堆叠层数，包括300层以上乃至400层技术。
  • 闪迪和铠侠的BiCS、三星的V8/V9，本质上都以提升堆叠层数和存储密度为核心。
  • 新一代产品相较上一代会出现层数跃迁，但目前尚未形成某一家长期、全面领先的结构性格局。
  • 整体来看，各家技术水平仍较接近，竞争重点在于量产效率、良率和产品导入速度。

2. 闪迪与铠侠的CPA技术是否具备优势？

  • 铠侠与闪迪在Big A之后采用CPA技术。
  • CPA可理解为与Hybrid Bonding类似的技术，可以在两侧同时开展生产。
  • 该技术能够在一定程度上提升生产效率，现阶段可能具备一定工艺和成本优势。
  • 但该优势能否转化为长期领先，还取决于良率、规模量产以及高层数产品的实际表现。

3. QLC NAND当前最大的技术瓶颈是什么？

  • QLC的物理电压窗口较窄，对生产工艺和控制精度要求更高。
  • 当前QLC良率仍不理想，是整个行业共同面对的问题。
  • 三星、海力士由于更早与AI客户合作，QLC进度相对领先，但其良率可能也仅在60%左右。
  • 闪迪、铠侠及其他厂商同样面临QLC量产和良率提升难题。
  • 明年QLC需求预计进一步增加，因此谁能率先突破良率瓶颈，谁就更有可能获得产能、成本和市场份额优势。

6. AI存储需求演变与数据分层

1. AI对eSSD需求的驱动力发生了什么变化？

  • 2025年初，eSSD需求增长主要由热数据和计算侧存储需求拉动。
  • 随着200G、300G、400G等系统铺开，服务器机架中的Computer Tray配置了VSSD的E1.S卡槽。
  • 客户若希望服务器满载运行，通常需要将相关卡槽插满，由此带动Computer eSSD需求。
  • 到2026年，AI产业的关注点开始从提升模型“智力”转向增强模型“记忆力”。
  • 市场发现，仅提升训练和推理能力并不足够，还需要更大规模地保存数据、上下文及各类知识内容。
  • 因此，NAND需求重心开始由Computer eSSD进一步扩展至Storage eSSD。

2. Computer eSSD和Storage eSSD分别对应哪些数据层？

  • Computer eSSD主要位于热数据层，直接服务于高频访问、实时训练和推理。
  • Storage eSSD主要位于温数据层，用于保存访问频率相对较低但容量规模较大的数据。
  • 典型数据类型包括：
  1. 训练缓存和GPU直接访问的Training Cache，属于热数据。
  2. 预训练数据集，主要属于温数据。
  3. Token数据、RAG数据库及相关上下文数据。
  4. 图片库、视频库等大容量非结构化数据。
  5. KV Cache及模型Checkpoint等数据。
  • AI存储需求正从单纯的训练缓存，扩展到覆盖训练、推理、记忆和长期数据保存的多层次体系。

3. TLC和QLC分别适用于哪些AI存储场景？

  • TLC具有读写速度快、随机读写性能较强等特点，IOPS能够更好匹配HBM带来的高带宽。
  • TLC主要用于热数据层，适合：
  1. 实时推理。
  2. 高QoS场景。
  3. GPU直接访问的Training Cache。
  4. 对随机读写要求较高的数据。
  • QLC更适合读多写少、大容量和成本敏感的场景，主要用于温数据层。
  • 可通过产品采用TLC还是QLC，判断其最终更可能落在热数据层还是温数据层。
  • 随着AI“记忆”需求增强，温数据容量快速增长，将进一步拉动高容量QLC eSSD需求。

7. HDF及新型存储产品进展

1. HDF目前处于什么阶段？

  • 按公司当前规划，HDF将在今年下半年向客户送样。
  • 上游供应链的部分元器件已经开始采购和认证，相关供应商正在提交产品进行Qualification。
  • 今年下半年实现样品交付的确定性较高。
  • 明年预计进入量产阶段，但仍以低量生产为主。
  • 真正的大批量量产预计要到2028年才会出现。

2. HDF主要应用于什么场景？

  • HDF理论上会采用SLC，与铠侠为英伟达提供的升级版SLC产品思路相近。
  • 该类产品可与TLC搭配，用于热数据层的高频访问存储。
  • 主要对应ICMS中的上下文文本介质层及高频数据缓存层。
  • 其核心价值是兼顾接近高性能缓存的访问能力与更大的存储容量，满足AI上下文、缓存和高频数据调用需求。

8. 综合判断

1. 是否需要对NAND价格和行业景气度过度担忧？

  • 整体不需要过度悲观，供不应求格局仍将持续。
  • 行业需求增长高于供给增长，未来一年约5个百分点的缺口预计仍会存在。
  • AI客户需求强劲，并通过LTA及按EB承诺的新业务模式提升了需求确定性。
  • 闪迪的产品结构正快速转向高ASP、高利润的eSSD，企业级产品占比将显著提升。
  • 消费电子领域可能因终端涨价、低端产品降配和现货库存变化出现阶段性波动，但影响主要集中于消费级和现货市场。
  • 企业级SSD的定价主要通过长期合同、基准价格和指数联动机制确定，受消费级现货价格波动的影响相对有限。
  • 中长期核心变量仍是AI存储需求增速、高容量产品迭代、QLC良率突破以及原厂有效产能释放速度。
