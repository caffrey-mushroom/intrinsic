1. 营收增长与业务表现

a) Nebius 2026年Q3营收预计达到什么水平，增长主要由哪些因素驱动？

  • Q3营收预计约为 9亿—10亿美元。
  • 增长主要来自大型合同落地，而非单纯依靠GPU利用率或价格提升，核心驱动包括：
  1. 即将公布的与“40L Labs”签订的大型交易。
  2. 另一份期限为3年、总金额约10亿美元的合同。
  3. 企业客户、Token Factory、前沿实验室及AI原生企业的合同收入逐步确认。
  • Q3与Q4收入仍会受到数据中心上线节奏影响，尤其是芬兰、亚洲及法国项目延期导致可计费容量低于原计划。
  • 访谈中关于全年净营收的部分数字存在转录歧义，但明确判断是：全年结果可能落在管理层指引的偏低区间，主要原因是部分容量未按期通电并开始计费。

b) Token Factory及其他经常性收入增长情况如何？

  • Token Factory企业业务正在快速扩张，预计2026年末ARR约为 8亿美元，乐观情况下可上调至 10亿美元。
  • 截至2025年Q4末，Token Factory ARR约为2,500万美元；若达到8亿美元，意味着一年内增长约30倍。
  • 访谈提及其他经常性收入目标约为70亿—90亿美元，但该数字与其他收入口径存在明显差异，需进一步确认其对应年份及业务范围。
  • 当前Token Factory及推理业务增长主要受以下因素推动：
  1. 企业AI应用加速落地。
  2. 企业从高成本闭源模型转向开放权重模型。
  3. AI原生企业和传统企业的单客户云计算消费金额快速提升。
  4. GPU即服务与推理即服务成为公司现阶段利润率最高的产品。

c) Q4收入增长的主要来源是什么？

  • Q4预计继续受此前签署的大型合同驱动，相关客户涵盖：
  1. 企业客户。
  2. Token Factory客户。
  3. 前沿实验室。
  4. AI原生企业。
  • 原始记录提及约10亿美元及6.4亿美元的收入增量，但未清晰说明分别对应Q3、Q4还是全年，建议后续核实。
  • Q4收入弹性还将取决于：
  1. 延期数据中心能否完成通电。
  2. GPU部署后能否及时验收并计费。
  3. 10月GPU涨价能否传导至新签与续签合同。

2. 数据中心上线节奏与区域政策风险

a) Vineland项目目前进展如何，主要延期原因是什么？

  • Vineland当前主要瓶颈是 Bloom Energy设备安装与部署，并非许可容量不足。
  • 目前已有约 700兆瓦容量具备上线条件，许可问题基本得到解决。
  • 项目仍存在诉讼，但诉讼影响已经减弱，数据中心建设与部署仍在推进。
  • 短期风险主要是设备安装和工程交付节奏，而非项目被完全叫停。

b) 美国政治环境变化会对Nebius数据中心建设产生什么影响？

  • 民主党影响力增强后，部分州可能对数据中心采取更严格的监管立场，重点涉及：
  1. 电力消耗。
  2. 天然气发电及排放。
  3. 土地与许可。
  4. 前沿AI实验室的大型数据中心项目。
  • Nebius整体美国风险敞口相对有限：
  1. 在得克萨斯州没有项目敞口。
  2. 宾夕法尼亚州项目在暂停新建措施生效前已经启动，因此暂未受到直接影响。
  3. 密苏里州Independence项目位于共和党执政州，政策风险较低。
  4. 伯明翰项目已取得大部分关键许可，当前进展相对稳定。
  • 潜在风险较高的项目主要位于俄克拉何马州和明尼苏达州，相关部署较新，单体规模约100兆瓦。
  • 新泽西州项目虽无法扩展至原计划的更大规模，但仍有约700兆瓦容量可以继续推进，被视为积极信号。
  • 50兆瓦以下的托管项目通常受到的州级监管压力较小。

c) Nebius将如何降低美国政策风险？

  • 公司可能主动降低对美国单一市场的依赖，加强欧洲、亚洲和中东布局。
  • 当前重点储备包括：
  1. 6个单体约40兆瓦的部署项目。
  2. 面向亚洲主权AI的约300兆瓦项目。
  3. 与微软洽谈中的潜在合作项目，但尚未最终确认。
  4. 中东扩张项目，包括已经签约的Humane及其他潜在国家级客户。
  5. 阿曼约100兆瓦项目。
  • 区域多元化有助于降低单一州监管、许可和能源政策变化带来的建设风险。

d) 哪些其他新云厂商在得克萨斯州面临更高风险？

  • 风险敞口较高的厂商包括：
  1. CoreWeave。
  2. Core Scientific。
  3. Galaxy Digital。
  4. Crusoe Energy。
  5. Iris。
  6. Applied Digital。
  • Galaxy Digital项目几乎全部位于得克萨斯州，长期扩建计划风险较高。
  • Crusoe在Babylon、Stargate、Oracle、OpenAI及Goodnight等项目上敞口较大，尤其是与OpenAI和Oracle相关的项目可能成为监管重点。
  • Iris约50%的机群涉及得克萨斯州，Sweetwater 1可能按计划推进，但Sweetwater 2面临更高风险，同时公司还存在融资压力。
  • CoreWeave作为Core Scientific的租户，也会间接受到相关项目影响，其中约260兆瓦项目可能带来较大风险。
  • Applied Digital的Monarch及Anthropic相关站点同样可能成为重点监管对象。
  • SpaceX的Colossus 1、2、3项目存在天然气许可风险，其中尚在建设的Colossus 3受到的潜在影响最大。

3. 2027年容量规划与项目管线

a) Nebius是否仍能在2027年新增1.5吉瓦容量？

  • 专家维持此前判断，预计2027年新增容量约 1.5吉瓦。
  • 管理层公开口径相对保守，预计容量为1吉瓦以上；专家测算约为1.5吉瓦，两者差异主要来自：
  1. 部分新项目尚未正式纳入管理层指引。
  2. 管理层预留了项目延期空间。
  3. 公司可能根据资金、GPU和客户需求重新调整项目优先级。
  4. 部分储备项目可能被取消或无限期推迟。
  • 即使2027年融资环境恶化，约 1吉瓦容量已经获得融资支持并具备较高确定性。
  • 额外500兆瓦尚未完全锁定，需要新增客户预付款、过桥贷款、资产支持证券及轻资产合作伙伴支持。

b) 当前项目管线有多大，如何定义“项目管线”？

  • 已公布项目管线约为 4.3吉瓦，不包括亚洲站点。
  • 若计入亚洲约300—500兆瓦项目，总管线规模约为 4.9吉瓦。
  • 项目管线的定义是：
  1. 已经开工建设的项目。
  2. 已经投入运营的项目。
  • 单纯处于概念或早期储备阶段、尚未建设的项目不纳入该口径。

c) 2027年主要新增项目包括哪些？

  • 已披露或测算的主要项目包括：
  1. Vineland：约140兆瓦。
  2. 密苏里州Independence：约250兆瓦。
  3. 宾夕法尼亚州：约260兆瓦。
  4. 伯明翰：约120兆瓦。
  5. 法国Béthune：约130兆瓦。
  6. Lappeenranta：约70兆瓦，但原计划扩至310兆瓦的部分可能存在延期。
  7. Mäntsälä：新增超过70兆瓦。
  8. AIB/Blockchain Digital US：约50兆瓦。
  9. KSA：规划约50兆瓦，其中约35兆瓦可能率先上线。
  10. 以色列3个站点：合计约100兆瓦。
  11. 美国、欧洲及亚洲其他托管站点：合计约300兆瓦。
  12. 阿曼项目：约100兆瓦。
  • 专家口径下，当前确认容量约为1.565吉瓦，但其中部分项目仍可能因资金和优先级调整而延期。

d) 为什么管理层仅指引1吉瓦以上，而专家预计1.5吉瓦？

  • 管理层指引较保守的原因主要包括：
  1. 部分项目近期才公布，尚未完全纳入正式预测。
  2. 公司历史上经常重新分配资本、GPU和建设资源。
  3. 不符合当前战略优先级的项目可能被推迟，即使技术上已经具备实施条件。
  4. 亚洲扩建项目曾计划于3月启动、9月落地，但后来因资源转向美国和中东而取消。
  5. 德国等地区也曾出现规划存在、实际部署为零的“储备项目”。
  • 因此，1吉瓦代表高确定性底线，1.5吉瓦则取决于融资和项目执行。

4. 资本开支、预付款与融资安排

a) 2027年实现1—1.5吉瓦新增容量需要多少资本？

  • 专家估计：
  1. 新增1吉瓦容量约需 400亿美元资本投入。
  2. 若新增1.5吉瓦，整体资金需求可能接近 500亿—600亿美元。
  • 公司现有现金及已知融资来源大致可支持1吉瓦，但无法无条件覆盖额外500兆瓦。
  • 访谈提及Nebius明年资本开支预测约320亿美元，但该数字仍需更新。
  • 轻资产合作伙伴已规划承担约50亿美元基础设施投资，可降低Nebius自身现金资本开支。

b) 2027年1吉瓦容量的资金来源有哪些？

  • 主要资金来源包括：
  1. 客户预付款。
  2. 经营现金流。
  3. 现有资产负债表现金。
  4. 供应商融资。
  5. AWS相关GPU合同资金。
  6. 资产支持证券融资。
  7. 过桥贷款。
  8. 潜在高级票据。
  9. 轻资产合作伙伴出资。
  • 访谈提及的部分已知资金来源包括：
  1. 约55亿美元现有资产负债表资金。
  2. AWS相关GPU合同约50亿美元。
  3. 供应商融资约27亿美元。
  4. 资产支持证券融资约50亿美元。
  5. 经营现金流储备约60亿美元。
  • 原始记录中关于现金余额及预付款总额存在转录歧义，建议以公司财报和合同披露为准。

c) 额外500兆瓦容量如何融资？

  • 额外500兆瓦尚未得到充分融资保障，主要依赖：
  1. 新客户预付款。
  2. 100亿—200亿美元的潜在过桥贷款。
  3. 基于现有数据中心发行资产支持证券。
  4. 尚未披露的轻资产合作项目。
  5. 新签前沿实验室和超大规模客户合同。
  • 可用于资产证券化的数据中心包括：
  1. Meta位于密苏里州Independence的项目。
  2. 欧洲已运营数据中心。
  3. Mäntsälä数据中心。
  4. 其他尚未完全利用的设施。
  • 技术上，公司有能力为1.5吉瓦融资，但是否推进取决于管理层是否愿意使用几乎全部金融资源并承担较高杠杆和执行风险。

d) 客户预付款是否已成为新云行业的普遍趋势？

  • 客户预付款已经成为行业标准，而非CoreWeave独有的资金短缺应对方式。
  • 典型预付款比例包括：
  1. Iris部分项目可达到约90%。
  2. Nebius大型专用部署约为65%。
  3. 常规企业和AI原生客户合同约为25%—35%。
  • 微软、Meta及前沿实验室均在采用大额预付款模式。
  • 大额预付款的经济逻辑是：
  1. 客户获得更低的长期GPU租赁价格。
  2. 新云厂商减少债务融资需求。
  3. 降低高利率环境下的融资成本。
  4. 减少数据中心建成后需求不足的市场风险。
  • 代价是每兆瓦收入可能下降，且长期合同会锁定部分收入上行空间。

e) 为什么Nebius可能使用过桥贷款？

  • Nebius希望将现金储备维持在 50亿美元以上。
  • 当现金余额预计接近50亿美元时，公司会启动新的融资安排。
  • 过桥贷款期限较短：
  1. 对贷款方风险较低。
  2. Nebius支付的利息相对较少。
  3. 可用于衔接客户预付款、资产证券化或长期融资。
  • 预计相关过桥贷款主要在2027年使用，而非当前季度。

f) 公司会发行高级无担保票据吗？

  • 公司短期更倾向于资产支持证券，而不是高成本高级票据。
  • 当前债券融资利率约为14%，接近垃圾债券水平，融资吸引力较低。
  • 若股价和市场环境改善，Nebius可能在2027年发行高级票据。
  • 若资本市场继续疲弱，公司将优先使用：
  1. 客户预付款。
  2. 资产支持证券。
  3. 过桥贷款。
  4. 供应商融资。

g) 资本开支有多大灵活性？

  • 额外约200亿美元支出具有较高灵活性，并非全部必须发生。
  • 公司可以根据以下因素推迟项目：
  1. 客户预付款到账时间。
  2. 合同定价水平。
  3. GPU租赁需求。
  4. 债务融资成本。
  5. 现金余额是否接近50亿美元警戒线。
  • 高确定性的1吉瓦将优先交付，额外500兆瓦可根据市场和融资条件调整。

5. 合同期限、定价与续约敞口

a) 不同期限和客户类型的合同定价如何？

  • 1年期合同：
  1. 每兆瓦年收入约 4,000万—5,000万美元。
  2. 主要面向AI原生企业和短期算力需求客户。
  3. 定价和利润率最高。
  • 3年期合同：
  1. 每兆瓦年收入通常约 2,000万—2,500万美元。
  2. 部分合同可达到3,000万美元。
  3. 企业客户更倾向于签署3年合同。
  • 超大规模云服务商合同：
  1. 每兆瓦年收入约 1,500万—2,000万美元。
  2. 通常采用固定价格、裸金属或专用部署模式。
  3. 定价灵活性较低，但预付款和现金流保障更强。

b) Q4和2027年定价趋势如何？

  • 市场呈现明显“K型分化”：
  1. GB200、GB300、Vera等最新一代GPU需求旺盛，价格持续上涨。
  2. GPU即服务价格预计继续提升。
  3. 旧型号和裸金属服务价格可能承压。
  • 英伟达10月实际提价约15%，未来服务器价格可能进一步上涨。
  • 专家预计2027年Q1和Q2市场格局不会发生根本变化。
  • 较旧H系列GPU的续约价格也出现明显上涨，部分可达到原价格的2倍。
  • 服务器采购成本上涨会压缩固定价格裸金属合同的利润空间。

c) Nebius是否仍会为短期合同保留产能？

  • 公司将继续采用分层策略：
  1. 大型专用部署以高比例预付款和长期合同为主。
  2. 企业及AI原生客户以1—3年合同为主，其中1年期占比较高。
  3. 保留部分容量用于GPU即服务和短期合同，以获得更高价格和利润率。
  • Nebius当前重点偏向短期和中期GPU即服务合同，而非全面转向裸金属。
  • 裸金属模式能够改善现金流，但会降低定价弹性，并带来服务器成本上涨风险。

d) Q4有多少容量需要续约或重新定价？

  • Q4到期的固定期限合同约为：
  1. 25兆瓦。
  2. 约18,000块GPU。
  • 按需现货滚动计价合同约为：
  1. 55兆瓦。
  2. 约34,000块GPU。
  3. 约占整体容量的10%。
  • 两部分合计约：
  1. 80兆瓦。
