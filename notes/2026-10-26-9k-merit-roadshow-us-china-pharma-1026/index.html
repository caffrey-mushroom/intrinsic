专家周报会议纪要

1. 本次周报核心结论

a) 本次周报最值得关注的3个结论是什么？

  • Tango Therapeutics的PRMT5项目进一步去风险，但短期催化不足
  1. ESMO 2026公布的数据整体较强：MTAP缺失、RAS突变转移性胰腺癌患者的ORR达到82%，DCR为100%，9个月PFS率为88.4%。
  2. 股价在数据公布前已连续上涨，较高预期提前计入，因此数据公布后出现明显兑现。
  3. 项目已从早期信号验证阶段进入风险明显降低的注册执行阶段，但真正的大幅重估仍需等待注册性3期临床数据。
  4. 1线3期临床预计推迟至2027年上半年启动，未来2—3个季度重大临床催化较少，股价大概率跟随XBI波动。
  5. 公司现金储备偏紧，已计划裁员14%、降低新靶点研发优先级，不排除数据公布后继续融资。
  • Moderna黑色素瘤项目进一步去风险，但公司估值已计入过高预期
  1. 3期RFS HR为0.58，处于市场预期中较乐观的水平，支持黑色素瘤项目进一步去风险。
  2. DMFS HR为0.62，虽然达到预设统计学标准，但较2期数据有所走弱；OS HR为0.77，数据仍不成熟。
  3. 黑色素瘤项目基本面较强，但非小细胞肺癌等跨瘤种项目的关键数据仍需等待较长时间，市场却已给予较高成功概率。
  4. 当前市值已经脱离传统创新药估值框架，一旦后续数据存在瑕疵，容易引发较明显的“杀多”行情。
  • AIDD概念持续升温，但大型生命科学工具公司的直接业绩增量尚未得到验证
  1. Twist、金斯瑞等较早受益企业已经出现一定业绩表现，Thermo Fisher和Danaher则是相对稳健的AIDD观察标的。
  2. 两家公司传统Biotech业务已经确认复苏，但AIDD业务目前仍更接近远期增长期权，而非2026—2027年的主要收入驱动力。
  3. Thermo Fisher和Danaher对应2027年预期PE约24—26倍，估值已不低，短期弹性可能有限。
  4. 相较生命科学工具龙头，艾伯维、礼来、强生等大型药企的EPS增长和估值性价比可能更优。

2. Tango Therapeutics与PRMT5项目进展

a) Tango此次公布的转移性胰腺癌疗效数据如何？

  • 整体疗效表现
  1. 此次更新的是MTAP缺失、RAS突变转移性胰腺癌数据，可评估患者由此前的12例增加至22例。
  2. 22例患者中有18例出现缓解，ORR为82%，DCR为100%。
  3. 9个月PFS率为88.4%，中位PFS尚未达到，显示出较好的缓解持续性。
  4. 此前市场普遍认为ORR超过70%即属于较强数据，82%的结果高于主流预期。
  5. 与RMC-6236单药约32%的ORR相比，联合治疗在MTAP缺失患者中的疗效提升明显。
  • 数据确认情况
  1. 18例缓解全部为PR，尚未出现CR。
  2. 截至原始数据截止日，11例为确认PR，对应确认ORR为50%。
  3. 另外7例在数据截止后得到确认，目前18例缓解均已确认，因此公司采用82%的ORR作为最终宣传口径具有合理性。

b) 不同治疗线次的疗效表现有哪些亮点？

  • 2线治疗
  1. 7例患者中有6例出现缓解，ORR为85.71%。
  • 3线治疗
  1. 13例患者中有11例出现缓解，ORR为84.62%。
  2. 3线患者的缓解率并未较2线下降，说明后线疗效没有明显衰减。
  3. 考虑到胰腺癌后线治疗难度较高，这一结果具有较强的临床意义。
  • 与单药数据对比
  1. RMC-6236单药用于2线整体人群时，ORR约为32%—33%。
  2. 在3线及以上患者中，单药ORR约为20%。
  3. 联合方案在2线和3线均达到80%以上ORR，表明PRMT5与泛RAS抑制剂可能具有较强协同效应。

c) 推荐剂量组的疗效水平如何？

  • 3期计划采用的低剂量组为200毫克Vopi联合100毫克Direx，每日口服给药。
  • 该剂量组ORR为78.95%，接近80%。
  • 高剂量组为250毫克Vopi联合100毫克Direx，整体疗效同样约为80%，并未达到此前市场可能期待的90%左右。
  • 尽管ORR较早期小样本数据有所回落，但接近80%的水平仍具有较强竞争力。

d) 非小细胞肺癌数据及后续开发计划如何？

  • 目前非小细胞肺癌样本量较小，仅有5例患者。
  • 其中4例出现缓解且均已确认，第5例患者肿瘤缩小26%。
  • 初步信号表明该药在非小细胞肺癌中具备潜力，但尚不足以形成确定性判断。
  • 公司当前优先将资源投入转移性胰腺癌1线适应症，非小细胞肺癌的中后期临床设计和资源配置仍需进一步明确。
  • 明年的投资者会议预计将披露肺癌开发计划，是后续重要观察节点。

e) 联合方案的安全性是否存在问题？

  • 正面表现
  1. 在25例可评估安全性的患者中，未出现4级或5级治疗相关不良事件。
  2. 没有患者因治疗相关不良事件退出研究。
  • 主要瑕疵
  1. 3级治疗相关不良事件发生率由2026年6月公布时的25%升至40%。
  2. 44%的患者需要调整剂量。
  3. 治疗中断比例为40%，减量比例为20%。
  4. 安全性总体仍可管理，但3级不良事件和剂量调整比例上升，可能是市场对数据存在分歧的重要原因。

f) 联合用药在药代动力学和药物相互作用方面有什么特点？

  • Vopi能够提高Direx和Zadun的药物暴露，与其作用机制相关。
  • 联合方案中Direx剂量仅为单药剂量的约1/3，即100毫克对比单药研究中的300毫克。
  • 如果在Direx暴露相近的情况下，联合方案疗效仍显著优于单药，则增量疗效可更多归因于PRMT5抑制剂的协同作用。
  • 降低Direx剂量也可能在一定程度上改善联合治疗的耐受性。

g) 后续3期临床将如何推进，主要风险是什么？

  • 临床规划
  1. 1线注册性3期临床原计划于年内启动，现预计推迟至2027年上半年。
  2. 公司已与FDA讨论临床设计，包括对照方案、入组标准、化疗选择、样本量和试验开展区域。
  3. 研究拟将ORR和PFS设置为双主要终点，OS为关键次要终点。
  4. 两个主要终点中任意一个达到要求，即可能支持提前申报。
  5. 入组患者需要通过NGS确认MTAP缺失，患者筛选标准较严格。
  6. 若2027年上半年启动入组，首次ORR或PFS分析预计不会早于2028年上半年至年中。
  • 主要风险
  1. 启动时间较市场原预期延后约2个季度，导致关键数据进一步后移。
  2. 若Revolution的1线项目率先读出阳性结果，化疗可能不再是最适合或最容易获得监管认可的对照方案。
  3. 对照臂变化可能影响临床设计、监管路径和最终市场空间测算。
  4. 后续3期临床的药物供应协议尚未签订，存在供应和商业合作不确定性。
  5. 由于相关药物需要优先保障已获批适应症、同情用药及early access患者，临床试验供药可能面临压力。

h) MTAP缺失适应症的市场空间有多大？

  • MTAP缺失在胰腺导管腺癌中的占比约为24%。
  • 对应1线患者约2万人，2线患者约9,200人，已有较明确的流行病学基础。
  • 除胰腺癌外，潜在适应症还包括非小细胞肺癌、结直肠癌等，整体市场空间较大。
  • PRMT5与泛RAS或特定RAS抑制剂联用，有望覆盖多个高未满足需求癌种。
  • Revolution的估值逻辑对应约120亿—140亿美元销售峰值，再以约3倍PS折现，反映出市场对相关适应症空间的较高预期。

i) Tango目前应如何调整组织和资源配置？

  • 公司需要降低新靶点发现和早期研发项目的优先级。
  • 计划裁员14%，主要涉及研发人员，以降低运营成本。
  • 核心资源将集中于：
  1. 推进胰腺癌1线注册性3期临床。
  2. 推进456脑渗透性PRMT5抑制剂入组。
  3. 开展与RMC-6236及ERAS泛RAS抑制剂的联合研究。
  • 公司现金储备不足以从容支持多项重要临床，不排除后续继续定增融资。
  • 现阶段战略重点应从广泛的新靶点发现，转向高确定性核心管线的注册执行。

j) PRMT5领域的竞争格局如何，Tango处于什么位置？

  • 在Revolution和Tango数据推动下，PRMT5领域热度显著提升。
  • 百时美施贵宝、吉利德、百济神州等大型药企均已布局，IDEAYA也重新推进相关管线。
  • Tango在转移性癌症1线治疗领域仍处于相对领先位置，公司认为自身进度领先约12个月。
  • 但随着大型药企进入，后续竞争将从早期临床信号转向：
  1. 注册性临床执行速度。
  2. 联合治疗伙伴选择。
  3. 安全性和剂量优化。
  4. 药物供应保障。
  5. 透脑型PRMT5管线的差异化能力。

k) Tango近期有哪些催化剂，股价如何判断？

  • 近期催化剂
  1. 2026年3季报及电话会议，重点确认3期临床规划、融资需求和药物供应协议。
  2. 明年投资者会议，预计披露非小细胞肺癌开发计划。
  3. 与RMC-6236及ERAS泛RAS抑制剂的联合研究进展。
  4. 456脑渗透性PRMT5抑制剂的入组情况。
  • 中长期催化剂
  1. PDAC 1线注册性3期临床启动。
  2. 预计2028年出现的ORR或PFS关键分析。
  3. 2线胰腺癌及其他MTAP缺失癌种的开发规划。
  • 股价判断
  1. 数据进一步释放了临床风险，但此前股价已提前反映较高预期。
  2. 公司经风险调整后的企业价值仍处于较低水平，长期具备潜在重估空间。
  3. 未来2—3个季度重大临床催化有限，短期大概率跟随XBI呈现Beta波动。
  4. 真正的大幅重估仍需等待3期中期或最终数据，当前更适合作为中长期重点跟踪标的。

3. Moderna个性化mRNA肿瘤疫苗

a) Moderna最新黑色素瘤数据表现如何？

  • RFS数据较强
  1. RFS HR为0.58，接近市场预期中最乐观的水平。
  2. 市场此前预期范围大约为0.5—0.7以上，0.58属于较好的读出。
  3. 该数据进一步支持个性化抗原疗法用于黑色素瘤辅助治疗的有效性。
  • DMFS存在一定瑕疵
  1. 整体DMFS HR为0.62，P值为0.002。
  2. 结果已经越过预设的双侧统计学界值0.016，统计学意义明确。
  3. 但相较2期数据，DMFS表现有所下降。
  4. 低危亚组置信区间跨1，高危组DMFS HR也只有0.59，仍需更长期随访。
  • OS尚未成熟
  1. 当前OS HR为0.77，方向有利。
  2. 由于随访时间不足、数据尚未成熟，暂时不适合据此进行过度外推或炒作。

b) 美国亚组DMFS HR为1.77是否意味着疗效不佳？

  • 该亚组仅发生10例DMFS事件，其中联合组8例、对照组2例。
  • 样本量和事件数过少，结果容易受到偶然因素影响。
  • 该数据更接近统计噪音，不能据此判断美国患者疗效不佳。
  • 后续应结合更成熟的整体数据和预设亚组结果进行分析。

c) 项目的安全性和获批前景如何？

  • 安全性
  1. 两组严重不良反应整体较为接近。
  2. 联合治疗未明显叠加PD-1相关免疫毒性。
  3. 发热、注射反应和停药率有所增加。
  4. 与PD-1、CTLA-4组合的效果并未达到市场此前的高预期。
  • 监管及获批前景
  1. RFS数据具备支持申报和获批的潜力。
  2. 但个性化mRNA肿瘤疫苗属于新治疗模式，历史审评先例有限。
  3. 能否仅凭当前RFS结果直接获批仍存在争议。
  4. DMFS、OS成熟度以及监管机构对新治疗模式的接受程度，将是后续关键。

d) 个性化mRNA肿瘤疫苗的生产和交付瓶颈在哪里？

  • 当前主要瓶颈可能不在疫苗生产端，而在上游肿瘤组织获取环节。
  • 研究入组约1,140人，但筛选人数超过1,740人，筛选失败人数超过600人。
  • 最常见的筛选失败原因是病理科或临床中心无法提供足够、合格的肿瘤组织样本。
  • 对于组织样本合格的患者，个性化疫苗的生产成功率相对较高。
  • 后续商业化放量不仅取决于生产能力，还取决于医院病理流程、取材质量和跨中心样本运输能力。

e) 还需要等待哪些关键生物标志物数据？

  • 目前尚未充分披露的重要数据包括：
  1. TMB肿瘤突变负荷。
  2. PD-L1亚组。
  3. BRAF亚组。
  • TMB与个性化新抗原疫苗的作用机制最为接近，是判断跨瘤种可复制性的关键指标。
  • 在上述数据披露前，不宜对非小细胞肺癌等其他瘤种给予过高成功概率。

f) 跨瘤种项目的后续时间安排如何？

  • 黑色素瘤
  1. 已经实现较高程度的风险释放，是目前最确定的项目。
  • 辅助肾癌
  1. 处于2期阶段，预计可能于2028年1月完成相关研究。
  • 肌层浸润性膀胱癌
  1. 处于1/2期阶段，辅助治疗队列已完成入组。
  2. 预计关键时间点为2027年4月。
  • 非小细胞肺癌
  1. 随机入组接近完成。
  2. 主要临床阶段可能要到2030年完成。
  3. 即使中期数据提前半年至1年读出，下一个重大催化剂仍距离较远。
  4. 当前估值已经对该适应症给予较高销售预期，时间和临床不确定性均较大。

g) 如何评估Moderna当前估值？

  • 黑色素瘤项目可以给予较高估值，极乐观情况下可支持约100亿美元价值。
  • 市场对相关适应症的最高销售预期约为40亿美元，若给予较高市场份额并按3倍PS计算，可形成较高估值支撑。
  • 但当前市值已同时计入黑色素瘤、非小细胞肺癌及其他癌种的较高成功概率。
  • 公司净现金约40亿美元，其他管线估值可能在100亿—150亿美元区间。
  • 在此前两轮轧空和股价大幅上涨后，部分适应症的隐含PoS由10%—20%快速提高至70%—80%，明显偏离传统创新药估值框架。
  • 当前隐含PS可能达到5—6倍，整体仍偏高。
  • 黑色素瘤已高度去风险，但不足以完全支撑当前市值；若跨瘤种项目出现瑕疵，股价可能面临较大回调压力。

4. AIDD行业与生命科学工具公司

a) 泛AIDD领域目前有哪些值得关注的标的？

  • 弹性标的
  1. Twist。
  2. Ginkgo。
  3. 金斯瑞及其他细分领域小龙头。
  • 相对稳健标的
  1. Thermo Fisher。
  2. Danaher。
  • 行业指标股
  1. Thermo Fisher和Danaher可观察生命科学工具及上游耗材需求。
  2. Medpace和Charles River可辅助判断海外Biotech融资、研发和临床活动景气度。
  • AIDD目前更靠近化学和药物发现前端，距离人体临床验证仍较远。
  • 短期机会可能首先在临床试验上游、实验室工具、合成生物和研发服务环节体现。

b) Thermo Fisher最新季报反映了哪些行业变化？

  • 收入、EPS及调整后EPS均超过市场预期。
  • 有机增长达到6%，显著高于市场一致预期的4.3%和公司此前约4%的指引。
  • 6%的有机增长创疫情以来最佳表现。
  • 有机增长剔除了并购、资产剥离和汇率影响，更能反映现有业务自身经营的恢复情况。
