a) 编程、金融服务和医疗健康分别贡献多少收入？

  • 截至访谈前一周：
  1. 金融服务收入占比约21%，年底目标接近25%；
  2. 医疗健康、生命科技收入占比约16%，年底目标约20%；
  3. 编程收入预计年底占比约35%。

b) Claude Code对收入和Token消耗的贡献如何？

  • 编程业务的核心增长来自：
  1. 软件开发和代码生成；
  2. 遗留代码库现代化；
  3. 核心银行和交易系统改造；
  4. 专有定价模型开发；
  5. 复杂风险模拟。

  • 公司正在探索利用Claude开展被忽视疾病的药物研究，预计医疗健康和科学领域将在下一年度实现较大增长。

3. 金融服务核心应用与Token消耗逻辑

a) 金融服务行业增长最快的应用场景有哪些？

  • 金融服务正在从基础问答型聊天机器人转向自主、多步骤的智能体工作流。
  • 主要应用场景分为以下几类：
  1. 前台业务：金融建模、交易执行、客户产品推荐；
  2. 中后台业务：KYC、AML、承保、保险审查、实体解析；
  3. 风险与合规：交易调查、信贷备忘录起草、贷款契约监控；
  4. 软件现代化：改造遗留交易系统和核心银行代码库；
  5. 量化和定价：构建专有定价模型、运行复杂风险模拟。
  • 投资银行、私募股权、资产管理机构会同时使用Claude网页版，以及面向Excel、PowerPoint、Word等办公软件的Claude能力。

b) Claude如何从单点工具扩展到银行全流程？

  • 某一级银行最初仅使用Claude改造后台遗留代码库。
  • 随后，Claude逐步嵌入KYC和AML检查流程，并扩展至内部人力资源、财务和运营部门。
  • 在客户服务场景中，Claude可以分析客户账户及资金支出，为个人银行客户经理提供适合讨论的产品选项。
  • 该案例反映出Claude正从后台技术工具转变为覆盖销售、运营、合规和客户服务的企业基础设施。
  • 随着嵌入程度提升，客户Token消耗速度显著加快，即使Token单价下降，Anthropic仍可通过更高的使用量保持盈利。

4. 客户支出增长与净收入留存

a) 英国和欧洲金融、医疗客户的支出增长情况如何？

  • 英国和欧洲企业在AI投入上相对谨慎，通常需要看到同行业机构率先采用后才会扩大支出。
  • 从Q1到Q3，金融服务和医疗客户的预算使用率出现大幅提升：
  1. Q1约使用可用IT或AI预算的30%；
  2. Q3已提升至约75%；
  3. 年底可能接近100%。
  • 从客户角度看，Q1至Q4的平均支出可能增长至约3倍。
  • 支出增长主要来自试点项目转入生产、AI嵌入更多工作流程，以及ROI逐渐得到验证。

b) Anthropic的净收入留存率表现如何？

  • 专家称Anthropic已披露的净收入留存率为900%。
  • 这意味着原先支出100美元的客户，当前平均支出可能增至900美元，即扩大至原来的9倍。
  • 该指标为整体口径，并不代表每个客户均实现9倍增长。
  • 增长不仅来自客户预算扩大，还来自系统集成商、云服务商及渠道合作伙伴推动的项目扩展。

c) 现有客户明年的预算可能增加多少？

  • 已经验证ROI的头部客户，部分已将AI预算提高至原来的2倍。
  • 大多数重点客户正在进行预算上调，部分客户仍处于试错和验证阶段。
  • 根据企业及内部反馈，部分客户未来12个月的AI预算可能提高至原来的2—3倍。
  • 企业正在将原本分散于IT、人力资源、销售、财务、法务及运营部门的预算重新分配至AI。
  • 但客户不会无条件扩大投入，预算上限仍取决于投资回报、隐性成本、用量可预测性和模型价格变化。

d) 客户如何衡量AI投资回报率？

  • 企业主要关注三类回报：
  1. 节省时间；
  2. 节省资金；
  3. 加快产品或服务上市速度。
  • 如果三项指标中有两项明确实现、另一项部分实现，企业通常就会认可AI投资的合理性。
  • 客户已逐渐接受“短期成本上升、长期效率和收入改善”的逻辑。
  • 去年初，ROI不明确是企业扩大AI支出的最大障碍；目前这一障碍已明显减弱。

5. ARR增长、模型发布与增长驱动因素

a) Opus 5.5发布后ARR快速增长，是否主要由新模型推动？

  • Opus 5.5具备旗舰级实时性能，同时成本更低，有助于在竞争环境下推动更广泛采用。
  • 但专家认为，10月ARR增加100亿—150亿美元并非单一由Opus 5.5推动，而是多项业务共同作用。
  • 按专家判断，10月ARR可能达到850亿—860亿美元，部分尚未入账的收入将计入11月。
  • 主要增长因素包括：
  1. Opus、Sonnet和Haiku 5.2模型表现良好；
  2. 金融智能体和第一方产品增长；
  3. 全球系统集成商合作扩大；
  4. 超大规模云服务商带来订单；
  5. 客户在年底使用尚未消耗的云积分；
  6. GTM团队扩张，直接销售能力增强；
  7. 金融服务、科学及医疗垂直解决方案增长；
  8. 合资及渠道业务贡献提升。

b) 各模型的收入贡献结构如何？

  • Sonnet为当前主力模型，收入贡献占比约55%。
  • Opus收入贡献占比约18%。
  • Haiku收入贡献占比约16%—18%。
  • 其余收入来自Fable及非公开版本Mythos。
  • 受监管行业对Opus、Sonnet和Haiku均有较高采用率，企业会根据任务复杂度和成本采用多模型组合。

c) Token降价是否会影响收入增长？

  • Token价格正在下降，市场也存在价格竞争。
  • Anthropic已经将Opus模型价格下调20%。
  • 公司增长逻辑不是依赖单价上涨，而是依靠：
  1. Token使用量快速增长；
  2. 工作流嵌入程度提升；
  3. 智能体执行步骤增加；
  4. 客户和应用场景持续扩张；
  5. 第一方软件及垂直解决方案提高黏性。
  • 专家认为，即使价格下降，只要使用量和工作流深度持续提升，公司仍可保持收入增长和盈利能力。

6. 2026—2027年增长目标与实现路径

a) 2026年和2027年的ARR目标是什么？

  • 按专家口径：
  1. 2025年12月ARR约为90亿美元；
  2. 2026年12月底目标约为1,100亿美元；
  3. 2026年较上年增长超过12倍；
  4. 2027年内部销售目标为同比增长4倍。
  • 专家认为，基于当前销售管线，2026年1,100亿美元目标可以较容易实现。
  • 2027年不再假设维持8倍、10倍或12倍增长，主要考虑市场趋于成熟、竞争者增加以及Token价格下降。
  • 即使增速降至4倍，仍属于非常高的增长水平。
  • 访谈中提到的“2027年底ARR达到1,800亿美元”与专家所述4倍内部目标存在明显口径差异，需以公司正式披露为准。

b) 2027年实现4倍增长的主要驱动因素是什么？

  • 增长主要由以下方面共同推动：
  1. 现有客户提高AI预算和支出；
  2. 延续当前速度获取新客户；
  3. 将企业预算从传统IT重新分配至AI；
  4. 从编程扩展至非编程知识工作；
  5. 扩大GTM销售团队和全球区域覆盖；
  6. 提升渠道合作伙伴数量和等级；
  7. 深入金融、医疗和科学等垂直领域；
  8. 通过第一方应用提高客户切换成本；
  9. 增加算力供给并提升算力效率。
  • 专家称，年支出超过100万美元的客户数量从2月约500家增至当前接近1,950家，但该数据需与前文客户总数口径进一步核实。

c) 算力是否会成为增长瓶颈？

  • Anthropic将算力保障视为实现4倍增长的首要条件。
  • 公司已签订未来5年的大规模算力协议，专家提到合同规模为8,960亿美元，并将从下一年度年初开始分配。
  • 公司预计至下一年度年底，算力资源可能接近12吉瓦。
  • 相关金额和时间均为专家口径，数值较大，需结合正式公告核验。
  • 公司希望同时通过研发优化和模型效率改善，降低单位任务的算力成本。

d) 渠道合作为何是重要增长杠杆？

  • Claude合作伙伴网络分为4个等级，优选等级目前仅开放给少数合作伙伴。
  • 专家称，公司单日曾收到超过20,000份加入优选等级的申请，但均未获批准。
  • 如果未来扩大优选合作伙伴数量，Claude可以借助系统集成商迅速嵌入更多企业工作流程。
  • 渠道扩张能够同时带来新客户、Token消耗和更深入的企业级部署。

7. Claude Co-work与非编程市场机会

a) Claude Co-work的战略定位是什么？

  • Claude Code主要服务程序员，Co-work则面向非编码知识工作者。
  • 普通企业中，编码相关员工或任务约占20%—30%，其余70%—80%来自人力资源、销售、财务、法务和运营等非编码岗位。
  • Co-work的目标是将Claude Code在开发者群体中的“先落地、再扩张”模式复制到非技术岗位。
  • 公司计划将Claude的自主、多步骤执行引擎引入日常办公流程，使不具备编程能力的员工也能创建和使用智能体。

b) Co-work目前出现了哪些积极信号？

  • Co-work在产品生命周期相同阶段的早期采用速度已超过Claude Code。
  • 在Anthropic最大的客户账户中，Co-work推动超过50%的企业实现跨产品采用。
  • 年支出超过10万美元的客户中，超过50%同时使用Claude API平台及Claude Code、Co-work等第一方应用；年初这一比例约为20%。
  • 约90%—91%的Co-work活动发生在非开发工作流中，主要包括：
  1. 业务运营；
  2. 情境化文档创建；
  3. 多步骤办公流程；
  4. 跨应用任务执行。
  • Co-work已通过超过10,000个应用市场连接器，与Adobe、Atlassian、HubSpot等企业应用进行集成。

c) Co-work未来将形成怎样的产品形态？

  • Anthropic已推出Claude Sheets、Meetings、Whiteboards和Data等企业版产品。
  • 长期目标是让Claude成为项目从启动到完成的主要工作空间，并与Microsoft 365和Google Workspace竞争。
  • Co-work既是获取非技术用户的入口，也是Anthropic从API供应商转型为企业软件平台的重要载体。

d) 成功客户的理想支出结构是什么？

  • 当前客户平均支出结构大致为：
  1. 编码相关支出约35%—40%；
  2. API和智能体平台约占相近比例；
  3. 其余来自Co-work。
  • Anthropic理想的客户支出结构为“30、40、30”：
  1. Claude Code占30%；

8. 企业预算重分配与未来行业趋势

a) 未来企业AI预算将发生什么变化？

  • 企业已开始从传统部门预算中重新分配资金至AI，而不再仅依靠IT部门承担相关投入。
  • 随着AI深度嵌入销售、运营、财务、人力资源、法务和客户服务，企业原先规划的AI预算可能很快不足。
  • 专家认为，未来讨论焦点将从“是否投资AI”转向：
  1. 应投入多少；
  2. 合理预算上限在哪里；
  3. 如何核算投资回报；
  4. 如何管理不可预测的使用量；
  5. 如何处理隐性成本和模型价格变化。
  • 企业AI预算在2027—2028年仍可能持续提高，原因是AI带来的效率和收入提升会早于预期显现。

b) 企业是否会采用多模型架构？

  • 企业正在采用混合模型架构：
  1. 高推理要求和关键任务使用Anthropic模型；
  2. 简单、成本敏感型任务使用价格更低的模型。
  • 部分具备较强IT能力的企业会同时管理两家或多家LLM供应商。
  • 这会增加模型之间的竞争，但Anthropic目前尚未看到其对ARR增长形成明显制约。
  • 公司将通过第一方应用、垂直解决方案、智能体工作流及治理能力，降低单纯API层面的可替代性。

9. 定价模式与商业模式扩展

a) Anthropic如何看待基于成果的定价？

  • 基于成果的定价是指客户不再按席位或Token付费，而是在任务完成、问题解决或业务成果实现后付费。
  • 这种模式目前更适合SaaS公司，例如Salesforce Agentforce已深度使用Claude，并采用部分成果定价方式。
  • Anthropic核心模型目前尚未采用基于成果的定价。
  • 专家认为，成果定价可能成为未来收入机会，但对LLM公司并不天然适用，原因是模型参与程度、任务边界和结果归因较难统一衡量。

b) Anthropic如何降低企业在不同API之间切换的风险？

  • 公司正在从原始API Token销售扩展至更完整的商业模式，包括：
  1. 全栈企业软件；
  2. 办公生产力套件；
  3. 行业垂直解决方案；
  4. 企业分析和治理附加服务；
  5. 混合销售和应用AI服务。
  • 重点产品与解决方案包括：
  1. Claude for Work；
  2. Claude for Financial Services；
  3. Claude for Science；
  4. 医疗健康解决方案；
  5. Claude Enterprise智能报告。
  • 公司计划投入1亿美元扩充混合销售团队和应用AI团队，以更快、更深入地进入企业工作流程。
  • 战略目标是将Anthropic由底层模型和API供应商，升级为企业AI操作系统和全栈软件平台。

10. 核心判断与潜在风险

a) Anthropic增长的核心逻辑是什么？

  • Anthropic当前并非依靠单一模型、单一行业或单一客户群实现增长，而是形成了多点共振：
  1. 编程业务继续增长；
  2. 金融服务和医疗快速追赶；
  3. Co-work打开非编程市场；
  4. 客户项目从试点进入生产；
  5. 现有客户支出显著扩张；
  6. 新客户数量持续增加；
  7. 渠道及云合作伙伴扩大；
  8. GTM和区域覆盖增强；
  9. 第一方软件提高客户黏性。
  • 公司希望建立“客户增加—工作流加深—Token消耗上升—收入扩大”的正向循环。

b) 未来主要风险有哪些？

  • 市场竞争加剧，新进入者持续增加。
  • Token价格战可能压低单位收入。
  • 企业可能采用多模型架构，API层面的转换成本较低。
  • 算力供应、算力成本及基础设施投入可能影响增长兑现。
  • 企业预算扩张仍取决于ROI验证，部分客户可能继续保持谨慎。
  • 多项ARR、客户数量、算力合同和大客户定义数据存在口径不一致，应以公司正式披露数据为准。
  • Anthropic需要持续将客户从API使用转向第一方应用、垂直解决方案和核心工作流，才能提高长期黏性与商业壁垒。
