ABF载板行业专家访谈纪要

1. 行业景气度与供需格局

a) 当前ABF载板行业的景气度和紧缺程度如何？

  • 受访者基于公司接单和产能排期判断，ABF载板行业在2029年以前、甚至2030年以前都将维持紧缺。
  • 公司现有产能已基本排满，目前没有能力承接新客户；部分新客户询价时，公司甚至不会报价。
  • 具体紧缺截止时间尚无法精确到某个月份，公司对外口径通常为“2029年至2030年前没有新增产能可支持”。
  • 受访者认为，ABF载板短缺会直接影响芯片出货：
  1. 芯片完成晶圆制造后仍需ABF载板才能封装。
  2. 封装环节缺少任一关键材料都无法完成交付。
  3. CoWoS产品可能在台积电、日月光等封装环节形成等待；EMIB体系同样会受到载板供应约束。

b) 是所有ABF产能紧缺，还是只有高端产能紧缺？

  • 就Ibiden而言，高端和低端产品目前均处于满产状态。
  • 日本工厂已全面转向高端产品，菲律宾工厂主要承接PC等相对低端产品。
  • 日本工厂自去年起不再生产低端PC类载板，相关订单全部转移至菲律宾，侧面反映低端产能同样紧张。
  • 公司高端产品占比更高，因此外部感受到的紧缺更集中在AI GPU、服务器CPU和先进封装载板领域。

c) 当前紧缺的主要原因是载板产能不足，还是上游材料短缺？

  • 2030年以前，主要瓶颈是ABF载板工厂自身产能不足，各家产线均处于高负荷运转状态。
  • 上游材料中：
  1. 玻纤布相对更紧缺，是当前CCL供应链的主要约束。
  2. ABF膜相对没有那么紧缺，Ibiden属于味之素重点保供客户。
  3. Intel、NVIDIA等大客户会直接管理玻纤布、CCL等二三级供应商，并通过投资锁定供应量。
  • 2030年以后，随着Ibiden新工厂投产，如果玻纤布和CCL等上游厂商未同步扩产，瓶颈可能从载板制造转移至材料端。
  • 因此，2030年后并非供过于求，而是可能出现“载板产能扩张、上游材料扩张不足”的结构性矛盾。

2. 高低端产能差异与切换能力

a) 高端和低端产能能否相互切换？

  • 日本工厂具备同时生产高端和低端产品的能力，但目前主要用于高端产品。
  • 菲律宾工厂已有20多年历史，也能生产部分高端产品，但设备较老，生产效率和产能利用率较低。
  • 在设备和工艺允许的情况下，高端产线可以向下兼容低端产品；老旧低端产线向高端产品切换则存在明显限制。

b) 高端和低端产能的核心差异是什么？

  • 第一项差异是设备能力：
  1. 高端产品线宽线距通常低于10微米，低端产品可能略高于10微米。
  2. 如果没有特定高精度曝光设备，难以实现高端产品要求的精细线路。
  • 第二项差异是Panel尺寸：
  1. 当前主流Panel尺寸约为510×515mm。
  2. 菲律宾老厂仍使用约410×510mm等旧规格。
  3. 对于90×90mm、100×100mm等大尺寸产品，较小Panel可排布的产品数量更少，单位时间产出偏低。
  • 第三项差异是复杂度和层数：
  1. 高端AI GPU、服务器CPU产品层数更高、Build-up次数更多。
  2. 大尺寸、高层数产品更占用曝光、压膜等关键工序产能，良率爬坡也更困难。

c) Ibiden是否仍生产BT载板？

  • Ibiden已于2022年将BT载板相关材料、设备和工厂出售给兴森科技（Fastprint）。
  • 出售后，公司彻底退出BT载板业务，目前聚焦ABF载板。

3. 产能口径与500K数据核算

a) 公司所称月产能500K具体是什么口径？

  • 500K指月度SAP/Build-up制程面积，单位为平方米，并非最终出货面积，也不是Panel数量。
  • 该口径主要根据曝光设备数量和单机月产能推算：
  1. 公司约有25至30台曝光设备。
  2. 单台设备月产能约1.5万至2万平方米。
  3. 按25台、单台2万平方米计算，对应约50万平方米/月。
  • SAP面积按每次Build-up逐层累计，因此不能直接等同于最终载板出货面积。

b) SAP产能应如何折算为实际出货面积？

  • 以10层板为例，其中2层为Core层，其余对应约4次Build-up，因此SAP面积需要除以4，而不是按10层直接计算。
  • 实际出货量还需要进一步考虑：
  1. 产品Build-up次数。
  2. 单颗尺寸及Panel排版数量。
  3. 产品良率。
  4. 不同工厂的Panel规格。
  • 因产品结构差异较大，SAP面积不能直接线性推算Pieces数量或收入。

c) 500K数据目前是否已经完全核实？

  • 尚未完全核实。
  • 按500K月度SAP面积、公司收入及同行数据进行交叉验证时，仍存在较大差异。
  • 访谈中一度以“1平方米SAP约1000美元”进行估算，但该价值量缺少实际出货面积、产品结构和平均售价支持。
  • 受访者表示需要重新核对500K的官方口径及其与收入的对应关系。
  • 后续核算需要统一以下口径：
  1. SAP/Build-up面积。
  2. 最终出货面积。
  3. Panel数量。
  4. Pieces数量。
  5. 产品层数、良率和售价。
  • 结论是：500K可以作为曝光设备理论产能参考，但不宜直接用于收入、出货颗数或客户份额测算。

4. 工厂布局与扩产计划

a) Ibiden当前主要工厂和产能如何分布？

  • 日本拥有3个主要量产基地；若按相连的1厂、2厂分别计算，可视为5个工厂。
  • 主要产能口径如下：
  1. 大垣工厂：约185K/月。
  2. 中央工厂：约185K/月。
  3. 大野工厂：约60K/月。
  4. 菲律宾工厂：约70K/月。
  • 日本工厂主要生产高端产品，菲律宾工厂主要生产Intel、AMD和NVIDIA的PC类、小尺寸、相对低端产品。
  • 按Cell划分：
  1. Cell 2和3合计约180K至185K/月，属于较老产线。
  2. Cell 4和5合计约180K至185K/月，其中Cell 5曾由Intel出资建设。
  3. Cell 6主要对应先进产品及EMIB-T相关产线。
  4. Cell 8于2025年10月开始稼动，新增约60K/月产能。

b) 当前有哪些明确的扩产项目？

  • 当前主要有两个扩产项目：
  1. 新增约30K/月的先进产能，预计2027年Q1量产。
  2. 另一项目仍在扩建，预计2028年至2029年左右再扩充约50%，目标产能可能由约60K提升至120K/月。
  • 公司还有Cell 7和Cell 9等后续规划，但预计属于2030年后的项目。
  • NVIDIA与多家ABF载板厂签署合作协议后，Ibiden目前没有新增未披露的大规模扩产计划，仍以既定项目为主。
  • 在新增产能有限的情况下，公司更可能通过调整客户结构，将资源从AMD等客户转向NVIDIA和Intel。

c) 客户投资如何影响产能分配？

  • Intel和NVIDIA均通过出资建设或追加投资锁定产能。
  • Intel目前可明确对应的专属产能约为：
  1. 中央工厂约90K/月。
  2. 新EMIB-T工厂初期约30K/月。
  3. 合计约120K/月，后续可能继续增加。
  • NVIDIA有约60K/月的共同投资或专属产能，此外还会使用其他自有工厂中的共享产能。
  • AMD没有在Ibiden投入资金，Ibiden曾多次要求其投资，但AMD选择投资三星电机和奥特斯等供应商。
  • 公司当前战略较明确：先进产品若客户不共同投资，公司将降低支持意愿，甚至停止供货。

5. 客户结构与销售额预测

a) Ibiden当前主要服务哪些客户？

  • 核心客户主要是NVIDIA、Intel和AMD，此外还有台积电、三星等规模较小的客户。
  • 出货颗数因产品尺寸和价值量差异较大，参考意义有限，因此更适合使用销售额占比衡量客户结构。

b) 当前财年ABF载板销售额和客户贡献如何？

  • 2026年4月1日至2027年3月31日财年，ABF载板销售额预计约3500亿日元：
  1. NVIDIA约1800亿日元。
  2. Intel原预计1000亿日元，后下调至约850亿日元。
  3. AMD约450亿日元。
  4. 台积电、三星等小客户合计约320亿日元。
  • 上一财年ABF载板销售额约2400亿日元：
  1. NVIDIA约1200亿日元。
  2. Intel约800亿日元。
  3. AMD约350亿日元。
  4. 其余来自三星和台积电。
  • 从2400亿日元增长至3500亿日元，并非完全依赖产量增长，主要来自：
  1. 新产品报价更高。
  2. 高价值量产品占比提升。
  3. 2025年10月新增约60K产能的部分贡献。

c) 后续销售额和客户结构如何变化？

  • 按受访者提供的后续财年预测，销售额可能依次达到约4700亿、6643亿、6500至6600亿、最终约8300亿日元。
  • 其中NVIDIA和Intel贡献持续提高：
  1. 约4700亿日元阶段：NVIDIA约2589亿、Intel约1174亿、AMD约468亿。
  2. 约6643亿日元阶段：NVIDIA约3903亿、Intel约1908亿、AMD约318亿。
  3. 约6500至6600亿日元阶段：NVIDIA约3900亿、Intel约2119亿、AMD降至约140亿。
  4. 约8300亿日元阶段：NVIDIA约5024亿、Intel约2681亿，其余客户合计约350亿至400亿，AMD可能仅约100亿。
  • 该组预测的具体财年对应关系在原始沟通中存在混用，但趋势非常明确：
  1. NVIDIA成为最大增长来源。
  2. Intel占比持续提升。
  3. AMD销售额和战略地位明显下降。

d) Ibiden在各客户供应链中的份额如何？

  • NVIDIA：Ibiden份额约70%，其余主要由欣兴、景硕等供应商承担。
  • Intel：在其全部采购中的份额约20%至30%；Intel通常保持4至5家固定供应商，不会将全部产品集中在单一厂商。
  • AMD：
  1. 高端服务器和AI产品份额约50%至60%的口径较为宽泛。
  2. Server CPU份额约50%。
  3. AI加速卡份额约30%至40%。
  4. PC CPU份额低于10%。

6. Intel业务与EMIB-T进展

a) Intel相关专属产能如何安排？

  • 中央工厂约有90K/月产能用于Intel，相关产线最初由Intel出资建设。
  • 当Intel需求较弱时，Ibiden曾用该产线生产其他客户产品；随着Intel订单恢复，其他客户订单已被转移，产线重新专供Intel。
  • 新建的Gama工厂（原记录音译）规划产能约30K/月，100%用于Intel的EMIB-T产品，预计2027年Q1量产。
  • 菲律宾工厂也有部分产能用于Intel PC类产品，但具体比例尚不明确。

b) Intel提到ABF载板紧缺，具体问题是什么？

  • 传统服务器CPU方面，Intel确实面临载板供应紧张。
  • 更重要的问题可能来自EMIB-T：
  1. 产品技术难度高。
  2. 当前良率长期无法有效提升。
  3. 设备和制程仍需进一步开发、测试。
  4. Intel认为终端需求可能高于初始规划，现有30K/月产能可能不足。
  • Intel近期又提供了1000多亿日元资金：
  1. 部分用于扩充产能。
  2. 部分用于设备和制程改良。
  3. 核心目标是提升良率并保障后续供应。
  • 追加投资最终能增加多少产能，受访者暂不掌握。

c) EMIB-T产品目前的规格和良率如何？

  • 当前试做产品主要有两个规格：
  1. 谷歌产品：115×119mm、20层、9-2-9结构，内部代号“Hutton Hill”。
  2. 亚马逊产品：119×120mm、20层、9-2-9结构，内部代号“Beckley Hill”。
  • 两款产品的Silicon Bridge均由客户提供，ABF载板单颗价格约200美元。
  • 前期试做良率仅20%多、不到30%。
  • 客户目标良率约57%，测算时可暂按50%计算；预计到次年年底才可能逐步接近目标。

d) 30K月产能对应多少出货量和产值？

  • 按9次SAP/Build-up计算：
  1. 30K SAP面积除以9，约为3333平方米实际制程面积。
  2. 按50%良率计算，可出货面积约1666平方米。
  3. 510×515mm Panel每片约可排16颗大尺寸产品。
  4. 1平方米约对应64颗。
  5. 月出货约10.7万颗。
  • 按单颗200美元计算：
  1. 月产值约2000万至2140万美元。
  2. 年化产值约2.4亿至2.6亿美元。
  • 该测算高度依赖良率，当前实际良率尚未达到50%，因此初期实际产值会低于上述水平。

e) EMIB和EMIB-T有什么区别？

  • 两种技术均是在压合ABF膜时开腔，将Silicon Bridge埋入载板。
  • EMIB采用绕行方式供电。
  • EMIB-T中的“T”代表Through Hole：
  1. 腔体中设置铜制垂直通孔。
  2. 电流可以上下直连，为Silicon Bridge供电。
  3. 技术难度和制造要求高于普通EMIB。
  • 普通EMIB目前Ibiden、新光、奥特斯等厂商可以生产。
  • EMIB-T尚未正式大规模量产，Ibiden和新光正在试做，欣兴未来也会试做，奥特斯预计2028年前后开始进入。

7. NVIDIA业务与产品迭代

a) NVIDIA为何成为Ibiden最重要的客户？

  • Ibiden在NVIDIA GPU载板中的供应份额约70%，在主要供应商中排名第一。
  • NVIDIA愿意通过共同投资、锁定玻纤布和CCL等方式保障供应。
  • 相比AMD，NVIDIA产品量级更大、订单确定性更高，也更愿意为先进产能提供资金。
  • Ibiden正在将AMD高端GPU释放出的有限产能转移至NVIDIA。

b) NVIDIA主要产品的载板规格如何演进？

  • GH100/H100：
  1. 尺寸约58×55mm。
  2. 5-2-5结构，共12层。
  • GB100：
  1. 尺寸约73×81mm。
  2. 6-2-6结构，共14层。
  • GR100：
  1. 尺寸约83×97mm。
  2. 8-2-8结构，共18层。
  3. 单颗价格约207美元。
  4. 510×515mm Panel约可排30颗。
  • GR150：
  1. 尺寸约110×90mm。
  2. 8-2-8结构，共18层。
  3. 每个Panel约可排20颗。
  4. 稳定量产后良率预计约80%。
  • FN100：
  1. 预计2028年推出。
  2. 尺寸可能为81×115mm。
  3. 规格尚未最终确定，预计仍为8-2-8。
  • 产品迭代趋势是尺寸更大、层数更多、价值量更高，对单位产能占用持续增加。

c) NVIDIA产品的良率情况如何？

  • GR100已经量产，但良率尚未达到90%。
  • Ibiden当前GPU产品中，基本没有良率达到90%的产品。
  • 大尺寸、高层数新产品在初期的良率普遍偏低，稳定量产后才可能达到80%左右。
  • 因此，即便名义SAP产能不变，产品结构向更大尺寸、更高层数升级，也会显著压缩实际可交付颗数。

d) NVIDIA未来是否可能采用EMIB？

  • 受访者预计，2028年前后Intel部分EMIB专利可能到期。

9. 定价机制与价值量提升方式

a) 在供需紧缺情况下，公司为什么没有大幅涨价？

  • 公司通常针对每一个新产品或新项目单独报价，而非按年度统一调整所有产品价格。
  • 报价流程一般为：
  1. 客户提出新项目。
  2. 试作前确定试作价格及未来量产价格。
  3. 客户每周滚动更新Forecast。
  4. 在Lead Time对应节点将Forecast转为正式PO。
  5. 后续按滚动预测持续生产。
  • 同一产品报价确定后，除非规格发生变化，否则价格通常不会频繁调整。
  • 因此，行业紧缺更主要通过以下方式体现：
  1. 新产品采用更高报价。
  2. 优先为投资客户分配产能。
  3. 淘汰低价值或缺乏战略支持的订单。
  4. 提升高价值量产品占比。

b) 公司能否对AMD等未投资客户涨价？

  • AMD产品已进行小幅涨价，但幅度有限，约2至3个百分点。
  • 例如部分产品价格由68美元上调至71美元。
  • 日系供应商一般不倾向于在老产品上大幅涨价，而是通过新品报价和产品结构升级提升收入。

c) 为什么销售额增长能明显快于产能增长？

  • 主要来自产品价值量提升，而非单纯出货面积增长：
  1. AI GPU载板尺寸持续扩大。
  2. 层数和Build-up次数增加。
  3. EMIB-T等先进技术显著提高单颗价格。
  4. NVIDIA、Intel等高价值客户占比提升。
  5. AMD PC类低价产品和部分低价值订单占比下降。
  • 因此，未来销售额可能快速增长，但实际SAP产能增幅相对有限。

10. 核心结论与待核实事项
