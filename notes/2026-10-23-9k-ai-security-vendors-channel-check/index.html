专家访谈纪要

1. 信息安全预算与市场增长趋势

a) 与去年相比，客户安全预算的配置方式发生了哪些变化？

  • 安全需求并未下降，主要变化在于客户重新分配预算：
  1. 越来越多客户将独立安全产品整合至Palo Alto、CrowdStrike等供应商的一体化平台，以减少重复授权和工具重叠。
  2. 传统硬件更新更具选择性，客户倾向于延长现有基础设施的使用寿命，优先采购云交付的安全能力。
  3. AI驱动的检测、自动化和托管安全服务正在吸引增量投资，传统安全工具获得的预算相应减少。
  4. 采购审查更加严格，客户在续约时要求更明确的投资回报率、更高的产品利用率和更有利的商务条款。
  • 传统安全支出整体仍保持稳定和韧性，但增长方向已经从“增加更多工具”转向“现有能力的现代化与整合”。
  • 平台型供应商将明显受益，独立产品供应商则面临更大的定价和续约压力。

b) 2026年和2027年信息安全支出预计增长多少？

  • 2026年安全支出预计同比增长10%至12%。
  • 2027年预计同比增长13%至15%，较2026年加快约3至4个百分点。
  • 分领域来看：
  1. 传统安全支出预计增长4%至8%。
  2. AI相关和云安全投资预计增长25%至30%。
  • 2027年增速加快的主要驱动力包括AI安全、云工作负载保护、身份安全和网络韧性。
  • 客户正由AI试验转向生产环境部署，这将产生围绕身份、数据、应用和基础设施的新增安全需求。
  • 上述判断仍具有前瞻性，最终增速需要结合2026年业务管线和客户项目落地情况观察。

c) 哪些新增安全需求最受客户关注、最容易获得预算？

  • 按照预算优先级排序：
  1. 身份与访问安全：预算优先级最高。
  2. 云安全与数据安全：客户投入重点。
  3. AI专项安全：增速最快，但预算转化的可预测性相对较低。
  • 身份与访问安全的主要需求包括：
  1. 特权访问管理。
  2. 机器身份和服务账户管理。
  3. AI智能体身份、权限及授权控制。
  4. 满足运营和监管合规要求。
  • 云与数据安全重点包括DSPM、零信任架构、云工作负载保护及敏感客户数据保护。
  • AI安全重点包括：
  1. 防止AI应用中的敏感数据泄露。
  2. 控制AI智能体的访问权限。
  3. 提升AI模型交互的可观测性。
  • 预计2026年：
  1. 身份与访问安全增长14%至18%。
  2. 云与数据安全增长18%至20%。
  3. AI安全由于基数较低，增幅预计超过30%。
  • 当前身份安全最容易获得预算批准；从未来几年的增量空间看，AI安全潜力最大。
  • 能够把AI安全与身份、云和数据保护平台整合的供应商，将处于更有利的位置。

d) 安全预算占企业总体IT预算的比例如何变化？

  • 大型客户2025年安全预算约占IT总支出的9%至10%。
  • 2026年预计提升至10%至12%，平均约为11%。
  • 2027年预计整体保持稳定并可能进一步提高约1个百分点。
  • 安全预算占比提升的主要原因包括：
  1. 安全支出增速高于整体IT支出。
  2. 身份安全、云保护、监管合规和网络韧性的重要性提升。
  3. AI投入生产后，企业需要加强对机器身份、敏感数据及自主智能体的管控。
  • 具体占比还取决于统计口径是否纳入安全相关云服务和托管服务。
  • 在其他可自由支配支出受到更严格审查的情况下，网络安全正成为企业IT预算中更受保护的组成部分。

2. AI时代的安全硬件需求变化

a) 随着AI智能体和AI IoT扩大应用，哪些安全硬件需求将增长？

  • 硬件需求将向高性能网络安全、边缘安全和基于硬件的身份保护集中。
  • 主要增长方向包括：
  1. 支持AI的下一代防火墙和高吞吐量安全设备：用于加密流量低延迟检测及AI工作负载保护，Palo Alto和Fortinet定位较好。
  2. 边缘安全网关和工业物联网安全硬件：制造、物流、零售及关键基础设施行业需求较强，重点满足安全连接、设备身份验证和网络分段需求。
  3. HSM、TPM和安全元件：受益于机器身份、加密保护和AI智能体身份验证需求增长。
  • 预计增长水平：
  1. 支持AI的高吞吐量防火墙增长10%至15%。
  2. 边缘和工业物联网安全网关增长15%至20%。
  3. HSM及基于硬件的身份保护增长12%至15%。
  • HSM相关增量需求中的一部分可能由云端HSM服务承接，而非实体设备。

b) 哪些传统安全硬件需求可能放缓或下降？

  • 传统独立VPN集中器、传统防火墙设备和专用安全监控硬件将面临更大压力。
  • 客户正在从传统设备转向零信任网络访问和云原生安全平台。
  • 预计：
  1. 传统防火墙设备增速为0%至5%。
  2. 独立VPN设备可能下降5%至10%。
  3. 传统专用安全监控设备可能出现类似幅度的负增长。
  • AI智能体不会推动实体安全硬件支出普遍增长，大部分增量投资仍由软件驱动。
  • 硬件增长将主要集中在高性能流量检测、安全边缘连接、加密信任和运营技术环境保护等领域。

3. 安全市场竞争格局与平台整合趋势

a) 主要安全厂商的市场份额变化如何？

  • Palo Alto：
  1. 是平台整合趋势的主要受益者之一。
  2. 客户正从传统网络安全扩展至SASE、云安全和Cortex。
  3. 在大型、复杂企业环境中的竞争地位持续提升。
  • CrowdStrike：
  1. 市场份额明显提升。
  2. Falcon平台正从端点安全扩展至身份安全、云安全和下一代SIEM。
  • Cloudflare：
  1. 在应用安全、零信任、API保护和网络服务领域获得更多关注。
  2. 将安全与连接能力整合在统一全球平台上的模式，对云优先企业吸引力较强。
  • Zscaler：
  1. 在零信任转型和传统VPN替换中定位有利。
  2. 同时面临Palo Alto及其他一体化SASE供应商的激烈竞争。
  • Okta：
  1. 身份安全总体需求仍在增长。
  2. Microsoft Entra及Microsoft 365 E5捆绑销售带来较大的价格压力。
  3. 在复杂身份环境和客户身份场景中仍有较强竞争力。
  • Rubrik在网络韧性领域的业务表现显著改善。
  • 综合来看，Palo Alto和CrowdStrike是安全预算整合趋势中最主要的受益者；Cloudflare持续改善；Zscaler有所改善但竞争加剧；Okta表现相对复杂。

b) 客户如何整合安全供应商和预算？

  • 客户正从采购大量单项“最佳产品”，转向将安全能力集中至3至4家战略平台供应商。
  • 端点和SOC整合案例：
  1. 某大型金融客户原本分别采购CrowdStrike端点安全、独立SIEM及身份威胁检测工具。
  2. 续约时将更多能力整合进Falcon平台。
  3. CrowdStrike合同价值提高30%，但客户总体安全预算仅增长10%。
  • 网络和云安全整合案例：
  1. 某零售客户原本使用Palo Alto防火墙、独立VPN、单独云安全工具及多个Web安全产品。
  2. 客户评估通过Prisma Access及更广泛的平台组合整合相关能力，同时也考察Zscaler和Cloudflare。
  3. 决策重点由单项产品功能转向总体成本、集成复杂性和运营效率。
  • 身份管理整合案例：
  1. 已购买Microsoft 365 E5的客户开始评估是否仍需为全部员工身份场景单独采购Okta。
  2. 部分客户将标准身份验证迁移至Entra，仅保留Okta支持复杂应用和身份场景。
  3. 身份安全总体支出仍在增长，但Okta在部分客户中的合同规模可能收缩。

c) 安全采购决策机制发生了哪些变化？

  • 过去各安全团队对专业产品拥有较大自主权；现在通常由CISO、企业架构师和采购团队共同决策。
  • 采购考量重点包括：
  1. 平台覆盖范围。
  2. 风险降低程度及其可衡量性。
  3. 至少3年的总体拥有成本。
  4. 产品实际利用率和投资回报率。
  • 某客户此前每年向15家安全厂商支付约1,000万美元，整合后供应商数量降至8至10家，重叠许可证费用及运营成本下降15%。
  • 供应商整合并不一定导致安全总支出下降，而是将预算重新分配给更少的战略供应商。
  • 这也是Palo Alto、CrowdStrike等平台型厂商增速高于安全市场整体增速的重要原因。

4. Palo Alto业务表现与增长预期

a) Palo Alto新客户ACV增长情况如何？

  • 2026年8月至10月季度，新客户ACV同比增长约15%至25%，整体判断接近25%。
  • 主要驱动力包括：
  1. 更大规模的平台协议。
  2. Prisma SASE采用。
  3. Cortex业务扩展。
  4. 客户将多项安全能力整合至Palo Alto平台。
  • 预计下一季度新客户ACV仍将保持约25%的同比增长。
  • 对整个2027财年的预期也大致相近，平台整合和AI安全需求将继续提供支持。

b) Palo Alto现有客户净ACV增长情况如何？

  • 2026年8月至10月季度，现有客户净ACV同比增长约18%至20%，平均判断约为18%。
  • 下一季度预计同比增长12%至18%。
  • 2027年全年预计保持相近水平，整体判断约为18%。
  • 增长主要来自Cortex、SASE、云安全和AI安全能力的交叉销售与扩展。

c) Palo Alto新增ACV中新老客户的贡献结构如何？

  • 现有客户净扩张约贡献新增ACV的60%。
  • 新客户约贡献新增ACV的40%。
  • 现有客户贡献较高，主要是因为Palo Alto拥有庞大的客户基础，可在既有客户中继续销售Cortex、SASE、云安全及其他模块。
  • 随着平台整合加速，中期内现有客户贡献占比可能进一步提高，但目前尚未发生非常显著的结构变化。
  • 已平台化客户约贡献总ARR的60%，但该指标不等同于新增ACV贡献比例。

d) Palo Alto客户数量增长是在加速还是放缓？

  • 公司仍在通过SASE、Cortex和云安全产品持续吸引新客户。
  • 新增客户数量保持正增长，但尚无证据表明客户数量增速明显提升。
  • 整体业务增长更多来自：
  1. 现有客户采用更多平台。
  2. 单个新签合同规模扩大。
  3. 合同覆盖的安全能力增加。
  • 即使客户数量增速保持稳定，合同价值仍可能加速增长。
  • 平台化业务净新增在2026财年Q2表现较好、Q3进一步加速、Q4实现显著增长，预计积极势头延续。

e) Palo Alto各产品线增长情况如何？

  • Prisma SASE：
  1. 上季度增长约35%。
  2. FY27预计维持相近水平，但随着业务基数扩大，增速可能逐步趋于温和。
  • Prisma Cloud：
  1. 上季度增长约10%至15%。
  2. 下一财年预计增长15%至25%。
  3. 主要由云工作负载保护需求驱动，但市场竞争较为激烈。
  • Cortex：
  1. 上季度ARR增长超过50%。
  2. 收入增长超过20%。
  3. 下一财年收入增速预计处于20%高位，乐观情况下可达30%。
  4. XSIAM采用和SOC整合是主要驱动力。
  • CyberArk身份安全：
  1. 上季度收入增长超过16%。
  2. 下一财年增速最高可能达到20%。
  3. 受益于特权访问、机器身份和AI智能体授权需求。
  • Prisma AI Security：
  1. ARR增长较快，但由于基数较小，暂时没有明确的增速口径。
  2. 市场关注度正在提升，未来表现仍需更多数据验证。
  • 整体而言，Palo Alto正加速向传统防火墙以外的领域扩展，Cortex、Identity和AI Security将贡献更多增量增长。

5. Cloudflare业务表现与AI代理流量

a) Cloudflare新客户ACV增长情况如何？

  • 2026年第三季度，新客户ACV同比增长约25%。
  • 第四季度预计增速可能超过30%。
  • 主要驱动力包括：
  1. 大型合同数量增加。
  2. 零信任业务增长。
  3. 应用安全和API保护需求提升。
  4. 网络现代化项目增加。
  • 增长更多来自大合同和初始合同金额提升，而不是单纯依靠小客户数量增加。
  • Cloudflare将安全、网络和开发基础设施结合，为扩大初始合同规模创造了条件。

b) Cloudflare现有客户净ACV增长情况如何？

  • 现有客户净ACV同比增长约20%。
  • 第四季度预计保持相近或提升至约25%。
  • 主要由零信任、应用安全、网络服务及新增工作负载扩展驱动。
  • 大型客户将更多能力整合至Cloudflare平台，现有客户扩展正成为越来越重要的增长动力。
  • 当前客户组合的净留存率超过100%。

c) Cloudflare新老客户ACV贡献比例如何？

  • 新客户贡献约55%至60%。
  • 现有客户贡献约40%至45%。
  • 可概括为新客户与现有客户约为60%比40%。
  • 下一季度预计总体结构保持稳定。
  • 随着客户采用逐渐成熟，现有客户贡献可能小幅提升。
  • 相较于Palo Alto，Cloudflare仍在快速扩大大客户基础，因此新客户贡献占比相对更高。

d) AI代理流量增长是否已转化为ACV增长？

  • 已有较充分证据表明Cloudflare平台上的AI代理流量正在加速增长。
  • 但代理流量转化为客户ACV扩张仍处于早期阶段。
  • 当前主要表现为：
  1. 不同客户的代理流量增幅差异较大。
  2. 代理流量较高的客户可能增加机器人管理、API安全、零信任和AI网关支出。
  3. 流量增长尚未自动转化为更高ACV，部分客户现有合同容量仍然充足。
  4. 需要扩大使用规模的客户，后续可能追加用量承诺。
  • 随着更多客户将AI代理投入生产，预计代理流量对Cloudflare业务扩张的影响将在下一年更加明显。

6. CrowdStrike业务表现与端点安全增长

  • 大型客户正在替换分散的端点安全及SOC安全解决方案，为CrowdStrike带来较强增长动能。

  • 下一季度预计同比增长20%至25%。
  • 主要驱动力包括：
  1. Falcon Flex采用。
  2. 增购Falcon模块。
  3. 身份保护。
  4. 云安全。

c) CrowdStrike新老客户ACV贡献结构如何？

  • 现有客户ACV贡献约55%。
  • 下一季度预计结构基本稳定。
  • 随着Falcon Flex采用和交叉销售推进，贡献结构可能小幅向现有客户倾斜。
  • CrowdStrike既拥有庞大的现有客户扩展空间，新客户拓展也依然保持强劲。

d) CrowdStrike端点安全业务是否持续加速？

  • 端点安全业务继续呈现明显增长趋势。
  • 端点安全业务同比增长约15%至20%。
  • 付费端点许可证数量同比增长约15%。
  • 端点ARR增长约20%，快于许可证数量增长，表明部分增长来自高级功能和单个端点合同价值提升。
  • 主要驱动力包括：

提问者：您刚才提到，客户的决策正在受到影响，他们在大幅整合安全预算。您能否详细介绍一下您观察到的情况，并举一些案例？

回　答　者：可以。根据我的观察，今年网络安全采购领域最明显的变化之一，是客户正从购买单个同类最佳产品，转向将相关能力整合到3到4家战略平台供应商。我可以举3个例子，分别说明。

第1个例子是端点和SOC整合。我们有一家大型金融服务客户，使用CrowdStrike进行端点保护，同时还使用独立的SIEM平台和额外的身份威胁检测工具。续约时，该客户评估了扩大Falcon协议覆盖范围，以纳入更多相关能力。最终，客户没有续签3份独立合同，而是与CrowdStrike协商签订了一份规模更大的协议，使CrowdStrike的实际合同价值提高了30%，而该客户的总预算仅增长了10%。这正是我之前提到的情况。

第2个例子是网络和云安全整合。我们有一家零售客户，原先使用Palo Alto防火墙、独立VPN解决方案、单独的云安全工具以及多个Web安全产品。该客户评估了通过Prisma Access及更广泛的平台产品组合来整合这些能力，也考虑了Zscaler和Cloudflare。其决策更多基于总体成本和集成复杂性。
