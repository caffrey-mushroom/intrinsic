专家访谈纪要

1. 明年排产与产能规划

a) 明年整体排产规模是多少，较此前发生了什么变化？

  • 最新排产规模
  1. 根据当前版本，明年整体排产约为147台。
  2. 排产计划处于持续滚动调整中，并非最终锁定值。
  3. 约两个月前的上一版计划为220台左右，最新版本已明显下修。
  4. 若后续没有新增、明确进入洽谈阶段的大额订单，预计全年将围绕147台推进，上下浮动10—20台属于正常范围。
  • 排产下修的可能原因
  1. 可能同时受到订单预期变化、机头资源不足、合作关系变化、市场需求变化及供应链风险等因素影响。
  2. 公司通常不会公开说明排产下调的具体原因，因此目前只能根据业务情况进行推测。
  3. 排产不仅代表销量预期，还意味着提前锁定人员、厂房、设备和物料等资源；越接近实际生产期，计划越严格、数据也越接近真实情况。
  4. 此前按每月20台、全年约240台的能力储备资源，目前147台的安排相对更加审慎。

b) 排产通常提前多久具有较高确定性？

  • 相对可靠的排产窗口约为提前4个月。
  • 单个项目从工程设计、BOM冻结、客户确认、物料采购到制造交付，完整周期通常为6—7个月。
  • 海外采购物料通常需要考虑供应商生产周期和海运周期，部分物料正常采购周期可达6个月。
  • 排产计划几乎每天都会调整，主要变化包括：
  1. 开工时间；
  2. 各型号上线顺序；
  3. 工位安排；
  4. 物料到货节奏；
  5. 客户交付优先级。
  • 日常计划虽频繁调整，但未来4个月左右的资源安排相对更具参考价值。

c) 147台设备的功率结构如何？

  • 25MW设备
  1. 为绝对主力，预计超过100台。
  2. F泰合作项目自身约为100台，此外还有其他厂商的25MW机头。
  3. 其他25MW产品主要包括原有西门子机头，并非全新开发机型。
  • 其他功率段
  1. 6MW和8MW设备合计十几台，不超过20台。
  2. 其中一个功率段采用川崎新设计机头，可能约8台，但具体是6MW还是8MW尚待确认。
  3. 35MW设备有一定数量，但不是主力。
  4. 45MW设备约2台。
  • 需要注意
  1. 上述结构来自访谈者印象，部分具体数量和机型归属尚未最终核实。
  2. 原来锁定的西门子、贝克休斯等机头数量可能有所减少，但F泰约100台的规划暂未发生明显变化。

d) 当前产能能否支撑147台甚至100台F泰设备？

  • 当前产线按照每月20台的能力进行设计，理论年产能约240台，因此支撑147台不存在明显硬件瓶颈。
  • 公司已按此前220—240台的规划提前储备厂房、人员和工位：
  1. 新建1座约2万平方米的总装厂房，规划约60个工位，预计年底前交付；
  2. 另有厂房用于喷涂业务，目前约使用一半；
  3. 已租用约1.5万平方米工厂并投入使用；
  4. 相关硬件资源总体较为充足。
  • 如果F泰产品研发和可靠性验证顺利，即使明年2月或3月才开始进入交付阶段，仍有机会通过加速生产追回100台目标。
  • 若后续新增订单充分，现有资源也具备向200台以上扩张的基础。

2. F泰合作模式与双方分工

a) F泰与杰瑞分别负责哪些工作？

  • F泰的主要职责
  1. 提供机头及机头设计方案；
  2. 完成航改机头改造；
  3. 输出机头技术参数；
  4. 与杰瑞协同完成接口和适配方案设计；
  5. 参与机头测试，并可能参与部分联测；
  6. 承担部分销售和客户拓展职能。
  • 杰瑞的主要职责
  1. 根据机头参数完成整套发电设备的成套适配；
  2. 设计撬装或车装结构、底盘、框架和外壳；
  3. 完成压力、管路、仪表监控、电气走向等设计；
  4. 采购发电配套设备、柜体、仪表、附属配件等；
  5. 完成结构件加工、线束制作、仪表箱组装、总装和测试；
  6. 负责包装、海运、北美当地加工及最终联调；
  7. 提供客户端安装、调试、试生产、售后、维修及备件服务；
  8. 负责SCR尾气处理系统的设计和总成。
  • 合作本质
  1. F泰主要掌握机头技术和机头资源；
  2. 杰瑞主要承担从机头到完整发电装备的工程化、成套化和交付服务；
  3. 双方在设计阶段持续交换图纸和参数，并非等机头实物交付后才开始合作。

b) 双方销售职责和订单分成如何安排？

  • F泰与杰瑞均会承担客户拓展和订单获取职责。
  • 原则上，谁在获取订单、客户导入和项目推进中的贡献更大，谁获得的收益和分成更多。
  • 已披露的首个大型客户订单，据访谈者判断可能主要由F泰获取，客户核心诉求也可能是使用F泰机头。
  • 具体客户归属、销售提成、交付价格、利润分配等信息高度保密，可能仅有公司最高层少数人员掌握。

c) F泰为什么选择与杰瑞合作？

  • 访谈者推测，F泰可能在获取订单后，需要寻找具备总成和批量交付能力的合作方，因此主动推动与杰瑞合作。
  • 杰瑞在以下方面具备优势：
  1. 国内完整且低成本的制造供应链；
  2. 成套设备设计和工程交付能力；
  3. 北美项目执行及现场服务能力；
  4. 结构件、管路、撬装、车装、喷涂和总装能力；
  5. EPC、数据中心及液冷业务协同能力。
  • 双方合作推进速度较快，相关事项可能在约一个月内落地。
  • F泰并不在杰瑞最初的机头合作规划中，原规划主要涉及川崎和西门子。

3. F泰原型机进度与首台交付判断

a) 当前原型机进展如何？

  • 原型机原计划于9月左右定型，但目前已经延期。
  • 按原计划，现阶段应已完成样机交付，并启动首台装配测试和客户认证，但相关工作尚未正式开展。
  • 当前至12月前的生产计划中，暂未看到F泰相关型号的明确排产，也没有预留对应产能。
  • 按排产逻辑推断：
  1. 若对方承诺1个月后交付机头，杰瑞即可提前安排生产；
  2. 目前连12月生产计划都未安排，意味着F泰尚未明确承诺12月可交付；
  3. 因此，12月实现完整设备交付存在较大难度。

b) 年内是否有可能完成“首次交付”？

  • 双方内部要求和期望仍是争取在年前完成原型机交付，至少形成阶段性里程碑。
  • 访谈者认为，12月完成机头或原型交付仍存在可能，双方目前都在加快推进。
  • 但若“首次交付”指真正可供客户稳定运行的完整设备，则年底前实现的可能性较低。
  • “首次交付”定义存在一定操作空间，可能包括：
  1. 完成原型机交付；
  2. 完成简易联测设备交付；
  3. 将尚未完全成熟的样机送至客户现场；
  4. 举行阶段性交付仪式。
  • 因此，需要区分“资本市场口径的里程碑交付”和“可商业运行设备的实质交付”。

c) F泰所称的完整设备测试应如何理解？

  • F泰目前主要负责机头本身的测试，尚未与杰瑞完成正式商业设备的完整成套。
  • 所谓“complete set”可能指在测试台或简易框架上进行联测，不一定是最终交付形态。
  • 测试设备可能仅具备：
  1. 简易支架；
  2. 必要仪表和线路；
  3. 功能性连接；
  4. 基础控制和运行验证。
  • 正式交付设备还需完成车装或撬装结构、喷涂、仪表、电气、包装、北美加工和最终测试等工作。

d) 何时能够更清楚地判断项目进度？

  • 访谈时点为10月底，预计11月中旬左右可能出现更明确的交付承诺或排产信号。
  • 由于未来约4个月排产的确定性相对较高，可通过后续是否出现生产计划、工位预留和物料锁定反推项目进度。
  • 建议按月跟踪原型交付、首台排产、物料齐套和北美测试安排。

4. 制造流程、交付周期与加速空间

a) 完整制造和交付流程包括哪些环节？

  • 前期工程阶段
  1. 接单后开展工程设计；
  2. 与客户确认技术要求；
  3. 锁定研发方案和图纸；
  4. 冻结BOM和工程状态；
  5. 确定国内、海外供应商；
  6. 启动物料采购。
  • 制造阶段
  1. 采购机头、发电配套设备、柜体、仪表、底盘及大框架；
  2. 结构件下料、切割、焊接和喷涂；
  3. 电缆试制和线束制作；
  4. 仪表箱设计、组装及电气连接；
  5. 完成底盘和下部结构搭建；
  6. 吊装机头并完成管路、电气和配件组装；
  7. 下线测试、问题整改、拆装及重新喷漆；
  8. 包装、装箱和海运。
  • 海外交付阶段
  1. 在北美完成符合原产地法规要求的部分加工；
  2. 完成最终联调和功能测试；
  3. 运至客户现场；
  4. 安装、调试并投入试生产；
  5. 达到稳定发电及合同约定条件后完成验收。

b) 正常制造周期需要多久？

  • 项目锁定、物料齐套率达到约80%后即可开工。
  • 正常制造周期约为3个月：
  1. 铆焊和涂装约1个月；
  2. 组装约1个月；
  3. 测试约半个月；
  4. 整改、包装、发运确认和订船约8—10天。
  • 加上海外采购、海运、北美测试和现场安装，完整项目周期通常为6—7个月。

c) 是否必须等到机头到货后才能开始生产？

  • 不需要等待机头实物到货后再开工。
  • 当前设计会预留机头安装开口，先完成底盘、框架、管路、电气和其他部件，再将机头吊装落位。
  • 类似于先完成汽车底盘、轮胎、车身、座椅及喷漆，再安装发动机。
  • 如果F泰提前提供明确交付承诺，杰瑞可同步启动排产和前置制造。

d) 从机头实际到货到最终交付，最短需要多久？

  • 正常情况下约需1.5—2个月。
  • 即使极限加速，至少也需要约1.5个月，原因包括：
  1. 机头接口对接；
  2. 管路和电气连接；
  3. 整机测试；
  4. 问题整改；
  5. 拆装和复装；
  6. 喷漆修复；
  7. 包装及发运。
  • 若项目紧急，可采取以下方式提速：
  1. 单工位人员从5人增加至8—10人；
  2. 安排白班、夜班连续作业；
  3. 提升项目优先级；
  4. 将其他项目后移；
  5. 提前储备短交期物料。
  • 随着标准化程度提升，首台可能需要3个月，到第5台时制造周期可能缩短至1.5—2个月。

5. 尾气处理系统与SCR业务

a) SCR尾气处理系统由谁负责？

  • 北美环保要求较高，整套设备需要配套SCR尾气处理系统。
  • SCR由杰瑞负责整体设计和总成，F泰主要配合机头接口和参数适配。
  • 双方可同步开展研发，无需完全等待机头定型后再开始。
  • 尾气处理系统大部分设计具有通用性，主要需要调整：
  1. 接口尺寸；
  2. 压力参数；
  3. 管径和口径；
  4. 尾气处理能力；
  5. 控制和监控逻辑。
  • 完成独立设计后，再与机头进行接口适配和联调。

b) SCR系统的技术和生产难度如何？

  • 工作量较大，但整体技术风险低于机头航改和整机可靠性验证。
  • 产品更适合批量化生产，预计需配套100台以上设备。
  • 杰瑞已单独设立事业部，并租用专门厂房负责尾气处理系统生产。
  • 杰瑞主要完成结构件、管路、外观、喷涂、包装和最终总成；传感器、仪表、电路、电器等核心零部件仍向专业供应商采购。
  • 由于大量采用国产零部件，成本相对可控。

6. 明年交付的核心风险

a) 最关键的风险是什么？

  • 第一，研发及产品可靠性
  1. F泰、川崎等新产品目前仍有部分停留在图纸、原理和验证阶段。
  2. 尚未充分验证机头改造与整套设备的匹配性、稳定性和耐用性。
  3. ETO模式下首台产品必须经历试验、磨合和制造验证。
  4. 若航改原理本身不可行，或出现严重稳定性缺陷、标定问题和耐用性问题，后续将很难通过加班或扩产弥补。
  5. 研发可靠性是能否完成100台目标的决定性变量。
  • 第二，供应链
  1. 即使机头到位，底撬、关键仪表、电气产品和海外定制件也可能无法及时到货。
  2. 部分国际品牌产品需要排队，交付周期较长。
  3. 若图纸冻结和释放过晚，会压缩供应商加工时间，增加抢工和延期风险。
  4. 供应商订单集中、产能扎堆，也可能造成关键部件延期。
  5. 如果指定进口产品无法采购，可能需要进行国产替代，并重新完成选型、测试和设计调整。
  • 第三，人员制造能力
  1. 公司自今年4月起已为该业务储备约200—300人，目前仍在持续招聘。
  2. 新员工需要经过技能培训和实操培养，才能匹配批量生产要求。
  3. 厂房和工位总体充足，后续重点在于人员熟练度和组织管理能力。

b) 供应链问题是否能够解决？

  • 访谈者认为，多数供应链问题最终可通过以下方式解决：
  1. 加价20%—30%抢购物料；
  2. 调整采购优先级；
  3. 更换供应商；
  4. 推动国产替代；
  5. 与客户协商接受替代型号；
  6. 重新进行适配和测试。
  • 因此，供应链更多是成本、交期和执行问题，并非绝对无法解决。
  • 与供应链相比，研发可靠性和产品原理是否可行更为关键。

c) 标准化后产能爬坡是否会更顺利？

  • F泰25MW机型数量较大，具备形成标准化和批量化的条件。
  • 首批产品完成设计、验证和供应商磨合后，后续项目可复用：
  1. 底盘和框架设计；
  2. 管路及电气方案；
  3. 供应商体系；
  4. 生产工艺；
  5. 测试方法；
  6. 质量问题整改经验。
  • 首台制造时间可能达到3个月，但第5台以后有望降至1.5—2个月，量产效率将明显高于传统单件定制模式。

7. 国内制造、北美加工与原产地安排

a) 主要生产环节在哪里完成？

  • 大部分制造工作在国内完成，包括：
  1. 结构件加工；
  2. 钢材、钢管及管路加工；
  3. 底盘和框架制造；
  4. 电气和仪表总成；
  5. 喷涂；
  6. 整机组装；
  7. 部分功能测试。
  • 机头的大部分处理也将在国内完成，不会全部放在美国生产。
  • 国内供应链、人工和钢材成本较低，是项目实现盈利的重要基础。

b) 北美环节主要负责什么？

  • 为满足原产地法规，需要将部分高价值、高技术含量的加工环节放在北美完成。
  • 可能通过在北美增加关键加工工序、专有技术处理和最终组装，提高当地附加值比例。
  • 北美还将完成：
  1. 最终联调；
  2. 功能测试；
  3. 客户现场安装；
  4. 发电验证；
  5. 最终验收。
  • 当地约有18个测试工位，可同时容纳18台设备测试；加拿大基地也可作为补充，目前正在扩建。
  • 海运时间、北美测试时间和现场安装时间均已纳入整体排产计划。

8. 客户验收与商业模式

a) 客户收到设备后是否还需长期验证？

  • 客户验收条件会在合同中明确约定。
  • 设备运抵客户现场后，需要经过安装、调试和稳定发电验证。
  • 只有达到约定的功率、稳定性、排放及运行时间要求后，才会完成最终验收。
  • 通常不会等客户完全测试完首批设备后，才生产和交付剩余设备。
  • 客户订购多少台，公司就按照合同节奏进行交付；若设备出现问题，则由杰瑞负责现场整改和售后服务。

b) 当前有哪些业务交付模式？

  • 设备销售模式
  1. 杰瑞交付整套设备；
  2. 客户自行负责后续运维；
  3. 收入主要来自设备销售和售后备件。
  • 发电服务模式
  1. 杰瑞连人带设备提供服务；
  2. 负责安装、调试、运维和发电保障；
  3. 根据服务周期、发电量或项目合同收费。
  • 两种模式的收费逻辑、利润结构和后续服务责任不同。

9. 柴油发电新业务

a) 柴油发电业务的产品形态是什么？

  • 公司新增柴油发电业务，产品在行业内被称为“小蜜蜂”。
  • 初步方案为8台柴油发电机组成1个撬式发电机组。
  • 单个总成功率估计在1—3MW之间，但访谈者无法确认准确数据，后续仍需核实。
  • 柴油机可能主要来自潍柴等供应商，杰瑞负责成套和总装。

b) 柴油发电业务的排产规模如何？

  • 当前已排产300多台总成设备，并已进入批量生产。
  • 300多台指8台柴油机组成后的撬式总成，而非单台柴油机数量。
  • 尽管定位为燃机业务的补充，但当前排产规模已不小。
  • 单机功率和对应总兆瓦数尚待进一步确认，不宜直接按照3MW/台测算。

c) 柴油发电设备主要应用于哪些场景？

  • 应急或备用发电
  1. 燃机停机检修时提供临时替代；
  2. 应对紧急供电需求；
  3. 在燃机机头短缺时作为补充方案；
  4. 为海外项目提供临时发电服务。
  • 国内设备置换
  1. 用柴油发电设备替换国内油田或分布式能源场景中的现有燃机；
  2. 将被替换出的燃机进行改造；
  3. 改造后再用于其他客户或项目交付。
  • 该模式带有一定二手设备置换和存量资源盘活属性。

10. 订单储备与市场拓展

a) F泰100台之外是否还有新增客户机会？

  3. 首批客户运行反馈；
  4. AI数据中心建设是否持续扩张；

c) 国产机头是否可能成为替代方案？

  • 当前行业内多家商业机头均存在交付延迟，客户又有较强的交付紧迫性。
  • 随着国产轮机技术推进，客户未来可能接受国产替代方案。
  • 国产替代的潜在优势包括：
  1. 缩短交期；
  2. 降低采购成本；
  3. 减少海外供应链风险；
  4. 提高供应保障能力。
  • 但国产方案仍需经过客户认可、适配设计和可靠性验证。
