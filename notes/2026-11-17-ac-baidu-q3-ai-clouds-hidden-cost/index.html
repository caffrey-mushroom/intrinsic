原标题：百度“AI过半”的代价：经营利润砍半、账本重了一截，提前摊开国内公有云的真实底牌

核心摘要

  1. 百度三季度一般业务收入249.7亿元，环比仅少2.1亿元，但分部毛利从112.0亿元降至98.4亿元，毛利率从44.5%跌至39.4%，Non-GAAP经营利润从38.2亿元降至16.9亿元、环比降56%。
  2. 在线营销收入119亿元、同比降22%，AI Cloud Infra收入82亿元、同比增94%，其中GPU云同比增191%、环比增43%，高毛利广告被低毛利算力置换。
  3. 13.6亿元毛利缺口中约7亿多元来自结构置换，折旧摊销单季从23.2亿元增至27.4亿元，最多贡献约三成缺口。
  4. AI云利润率改善可能受昆仑芯外售抬升：按55%外售毛利率测算，昆仑芯外部确认8亿、13亿、18亿元时，纯GPU云毛利率分别约为17%、11%、3%。
  5. “其他净额”从亏0.9亿元转为收益11.0亿元，使集团Non-GAAP经营利润环比降55%，而Non-GAAP归母净利润仅降7%，容易误读主业下滑幅度。
  6. 租赁使用权资产从年初92.9亿元增至252.7亿元、增幅172%，银行借款从约257.6亿元增至约509.5亿元，不含爱奇艺的自由现金流Q2、Q3合计约负130亿元。
  7. 9月底应收账款136.3亿元已超过预收及递延收入134.8亿元，商业模式正从“先收钱后服务”转向“先投入后收款”，单季折旧已达一般业务经营利润的1.6倍。
  8. 测算显示在25%降本率下，昆仑芯M100需替代约43%外采推理负载才能抵消单季折旧增量，改善报表大概率要到2027年下半年以后。

摘要

  1. 百度AI云利润率改善与集团利润腰斩如何同时成立；
  2. 芯片外售、债券收益等因素如何影响利润观感；
  3. 租赁扩表、借款与应收上升对现金流的影响；
  4. M100替代比例与国内云厂的映射与跟踪。

百度三季度交出了一份很“分裂”的成绩单：管理层说AI云的利润和利润率同比、环比都在提高，AI业务收入已占一般业务的一半以上；可同一张报表上，一般业务的经营利润一个季度少了一半多。两件事同时成立，说明问题不在云本身，而在这笔“用云换搜索”的账怎么算。本文试图把这笔账算清楚。

一、利润去哪了：问题不在云，而在“换”的代价

先把一个常见误读排除掉。如果AI云在亏钱，那么云收入涨得越快，利润就该掉得越狠，这是最直接的解释。但电话会上管理层明确说，AI Cloud Infra的利润和利润率同比、环比双升，GPU云、昆仑芯、MaaS三项合计已占这块收入的多数。也就是说，“云拖累利润”这个解释，和公司自己的说法正面冲突。既然云没有亏，那利润一定是从别处漏掉的。所以本文要回答的核心问题是：云的增长，能不能补上搜索留下的利润缺口？

百度11月16日披露的三季报给出的答案是：至少这一季补不上。数据很清楚：一般业务收入249.7亿元，环比只少了2.1亿元，几乎没动；但分部毛利从112.0亿元降到98.4亿元，一个季度少了13.6亿元，毛利率从44.5%掉到39.4%，跌破了40%。一般业务口径的Non-GAAP经营利润从38.2亿元降到16.9亿元，环比少了56%。收入几乎不变，毛利却大幅下滑，这说明变的不是“卖了多少”，而是“卖的是什么”。

收入结构的变化印证了这一点。在线营销收入119亿元，同比少22%，占一般业务的比重从二季度的52%再次跌回48%（一季度也是48%）；AI Cloud Infra收入82亿元，同比增94%，其中GPU云同比增191%、环比增43%。一边是毛利率很高的搜索广告在缩，一边是毛利率低得多的算力业务在涨，两者加总收入差不多，毛利自然差很多。

我们可以把这13.6亿元的毛利缺口粗略拆成几块，看看各自有多大。第一块是结构置换。广告环比少了12亿元，搜索广告的服务器和研发大多是固定成本，多卖或少卖一块钱，毛利变化接近这一块钱本身，本文按75%的边际毛利率估算，大约少了9亿元毛利；AI Cloud Infra环比多了9亿元收入，按20%左右的毛利率算，只补回约1.8亿元。仅这一进一出，就差了7亿多元。

第二块是折旧，这也是市场讨论最少的一块。EBITDA调节表中，一般业务的折旧摊销（不含并购形成的无形资产摊销）从23.2亿元增至27.4亿元，单季多了4.2亿元。公告没有披露其中多少计入营业成本，因此它对毛利缺口的贡献最多约三成，应视为上限。剩下约2.3亿元是模型残差，可能涉及公告点名的流量获取成本（TAC）同比上升、营业成本中的股权激励等，但现有披露不足以把它准确分配到具体项目。

拆下来，可以看到：一半左右的缺口来自业务结构换挡，这是转型的必然代价；另有相当一部分来自前期资本开支开始转化为折旧，这部分会随着算力规模扩大持续存在。前者会随着广告企稳而收敛，后者不会自动消失，必须靠更高的利用率或更低的单位算力成本去消化。这是后文要讨论的重点。

二、云的利润率为什么在涨：芯片外售和债券收益帮了忙

既然管理层说云的利润率在提高，就有必要追问一句：是谁在提高？AI Cloud Infra并不是单一业务，它把GPU云租赁、昆仑芯芯片销售和MaaS模型服务装在了一起。这三样东西的毛利率差别很大，放在一个口袋里，整体利润率改善可能来自任何一块。

关键在于昆仑芯的会计处理。昆仑芯是百度并表的非全资子公司，它卖给外部客户的芯片和整机，收入和毛利会全额进入AI Cloud Infra；卖给百度自己的部分，则在合并报表里互相抵消。所以，昆仑芯对外卖得越多，云的表观毛利率就越高，但这和GPU租赁本身赚不赚钱没有关系。国产加速卡的外售毛利有多高，可以参照同业：海光信息、寒武纪2025年的公司综合毛利率分别为57.8%和55.2%。按这个水平，昆仑芯一个季度只要确认十几亿元外部硬件收入，就能把整个AI Cloud Infra的毛利率抬高好几个百分点。

本文统一按55%的外售毛利率、36亿元MaaS及其他收入（毛利率20%）、AI Cloud Infra表观毛利率22%做了三档情景：昆仑芯外部确认8亿、13亿、18亿元时，剩下的纯GPU云毛利率分别约为17%、11%、3%。需要说明，这是敏感性测算，公司从未拆分披露。它要说明的不是“GPU云一定只有个位数毛利”，而是在混装口径下，外界无法分清“芯片卖得好”和“租赁赚得好”。这两件事对估值的意义完全不同：前者是一次性的硬件销售，后者才是可以持续滚动的云收入。

利润表下方还有两层缓冲，同样会让主业看起来比实际好。一是“其他净额”从上季亏损0.9亿元转为收益11.0亿元，公告解释主要是交易性债务投资的公允价值由亏转盈，而按百度的Non-GAAP定义，这部分收益不会被剔除。二是与二季报相比，三季报的Non-GAAP定义新增了“行政处罚”相关的排除条款，同时权益法调节项从0.82亿元增至4.91亿元（公告没有说明这一增幅中多少与处罚有关）。两者叠加的结果是：集团口径Non-GAAP经营利润环比降55%（从37.9亿元到17.1亿元），而Non-GAAP归母净利润只降了7%（从25.7亿元到24.0亿元）。如果只看净利润，很容易把一次主业利润的大幅下滑，误读成一次温和回调。

三、资本开支少了，钱却没少花：租赁、借款和应收都在涨

看完利润表，再看资产负债表，因为算力生意的成本，很大一部分先体现为资产，后体现为折旧。管理层把三季度资本开支下降归因于更好地利用现有算力。现金流量表确实如此：不含爱奇艺的资本开支从113.7亿元降到73.1亿元。如果只看这一个数，会得出“扩张放缓、现金压力缓解”的结论。

但资产负债表给出的是另一幅画面。租赁使用权资产从年初的92.9亿元涨到252.7亿元，九个月多了约160亿元，增幅172%；同期租赁负债合计只从83.9亿元涨到94.5亿元。资产多了160亿元，对应的负债只多了10亿元出头，说明大部分新增租赁资产不是靠“先用后付”形成的，而很可能是提前付了钱，即预付租赁或其他形式的前期支付。公告没有给出拆分，这一点还要等附注确认。但方向是清楚的：资本开支科目下的支出降了，资本却通过租赁这条路继续在投入。三季报同时修改了Adjusted EBITDA的定义，开始加回融资租赁使用权资产的摊销，这也说明这类资产已经大到需要单独处理。

借款也在同步上升。把短期借款、一年内到期的长期借款和非流动长期借款三项加总，银行借款从年初约257.6亿元增至9月底约509.5亿元，净增约252亿元；同期百度发行的应付票据在减少。按CFO在电话会上的口径，百度期末净现金约1,330亿元（按资产负债表扣除全部借款、票据和可转债粗算约1,290亿元，口径不同）。一边账上有大额净现金，一边大幅增加银行借款，一种可能的解释是现金和投资不一定在需要用钱的境内主体手里，即境内外资金错配，但公司并没有说明原因。对投资者来说，结论是“净现金”这个数字不能直接当成可随时调用的弹药，打折时要更保守一些。

营运资金的变化更能说明商业模式在变。9月底应收账款净额136.3亿元，已超过客户预收及递延收入合计的134.8亿元。过去的搜索广告是“先收钱、后服务”的生意，客户预付款本身就是一笔无息资金；现在越来越像“先投入、后收款”的生意。管理层说GPU云预付客户在增多，按合同价值计的前三大客户续约时都签了多年期合同，其中一家期限是上一轮的6倍。但三季度销售及管理费用环比涨了19%，公告给出的原因恰恰是预期信用损失增加。客户合同越签越长、坏账准备却在上升，两件事之间的张力，需要年报附注来解答。

最后落到现金流上。集团经营现金流为正28亿元，管理层称已连续五个季度为正；但不含爱奇艺的自由现金流二季度为负82.7亿元、三季度为负46.9亿元，两季合计约负130亿元。这不是偿债危机，而是用存量现金补贴转型，但补贴总有边界。单季2 7.4亿元的折旧摊销，已是一般业务Non-GAAP经营利润的1.6倍。要注意，折旧已经计入经营成本，并不是还有一块缺口没扣；它的意义在于，百度的利润弹性正在从“流量×单价”变成“利用率×折旧年限”。笔者在5月10日报告中提出，算力租赁应从PS/EBITDA转向PB/ROE估值；百度这一季的报表，正在把自己推向这把尺子。

四、M100能不能扭转局面：至少要替代四成外采卡

前面的分析把问题收窄到了一点：折旧不会自己消失，要让云的增长真正补上搜索的缺口，必须把单位算力成本降下来。百度手里最直接的工具是自研芯片。三季报确认，昆仑芯M100面向大规模推理，预计2026年底具备量产条件；按此前公布的路线图，下一代M300计划2027年推出。那么，M100要用到什么程度，才能在账上看到效果？

本文用一个简单的框架来算：单季节省额 = 可替代的推理成本 × 替代比例 × 综合降本率，然后拿它和单季折旧增量（本季约4.2亿元）比较。可替代的推理成本按AI Cloud Infra收入×(1−22%)×60%的推理占比估算，约38.4亿元/季。降本率参考行业调研给出的区间：在适配良好的推理场景里，自研芯片的综合成本比外采低20%–30%。

结果是：降本率25%时，M100要替代约43%的外采推理负载，节省额才追得上一个季度的折旧增量；降本率只有20%时，比例要升到约54%；即便降本30%，也要约36%。换句话说，M100不是“能量产就行”，而是要在百度自己的推理负载里占到四成左右，才算真正改善利润。这道门槛不低，原因也很具体：自研芯片在放量初期，往往还要承担利用率爬坡、软硬件适配和研发折旧的成本，降本优势通常先在标准化推理场景出现，再逐步扩展。所以M100对报表的改善，更可能在2027年下半年以后显现，而不是2027年一季度。

还有一个容易被忽视的变量：关联定价。昆仑芯已秘密递表港交所。上市后，它卖给百度云的价格定得越高，昆仑芯的利润越好看，百度云的毛利就越薄，反过来也一样。母子公司之间天然存在一个利润跷跷板，昆仑芯上市文件中披露的关联交易定价，因此会成为观察百度云真实成本的一个窗口。这与5月27日报告中的思路一致：决定云厂利润的，不是芯片有没有做出来，而是自研芯片在自家负载中的渗透率。

至于Token Exchange，试运行首月入驻供应资源超100个、日均Token调用超7,000亿，方向上有助于消化闲置算力，提高利用率。但它目前没有收入口径披露，对利润的贡献无法量化，更适合当作一个期权，而不宜放进基准盈利预测。

五、这套账对其他云厂意味着什么，接下来该盯哪些数

百度三季报的价值，不只在于它自己的问题，还在于它提供了一套可复用的检查方法。总结下来是四个问题：1）原来的现金牛还剩多少增速？2）租赁和预付款是不是在悄悄扩表？3）折旧和经营利润的比值是多少？4）应收和预收谁更大？用这四把尺子去量其他云厂，差异就很清楚了。

阿里巴巴手里有平头哥，也在大规模新建机房，但从行业调研看，春季调价后客户实际账单只涨了8%–15%，说明价格并不能把上游成本完全转嫁出去；自研芯片省下来的钱，最终有多少留在阿里云的利润里、有多少以折扣形式让给客户，是判断其利润率的关键。腾讯方面，一份调研摘要提到其2026年AI收入近八成来自GPU租赁、MaaS接近成本线定价（未经公司证实，只作线索）；如果属实，腾讯云面对的也是“租赁化”带来的利润率考题，区别在于它背后的游戏和广告现金牛比搜索稳得多，补贴能力更强。字节跳动的火山引擎则优先满足内部负载，对外云服务的回报和内部模型的降本效果是两本账，不能混为一谈。芯片一侧，海光信息、寒武纪站在外售高毛利的一端，云厂在价格上让出的利润，某种程度上正是它们毛利的来源。

回到百度，接下来几个季度值得盯的信号有六个：折旧摊销与Non-GAAP经营利润之比能否回到1倍以下；租赁使用权资产的季度增量是否放缓；预期信用损失是否继续上升；M100的量产进度和自用部署规模；昆仑芯上市文件中的关联交易定价；以及公司是否首次单独披露AI云的利润率。这些指标的方向决定了答案：如果到2027年上半年，折旧比继续上行，AI云的利润率口径依然模糊，市场给百度的估值参照会从“AI平台”逐步滑向“算力租赁商”；反过来，只要其中两三个指标出现拐点，今天的利润压力就可能变成估值修复的空间。
