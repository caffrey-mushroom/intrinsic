专家访谈纪要

1. 网络安全采购与预算趋势

a) 本季度整体网络安全采购增长如何，增速是否加快？

  • 本季度网络安全支出明显高于其他季度，整体同比增长约 30%，较上季度进一步加速。
  • 银行、金融保险、石油天然气等行业增长最为突出，部分大型银行和能源企业对网络安全预算已基本“不设上限”。
  • 本季度客户围绕网络安全开展了大量采购和项目活动，整体需求趋势仍在上行。
  • 预计这一增长趋势将在明年延续，并逐步扩展至更多行业。
  • 对明年的初步预测是网络安全相关支出平均增长约 20%，年中重新评估后可能上调至 25%—30%。

b) 现有客户续约和增购发生了哪些变化，增长由什么驱动？

  • 现有客户续约及增购需求明显增强，主要驱动因素包括：
  1. 网络攻击数量大幅增加，部分组织遭受的攻击量较正常水平增长 100%—200%。
  2. 攻击持续时间更长、复杂度更高，AI驱动型攻击显著增加。
  3. 大多数超大型组织都曾以某种形式遭遇安全漏洞，本季度相关事件尤其集中。
  4. 客户需要同时强化身份、终端、云、应用及安全运营等多个层面的防护。
  • 尽管今年整体预算环境较为严峻，网络安全支出基本未受影响，仍然维持增长。
  • 在所观察的客户群体中，没有客户减少网络安全支出。

c) 网络安全支出占IT预算的比例发生了什么变化？

  • 大多数组织过去的网络安全支出通常约占IT预算的 12%，目前已上升至约 20%。
  • 这一提升覆盖全球客户和大型企业，其中较大一部分增量发生在本季度，部分发生在上一季度。
  • 明年预计网络安全支出占IT预算的比例至少维持在 20%左右，实际可能进一步达到 25%—30%。
  • AI被默认捆绑进产品及SKU，是预算持续提升的重要原因：
  1. 客户购买新SKU或升级时，通常无法剔除AI功能。
  2. 产品嵌入AI后，平均价格可能上涨约 20%。
  3. 企业系统中存在多个供应商，每家供应商都在加入AI，形成叠加式预算压力。

d) 安全预算增加是新增预算，还是挤占其他IT项目？

  • 网络安全预算增长会挤压其他IT项目，尤其是终端用户计算及传统软件支出。
  • 企业可能采取以下措施释放预算：
  1. 不采购AI PC，继续购买低端笔记本电脑。
  2. 降低设备配置或推迟设备更新周期。
  3. 压缩Adobe、Salesforce、Oracle、IBM等传统软件供应商的合同成本。
  4. 优化许可证数量，减少闲置或低使用率许可证。
  • 总体判断是网络安全预算将确定性增加，而非安全类软件及终端设备预算将承担更多成本压力。

2. 网络攻击变化与重点安全功能

a) 如何理解近期频繁发生的攻击和系统宕机事件？

  • 目前难以对单个事件作统一归因，但AI正在推动攻击数量和攻击复杂度快速上升。
  • 部分组织面临的攻击数量较通常水平增加 100%甚至200%。
  • 安全建设已不再局限于单一环节，而是转向全面审视：
  1. 身份安全。
  2. 终端检测与响应（EDR）。
  3. 多云环境下的云安全。
  4. 应用安全。
  5. 安全运营与事件响应。
  • 近期多起安全事件使企业更加重视端到端安全能力，而非只采购单点产品。

b) 本季度新增预算主要流向哪些安全功能？

  • 本季度最受关注的三大方向为：
  1. 身份安全：今年最核心的预算投入方向。
  2. 云安全：大型企业普遍采用多云架构，相关需求强劲。
  3. 电子邮件安全：大量攻击和数据泄露通过电子邮件发生。
  • 终端安全同样获得大量支出，CrowdStrike、Microsoft等厂商持续受益。
  • Palo Alto的Cortex等安全运营产品过去两年取得良好进展。
  • 如果只选一个最重要的细分领域，专家认为是 身份安全。

c) 哪些安全领域可能面临产品形态颠覆？

  • 传统漏洞扫描和漏洞管理产品面临明显冲击。
  • Qualys、Rapid7等厂商主要基于已知漏洞进行扫描，而AI原生产品能够：
  1. 自动开展渗透测试。
  2. 通过多智能体发现未知漏洞。
  3. 持续学习并适应复杂环境。
  4. 在多云和动态架构中提高漏洞发现效率。
  • Qualys和Rapid7目前增长已经偏低，说明冲击已经发生，未来可能进一步加剧。
  • 渗透测试、漏洞搜索与漏洞管理将是AI原生安全厂商最有可能实现产品颠覆的领域。

3. 客户采购、供应商整合与合同周期

a) 当前是否存在提前采购或前置采购？

  • 部分大型银行已经开始提前采购并作出采购承诺。
  • 但网络安全采购无法快速完成，客户需要从整体环境出发评估产品、供应商和部署方式。
  • 当前更明显的趋势不是简单前置采购，而是 供应商整合：
  1. 客户不再希望保留10家、12家甚至20家安全供应商。
  2. 企业希望减少供应商数量，以降低集成、运维和管理成本。
  3. 平台型厂商因此更容易获得新增预算。
  • Palo Alto、CrowdStrike和Microsoft是供应商整合趋势下的主要受益者。

b) 新客户从预算分配到签约部署的周期有何变化？

  • 新客户采用周期略有延长，主要原因包括：
  1. 需要从整体环境角度设计完整解决方案。
  2. 多年期合同需要更长的内部审批流程。
  3. 客户更加关注治理、合规、集成和投资回报。
  4. 合同沟通和决策方式较过去更加复杂。
  • 周期虽然有所延长，但尚未显著影响客户最终决策和产品采用。

c) 网络安全合同期限有何变化？

  • 客户正逐步减少一年期等短期合同。
  • 预计明年，大多数网络安全供应商的合同期限至少为 3年。
  • 部分企业会从 5年期承诺 的角度评估供应商，因此安全采购正在成为长期战略决策。
  • 客户选择供应商时主要考虑：
  1. 产品组合广度。
  2. 与现有环境的集成便利性。
  3. 产品部署和迁移难度。
  4. AI产品路线图。
  5. 成本效率及投资回报。
  6. 治理和合规适配能力。

d) 客户如何衡量AI安全投入的投资回报？

  • 企业主要关注AI能否带来以下回报：
  1. 减少人工干预。
  2. 降低人员和资源投入。
  3. 缩短安全环境管理时间。
  4. 减少攻击发生次数。
  5. 加快攻击识别和响应。
  6. 自动识别新的攻击行为。
  7. 实现策略自动化。
  • 目前AI能力无法立即全面投入使用，主要约束是治理和合规框架尚未完善。
  • 银行、石油天然气行业预算和采用进度相对领先，其他行业本年度的AI安全专项预算仍然有限。

4. AI安全应用、Token消耗与治理限制

a) AI安全场景未来是否会消耗大量Token？

  • 专家认同未来约 20%的Token可能用于安全相关领域 的判断。
  • 自动化渗透测试、AI SOC、自动代码扫描、漏洞发现、AI应用红队测试及智能体安全运营均会产生大量Token需求。
  • 相关合同第一年已经出现约 20%的使用量增长，符合初期预期。
  • 第二年增长预计更快，原因包括：
  1. 客户对AI工具更加熟悉。
  2. AI使用意愿提升。
  3. 更多安全智能体进入生产环境。
  4. 合同进入第二年后，客户使用场景进一步扩展。

b) 一次企业级自动化渗透测试大约消耗多少Token？

  • 以一家世界500强企业为例，一次自动化渗透测试平均可能消耗 500万—1,000万枚Token，复杂情况下可能更高。
  • 实际消耗取决于：
  1. 企业环境复杂度。
  2. 智能体执行任务的数量和难度。
  3. 是否涉及多云、多系统及多应用。
  4. 智能体在环境中的行动范围和执行深度。
  • 目前难以形成统一的金额标准，任务越复杂、执行足迹越广，Token消耗越高。

c) AI安全采用的主要障碍是什么？

  • 当前最大的障碍不是客户是否愿意使用AI，而是如何满足治理和合规要求。
  • 大型全球企业需要逐项审查数据处理方式、部署方案和法律条款。
  • 不同地区采用节奏存在差异：
  1. 美国和北美采用速度相对较快。
  2. 欧洲因不同国家监管规则差异较大，采用速度相对较慢。
  3. 全球性企业需要同时满足多个司法辖区要求。
  • 治理和合规框架正在改善并逐步放宽，明年AI采用速度预计明显加快。

5. 安全产品价格与硬件成本趋势

a) 本季度网络安全产品价格发生了哪些变化？

  • 网络安全产品整体平均价格上涨约 10%—12%。
  • 大型全球客户因签订大额合同，实际涨幅通常约为 6%—8%。
  • 软件价格涨幅相对温和，硬件价格上涨更明显。

b) 哪些产品涨价最明显？

  • 防火墙等安全硬件的典型涨幅约为 12%—20%。
  • Palo Alto及部分硬件供应商均出现明显提价。
  • Cisco涨幅尤其突出，部分硬件成本上涨约 20%—40%。
  • 明年服务器、存储和安全硬件成本预计仍将上涨，不太可能出现明显下降。

6. 核心安全厂商竞争格局

a) 哪些厂商本季度表现最好？

  • Palo Alto排名第一，明显领先于其他渠道厂商。
  • 主要优势包括：
  1. 过去两年持续推进平台化战略。
  2. 客户投诉为零，稳定性和客户信任度较高。
  3. 对大型客户采用全球定价机制，有利于巩固全球客户关系。
  4. 身份安全领域的收购有助于客户进一步整合支出。
  5. 平台化、自动化和AI能力有利于追加销售与交叉销售。
  • CrowdStrike排名第二，与Palo Alto较为接近。
  • 主要优势包括：
  1. Flex消费模式允许客户按需使用产品。
  2. 支持客户在逐步退出原供应商时灵活扩大CrowdStrike使用范围。
  3. 客户支持能力被认为是行业最佳之一。
  4. 即使经历宕机事件，也没有客户因此离开。
  • 两家公司均持续实现同比增长，是当前客户群中表现最出色的两家主要供应商。

b) Microsoft、Fortinet和Zscaler的表现如何？

  • Microsoft
  1. 依托EA协议中的支出承诺持续增长并获得市场份额。
  2. 大型企业已有庞大的Microsoft环境，追加采购较为便利。
  3. E5、E7初期价格看似较低，但续约时成本较高。
  4. 客户虽然对成本保持警惕，但因已有支出承诺，仍会继续采购。
  • Fortinet
  1. 今年表现较好，尤其是防火墙业务。
  2. 其市场信息逐渐获得更多客户认可。
  3. 在现有客户群中具备较强竞争力。
  • Zscaler
  1. 同比增长约 20%。
  2. ZIA和ZPA等产品表现良好，ZTNA仍是主要收入来源。
  3. 当前增长主要来自现有客户扩容。
  4. 正从ZTNA厂商向平台化和AI安全方案拓展，但转型需要时间。
  5. 明年有望依托现有客户基础推广更多新产品。

c) Rubrik、Okta、Cloudflare和Checkpoint表现如何？

  • Rubrik
  1. 同比增速约 30%。
  2. 将安全理念融入备份、恢复和韧性方案。
  3. 身份备份与恢复尤其受到客户关注。
  • Okta
  1. 同比增速约 20%。
  2. 在中端市场和中小型企业中表现较好。
  3. 正投入大量资源进入大型企业和全球客户市场。
  4. 在顶级全球客户市场面临SailPoint的强势竞争。
  5. SailPoint在身份治理与合规领域占据主导地位，大客户切换意愿较低。
  • Cloudflare
  1. 增速约 18%—20%。
  2. 在渠道中持续取得进展，新增客户约 20—25家。
  3. 在SASE领域对Zscaler形成明显挑战，尤其具备价格优势。
  • Checkpoint
  1. 增速仅约 5%，明显低于预期。
  2. 过去两三年增速长期维持在5%左右，最高可能约6%。
  3. 市场定位和市场进入策略不够清晰。
  4. 新客户获取几乎不存在，正在失去市场份额。

d) 云原生安全和第三方专业安全产品如何竞争？

  • 客户不会完全依赖云原生或大型平台厂商，仍会采购第三方专业产品。
  • 平台厂商的优势在于：
  1. 产品组合更广。
  2. 集成便利。
  3. 能够帮助客户整合供应商。
  4. 与企业既有环境和合同体系衔接更容易。
  • 第三方专业厂商的优势在于：
  1. 聚焦一至两个细分领域。
  2. 能提供平台厂商不具备的独特能力。
  3. 在特定安全场景下产品深度更强。
  • 最终选择取决于产品广度、集成难度、AI路线图及投资回报，而非简单二选一。

7. AI模型厂商与AI原生安全公司的影响

a) OpenAI、Anthropic未来将在安全市场扮演什么角色？

  • OpenAI、Anthropic可能承接部分企业安全预算，并对市场产生长期颠覆性影响。
  • 两家公司正在建设渠道体系，并开始通过渠道销售产品。
  • 当前采用规模仍较小，主要原因包括：
  1. 企业担忧数据如何处理。
  2. 部署方式尚不清晰。
  3. 产品尚未在大型企业环境中得到充分验证。
  4. 客户信任需要时间建立。
  • 未来一年左右，它们更可能作为现有安全环境的补充，而非直接取代Palo Alto或CrowdStrike。
  • 当前主要能力偏向AI咨询和建议，例如：
  1. 提示企业如何收紧安全策略。
  2. 建议应调整或修正哪些配置。
  3. 协助识别潜在风险。
  • 由于缺乏完整安全产品，最终执行仍需要实际的软件供应商完成。

b) AI原生安全公司相较传统厂商有哪些优势？

  • AI原生公司在渗透测试领域尤其具备发展潜力。
  • 主要优势包括：
  1. AI能够持续学习并适应新环境。
  2. 多智能体可以自动完成复杂测试。
  3. 能发现传统扫描工具无法识别的新漏洞。
  4. 整体成本效率更高。
  5. 定价更具竞争力。
  • 明年及后年，AI原生安全公司预计将继续扩张，并对部分传统供应商形成挑战。
  • Anthropic等模型厂商可能在漏洞发现、渗透测试等领域获得更多收益。

c) AI原生公司能否挑战大型平台厂商？

  • 在渗透测试、漏洞扫描和漏洞管理等单点领域，AI原生公司具备较强颠覆能力。
  • 对Palo Alto、CrowdStrike等大型平台厂商形成全面挑战仍然困难，原因包括：
  1. 大型平台厂商掌握大量客户环境数据。
  2. 对企业安全环境理解更加深入。
  3. 产品组合和执行能力更完整。
  4. 客户信任、渠道和服务体系更加成熟。
  • 因此，AI原生公司的短期机会主要集中于细分领域，而不是全面替代大型安全平台。

8. 政府、公共部门与监管趋势

a) 政府和公共部门是否会增加网络安全预算？

  • 公共部门网络安全预算预计将继续增加。
  • 英国正在对网络安全进行重大投资，医疗及其他公共部门均将其列为重点。
  • 对政府和大型组织而言，采用AI已不是“是否采用”的问题，而是“如何合规采用”的问题。
  • 如果不使用AI，组织可能在防御效率、攻击识别和风险控制方面明显落后。

b) 监管将如何影响AI和安全采购？

  • AI监管重点集中在：
  1. 数据处理方式。
  2. 数据所在地及跨境流动。
  3. 模型和产品的部署方式。
  4. 全球不同地区的合规要求。
  • 大型厂商通常不会为单个客户修改AI相关条款，客户往往只能接受标准条款，否则合同可能无法签署。
  • 今年由于预算有限及合规审查复杂，AI采用仍面临挑战；明年随着治理框架完善，采用速度预计明显加快。

c) 如何看待Palo Alto收购后训练相关企业？

  • 该收购整体具有积极意义，有助于：
  1. 提升客户对AI的理解和信心。
  2. 帮助客户看清AI投资回报。
  3. 支持Palo Alto追加销售和交叉销售。
  4. 让客户更好地理解产品集成方式和AI应用价值。
  • 目前判断实际效果仍为时尚早，相关能力尚未完全纳入平台。
  • CyberArk等此前能力也尚未完成全面整合，未来仍需观察具体落地数据。

9. 非安全软件、硬件与整体IT支出变化

a) 网络安全之外的软件需求趋势如何？

  • 与网络安全支出加速相反，企业正在普遍寻求降低传统软件成本。
  • 重点压缩对象包括Adobe、Salesforce、VMware、Oracle、IBM等高支出供应商。
  • AI可以帮助客户分析：
  1. 实际需要多少许可证。
  2. 哪些许可证已被使用。
  3. 哪些许可证处于闲置状态。
  4. 哪些产品可以被低成本替代方案取代。
  • 明年企业软件支出将更加集中，预算衡量和许可证管理也会更加精细。

b) Adobe、Salesforce和VMware分别面临什么情况？

  • Adobe
  1. 客户普遍希望降低成本。
  2. 仅使用Sign或Acrobat的客户可能转向Canva、Foxit等替代产品。
  3. 替代后支出可能下降 40%—50%。
  • Salesforce
  1. 本年度同比增长约 10%。
  2. 墾长部分来自较大幅度提价。
  3. 因缺少成熟替代方案，客户较难完全退出。
  4. 客户会通过优化许可证数量来控制成本。
  • VMware
  1. 高昂成本推动客户寻找替代方案。
  2. 企业摆脱VMware的意愿正在增强。

c) 明年软硬件支出的整体结构将如何变化？

  • 网络安全将成为企业投入最多的领域之一。
  • 传统软件供应商，尤其是客户支出最集中的厂商，可能面临明显预算压力。
  • 硬件成本将继续上升，服务器、存储、安全设备等价格预计不会下降。
  • 企业为满足硬件和网络安全投入，将进一步压缩非核心软件、终端设备和低效许可证支出。
