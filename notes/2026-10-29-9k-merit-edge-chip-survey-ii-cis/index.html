1. CIS市场空间与应用结构

1. CIS下游主要应用场景如何划分？

  • CIS下游应用主要分为四大板块，与公司现阶段业务方向基本一致：
  1. 手机消费电子：目前最大的基本盘，市场规模排名第一。
  2. 安防：包括传统监控、影像市场，以及智能家居、AIoT等广义安防应用。
  3. 汽车：主要指与OEM直接合作的前装市场，目前体量已与广义安防市场接近。
  4. 工业及机器视觉：当前发展最快的方向，核心产品多采用全局快门（Global Shutter）架构。
  • 工业及机器视觉可进一步拆分为：
  1. 工业级视觉：包括2D工业相机、3D相机，以及PCB、3C电子、光伏、锂电、半导体设备、汽车制造和机械臂抓取等检测场景。
  2. 消费级机器视觉：包括无人机、具身机器人、四足机器人、轮足机器人、扫地机器人及机器人数据采集设备等。
  • 除四大板块外，医疗内窥镜、AR眼镜、军工、科研等领域也存在需求，但目前体量较小，尚未形成独立的大市场层级。
  • 国内具备一定规模的CIS企业基本都聚焦手机、安防、汽车和工业四类市场，尚不存在只专注医疗或AR眼镜应用的大型CIS厂商。

2. 全球CIS市场规模及各应用板块占比如何？

  • 以2025年前后为时间节点，全球CIS市场规模约为200亿至220亿美元，2025年与2026年的总体市场容量差距不大。
  • 按营收口径大致拆分：
  1. 手机消费类：约占60%至70%，仍是最大市场。
  2. 安防：约占15%。
  3. 汽车：约占15%，与安防体量基本接近。
  4. 工业：约占10%，目前仍处于发展初期。
  5. 医疗、眼镜及其他应用：整体占比较低，主要为个位数。
  • 上述比例属于行业大致估算，不同统计口径之间可能存在重叠或偏差。
  • 按出货量计算，手机占比会高于按营收计算的占比，主要因为单部手机通常搭载多颗CIS。

3. 中国市场在全球CIS市场中占多大比重？

  • 中国市场涵盖手机、汽车、安防、工业及其他领域，整体约占全球市场的40%至50%以内，通常低于50%。
  • 汽车和安防领域的中国市场占比相对更高，主要原因包括：
  1. 国内新能源汽车渗透率和产量较高。
  2. 国内单车平均摄像头搭载量较高。
  3. 国内安防摄像头需求量明显高于海外市场。
  • 从2025年至2026年的结构变化看，国内汽车和工业应用的营收占比将继续上升。

4. CIS行业未来整体增速如何，是否主要体现为结构变化？

  • 从2023年至2026年的行业表现看，CIS整体复合增速大致为5%至10%。
  • 个别年份或季度可能受缺货、涨价、新应用放量等因素影响而出现更高增速，但长期仍以中低个位数至低双位数增长为主。
  • 未来行业机会更多来自内部结构变化，而非整体市场指数级扩张：
  1. 手机市场进入成熟期，出货量、单机搭载数量和产品规格均接近瓶颈。
  2. 汽车受智驾渗透和像素升级推动，仍有数量及价值量提升空间。
  3. 工业机器视觉受机器人、工业4.0、国产设备和AI应用推动，增长速度较快。
  4. 安防及AIoT仍可通过智能家居和新终端延伸应用边界。
  • 手机、智能手机、功能机、笔记本电脑等主体消费电子设备增长较慢，但运动相机、全景相机等延伸品类仍存在一定机会。

2. 机器人、数采与端侧AI市场

1. 机器人及数据采集市场是否会迎来爆发式增长？

  • 短期内，机器人及数据采集市场很难复制2021年至2022年智能手机市场在销量和价格上的指数级增长。
  • 无论工业板块如何发展，在未来1至3年甚至3至5年内，其总体体量都很难达到手机消费电子板块的规模。
  • 该市场的主要优势不是短期爆发性，而是具备较强的持续增长能力，具有“长坡厚雪”的特征。
  • 机器视觉应用可以持续向多个领域延伸：
  1. 工业相机和3D相机。
  2. PCB及3C电子检测。
  3. 光伏、锂电和面板检测。
  4. 国产半导体检测设备。
  5. 汽车生产制造检测。
  6. 机械臂抓取和定位。
  • 手机、安防和部分汽车CIS的国产化率已经相对较高，而工业机器视觉仍主要由海外厂商主导，因此国产替代空间更大。

2. 传统数采和机器人数采有何区别？

  • 数采市场可分为两个阶段或两种商业模式：
  1. 传统工业数采：通过工业相机或3D相机，在固定场景中大量采集被检测物图片，建立数据库并进行模型学习，最终形成算法和检测方法。
  2. 端侧及机器人数采：随着具身智能和海外AI企业加大投入，数据采集逐步从传统工业场景拓展至消费级、端侧和机器人场景，为机器人模型和数据库建设提供素材。
  • 新一代机器人数采与传统工业数采并非完全分离，而是在应用场景和设备形态上的延伸。
  • 奥比等模组厂商已开始提供数采设备和整体方案。
  • 从市场容量看，新型机器人数采市场未必能够超过传统工业数采市场。
  • 机器人数采预计存在1至2年的阶段性行情，后续持续性仍需观察终端应用和商业模式落地情况。

3. 机器人等2C端侧产品能否复制智能手机的换机周期？

  • 较难与智能手机进行类比，主要存在三方面差异：
  1. 用户覆盖范围不同：手机几乎下沉至每一个消费者，而机器人或数据采集设备的用户群体明显更小。
  2. 终端数量不同：单套机器人或数采设备可使用3至10颗CIS，单套用量可能高于手机，但终端设备总量很难达到手机规模。
  3. 产品规格不同：机器人素材采集目前主流需求为1080P，远低于手机主摄普遍采用的5000万像素及最高2亿像素。
  • 手机通常搭载3至4颗传感器，迭代速度快；机器人整套方案即使包含头戴设备、灵巧手等模块，最多约使用10颗传感器。
  • 实际落地时，如果不配置手部采集模块，仅使用头戴式设备，可能只需要2至3颗传感器。
  • 汽车、机器人及工业检测等端侧设备的生命周期通常是手机的2至3倍：
  1. 手机可能每年迭代一次。
  2. 其他端侧设备通常2至3年迭代一次。
  • 因此，端侧AI产品在总量、单价和更新周期方面均难以达到手机市场同等量级。

4. 为什么机器人素材采集不需要手机级高清CIS？

  • 机器人素材采集的拍摄场景相对固定，不需要像手机拍摄或汽车行驶环境一样，应对复杂光线、动态范围和极端工况。
  • 当前主流机器人及传统机器视觉数采产品以1080P为主，已经能够满足多数数据采集需求。
  • AI眼镜的像素规格相对更高，但长期主要锚定在约1300万像素，仍明显低于3200万或5000万像素。
  • 部分客户曾研发5000万像素眼镜产品，但最终综合效果反而不如1300万像素方案，原因可能涉及功耗、尺寸、发热、算法和系统适配等约束。

5. 不同规格CIS的价格差距有多大？

  • 抛开短期缺货和涨价因素：
  1. 传统1080P Global Shutter产品平均价格约为7至8美元，通常低于10美元。
  2. 旗舰级5000万像素手机CIS价格约为25至30美元。
  3. 部分0.7μm、0.5μm等小尺寸5000万像素产品主要用于中端机主摄或副摄，最低价格可能只有4至5美元，但不能代表旗舰级性能。
  • 按典型高规格产品比较，1080P全局快门产品与旗舰级5000万像素手机CIS的价格差距约为4至5倍。

3. 全球及国内CIS竞争格局

1. 全球CIS市场的主要供应商和份额如何？

  • 索尼
  1. 仍为全球CIS市场第一，2025年前后的整体市场份额约为40%，历史份额更高。
  2. 长期绑定苹果，国内OPPO、vivo、小米等品牌的部分旗舰机也采用索尼高端产品。
  3. 近两年受国产替代、项目切换和国内供应链崛起影响，份额有所下滑，但绝对体量仍居第一。
  4. 除消费电子外，工业机器视觉也是索尼的重要收入来源，IMX系列与基恩士等工业客户合作较深。
  • 三星
  1. 市场份额约为20%或略低于20%。
  2. 主要覆盖自有品牌手机、汽车、眼镜及部分工业应用。
  3. 当前与豪威处于接近的市场梯队。
  • 豪威
  1. 是近两年受益最明显的厂商之一，综合市场份额已逼近三星。
  2. 与小米旗舰机合作较深，小米15、16等系列大量采用豪威定制产品。
  3. 在汽车缺芯后快速切入国内市场，已进入全球汽车CIS第一梯队，并成为市场份额领先的玩家。
  4. 同时覆盖手机、汽车、安防和部分工业机器视觉。
  • 思特威、格科微、海力士等
  1. 按营收体量仍低于索尼、三星和豪威第一梯队。
  2. 思特威和格科微整体营收处于相近量级。
  3. 访谈口径称思特威、格科微的全球份额均在10%略高水平，但具体比例仍取决于市场统计范围和口径。
  4. 海力士目前已大幅收缩相关业务。

2. 豪威在各细分领域的竞争优势是什么？

  • 手机领域：
  1. 受益于国内手机供应链切换。
  2. 与小米旗舰机合作深度较高，具备较强的定制能力和客户黏性。
  • 汽车领域：
  1. 在2023年汽车缺芯后迅速切入市场。
  2. 在索尼、安森美退出部分国内中低端市场后快速扩大份额。
  3. 产品矩阵丰富，当前在国内汽车CIS市场处于领先位置。
  • 安防领域：
  1. 豪威和思特威基本处于同一梯队。
  2. 豪威在营收口径上领先，思特威在出货量口径上具备优势。
  • 工业领域：
  1. 已布局部分机器视觉产品。
  2. 在国内可规模供应Global Shutter产品的厂商中占据重要位置。

3. 思特威目前的业务布局和竞争位置如何？

  • 安防业务：
  1. 是思特威早期最重要的基本盘。
  2. 在安防CIS出货量方面处于第一梯队，与豪威竞争较为接近。
  • 手机业务：
  1. 2023年绑定华为后，成功进入Mate、Pura等中高端旗舰系列。
  2. 自2024年起逐步切入小米新一代数字系列。
  3. 已打开国内头部安卓客户，但进入OPPO、vivo、荣耀等客户仍需要时间。
  • 汽车业务：
  1. 相较豪威约存在半年左右的产品和市场切入差距。
  2. 在汽车缺芯初期，思特威产品矩阵不足，未能像豪威一样快速获取大量份额。
  3. 2025年至2026年，汽车业务体量预计仍与豪威存在较大差距。
  4. 国内大规模汽车CIS供应商主要仍是豪威和思特威，格科微尚未实现大批量出货。
  • 工业业务：
  1. 已进入工业机器视觉、消费机器视觉和机器人数采市场。
  2. 当前在国内工业客户供应体系中的位置约为第四供应商，前面依次为索尼、安森美和长光辰芯。
  3. 国产替代空间较大，但需要持续提升产品性能、客户验证和量产能力。

4. 格科微采取了怎样的差异化竞争策略？

  • 格科微目前仍以中低端手机CIS为核心市场，强调极致性价比。
  • 主要竞争优势包括：
  1. 通过自建Fab降低制造成本。
  2. 优化Die尺寸，在8英寸或12英寸晶圆上获得更多芯片产出。
  3. 拥有自身模组和封装IP，进一步压缩产品尺寸。
  4. 中低端产品对先进制程要求有限，90nm、110nm和部分55nm工艺即可满足需求。
  • 格科微主推单芯片BSI方案：
  1. 过去5000万像素小像素产品可能需要堆叠工艺。
  2. 格科微可用单芯片方案实现更低成本。
  3. 性能可能不及堆叠式产品，但在成本敏感市场中优势明显。
  • 在手机基本盘之外，格科微正向中低端安防和汽车市场拓展。
  • 格科微尚未量产工业Global Shutter产品，已于今年开始布局，预计明后年才可能进入量产阶段。

5. 工业机器视觉领域有哪些主要国内厂商？

  • 目前在工业机器视觉、消费机器视觉、机器人素材及其他Global Shutter应用中，国内可规模选择的供应商主要包括：
  1. 思特威。
  2. 豪威。
  3. 长光辰芯。
  • 长光辰芯专注机器视觉细分市场：
  1. 早期从军工、科研及高端定制产品起步。
  2. 近两年逐步向中低像素工业产品下探。
  • 其他创业公司包括元视芯、新视达、辰芯、创视微等：
  1. 元视芯前两年抓住汽车市场机会，目前重点推广汽车产品。
  2. 新视达主要从事安防CIS。
  3. 辰芯近两年转向布局医疗产品。
  4. 这些公司整体仍处于早期阶段，尚未实现大规模量产。

6. 未来几年全球CIS市场份额将如何变化？

  • 海外供应商的整体市场份额预计将进一步被压缩，索尼、三星等厂商的绝对优势将弱化。
  • 未来第一梯队可能由豪威、索尼、三星三家构成，各自可能占据20%至30%左右的市场份额。
  • 手机、安防和汽车中低端市场的竞争将更加白热化，同质化程度进一步提升。
  • 机器人和机器视觉市场快速发展后，将有更多国内厂商布局Global Shutter产品。
  • 30万、100万、130万像素等低像素消费级机器视觉产品技术门槛相对较低，部分产品无需采用堆叠工艺，未来价格竞争可能更加激烈。

4. 汽车CIS客户与增长逻辑

1. 思特威与哪些车企绑定较深？

  • 车企客户可分为直供和间接导入两类。
  • 目前主要直供客户包括：
  1. 比亚迪。
  2. 吉利。
  3. 零跑。
  • 对其他主机厂，公司主要通过Tier 1、模组厂和SOC平台厂进行项目导入和定点。
  • 从广义项目覆盖看，上汽、一汽、广汽、长城及蔚小理等国内大部分主机厂均有公司产品项目，只是份额不同。

2. 思特威在直供车企中的份额处于什么位置？

  • 从宏观和总量角度看，思特威通常为第二供应商，豪威为第一供应商。
  • 具体到不同应用，供应份额会有所区别：
  1. 环视类应用。
  2. 智驾类应用。
  3. 座舱类应用。
  • 不同车型和平台会采用不同供应组合，不能简单按整车客户统一判断份额。

3. 汽车CIS业务未来增速如何？

  • 公司汽车业务今年预计增长约40%。
  • 明年增速可能低于今年，但预计仍可达到20%以上。
  • 主要增长驱动力包括：
  1. 今年是智驾CIS产品放量元年。
  2. 300万和800万像素智驾产品开始陆续出货。
  3. 130万像素产品生命周期接近尾声，新平台将从300万像素起步。
  4. 环视摄像头通常需要4颗，不会因像素提升而明显减少数量。
  5. 像素规格升级将同步提升单颗产品价值量和业务收入。
  • 在单车摄像头数量稳定、规格持续提升的背景下，公司对汽车业务中长期增长保持信心。

5. 工业CIS技术门槛与国产替代

1. 工业CIS像素不高，为什么国内供应商仍然较少？

  • 工业CIS的主要门槛并非单纯像素，而是全局快门架构和制造工艺。
  • Global Shutter产品通常需要采用堆叠工艺：
  1. 单芯片或前照式方案难以获得理想性能。
  2. 工业客户对高速运动拍摄、低畸变、噪声、动态范围和稳定性要求较高。
  • 国内晶圆厂在全局快门工艺和良率方面仍存在不足，即使中芯国际等厂商的相关能力也有待提升。
  • 豪威、思特威和长光辰芯的Global Shutter产品大多由海外晶圆厂代工，包括：
  1. TSMC。
  2. Tower。
  3. 三星。
  • 全局快门所需堆叠属于晶圆级制造工艺，需要晶圆厂完成，不能只依靠后端封装实现。

2. 格科微自建Fab能否完成堆叠工艺？

  • 理论上具备完成相关工艺的能力，但最终竞争力取决于产品性能和良率。
  • 格科微当前的主要优势仍集中在中低端手机市场，而非高性能Global Shutter领域。
  • 其现阶段商业模式更强调：
  1. 成本控制。
  2. 单芯片BSI。
  3. 极致尺寸。
  4. 自有封装及模组IP。
  • 因此，格科微是否能在工业堆叠产品中形成优势，还需要后续量产表现验证。

3. 国内CIS企业与晶圆厂通常如何合作？

  • CIS行业普遍采用与特定代工厂深度绑定的合作模式：
  1. 豪威主要与中芯国际合作。
  2. 格科微此前与华虹、华力、武汉新芯合作较多，目前已拥有自建Fab。
  3. 思特威主要与晶合合作。
  • 各家通过长期绑定代工厂，围绕产能保障、工艺迭代和成本优化拓展业务。
  • 思特威现阶段仍以Fabless模式为主，没有明确提出自建Fab计划。

4. 工业板块未来能否超过安防业务？

  • 工业业务增长潜力可与汽车业务相提并论。
  • 如果机器视觉、数采和光通信等细分应用实现实质性放量，工业业务营收未来有可能超过安防。
  • 主要增长空间包括：
  1. 工业相机国产替代：公司当前在国内供应链中约为第四供应商，替代空间较大。
  2. 国产设备需求：半导体、3C、光伏、锂电等国产设备厂商将增加高价值机器视觉产品需求。
  3. 机器人数采：短期预计存在1至2年的需求行情。
  4. 医疗内窥镜：部分小规格内窥镜开始纳入医保，可能推动一次性内窥镜市场放量。
  5. 光通信产品：若Micro LED相关产品验证成功，可能形成新的工业业务增量。
  • 以海康机器人为例，其向索尼采购Sensor的金额曾达到大几亿元、接近10亿元，表明单一头部客户就具备较大的国产替代空间。

6. CIS技术差异化与高端产品能力

1. 不同厂商的CIS产品是否存在明显技术差异？

  • 中低端产品同质化程度越来越高，分辨率、像素、帧率、动态范围等基础参数差异有限。
  • 真正的技术差异更多体现在：
  1. 制程节点，如从28nm升级至22nm。
  2. 模拟与数字电路的布局和设计。
  3. 功耗控制。
  4. 算法适配。
  5. 动态范围。
  6. 成本与性能的平衡。
  • 以高端5000万像素手机CIS为例，LOFIC等技术可以提升高动态范围能力。
  • 即使各家采用相近的大架构，逻辑设计和工艺优化仍会造成性能差异，例如：
  1. 公司产品动态范围可能达到120dB。
  2. 竞争对手可能约为115dB。
  • 如果在性能领先的同时控制成本，公司就能形成性价比优势。

2. 性价比优势主要适用于哪些手机应用？

  • 性价比优势主要体现在：
  1. 旗舰机副摄。
  2. 中端机主摄。
  3. 中端机副摄。
  • 对旗舰机的核心主摄而言，性能仍是第一优先级，价格并非最关键因素。
  • 公司切换至国内晶圆厂生产，有助于降低成本和改善供应，但能否进入旗舰主摄仍取决于综合性能。

7. ASIC、AR与视觉系统解决方案

1. M2、AR及SerDes产品是如何规划的？

  • M2、AR、Micro LED、CPU等产品均源自公司机器视觉事业部积累的IP和系统方案能力。
  • CIS在实际应用中需要搭配SOC或ISP芯片，部分客户希望公司提供完整打包方案，包括：
  1. 模组。
  2. 镜头。
  3. CIS。
  4. 后端处理芯片。
  • 公司前两年成立飞林微子公司，主要开发SOC或ASIC定制芯片。
  • 产品规划包括：
  1. M2：最初主要面向汽车应用，但推广难度较大，客户采用意愿有限。
  2. AR：在具身机器人发展后推出，面向机器人和端侧视觉打包方案。
  3. SerDes：承担CIS与SOC之间的高速通信，是公司重点布局的核心IP之一。
  • 公司的目标是从单纯销售CIS，逐步升级为提供完整视觉系统解决方案。

2. M2、AR及SerDes短期能否快速放量？

  • 当前营收体量和放量预期并不特别乐观。
  • 相关产品存在一定同质化，客户对于CIS、模组和处理芯片的打包方案并未表现出很强的付费意愿。
  • 短期内，这些衍生产品仍难成为公司核心收入来源，后续增长取决于机器人、汽车和AIoT客户的实际采用情况。

8. Micro LED光通信产品进展

1. Micro LED产品目前处于什么阶段？

  • 公司在6至7月份推出了A样。
  • A样的产品结构和完成度不高，主要用于展示技术投入、产品构想和可实现性。
  • 公司预计在10月份至年底，最晚于明年第一季度初提供C样。
  • C样将具备送交客户验证的条件，计划覆盖：
  1. 头部模组厂。
  2. 板卡厂。
  3. 云计算厂商。

2. Micro LED产品定位是什么，替代哪类产品？

  • 产品并非用于替代铜缆，而是替代传统激光类光通信产品。
  • 第一代产品计划从800G切入：
  1. 暂时不会直接挑战1.6T或3.2T。
  2. 主要替换部分存量800G市场。
  3. 也可能与传统800G及1.6T产品共同运行。
  • 当前主要面向短距离可插拔光模块，而非直接采用CPO方式与板卡或处理器集成。
  • 产品仍需要通过线体连接。

3. Micro LED产品何时可能实现出货？

  • 在非常理想的情况下，最快可能于明年下半年实现小批量出货。
  • 当前仍处于产品开发和客户验证阶段，真正大规模放量时间尚不明确。
  • 是否能够商业化取决于：
  1. C样性能。
  2. 客户验证进度。
  3. 800G产品的可靠性和成本。
  4. 传统激光方案的替代意愿。
  5. 行业标准和技术路线能否逐步统一。

4. Micro LED产品由谁代工，公司的核心优势是什么？

  • 当前产品由TSMC代工。
  • CPO及相关光电产品尚未形成统一标准，各家技术路线差异较大。
  • TSMC主要提供工艺平台，重点能力包括：
  1. 模块堆叠。
  2. 一级和二级微透镜工艺。
  3. 制造工艺优化。
  • TSMC较少直接参与完整产品架构设计。
  • 公司的核心优势在于：
  1. 具备CIS领域长期积累的光电转换经验。
  2. 在PD部分拥有可复用IP。
  3. 在SerDes部分拥有一定技术积累。
  4. 可将PD、SerDes和光开关阵列进行系统整合。
  • 公司后续主要需要在开关阵列和工艺创新方面加大合作与研发投入。

9. 手机、安防及工业业务展望

1. 手机业务今年和明年预计如何增长？

  • 公司手机业务上半年增速较低，主要与手机厂商提货节奏有关。
  • 下半年通常是旗舰智能手机集中发布窗口，因此全年增量更多将在下半年体现。
  • 预计2026年相较2025年，手机业务整体增速约为10%。
  • 未来已难以复制此前接近翻倍的高速增长，主要原因包括：
  1. 公司在部分旗舰客户中的导入和份额已经较高。
  2. 新增渗透空间更多集中在中低端产品。
  3. 中低端市场更强调价格和性价比，竞争更加激烈。

2. 手机业务未来还有哪些增长方向？

  • 未来主要有三个方向：
  1. 持续导入新客户：继续突破国内其他头部安卓厂商，同时向海外头部手机厂商送样；目前虽未取得实质订单，但认可度和口碑已有明显提升。
  2. 切换供应链：部分高端产品过去主要由TSMC生产，公司正尝试导入华力、晶合等国内产能，以改善成本和供应保障。
  3. 拓展同规格衍生市场：将手机CIS产品延伸至运动相机、全景相机等场景，复用1英寸、1亿像素、2亿像素等规格和技术。
  • 即使传统智能手机业务进入成熟期，同类高规格产品仍可在其他消费影像设备中获得增长。

3. 进入手机品牌后，公司通常如何获得项目份额？

  • 在旗舰机领域，通常不是同一颗CIS由多家供应商共同供货。
  • 更常见的方式是：
  1. 在某一旗舰系列中进入Pro或Pro Max等特定机型。
  2. 供应其中一个规格，如主摄或长焦。
  3. 以单一项目、单一机型和单一规格切入，而非包揽整机全部CIS。
  • 手机客户的供应模式与汽车类似，通常根据摄像头位置和规格分配不同供应商。

4. 安防业务未来如何发展？

  • 安防属于典型周期性行业。
  • 短期营收可能受到缺货和涨价影响，出现阶段性快速增长或波动。
  • 从长周期看，安防市场整体发展相对平稳，与成熟期手机业务类似。
  • 广义安防中的AIoT和智能家居应用仍能贡献一定结构性增量，但预计难以出现长期高速增长。

5. 工业业务的增长取决于哪些因素？

  • 工业业务能否快速增长，主要取决于以下应用是否实现实质性放量：
  1. 工业视觉相机国产替代。
  2. 国产半导体和高端制造设备。
  3. 机器人及端侧数采。
  4. 医疗内窥镜。
  5. Micro LED及光通信产品。
  • 如果上述领域顺利放量，工业业务未来营收有可能超过安防业务。

10. 毛利率与整体业绩展望

1. 中低端市场竞争加剧是否会导致公司毛利率下降？

  • 从长期看，公司整体毛利率预计不会明显下降。
  • 主要原因包括：
  1. 汽车和工业业务占比将逐步提高，这两个板块现阶段毛利率相对有保障。
  2. 公司手机业务以中高端像素产品为主，尤其是5000万像素产品占比较高，不同于格科微以中低端产品为主的结构。
  3. 手机板块部分产品毛利率可能有所下滑，但整体处于可控范围。
  4. 国内代工厂导入和供应链切换有助于抵消价格竞争影响。
  • 未来毛利率的核心支撑将从单一安防业务，逐步转向手机中高端、汽车和工业业务的组合。

2. 公司今明两年的收入增长目标如何？

  • 公司今年对外披露的收入规模约为110亿元上下。
  • 明年具体目标尚未最终确定。
  • 若仅考虑CIS业务，不考虑AI相关CPU、服务器等衍生产品，预计明年仍可实现10%至15%的收入增长。
  • 其他衍生业务的增长需要根据产品进度和客户验证情况判断，包括：
  1. M2、AR和SerDes。
  2. Micro LED光通信。
  3. AI相关CPU及服务器产品。
  • 现阶段公司较确定的增长来源仍是汽车CIS、工业机器视觉国产替代，以及手机业务的温和增长。

提问者：格科微的Fab能够自行完成堆叠工艺吗？

提问者：但据我理解，如果这类工艺只有晶圆厂才能做好，国内的中芯国际、华虹也难以做好，格科微为什么能够做好？

格科微目前的第1个优势在于极致的尺寸，即在12寸或8寸晶圆上产出足够多的Die。第2，它拥有自己的模组IP，也就是说，Sensor Die切割完成后，还可以通过自己的封装方式进一步将尺寸控制得非常优秀，形成相对优势。第3，中低端手机对制程的要求不高，不需要达到28纳米或22纳米，90纳米、110纳米以及部分55纳米制程，已经能够满足其对中低端产品的定义需求。

因此，他们目前还主打单芯片BSI手机产品这一概念。过去需要通过堆叠工艺生产5000万像素的小像素产品，现在他们可以采用单芯片方式实现极致性价比。其性能可能无法对标堆叠产品，但如果客户有成本方面的诉求，其优势会非常大。

提问者：明白了。整体来看，格科微更多采取的是差异化竞争策略。

回　答　者：对。

提问者：思特威是坚持Fabless模式，还是也计划建设自己的Fab？

回　答　者：国内从事CIS的企业，或者说整个CIS行业，基本存在一种潜在的合作模式，即各家都会锚定或绑定1家合作特别紧密的代工厂。

回　答　者：在工厂合作方面，举例来说，豪威与中芯国际合作；格科微以前与华虹、华力、武汉新芯合作较多，但现在已有自己的Fab厂；思特威则主要与晶合合作。因此，从产能和工艺来看，各家基本上都围绕这种合作方式拓展业务。

提问者：从未来几年来看，随着CIS内部应用场景发生变化，您认为这几家公司的市场份额将如何演变？

回　答　者：如果从绝对体量或宏观角度来看，海外供应商的市场份额会被进一步压缩。也就是说，索尼、三星、SMI的优势不会再像以前那么明显。未来第一梯队可能是豪威、索尼、三星这3家，各自拥有30%或20%左右的市场份额，这是完全有可能的。

进一步下探到各个应用板块，无论是手机还是汽车，竞争都会更加白热化，尤其是中低端产品。过去手机、安防领域的门槛本来就比较低，现在汽车领域部分中低端产品的门槛也越来越低。

此外，随着机器人或机器视觉市场快速发展，国内也有较多新兴企业正在布局Global Shutter，也就是全局快门产品。特别是部分低像素或消费级机器视觉产品，例如30万、100万、130万像素等尚未达到1080P分辨率水平的产品，其门槛相对较低，甚至不需要采用堆叠工艺，使用单芯片也能打造具有极致性价比的产品。

提问者：如果从技术难度或各家产品的技术差异来看，CIS产品是否存在明显的技术领先？

回　答　者：可以换一个角度理解。中低端产品的竞争越来越激烈，因此这类规格产品的同质化也越来越严重。对于外部客户或刚接触这个行业的人而言，关注的无非是分辨率、像素、帧率、动态范围等参数。在宏观层面，A供应商与B供应商在这些参数上基本不会存在特别大的差异，也很难通过这几个参数实现差异化。

差异主要体现在更高阶的工艺上。例如，原本采用28工艺，友商也是28，如果能够做到22，同时在模拟部分或数字部分的布局、方式和设计上更加灵活，最终就可能在功耗、算法等方面与友商形成差异化。

目前在中高端手机CIS领域，例如5000万像素产品中，有一个概念叫LOFIC。顾名思义，LOFIC翻译过来就是一个电容上面的……

回　答　者：从宏观层面看，客户只需要1个完整产品的大架构。友商也会设计相关逻辑，但从实际表现来看，我们的逻辑设计可能略好。例如，我们的动态范围最终达到120dB，友商可能只有115dB；如果进一步控制成本，我们在性价比方面就更具优势。

提问者：关于竞争格局已经比较清楚了。半年报中还提到公司有M2、AR等ASIC产品，目前这一业务是如何规划的？

回　答　者：M2、AR、Micro LED、CPU等产品，实际上都是我们机器视觉业务部或事业部此前衍生出的想法或IP。以CIS为例，在实际使用过程中，CIS需要搭配后端的SOC芯片或ISP芯片。因此，有些客户会要求我们提供打包方案，涵盖模组、镜头、CIS及后端处理芯片。处理芯片不需要具备特别大的算力，只需保证图像输出结果达到客户要求即可，尤其是在部分低端端侧、以前的智能设备、AIoT及部分汽车应用中。

基于这一思路，我们在前2年成立了1家名为飞林微的子公司。飞林微专注于SOC，也可以称为ASIC，即定制化集成电路芯片。M2主要针对汽车应用，但汽车应用较难推广，客户使用意愿不强，原因较为复杂。发现这条路径难以推进后，具身机器人正好发展起来，也需要类似的产品打包方案，因此推出了AR产品。

除这2款SOC芯片外，我们还有SerDes芯片，即通信芯片。由于CIS需要与SOC芯片通信，SerDes也是1个核心IP。围绕该IP，我们在专利和硬件产品方面也进行了一些布局。这些产品丰富了公司的视觉系统解决方案，使我们不仅销售CIS，也能够提供完整的视觉系统方案。

提问者：目前AR、M2及SerDes等产品的营收贡献或放量预期如何？是否会较快增长？

回　答　者：如果仅针对AR、M2或SerDes等衍生类产品，目前的体量并不特别乐观。这些产品也存在一定同质化问题，客户最终对我们此前提出的打包方案并不特别愿意买单。

回　答　者：基本上会覆盖您所了解的头部模组厂、板厂和云厂。

提问者：这款产品是替代目前的可插拔光模块，还是采用CPO方式？

回　答　者：目前主要还是替代前者，即短距离可插拔模块。产品仍需采用线体连接，并非与板卡或处理器直接集成在一起。

提问者：TSMC也有一些光电共封平台。我们的方案与其自主开发的技术路线相比，主要差异或亮点体现在哪些方面？

回　答　者：目前，无论是TSMC，还是海外的Avago、Microsoft，以及国内的友达、京东方，均未形成统一或标准化的产品模式。例如，CIS领域的安防200万产品，大家的方案基本相近，但在CPO领域，各家的方案仍然五花八门。

回　答　者：做PD的公司可能更多聚焦于光开关阵列、驱动电路的设计。至于PD和SerDes部分，他们要么与第三方合作，要么直接向代工厂采购，最后再堆叠在一起。我们依托以前做CIS的经验，在PD部分以及1部分SerDes方面拥有成熟的IP，可以直接复用。我们最多需要在开关阵列和工艺创新方面开展更加深入的合作或研发。

提问者：关于公司业绩，手机业务上半年增速可能只有1%，终端销量也在下滑。展望全年，手机业务大概会处于什么状态？

提问者：展望未来，手机业务可能会向中低端市场拓展，但这一市场的竞争相对激烈。这是否意味着未来几年手机业务将处于温和持平的状态？

第2个方向是切换供应链。以前高端旗舰手机产品可能只能在TSMC生产，现在我们也在尝试采用华力或部分晶合的产能，从而进一步改善总体成本和供应。

第3个方向是手机板块还可以衍生。

回　答　者：在手机、运动、全景等门类中，产品规格基本通用，例如1英寸、200兆、100兆等规格。因此，传统智能手机业务达到一定规模后，并不意味着同类产品没有增长空间，至少还可以向其他方向发展。

提问者：汽车业务的预期如何？从增速来看大概是什么水平？
