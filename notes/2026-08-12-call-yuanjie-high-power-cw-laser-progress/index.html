元杰光芯片产品进展专家访谈纪要

1. 高功率CW产品进展

a) 元杰高功率CW产品目前有哪些规格？

  • 公司对外介绍的高功率CW产品主要包括200mW和400mW两种规格
  • 市场所称的“300mW产品”，通常对应公司400mW产品档位，实际功率可能调至370mW、380mW左右
  • 200mW产品实际功率可能为170mW、180mW或190mW，只要满足客户端要求即可使用
  • 当前不同功率产品的主要定位：
  1. 70mW、100mW产品主要应用于传统AI光模块，已经进入批量供货阶段
  2. 200mW、400mW产品主要面向NPO、CPO等高功率应用，目前仍处于早期验证阶段
  3. 高功率产品也可以向下兼容低功率、低规格场景，但经济性取决于产品价格和客户方案

b) 400mW CW产品是否已经通过客户验证并实现量产？

  • 目前尚不能认定400mW产品已经完成客户验证或正式量产
  • 当前进展主要是小批量出货，由客户拿样制作模块并开展后续验证：
  1. 单次或单月出货规模可能为数百颗
  2. 部分客户可能隔几个月下单一次，每次采购约1,000颗
  3. 出货节奏不稳定，属于时有时无的验证性订单
  • 下游客户通常先用芯片样品制作模块、参加展示或获取终端订单，再将模块送至应用端运行验证
  • 中际旭创等国内客户均在拿样制作模块，推动NPO、CPO相关研发，但目前没有明确的全面验证通过信息
  • 市场传言“300mW产品已经通过英伟达验证并获得大量订单”缺乏明确依据，更可能是把拿样、小批量模块验证误解为正式验证通过
  • 1U等方案仍处于过渡阶段，最终可能采用400mW或800mW级产品，技术路线尚未完全定型

c) 400mW产品当前良率和可用比例如何？

  • 当前产品主要按照功率是否达标进行筛选，尚未完全进入客户端规模使用阶段
  • 现阶段部分产品并未完成充分的老化等长期可靠性评价，因此不能简单等同于成熟量产良率
  • 按功率指标推算，可用比例约为10%
  • 当前仍属于小批量硬筛选阶段，样本量较小，统计良率的参考意义有限
  • 真正进入整片投产和大批量运行后，工艺、可靠性和一致性问题才会更充分暴露
  • 后续需要通过芯片设计、外延、制造工艺及筛选标准优化提升良率，否则低良率将直接压低产品毛利率

d) 200mW CW产品目前进展如何？

  • 200mW产品目前同样处于送样和模块验证阶段，尚未实现稳定量产
  • 国内较早的高功率样品由仕佳光子于3月推出，元杰约在5月完成首次出样
  • 当前出货量一般为数百颗，但并非每个月持续出货，客户可能隔几个月采购一次
  • 200mW产品的可用比例初步估计也在10%左右，但现阶段尚不适合用小批量数据判断稳定量产良率
  • 目标应用以NPO、CPO为主，但模块封装和应用端适配仍需要继续研发和验证
  • 客户也可以将200mW产品用于传统光模块或低功率场景，前提是采购价格和方案成本能够接受

e) 70mW、100mW CW产品的商业化情况如何？

  • 70mW、100mW产品已经进入批量供货阶段
  • 中际旭创等客户已在采购相关低功率产品
  • 与200mW、400mW产品相比，70mW、100mW产品的出货更持续，商业化成熟度更高
  • 当前AI光模块主要采用70mW、100mW产品，200mW、400mW暂时主要服务于NPO、CPO方向

2. NPO、CPO应用及验证流程

a) NPO、CPO是否必须采用200mW或400mW高功率芯片？

  • NPO、CPO对每个通道存在明确的最低光功率要求，低于规定功率的芯片无法使用
  • 具体功率下限会因模块方案、通道设计和应用类型而有所不同
  • 专家未能当场确认150mW、370mW等具体分界数值，需要后续查阅技术资料
  • 70mW、100mW是否可用于特定NPO、CPO方案，取决于能否满足对应方案的最低功率要求，并非所有方案均可使用
  • 高功率CW产品仍是当前NPO、CPO研发的主要目标方向

b) 200mW、400mW产品从研发到正式订单需要经历哪些环节？

  • 芯片厂内部开发阶段：
  1. 根据客户需求确定200mW或400mW产品规格
  2. 开展外延模拟、芯片设计及投片
  3. 从外延到完成相关工艺流程约需1个月
  4. 加上测试和筛选，形成可送样产品大约需要1个半月或更长时间
  • 客户模块验证阶段：
  1. 客户收到芯片后进行模块设计和封装
  2. 模块制作可能需要2至3周，也可能需要1至2个月
  3. 完成模块后，再送至上游、下游或最终应用端验证
  4. 单轮应用验证通常至少需要约2个月
  • 问题整改和再次送样阶段：
  1. 如果性能不符合要求，需要检查芯片设计、工艺或筛选标准
  2. 若设计存在问题，需要修改设计并重新投片
  3. 若设计符合要求，则可能通过加强筛选、排除异常特性后再次送样
  4. 模块厂商通常只会给予2至3次送样机会，不会无限期验证
  • 供应商准入阶段：
  1. 产品验证通过后，客户还要评估产能、价格、性能及供货承诺
  2. 之后通常还要进行验厂、数据审核和整改
  3. 验厂流程快则约1个月，慢则约2个月
  4. 商务层面还需客户高管、市场和销售团队共同推进

c) 产品验证通过后是否一定能获得订单？

  • 验证通过仅代表产品技术指标具备进入客户供应链的可能，并不等于一定获得订单
  • 客户通常会同时验证两至三家供应商，再综合选择
  • 最终采购决策主要考虑：
  1. 芯片性能及长期可靠性
  2. 产品价格
  3. 当前供货能力
  4. 后续扩产和持续供货承诺
  5. 供应商现有产能是否已被其他产品占满
  • 部分拿样方可能只是研究机构，以技术研究和方案展示为目的，不一定形成商业订单
  • 即使产品性能验证通过，若供应商无法保障稳定供货，客户仍可能选择其他厂商

d) 产能和良率在客户导入中有多重要？

  • 产能和良率是光芯片供应商能否实现商业化的核心指标
  • 产能决定客户能否获得稳定、充足的供货，也是客户选择供应商的重要条件
  • 良率直接影响单位生产成本和毛利率
  • 若现有100mW产品已经占用大量产能，200mW、400mW产品量产后也将挤占产能，客户会担忧新增高功率产品无法稳定交付
  • 因此，高功率产品后续不仅要完成性能验证，还必须同步解决良率和规模化产能问题

3. 高功率CW产品定价与商业化前景

a) 400mW CW产品目前如何定价？

  • 400mW产品目前基本不提供免费样品，客户需要付费采购
  • 当前价格大致情况：
  1. 最初样品价格约为1,200元/颗
  2. 面向小型客户时，价格可能约为800元/颗
  3. 数百颗规模发货时，价格可能降至约600元/颗
  4. 部分厂商的400mW产品报价仍坚持在1,000元/颗以上
  • 上述价格均为人民币
  • 当前产品价格较高，主要是因为国内供应稀缺、良率较低，产品主要通过硬筛选获得
  • 现阶段尚未进入稳定大批量采购，因此当前样品价格不能代表未来量产ASP
  • 后续量产价格将取决于客户订单规模、产品良率、竞争格局以及各厂商供货能力

b) 400mW产品的高价格能否带来较高毛利？

  • 当前高价格并不意味着高毛利
  • 在可用比例约10%的情况下，大量不达标芯片会摊高单颗合格品成本
  • 若后续仍依赖硬筛选而无法改善工艺良率，即使单颗售价较高，整体毛利率也可能较低
  • 提升毛利的核心路径包括：
  1. 优化芯片设计
  2. 提升外延及晶圆工艺稳定性
  3. 改善测试和筛选能力
  4. 提升整片一致性
  5. 通过规模量产降低固定成本

4. 国内外高功率CW竞争格局

a) 国内哪些厂商在400mW高功率产品方面进展较快？

  • 仕佳光子是国内较早推出高功率CW产品的厂商，约在3月完成相关出样
  • 元杰约在5月完成出样，当前与仕佳光子的商业化状态大体类似，均处于送样和早期验证阶段
  • 索尔思也具备相关产品开发能力，并且参与技术研发时间更早
  • 青岛海信也在推进相关技术，但采用的技术方案有所不同
  • 当前国内进展较好的厂商主要包括：
  1. 索尔思
  2. 仕佳光子
  3. 青岛海信
  4. 元杰等其他光芯片企业

b) 索尔思的技术水平和客户资源如何？

  • 专家判断索尔思的技术水平相对更好，主要因为其研发起步较早、积累时间更长
  • 索尔思在DFB、DML等光芯片领域的整体水平处于国内领先位置
  • 索尔思的优势更多体现在性能水平，专家并未确认其高功率产品良率明显领先
  • 索尔思已被中际旭创收购，产业协同和客户支持能力更强
  • 在100G产品方面，索尔思已基本具备完整出货能力

c) 海外厂商的高功率光芯片进展如何？

  • Lumentum、Coherent等海外厂商较早就已推出高功率产品，相关技术成熟度领先国内
  • 以100G产品为例，海外厂商在2至3年前已完成相应产品开发
  • 海外厂商在50G、100G、200G DML等高性能芯片方面，整体性能优于国内厂商
  • 国内产业链的相对优势主要体现在光模块设计、制造和规模化交付，海外模块端的竞争力相对弱一些
  • 国内光芯片厂商仍需要在芯片性能、良率、一致性和可靠性方面持续追赶海外水平

5. EML产品验证及量产进展

a) 100G EML目前进展如何？

  • 100G EML已经完成客户验证，索尔思等厂商已基本具备出货能力
  • 但整体市场尚未全面起量，部分厂商仍以样品验证和小批量交付为主
  • 产品通常以COC形式销售，而非直接销售裸芯片
  • 专家预计，100G EML的供应能力有望在今年年底或明年年初进一步补齐
  • 此前带相关功能的100G EML价格约为100至150元人民币，当前实际成交价可能已经下降，但具体降幅不明确

b) 100G EML的良率处于什么水平？

  • 100G EML生产难度较高，元杰等国内厂商的良率估计约为10%至20%
  • 索尔思可能相对更好，专家估计约为20%左右
  • 良率属于厂商核心机密，相关数据主要来自专家与客户沟通后的经验判断，并非企业正式披露
  • 当前较低的良率仍是国内EML产品扩大供货和改善盈利能力的主要障碍

c) 200G EML目前是否已经验证通过？

  • 200G EML仍处于客户验证阶段，尚未完成正式验证
  • 当前主要由中际旭创等客户进行验证
  • 研发阶段尚未进行整片规模投产，通常每片仅投少量研发批次，因此暂时无法准确核算量产良率
  • 专家估算现阶段良率约为20%，与100G EML大致处于同一量级
  • 预计今年年底或明年年初，100G和200G EML的供应能力可能进一步完善，但200G产品仍需视客户验证结果而定

d) 索尔思EML批次报废事件如何看待？

  • 行业内确有索尔思某批EML产品报废的相关消息，但专家未确认具体规模和原因
  • 在光芯片制造过程中，单批次产品报废并非罕见，可能由去离子水、外观缺陷、贴片工艺或其他制造环节异常引起
  • 一次工艺异常可能影响几十片甚至上百片晶圆，并且不一定只影响EML产品
  • 因此，单批报废不能直接说明厂商失去产品能力，但反映出光芯片制造对工艺稳定性和质量控制要求极高

6. 400G EML及更高速产品规划

a) 400G EML是否一定比200G EML更难？

  • 从整体性能要求看，400G产品通常面临更高的带宽、功耗、散热和封装难度
  • 但不同速率产品的芯片尺寸、结构和贴片方案差异较大，不能简单认为必须完成200G后才能开发400G
  • 正贴、背贴等不同封装工艺会显著影响散热和热管理能力
  • 专家举例，元杰此前采用正贴工艺时芯片可能因散热问题烧坏，而其他厂商采用背贴工艺后热控制效果更好
  • 因此，更高速芯片的实现不仅取决于芯片本身，还取决于贴片、封装和整体热管理方案

b) 国内400G EML目前处于什么阶段？

  • 国内光通信企业当前的重点仍是100G和200G EML
  • 据专家了解，国内能够出货的光通信公司中，尚未有企业正式开展成熟的400G EML商业化
  • 部分研究所可能已开展前沿研发，但尚未形成明确的产业化进展
  • 元杰目前也尚未正式推进400G EML产品
  • 国内部分企业虽然已经开发出100G产品，但由于功率或带宽不达标，可能会使用更高规格设计的产品降级满足客户需求

7. 核心结论与后续关注点

a) 如何判断元杰高功率CW产品当前所处阶段？

  • 70mW、100mW产品已经实现批量供货，是现阶段相对成熟的产品
  • 200mW、400mW产品已经完成出样并有验证性出货，但仍处于客户拿样、模块制作和应用端验证阶段
  • 当前尚无充分信息证明400mW产品已经通过核心终端客户全面验证，也不能认定已经获得大规模正式订单
  • 小批量付费出货与正式量产需要区分，现阶段高功率产品的出货节奏仍不稳定
  • 400mW产品当前可用比例约10%，量产前仍需重点解决良率、可靠性和一致性问题

b) 后续需要重点跟踪哪些节点？

  • 200mW、400mW产品是否完成模块端及终端应用验证
  • 中际旭创等核心客户是否给出明确qualification结果
  • 产品是否进入客户正式供应商名单并完成验厂
  • 验证性订单是否转为连续、大批量订单
  • 400mW产品良率能否由约10%显著提升
  • 高功率产品产能是否会与现有100mW产品形成冲突
  • NPO、CPO实际落地节奏及每通道最低功率标准
  • 200G EML能否在年底或明年年初完成验证
  • 国内厂商与索尔思、仕佳光子及海外厂商之间的性能和良率差距
