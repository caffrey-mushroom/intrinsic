Questions

Could you describe what Aiden Technologies does? What products and services does the company provide?

Expert: Aiden Technologies is a SaaS software company that automates Windows endpoints. It sits alongside tools like Microsoft Configuration Manager and Microsoft Intune to deploy and update applications and also third-party applications. It enforces a defined endpoint configuration, patch management, patch vulnerability, provision devices and provide evidence that the fleet or all the devices are actually compliant. Their core statement or core ideal is based upon a desired state management platform where they define how a device should look and then ensure that that device is that way based upon the policies that they set forth.

What is the value proposition of Aiden's solutions and services?

Expert: It will reduce manual packaging, patching, deployment and remediation work. It closes the gap between what we desired our policy to be and that the endpoint is actually compliant to that. It helps IT and security operate from the same standpoint or endpoint state, I guess, in evidence. It minimises user disruption by coordinating all the patches at once. If a machine has to do a bunch of reboots, then the Aiden Technology will ensure that there's only one reboot and minimise that number of reboots that has to happen.
