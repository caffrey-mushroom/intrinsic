微软FY27 Q1 Azure、AI与Microsoft 365业务专家访谈纪要

1. Azure整体业绩与业务结构

a) FY27 Q1 Azure整体营收和增速如何？

  • 整体营收及增速
  1. FY27 Q1对应2026年7月至9月，Azure及其他云服务营收约为325亿美元。
  2. 按固定汇率计算，同比增长约44%—45%；名义增速约为42%。
  3. Azure延续加速增长态势，上一阶段单季度营收约为294亿美元。
  4. 按当前趋势估算，Azure全年营收预计可突破1,000亿美元。
  • 数据确认程度
  1. 325亿美元为已经向管理层汇报并通过的内部大数，预计不会出现明显调整。
  2. 财务后续可能进行细节调整，潜在差异约为1%，但不会改变整体营收和增速判断。
  3. 如无特别说明，本次数据均为微软集团层面的全球口径。

b) Azure AI与Core Azure分别贡献多少收入？

  • Azure AI业务
  1. Azure AI营收约为78亿美元，同比增长超过80%。
  2. Azure AI约占Azure整体营收的24%，为当前增长最快的业务板块之一。
  3. Azure AI主要采用API按量计费、专属容量部署和项目制服务等商业模式。
  • Core Azure业务
  1. Core Azure即非AI核心业务，包括计算、存储、网络、数据库、安全、身份认证等。
  2. Core Azure营收约为247亿美元，同比增长约32%。
  3. 该部分是Azure的基本盘，主要采用消耗型计费模式，按照CPU、内存使用时长等资源消耗收费。
  4. 核心增长动力来自企业云迁移深化、混合云扩容以及安全合规需求提升。

c) Azure当前采用哪些计费与销售模式？

  • Azure整体主要采用以下模式：
  1. 按需消耗计费。
  2. 预留资源或长期消费承诺。
  3. 根据客户采购规模设置分层折扣。
  • Azure AI在上述基础上进一步采用：
  1. API调用及Token按量计费。
  2. 专属容量部署。
  3. 模型训练服务。
  4. 定制化及项目制服务。
  • Azure AI定制化服务约占整体收入的12%—15%。

2. Azure AI收入拆分与模型生态

a) Azure AI收入中，OpenAI和自有AI服务分别占多少？

  • Azure OpenAI Service
  1. Azure OpenAI Service约占Azure AI收入的60%。
  2. 按78亿美元计算，对应单季度收入约为46.8亿美元。
  3. OpenAI仍是Azure AI收入的核心来源，也是微软最重要的AI生态合作伙伴。
  • 微软自有AI服务
  1. 自有AI服务约占Azure AI收入的40%。
  2. 主要包括Azure AI Foundry、认知服务、机器学习平台等。
  3. Azure AI Foundry约占Azure AI整体收入的12%，对应约9.36亿美元。
  4. 认知服务、机器学习平台等其他业务暂未进一步拆分。

b) Anthropic在Azure AI中的占比和增长情况如何？

  • Anthropic业务起量时间较短，尚未在本季度内部大数中单独拆分。
  • 按月度口径观察：
  1. 7月占比约为4%。
  2. 8月提升至4.8%，接近5%。
  3. 9月预计进一步上升。
  • 专家判断，市场所称Anthropic占比已达到9%的说法可能偏高，但不同统计口径可能造成差异。
  • 专家提到，Anthropic相关月度规模从约140增长至150，9月可能达到180—190，但原始访谈未明确对应币种、单位及具体统计口径。

c) 第三方模型业务的增长情况如何？

  • 第三方模型指OpenAI以外的模型业务，包括Claude、Mistral、DeepSeek等。
  • 该板块同比增速约为165%，是当前Azure内部增速最快的业务板块。
  • 核心驱动力是企业客户开始采用多模型混合部署，不再只依赖单一OpenAI模型。
  • 微软将继续扩大第三方模型接入，通过丰富多模型生态提升Azure平台的客户覆盖面和收入规模。

d) Azure OpenAI Service的收入由哪些服务构成？

  • Azure OpenAI Service收入结构大致为：
  1. Token/API调用收入占45%。
  2. 专属容量部署收入占32%。
  3. 模型训练收入占剩余约23%。
  • 上述比例为各类服务占Azure OpenAI Service收入的比例，而非成本、利润或毛利占比。
  • 当前重点优化方向主要是吞吐量和推理效率，并已上线GPT-4o的分级版本。

3. OpenAI合作关系与算力分配

a) 微软与OpenAI的合作关系是否发生变化？

  • OpenAI仍是微软最重要的云基础设施客户和战略合作伙伴。
  • 双方已在以下三个层面形成深度协同：
  1. 技术协同。
  2. 算力供应。
  3. 商业化转售。
  • Azure针对OpenAI模型进行了从硬件到底层软件栈的全栈定制优化，训练效率较通用架构提高30%以上。
  • 去年10月双方签订新协议，OpenAI承诺采购约250亿美元的Azure服务，主要用于训练和推理算力需求；合作期限在访谈中未明确。
  • Azure OpenAI Service已成为双方商业化联动的核心产品：
  1. 获得OpenAI主流模型的官方推荐。
  2. 由微软负责运维。
  3. 满足双方企业级安全与合规要求。
  4. 提供SLA保障和技术支持。

b) OpenAI训练和推理负载如何在不同云厂商间分配？

  • 训练负载
  1. 约90%的核心训练负载部署在Azure。
  2. 少量边缘测试及小模型微调部署在AWS和CoreWeave。
  3. 大模型训练周期长、规模大，对底层优化依赖程度高，迁移成本较高，因此核心训练负载预计不会发生明显变化。
  • 推理负载
  1. Azure承载约65%的OpenAI全球推理负载。
  2. AWS承载约18%。
  3. Oracle、Google Cloud和CoreWeave等合计承载约10%以上。
  4. OpenAI正采用多云供应商策略，但Azure仍是其最大的训练及推理基础设施供应商。

4. Core Azure增长驱动力与客户消费趋势

a) Core Azure增长主要由哪些因素推动？

  • 非AI核心业务增长主要由大型及超大型企业的核心系统云迁移驱动。
  • 云迁移及其衍生业务，包括混合云部署、扩容、安全与合规需求，合计贡献非AI核心业务收入的80%以上。
  • 企业级客户年留存率达到96%以上，体现出较强的客户黏性。
  • 部分超大型企业的采购规模提升至原来的约110%—115%。
  • 随着核心业务系统逐步上云，客户更换云服务商的成本持续提高，Core Azure有望形成长期稳定的收入基本盘。

b) 哪类客户的消费增长最明显？

  • 中小型企业
  1. 整体变化有限。
  2. 对行业变化和算力资源变化的敏感程度相对较低。
  • 中型企业
  1. 对可获得的算力规模和资源位置较为敏感。
  2. 普遍希望扩大资源占用和部署规模。
  • 大型及超大型企业
  1. 是本季度消费加速最明显的客户群体。
  2. 增长尤其集中在金融、医疗等强监管行业。
  3. 其部署、合规审计和权限体系建设节奏均明显加快。

c) 大客户的部署周期为何加快？

  • 大型客户的需求主要发生了三方面变化：
  1. 真实数据接入要求提高：模型训练和系统对接需要使用客户真实业务数据，数据权限和安全限制更加严格。
  2. 安全合规验收提速：相关审计和验收周期由过去约2个月缩短至约1个月。
  3. 定制化权限体系需求增加：客户要求建立更细致的身份、权限及治理体系，方案沟通和落地速度明显加快。
  • 当前增长并非单纯来自容量改善，而是客户正式部署进程加快、资源需求扩大和合规要求提高共同推动。

d) 企业新增AI和云预算属于纯增量吗？

  • 从微软可观察到的情况看，大客户针对新增功能通常需要单独履行预算审批流程，因此可以视为新增预算。
  • 但专家无法确认：
  1. 新增预算最终归属于研发预算还是合作预算。
  2. 客户是否同步削减其他既有IT预算。
  3. FY27整体预算相较本年度的净增幅。
  • 因此，目前只能确认项目预算为单独审批，不能确认客户整体IT支出的净增量。

5. Azure AI Foundry产品进展

a) Azure AI Foundry的定位和增长动力是什么？

  • Azure AI Foundry定位为企业级AI应用的一站式开发与部署平台。
  • 工具链覆盖：
  1. 模型选型。
  2. 模型微调。
  3. 模型评估。
  4. 应用部署。
  5. 安全与治理。
  • 核心目标是降低企业搭建生产级AI应用的门槛。
  • 随着企业AI从概念验证进入正式生产环境，客户对向量数据库、模型治理、数据库合规和AI安全治理的需求显著提升。

b) Azure AI Foundry哪些功能落地效果较好？

  • 当前表现较好的功能主要包括：
  1. 企业级Agent开发套件。
  2. 多模型路由引擎。
  3. 与FDE前线交付体系的打通。
  • 年消费超过10万美元的中大型客户占比已由48%提升至62%，反映高价值客户的消费深度有所提高。
  • Azure OpenAI Service客户覆盖已超过85%的财富500强企业。
  • 单季度新增付费客户约1,100—1,200家，其中约60%来自金融、制造和医疗等传统行业，表明AI正在向垂直行业加速渗透。

c) 企业AI是否已从POC转向正式部署？

  • 整体趋势已经从早期概念验证逐步转向生产级部署。
  • 不过，专家目前主要掌握平台营收和客户采购数据，尚未系统跟踪不同场景的实际调用分布。
  • 对客服、内部文档、工作流等场景的批量部署规模、ROI和模型调用结构，暂时没有可量化数据。
  • 当前微软更多提供模型、平台及工具链，具体场景通常由客户自行接入和决定。

6. Microsoft Copilot商业化进展

a) Copilot当前付费席位和增长情况如何？

  • Copilot付费席位达到3,750万。
  • 单季度新增付费席位约750万，环比增长约25%。
  • 新增席位来源结构：
  1. 约70%来自存量客户扩容。
  2. 约30%来自中小企业新客户。
  • 头部企业平均席位覆盖率由35%提高至52%，说明增长主要来自大型客户扩大员工覆盖范围。

b) Copilot的实际成交价格是多少？

  • 面向中小企业的Copilot Business促销价为每用户每月18美元，预计至少维持至本年年底。
  • 企业版挂牌价为每用户每月30美元，但批量采购后实际成交价通常为：
  1. 每用户每月22—28美元。
  2. 平均成交价为24美元以上，接近25美元。
  • 企业客户实际折扣幅度取决于采购规模和合同条件。

c) Copilot Home的上线和收入贡献节奏如何？

  • Copilot Home已经正式发布，并于10月开始向所有付费用户批量推送。
  • 部分存量客户预计在10月至11月完成全员部署，12月正式启用。
  • Copilot席位使用率预计由10月的45%提升至60%以上。
  • 该产品部署正在配合企业第四季度IT预算落地，短期收入增量主要来自存量客户扩容和使用率提升。

d) Copilot Code的部署进展如何？

  • Copilot Code主要面向企业开发者群体，部署门槛较低，客户接受度较高。
  • 目前主要通过大型企业研发部门进行渗透。
  • 本季度企业版激活率预计可达到60%以上。
  • 部分功能可在本季度开放，但全面开放预计要到下一年度。
  • 核心功能包括：
  1. 代码生成。
  2. 调试。
  3. 架构重构。
  4. 项目脚手架。
  5. API集成。
  6. 自然语言驱动应用开发。

e) Autopilot的商用进展如何？

  • Autopilot目前仍处于预览阶段，第四季度将扩大预览客户范围，但不会形成规模收入。
  • 产品定位为自动化工作流智能体，可跨客户内部系统和应用执行长周期任务。
  • 主要应用方向包括：
  1. 报告生成。
  2. 数据同步。
  3. 合规检查。
  4. 客户跟进。
  5. 流程自动推进。
  • 全面商用和功能落地预计在2027年上半年完成，具体时间可能在Q1末至Q2之间。
  • 目前尚未形成任务成功率、客户满意度及规模化ROI等数据，仍需等待后续客户预览反馈。

f) Copilot如何向客户展示实际价值？

  • Copilot Home重点覆盖：
  1. 文档创作。
  2. 数据分析。
  3. 会议辅助。
  4. 邮件处理。
  5. 信息检索。
  6. 重点信息提取和AI总结。
  • 产品已深度集成Office和Teams，使客户可以在原有工作环境中直接调用AI能力。
  • 微软会根据内部应用测试向客户展示效率提升和潜在人力节省，但目前尚未披露统一的成功率或满意度指标。

7. 产品开源与新一代Copilot规划

a) 新一代Copilot是否会开放部分源代码或能力？

  • 微软计划从新一代Copilot中拆解部分核心模块并纳入开源内容。
  • 初步涉及Copilot Home、Code及相关能力，但具体发布渠道尚未明确。
  • 技术文档预计在本月同步推出，开源工作刚刚启动。
  • 相关内容计划于第四季度完成梳理，预计10月底推出初阶版本，后续仍可能根据技术和业务沟通进行调整。
  • 该项工作主要由技术部门主导，目前仍处于早期阶段。

8. 中长期增长逻辑与行业布局

a) Core Azure的高增长能够持续多久？

  • 微软内部判断，非AI核心云业务在企业云迁移、混合云和安全需求带动下，增长趋势可持续至2028年。
  • 2028年后，随着核心市场逐渐成熟，增速可能进入相对平稳阶段。
  • 由于核心系统迁移后切换成本较高，客户留存和收入稳定性预计仍将保持较高水平。
  • AI业务也会反向带动计算、存储、数据库和安全等非AI基础设施需求。

b) Azure AI的高增长周期能够持续多久？

  • 内部预计AI市场至少在2030年前仍处于增长阶段。
  • 不同阶段的核心驱动力为：
  1. 至2028年，多模态模型将是AI业务的主要增长引擎。
  2. 2028年至2030年，Copilot及智能体类服务将逐步成为推荐、应用和收入增长的主力。
  3. 2030年以后，需要观察是否出现新的技术和产品增长点。
  • 政府、教育、国防和公共事业客户一旦完成部署，合同期限长、稳定性高，有望成为2030年后的收入基本盘。

c) 未来重点客户和行业有哪些？

  • 科技、互联网及AI原生客户
  1. OpenAI为最大客户。
  2. 其他客户包括Anthropic及相关生态厂商。
  3. 互联网和SaaS客户包括字节跳动海外业务、Salesforce、Adobe、Spotify和PayPal等。
  4. 游戏和数字内容客户包括动视暴雪、育碧等。
  5. 该类客户需求增长较快，但波动相对较大。
  • 金融服务业
  1. 金融行业贡献接近Azure总营收的19%。
  2. 大型金融客户单客年消费约为全行业平均水平的2.6倍。
  3. 代表客户包括摩根大通、高盛、美国银行、汇丰银行、安联保险和贝莱德等。
  4. 金融是Azure传统企业级市场中价值最高的行业之一。
  • 高端制造业
  1. 是当前增长最快的传统行业之一。
  2. 也是下一年度重点突破的赛道。
  3. 代表客户包括西门子、博世、奔驰和宝马等。
  • 医疗健康行业
  1. 客户价值、信任度和留存率较高。
  2. 是下一年度重点拓展方向。
  3. 代表客户包括诺和诺德、辉瑞、罗氏和强生等。
  • 政府及公共部门
  1. 预计在2028年至2030年成为重点拓展对象。
  2. 覆盖联邦及地方政府、公共事业、教育和国防机构。
  3. 采购周期和合同期限较长，客户流失率较低，有利于形成稳定收入。

9. FDE前线交付体系

a) FDE目前承担什么职能？

  • FDE的定位是通过前线工程和交付能力，帮助客户将底层算力、中间件平台和上层模型连接成完整的AI解决方案。
  • 其潜在价值包括：
  1. 推动行业解决方案落地。
  2. 提升企业AI工程化能力。
