摘要

  1. 利润超预期后三地股价为何仍下跌；
  2. 美股花钱方、收钱方与链条外公司的定价差异；
  3. A股光通信公司的现金使用与扩产方向；
  4. 港股应收与回款如何影响估值。

3Q26业绩期里，亚马逊营业利润率创历史新高，Meta净利润增长264%，中际旭创前三季度归母净利润增长两倍多，股价却都在财报后下跌。同一周，微软同样大举花钱，还发了九年来第一笔美元债，股价反而上涨。利润表上的成绩都不差，股价反应却分化得厉害。三地市场到底在用什么标准定价？

一、利润超预期为什么不再值钱

先看几个反常的样本。

→ 亚马逊：3Q26营业利润率13.9%，创历史新高；AWS增速39.3%，为近五年最快。但过去十二个月自由现金流从去年同期的+147.9亿美元变成-423.6亿美元。股价在常规交易中跌4.25%，财报后盘后再跌6.11%，相对前一日收盘累计约10%，次日盘前跌近7%。

→ Alphabet：单季自由现金流-90.65亿美元，10月29日股价跌12.64%，单日市值蒸发约5,000亿美元。

→ Meta：单季自由现金流在上市十四年来首次转负，前三季度回购从262亿美元降到零，5年期CDS升到119.3bp的历史高点。

再看反例。微软FY27一季度经营现金流580亿美元，扣掉394亿美元现金资本开支后，自由现金流仍有+186.3亿美元。它在10月29日发行了九年来第一笔美元债，规模250亿美元，订单峰值1,150亿美元，超额认购4.6倍。财报后股价盘后却上涨超过3%。

同一周，同样大举花钱、同样发债，为什么有的公司被卖、有的被买？本文的解释是，市场在重新给三样东西定价：

→ 融资依赖度：钱是自己赚的，还是借来的；

→ 再投资的回收期限：投下去的钱多久能回来；

→ 收入变现的确定性：收入能不能变成现金。

这里的“投”既包括资本开支，也包括存货、应收等营运资金。两者的回收节奏不同：营运资金按季度周转，资本开支按年回收，所以市场对两者的容忍度也不同。这个框架只适用于再投资规模大的公司。Shopify的资本开支约占营收0.05%，苹果把当季经营现金流几乎全部返还给股东，这类公司的股价主要由成本和增长决定，见第四节。

用“花钱方、收钱方、借钱方”三种角色来看AI产业链，可以把三地的反应放进同一个框架。花钱方是云厂和终端厂；收钱方是芯片、存储、光模块等供应商；借钱方是靠举债或股权融资来支撑投入的公司，一家公司可以同时扮演几种角色。此前的判断是，风险会沿着“账单”在这些角色之间传递，3Q26的反应提供了一批验证样本：

→ 美股在罚看不到回收期的借钱方；

→ A股在罚把钱投向技术快速迭代环节的收钱方；

→ 港股在罚收不回钱的收钱方。

三地表面上各有各的逻辑，底层是同一个问题：现金从哪来、何时回来、谁在垫资。下文逐一展开。

二、美股：市场罚的不是发债，而是看不到回收期的现金缺口

发债本身不是问题

如果市场真的嫌弃发债，微软发了250亿美元的债，股价不该上涨。把谷歌、微软、甲骨文放在一起比较，差别不在发不发债，而在于有没有讲清楚钱什么时候回来。

→ Alphabet：三季度资本开支513.6亿美元，其实低于预期。真正超预期的是自由现金流缺口：市场原本只准备看到约27亿美元的缺口，结果看到的是90亿美元以上。

→ 微软：公司把这次融资定义为“可选项而非迫切需求”，市场也把它理解为财务纪律，而不是缺钱的信号。

→ 甲骨文：公司给出了时间表，FY27–28是投资高峰，FY29自由现金流不低于300亿美元，2030财年前的外部融资上限定为200亿美元。股价反涨12%，5年期CDS基差收窄到约24bp。

三家花的钱都不少，区别在于有没有给出“钱什么时候回来”的答案。

借钱方的风险正在外溢

亚马逊是借钱方的典型。三季度单季资本开支772.6亿美元，是当季424亿美元经营现金流的1.8倍。长期债务从2025年底的656亿美元升到1,731亿美元，首次超过1,142亿美元的现金及有价证券。

Meta走得更远：

→ 10-Q披露的未来支出承诺共8,250亿美元，其中3,557亿美元是未入表租约，4,545亿美元是不可撤销采购合同，其余约148亿美元为其他承诺；

→ 继550亿美元发债之后，又推出总额975亿美元的股权融资计划：250亿美元A类普通股、125亿美元强制可转换优先股，另有最高600亿美元C类无投票权股的ATM额度，预计2027年一季度启动；

→ 11月2–3日又向美元和欧元市场询价，计划发行至少200亿美元新债，这是它第一次发欧元债。

信用市场的反应比股市更早。博通5年期CDS升到175.4bp，创历史新高；英伟达CDS升到127bp，首次高于Meta，与CoreWeave的相关系数达到0.80。这说明风险已经开始从借钱方传给收钱方：客户靠借钱付账，供应商的信用风险也会跟着上升。

收钱方：SK海力士的现金转化率低，不等于质量差

SK海力士就是被牵连的收钱方。不过它的现金流数据很容易被误读，需要拆开看。三季度营业利润83.33万亿韩元，营业利润率80%；经营现金流只有54.80万亿韩元，转化率65.8%；自由现金流占收入比从二季度的69%降到40%。

转化率下降的原因可以拆成两部分：

→ EBITDA与经营现金流之间约32.9万亿韩元的差额里，约四成是收入扩张带来的营运资金占用；其余大概率是上半年预缴的法人税。

→ 应收周转天数从一季度的58天降到三季度的52天，说明应收增加是因为收入在增长，而不是放松了账期。

所以，转化率低不等于质量差。市场把它的远期市盈率压到3.3–4倍、股价较6月高点腰斩，定价的其实是以下三件事：

  1. 五年长约只锁量，不锁价，也不锁现金，14家长约客户的押金还没有出现在资产负债表上。
  2. 四季度资本开支环比增40%，达到16–18万亿韩元，2027年还要“显著增加”；Solidigm取消上市后，资金需求只能由母公司承担。
  3. 最根本的一点：下游云厂自己在靠发债付账，这种付款能力能维持多久。

如果“现金缺口挨罚”的逻辑成立，那么现金越好的收钱方应该越受市场奖励。11月3日公布业绩的三家收钱方，给出的答案恰好相反。

Astera Labs：现金最好，股价基本不动

Astera Labs为AI服务器和机柜做互联芯片，产品包括PCIe/CXL重定时器和Scorpio交换芯片。三季度业绩如下：

→ 营收5.85亿美元，环比增长49%，同比增长154%，比一致预期高约6%；

→ GAAP毛利率72.3%；

→ 经营现金流3.42亿美元，相当于营收的58%、GAAP净利润的1.9倍；

→ Scorpio X系列年化收入超过10亿美元；

→ 四季度营收指引7.3亿–7.5亿美元，中值环比再增27%。

它没有营运资金缺口，也不需要补贴客户，现金质量明显好于下文的超微电脑和AMD。但电话会后，股价在盘后小跌0.3%。盘后数据还不能作为定论，但方向和SK海力士一致：市场不再为高毛利收钱方的超预期付溢价，更关心72%左右的毛利率能维持多久。

超微电脑：经营现金流为负，股价反而上涨

超微电脑FY27一季度营收199亿美元，约为上年同期的4倍；净利润15.94亿美元，经营现金流却是-4.34亿美元。存货一个季度内从129亿美元增至151亿美元。公司6月已经通过普通股、7%强制可转换优先股和ATM额度融资，融资组合和Meta相同。管理层明确表示，这笔钱用于支撑在手订单所需的营运资金。按本文的分类，它既是收钱方，也是借钱方，股价却在盘后一度上涨8%。

为什么现金流为负，市场还愿意奖励？有三个原因：

  1. 一季度营收10月20日已经预告，这次的新信息是指引。二季度营收指引中值比一致预期高约20%，全年指引上调到720亿–820亿美元。
  2. 缺口几乎全是营运资金，资本开支只占营收的约0.2%。存货对应未来一两个季度的交付，公司还给出了现金转换周期的控制区间。
  3. 这类缺口按季度周转，回收路径算得出来，和数据中心按年计算的回收期是两回事。

AMD：用自己的股票补贴客户，股价照样上涨

AMD三季度营收133.8亿美元，同比增长45%，数据中心收入同比增长97%。四季度营收指引170亿美元（±3%），中值比FactSet一致预期约163亿美元高约4%，同比增长约66%。股价盘后上涨6%至9%，其中除了超跌反弹的成分，和超微电脑一样，市场奖励的主要是未来收入。

AMD和超微电脑的不同之处在于，它的报表记下了“给客户融资”的成本。

→ 金额：现金流量表加回了11.79亿美元“向客户发行认股权证的非现金影响”，上年同期为零，规模约为当季营收的9%。

→ 会计处理：其中10.97亿美元是认股权证负债的公允价值变动。公司说明，这笔重估主要随AMD股价变动，记在营业外，并在非GAAP口径中剔除。也就是说，GAAP每股收益1.46美元扣掉了这笔费用，非GAAP每股收益2.09美元没有扣。

从时间上看，它对应2025年10月与OpenAI签订的认股权证安排：

→ 最多1.6亿股，约为当时总股本的10%；

→ 行权价每股0.01美元；

→ 随部署进度和AMD股价目标分批归属；

→ MI450和Helios机架9月开始量产出货。

这笔钱没有流出现金，但已经从GAAP利润里扣掉，最终由现有股东以潜在摊薄的形式承担。而且它的规模跟着AMD自己的股价走：股价越涨，需要重估的负债越大。前文用博通、英伟达的CDS说明风险从借钱方传给了收钱方，AMD的认股权证则让这种传导在收钱方的GAAP利润表里有了具体金额。

AMD的现金流也在变薄：

→ 三季度经营现金流12.02亿美元，只占营收的9%，低于上年同期持续经营口径的17.88亿美元；扣除6.48亿美元资本开支后，自由现金流约5.5亿美元。

→ 存货和应收分别占用29.95亿美元、19.28亿美元现金，应付账款增加23.13亿美元，抵消了一部分。

→ 存货114.6亿美元、应收账款92.1亿美元，较2025年末都增长约45%，与营收增速相当。第三方测算的存货周转天数为169天，比五年均值多24天。

不过，四季度指引环比增长27%，这批存货对应下个季度的交付，暂时仍可以按“季度周转”来理解。

小结：市场惩罚的是没有回收时间表的长期缺口

把六家公司放在一起看，“现金缺口挨罚”这句话需要加上限定条件。存货、应收这类营运资金缺口按季度周转，回收路径算得出来，市场可以容忍，例子是超微电脑和AMD。数据中心这类资本开支按年回收，而且还在扩大，市场会惩罚，例子是Meta。

风险确实在从借钱方传给收钱方，但收钱方要分三层看：

→ 高毛利零部件商，面临利润率回落（SK海力士、Astera Labs）；

→ 低毛利整机厂，承担营运资金和客户信用风险（超微电脑）；

→ 芯片商用自己的股票补贴客户，代价由股东以潜在摊薄承担（AMD）。

在板块层面，股市已经开始给这种传导定价。10月费城半导体指数下跌15.4%，背景是市场担心AI基建靠大规模举债推进，投入未必有回报。但到了个股财报日，前瞻指引仍然比现金质量更重要。

三、A股：有现金不够，关键看钱投向哪里、多久能收回

旭创535亿元现金为什么换不来溢价

先看中际旭创的例子。期末货币资金535.32亿元，比年初增长387%。但这笔钱不是经营赚来的：三季度“吸收投资收到的现金”527.12亿元，主要来自7月30日港股IPO的募资。所以问题不在于有没有钱，而在于钱从哪来、怎么花、市场怎么看。拆成三笔账更清楚。

第一笔账：经营能不能自己造血。前三季度净利润240.95亿元，经营现金流只有80.08亿元，转化率约三分之一。存货从126.81亿元涨到238.78亿元，应收从62.77亿元涨到173.09亿元，合同负债却只有0.11亿元。订单已经排到2027/28年，但客户预付款几乎为零，锁料备货基本靠公司垫资。这说明订单可见度高，不等于客户愿意替供应链出资。

第二笔账：钱怎么花。

→ 三季度购建长期资产付现43.59亿元，对外投资净流出12.42亿元，回购约49.97亿元；527亿元募资到账三个月，只用了约两成。

→ 募资产生的利息约1.36亿元，港元汇兑却亏了约3.9亿元。前三季度汇兑损失13.87亿元，占利润总额的5%。

第三笔账：价格信号。H股发行价980港元，折合约839元人民币；9月A股回购均价约884元；11月2日A股报550元，三个交易日累计跌13.58%。市场价比公司自己的回购价低约38%，比H股发行价低约34%，差了三成多到近四成。公司自己买卖的价格和市场价之间差距这么大，说明市场对这笔现金的用途有很大顾虑。

市场担心的是技术路线

市场不给这笔现金溢价，最大的变量是技术路线。

→ 10月21日，英伟达宣布联合矽品，在2027年中把CPO光引擎产能提升15倍。

→ 11月2日，Marvell以1,150亿美元企业价值、全股票方式收购Lumentum，预计2028年上半年交割。上游光芯片龙头直接进入光引擎环节。

买方担心的不是中际旭创没钱扩产，而是每年上百亿元的资本开支投进传统可插拔产线，到了1.6T/3.2T和CPO时代会变成折旧负担。

另外两个因素也要算进去：

→ 杠杆资金：融资余额较峰值降了43%，但融资密度升到3.63%；10月15日单日融资买入14.93亿元，居全A第一。部分回撤是杠杆资金换手，而不是基本面重估。

→ 政策风险：公司已被列入美国国防部1260H清单，2027年6月30日起间接采购禁令生效；海外收入占比94.8%，政策风险带来估值折价。

长飞和源杰：资本开支方向决定高毛利能维持多久

长飞光纤和源杰科技的分化，说明同一个逻辑在上游同样适用。两家都缺产能，但缺的是两类不同的东西：

→ 光纤缺的是光棒产能。这是产能约束型稀缺，新建产线需要18–24个月，供给响应慢。

→ 光芯片缺的是通过验证的国产高速光源。这是时间窗口型稀缺，一旦竞争对手通过验证，稀缺性就会下降。

所以，决定高利润能否持续的，是资本开支方向，而不是当期毛利率。三季报的反差正好说明这一点。长飞单季毛利率从二季度的60.5%回落到57.4%，源杰从82.1%升到83.4%。但源杰10月单月跌超50%，长飞11月2日涨停。毛利率走势和股价走势正好相反，说明市场在提前给“高毛利难持续”定价。

两家的资本开支也呈现出相反的组合：

→ 长飞在收获：前三季度购建长期资产13.95亿元，只占收入的7.3%；在建工程从15.57亿元降到8.54亿元；交易性金融资产从16.83亿元增到38.77亿元；合同负债从6.32亿元增到9.49亿元；内生自由现金流为+32亿元。

→ 源杰在下注：购建长期资产10.53亿元，占收入的65%，超过8.63亿元的经营现金流；借款从零变成短期借款1.58亿元加长期借款3.88亿元。

两家单季ROE几乎相同，估值的巨大差距来自市场对两种稀缺能维持多久的不同判断。

光通信之外的旁证

宁德时代三季度单季资本开支171亿元，存货1,448亿元，经营现金流下降94%至14.1亿元，财报次日A/H股双双跌超10%。同期，紫金矿业、中国海油、中国神华、长鑫科技等六家前三季度自由现金流超过500亿元的龙头稳步走高。从这些案例看，资金的取向相当一致：扩产强度高于经营现金流的中游公司被抛售，供给响应慢、资本开支克制的上游公司更受青睐。

与超微电脑对照：营运资金压力会放大抛售，但不足以单独引发抛售

把超微电脑和中际旭创放在一起看，也支持本节的判断。中际旭创的缺口有一部分是面临CPO换代的产线，超微电脑的缺口几乎全是按季度周转的存货。但不能因此认为“占用营运资金就会挨罚”：超微电脑经营现金流为负，股价照样上涨。更准确来说，营运资金压力会放大抛售，但单靠它不足以引发抛售。当然两地的信息披露制度、杠杆资金和政策风险也不一样，这组对比只能作为旁证。

四、链条之外：现金流充裕的公司为什么也会跌

前三节讨论的都是AI投入链条上的公司。如果“看不到回收期的现金缺口挨罚”是普遍规律，那么现金流充裕、没有缺口的公司应该被奖励。11月2日至3日公布业绩的苹果和Shopify提供了检验：苹果不为AI举债，也不赚AI基建的钱；Shopify几乎没有资本开支。两家现金流都很充裕，股价却都下跌。这正好划出了本文框架的适用范围。

苹果：替AI付存储账单

苹果FY26四季度截至2026年9月26日，业绩如下：

→ 营收1,145亿美元，同比增长12%，高于约10%的指引中值，也高于约1,135亿美元的一致预期；

→ 每股收益2.10美元，高于约2.00美元的预期；

→ 当季经营现金流281亿美元，向股东返还280亿美元。

股价在发布前当天已跌1.8%，电话会后盘后又跌2.8%。问题主要出在成本：

→ 47.9%的毛利率里含约1个百分点的关税退款，剔除后约46.9%，低于上季给出的47.5%指引中值。

→ 上一季，时任CEO库克把存储涨价形容为“百年一遇的洪水”。

→ 本季iPhone收入576亿美元，在供给受限的情况下仍增长17%；大中华区收入则低于预期。

放回本文的框架：SK海力士80%的营业利润率，有一部分来自苹果这类终端厂支付的存储账单。也就是说，收钱方的高毛利不只由AI花钱方买单，终端厂也在付。终端厂能否把涨价转嫁给消费者，决定了这部分利润能维持多久。

Shopify：资本开支只有200万美元，照样被罚

Shopify 11月3日盘前公布三季度业绩：

→ GMV 1,191亿美元，同比增长29.5%；

→ 营收37.4亿美元，增长32%，与一致预期持平；

→ 每股收益0.49美元，略高于0.47美元的预期；

→ 资本开支200万美元，自由现金流8.16亿美元，自由现金流率22%。

这是“没有现金缺口”的极端样本，但股价当天下跌约8.7%。市场看的是增长质量：

→ 毛利只增长28%，比营收慢4个百分点。原因是毛利率较低的商家解决方案收入增长35%，快于毛利率79%的订阅收入（增长20%）。

→ 四季度指引延续了这个格局：营收增速30%出头，毛利增速接近30%，但仍低于营收增速。

→ 管理层表示，正在为AI能力和购物季基础设施加大投入（公司电话会）。

从股价反应看，市场更在意展望、投入计划和本来就很高的预期。对这类轻资产公司，现金流更像背景条件，而不是决定股价的变量。

小结：现金缺口只对花钱方是主要变量

把本季美股案例放在一起看，除Meta外，绩后股价反应和现金质量几乎相反。定价规则可以归纳为三条：

  1. 花钱方：市场惩罚看不到回收期的缺口（Meta）。
  2. 收钱方：市场奖励前瞻指引，暂时不惩罚营运资金占用和对客户的股票补贴（超微电脑、AMD）；但高毛利已经换不来溢价（Astera Labs）。
  3. 链条之外：现金流再强也保不住股价，市场看的是被抬高的成本（苹果）和放慢的毛利增速（Shopify）。

所以，“美股罚看不到回收期的现金缺口”只对重投入的花钱方成立。其他公司的股价跟着最大的那项预期差走，第二节分析Alphabet时用的也是这个方法。

五、港股：营收增长要看能不能收回现金

优必选：应收高企，回款跟着地方预算走

先说明时间口径：港股没有强制季报，下面的财务数据来自1H26中报，引用的股价表现主要发生在2026年10–11月。

优必选是港股这条逻辑最典型的案例。

→ 收入与亏损：上半年营收12.69亿元，同比翻倍；净亏损3.39亿元。

→ 应收：期末应收账款原值22.25亿元，相当于当期营收的175.3%；计提5.46亿元坏账后，净额16.80亿元，仍是营收的132.4%。

→ 账龄与减值：一年以上账龄7.67亿元，占34.45%；单期信用减值从130万元跳到9,107万。

回款慢有结构性原因：

→ 2025年10–12月的六笔数采中心订单约8.29亿元，占全年签约额近59%，全部有地方国资背景。

→ 302个人形机器人招采项目里，“其他一般企业”只有2个。

这意味着回款跟着地方预算节奏走，而不是跟着产品力走。8月公司把3.87亿港元未动用的配售款，从“产业投资”改为“向供应商付款”，上市以来已经六次配售。

对照组：同样做机器人，回款决定估值

同为人形机器人公司，宇树科技涨得多，原因不在产业位置，而在于能不能把产业位置变成现金。宇树科技上半年营收11.52亿元，应收仅1.20亿元，占营收的10.4%，盈利2.74亿元；前三季度归母净利3.87亿元。

港股硬科技里，类似的出清不止一家：

→ 黑芝麻智能：应收净额为营收的160.8%，周转246天，核数师对持续经营相关事项作出了提示。

→ 极智嘉：应收占营收的86.7%，股价较年初高点跌近70%。

消费和医药：同一条逻辑同样适用

如果“回款决定估值”只在硬科技里成立，它可能只是行业现象。消费和医药的案例说明，这条逻辑在港股更普遍。

反面案例：

→ 百威亚太：因印度国营渠道的逾期应收一次性计提3,000万美元拨备，三季度纯利腰斩，年内股价跌24.2%。

→ 巨子生物：618前向经销商压货上亿元，换来首份营收、净利双降的中报，股价自高点跌71%。

正面案例：

→ 农夫山泉：贸易应收周转只有4.5天，在手现金265亿元，派息111亿元，市值稳定在近5,000亿港元。

→ 珍酒李渡：取消打款压货考核，改为按真实开瓶即时返利，合同负债12.78亿元，是21家上市酒企里仅有的三家双增之一，并上调了全年指引。

→ 石药集团：上半年经营现金流45.35亿元，承诺2027–29年分红率不低于50%。

医药里有一条边界要说明。晶泰、英矽这类AI制药公司的远期BD里程碑款不是应收账款，不能叫“赊账”。但“一次性首付款占比多高、可复制的收入有多少”，问的是同一个问题：收入能不能稳定变成现金。

六、投资推论与跟踪指标

三地的推论

回到开头的问题：利润已经很好，市场为什么还在卖？三地的答案指向同一个方向，即市场在追问现金从哪来、何时回来、谁在垫资。落到投资上，推论如下。

美股。这套定价标准对看不到回收期的借钱方最不利。能自我造血、又给出回收时间表的公司相对受益：微软和甲骨文被奖励，是因为它们把不确定的资本开支变成了可以计算的回收期。收钱方的高毛利会在需求见顶之前就被打折，SK海力士的腰斩是预演，博通和英伟达CDS走阔是后续信号。第四节的案例也提醒，这个结论只对重投入的公司成立。

A股。中际旭创的估值修复，不取决于下一季利润，而取决于535亿元现金的使用纪律。如果继续投向可插拔产线，折旧负担会在2027–28年CPO放量时集中体现；如果转向上游光芯片或CPO相关能力，市场才可能重新定价。长飞式的“资本开支强度低、合同负债增长、在建工程下降”组合，是这轮重估里最经得起时间考验的资产特征。源杰的高毛利，要靠2027年前国产EML/CW光源的验证窗口来支撑；Marvell收购Lumentum可能带来的“去Lumentum化”需求，是它最重要的外部变量。

港股。应收/营收比、账龄迁徙率和配售频率，已经成为筛选硬科技和消费医药公司的通用指标。有真实回款、又有分红承诺的公司，会继续享有稀缺溢价；靠国资订单和配售维持的赊账式增长，出清还没结束。

跟踪指标

美股：四大云厂4Q26自由现金流是否继续为负；Meta 200亿美元新债的定价利差；SK海力士2027年一季度法人税清缴后现金流是否回升，长约押金是否入账。

A股：中际旭创年报的存货与应收周转、H股募资使用进度，以及CPO或上游方向的资本开支公告；Marvell-Lumentum交割进度对InP供需的影响；长飞合同负债和光棒产能释放节奏。

港股：优必选承诺的2026年四季度EBITDA转正能否兑现、一年以上账龄占比的变化、是否再次配售；消费医药公司下半年合同负债与销售收现比。

这些指标中任何一个出现拐点，都比下一季的利润增速更能说明市场的定价标准有没有改回去。
