核心摘要

  1. 专家认为 Azure 下季度 49–50% 增速有四个驱动：算力调度的工程效率、产品与平台变现结构、客户订单与合约结构，以及外部供给因素。
  2. GPU/CPU 异构动态路由已规模化上线，约 90% 的请求可在自研小模型、Claude、开源模型之间按时延、成本和质量调度，单位算力承载的 token 数环比提升约 30%。
  3. 一季度 capex 下调的主因是第三方新云 GPU 交付延迟，需求没有消失，这部分长期消耗型合同将在二到四季度逐步确认，第三方 GPU 交付预计 11 月中下旬开始增加。
  4. Foundry 一季度已有约 12 万家客户，多模型混合部署推动高毛利 PaaS 收入大增，管理层首次正式提出 AI OS 战略。
  5. M365 Copilot 可能从席位订阅转向席位打底加按 API token 计费，Agent 365 智能体数量一季度环比增长近 30%，带动每个付费席位的 Azure 后端消耗。
  6. RPO 一季度约 6770 亿美元，同比增长 70% 以上，加权周期两年多，约三分之一在 12 个月内确认，金融、医疗、政府、制造是大额长期合约的主力。
  7. Azure 经营利润率一季度同比下滑两个多百分点，结构性压力来自短折旧周期的高端 GPU、成本更高的第三方算力与 OpenAI 分成、高密度机柜电力冷却成本和合规本地化开支。
  8. 利润率的缓冲来自模型路由降本、高毛利 PaaS 占比提升和存量机柜利用率上升，降本的下一个关键是 Maia 300 在本财年下半年规模化部署。
  9. 专家提示美国可能收紧中国开源模型：联邦政府已禁止使用 Kimi 等模型，若民主党在中期选举大胜，政策可能直接全面禁止，客户项目部署周期会因此拉长。

正文

【以下为专家观点汇总，具体细节仅供参考。】

怎么看管理层指引Azure收入在Q4提速增长的核心driver？

F27 Q1 Azure的整体收入增长主要来自三个部分。第一，GPU资源利用率达到满负荷。第二，闲置的CPU资源被对外租赁，甚至出售。第三，token价格上涨。这是Q1最核心的三个增长驱动因素。但有一个影响因素，就是每年12月都有圣诞和新年假期，所以现在的压力主要集中在12月。预计大单的节奏会有优化空间，因为欧美那边到12月第二周，很多人就开始休假了。另外，今年（2026年）的目标最初定得比现在低，后来有所提升。不只是A公司，包括其他CSP，目标都有所上调。原因是大家都在努力满足最差三个月或投资者圈子的预期。

Q2的49-50%增速驱动主要有四个层面。

  • 第一，算力供给侧的工程效率提升。
  • 第二，产品和平台变现结构的进一步优化。
  • 第三，客户订单和合约结构的持续优化。
  • 第四，宏观层面及外部供给方的持续影响因素。

算力供给侧的工程效率提升具体是如何实现的？

主要是GPU和CPU的异构动态路由，比如自动化调度和融合调度。Q1时，自动模型路由已经实现规模化上线，90%的调度，包括API token请求，可以在自研小模型如GPT-6、Claude、开源模型之间进行调度，根据时延、成本和质量进行路由。在保证输出质量的前提下，推理调度和推理成本都在下降。原本闲置、低负载的通用GPU和CPU池被释放出来，用于承接POST TRAIN AGENT索引、RAG workload等任务，提高存量机柜的利用率，而不是单纯依赖新增高端GPU。

在调度层面，单位算力可承载的token数量环比提升了约30%。同时，Q1的capex下调了主要原因是第三方新云GPU交付延迟。在这种背景下，需要进一步缓解供给瓶颈，并将其直接转化为可承接客户消耗型收入，而不是被硬件卡住。

站在算力供给层面，Foundry的平台化非常关键。Foundry在Q1时已有12万家客户，增速表现良好。平台化叠加多模型混合部署，使得Q1 Foundry收入同比大幅增长，多模型客户数量也在快速增加。Foundry属于高毛利、高消耗弹性的PaaS，客户不再只使用OAI的模型，而是可以混合部署，包括自研和开源模型，如P1、P3等。

其实A公司的AI战略目标是打造AI OS，这次电话会上，管理层首次正式提到这个概念。平台化是核心，模型能力无论是一方还是三方的P1、P3，都不是重点，关键在于满足客户需求，实现多模型混合部署，包括自研、第三方和开源模型等。同时，合约模式也从一次性POC转向长期按TOKEN计费。管理层也明确提到Q2 Foundry扩容排期，包括区域数据中心上限，五大洲持续新增区域节点，将持续带来业绩增量和消耗性收入。

从第三方GPU的交付时序来看，二季度交付情况有所恢复。按照管理层原话，GPU效率的争议会抵消一部分推迟到下半年的第三方GPU合同。一部分原计划Q1、Q2上线的外部托管算力因供应链延后，但内部通过调度效率，将原本下半年释放的收入部分前置到Q2兑现。延后的第三方算力合同本身是长期大额消耗型订单，只是收入确认时点后移，需求并未消失，Q2、Q3、Q4会逐步释放。

第四个层面是存量资产的折旧曲线和算力资产结构进一步优化。算力资产正向短使用周期的GPU倾斜，折旧节奏更匹配AI模型迭代。同时，老旧几代的通用服务器和存储池持续进行密度升级，如单机存储扩容、网络带宽升级等，以提升单机柜收入密度，单位机柜ARPU进一步提升。

产品和平台变现结构的进一步优化的具体体现？

产品变现结构，主要包括分层定价和Copilot叠加用量消费，进一步提升Azure的ARPU。从商业模式看，A公司一直坚持AI和云的打包销售逻辑。SaaS目前的席位订阅模式正向席位打底、用量计费双轨模式转变。关于双轨模式，原计划2027年（FY28 H1）可能会出现Seats加API TOKEN的收费方式，但由于CAPS战略拐点和收入目标上调，管理层可能将M365和M365 Copilot的SaaS用量转为API TOKEN计费，目前内部还在讨论。

这种结构并非一次性订单冲击。无论是M365、Copilot Security、Copilot D36、Copilot GitHub等产品，配套的Azure后端消耗会持续上行。Copilot席位在M365中确认，但其推理、Agent编排、向量库RAG等后端算力运行在Azure上。随着Copilot付费席位持续渗透，Agent 365智能体数量扩张，Q1智能体环比增长近30%，突破数千万。每个付费席位带来的Azure消耗也在提升，除了席位ARPU，还要叠加算力ARPU。

产品变现结构的第二个驱动点是高端SKU产品，包括长上下文、高优先级算力溢价定价。高优先级推理、长上下文窗口、私有化部署，尤其是FDE（7月独立组建FDE部门），专属模型部署等，都是高溢价SKU，定价明显高于基础TOKEN调用。管理层等人在沟通中也提到，Q2高端付费T2占比将进一步提升，带动Azure收入增速，而不仅仅依赖低价基础TOKEN放量。

第三个点是行业垂直领域，无论是云加AI的整体布局，在这个领域出现的一个苗头或迹象，从Q1开始分析，一些大额的长期承诺订单正在陆续落地和确认。也就是说，无论是之前提到的go back to essential plus one，还是AI行业的T1、T2、T3层，目前主要集中在金融、医疗、政府、制造这几个部门。这些部门在长期定制化AI，即FDE入场的方式下，定制化的AI加云合约，基本上都是承诺用量加上接期用量的模式。相当一部分在F26下半年签署的RPO或剩余部分，将在F27的Q2进入收入确认周期。在RPO层面，一季度大约是6770，同比增长70%以上，环比基本持平。加权周期大约是两年多，其中约三分之一在12个月内确认。Q2也是这一批大额企业承诺集中确认的窗口之一。从A公司的seasonality角度看，Q2的体量通常大于Q4。因此，从RPO履约落地的角度，这也是一个核心贡献点。

客户订单和合约结构的持续优化指的是什么？

首先，客户结构方面，越来越多的头部大客户，其云加AI预算结构正在逐步向AI算力层转移。内部做过评估，相信他们是找了MDB或BIG FOUR中的一家进行的。全球500强企业中，约30%计划加速AI加公有云的支出，而传统的IaaS，比如VIRTUAL MACHINE上的存储迁移节奏相对稳健。新增AI预算叠加，形成存量迁移和新增AI抓手的双重增量。对于高利润、高毛利的IaaS形成了稳定的底盘。Friendly AI推理等则是增量的加速器。同时，混合云、私有云和安全领域，专属及FD专属集群订单交付正在加速。相当一部分如FSI、医疗及高监管敏感行业的客户，会选择I式专属集群进行进一步隔离部署。

在开源模型方面，包括对标美国几家IaaS百大客户目前仍以闭源为核心。对于开源，他们并非不想用或不用，但有一个点需要关注。由于中期选举刚开始，大概率蓝方会胜出。众参院一直有声音，尚未落地的政策是美国政府可能会对中国所有开源模型一刀切。上周美国联邦政府已发文，联邦政府及部分机构不允许使用中国如KIMI这类开源模型。在这个层面上，意味着客户项目的部署周期相对拉长，但单项目金额会更大。Q2有部分前期签约的专属集群完成机房上架、联通并开始正式计费，这也带动了相应基数的提升。第三个小点是区域均衡性的平衡和增长。北美市场依然是最大市场，也是增速主力军。除北美外，欧洲、亚太中的亲美国家及中东新增区域节点陆续上线，本地数据主权合规驱动下，客户AI workload可以留存在本地，Azure不再全部跑北美大区。针对非北美区域，即EMEA和亚太中亲美国家，增速有望进一步提升，分散单一区域的周期波动，对整体有一定助力作用。

持续性和基数方面，从新财报口径下的ASR收入确认来看，F26按新财报口径，上财年Q1为223亿多，接近224亿，Q2为241亿。因此，按seasonality逻辑，Q2应为全年最大，但实际上去年（2025年）F26的Q2并不高，基数不算极端高，相较Q4压力更小。同时需要提示的是，Q2之后，下半年增速可能会有所调整，甚至逐步提升也是有可能的。汇率方面，指引假设的汇率影响较小，固定汇率增速与报告美元口径的增速差距在一个百分点以内，不会大幅影响增速。

在这个逻辑下，内部算力调整和工程效率提升的影响大于AI口拍agent后端的Azure消耗及Foundry的PaaS方量，再大于长期企业RPU合约确认，进一步大于区域扩容和混合多云安全保障。第三方交付延迟属于供给侧扰动，但并不完全影响需求。这些基本上是Q2最核心的key driver。

美国政府可能的一刀切国产开源模型只是指政府和公共事业部门，还是所有企业都会受到影响？

其实现在已经有一些苗头了。比如之前kimi那边，美国联邦政府已经不允许使用了。现在关键要看这两天中期选举的结果。如果红方胜，也就是共和党赢，川普继续占据众参院的大部分席位，按照川普和众参院的风格，他们会采取逐步切割的方式。如果蓝方胜，也就是民主党上台，有可能会直接全面禁止。原因在于OAI和Anthropic等核心模型厂商一直在呼吁，认为中国的开源模型影响了他们的模型能力、售价、议价权和护城河，甚至影响了整个金融市场。民主党本身推行精英政策，如果这次众参院大胜，政策的节奏和力度会比红方胜或两党平衡时要强得多。所以目前还不能确定是否会一刀切，但至少可能会陆续对中国如kimi等开源模型一步步收紧。当然，从A公司的角度，其实是保持中立的，既欢迎开源，也做闭源。

Azure的OPM在Q3水平？主要的动力和利润率压力来源？

目前来看，Q1的OPM大约同比下滑了两个多百分点，环比下滑了一个多百分点。需要强调的是，新财报口径下的A&I的OPM要比这个高，因为A&I包括了毛利较高的M365业务，所以不能直接用A&I财报部分的利润来代表Azure部分。I市的成本结构中，比如GPU折旧、OI的第三方供应商分成、数据中心电力、冷却、硬件维保等，这些在成本中的占比远高于SaaS业务，因此其利润率天然更低。随着AI算力占比提升，利润率会持续承压。

Q1 OPM提升的正向因素主要有：第一，算力调度效率提升，模型路由降本，单位token的边际成本有所下降，但幅度不大。目前总部寄希望于下个日历年，也就是本财年下半年的Maia 300开始规模化部署，完成集群化测试和部署，集群规模在万卡、万美以上。这样边际成本会进一步下降，目前Maia 200已经部分规模化，成本也在下调。第二，Auto Fusion的调度在Q1实现了小到大规模的落地，高优先级请求走高端NVIDIA卡，低优先级检索摘要、简单Agent切换到闲置CPU和低成本开源模型，推理成本下降，提升了增量边际贡献，对冲了部分硬件折旧。这也是电话会一直强调的效率缓冲垫，是收入增长但利润没有大幅下滑的核心原因。第三，收入结构向高毛利的PaaS倾斜，比如Foundry、模型服务等，而低毛利的裸金属租赁相对稳定，没有大幅增长。裸金属租赁毛利最低，而模型编排、向量数据库、Agent平台、安全AI等增值服务毛利更高，Q1这些部分增长较好，优化了H的收入结构。第四，存量机柜负载率提升，摊薄了折旧、电力、机房租金等固定成本。一季度新增GPU交付延期，存量集群利用率进一步提升，固定成本分摊到更多收入，单位固定成本下降。长期大额履约订单占比提升，这类客户折扣更低，收入可预测性更强，坏账和竞价折扣损耗更小。这些都是拉高OPM的核心因素。

而拉低OPM的主导因素是算力资产结构转向高成本。短折旧周期的GPU资产，其实在本季度的披露中也有提及，大量新增的资产都是高端GPU，折旧年限比传统服务器更短。季度折旧费用持续上升，即使capex因交付延期低于451亿元，但已上线的GPU资产折旧依然在爬坡。这是结构性的压力，并非短期或单点的波动。第二个方面，第三方GPU和外部算力采购的上行和延迟，一部分客户需求通过外包给第三方算力伙伴获取GPU，这部分收入的成本相对较高，增量收入的边际利润低于自有算力。同时，OAI模型调用的分成成本也会随着token消耗上升。第三个方面，电力和冷却基础设施运维成本上升，尤其是高密度AI机柜的PUE优化进入瓶颈期。高密度GPU集群的散热和供电成本显著高于传统云，PUE难以持续下降。能源扩张或电力短缺压缩了硬件层的毛利。第四个方面，分摊费用进一步上升，无论是Azure专属AI研发、合规、安全、现场运维团队扩编，还是销售费用分摊，随着业务快速增长，这些费用也在同步提升。对于政府、金融、医疗等高合规、高认证、需要高隔离集群运维的行业，带来更多OPEX成本。还有一个因素是短期供给错配，为了抢交付部分紧急算力，采购成本偏高，相当于临时补缺。由于第三方交期延后，对于重点区域和大客户，临时采购算力时只能按现货价格进行，这也加大了成本压力。

怎么判断Q4 Azure的OPM趋势和主要driver？

首先，高折旧的GPU资产开始转入在用，折旧费用环比进一步提升。Q1的capex偏低是因为交付延迟，并非取消订单。Q2开始，延后的GPU、内存、存储等批量到货，上架资产负债表，短期高折旧资产进一步增加。折旧属于刚性成本，滞后于资本支出。

第二，第三方GPU交付在Q2后半段（11月中下旬）开始增加，这部分增量收入的边际利润率较低，因为延后的算力合同在下半年逐步释放，Q2开始确认。但新增外部算力收入释放较慢。

第三，收入结构中AI算力占比进一步提升，传统高毛利的IaaS和PaaS占比下降。Azure AI占比略提升。这意味着低利润的AI层面比重提升。

第四，合规和本地化成本增加，无论是欧洲DSA数据主权、数据驻留，中东、亚太本地机房配套，还是合规审计，都进一步增加了固定成本分摊。新区域上线初期，负载爬坡、利用率偏低，也会在短期内拖累利润率。
