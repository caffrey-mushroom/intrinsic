1. 产品布局与芯片路线

a) 公司未来的核心产品布局是什么？

  • 公司未来将形成“主控SoC+AI协处理器”的双轨产品布局。
  • 主控SoC路线
  1. 现阶段重点产品包括RK3588、RK3576、RK3572等8纳米芯片。
  2. 下一代产品包括6纳米RK3668和4纳米RK3688，产品支持能力、算力及价格带将持续提升。
  3. 下一代高端芯片从流片、研发验证到客户量产通常需要半年至一年以上，预计主要在2028年进入放量阶段。
  • AI协处理器路线
  1. 已推出RK1828、RK1820，后续将推出RK1860及更高阶产品。
  2. 产品主要用于专用模型和通用端侧大模型部署，覆盖AI NAS、AI电视、机器人、会议教育大屏、AI PC及AI手机等场景。
  3. 公司希望通过协处理器补充主控芯片的AI算力，形成面向AIoT终端的完整方案。

b) RK3588目前的定位、价格和应用情况如何？

  • RK3588是当前旗舰主控芯片，单价维持在40多美元，价格整体较为稳定。
  • 主要应用场景包括：
  1. 车载智能座舱；
  2. ARM生态服务器；
  3. 会议教育大屏；
  4. AI NAS；
  5. 机器人“小脑”；
  6. 机器人数据采集设备。
  • RK3588目前贡献公司约25%-30%的收入，是第一大单品。
  • 相关业务仍在增长，预计至少还有数十个百分点的增长空间。
  • 公司认为RK3588在CPU、GPU、NPU工具链、行业生态和客户覆盖方面具有综合优势，短期内竞争壁垒仍然较强。

c) RK3576今年为何快速增长？

  • RK3576是公司的次旗舰芯片，当前定价约16美元。
  • 去年出货量不足200万颗，今年预计达到600万-700万颗，是今年增速最快的主控产品之一。
  • 主要应用于：
  1. 割草机器人；
  2. 广告机；
  3. 会议教育大屏；
  4. 小米汽车后舱电视及投影设备；
  5. 上汽仪表、中控；
  6. 电子书及电子墨水屏。
  • 增长不仅来自市占率提升，也来自割草机、电子墨水屏、车载座舱等新增市场机会。
  • 在会议教育大屏领域，RK3576已替代部分晶晨A311D2的市场。
  • 预计RK3576将成为公司8纳米产品线的中坚产品，目前收入占比已超过10%。

d) RK3572的定位和放量节奏如何？

  • RK3572于今年春节期间推出，定价约12美元。
  • 产品主要面向低端白牌8核平板市场。
  • 今年已经开始量产，预计明年可达到数百万颗出货规模。
  • RK3572将成为明年主控芯片增长的重要增量来源之一。

e) 22纳米主控产品目前的发展情况如何？

  • 22纳米产品主要分为356系列和RV系列。
  • 356系列
  1. 包括RK3568、RK3566、RK3562等。
  2. 主要用于车载后装中控、收银终端、POS机、广告机、排队机和显示屏。
  3. 今年实现约20%-30%的增长，整体进入相对稳定的发展阶段。
  4. 目前收入贡献约20%。
  • RV系列
  1. 包括RV1126B、RV1106、RV1103等。
  2. 主要面向IPC及视觉应用，包括3D打印相机、3D打印机、投屏器和无人机航拍。
  3. 去年出货规模约千万颗，今年提升至3000万-4000万颗，实现2-3倍以上增长。
  4. 目前收入占比超过10%。
  5. 公司计划明年推出支持8K的视觉芯片RV1128。

f) 下一代高端主控芯片何时形成收入贡献？

  • 公司正在规划6纳米RK3668和4纳米RK3688。
  • RK3668预计在明年春节前后取得流片结果；RK3688预计明年下半年有机会推出。
  • 由于AIoT客户研发和验证周期通常需要半年至一年以上，两款产品预计明年不会产生显著收入贡献，主要放量时间可能在2028年。
  • RV系列积累的视觉、ISP及低功耗IP可复用于RK3668、RK3688等更大型芯片，从而降低后续研发风险。

2. AI协处理器产品与商业化进展

a) RK1828和RK1820目前的出货进展如何？

  • RK1828和RK1820于去年10月发布，今年上半年仍以送样和客户验证为主。
  • 今年下半年已经出现单客户数千颗甚至上万颗的需求，处于稳定爬坡阶段。
  • 当前主要应用于：
  1. AI NAS；
  2. AI电视；
  3. 移动机器人；
  4. 会议教育大屏；
  5. 开源板及类树莓派产品。
  • 今年协处理器对公司整体收入的贡献仍然有限，后续放量取决于端侧模型、算法和应用生态成熟度。

b) RK1828和RK1820如何定价，明年是否会涨价？

  • 当前主要销售SoC及M.2模组，模组价格分别为：
  1. RK1828约1500元；
  2. RK1820约1000元。
  • 预计今年年底至明年年初进行涨价，明年整体涨幅预计为10%-20%。
  • 涨价主要由存储成本持续上涨推动，而不是终端需求过热。
  • 公司去年储备的低价存储在今年一定程度上缓冲了成本压力，但后续仍需将部分成本向下游传导。

c) 两款协处理器的存储配置和毛利率如何？

  • RK1828采用两层2.5GB存储堆叠，总容量约5GB。
  • RK1820配置约2.5GB存储。
  • 当前协处理器毛利率最高可达到60%-70%，主要原因包括：
  1. 产品处于导入初期，附加值较高；
  2. 当前价格包含模组环节利润；
  3. 使用了部分此前采购的低价存储。
  • 随着存储成本上涨，后续毛利率可能受到一定影响，但公司认为产品仍具有较强性价比。

d) RK1860的定位、发布时间和定价如何？

  • RK1860是下一代协处理器，采用8纳米工艺和3D堆叠方案。
  • 产品预计今年年底发布，明年上半年完成市场导入，明年下半年有望实现一定规模放量。
  • 产品能力包括：
  1. 单颗可部署13B-14B模型；
  2. 两颗级联可部署25B-28B模型；
  3. 面向比RK1828更高参数量、更复杂的端侧模型。
  • 主要目标市场包括移动机器人、AI NAS、会议教育一体机、财税一体机、AI PC和AI手机。
  • 裸芯片预估价格约200美元，模组还需增加外围电路、电源、PCB及M.2、SO-DIMM等接口成本。
  • RK1860算力Die预计近期返回，完成DRAM堆叠预计要到年底。
  • 堆叠层数增加后，良率仍需验证，但公司目前判断整体工艺风险可控。

e) RK1860如何参与AI手机市场竞争？

  • 公司不会与高通、联发科的手机SoC直接竞争。
  • 在AI手机中，RK1860将以“1+1”方式搭配高通或联发科的基带主芯片，作为独立AI协处理器提供端侧模型算力。
  • 目前公司已与数家手机厂商推进合作，但仍需完成方案讨论、样机测试和实际验证。
  • AI手机对成本、功耗、散热和生态要求较高，短期仍处于共同开发和验证阶段。

f) 13B-14B模型是否足以满足下一代端侧需求？

  • 公司认为单颗13B-14B、双颗25B-28B基本能够覆盖未来主要端侧需求。
  • 端侧30B以上模型在现阶段一定程度上属于过渡性需求，并非长期唯一方向。
  • 随着模型优化，同一任务所需参数量将持续下降，例如过去需要7B模型完成的任务，未来可能由3B模型实现。
  • 端侧AI不能单纯追求更大算力，而需要在性能、存储、成本、功耗和延迟之间取得平衡。
  • 对于更复杂的应用，可以采用端云协同，而非全部由终端独立完成。

g) 为什么协处理器的放量仍难以预测？

  • 当前端侧模型主要由云端通用大模型蒸馏而来，针对具体行业的专用模型尚未成熟。
  • 很多传统行业客户缺少模型、算法和应用开发能力，无法仅凭一颗芯片完成产品落地。
  • 端侧AI需要芯片厂商、模型厂商、应用厂商和终端客户共同推进。
  • 公司将继续加速RK1860推广，并通过AI生态大会、模型厂商合作和客户共创推动行业成熟。
  • 现阶段明年具体出货量仍无法准确预估。

3. 3D堆叠技术与成本优势

a) 公司的3D堆叠方案有哪些优势？

  • 公司将算力Die与DRAM进行3D堆叠，区别于传统外置DRAM方案。
  • 主要优势包括：
  1. 降低存储系统整体成本；
  2. 降低数据传输功耗；
  3. 改善推理速度和端到端延迟；
  4. 提高产品集成度；
  5. 更适合功耗和空间受限的端侧设备。
  • 以其他100T以上算力、外置30GB以上DRAM的方案为例，仅存储成本就可能达到数千元，完整方案成本约5000-6000元。
  • 公司当前协处理器售价约1000-1500元，即使后续涨价，整体性价比仍然较高。

b) 公司为何较早选择3D堆叠路线？

  • 公司管理层在5-6年前已经开始讨论算力芯片与DRAM堆叠方案。
  • 当时行业更常见的是chip-on-chip、SoC或内存之间的堆叠，将AI算力芯片与DRAM直接堆叠相对创新。
  • 随着封装工艺逐步成熟，公司开始将该路线产品化。
  • 当前算力Die由晶圆代工厂生产，DRAM采用定制方案，再由合作封装厂完成堆叠。

c) 3D堆叠领域有哪些竞争者？

  • 已布局或计划布局相关技术的厂商包括：
  1. 小米；
  2. 高通；
  3. 以色列Hailo；
  4. 国内部分存储及AI芯片厂商。
  • 部分竞争者虽然已经完成流片，但软件生态和工具链仍需持续打磨。
  • 公司当前的先发优势主要体现在产品落地、功耗、成本及AIoT生态积累。

4. 市场竞争与生态壁垒

a) RV系列的市场竞争格局如何？

  • IPC市场头部厂商包括星宸科技、北京君正等，去年单家出货量均超过1亿颗。
  • 海思今年重新参与国内项目，预计出货可达到数千万颗。
  • 此外，富瀚微、安凯微等厂商也在参与竞争，行业参与者较多。
  • 公司目前处于中上梯队，在IoT及视觉芯片领域的市场份额约为百分之十几。
  • 公司今年市占率提升主要来自：
  1. 涨价幅度低于部分竞争对手；
  2. 产品在AI、ISP及低功耗方面具备综合优势；
  3. 缺货环境下保持了较好的供货和性价比。
  • 明年随着存储带来的利润空间下降，低端市场价格竞争预计会进一步加剧。

b) 公司如何看待晶晨对RK3588的竞争？

  • 公司认为晶晨相关产品虽然价格较低、标称NPU算力较高，但与RK3588的目标市场并不完全一致。
  • RK3588的主要优势包括：
  1. CPU、GPU性能更强；
  2. NPU工具链和实际使用效率更好；
  3. 生态和软件支持更完整；
  4. 能覆盖大量中小客户及碎片化行业；
  5. 已在车载和机器人领域形成量产经验。
  • 晶晨可能在会议教育大屏领域形成一定竞争，但RK3588主要定位于超高端市场，整体影响预计有限。

c) 为什么AIoT芯片的生态非常重要？

  • 芯片参数只是产品竞争力的一部分，客户能否快速完成量产更依赖完整生态。
  • 生态能力包括：
  1. 系统软件；
  2. AI工具链；
  3. 功能验证体系；
  4. 应用软件；
  5. 方案商及技术服务网络；
  6. 多行业量产经验。
  • 客户取得芯片后，需要快速完成技术链路、功能和量产验证，因此成熟生态可显著缩短产品上市周期。
  • 生态建设周期较长，也是RK3588等产品的重要竞争壁垒。

5. 机器人与数据采集业务

a) 公司在机器人“小脑”市场的地位如何？

  • 当前国内头部机器人品牌的小脑大多采用RK3588。
  • 公司判断其在机器人小脑领域的市场占有率超过50%。
  • 机器人通常使用1颗RK3588，部分复杂方案会使用2-3颗。
  • RK3588在性能、成本、生态和量产稳定性方面具有优势，未来机器人放量后，大部分客户继续采用该方案的可能性较高。

b) RK3588的生态卡位是否有助于协处理器进入机器人“大脑”？

  • RK3588已进入大量机器人客户，有利于公司进一步导入RK1828、RK1860等协处理器。
  • 主控芯片与协处理器的组合方案可以分别承担：
  1. 运动控制、感知和基础计算；
  2. 更复杂的大模型推理及端侧数据处理。
  • 目前机器人客户同时采用主控芯片和协处理器的占比仍然较低，主要受模型成熟度和客户研发能力限制。
  • 长期来看，既有生态和客户基础将提高协处理器导入成功率。

c) 机器人数据采集市场的增长空间如何？

  • 数据采集领域今年预计达到十几万至20万套。
  • 明年预计提升至数十万套，乐观情况下有机会达到100万套以上。
  • 市场参与者包括机器人厂商、模型厂商以及深圳的方案公司和硬件企业。
  • 头戴式或手持式采集设备不适合直接搭载高功耗协处理器，但可以增加独立边缘计算网关。
  • 数据可先通过RK1860等产品在端侧完成筛选和清洗，再上传云端，从而降低云端计算和传输负担。

d) 机器人业务目前能否按收入占比拆分？

  • 公司业务横跨大量碎片化行业，单一行业收入占比通常只有几个百分点。
  • 很多芯片通过方案商销售，公司无法准确掌握最终应用场景。
  • 因此，目前难以按机器人、消费电子或汽车电子等终端领域精确拆分收入。
  • 相比终端场景，按芯片产品系列拆分收入更具可操作性。

6. 收入结构、毛利率与价格策略

a) 当前各产品的收入贡献如何？

  • RK3588收入占比约25%-30%。
  • RK3576收入占比超过10%。
  • RV系列收入占比超过10%。
  • RK3568、RK3566、RK3562等356系列合计收入占比约20%。
  • 其他产品合计贡献约10%-20%。
  • 从增速看，RK3576和RV系列是今年增长最快的两条产品线。

b) 主要芯片的毛利率处于什么水平？

  • RK3588等旗舰产品毛利率超过50%。
  • RK3576毛利率约45%-50%。
  • 356系列相关产品毛利率约40%-45%。
  • RV系列毛利率约30%-40%。
  • RK1828、RK1820协处理器当前毛利率最高可达到60%-70%，其中包含模组利润和部分低价存储库存收益。

c) 低价存储库存对今年利润贡献多大？

  • 此前采购的低价存储对全年利润贡献预计约1亿-2亿元，占整体利润的比例不算高。
  • 相关存储主要用于RV等带存储的低端产品。
  • RK3588、RK3576等高端主控芯片主要采用外置存储，由客户自行采购，因此公司不会直接承担相关存储成本。
  • 下半年IPC终端价格较低，存储持续涨价后，部分客户的成本承受能力已经接近上限。

d) 明年哪些产品可能涨价？

  • RK1828、RK1820等协处理器预计涨价10%-20%，主要反映存储成本上涨。
  • RK3588等高端8纳米产品预计涨价约10%。
  • 其他8纳米产品预计涨价5%-10%。
  • 22纳米产品的具体涨幅尚未确定。
  • 由于带存储的低端产品收入占比仅为10%多，不能据此判断公司整体毛利率将明显下降。
  • 高端产品竞争力较强，且多数不内置存储，预计价格和毛利率相对稳定。

7. 供应链、产能与业绩展望

a) 当前供应链瓶颈主要体现在哪些环节？

  • 高阶HDI、芯片基板、玻纤布及电子布等环节仍存在供应紧张。
  • RK3588、RK3576等高端芯片需要使用较高阶的HDI材料，相关交期有所拉长。
