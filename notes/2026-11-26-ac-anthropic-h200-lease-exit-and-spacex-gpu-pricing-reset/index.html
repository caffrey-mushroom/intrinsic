摘要

  • 据 SemiAnalysis 行业消息，Anthropic 可能不再续租 SpaceX 约5万张 H200 集群（预计2027年初释放，意向转租价约5美元/卡时）；同期，SpaceX 将 Blackwell

小集群现货报价从15—15.5美元/卡时下调至10—12美元，向大客户价格靠拢。

  • 笔者将此事定性为中性事件，完全符合此前对“高价边际算力退出、单位成本下行”的判断。SpaceX 在供给极度紧缺期赚取的超高溢价本就不可持续，而 Anthropic 也有极强动力优化性价比偏低的旧卡产能。
  • 这是一次供应商、卡型与采购价格的组合调整，既不能推导出 Anthropic 总算力需求收缩，更不足以证明整个 AI 产业需求转向。

一、每GW一年收租超600亿美元：本就不可持续的稀缺溢价

市场一看到“退租”和“降价”，第一反应往往是需求崩塌。但如果把 SpaceX 原先的报价换算成每GW的年度收入，就能一眼看清这次调价的本质。

按 JPM 的单卡综合功耗估算（GB300为2.12kW、GB200为1.87kW）及每年8,760小时满载换算，SpaceX 调价前后的每GW年化租金如下：

对照每GW约400—500亿美元的初始建设成本，原报价下仅仅一年的租金收入，就已经超过了整座集群的硬件建造成本。即便扣除电费、运维和融资成本，这种收入回收速度也明显属于供给极度短缺期的“暴利定价”。

随着供应商增多、交付提速以及客户替代选择改善，小集群报价从15美元以上回落至10—12美元，本质上是高位稀缺溢价的正常收缩，而非需求塌方。SemiAnalysis 同样没有因此下调其 GB300模型假设（仍维持约12美元/卡时），并认为新 Blackwell 部署的回本周期依然具备吸引力。

至于 H200 约5美元/卡时的报价，这是 SpaceX 重新招租的意向价，并非 Anthropic 原合同单价。笔者此前拆解过双方合同结构：这份名义上延续至2029年的协议带有提前取消权，本就不能全部视为刚性 backlog。

合同本来就把2027年一季度设为重新选择算力的窗口。不同协议的初始不可取消期分别在2027年1月和3月结束，此后任何一方均可提前90天书面通知取消。若在不可取消期结束后发出通知，实际退出大致落在二季度。因此，明年上半年逐步调整这批容量，本就在原有合同安排之内，不能把“不可取消期结束”与“已经完成退租”直接画等号。

客户退出后，旧资产的重新定价和空置期风险回到出租方身上——这考验的是算力房东的回报率，却不代表模型公司的总预算在缩水。

二、训练要B卡、推理看性价比：Anthropic的算力组合优化

这次被退租的是5万张 H200，底层逻辑与笔者此前讨论 H100 时完全相通。旧卡并非不能跑模型，但在前沿实验室的账本里，训练和推理遵循两套完全不同的采购标准：

• 训练侧看重的是“时间与效率”：前沿训练拼的是互联带宽、集群稳定性和单位时间内能跑完多少轮实验。早几周完成训练，可能就意味着下一代旗舰模型抢先上线。随着 Blackwell 放量，Hopper 在超大规模训练上的性价比明显掉队，即便小时租金更低，也未必是划算的训练选择。

• 推理侧看重的是“单位任务成本”：训练端退下来的旧卡虽然可以转做推理，但推理客户比的是延迟、吞吐和每个有效任务的实际花费。有推理需求，不等于买方愿意继续为旧卡支付高昂溢价。

笔者此前按招股书费用口径测算，Anthropic约75%的算力支出用于训练、研发等内部及非付费用途。这意味着，其庞大的总算力建设不能简单画等号于当期付费推理需求。同时，随着企业客户从早期“扩张席位”向“嵌入复杂生产流程”过渡，部署周期拉长，Anthropic 短期 ARR增速有所放缓，推理侧的紧迫度也随之下降。

在“训练刚需新卡、推理不急着买单”的阶段，一边加大 Blackwell 等新一代算力采购，一边砍掉边际成本偏高的 H200 租约，是极其理性的组合优化。在公司尚未正式披露原因前，笔者更倾向于将其理解为结构调整，而非总需求转弱。

三、模型早已计入“去SpaceX化”：砍单不等于总预算收缩

复核笔者此前的 Anthropic 财务模型，算力总费用与 SpaceX 费用的变化已经清楚体现了这一判断。按现有模型口径，具体测算如下：

模型中，SpaceX费用占总算力与基础设施费用的比例，从2026年的43.4%降至2027年的15.0%，2028年起归零；与此同时，总算力与基础设施费用仍从2027年的约1,093亿美元，增长至2028年的约1,748亿美元，并在后续年份继续增加。

这虽然是笔者的模型情景（非公司指引），但它清晰说明了一个核心逻辑：削减某一家高价供应商的采购，与整体算力总费用持续扩张，完全可以同时发生。模型本来就没有把 SpaceX的高价资源视为永久性的算力底座，因此，这次调整并没有推翻此前的总量判断，也是笔者将此事定性为中性事件的直接依据。

真正改变的是钱付给谁、采购哪一代芯片，以及每单位有效算力的成本，而不是必然减少投入总量。SpaceX这类能快速交付的大集群，在算力最紧缺的窗口期价值极大，能帮模型厂填补其他产能落地前的空窗。但当长期合作产能陆续到位，这类过渡性资源必然面临重新比价。

根据公开披露，Anthropic 已建立起横跨 Trainium、Google TPU、NVIDIA 和 AMD 的多芯片体系，按性价比动态调度工作负载。按笔者此前讨论的长期成本路径，随着低 TCO 的 ASIC产能放量及部署效率提升，头部实验室的每GW年度算力成本终将向100多亿美元逐步靠拢。高价外租资源占比下降，本来就是这条成本曲线演进的必经之路。

四、数据交叉验证：行业并未出现租金普跌

如果跳出 SpaceX 这家单一供应商，去对照全市场的价格水位，也能印证“目前只是局部高价回调，而非行业普跌”。

FUNDA 的 GPU Rental Price Tracker 显示，截至2026年11月25日，H100、H200、B200、B300四类卡的现货指数近一周涨跌互现、波动极小，近两周则全部录得上涨，并未出现各代产品租金同步大幅下行的迹象：

拉长到30天曲线看，H200 与 B200 大体横盘，H100 温和走高，B300 的价格中枢也高于月初。此外，FUNDA 同期 H200 Reserved（预留实例）指数约为5.34美元/卡时，从这个口径看，也不能简单断定 SpaceX对 H200 开出的5美元意向价就一定脱离市场。

当然，现货指数与大规模、连续可用的互联集群并非完全同质的产品，不能直接用来给 SpaceX 的合同定价。但它提供了一个清晰的行业温度计：目前看到的是个别高价溢价的回落，市场整体租金依然具备韧性。对 SpaceX而言，接下来真正需要观察的，是这批退租的 H200 何时找到新买家、最终成交价以及实际出租率。

五、回归终局：别把供应商调整，误读成长期需求见顶

当前市场对 AI资本开支回报（ROI）的疑虑较重，负面叙事集中，一笔退租、一次降价，都很容易被放大成“算力需求见顶”的证据。但在做投资判断时，必须把两件事分清：客户是削减总预算，还是优化供应商？是全行业租金崩塌，还是紧缺期溢价回归？从现有证据看，这次事件明显更接近后者。

站在长期视角，真正决定算力投入能否闭环的，不是某一张旧卡的租约，而是需求端能否持续创造增量：

• 企业级 ARR 能否重新加速：早期靠卖席位容易起量，下一阶段的关键在于更多 Agent 和复杂应用进入企业真实生产流，撬动持续扩大的 API 预算。过渡期的部署放缓，不能直接等同于需求见顶。

• 新场景的商业化兑现：例如网络安全（AI 是否推高攻防与修复频率，形成刚性防护预算）以及 AI4S（在药物发现、材料与工程领域能否产出可验证的商业价值），潜力巨大，但收入兑现节奏需要分别跟踪。

• RSI（递归自我改进）能否带来更大的商业需求：更强的模型会加速研发并压低单位任务成本，这意味着 token 用量增长未必同步转化为收入和 Capex；但前沿竞赛仍会倒逼头部实验室加大训练投入。最终回报取决于新增付费场景与企业预算，能否跑赢单位成本的下降速度。

综上，笔者对此次事件维持中性判断。高价边际算力逐步出清本在预期之内，尚不足以改写长期算力需求逻辑。
