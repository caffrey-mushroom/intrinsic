摘要

FY27 Q1 Azure营收325亿美元、同比增长约44%，Azure AI贡献78亿美元并增长80%多，OpenAI仍为核心驱动力，第三方模型业务增长165%。Copilot席位增至约3,700万到3,750万，大客户云迁移与多模型部署支撑中长期增长。

要点

  1. FY27 Q1 Azure及其他云服务营收325亿美元，按固定汇率同比增长约44%、接近45%，其中Azure AI营收78亿美元、同比增长80%多并占整体约24%，Core Azure营收247亿美元、同比增长32%
  2. Azure AI增长主要由OpenAI驱动，Azure OpenAI Service贡献Azure AI收入约60%，OpenAI相关业务同比增长112%；其收入结构中Token调用占45%、专属容量部署占32%，其余为训练服务
  3. 企业多模型混合部署推动第三方模型厂商业务同比增长约165%，Anthropic占Azure AI收入的比例由7月约4%升至8月4.8%，9月估计约8%，但该估计并非基于直接数据
  4. 大型和超大型客户是Azure增长主力，云迁移收入占非AI核心业务云收入至少80%，企业级用户年留存率达96%以上，超大型客户采购规模提高约10%到15%，强监管行业项目周期和验收时间由两个月压缩至一个月
  5. Copilot付费席位约3,700万到3,750万，单季度新增约750万、环比增长25%，其中70%来自存量客户扩容，头部企业平均席位覆盖率由35%升至52%，每席位平均实际成交价格约23美元
  6. Azure约承载OpenAI核心训练负载的90%和全球推理负载的65%，微软全栈优化使训练效率较通用架构提高30%以上；预计非AI业务增长持续至2028年，多模型与Copilot推动AI市场至少增长至2030年

Q:请介绍FY27 Q1 Azure的营收和增长情况；如果方便，也请进一步拆分Azure AI及其相应的增长情况。

A:按FY27 Q1，即2026年7月至9月计算，Azure及其他云服务的整体营收为325亿美元。按固定汇率计算，同比增长约44%，接近45%；名义增速有时对外披露为42%，但差距不大。整体延续加速态势，之前几个季度大约为294亿美元。按全年估算，营收预计可以突破1,000亿美元。整体采用按需计费、预留承诺和分层折扣等方式。

Azure AI业务整体营收为78亿美元，同比增长80%多，占Azure整体营收约24%，也是Azure增长最快的业务板块。在这78亿美元中，Azure OpenAI Service贡献约60%的收入；自有AI服务，包括Azure AI Foundry、认知服务和机器学习平台等，合计约占40%，未进一步拆分。计费模式包括API按量计费、专属容量部署和项目制。

Core Azure是非AI核心业务，包括传统计算、存储、网络、数据库、安全、身份认证及其他规模相对较小的业务，整体营收为247亿美元，同比增长32%，仍处于稳健增长阶段，也是Azure的基本盘。增长主要来自企业云迁移深化、混合云部署扩容以及安全合规需求提升。收费仍以资源消耗为主，主要按CPU、内存小时等计费。

Q:目前大约是16日，您刚才给出了相对准确的325亿美元。这个数字采用什么口径，是内部数据还是外部流传的数据？后续是否还有调整的可能？

A:如果是7月至9月的数据，基本不会再有较大调整，业务层面的数据已经确定。后续可能只有财务方面个别细节的调整，差值大约在百亿左右，可能略有变化，但不会影响325亿美元这一大数。

Q:Azure AI能否继续向下拆分？您是否了解OpenAI或Anthropic的收入贡献？

A:这一业务可以进行更细拆分。OpenAI单独占Azure AI收入的60%，即78亿美元乘以60%。自有AI服务中，Azure AI Foundry单独占Azure AI收入的12%，即78亿美元乘以12%。剩余部分包括认知服务、机器学习平台等，目前未进一步拆分。

Q:Anthropic也已上架，其收入占比大约是多少？

A:Anthropic起量时间不长，这次尚未独立拆分。目前只看了7月和8月的数据:按月计算，其占比在7月约为4%，8月升至4.8%，接近5%。

Q:Anthropic整体处于加速状态吗？

A:是的，整体处于加速状态。由于尚未完全起量，目前占比还没有达到较高水平，但Anthropic属于Q4的重点。

Q:另一位专家提到，Anthropic占整个Azure AI的比例可能已经升至9%左右。与您刚才的数据相比，这一数字是否明显偏高？

A:不一定。此前看到的是7月和8月数据，占比应当从4%升至5%，当时量级攀升较慢。如果9月继续上升，估计占比应在8%左右；由于统计口径不同，8%到9%之间可能存在差异，但整体不会相差太多。该判断并非基于直接看到的9月数据，而是根据已有情况倒推得出。

Q:Azure AI内部哪一项业务增长更突出？整体增长是否主要由OpenAI带动？

A:大量增长来自OpenAI，其总体同比增幅达到112%。目前各项数据口径已经确定，同比数据也已形成；如需更细的数据，还可以按照现有口径进一步计算环比等指标。

Q:目前的增长是否仍与此前指引基本一致？9月调整口径后，Azure整体增长指引为44%到45%，现在看到的结果也在这一范围内，没有高于45%吗？

A:目前看不到高于45%的情况，基本处于该区间。微软的预估通常相对准确，也基本符合行业发展态势。

Q:目前公司对开源模型部署持什么态度，已经部署了哪些模型？开源模型的收入贡献处于什么状态？即使规模仍然较小，是否有增量信息可以分享？

A:公司会将部分内容开源，但涉及具体技术模块的信息仍需进一步确认。Q3刚发布新一代Copilot，将整合Home、Code和Autopilot等核心模块，并把其中一部分功能补充到开源代码中。具体发布渠道尚不清楚，这项工作于上月25日发布，相关技术文档预计本月同步推出。

Q3的一项工作是上线新一代Copilot，另一项是从中拆出部分内容进行开源，主要由技术侧主导。相关内容目前仍在梳理，预计于Q4完成，并在10月底形成初阶版本，后续核对后可能继续调整。目前主要是从Copilot相关内容中梳理一部分进行开源。

Q:OpenAI目前在微软产生的收入主要来自训练还是推理？两部分收入的变化趋势如何？另外，OpenAI现在也在AWS使用算力，您是否了解其在Azure、AWS等平台之间分配算力的策略和机制？

A:先看Azure AI的收费模式:标准API调用按Token计费，此外还有专属容量部署和定制化服务。定制化服务大约占整体的10%到15%；剔除这部分后，剩余收入主要来自标准API调用和专属容量部署。目前仅统计了Azure OpenAI Service的整体比例，其中Token调用收入占45%，专属容量部署占32%，其余为训练费用。

Q:刚才45%、32%等比例的分母是什么？这是OpenAI在微软消耗总量的构成，还是收入构成？

A:这是三种服务产生的收入比例:45%对应Token调用，32%对应专属容量部署，其余为训练服务。这里所说的是营收，而非利润或毛利，包括数据训练服务产生的收入，以及按Token调用量进行阶梯计费的服务收入。

Q:对于签署大额Azure承诺的客户，本季度实际消费是否加快？如果加快，原因是什么？如果没有加快，是因为客户部署需要时间，还是微软的容量跟不上？

A:可以分客户层级来看。中小企业大致指员工人数在300人以下的企业，但实际划分标准并不完全一致。这一群体基本没有太大变化，因为其对行业变化的敏感度相对较低。中型企业尤其关注能够获得多少算力和资源位置，对资源占用及扩张的要求一直较高。大型和超大型企业近期变化更明显，但不同企业和行业之间存在差异，目前尚未进一步拆分。

变化较大的主要是强监管行业。这些行业对部署和合规的要求更高，具体表现为部署标准更严格、要求事项更多，同时交付速度也要加快。第一，与客户内部数据系统对接及开展训练时，需要使用客户开放的真实数据，因此数据侧管控很严。第二，对接过程中需要配合客户的安全、合规及审计要求，相关额外功能的标准也很严格，项目周期和验收时间已基本从此前的两个月压缩到一个月。第三，定制化权限体系的成型及方案沟通也需要更快推进。

总体而言，相关工作量正在加大、推进节奏正在加快，增长确实主要由大型和超大型客户驱动。

Q:大型和超大型客户的增长具体由哪些使用场景或功能带动？是微软发布了新产品，还是客户原有用量自然上升？

A:可以分为几个方向。第一是非AI核心业务。即使没有AI，微软原有核心业务仍然存在并保持稳健增长，主要驱动力是大型和超大型企业的核心系统云迁移。云迁移相关收入占非AI核心业务云收入至少80%，并会叠加带来混合云部署扩容及安全合规需求。这些因素可以分别考察，但本质上均由云迁移带动。企业级用户年留存率此前披露可达到96%以上，超大型客户采购规模大约提高了10%到15%。

第二是OpenAI相关业务。按体量看，该业务仍排在首位；尽管基数已经较高，整体仍维持约110%的增幅。本季度与上季度差距不大，仍处于爆发式增长阶段，主要是因为AI相关业务本身尚在快速爆发，增长速度没有明显变化。但从明年开始，增速会逐渐放缓:一是此前体量较小，现在体量已明显扩大；二是相关市场已经开发得较为充分。明年Q1的策略将调整为稳健高速增长，目前只有大方向，具体策略和动作尚未形成。

第三是自有企业AI业务，这也是当前AI板块增速较快的赛道。其核心驱动来自两方面:一是企业AI从POC走向生产，客户对Azure AI Foundry、向量数据库，尤其是AI安全治理等平台级产品的需求提高。企业AI正从此前的野蛮发展逐步走向合规，因此数据库合规性和安全治理等需求增长较快。二是FDE前线交付体系逐步完善，将带动行业解决方案和工程化服务收入增长。该板块的具体数据尚未细看，但增幅相对较高。

第四是第三方模型厂商业务，即OpenAI和微软自有模型之外的模型业务。这是Azure增速最快的板块之一，增速约为165%。核心背景是企业越来越多地采用多模型混合部署，不再单纯依赖OpenAI，而是根据不同场景选择模型。微软也会持续引入Cla ude、Mistral等主流模型，完善多模型生态，由此带动该板块收入实现更高增长。

从具体产品看，Azure OpenAI Service上线了GPT-4o的分级版本。目前主要工作是接入第三方模型和完善多模型生态，能力优化则集中在吞吐量和推理效率，其他方面暂时没有明显变化。客户覆盖方面，累计覆盖超过85%的《财富》世界500强企业。Q3新增付费客户约1,100多家，接近1,200家，其中60%来自金融、制造和医疗等传统行业，AI向垂直领域渗透的趋势较为明确。

Azure AI Foundry主要用于搭建企业级AI应用的一站式平台，覆盖模型选型、微调、评估、部署等全流程工具链，目的是降低企业搭建生产级AI的门槛。目前实际落地较好的功能包括企业级Agent开发套件、多模型路由引擎，以及与FDE交付体系打通。年消费10万美元以上的中大型客户占比从约48%提高到62%，整体效果较好。

Q:刚才提到的客户覆盖、新增付费客户和消费占比等数据，是中国区、亚太区还是全球范围的数据？

A:刚才所述数据均为全球口径，并非中国区数据。

Q:Copilot目前的付费席位规模和单季度新增情况如何？

A:Copilot目前总体付费席位约为3,700万到3,750万，单季度新增约750万，环比增长达到25%。由于新一代产品刚上线，暂时没有更多数据。

Q:Copilot新增席位主要来自新客户，还是存量客户增加席位？每个席位的实际成交价格大约是多少？

A:新增席位中，70%来自存量客户扩容，头部企业的平均席位覆盖率从35%提高到52%；另外30%来自中小企业新客户。面向中小企业的Copilot Business促销价为每用户每月18美元，该价格至少会维持到今年年底，明年可能调整。企业版经过批量折扣后的基础席位费用并不固定，实际成交价约为每用户每月22到28美元。

Q:综合计算后，Copilot每席位的平均实际成交价格大约是多少？

A:大约为24美元，接近25美元；平均数约为23美元。

Q:10月初，公司统一了Copilot入口，在Foundry App中整合了Home、Code和Autopilot。这些产品的上线节奏如何？哪些客户已经可以使用，哪些功能仍处于预览阶段？客户何时会大规模部署，收入何时会受到较大规模影响？

A:Copilot Home已经完成正式发布。10月正在向所有付费用户批量推送，并配合Q4企业IT预算落地。预计12月可以正式启用相关功能，席位使用率预计将从10月的45%提高到60%以上。目前已经进入落地阶段，因此确定性较高。

Copilot Code更聚焦开发者群体，其接受度较高，部署门槛也较低，主要跟随大型企业研发部门进行渗透。目前仍处于快速沟通和普及阶段，企业版激活率预计本季度可以达到60%以上。部分功能有望在本季度开放，但全面开放要到明年。

Autopilot目前仍处于预览阶段。Q4会扩大客户预览范围，但不会形成规模化商业部署。此前预计在FY27 Q1落地，目前只能判断将在FY27上半年完成全面功能落地。部分功能部署可能于Q1末完成，也可能延至Q2；也不排除部分功能部署和全面部署均要到Q2完成，目前还无法准确判断。

Q:Autopilot是否已在内部或客户侧测试任务处理成功率、客户满意度等指标？目前能否判断它在实际生产、文档或任务处理过程中是否真正有效？

A:目前只是让客户进行预览，技术人员会在预览过程中协助客户开展初步对接和尝试。任务处理成功率、客户满意度及实际效果测试均属于预览阶段正在开展的工作。目前尚未看到结果，最早要到本月25日才能了解客户初步预览和对接的情况。

Q:大客户正在持续上云，并从本地部署转向混合云。客户当前及明年的IT预算会从原有其他预算中扣减，还是会新增一笔纯增量预算？

A:不同客户的情况并不相同。根据目前掌握的信息，客户提交的相关预算都会重新履行审批流程，因此应当属于单独预算。但客户内部将其归为研发预算、合作预算还是其他类别，目前并不清楚，只能确定每一笔预算均单独履行流程。可以确定的是会有新增预算，但新增预算在客户内部如何分类尚不明确。

Q:客户是否会同时减少原有预算，目前还无法看到，对吗？

A:是的。客户只会披露每一事项的预算金额，目前连FY27的整体预算都尚未给出准确数字。即使新功能预算单独获批，也可能同时减少原有预算，或者原预算较今年有所下降、增长不足；目前无法感知这些变化，因此不能给出明确答案。

Q:企业AI从POC走向正式部署时，哪些使用场景已经较为成熟，企业在测算ROI后愿意大规模上量？例如客服、内部工作流或文档处理等，能否举例说明？

A:这一问题还需要进一步查看数据，目前尚不清楚哪些场景占比更高。需要考察客户付费后主要使用哪些模型，以及具体应用于哪些场景。微软目前更多是提供模型，由用户决定如何接入和使用；现阶段尚未针对每个场景进行深入了解，也没有开展场景化匹配。

Q:微软内部在模型分配或路由方面采用什么机制？对于OpenAI等不同模型的API，是由微软根据任务进行推荐，还是仅向客户提供接口，由客户自行选择？

A:Copilot会提供预计能够帮助客户处理的功能，一个场景也可能同时使用多个功能。Copilot Home可提供文档创作、数据分析、会议辅助、邮件处理、重点信息提取、AI总结和信息检索等功能，并深度集成Office和Teams。推广时会说明它能够在整个工作链路中提供哪些辅助、完成哪些转换，以及在用户熟悉的Office或Teams中增加哪些能力和附加价值。

Copilot Code主要提供代码生成、调试、架构重构、项目脚手架、API集成以及自然语言驱动的应用开发。推广时会介绍代码生成能够达到的程度、用户应如何描述需求、可以生成什么样的代码，以及每项功能需要客户或使用者执行什么操作、最终能够达到什么效果，并进一步说明可能实现的效率提升和人力节省。

Autopilot定位为自动化工作流智能体。相关方案刚形成不久，当前版本可能还会调整。它可以横跨客户内部系统和应用执行长周期任务，并自动推进流程，例如报工、数据同步、合规检查和客户跟进。目前还没有太多实际数据，现阶段主要是向客户说明产品能力，推动客户接入和应用。

Q:关于Azure和Azure AI，本季度还有哪些重要变化尚未提及？无论是模型供给、内部产品架构还是客户侧变化，能否补充一些增量信息？

A:第一点是Azure与OpenAI的合作。微软正在对接多种大模型，而率先跑通的是与OpenAI的合作。OpenAI仍是微软核心的云基础设施客户和战略合作伙伴，双方在技术协同、算力供应和商业化转售三个层面基本完全打通。在技术深度协同方面，微软对OpenAI模型从硬件到软件栈进行全栈定制化优化，训练效率比通用架构高30%以上，这也是微软较强的技术壁垒。

去年10月，双方签订了新一轮协议，OpenAI采购约2,000亿美元的Azure服务，具体期限暂不确定，主要用于满足训练和推理的算力需求。Azure OpenAI Service体现了双方的商业化联动。目前，微软已经成为OpenAI模型的主要官方推荐渠道之一，双方会共同推广该产品，并认可其为由微软自行运维的产品；同时，该产品也已具备企业安全合规、SLA保障和技术支持。

第二类是金融服务业。金融服务业是传统企业级市场的第一大行业，AI服务单价较高，也是Azure传统企业级市场的优势行业。金融大客户的单客年消费约为全行业平均水平的2.6倍，整个行业贡献接近Azure总营收的19%。代表性客户包括全球银行、保险巨头和证券交易所，具体包括摩根大通、高盛、美国银行、汇丰银行、安联保险和贝莱德等。
