乐鑫科技专家访谈纪要

1. 产品定位与AIoT应用方向

a) ESP8266与ESP32系列的产品定位分别是什么？

  • ESP8266及ESP32-C系列：连接型产品
  1. 主要服务于Wi-Fi或“Wi-Fi+MCU”的连接需求，核心定位仍是IoT连接芯片。
  2. ESP8266已服役约12年，后续将逐步被架构更精简、成本更低的C2、C3系列替代。
  3. C2、C3通过软硬件及芯片架构优化，并从FreeRTOS相关架构逐步向RISC-V演进，降低了部分IP成本。
  • ESP32-S系列：主控及端侧AI产品
  1. S2、S3主要面向“MCU+Wi-Fi”及端侧AI需求。
  2. 支持本地模型移植和算法处理，可应用于人脸与图像识别、语音交互、信号处理以及大尺寸触控屏控制。
  3. 当前正受益于端侧模型发展，产品出货增速高于传统连接型产品。
  • ESP32-P系列：纯主控产品
  1. P4是纯双核MCU，不集成通信功能，主要面向更高性能的主控和端侧AI市场。
  2. P4与S2、S3并非直接替代关系，而是面向不同应用市场。
  3. P4目前尚未大批量出货，现阶段定价较高，未来有望进一步提升公司整体ASP和收入占比。

b) 公司当前主要收入和出货来自哪些应用领域？

  • 第一增长曲线仍来自Wi-Fi或“Wi-Fi+MCU”市场。
  • 智能家居相关应用约占整体应用的60%，主要包括：
  1. 冰箱、空调等传统白色家电。
  2. 咖啡机、电饭煲、豆浆机、电风扇、烤箱、微波炉等小家电。
  3. 智能音箱、扫地机器人等新型智能家居产品。
  • 近两年新增应用主要来自：
  1. 工业互联及工控。
  2. 大交通相关场景。
  3. 集约农业，尤其是温室大棚场景。
  4. 商业及其他长尾应用。
  • 上述新领域目前基数相对较小，但有望成为新的收入和利润来源。

c) AIoT的核心能力是什么，增量主要来自哪里？

  • AIoT的核心能力包括：
  1. AI算法和模型能力。
  2. 本地芯片计算与信号处理能力。
  3. 端侧AI推理能力。
  4. Wi-Fi连接及云端协同能力。
  5. 人机交互及触控显示能力。
  • AIoT增量不太可能完全来自某个全新的单一市场，更可能来自现有智能家居产品的持续升级，包括交互体验、智能化程度和AI能力提升。
  • 典型技术路径是：部分信号和数据由端侧芯片处理，再通过云端完成进一步解析和分析，最终形成交互式应用。

d) 哪些细分市场最具端侧AI放量潜力？

  • 智能安防是当前确定性最高的应用方向
  1. 主要产品包括智能门铃、智能门锁和摄像头。
  2. 端侧芯片可完成摄像头驱动、本地人脸识别和异常情况判断。
  3. 产品还可通过Wi-Fi将快递人员、陌生人或异常行为上传至云端，并实现实时语音通信。
  4. 智能安防目前基本保持每年20%以上的增速，是消费电子和智能家居中增量较大、增长相对稳定的细分市场。
  • AI玩具、教育硬件和智能陪伴产品具备较大潜力
  1. 主要包括智能玩具、智能音箱、桌面机器人、智能台灯和点读笔等。
  2. 教育类产品受家长教育投入及礼品需求支撑，消费者对AI教育产品的付费意愿相对较强。
  3. 海内外大厂正积极拓展智能硬件生态，市场上已有大量项目处于立项、Demo及小批量生产阶段。
  4. 当前尚未出现国民级、现象级爆款，最终市场规模仍需观察。
  • 小家电大屏化、触控化升级有望形成稳定增量
  1. 豆浆机、烤箱、微波炉等原本采用物理按键的产品，正逐步升级为大尺寸触控屏。
  2. ESP32 MCU可以驱动触控屏及人机交互界面，是用户能够直接感知的智能化升级。
  3. 当前相关项目数量较多，整体增长情况较好。

e) 哪些AI硬件更容易形成商业闭环？

  • 低价插座、灯具等产品原本售价仅十几元至几十元，如果加入大模型后每年还需支付百元以上Token费用，商业模式较难成立。
  • 机会更可能集中在：
  1. 智能化价值更突出、终端售价更高的产品。
  2. 家庭安防等刚需品类。
  3. 教育、礼品等消费者付费意愿较强的品类。
  4. 具备高频交互需求和明确用户价值的产品。
  • 当前AI智能硬件仍处于产品定义、模型成本和商业模式探索阶段，具体载体及落地形式尚未完全清晰。

2. 开发者生态与长尾客户战略

a) 乐鑫为什么重点建设开发者生态？

  • 传统芯片公司通常聚焦少量头部客户，为其提供驻场、调试和生产支持等全链路服务。
  • IoT市场的创新应用更多由中长尾客户、创客、高校师生及研发团队推动，这些客户此前往往不被传统芯片公司重视。
  • 乐鑫从早期即通过全球KOL、研发专家、论坛及社区影响力人士构建生态，以较低成本覆盖全球分散的开发者和潜在客户。
  • 公司不可能依靠大量销售和BD人员在全球寻找车库创业团队，因此需要通过开放生态和线上内容主动吸引客户。

b) 公司如何降低开发者使用芯片的门槛？

  • 公司向开发者开放并持续完善以下资源：
  1. ESP-IDF开发框架。
  2. Datasheet和技术文档。
  3. SDK及示例代码。
  4. 完整应用演示视频。
  5. GitHub、GitLab等平台上的开源项目。
  • 开发者在制作扫地机器人、桌面机器人或AI作品时，可以直接搜索并找到相关案例，从而更快完成原型验证。
  • 公司通过GitHub、GitLab、Google、百度及社区论坛等开发者日常使用的平台扩大触点，形成长期“种草”效应。
  • 开发者在学生阶段形成的产品认知和使用习惯，可能延续到其进入小米等企业后的项目选型中。

c) 开发者生态如何转化为收入和出货？

  • 开发者生态不是传统CRM系统，公司很难追踪每个项目的开发进度、量产时间及最终出货规模。
  • 开发者从建立认知、产生兴趣到最终商业化，并不存在必然关系，因此生态贡献难以精确量化归因。
  • 潜在转化路径包括：
  1. 开发者通过线上内容发现并试用ESP32。
  2. 项目进入原型、Demo或立项验证阶段。
  3. 公司识别出有量产潜力的团队或大厂工程师。
  4. 将其导入私域，由FAE或销售团队提供专项支持。
  5. 根据产品定义、团队能力和供给匹配度，重点支持量产及大规模出货。
  • 公司不会过度功利地评估每个开发者，而是优先解决问题、满足需求，并培养长期黏性。

d) 当前开发者生态的增长情况如何？

  • 去年以来，尤其是今年，相关项目或生态新增量快速上升：
  1. 日常新增量大致为500—800。
  2. 高峰期可达到1,000以上。
  3. 最近一个月日均新增约550—650。
  4. Q3阶段日均新增刚超过400，近期已提升至约550，呈现明显边际加速。
  • 在端侧AI芯片领域，无论搜索优化还是内容建设，搜索结果前20名中大概率可以看到乐鑫相关布局。
  • 横向比较，日均超过550属于显著优势，说明公司早期积累的开发者内容和社区触点正在AI浪潮中被进一步放大。

e) 开发者热度能否作为未来业绩的领先指标？

  • 专家认为，开发者生态繁荣及搜索热度提升可以视为未来成功的早期指标。
  • 如果每天有约500个项目进入生态：
  1. 其中约400个可能主要出于个人兴趣。
  2. 约100个可能具备真实产品化意愿。
  3. 这些项目可能来自创客、研发公司、大厂研发人员或已获得融资的创业团队。
  • 公司会评估项目方的产品定义能力、投入程度和量产可靠性，并判断芯片或模组能否满足其需求。
  • 需要注意，历史上智能音箱热潮期间，公司每天也曾接触约80个相关项目，但最终市场主要被阿里、小米、百度、华为等大厂收割，中长尾项目并不必然能够量产或放量。

f) 公司开发者生态的壁垒体现在哪里？

  • 多数国内外大型芯片厂商较重视知识产权保护，传统上只向少数全球头部客户开放开发资源。
  • 乐鑫选择更开放的方式：客户能够自行开发，公司就支持其出货；即使项目失败，公司损失也相对有限。
  • 随着Z世代工程师成长，行业文化正从封闭式头部客户服务转向开放、自主开发。
  • 竞争对手即使开始布局开发者社区，也面临内容和社区积累不足的问题。
  • 开发生态类似内容平台“种草”，先发者已经积累大量文章、代码和案例，后进入者较难快速获得同等搜索排名和用户心智。

3. 产品结构、ASP与毛利率变化

a) 从传统连接芯片向AI SoC和主控芯片升级，对ASP有何影响？

  • 芯片ASP大致如下：
  1. ESP8266约0.6美元。
  2. C2约0.5美元。
  3. C3约0.55美元。
  4. S2约0.8美元。
  5. S3约1美元。
  6. P4目前参考价格约1.5美元，尚未大规模出货。
  • 从C2、C3升级至S2、S3，芯片ASP基本实现接近翻倍。
  • P4进入规模量产后，预计将进一步提升公司整体ASP及收入结构。

b) 不同产品的毛利率大致如何？

  • 传统连接型产品如ESP8266、C2、C3，毛利率约40%或略高于40%。
  • S2、S3及P4等主控或端侧AI产品，毛利率普遍在50%以上。
  • 毛利率提升的主要驱动因素包括：
  1. 高ASP、高毛利的S系列和P系列占比提升。
  2. ESP8266向C2、C3切换，软硬件架构进一步精简。
  3. RISC-V架构有助于节省部分IP费用。
  4. 模组销售占比提高。
  5. 存储等成本上涨能够向下游传导。

c) 公司产品结构目前如何？

  • 按访谈中的大致比例关系：
  1. ESP8266芯片及模组约占20%。
  2. C2、C3芯片及模组约占50%。
  3. S2、S3芯片及模组约占25%。
  4. H/C等其他系列约占10%。
  5. 较早期的ESP32-D2WD等产品约占10%。
  6. P4目前占比很低。
  • 上述比例为大致结构关系，存在口径重叠，因此合计超过100%，不宜作为精确财务拆分数据。
  • 后续趋势是端侧AI及主控芯片占比持续提升，传统Wi-Fi连接型产品占比相对下降。

d) 模组占比提升对ASP有何影响？

  • 当前越来越多中长尾客户倾向直接采购模组，而不是自行采购存储、Codec和其他被动器件进行组装。
  • 模组ASP大致为：
  1. ESP8266模组约1美元。
  2. C2、C3主力模组约0.9美元。
  3. S系列模组约1.2—1.5美元。
  • 模组集成NOR Flash等器件，价值量高于单芯片，因此模组占比提升有助于提高整体ASP。
  • 公司作为规模较大的存储产品买方，采购价格优于中小客户，在部分情况下还可以获得一定采购价差收益。

e) 各产品线未来的出货增速如何？

  • ESP8266向C2、C3切换是当前最稳定的增长来源：
  1. 预计每年仍可增长约10%。
  2. 保守估计增速为10%—15%。
  • S2、S3今年整体用量增速已达到22%以上。
  • 如果明年维持当前趋势，S2、S3的出货量和增速有望进一步提高。
  • 早期信号包括：
  1. 开发者需求快速增长。
  2. 大厂项目持续立项。
  3. 项目逐步进入试产及量产阶段。
  4. P4开始进入规模化放量周期。

f) S2、S3为什么预计在2028年前后达到出货量高点？

  • 单颗芯片的行业生命周期通常可达到约12年：
  1. 第1年推出产品。
  2. 第2年送样并推进客户验证。
  3. 第2—3年进入小批量阶段。
  4. 第4—5年开始起量。
  5. 第7—8年在目标应用中形成较高渗透率，出货量可能达到高点。
  6. 随后受摩尔定律、降本需求和替代方案影响，原有产品逐渐下降。
  • ESP8266基本验证了这一路径：
  1. 约2014年推出。
  2. 在疫情前后达到出货高点。
  3. 随后逐步由C2、C3承接。
  • S2、S3约在2022年前后推出，按照6—8年的成长周期推算，预计2028年前后达到出货量峰值。
  • 2028年后，P系列等新产品有望接续增长，但当前产品迭代速度较过去更快，实际周期可能缩短。

g) P4与S2、S3的关系是什么？

  • S2、S3属于“MCU+通信”产品，P4属于不集成通信功能的纯主控产品。
  • P4面向新的主控及高性能端侧AI市场，不是对S系列的简单替代。
  • P4价格和未来收入贡献预计高于S系列，有望成为公司后续ASP提升的重要来源。

4. 存储涨价、价格传导与供应链管理

a) NOR Flash涨价对公司成本有何影响？

  • 公司目前采购NOR Flash的成本较年初上涨约8%。
  • 年初公司已储备约半年库存，因此上半年受到的影响相对有限。
  • 下半年开始采购新批次存储产品后，公司逐步向下游进行价格传导。
  • 与DDR等大容量存储相比，公司使用的NOR Flash和PSRAM价值量较低，涨幅也未达到成倍增长，因此整体影响相对可控。

b) 公司如何将存储成本上涨传导给客户？

  • 公司作为大买家可获得阶梯采购价格，采购成本优势优于中小客户。
  • 如果公司采购成本上涨8%，不同客户的传导策略不同：
  1. 对一般客户，可直接传导约8%的涨幅。
  2. 对采购规模较小、议价能力弱的客户，可能涨价10%甚至15%。
  3. 对采购规模大、战略价值高的客户，可不涨价或仅部分传导。
  4. 对小米等议价能力较强、已有价格约定的核心客户，可能仅象征性上涨3%—5%。
  • 客户终端售价越高，对芯片小幅涨价的接受度通常越高；终端售价仅十几元或几十元的客户，对价格变化更敏感。

c) 涨价订单目前占比如何？

  • 在机器人等复杂端侧应用中，终端可能采用高通或其他厂商的大型SoC，乐鑫产品仅用于灵巧手、关节或局部连接控制，因此占整机BOM的比例很低。
  • 涨价对客户的影响需要结合终端售价、芯片功能定位及客户利润水平判断。

e) 存储涨价是否会抑制客户开发和拉货需求？

  1. 项目立项判断。
  2. 下单数量。
  3. 生产节奏。
  4. 拉货时间点。
  5. 最终利润水平。
  • 如果价格仅在合理范围内波动，主要考验公司和客户的供应链管理能力；如果涨幅过大，则可能明显影响项目推进和公司季度收入。
  • 当前消费和项目立项整体更加理性，市场已从AR、VR、智能眼镜等尝试性项目，回归刚需及可商业化场景。

d) 公司是否会将40纳米产能转移至国内晶圆厂？

  1. 晶圆良率能否稳定。
  2. 长期生产一致性。
  3. 供应链切换风险。
  4. 与现有晶圆厂的合作经验。
