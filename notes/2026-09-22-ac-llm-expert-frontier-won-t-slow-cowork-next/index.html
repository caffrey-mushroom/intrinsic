摘要

  • 解读Anthropic等模型厂商关于放缓前沿模型能力提升的表态，以及模型厂商之间的竞争节奏；
  • 当前模型能力的发展速度与下游产品、企业实际应用、组织适配之间的匹配问题；
  • 假设模型训练放缓情况下推演推理需求对硬件的支撑，展望2027年算力供需变化；
  • Coding之后的Cowork/办公自动化应用的规模化潜力和商业模式；
  • 开源与闭源模型竞争格局。

以下是专家观点：

Chris：最近Anthropic CEO提出放慢前沿模型能力的提升速度。怎么看待这种观点？以及潜在的影响是什么？

专家：这类说法并不是第一次出现。2024 年时马斯克也曾提出大家要slow down，但他第二年模型照常发布。这其实就是一个胆小鬼博弈：听从他的建议放慢进度，结果他明年就可能反超。所以这种倡议没有实际价值。从第一性原理来看，这个逻辑是合理的，因为现阶段的问题并不是模型能力不够强，导致应用或变现缺乏想象力，恰恰相反，模型能力已经足够，但在与客户或产品团队接触时，会发现知识鸿沟非常大。现在的情况是，模型本身在前端快速发展，下游产品除了coding领域，可能连现有模型能力的十分之一都没有发挥出来。所以即使未来六个月SOTA模型零进步，对于下游应用开发或产品普及几乎没有影响，因为问题不在于模型不够强，而在于产品本身不够好。但从模型开发厂商的角度来看，他们也不会真的放慢进度。Anthropic如果说要放慢，就需要确保Google、OpenAI、Meta、Thinking Machines Labs和微软等公司也一起放慢。虽然他们的能力参差不齐，但你也会担心他们在六个月内追上来。最终结果还是胆小鬼博弈，谁都不会真的放缓。所以这种倡议只是说说而已，没有实际区别。而且，即使能说服美国的模型公司放慢，怎么说服中国的公司也放慢？中国的模型公司肯定不会理会这种倡议。双方继续竞争，等到美国公司调整得差不多了，中国公司就会考虑在某些场景实现反超。如果无法反超，也会在模型架构上进行极致优化，把成本压到对方无法竞争的程度，然后在国际市场上展开竞争。如果无法让所有人都停下，最理性的选择就是自己也不停下。

Chris：如果假设北美模型的速度放慢了，对于硬件层面的需求会有什么影响？在推理侧或应用侧，整体需求是否可以得到支撑？

专家：支撑整体需求增加是非常确定的。首先从应用角度来看，即使是 Google 这样的厂商，目前存在的一个大问题是，真正好用的 AI 产品基本都是 AI startup 做的。大厂如 Google、微软、亚马逊、领英等，做出来的 AI 产品并没有哪一个真正被广泛认可，因为这些团队在推进和打磨产品方面速度很慢。但实际上，大部分普通人在日常生活和办公中用的产品，基本还是这些大厂的产品，比如 iPhone 或安卓手机，微软或谷歌的办公套件。这就导致了一个很大的不匹配。如果是普通白领，上班用微软 Word 和 PPT，下班用苹果手机，会发现 AI 还没有真正渗透到这些核心场景。最多只是边栏加了一个不太好用的 Copilot，渗透率远远不够。假设模型完全不进步，半年内这些厂商把预训练全部停掉，把现有算力全部用于产品落地和推理，现有算力完全可以被消耗掉。实际上，大厂现在普遍面临算力不足的问题。当然，市场上对于算力是否不足的看法差异很大，因为不同规模的公司在落地时感受不同。但如果看 OpenAI 和 Anthropic，这两家拥有的算力非常多。

以 Anthropic 为例，目前大约有 3 个 GW 的算力，运行 Claude Code、Claude Code Design、Claude Work 等应用大约用掉 1 个 GW。明年（2027年）的目标是再增加 10 个 GW。大家会疑惑，这 10 个 GW 怎么用？如果按照他们自己说的放缓模型训练，这 10 个 GW 理论上就要全部用于产品推理。能想象今年（2026年）、明年（2027年）Claude Code 的业务规模是今年的十倍吗？显然难以想象。所以这里存在一个悖论。极大概率是，明年新增的 10 个 GW，可能有 3 个 GW 用于新增模型预训练，3 个 GW 用于开拓细分垂直市场或与企业战略合作，比如服务麦肯锡、毕马威、德勤、安永等公司，拓展业务边界。最后可能有 3 个 GW，加上今年的 1 个 GW，共 4 个 GW 用于拓展 Claude Code 这类 To C 或 To B 的产品，这可能是比较合理的分配。主要还是看明年（2027年）能否把算力用好。如果算力没有用满，到年底突然发现有 2-3 个 GW 用不了，这部分算力释放出来，市场就不会像现在这样觉得算力极度紧缺，整体价格和供需关系会相对平衡一些。但要说算力完全过剩，个人认为还不至于。整体来看，明年（2027年）是否供需平衡，还是极度紧张，主要取决于 Anthropic 等公司如何分配和利用算力。

Chris：即使训练放缓，推理场景的需求带来的硬件支撑性是比较确定的。具体来看，是多场景共同增长，还是会有某些场景出现类似 coding 这样的爆发式 token 需求增长？该如何理解？

专家：token 目前还没有完全饱和，不同企业在 coding 应用上的规模差异很大。坦白说，上半年所谓的 token maxing，主要是因为很多企业领导层对业务不熟导致的。现在大家在控制成本方面，并不是减少 token 使用，而是尽量避免浪费，这反而有助于 token 的普及。例如，一个公司内部，研发或科研人员需要最好的模型，可以用 Fable 或 Astra，甚至允许开 Astra High，每周有一万美元额度。但对于 HR、财务等部门，Kimi K3 这样的模型就足够用了。大部分企业现在都在探索如何合理分配模型资源。还是那个问题，模型自身发展太快，公司管理没有跟上，需求一直非常旺盛。

目前来看，除了 coding 之外，比较靠谱的增长路径是 co-work，也就是办公场景。办公场景在发达国家和发展中国家都容易普及。无论中国还是美国，有大量白领每天都在用 PPT、Excel 和 Word。只要办公自动化做到一定程度，就已经很有价值。虽然很难为每个企业的细分工作流做出 100% 贴合的办公系统，但如果能自动化 70% 的工作，已经非常不错了。剩下的一些工作，比如企业内部可以通过 MCP 的方式，把内部系统接入到网络中。对于常规办公，尤其是互联网导向的企业，这套方案泛化起来并不难。基本思路是把所有办公软件标准化，做成 MCP 或类似 Codex、Claude Code 的系统，然后把公司内部的行政、财务、工程等流程，通过 skill 的方式集成到业务流中。目前模型能力的提升速度远超下游产品和企业管理的适应速度，导致实际应用和需求始终处于极度旺盛但未被充分满足的状态。未来一段时间，硬件和算力的分配与利用效率，将直接影响行业供需关系和产品渗透率。这其实基本上可以解决相当一部分企业的痛点，而且也相对容易规模化。

剩下的部分可能就不太容易规模化，主要是偏垂直场景的use case。比如现在北美整体跑得比较好的use case，一个是医疗，一个是法律。实际上美国的医疗和法律与中国的逻辑非常不同。美国的医疗宏观上来看，都是一堆有资格证的个体户开的小诊所。美国的法律也是这样，所以法律和医疗都是偏精英、个人导向的高付费群体会买单的服务。比如说一个大律师或者德高望重的医生，开了自己的诊所，养了一些助理，钱都是自己出，相当于自负盈亏。所以他们很有动力把自己内部的很多工作流、复杂、冗余的流程自动化，比如预约咨询、开病历、筛查病人过去的诊断记录、看病后报保险等。如果这些流程能自动化，他们会非常满意，付费意愿也很强。这些场景目前做得还不错，但要普及的话，极大概率是靠垂直场景对应的创业公司来实现。还是那个问题，这些小的business、小的个人个体户自己没能力解决这些问题。如果依靠微软解决，也不现实，因为只要公司规模上到十万人，也解决不了这些问题。所以最终每一个垂直行业在北美可能都会出现两三家这样的创业公司，把整个行业的解决方案做得相对比较好。这可能是中期一个很明显的趋势。当然长期来看，他们能否持续发展也不确定，因为Anthropic也不是傻子。如果Anthropic发现某个行业做得特别成功，盈利很好，自己增长放缓时，一定会考虑进入这个产业。所以更多的是一种动态平衡。

Chris：对于cowork场景，从行业经验来看，toB端落地鸿沟具体指什么？

专家：Cowork现阶段主要就是大企业表现不佳，小企业比较挣扎的鸿沟。做这类产品基本只有两条路。比如2023年很多AI产品刚出来时，大部分PPT解决方案都是小团队做的，解决方案质量很差，因为懂模型的人很少。到2025、2026年，目前像Genspark、Manus这样的公司，确实有一部分比较稳定的用户群。但如果看Genspark的用户群，无论是DAU还是MAU，其实都是缓慢下降的趋势。原因很简单，现在模型进步节奏非常快，普通模型做PPT其实也还不错。从长期来看，这类功能肯定是PPT里的PPT生成由微软自己做，Google Slides里的由Google自己做。他们做成第一方服务，用户体验会更加贴合。Genspark整体AI解决方案做得还不错，但PPT做得很差。不是说AI转PPT这件事差，而是得先有一个PPT软件，再用AI生成该格式下的PPT，再转换成Google Slides或微软PowerPoint的格式，所以基础比较弱，不好推广。只要微软和Google推出差不多的解决方案，Genspark和Manus这样的企业就很难撑下去。

从长期来看，还是大厂慢慢醒悟，把产品打磨到合格，用户自然不需要再下载第三方服务、登录各种账号、付费，再切回自己的软件去用，这肯定是终局。但现在这个阶段还有一个问题，目前推出的产品，比如Genspark，整体解决方案做得好，但也只是今年上半年。模型进步和强化学习等方法论成熟，使得可以用非常便宜的价格做PPT生成。某种程度上，PPT或co-work系列降本也是由Genspark这类企业推动的。他们现在新版模型Gen-1，是用MiniMax的M3后训练出来的，在code design或co-work场景下可以和OpenAI 5.1打平，但成本只有OpenAI的1/8或1/10左右。所以从投资收益角度来看，是第一个把co-work跑回来的。

同样道理，Anthropic会不会让自己赔钱？但普通人有多少会用claude co-work生成自己的PPT？一个PPT生成要40美金，这在美国可能有人用，但在中国基本不可能。白领一个月工资有限，网上生成一份复杂PPT，500元人民币就没了，这不容易规模化。所以演进的路径基本上就是大厂前两年一直无所作为，但它有现成的应用生态和大量企业级、个人付费用户，只要稍微做点什么，不至于太惨。小厂在过程中动得最快，客观推动了垂直场景产品落地和模型进步，但长期来看势能可能被大厂慢慢吸走。这基本上是co-work类产品的演化路径。

Chris：在当前阶段，人才供给失衡，模型能力远超实际应用需求的情况下，开源和闭源模型之间的竞争格局会如何发展？

专家：从长期来看，开源模型一定会有它的一席之地，不可能被打败。无论从业务需求还是像老黄卖卡的角度，大家都希望更多人用他们的卡。开源模型、闭源模型、NeoCloud、Inference Provider在行业内不同角色之间相互制衡、竞争，最终都买卡。从任何逻辑来看，开源模型都应该有自己的位置。但个人认为，中短期内开源模型的日子可能不会太好过，尤其是中国的开源模型。美国的开源模型已经开始赶上了，过去美国没有能打的开源模型，现在Meta的Llama 3和Llama

  1. 1已经进入这个行列。但国内情况不同，之前遇到一些NVIDIA的人，他们说最好的内核工程师在北京。从系统优化和模型架构层面，中国人的智力水平毋庸置疑。但现在模型训练范式又从架构优化、后训练、调优转回到大规模预训练，这让情况变得复杂。中国缺的不是智力水平，而是物理意义上的算力。2025年到2026年上半年，中国模型势头很猛。过去的逻辑是AI想象空间无限，不愿意处理低端客户，主要服务大厂，撑住千亿ARR就可以。很多NeoCloud现在也搞Token

Factory，但实际收入有限。Anthropic过去允许蒸馏，贡献收入，低端用户买单他们也不介意，因为这些用户买不起他们的服务。但现在开源模型，尤其是中国模型追得太快，已经接近同一水平，Anthropic一定会限制蒸馏和技术能力。中国公司要么解决数据问题，要么突破算力瓶颈。模型架构优化更多是在推理或训练阶段提升内存复用率、降低成本、提升存储，但本质上不是扩大蛋糕，而是降本。过去大家配合，Anthropic提升模型智能，中国优化模型架构，推出更小更快更便宜的模型，形成生态位。但现阶段如果被卡死，只能优化推理效率或KV Cache，这对整体模型智能进步意义不大。
