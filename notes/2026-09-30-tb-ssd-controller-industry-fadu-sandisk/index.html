00:59:35] What is CXL [compute xpress link]? What does it do and why is it needed? Who are the main players?

Expert [01:00:01]: Let's start with the server. The whole problem is the CPU, whether it's AMD or Intel. As the number of cores have grown over the last 10 years, the bandwidth per core has declined. If we look at CPU from hyperscale usage point of view, the usage has gone down, and there is an unused compute power that they cannot monetise, okay? That's the problem statement. In order to solve that, previously, we had three or four different interfaces where we could add additional memory to the CPU. If we look at CPU, Intel and AMD, they have fixed number of slots, DDR slots where you can put the number of RDIMMs on it. The objective is we need to have a cache coherent memory attached to the server could be slower, and we are okay with that. CXL solves that problem. It is a cache coherent memory on PCIe bus, you can add more DRAM as an E3 or add-in card. Now you can utilise the unused compute power and sell that to your customers. Hyperscalers can do that. That's the first use case. The second use case is now KV cache. It has become a very big and important use case.

CXL solves the problems of underutilisation of the CPUs by adding more memory on the PCI bus. The fancy thing is it's a cache coherent, data is not lost. It is slower. If we look at how much of the memory is hot memory, warm memory and cold memory, industry has been saying this for a long time, about 35-40% of the memory on server is hot. 30-40% is probably warm and 10-15% is cold. Cold and warm tiers are very good candidates to be placed on CXL. That's where the second use is. The third use is still there is some memory underutilised. Let's pool it together. We pool it at the rack level. Now you can utilise most of your memory and sell that as a service to your customer. The reason for doing that is if you look at how much DRAM is purchased by hyperscalers, how many CPUs are purchased by hyperscalers and the AI infra or infra, IT infra is underutilised by 40%. 40% of USD 1tn, that's a lot of money and dedicated to CPU and memory.
