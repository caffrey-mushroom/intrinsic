SUMMARY

Overview

The discussion examines whether TSMC’s reported 3D DRAM plans signal a move into conventional memory manufacturing. The expert argues that TSMC is more likely to expand its role in advanced packaging and HBM base-die production, while continuing to rely on Samsung, SK Hynix, and Micron to manufacture memory stacks. The conversation also covers HBM technology, capacity constraints, costs, competition, and customer diversification.

Key Insights

The expert views TSMC’s likely role as a partner to memory manufacturers, not a fourth commodity DRAM producer. Its focus would be custom base dies made on advanced logic processes and integration of memory stacks into packages. Advanced base dies and 3D packaging could reduce data-transfer delays, power use, and heat, helping address AI systems’ memory bottlenecks. The expert expects TSMC to supply most HBM4 base dies initially, but believes Samsung could gain share as demand from customers beyond Nvidia grows. HBM technology may advance more slowly as manufacturers balance performance goals against cost and yield. Using fewer memory layers in some products could improve yields and increase base-die demand. The expert considers a TSMC move into standalone memory unlikely. Building or converting a memory fab by 2029 would be a signal of a change in strategy; otherwise, collaboration is the more probable path. Suppliers are likely to reduce reliance on Nvidia and seek additional customers, particularly Google and Amazon. The expert expects this diversification to spread across the semiconductor supply chain.

BC: Regarding the breakthrough of the memory wall that you mentioned earlier, apart from TSMC serving as a manufacturer of HBM base dies, what other approaches do you think companies such as Nvidia will try in order to overcome the memory wall? TC: TSMC and Nvidia are currently pursuing two approaches to address the memory wall. The first is for TSMC to take full responsibility for the base die, as I mentioned earlier. The second is to use advanced process technology. I will provide a more detailed explanation of these two areas. First, regarding the base die, the new generation of base dies will not simply be base dies. They will also incorporate the memory controller and certain logic functions that require extensive communication with memory.

The base die was previously manufactured on a 12 nm process and is now being manufactured on a 3 nm process, but the die size remains the same. What does that indicate? If a 3 nm base die contained the same functions, it should be smaller. Its area should be reduced. However, because it remains the same size, it means more components and functions have been incorporated. The memory controller and certain functions that need to communicate extensively with HBM will be placed on the base die. This has two benefits. The first is that it can alleviate the memory-wall problem because large volumes of data will no longer need to travel from the base die to the compute die. Some functions that require lengthy or frequent communication will be placed on the base die, allowing them to communicate directly and quickly with HBM. This can alleviate the memory wall.

The second benefit is that power dissipation and the heat generated by power consumption can also be reduced. Data does not need to travel as far or move back and forth as frequently. It only needs to communicate with memory over a very short distance. This is the improvement offered by the base die. It increases functionality, reduces power consumption, and lowers heat generation. That is the first approach. The second approach involves advanced packaging. As I mentioned, this project is being handled by TSMC’s advanced packaging business unit. TSMC will transition the current CoWoS 2.5D package to its most advanced 3D package, known as the SoIC package.

The benefit of the SoIC package is that it uses more advanced technology to stack chips vertically. Horizontal communication is no longer required because all communication occurs vertically. The vertical communication path is much shorter, and resistance is also significantly reduced. This indirectly lowers power dissipation and further reduces heat generation. Therefore, improvements are being made in both areas simultaneously. This can make Nvidia’s new solutions more efficient, reduce their power consumption, and improve performance.

As I mentioned earlier, Nvidia is essentially planning two solutions. One is called NV-HBM, which is Nvidia’s proprietary solution. Products sold to other customers could also use the NV-HBM solution. However, Nvidia and TSMC are also planning another general-purpose version, which is the JEDEC version of HBM. This version will use a more mature process, possibly remaining on 12 nm or moving to no more advanced than 7 nm.

The main purpose is to supply applications that do not require such high performance or such low power consumption but need a lower-cost solution. Manufacturing the base die on 12 nm or 7 nm will be less expensive. They will develop it as a more general, open solution that anyone can adopt. Therefore, two solutions are currently being planned. In both cases, TSMC will take full responsibility for the base-die solution.
