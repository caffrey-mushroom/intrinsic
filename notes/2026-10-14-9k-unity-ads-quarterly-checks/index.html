1. Q3广告业务表现与增长驱动

a) Q3 Vector相关广告支出的实际增速如何，是否超出管理层预期？

  • Q3实际表现明显好于此前预期：
  1. 广告总支出环比增长约40%，高于此前“环比增长超过20%”的判断
  2. iOS端环比增长约46%
  3. Android端环比增长约33%-34%
  4. 增长拐点大约出现在Q3第3至第4周，此后持续加速
  • 从同比口径看：
  1. Q3整体网络广告支出超过去年同期的2倍
  2. 根据访谈展示的图表，iOS端同比增幅约165%，Android端接近100%
  3. iOS增速持续快于Android，是Q3增长的主要贡献端之一

b) 为什么iOS和Android广告支出均实现高增长，且iOS增速更快？

  • 核心原因是Vector模型能力和广告产品效果同步改善：
  1. Day 28及其他长周期广告活动的表现持续提升
  2. Vector在预测、机器学习、用户定向等方面进行了大量更新
  3. 平台能够更精准地筛选高质量、高留存用户，提升广告主ROAS
  4. 单个广告主的投放效果改善后，会主动扩大预算
  • 客户口碑形成了正向循环：
  1. 现有客户满意度提高，并向其他广告主推荐Unity
  2. 平台广告主数量增加
  3. 每位广告主的平均支出同步上升
  4. Q3增长并非由一至两家一次性大客户单独驱动，而是较广泛的客户扩量
  • iOS端增速更快的具体量化原因未被进一步拆分，但从实际数据看，iOS对Vector长周期价值预测及优质用户获取的反馈更明显。

c) 为什么Q3管理层指引只有19%-21%，明显低于实际广告支出趋势？

  • 受访者未能给出确定解释。
  • 可能的口径差异包括：
  1. 受访者展示的数据主要针对Unity Ads网络
  2. 公司整体指引可能还综合了LevelPlay、游戏引擎及其他业务
  3. 广告支出增速不完全等同于Unity合并口径收入增速
  4. 图表与管理层指引可能采用了不同时间范围或确认口径
  • 因此，Unity Ads网络的高增长不能直接等同于公司整体收入增速。

2. Vector技术升级与Day 28产品演进

a) Vector在Q3前后进行了哪些核心升级？

  • Vector机器学习技术栈和产品体系经历了连续升级：
  1. 2025年10月，Unity升级Vector机器学习技术栈
  2. 2026年3月，在原有IAP广告活动基础上，推出广告变现及混合变现广告活动
  3. 2026年4月，进一步更新Vector模型和基础设施
  4. 随后将Day 28广告活动向所有客户和广告主开放
  5. 广告及混合优化器在6月左右全面开放后，广告支出趋势明显上行
  • 产品全面开放后形成数据飞轮：
  1. 更多广告主能够实际测试Day 28产品
  2. 每位广告主产生的数据持续输入机器学习模型
  3. 模型预测与定向效果随数据积累而提升
  4. 效果改善进一步吸引客户增加预算，推动业务加速增长

b) Day 28广告活动的渗透率提升到什么水平？

  • Q2时，Day 28广告活动已被超过25%的广告主采用。
  • 最新展示数据显示：
  1. Day 28广告支出占比已由此前约25%提升至37%
  2. 在排名前100的游戏中，有95款在Q3开展了Day 28广告活动
  3. 重点客户SEA Games截至9月底的Day 28广告支出占比达到55%
  4. 部分广告主已将预算从Day 7转移至Day 28，甚至只投放Day 28
  • Unity仍建议客户同时投放Day 7和Day 28：
  1. 两者采用不同模型，覆盖的用户周期不同
  2. Unity的Day 28模型需要借助Day 7数据进行学习
  3. 同时投放有助于维持各类用户群体活跃度，并提升长期学习效果

c) Day 28广告活动对留存、ARPU和ROAS有何影响？

  • 留存率是Day 28产品最突出的优势：
  1. IAP模式下，第28天留存率可提高约35%
  2. 混合变现模式下，留存用户数量可提升至2倍以上
  3. 另一组质量样本显示，100%的游戏留存率均有改善，平均提升约80%
  • ARPU短期可能下降：
  1. IAP模式ARPU下降约7%
  2. 广告收入模式ARPU下降约3%
  3. 混合变现模式ARPU下降约37%
  • ARPU下降主要因为新增的长留存用户单用户价值相对较低，但其生命周期更长，长期累计价值可能优于Day 7活动。
  • ROAS方面：
  1. Q3各观察窗口的ROAS均呈提升趋势，覆盖Day 0、Day 7和Day 28
  2. 质量样本中约80%的游戏实现ROAS增长
  3. 由于初期CPI较高，Day 15、Day 30及Day 45前后的ROAS可能偏低
  4. 随投放周期延长和用户留存改善，ROAS会逐步回升
  5. 仅依赖短期回收容易低估Day 28活动的长期价值

3. 广告价格、投放效率与增长质量

a) Q3 eCPM表现如何？

  • eCPM同比增长显著：
  1. 美国市场同比增长接近80%
  2. Tier 1市场同比增长约74%
  3. 全球市场同比增长约60%
  • 环比仍保持增长，但增幅低于同比：
  1. 美国环比增长约5%
  2. Tier 1环比增长约6%
  3. 全球环比增长约15%
  • Unity广告支出与展示量之比上升，说明单次展示价格变高，平台流量的定价能力有所增强。

b) Unity是否通过降低抽成或补贴客户来推动广告支出增长？

  • 受访者无法确认Unity后端是否调整了抽成比例或采用补贴策略。
  • 但其认为增长的核心并非单纯依靠补贴：
  1. 用户留存率的明显提升无法仅通过调整抽成实现
  2. 产品团队和Vector团队在AI预测、定向和模型优化方面进行了长期投入
  3. 早期测试曾因CPI较高受到客户质疑，但最终留存及长期回收证明产品有效
  4. 当前广告主普遍增加预算，说明效果改善具有一定广泛性
  • 因缺少抽成、返点及净收入数据，尚不能完全排除商业政策对增长的辅助作用。

c) Q3增长是否由少数大客户或一次性预算推动？

  • 受访者认为并非如此：
  1. 更多广告主正在进入Unity广告网络
  2. 所有广告主的平均每日支出均在增长
  3. 增长体现为客户数量和单客户支出的双重提升
  4. 客户扩量主要基于投放效果改善和满意度提高
  • 访谈未披露广告主总数和单个广告主平均支出的绝对值，因此无法进一步量化客户集中度。

d) Unity广告当前是否适合所有广告主？

  • Unity的CPI并不低，平台目前不属于低成本流量渠道。
  • 成功投放需要满足一定条件：
  1. 产品本身具备较好的用户价值和变现能力
  2. 广告主能够接受较高前期获客成本
  3. 需要以长期留存和生命周期回收评估效果
  4. 通过不同广告活动组合反复测试，寻找适合自身产品的投放方式
  • 因此，并非所有广告主都能立即获得成功，但优质游戏或高LTV应用仍可通过Unity实现盈利。

4. Runtime数据与Unity的技术护城河

a) Runtime数据在广告推荐中发挥了什么作用？

  • Unity已将Runtime及游戏引擎数据用于优化用户获取活动。
  • 引擎数据可以提供其他广告网络较难获取的用户行为信息，包括：
  1. 用户每天观看广告的次数
  2. 用户在游戏中的购买时间和购买行为
  3. 用户每日游戏频次
  4. 从首次观看广告到实际转化所需时间
  5. 用户留存、付费及广告互动等长期行为
  • 这些数据可分别优化不同类型的广告活动：
  1. 广告变现活动：判断最佳获客时机和广告展示时点
  2. IAP活动：判断用户进入游戏后何时最可能付费
  3. 混合变现活动：兼顾广告收入与应用内购买
  4. 相似游戏推荐：识别更适合目标用户的游戏品类

b) Unity的数据闭环为何具有差异化优势？

  • 市场上约70%的游戏使用Unity引擎开发。
  • 当开发者同时使用Unity引擎、Unity Ads、聚合平台、变现工具及试玩广告工具时，各类数据均可输入Vector。
  • 由此形成闭环：
  1. 引擎提供底层用户行为数据
  2. 广告网络提供投放与转化数据
  3. 聚合和变现工具提供广告收入数据
  4. Vector利用数据持续训练模型
  5. 模型反向改善UA预测、用户定向和广告活动效果
  • 受访者强调，相关数据使用符合政策要求。

c) MMP数据在Vector模型中有何作用？

  • MMP集成是Vector运行的重要信号来源。
  • Unity要求客户至少提供180天数据，用于：
  1. 识别长期用户价值
  2. 训练Day 28等长周期模型
  3. 提高用户获取活动的预测准确性
  4. 判断不同投放渠道、广告活动及用户群体的真实回报
  • 长历史数据是Vector模型能够持续学习并发挥效果的重要前提。

5. Unity与AppLovin的竞争格局

a) Unity未来是否有机会追赶或超过AppLovin？

  • 受访者对此持积极判断：
  1. AppLovin是优秀的广告网络和聚合平台
  2. Unity除广告网络和聚合平台外，还拥有游戏引擎及Runtime数据
  3. 引擎数据是AppLovin短期难以复制的核心优势
  • 从部分客户的平台排名看：
  1. Unity过去可能仅排在广告支出平台的第4或第5位
  2. 当前AppLovin排名第1，Unity已上升至第2
  3. 两者差距正在逐季度缩小
  4. Unity在客户预算和市场声量中的份额均在提升
  • 受访者预计，Unity流量未来可能超过AppLovin，但未给出明确时间表。

b) Unity当前主要抢占哪些平台的预算份额？

  • Unity可能从多家广告网络获得预算，但最明显的份额来源是AppLovin。
  • 主要原因包括：
  1. Unity和AppLovin在Day 28广告活动上形成直接竞争
  2. 目前两家公司拥有相对成熟的Day 28广告产品
  3. Moloco可能也在测试类似产品，但成熟度暂不及前两者
  4. Unity能够直接与AppLovin竞争高留存、长生命周期用户
  • 受访者判断，AppLovin份额增速相对有限，而Unity份额持续增长。

c) Unity与AppLovin在产品和创意能力上各有哪些优势？

  • Unity的主要优势：
  1. 游戏引擎及Runtime数据
  2. Day 7与Day 28联动的模型学习机制
  3. 高质量、长留存用户获取能力
  4. 长视频广告在平台上的表现较好
  • Unity目前的相对短板：
  1. 尚无类似AppLovin的自动化创意生成工具
  2. AppLovin可基于一个竖版视频自动生成多种尺寸及文本组合
  3. Unity在广告创意自动化和批量生产方面仍有提升空间
  • Unity当前更倾向使用较长视频，以筛选质量更高、留存周期更长的用户。益智游戏头部广告主中，60秒及其他长时长视频表现较好。

6. 非游戏广告业务拓展

a) 非游戏广告支出目前占比多少？

  • 受访者没有准确数据，估计非游戏广告支出占Unity总广告支出的5%-10%。
  • 与过去游戏流量占比约99%的结构相比，非游戏业务已有明显突破。
  • 非游戏流量规模超出受访者此前预期，也是Q3淡季仍能实现增长的原因之一。

b) 哪些非游戏行业适合在Unity投放？

  • 短剧应用：
  1. 通常具备订阅或应用内购买模式
  2. 对优质付费用户和长周期价值预测有较高需求
  • 健康类应用
  • 工具类和实用类应用
  • 其他拥有订阅、IAP或高LTV模式的应用
  • Unity在应用内购买用户获取及优质用户筛选方面具备较高市场认知度，因此更适合生命周期价值较高的非游戏应用。

c) 为什么此前未使用Unity的非游戏客户开始尝试投放？

  • 主要由变现端和市场口碑共同推动：
  1. Unity在部分非游戏应用的竞价广告网络中取得较高钱包份额
  2. 客户从变现结果判断Unity拥有适合非游戏业务的流量
  3. 既然能够通过Unity获得变现收入，也愿意尝试在Unity开展UA
  4. Unity业务增长和市场研究提高了平台关注度
  5. 客户实际测试后效果较好，因此持续投放并推荐其他客户尝试

7. Q4及明年增长展望

a) Q4能否继续保持较高增长？

  • 受访者对Q4趋势较为乐观：
  1. 10月初的实际表现已好于去年同期
  2. 当前内部预期约为增长50%，但访谈未明确该数据的具体口径
  3. 按当前趋势，Q4广告支出同比增幅可能超过100%
  • 受访者未直接确认Q4能否继续实现30%-40%的环比增长，因此应区分：
  1. Q4同比增长可能继续非常强劲
  2. Q4环比增速尚无明确量化判断
  3. 广告支出增长也不能直接等同于公司确认收入增长

b) 明年的主要增长驱动因素有哪些？

  • 广告主数量扩张：
  1. 吸引更多游戏及非游戏广告主进入Unity网络
  2. 通过客户口碑和实际效果扩大市场覆盖
  • 单客户钱包份额提升：
  1. 现有广告主仍有更多预算迁移空间
  2. Unity在客户投放平台中的排名持续提升
  • 产品矩阵扩展：
  1. CPA广告活动
  2. 留存广告活动
  3. Offerwall积分墙
  4. Mediation广告聚合
  5. 游戏引擎
  6. Playable Tool试玩广告工具
  • Vector能力横向复制：
  1. 明年计划将Vector整合至更多产品
  2. 由单一广告优化能力升级为全产品机器学习底座
  3. 受访者预计届时整体业务规模可能明显超过今年

c) CPA和Offerwall可能带来多大增量？

  • Vector CPA广告活动支出同比增长约6倍，可能成为Q4的重要产品。
  • CPA主要针对游戏内特定事件，运行逻辑类似早期Google CPA模式，但底层由Vector支持。
  • Offerwall积分墙可通过任务激励提升用户互动，例如：
  1. 用户观看一定数量广告
  2. 完成指定任务
  3. 获得游戏内助推器或奖励
  • 该模式有助于同时提升广告库存、用户活跃度及游戏变现效率。

8. Google AI游戏合作与Unity Spark机会

a) Google Playground与Unity Spark的合作对Unity意味着什么？

  • Google Playground已于10月在美国面向18岁以上用户上线，Unity Spark也已推出。
  • Google Playground可将文本提示转化为可游玩、可分享的游戏。
  • 这一合作可能使Unity从传统专业编辑器进一步升级为AI生成游戏的底层引擎。
  • 核心价值包括：
  1. 降低游戏开发和编程门槛
  2. 让拥有创意但缺乏编程能力的人也能制作游戏
  3. 扩大游戏创作者和游戏内容供给
  4. 增加用户玩游戏、制作游戏及参与游戏生态的时间
  5. 为Unity引擎、UA、聚合、变现工具及数据业务带来新增需求

b) Unity可以通过哪些方式实现AI游戏业务变现？

  • 潜在变现方式包括：
  1. 运行时费用
  2. 高级AI编辑工具费用
  3. 角色、资产及预制关卡等内容费用
  4. 广告聚合服务
  5. 应用内购买服务
  6. 用户获取服务
  7. 专业创作者订阅或增值服务
  • 运行费用预计将低于普通Unity编辑器账户费用，并可能提供免费试用。
  • 由于游戏只需数分钟即可创建，费用设计原则是保持足够低的使用门槛，同时确保Unity及Google能够获得商业回报。

c) 收取引擎或运行费是否会限制创作者参与？

  • 受访者认为现阶段不会构成明显限制：
  1. 收费水平可以根据创作者需求进行定制
  2. 基础功能可能通过低价或免费试用吸引用户
  3. 高阶资产、专业AI功能和商业化工具可单独收费
  4. 运行费只是多种变现方式之一，不必完全依赖前端收费
  • 具体费率目前无法披露。

d) Unity与Google的合作能否发展成类似Roblox的生态？

  • 目前判断仍然过早，需要经过产品测试和用户验证。
  • 长期可能形成类似Roblox的创作者生态，但现阶段战略重点仍是：
  1. 推动Unity引擎使用量增长
  2. 提升Unity Ads用户获取支出
