存储行业价格及手机供应链专家访谈纪要

1. 消费电子存储价格走势与周期判断

a) 2026Q3至2027Q2，手机行业DRAM和NAND长协价格如何变化？

  • 以下均为手机行业长协价格的环比变化，不代表现货价格：
  1. 2026Q3：DRAM上涨约8%～13%，NAND上涨约5%～9%。
  2. 2026Q4：DRAM上涨约6%～10%，NAND上涨约0%～5%。
  3. 2027Q1预计：DRAM上涨约4%～7%，NAND变化约-2%～2%。
  4. 2027Q2预计：DRAM上涨约0%～5%，NAND变化约-5%～0%。
  • 2026Q4的价格已经基本落地，2027Q1、Q2尚未最终确定。
  • NAND在2026Q4已经出现边际下降迹象，但长协价格目前总体稳定；预计从2027Q1开始，多数NAND料号不再上涨，部分料号可能下跌。
  • PC行业的价格走势较手机行业更稳定，涨幅也相对更低。

b) 为什么DRAM价格仍将维持强势，而NAND可能率先转弱？

  • 企业级DRAM、HBM等产品的供需缺口预计仍将持续1～2年，其价格涨幅明显高于消费电子产品。
  • 2027年下半年以后，各原厂新增产能有望逐步释放，正常情况下，存储价格不太可能继续大面积上涨。
  • 后续较理想的状态是价格持平，多数料号缓慢小幅下降，但下降速度预计慢于以往周期。
  • NAND在消费电子领域的实际缺口并没有市场此前预期的那么大，终端拉货意愿也在减弱，因此价格率先失去上涨动力。
  • DRAM受服务器、AI等需求挤占产能的影响更明显，供给压力仍然较大，价格韧性强于NAND。

c) 本轮存储周期与以往周期有何不同？

  • 以往存储周期通常由原厂主动减产推动，价格上涨后又可能快速跌回低位。
  • 本轮周期的核心是需求拉动及产能向服务器、AI等高价值领域转换，不能简单按照传统减产周期理解。
  • 由于原厂将更多晶圆产能分配给服务器，消费电子可获得的产能受到压缩，因此本轮周期预计持续时间更长。
  • 专家判断，整个2027年甚至2028年上半年，消费电子存储价格仍可能处于相对高位；即使价格开始回落，手机厂商仍将承受较大成本压力。

2. 2026Q4手机DRAM主流价格与厂商差异

a) 目前主流DRAM料号的每GB价格大致是多少？

  • 以下为2026Q4长协平均价格，以三星主流报价为基准，单位按专家口径为美元/GB：
  1. R4X/低代际料号：约1.40～1.49美元。
  2. R5：约1.51～1.60美元。
  3. R5X：约1.60～1.70美元。
  • 上述报价没有进一步区分速率、晶圆切割和容量规格，因此属于平均区间。
  • 16GB、24GB、32GB等不同容量颗粒经过晶圆分割后，单位容量成本会存在差异。
  • 苹果2026Q3相关产品的采购价格约为1.50美元/GB；由于采购规模大、供应链控制能力强，价格略有优惠。
  • 原始记录对部分DRAM料号存在转写差异，具体型号仍应以后续正式报价单为准。

b) 不同DRAM原厂相对三星的价格差异是多少？

  • 以三星为价格基准：
  1. 长鑫：低约5%～8%。
  2. 海力士：低约2%～4%。
  3. 美光：低约3%～6%。
  • 中端产品的主流价差通常只有3%～5%，折算到每GB后往往只是几美分，通常不到0.1美元。
  • 高端产品的价差可能相对更明显，但近期不同原厂之间的整体价差正在收窄。
  • 当前市场仍有供给缺口，各原厂没有明显通过低价争夺市场份额的意愿。

c) 为什么三星DRAM报价普遍高于其他原厂？

  • 三星市场份额和晶圆产量较高，缺货环境下手机厂商对其依赖度更高。
  • 三星掌握较多高端料号，尤其是LPDDR5X 8533、10667等高速率产品，具备更强的定价能力。
  • 在时序、速率、良率、寿命和一致性方面，三星高端产品相对更优。
  • 三星与其他厂商并不存在显著代差，但在高端料号上仍保持一定的技术和质量优势，因此能够获得价格溢价。

d) 2026Q4不同DRAM产品的实际涨幅如何？

  • R5X整体涨幅约7%～11%：
  1. 三星长期采购订单上涨约9%～10%。
  2. 三星新增、增产订单上涨约12%～15%。
  3. 海力士上涨约5%～7%，部分原因是2026Q3涨幅较低后出现补涨。
  4. 长鑫上涨约3%～5%。
  • R5整体涨幅不超过6%：
  1. 三星上涨约3%～6%。
  2. 海力士上涨约2%～4%。
  3. 长鑫上涨约2%。
  • 不同原厂的季度定价、供货节奏和涨价方式存在差异，但同一料号之间的绝对价差没有明显扩大。

e) 当前手机DRAM的产品结构如何？

  • 暂不考虑出货量不足3%～4%的R6：
  1. R5X出货占比约42%～45%。
  2. R5出货占比约36%～40%。
  3. R4X占比约20%。
  • R5X和R5合计接近80%，R4X正在持续被挤压。
  • 三星、海力士对Legacy产品已明显减产或停产，进一步推动行业向R5、R5X升级。

3. 2026Q4手机NAND主流价格与涨价情况

a) 目前三星主流NAND产品价格是多少？

  • 以下均为2026Q4长协价格，单位为美元/GB：
  1. 三星UFS 2.2：约0.240～0.255美元。
  2. 三星236层UFS 3.1：约0.270～0.280美元。
  3. 三星236层UFS 4.1：约0.290～0.310美元。
  4. 三星276层UFS 4.1：约0.310～0.325美元。
  5. 236层QLC：约0.210～0.230美元。
  • 专家现场将UFS 2.1价格修正为约0.22～0.23美元，并说明其比UFS 2.2低约3%～5%；该绝对价格与降幅口径存在一定偏差，建议后续结合正式报价进一步核实。

b) 长存主流NAND产品价格是多少？

  • 长存232层UFS 2.2：约0.228～0.240美元/GB。
  • 长存232层UFS 3.1：约0.240～0.255美元/GB。
  • 长存232层UFS 4.1：约0.260～0.275美元/GB。
  • 长存321层UFS 4.1：约0.280～0.300美元/GB。
  • 长存QLC及部分SSD产品价格约0.20～0.22美元/GB。
  • 当前市场以200层以上产品为主，100多层产品的使用量已经明显下降。

c) 不同NAND原厂相对三星的价格差异是多少？

  • 以三星为基准：
  1. 长存低约7%～10%。
  2. 海力士低约3%～5%。
  3. 铠侠低约4%～6%。
  4. 闪迪低约4%～5%。
  5. 美光低约3%～6%。
  • 长存的价格优势相对明显，但本轮周期中，各家价差远小于过去国产替代初期约15个百分点以上的水平。

d) 2026Q4最具代表性的NAND涨价案例是什么？

  • 以主流236层UFS 3.1为例：
  1. 三星涨幅约5%～6%。
  2. 海力士涨幅约3%～4%。
  3. 长存同类产品价格基本持平。
  • 长存目前主要涨价的是处于产能爬坡阶段的UFS 4.0、UFS 4.1产品。
  • UFS 3.1供给相对充足，且消费电子NAND缺口有限，因此长存该类产品不具备明显涨价基础。

e) 长存为什么没有跟随海外厂商大幅涨价？

  • 消费电子NAND实际供需缺口有限，终端拉货意愿较弱。
  • 长存TLC供货规模较大，需要继续扩大市场份额，必须维持一定价格优势。
  • 对国内手机厂商而言，长存在价格、供应时效和本地化方面具有优势，若需要调整订单，通常会优先削减海外供应商，而非长存。
  • 长存产品与进口产品存在直接替代关系；如果失去价格优势，且市场又不处于极度缺货状态，其国内竞争力将明显下降。

4. 安卓品牌与苹果的采购价格及供应结构

a) 本次价格是否可以代表整个安卓手机行业？

  • 本次价格区间主要以OPPO采购价格为基础，并进行了模糊化处理。
  • 该区间基本可以覆盖80%以上安卓手机厂商的采购价格。
  • 小米、OPPO、vivo、荣耀等企业在不同料号上的采购价格会存在差异，但通常不超过3%～7%。
  • 差异主要来自采购批量、单一料号使用规模、供应商合作比例和供货组合。
  • 华为使用长存、长鑫的比例较高，部分产品采购价格可能比其他安卓品牌低约3%～5%。

b) 苹果的NAND供应结构如何？

  • 苹果2026年NAND供应占比大致为：
  1. 铠侠约23%。
  2. 闪迪约23%。
  3. 三星约24%。
  4. 海力士约24%。
  5. 美光约12%。
  • 各项占比为大致口径，合计可能因四舍五入或统计周期差异超过100%。
  • 近两年苹果对铠侠NAND的使用比例明显提升。
  • 苹果对供应链管控更直接，因此在NAND领域存在锁量、锁价或锁定价格浮动区间的合作模式。

c) 苹果的采购价格是否明显低于安卓厂商？

  • 在相同料号、相同速率和不考虑质量分档的情况下，苹果采购价格通常比核心安卓厂商低约8%～10%。
  • 苹果的大批量采购协议通常以半年为周期，而安卓手机厂商多数按季度议价。
  • 苹果要求同一晶圆中质量最优的颗粒，因此如果考虑质量分档，其名义价格并不一定低。
  • 苹果DRAM目前主要锁量，不完全锁价；NAND锁价能力相对更强。

d) 苹果是否以DRAM 2美元/GB、NAND 0.33美元/GB锁定2027Q1产能？

  • 供应链曾传出苹果以DRAM 2美元/GB、NAND 0.33美元/GB锁定三星2027Q1高端产能和价格。
  • 该价格尚未形成正式合同，真实性仍需谨慎验证。
  • 产能锁定的可信度较高，但即使是苹果，也很难完全锁定DRAM价格。
  • 如果该交易成立，主要原因包括：
  1. 提前锁定三星高端料号核心产能。
  2. 为年度长协重新谈判提前做准备。
  3. 三星借苹果高价采购向市场释放需求强劲、价格仍可上涨的信号。
  • 该价格对安卓厂商而言基本难以承接。
  • 即便苹果接受三星部分高价产能，综合海力士、美光、铠侠、闪迪等供应商后，其整体采购均价仍不会达到上述水平。

5. 手机厂商与数据中心客户的长协条款差异

a) 手机行业与数据中心的长协周期有何不同？

  • 手机行业LTA长协通常为1年，部分高端料号约1.5年，很少签订2年以上协议。
  • 数据中心客户通常签订3～5年长协。
  • 手机产品生命周期短，新机发布和季度备货变化较大，因此不适合长期锁定固定采购量。
  • 数据中心需求周期更长，且需要提前锁定大量服务器存储产能。

b) 双方在预付款、保证金和履约约束方面有何差异？

  • 数据中心客户对产能锁定要求严格，供货优先级最高，通常需要支付10%～40%的预付款或较高保证金。
  • 手机厂商过去基本不支付保证金；在本轮缺货周期中，三星、海力士可能要求支付10%～20%的预付款，部分规模较小的厂商可能支付30%。
  • 手机企业允许在季度之间协调产能、延后发货或砍单，但调整幅度通常限制在15%～25%。
  • 数据中心合同具有较强刚性，原厂必须满足最低供货量，客户也必须完成最低提货量；违约可能直接损失预付款或保证金。

c) 手机与数据中心客户在定价机制上有何不同？

  • 手机厂商通常按季度议价，核心模式是“锁量不锁价”。
  • 价格受市场供需、拉货节奏、产能分配及具体料号影响，季度之间可能出现明显跳涨。
  • 数据中心客户的价格上下限通常直接写入3～5年合同，并按照合同机制执行。
  • 数据中心价格短期跳跃性较低、稳定性更强，但相应履约约束也更严格。
  • 手机厂商之间的合同周期大体一致，主要差异体现在季度供货量、上下浮动比例及不同料号的供货比例。

d) 当前新增产能的分配优先级如何？

  • 专家口径显示，新增产能约80%～90%可能优先分配给服务器。
  • 现有产能中约50%～60%也可能优先供给服务器。
  • AI和数据中心需求持续挤占消费电子产能，是手机DRAM价格维持高位的重要原因。

6. 存储涨价对手机BOM、定价和终端需求的影响

a) 涨价前，存储占手机BOM成本的比例是多少？

  • 2000元以下低端机型：DRAM与NAND合计占BOM约15%～18%。
  • 2000～4000元中端机型：约12%～15%。
  • 4000元以上高端机型：约12%～15%。

b) 当前存储占手机BOM成本的比例上升到什么水平？

  • 1500～2000元以下低端机型：已达到约40%或40%以上。
  • 中端机型：约30%～32%。
  • 4000元以上高端机型：约29%～30%。
  • 低端机型成本压力最为严重，部分产品已累计涨价2～3轮，终端价格累计提高约400～600元。
  • 专家举例称，部分原BOM约900多元的1500元档机型，目前同配置BOM可能升至约1500元。

c) 手机厂商应对存储涨价的三阶段红线是什么？

  • 第一阶段：厂商内部消化
  1. 存储整体涨幅约30%～50%时，手机厂商可以通过牺牲利润自行承担。
  2. 低端手机原本利润率只有约4%～8%，继续上涨就可能进入亏损。
  • 第二阶段：厂商和消费者共同承担
  1. 厂商消化部分成本，其余通过终端涨价转嫁给消费者。
  2. 消费者可接受的涨价红线大致为：低端机约200元，中端机约300～400元，高端机约300～400元，旗舰机约600～1000元。
  3. 在厂商承担约30%、消费者承担约70%的情况下，理论上可承接存储价格上涨约100%～120%。
  • 第三阶段：价格击穿红线
  1. 当前部分DRAM价格已进入该阶段。
  2. 手机厂商只能进一步涨价、减配、减少生产或停产。
  3. 通过将12GB+256GB调整为8GB+256GB，或减少DRAM、增加相对便宜的NAND配置，可阶段性承接约220%～240%的涨幅。
  4. 如果价格继续上涨，只能将更多成本转嫁给消费者，或直接停止生产不盈利机型。

d) 存储涨价是否已经抑制手机终端需求？

  • 已经出现明显抑制，国内市场大约从2026Q2末至Q3初开始显现。
  • DRAM价格累计涨幅已超过手机厂商可消化的正常范围，低端产品受影响最明显。
  • 手机企业正在通过控制产量、减少存储备料、降低高内存版本占比等方式减轻亏损。
  • NAND累计涨幅明显低于DRAM，但也已超过正常市场承受能力；终端需求疲软是其在2026Q4停止上涨、2027年可能下降的重要原因。

e) 存储价格下行拐点将如何形成？

  • 上游持续涨价后，手机厂商被迫提高终端价格。
  • 消费者无法完全承接涨价，手机销量下滑、产品生命周期延长。
  • 手机厂商随之减少生产、采购及备货，存储需求下降。
  • 当需求下降至供给可以覆盖时，供需缺口消失，产能可能重新过剩，存储价格进入下行周期。
  • 当前最大不确定性不在于周期是否会逆转，而在于供需拐点何时出现。

f) 为什么苹果对存储涨价的承受能力更强？

  • 苹果整体毛利率较高，品牌溢价和成本转嫁能力远高于安卓厂商。
  • 苹果产品集中在高端市场，消费者对涨价的接受度更高。
  • 即使存储价格大幅上涨，苹果也有能力通过产品定价、配置组合和供应商组合维持毛利率。
  • 未来AI手机对内存和存储容量要求更高，但高端用户也更愿意为AI能力和高配置支付溢价。

7. 长鑫、长存扩产对行业供需和国产替代的影响

a) 国产手机厂商对长鑫、长存的使用比例提升到什么水平？

  • OPPO、vivo、荣耀、华为等国产品牌对国产DRAM或NAND的使用比例普遍已超过20%。
  • 往年相关比例通常只有8%～12%，2026年同比提升超过一倍。
  • 长鑫、长存新增产能将更多替代原本分配给海外原厂的采购份额。
  • 国产存储不仅能够保障供应，也能增强手机厂商与三星、海力士等海外原厂议价时的筹码。

b) 长鑫和长存扩产是否会扰乱全球存储市场？

  • 短期内不会明显扰乱全球市场，新增产能主要由国内手机品牌消化。
  • 长鑫月产能约30万片，长存月产能约20多万片，当前规模仍不足以大范围供应海外客户。
  • 国产厂商进入海外市场仍需满足合规、专利和产品验证要求，尤其是欧美高端市场进入难度较高。
  • 长鑫、长存的核心定位是服务国产品牌、缓冲海外断供风险，而非通过低价在全球市场激进扩张。
  • 2026年长存全球渗透率约13%，长鑫约9%；未来3～5年国产存储渗透率预计继续提升。

c) 长鑫产品与海外DRAM相比还有哪些差异？

  • 长鑫现有主力产品主要基于G4工艺，采用DUV光刻和多重曝光；海外头部企业更多采用EUV光刻。
  • 受单元尺寸、晶圆密度和工艺复杂度影响，长鑫单位成本可能略高。
  • 同类产品良率方面：
  1. 长鑫约88%～90%。
  2. 三星约95%。
  • 专家判断，长鑫产品持续性差距约10%，寿命差距约5%，一致性也存在一定差异。
  • 但在当前高端手机的实际使用中，功耗和体验差距并不明显，整体已经可以接受。
  • 长鑫相关产品在部分国产高端机型中的使用比例已超过30%。

d) 长鑫G5和R6产品进展如何？

  • 长鑫G5工艺仍采用DUV路线，目标是支持R6及24Gb等更高规格晶圆。
  • 当前G5良率约40%～50%，已经具备量产能力，但仍需继续爬坡。
  • 良率稳定后，G5产品质量有望接近海外同类产品。
  • 长鑫已经发布R6产品，并在部分国产折叠屏手机中使用，但当前出货量较少。
  • 基于G4工艺的R6在良率和速率方面仍弱于海外EUV产品，存在一定性能降档。
  • 专家认为，长鑫在A6等部分产品上的发布节奏已接近国际水平，但R6的规模量产能力仍需继续验证。

e) 长存与海外NAND厂商的技术差距如何？

  • 长存采用堆叠、晶圆混合键合等技术，并已取得部分相关专利授权。
  • 从200层、232层、321层及更高层数产品看，长存迭代进度已基本与海外厂商一致。
  • 当前长存与海外头部厂商在NAND领域已没有明显代际差距。
  • 当NAND继续向400层及以上发展时，长存的混合键合和堆叠技术可能逐步形成自身优势。
