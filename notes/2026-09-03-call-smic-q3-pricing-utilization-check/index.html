纪要总结

专家交流会议纪要

1. 三季度价格、收入与产能利用率

a) 三季度涨价情况如何，与二季度相比有何变化？

  • 三季度平均价格基本保持稳定
  1. 本轮涨价效应主要集中在二季度，三季度平均涨幅预计约为0%—1%，整体接近持平。
  2. 最终综合ASP仍会受到产品结构变化影响，因此实际结果可能与平均涨幅略有差异。
  3. AI相关套片价值量和价格相对较高，而手机消费类产品、尤其是大客户产品的涨价空间相对有限。
  • 二季度收入超预期存在一次性因素
  1. 二季度单季度收入达到约30亿美元的新台阶，高于公司原先预期。
  2. 除产能满载外，部分客户提取了此前已完成生产、存放在公司仓库中的产成品库存，推动二季度收入额外增长。
  3. 因此，二季度高收入水平不能完全线性外推，库存提货属于一定程度上的一次性因素。
  4. 尽管二季度基数较高，公司仍预计二季度至三季度的营收增速总体平滑。

b) 三季度收入增量主要来自哪里？

  • 主要来自产能利用率继续提升
  1. 二季度产能利用率为93.7%。
  2. 三季度预计将提升至95%以上，部分厂区和工艺平台接近满载。
  3. 产能利用率不会无限接近100%，因为公司需要保留部分机台用于研发、工艺验证和产品切换，研发活动本身会拉低统计口径下的产能利用率。
  • 全年订单能见度较高
  1. 当前订单基本已经排至年底，今年订单和产能消化不存在明显问题。
  2. 但二季度客户已提取较多产成品库存，后续公司缺少额外库存和闲置产能用于超计划供货。
  3. 明年订单尚未进入全面确认阶段，公司内部明年经营及产能计划也仍待战略会议确定。

c) 明年是否还有进一步涨价空间？

  • 行业整体仍处于较好的景气和涨价环境。
  • 明年可能重新评估今年尚未调价的手机消费类产品，AI相关套片也存在重新定价的可能。
  • 具体涨价幅度取决于客户体量、产品结构、供需缺口和长期合作关系，目前尚无法给出明确指引。
  • 大客户由于采购规模较大，涨价幅度通常低于小客户；小客户及高价值AI套片的定价弹性相对更高。

2. 产能扩张与资本开支规划

a) 已公告项目的扩产进度如何？

  • 深圳项目
  1. 已基本完成扩产。
  2. 深圳6厂产能约为4万片/月，主要承接DDIC等产品。
  3. 该厂去年产能利用率约为60%，二季度已提升至90%以上，后续有望接近满产。
  • 京城项目
  1. 京城P1已基本建设完成，产能约为5万片/月。
  2. P2尚未完成，目前产能不到1万片/月，明年仍将是主要扩产来源之一。
  • 东方项目
  1. 预计今年年底完成第一个厂区的产能安装。
  2. 第一个厂区设计产能约为5万片/月。
  3. 明年东方项目仍有部分新增产能释放。
  • 西青项目
  1. 当前尚未形成产能，土建也未完成。
  2. 项目进度暂时延迟，短期内不会形成有效供给。

b) 已公告项目完成后，是否还会继续扩产？

  • 成熟制程后续仍存在扩产需求，但新增计划尚未正式公告。
  • 未来扩产重点可能包括：
  1. AI套片带动的8英寸BCD产能；
  2. 本土化转移带来的成熟制程需求；
  3. NOR Flash、NAND Flash及12英寸BCD等紧缺平台；
  4. 先进封装、3D堆叠及相关实验线。
  • 原有判断认为，已公告项目到2028年基本能够满足中国大陆市场需求；但随着AI套片需求和本土化转移加速，现有项目可能不足以覆盖实际需求。
  • 公司通常在当前时点召开年度战略会议，确定下一年度的重要投资安排，因此新增Capex和扩产方案仍待内部决策。

c) 2027年是否仍是折旧高峰？

  • 此前公司将2027年视为折旧高峰，前提是仅考虑已经公告的四个项目。
  • 随着公司考虑新增8英寸、成熟制程及先进技术相关投资，2027年可能不再是折旧绝对值的顶峰。
  • 若新项目落地，资本开支和折旧周期都可能进一步延长。

3. AI套片与BCD业务供需

a) AI套片主要包括哪些产品，收入占比是多少？

  • 公司目前没有单独设置“AI套片”收入分类：
  1. 美国客户通常将其归入工业类；
  2. 其他客户可能将其归入电脑和平板类；
  3. 因客户填写口径不同，目前分类并不完全严谨。
  • 内部初步估算，AI相关非先进制程套片收入占比接近20%，但尚未经过逐一客户重新分类确认。
  • 该口径不包括AI主芯片，主要涉及：
  1. 电源管理芯片；
  2. 电路驱动及收发器；
  3. 功率放大类产品；
  4. 光模块配套芯片；
  5. 其他模拟及接口类芯片。

b) 8英寸产线的产品结构如何？

  • 从整体平均口径看，8英寸产线中80%以上、部分口径接近90%为BCD相关产品。
  • BCD主要服务于模拟类产品，包括电源管理、电路驱动、收发器等。
  • 部分8英寸产线还会生产碳化硅和功率器件，但并非整体产能的主要构成。
  • AI套片价值量和售价高于传统手机消费类芯片，因此具备更强的产能承受能力和定价空间。

c) BCD业务的供需缺口有多大？

  • 公司判断BCD业务当前供需缺口至少在30%以上。
  • 需求缺口仍在扩大，主要原因包括：
  1. AI服务器和AI终端对电源管理、驱动、接口芯片的需求快速增长；
  2. 海外及中国台湾地区产能被AI产品挤占；
  3. 客户加快向中国大陆晶圆厂转移；
  4. 传统DDIC等此前被认为过剩的产能，今年也重新趋紧。
  • BCD业务目前只有加单、没有明显砍单。
  • 由于公司产能有限，无法满足全部客户需求，在资源分配上可能会更多支持中国本土客户。

d) 美国客户的价格和收入贡献有何特点？

  • 美国客户收入按照客户注册地计入美国地区收入。
  • 美国客户数量不多但集中度较高，因此美国收入占比具有明显的大客户特征。
  • 美国地区收入占比约为8%，其中包括大型电源管理客户。
  • 大客户采购体量较大、合作周期较长，涨价幅度通常不会像小客户一样高。
  • AI套片占比与美国区收入占比暂时无法直接对应，原因是AI套片还包括中国及其他地区客户，且业务分类仍在调整。

4. 各工艺平台与产品景气度

a) DDIC业务为什么明显改善？

  • DDIC采用铝制程，工艺相对简单，适合成熟制程产线承接。
  • 中国台湾地区产能调整和转单，为公司带来了增量订单。
  • 增量主要来自两类客户：
  1. 原本在中国台湾地区生产、后续转入公司的产品；
  2. 公司现有客户增加采购量。
  • 深圳6厂是主要受益产线：
  1. 设计产能约4万片/月；
  2. 去年利用率约60%；
  3. 二季度利用率已超过90%；
  4. 后续预计维持满产或接近满产。

b) CIS为什么弱于DDIC？

  • CIS主要涉及40纳米、28纳米及55纳米等工艺。
  • 40/28纳米处于成熟制程与FinFET之间，公司自身产能相对充足，因此受到AI挤压的程度较低。
  • CIS终端需求当前不算强，订单表现弱于DDIC、NOR Flash和BCD。
  • 55纳米产能可以部分切换至NOR Flash，因此工厂可通过产品调配改善利用率。

c) 40/28纳米产能利用率如何？

  • 受手机和CIS需求调整影响，此前利用率约为92%。
  • 经过一个季度左右的产品切换和产能调配，三季度预计恢复至接近满载。
  • 即使部分CIS订单减少，公司也可将部分产能转至NOR Flash等紧缺产品，因此总体利用率仍有支撑。

d) 8英寸和12英寸产能的供需判断如何？

  • 8英寸产能
  1. 当前已经较为紧缺；
  2. DDIC、BCD、功率器件等需求同步增加；
  3. 未来AI套片和本土化替代可能进一步加剧紧张程度。
  • 12英寸产能
  1. NAND Flash、NOR Flash及90纳米BCD均较为紧缺；
  2. 12英寸BCD同样处于供不应求状态；
  3. CIS相对偏弱，但可通过工艺和产品切换消化部分产能。

5. 手机消费电子与存储业务判断

a) 消费电子订单是否已经完成调整？

  • 公司端的消费电子订单已基本完成主要调整。
  • 手机业务占比此前约为27%，后续逐步下降至约17%，约10个百分点的变化反映了手机客户的砍单和结构调整。
  • 当前手机相关订单已进入相对稳定状态，不会从100%直接降至0，客户仍需维持基本供应和产能安全。

b) 如何看待明年手机市场？

  • 整体手机市场明年仍可能继续下降，尤其是低端手机需求较弱，品牌厂商缺乏销售动力和利润空间。
  • OPPO、小米等品牌仍在发力中高端手机，对下半年及后续中高端市场保持较高预期。
  • 当前部分手机厂商已经开始洽谈更长期的产能分配，相关节奏较往年更积极。
  • 客户即使对终端需求谨慎，也仍会保留一定产能，主要考虑：
  1. 台积电明年给予手机业务、尤其是中国大陆客户的产能可能有限；
  2. 封装环节同样存在产能约束；
  3. 当前手机类晶圆价格尚未明显上涨，提前锁定产能成本相对可控；
  4. 客户需要保障供应链安全。

c) 为什么预计手机存储不会持续严重短缺？

  • 手机存储扩产和验证周期相对较短，新增产能大约需要8个月即可释放。
  • 手机存储短缺已持续一年以上，行业已经有时间进行扩产和产品验证。
  • 新增产能可以较快进入消费电子领域，而GPU及AI相关产品验证周期可能长达3—4年。
  • 因此，手机存储供给可能逐步增加，但AI相关存储仍将持续紧缺。

d) NAND和NOR Flash的供需趋势如何？

  • NAND Flash
  1. 公司相关工艺以28纳米为主，实际性能可能接近22纳米水平；
  2. 当前产能非常紧缺；
  3. 扩产成本较高，行业没有进行特别大规模的扩产；
  4. 预计NAND产能仍将持续紧张。
  • NOR Flash
  1. 中国台湾地区基本没有明显扩产；
  2. 中芯国际和华虹虽有扩产，但速度较慢；
  3. 新建NOR产线最快也要到明年下半年才会形成部分有效产能；
  4. 短期供给增加有限，价格和产能利用率具有支撑。

6. 设备、材料与供应链成本

a) 海外设备采购是否变得更困难？

  • 当前尚未看到设备采购难度出现明显恶化，但海外设备交期普遍延长至约12个月。
  • 中芯国际采购规模较大、与设备厂商合作历史较长，遇到紧急需求时，供应商仍可能对少量设备提供优先支持。
  • 部分欧洲、日本设备厂商正式报价涨幅可能达到10%—15%。
  • 凭借采购规模和议价能力，中芯国际实际承担的涨幅预计明显低于厂商公开涨幅。

b) 哪些设备和零部件最紧缺？

  • 存储产线配套的炉管较为短缺。
  • 炉管交期可能由原来的4—6个月延长至12—14个月。
  • 当前讨论主要集中于前道设备，后道设备情况尚不明确。

c) 材料价格是否上涨？

  • 部分材料存在调价压力，主要来自通胀、大宗商品和贵金属价格上涨，而非单纯的供需短缺。
  • 涨价品类包括：
  1. 靶材；
  2. 气体及氦气；
  3. 钽等贵金属相关材料；
  4. 硫磺及其他石化副产品；
  5. 部分光刻化学品及上游原材料。
  • 硅片供应链规模较大，当前未见明显缺产能或涨价趋势。
  • 公司要求供应商报价与上游原材料价格联动；若原材料价格下降，也会要求供应商同步降价。

7. 新技术、先进封装与长期产能方向

a) 2.5D与3D封装是什么关系？

  • 2.5D和3D并非相互替代，而是相辅相成。
  • 未来可能先进行部分芯片堆叠，再通过2.5D工艺完成系统级集成。
  • 现阶段2.5D仍是主要工艺，3D将作为后续重要补充。

b) 3D实验线的规划如何？

  • 明年计划在上海建设一条3D相关实验线。
  • 实验线初步规模约为1,000，原始交流未明确具体单位。
  • 后年是否进入量产阶段，取决于明年实验线的工艺进展、良率和客户验证情况。

c) EUV受限背景下，先进工艺如何继续迭代？

  • 在EUV受限的情况下，可通过以下方式提升等效性能：
  1. 3D堆叠；
  2. 5—8层stacking；
  3. bonding键合技术；
  4. 2.5D与3D组合集成。
  • 如果行业沿上述路线发展，中国先进产能仍远远不足，先进工艺及先进封装短期不存在明显供过于求的风险。
  • 相关业务在公司收入中的占比，最终取决于先进工艺和先进封装产能的建设进度。

d) 先进制程如何定价和处理良率？

  • 当前主要按照成品口径向客户定价。
  • 新产品、NPO阶段或新工厂初期通常不会承诺良率，主要按晶圆或产品约定价格结算。
  • 产品量产约两年后，通常会逐步承诺良率，例如成熟产品可能约定90%左右的良率目标。
  • 承诺良率后：
  1. 达到要求则按约定价格结算；
  2. 未达到要求可能需要给予客户折扣；
  3. 客户也会提出更明确的技术和良率指标。
  • 因此，承诺良率后名义售价不一定更高，但客户获得的有效良品成本更加明确。

8. 股权结构与亏损项目管理

a) 东方项目是否会出表？

  • 东方项目预计不会出表，但公司持股比例可能被逐步稀释。
  • 二季度中芯国际对东方项目的持股比例约为66.4%。
  • 部分股东此前未能及时完成实缴出资，中芯国际被迫增加投入，导致实际持股比例高于原计划。
  • 公司原本只要求保持约51%的控股比例，后续可能通过引入资金或其他股东增资降低持股比例。
  • 东方项目目前仍处于亏损状态，较高持股比例意味着公司需要承担更多亏损和资本投入。
