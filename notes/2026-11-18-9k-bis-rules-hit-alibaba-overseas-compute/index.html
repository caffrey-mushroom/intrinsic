专家访谈纪要：阿里算力布局、海外通道与云业务增长展望

1. 阿里整体算力分布与海外资源结构

a) 阿里当前整体算力规模及国内外分布如何？

  • 整体规划与增量
  1. 据受访者口径，阿里曾在云栖大会提出，到2032年总算力达到约20万张。
  2. 当前总算力约为4万至5万张，预计未来每年增加1万至2万张。
  • 截至2026年下半年的N卡分布
  1. 国内约有4万多张B系列卡，另有部分H系列和A系列卡。
  2. 海外约有6万张B卡、20万张H200，以及约3万至5万张AMD卡和其他N卡。
  • CPU部署情况
  1. 2026年上半年国内CPU出货量约14万颗。
  2. 海外也有部署，但规模很小，受访者称处于“个位数”水平。
  • 口径提示
  1. 上述“整体总算力4万至5万张”与后续分型号卡数量存在明显统计口径差异，可能涉及物理卡、等效卡、已部署卡、集团级资源和云业务可调度资源等不同定义。
  2. 相关数据需在后续使用时进一步统一口径。

b) 海外B卡中，自持和租赁的比例分别是多少？

  • 目前海外可调用的卡约6万至7万张，其中自持部分不到2万张。
  • 海外B卡绝大部分来自租赁，自建、自持规模相对较小。
  • 主要合作和获取渠道包括New Cloud、中立渠道，以及与协创、Macst等合作方共同推进海外数据中心建设。
  • 受访者后续进一步表示：
  1. 海外约6万张B卡中，约6成用于阿里内部。
  2. 约2成用于MaaS服务。
  3. 约2成用于对外转租或支持被投企业及大模型公司。

c) 海外B卡“6万张”和“8万张”两种说法有何区别？

  • 6万张口径
  1. 主要指截至2026年一季度末，已经完成物理部署且能够实际调度的B卡。
  2. 受访者认为，目前内部及多数行业专家更认可该口径。
  • 8万张口径
  1. 可能采用等效H100算力口径。
  2. 也可能将已部署数量、在途数量及其他资源合并计算。
  • 综合第三方研报、专家观点和市场分析，受访者认为6万张左右更加可靠。

2. 2027年海外B卡扩张计划与资本开支

a) 阿里原计划在2027年增加多少海外B卡？

  • 阿里原计划将海外B卡数量从约1万张提升至10万张以上。
  • 受访者给出的理论测算为：
  1. 2027年计划新增采购约4万至6万台。
  2. 加上原有约1万台存量，明年相关卡数量有望达到10万级别。
  • 该规划的主要约束原本不是资金和价格，而是海外采购及租赁通道能否保持畅通。
  • 口径提示
  1. “当前海外可调用约6万张”与“原有约1万张存量”的表述可能分别对应总可调用资源和自持资源。
  2. “新增4万至6万台后突破10万张”的数量关系也可能涉及服务器与卡数量转换，需进一步核实。

b) 2027年资本开支及买卡预算如何安排？

  • 阿里2027年资本开支预计约2300亿至2500亿元。
  • 其中约1600亿至1700亿元用于卡及相关算力资源。
  • 海外买卡预算约占40%，对应约640亿至680亿元。
  • 受访者认为，预算本身较为充足，真正影响扩张的是卡源、租赁资格、出口许可及跨境通道。

c) 自购和租赁在财务上如何处理？

  • 自购、自持部分
  1. 通常计入CAPEX。
  2. 海外自建数据中心和直接购买服务器、芯片等资产，主要按资本开支处理。
  • 租赁部分
  1. 通过New Cloud等渠道租赁的算力通常计入OPEX。
  2. 相关支出直接影响利润表，不计入固定资产。
  • 合资及SPV模式
  1. 例如沙特等地区通过合资公司或SPV获取的算力，内部规划时可能按自持资源管理。
  2. 但实际财务处理仍可能计入OPEX。
  • 受访者称，1600亿元买卡及算力预算中，自购部分约占六至七成，对应约840亿至900亿元。
  • 口径提示
  1. “840亿至900亿元”占1600亿元约53%至56%，与“六至七成”存在算术差异。
  2. 具体CAPEX/OPEX划分以公司正式财报为准。

3. BIS新规对海外算力通道的影响

a) 海外B卡扩张面临哪些主要困难？

  • 据受访者描述，2026年11月以来，海外卡源面临两类冲击：
  1. 原有依赖中东、东南亚数据中心和第三方渠道获取B卡的模式存在中断风险。
  2. BIS临时最终规则将监管范围从物理主机延伸至远程租赁和海外数据中心算力服务。
  • 受访者称，新规可能对超过特定算力门槛的海外数据中心服务实施许可要求，且存量服务器需在规定期限内补办相关许可。
  • 对阿里而言，核心逻辑由“有预算即可购买或租赁”转变为“即使有预算，也未必能够买到或租到”。
  • 下一阶段，通道能否持续、许可是否获批，将成为比价格和预算更重要的决定因素。

b) 东南亚存量B卡能够保留多少？

  • 分类型判断
  1. 自持资源的保留概率接近70%，主要因为资产和服务器掌握在阿里自身手中。
  2. 租赁资源保留概率不足20%，尤其是马来西亚、印尼、新加坡等重点监管地区。
  • 对6万张存量卡的情景判断
  1. 中性情景：保留约2.5万张。
  2. 悲观情景：不足2万张。
  3. 乐观情景：保留约3万张。
  • 自持部分预计大多可以保留；租赁部分：
  1. 较好情况下可能留下约1万至1.5万张。
  2. 悲观情况下可能仅剩约5000张。
  • 受访者判断，东南亚租赁通道存在实质性收缩甚至关闭的风险。

c) 新规影响何时能够看清？

  • 相关许可和过渡期限约为90天，对应至2027年2月中旬、春节前后。
  • 受访者预计，到2027年2月不会出现统一结果，而是出现三类状态：
  1. 部分资源获得许可。
  2. 部分资源被拒绝。
  3. 部分资源继续处于待定状态。
  • 到2027年2月，政策影响将开始变得清晰，但不会完全明确。
  • 真正看清2027年全年产能和算力供给，可能要到2027年6月以后乃至中下旬。
  • 期间还需观察阿里及其他国内厂商在欧洲新建数据中心和转移产能的进展。
  • 阿里目前按照较坏情景提前准备。

4. BIS新规后的三条应对路径

a) 第一条路径：将海外租赁中心转移至欧洲

  • 阿里计划在东南亚通道受阻后，将部分租赁和建设中心转向欧洲。
  • 重点考虑法国、荷兰、芬兰等地区，通过第三方共建和自主租赁数据中心获取算力。
  • 该方案的优势是地区合规性相对更高，并可对冲东南亚资源收缩。
  • 主要限制包括：
  1. 仍然受到BIS规则约束，不能完全规避许可要求。
  2. 数据中心建设、法务、合规和运营成本更高。
  3. 新产能形成需要时间，短期内难以完全承接东南亚存量。
  4. 欧洲当地电力、机房和整体产能也存在约束。

b) 第二条路径：提高平头哥自研芯片的内部占比

  • 平头哥将成为阿里应对海外高端GPU受限的核心底牌。
  • 当前平头哥自研芯片在集团内部算力中的占比不足10%。
  • 长期目标是提升至40%至50%。
  • 自研芯片可在部分推理和训练场景中替代A系列卡需求，但短期无法完全弥补高端N卡缺口。
  • 核心限制包括：
  1. 芯片性能与H200、B200等海外高端产品仍存在代际差距。
  2. 部分产品暂时难以承担旗舰大模型训练任务。
  3. 受到先进制程、台积电产能及HBM供应约束。
  4. 软件适配、生态建设及客户接受度仍需时间验证。

c) 第三条路径：下调目标、削减海外采购和租赁预算

  • 通过削减部分海外算力投入，可以缓解资本开支和利润压力。
  • 但该方案会削弱长期模型竞争力和云业务增长潜力，与阿里当前战略方向冲突。
  • 当前管理层更倾向于“All in”算力建设：
  1. 优先建设基础设施。
  2. 再推动模型、MaaS和上层应用增长。
  • 因此，主动大幅降低算力投入目标，暂时不是优先选项。

5. 平头哥自研芯片产品与产能规划

a) 平头哥当前主要有哪些芯片？

  • 含光800系列
  1. 主要用于传统电商推荐。
  2. 在大模型中的应用较少。
  3. 当前存量约10万张。
  • 810系列
  1. 受访者前段表述为对标H20，后续又表述为对标H200，产品定位口径存在差异。
  2. 当前数量约6万至7万张。
  3. 暂时较难全面承担旗舰大模型任务。
  • M890
  1. 当前主力产品，主要定位A100至H100之间。
  2. 采用144GB显存、800G带宽，FP16算力约600TFLOPS。
  3. 使用盘古BR128超节点，即128卡节点。
  4. 当前总量约10万颗，受访者预计到年底可能达到约40万颗。
  5. 已能够运行部分模型，但具体可支持版本的表述存在差异。
  • V900/V90
  1. 属于下一代产品。
  2. 目标是在相同功耗下对标H系列高端卡。
  3. 量产或输出时间存在Q1、Q2两种口径，预计在2027年上半年逐步落地。

b) 平头哥明年的整体出货目标是多少？

  • 当前平头哥整体芯片数量约50万张。
  • 2027年整体数量预计提升至约100万张。
  • 受访者同时提到，相关GPU资源中：
  1. 约60%用于内部。
  2. 约25%用于MaaS。
  3. 约15%用于外部商业化。
  • 自研芯片规模快速扩张将成为阿里算力增长引擎转换的关键，但性能、产能、HBM和生态适配仍是主要瓶颈。

6. 阿里云增长预期及主要压力

a) 2027年阿里云增速如何预期？

  • 内部基准预期仍希望保持50%以上增速，整体规模接近翻倍增长。
  • 若海外卡源、模型迭代或竞争环境不及预期：
  1. 中性增速可能回落至约45%。
  2. 偏弱情景约为40%至45%。
  3. 最低情景约为38%，低于38%的概率较小。
  • 中长期规模目标方面，受访者提到：
  1. 2027年前后规模可能突破2000亿元。
  2. 2028年至2029年前后可能突破3000亿元。
  • 访谈中也出现“到2029年目标为2000亿元”的不同表述，绝对规模及时间口径需进一步确认。

b) 为什么BIS新规不会是增速下降的唯一原因？

  • B卡获取困难只是导火索，增速下调还受到竞争、模型迭代和增长引擎转换等多重因素影响。
  • 当前阿里云新增收入中，接近六成与AI高度相关。
  • AI收入又高度依赖模型能力、算力供给和模型迭代速度。
  • 如果B200、B300等高端卡获取受限，可能影响4.0及后续模型训练，进一步影响：
  1. 模型领先性。
  2. 企业客户选择。
  3. AI算力消耗。
  4. MaaS和云服务收入增长。

c) 行业竞争会如何影响阿里云？

  • 主要竞争来自腾讯和字节跳动，尤其是字节正在积极争夺阿里云客户。
  • 据受访者口径：
  1. 字节2026年资本开支约1800亿元。
  2. 2027年预计约2000亿元。
  3. 其中投向IDC的资金不低于700亿元。
  4. 字节正在全网招投标，建设及租赁规模超过10GW。
  • 受访者认为，字节未在美股上市，受到美国监管的限制可能少于阿里。
  • 在同等竞争条件下，阿里海外算力和业务受限程度更高，可能面临客户和市场份额压力。
  • 阿里海外业务此前占比接近三至四成，高端卡和存量租赁资源受限后，海外业务增速预计将明显下降。

d) 2027年为何是增长引擎转换期？

  • 阿里此前主要依靠外购和租赁高端GPU扩大算力。
  • 2027年开始，需要逐步转向平头哥自研芯片。
  • 转换期可能出现以下摩擦：
  1. 自研芯片与现有模型和软件栈的适配问题。
  2. 外部客户对自研芯片的接受度问题。
  3. 高端模型训练能力不足。
  4. 合规及海外服务能力下降。
  • 相关影响不仅会体现在2027年，也可能延续至2028年。

7. 海外算力的内部使用及对外客户结构

a) 海外约6万张B卡主要如何分配？

  • 内部使用约占60%
  1. 重点支持通义大模型的训练和推理。
  2. 优先保障阿里内部AI业务和核心模型迭代。
  • MaaS约占20%
  1. 由企业客户通过模型和平台服务消耗算力。
  2. 客户覆盖传统央企、金融、制造业及民营企业。
  • 对外转租约占20%
  1. 主要面向阿里被投企业及大模型公司。
  2. 客户包括月之暗面、智谱和MiniMax等。
  3. 月之暗面使用规模最大，约使用8000至1万张卡，用于Kimi相关业务。
  4. 剩余部分提供给智谱、MiniMax等客户。

b) 海外算力获取和使用链条是什么？

  • 上游由阿里向New Cloud或其他海外数据中心获取算力。
  • 中间层由阿里统一调度、管理和分配。
  • 下游分别用于：
  1. 内部模型训练与推理。
  2. MaaS平台企业客户。
  3. 被投企业及外部大模型公司的算力租赁。
  • 新规实施后，上游资源稳定性下降，将向下游传导至服务能力、租金和客户交付。

8. B200、B300租金及未来价格趋势

a) 当前海外B卡的市场租金如何？

  • 海外单卡时租呈现明显分化：
  1. 中间市场此前约5至6美元/小时，目前下降至约4至4.5美元/小时。
  2. 部分受限制或特殊通道价格约8至9美元/小时。
  3. B200目前约4至5美元/小时。
  4. B300约9至10美元/小时。
