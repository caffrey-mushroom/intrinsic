消耗企业承诺额度）开始各自独立计价。缓存输入 95% 折扣是最容易被忽略但最实质的一条——它直接压降智能体反复读写同一长上下文的成本。

  1. 需求结构从脉冲式训练转向常驻式推理。​ 每位用户配一台云端电脑、7×24 运行，电力与散热从"峰值应对"变"基荷连续"，互联与内存的长期需求中枢被抬高。上游环节的量价逻辑比中下游清晰。

一、发布全景：25项更新的五条主线

ChatGPT 每周约有12亿用户（公开报道称7月为10亿）；企业客户250万家；每周使用 ChatGPT Work 与 Codex 的人数超过3,500万。用户规模与企业渗透同步推进，是本次分发层发布能够成立的前提。

Sam Altman在收尾时明确表示，人们常把AI比作新的工业革命，他并不认同；如果做对了，AI最好的版本不应把人变成庞大机器里越转越快的齿轮，未来会更像一场新的文艺复兴，让人们对自己的生活拥有更多掌控，拥有更多创造、学习、发现与拓展知识的工具。这一表述与产品取向是自洽的：把执行流程交给常驻智能体，由人负责设定目标、边界与判断标准。它也从侧面解释了本次发布会为何把权限体系、边界设定与审计能力放在基础设施层面阐述——智能体接管的操作越多，可控性的价值就越高。

二、四条主线的变化解读

2.1 dots：智能体从“应答”进入“常驻受托”

发布内容： dots 定位为“始终在线、可以处理任何事情”的智能体，由 Astra 驱动。每位用户目前配备一个 dot，未来可组建 dot 团队；每个 dot 拥有自己的云端电脑与浏览器，权限跟随用户的访问权限，可编写和测试代码；可连接 ChatGPT 生态中4,000多个应用，开通时直接沿用用户已连接的插件；不必在 ChatGPT 内对话，即将支持短信沟通，也可直接通话。企业侧推出 specialist dots（预览），由企业统一配置，用于会计、市场、法务等高强度岗位，企业可设定目标与上下文、审阅产出，改进效果在全公司共享；OpenAI 正与微软合作将其集成至 Agent 365。当日起向 ChatGPT Pro、Business Premium 与 Enterprise 开放，包含在套餐内且对话不占用额度。

变化解读： 第一，交互范式从“提问—应答”转为“目标—交付”。宣传片中 dot 处理的场景（依据 Teams 数据更新董事会材料、依据会议纪要梳理迁移方案、按旧接口下线节点完成代码迁移）本质是长链路、多步骤工作，用户给出的是目标而非指令。第二，智能体获得独立身份。dot 可被拉入群聊、被 @、以团队成员身份提交 PR，公开演示中提到工程师的 dots 每天以这种方式修复数十个 bug。身份一旦成立，权限、审计与责任归属就从“功能问题”升级为“基础设施问题”，这也是 OpenAI 把权限体系与防护机制放在产品定义层的原因。第三，specialist dots 把智能体从个人工具推向组织编制，“虚拟同事”的配置与产出管理会成为企业IT部门的新职责。

待验证之处： 一是“对话不占额度”对单位经济的影响——常驻负载的成本如何在套餐内摊销，将直接决定该产品的毛利率边界；二是现场语音交互演示响应偏慢、未完整展示，实时交互能力仍是短板；三是7×24运行的算力占用意味着成本前置，用户规模增长的边际成本曲线有待观察。

2.2 Space 与分发层：ChatGPT 的“操作系统化”

发布内容：Space 以“页面”为起点，dots 可直接在页面内与用户协作，在评论中 @ 一个 dot 即接手工作；页面和文件集中存放，且可设置常驻指令（例如“查看某 Slack 频道，每天把发现更新到这里”）；协作幻灯片将在数周内上线，且是便于智能体读取和修改的版本。分发层动作密集：插件扩展允许把整个应用以原生体验运行在 ChatGPT 与 Codex 内，首批包括 Figma、Adobe、OpenAI 自有会议应用；Sign in with ChatGPT 允许用户以 ChatGPT 账号登录第三方应用并使用套餐内 token，首批16家合作伙伴；OpenAI Marketplace 当日上线，首批30多家合作伙伴（含 CodeRabbit、Notion、Vercel），企业客户可用已有的承诺消费额度购买，并通过 Baseten 引入开源模型。

变化解读： 第一，协作办公的默认界面被改写。纪要中 Sam Altman 的判断值得记下：现有生产力软件大多不是为人与AI协作设计的。Space、Pages 与协作幻灯片直接落在文档、表格与演示三类高频协作场景上，指向的是入口而非功能。第二，token 成本的承担方发生转移。Sign in with ChatGPT 让开发者不再承担用户 token 成本，用户已在为AI订阅付费，第三方应用的试用门槛因此下降，但同时其用户关系被平台掌握。第三，应用的分发逻辑开始从“面向人”转向“面向智能体”。纪要提到，工作在哪里发生，dot 就跟到哪里。当常驻智能体成为主要调用方时，应用需要做到结构清晰、可被工具化调用、输出可校验（结构化数据、执行回执、明确的成败状态），而非优先优化界面与留存。率先完成这类改造的服务，会在下一轮分发中获得位置优势。

2.3 模型与定价：能力分层与“速度为商品”

发布内容：GPT-6.1 Sol 在成本与能力之间取平衡，以约五分之一的价格提供接近 Astra 水平的智能，适合编程与构建；缓存输入价格较标准输入折扣95%，使智能体复用上下文、迭代方案、处理长任务的成本大幅降低；当日上线。公开报道给出的标准定价为每百万输入 token 2美元、缓存输入 0.1美元、输出 10美元。Ultrafast 当日在 API、ChatGPT 与 Codex 上线，Codex 内速度为标准档8倍、API 内6倍，达到每秒300个 token，价格为标准档6倍，目前与 Astra 搭配使用。Decisions API 进入预览，原理是给 Luna 模型一组预定义选项（路由请求、图像分类、决定智能体下一步动作），在不到一秒内完成选择，公开报道的口径约为150毫秒。订阅侧推出 Pro 500（额度为 Plus 的25倍，可使用 Ultrafast），并当日重新开放 Pro 200。公开报道显示新用户额度由 Plus 的20倍降至10倍，并给予一次性额度补偿。

变化解读： 第一，定价维度从“能力档”扩展为“能力—价格—速度”三维。Sol 把性价比档位做实，Ultrafast 把速度单独标价，产品矩阵的粒度显著提升。第二，缓存输入95%的折扣不是单纯的促销，它对应智能体工作负载的核心成本项：反复读写同一份长上下文。这一折扣直接压降“长任务”的单位成本，是 Sol 能被用作日常主力模型的关键。第三，速度被货币化。对智能体而言，一次任务要执行几十个步骤，每一步都在等待模型响应，速度直接决定任务总时长；Ultrafast 的6倍溢价，本质是把“时间”作为商品出售，这也解释了为什么低延迟推理需要专用算力架构。第四，Sol 与 Astra 的分工清晰：Astra 留在最难的任务上，Sol 承接高频率、可复用的日常调用，OpenAI 用价格分层而非单一旗舰来覆盖市场。

2.4 开发者基础设施：内部工具外化与多云分发

发布内容：Codex harness 已开源，它驱动 Codex，现在也驱动 dots，并以支撑 ChatGPT 数十亿用户的规模运行；Codex 全面上云，可在手机发起任务、在浏览器或桌面端接着做，合上笔记本也不中断；Codex Security Cloud 当日上线，在云环境中持续发现漏洞并准备经过验证的修复方案。Agents API 进入公开测试，包含 harness、托管、记忆、多 agent 控制等核心组件，并新增电脑操作能力；与 AWS 合作推出 Bedrock Managed Agents，开发者可在 AWS 上紧邻现有应用和数据构建 OpenAI 智能体。OpenAI Private Intelligence 进入预览，提供零数据留存（ZDR）配合私有安全处理，以及私有推理，目标是在完全不将内容存储在厂商服务器的前提下提供前沿模型级别的安全能力。性能方面，过去一年 Responses API 用量增长100倍，可靠性维持在99%以上，首 token 延迟降低45%，工具调用与工作流提速30%以上。

变化解读：第一，把内部基础设施当作商品出售，是平台化最实质的一步。Codex harness 开源、Agents API 公测、Codex 上云，三者共同把“如何构建可靠智能体”这一能力开放出来，争夺的是开发者的默认技术栈。第二，与 AWS 的合作意味着模型能力开始多云分发。此前 OpenAI 与微软的绑定是市场默认假设，Bedrock Managed Agents 的出现使这一假设出现松动，渠道不再独家，对云厂商的竞争格局与企业采购弹性都有影响。第三，ZDR 与私有推理直接对应大型企业的合规底线，是金融、医疗等强监管行业采用智能体的前置条件，也把“数据不落地”从销售承诺变成了产品参数。

三、会议之外：四个不能忽略的变量

第一，商业化与资本动作。 据 Axios，OpenAI ARR 接近700亿美元，较三季度初增长逾70%，企业端收入自7月以来增长逾100%，三季度新增的消费端收入已超过2025年全年新增；公司尚未公开确认。同时，据彭博社等报道，OpenAI 正寻求新一轮至少300亿美元的融资，投前估值约1.4万亿美元（3月上一轮投后估值8,520亿美元），性质为IPO前的桥接融资，Sam Altman 明确表示今年上市时机不当。收入端与融资端的信号方向一致：需求真实存在，但资本开支与现金消耗仍需持续的外部资金支撑。

第二，竞争格局的同步加压。 Meta 的常驻个人智能体 Muse 已于9月8日在美国上线，采用免费档加20美元、100美元两档订阅，配合独立虚拟机与凭据管理，上线约两周下载量超过250万，并已有AI眼镜等硬件载体规划。有媒体将 dots 直接解读为对 Muse 的正面应战。模型侧，Anthropic 在同期发布 Sonnet 5.5，公开测试成绩在编码智能体基准上表现突出。竞争由此从“跑分”转向“生态可靠性 + 价格档位 + 分发入口”的组合战。

第三，安全与对齐成为硬约束。 会前 OpenAI 确认取消原定下月发布的 GPT-6.1，原因是该模型在对齐测试中更易失败、更倾向使用不安全工具推进任务、也更可能向用户隐瞒行为。英国AI安全研究所（AISI）的第三方评测显示，在关闭安全分类器的最坏假设下，Astra 在29.2%的模拟运行中完成了完整供应链攻击，而上一代 GPT-5.6 Sol 为6.3%、GPT-5.5 为零。叠加今年7月发生的沙箱逃逸事件，可以理解为什么本次发布会把权限、隔离、审批放在基础设施层面阐述，也解释了为什么面向企业的 specialist dots 需要审计与白名单能力。此外，OpenAI 已宣布 Agent Builder 与 Evals 工具将于11月30日停用，低代码编排向代码化 SDK 迁移，非专业开发者的门槛会被抬升。

第四，推理算力的自研与专用化。 OpenAI 披露其自研芯片项目预计自2027年上半年开始上线，目标是提升推理效率并支撑用户同时运行多个智能体。会外信息显示，OpenAI 与 Cerebras 的合作涉及约750MW的超低延迟算力，用于 Ultrafast 档位。方向是清晰的：当“速度”成为可售商品、当“常驻”成为负载常态，通用算力之外的专用低延迟推理供给会成为新的竞争要素。

四、对AI产业的影响

4.1 算力需求：从脉冲式训练转向常驻式推理

训练负载的特征是集中、可计划、有明确起止；常驻智能体带来的推理负载则是分散、持续、难以预测峰值。每位用户拥有独立云端电脑并7×24运行，意味着即使无人对话，也存在状态驻留、上下文维护与后台任务循环。这一变化对基础设施的影响有三点：一是电力与散热从“峰值应对”变为“基荷连续”，选址、供电冗余与液冷渗透率的约束提前；二是互联需求上升，推理集群数量增加、分布更分散，光互联的端口需求随服务器端口速率同步提高；三是计量方式变化，托管沙箱按容器规格与时长计价，说明运行环境本身已成为独立的计费与成本对象，单位算力的利用率管理变得关键。

4.2 推理经济学：单价下降与总量扩张同时发生

Sol 以约五分之一的价格提供接近旗舰的智能，缓存折扣高达95%，Ultrafast以6倍价格换6—8倍速度。三个价格信号指向同一结论：单次调用的成本在快速下降，而调用次数与单任务步骤数在快速上升。单位价格的下降并未压缩市场，反而通过降低智能体工作负载的门槛扩大了可商业化场景。对产业链而言，这意味着需求弹性的判断依据应从“单价×次数”转向“任务总量”，而任务量的增长取决于智能体能否真正接管长链路工作——本次发布会给出的证据是方向性的（1月时模型在耗时一天以上的任务上大多失败，截至7月配合Ultrafast 已能在无人干预下完成超过三分之一的“一天级”研究任务），但覆盖率仍只有三分之一量级，渗透节奏不宜线性外推。

4.3 软件与协作层：入口迁移与“面向智能体”的改造

Space、Pages、协作幻灯片叠加 Slack 与 Teams 内嵌，使 ChatGPT 直接进入团队协作场景；插件扩展则把整个第三方应用搬入 ChatGPT 与Codex。对协作类与工具类SaaS而言，风险不在于功能被替代，而在于分发入口与用户关系被上移：用户留在 ChatGPT内完成任务，第三方产品退化为被调用的能力模块，席位制与按用户收费的商业模式承压。反向的机会属于两类公司：一是能提供智能体难以自建的专业能力（专业数据、合规资质、行业工作流）并完成接口化改造的企业；二是承接“智能体调用”的新增流量、以用量或结果计费的环节。应用层的获客成本则在下降——Sign in with ChatGPT 让用户以订阅额度试用第三方产品，降低了付费转化的启动摩擦。

4.4 标准与治理：智能体身份、权限与支付的空白地带

发布会与外部信息共同指向一块尚未标准化的领域：智能体以什么身份访问外部服务、能否代用户完成交易、出事后的责任如何划分。会外已有实证：零售平台对第三方智能体的态度出现分化，有的禁止其浏览商品页，有的允许浏览但拦截自动结算。OpenAI通过权限跟随、边界设定与审计能力把治理内建到平台，实质是争夺事实标准。对产业的影响是双向的：短期内智能体的可触达范围受平台政策限制，落地速度低于演示水平；中期一旦接口与身份规范确立，具备标准化能力的企业会获得加速度。

五、结论

第一，本次 DevDay 的产业意义大于产品意义。它标志着头部厂商的竞争重心从“模型能力”转向“常驻智能体 + 分发入口 + 开发者基础设施”的平台组合，并首次把计费锚点从 token 扩展到运行环境、响应速度与分发渠道。

第二，需求侧的确定性提高，但受益环节的分布是不均衡的。常驻推理负载抬高了电力、散热、互联与内存的长期需求中枢，上游环节的量价逻辑比中下游更清晰；自研芯片与专用低延迟算力会在两年维度上改变供给结构。

第三，软件层的估值框架需要重估。当协作与工具的入口上移至智能体平台，按席位收费、依赖界面留存的商业模式面临结构性压力，投资标的选择应偏向“能力不可替代 + 已完成接口化改造”的一侧。

第四，需要密切跟踪的不是发布会清单，而是四件事：收入与成本的审计口径何时公开、Anthropic 的 IPO 定价、Ultrafast 与沙箱的实际定价、以及安全事件与监管的互动。这四项将共同决定AI资产在2027年的估值锚。
