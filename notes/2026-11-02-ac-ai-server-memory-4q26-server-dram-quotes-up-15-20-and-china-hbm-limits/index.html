原标题：AI服务器存储调研_ 4Q26服务器DRAM报价拟涨15-20%, 27年价格预计继续上涨, 北美AI需求强劲与中国GPU_HBM供应受限形成分化

核心摘要

  1. 专家称4Q26服务器DRAM试探性报价普遍上涨15–20%，若落地，2027年全年服务器DRAM价格仍有上涨空间。
  2. 北美CSP长协价格在3Q–4Q26基本触顶，未被长协覆盖的算力中心、二线互联网和OEM仍面临涨价；现货对合约溢价约80–90%，64Gb最坚挺，96/128Gb溢价收窄到10–20%。
  3. 中国客户自8月起谈判拉锯，原因是B300等高端GPU难以进入、国内三大云现金流转负、美元储备紧张。
  4. HBM现货价从上半年1500–2000美元涨到超过3000美元，为海外大客户采购价的6–7倍；长鑫2026年HBM只够支持十几万张国产加速卡。
  5. 昇腾910B、寒武纪、阿里PPU交付都低于预期，国内CSP转向采购用GDDR的910B2等替代品。
  6. 长鑫DDR5在国内服务器份额与三星、海力士接近，均在30–40%，报价已与海外持平，成本高约30%但利润仍可观。

摘要

  • 服务器DRAM价格走势及2027年供需展望；
  • HBM供应紧张及国产AI芯片交付情况；
  • DDR5国产替代及全球竞争格局。

以下是专家观点：

对于2027年存储产品的价格走势有何预判？

目前存储产品价格已处于高位。服务器市场，尤其是以北美为代表的区域，需求依然旺盛，客户对价格的接受度较高。具体来看，许多北美CSP签有长协，这部分协议价格在2026年第三、第四季度基本已触及价格上限，上涨空间有限。然而，未被长协覆盖的部分，例如部分算力中心、二线互联网公司以及OEM厂商，仍面临服务器DRAM价格的持续上涨。目前针对2026年第四季度的试探性报价显示，服务器集群内存的价格涨幅普遍在15%至20%之间。若此涨幅在第四季度落地，预计2027年全年服务器DRAM价格仍有上涨空间，这一预期已优于早前判断。

在当前市场环境下，客户为何仍能接受持续上涨的服务器DRAM报价？

尽管部分客户资金紧张，可能会减少采购量，但市场需求依然存在。一个关键指标是，现货价格相较于合约价格仍保持着显著溢价，近期溢价幅度可达80%至90%，这表明市场中仍有买家愿意接受高价。不过，市场内部存在分化：由于服务器内存普遍存在降规趋势，需求最为旺盛的64Gbit单条内存，其现货与合约价的溢价依然坚挺；相比之下，96Gbit和128Gbit内存的溢价则已大幅收窄，大约仅在10%至20%的区间。

北美市场对价格上涨的接受度较高，而中国市场的情况如何？是否存在价格谈判上的分歧？

北美市场近两个季度的价格谈判进程相对顺利，未出现明显的拉锯。相比之下，中国市场的价格谈判自2026年8月起就已开始出现拉锯。近期，国内客户在沟通中已开始释放偏向保守的信号，例如表示2027年的需求增长可能不及预期或完全没有增长。这种表态背后既有谈判策略的因素，也存在客观制约。

国内客户在谈判中表现保守，其背后的客观原因具体是什么？

国内客户面临的主要客观制约因素首先是GPU的获取困难。自2026年6月以来，B300等高端GPU难以进入中国市场。其次是资金问题，国内三大主要云服务商的现金流均已转负。此外，采购高端硬件需动用美元储备，在价格翻了数倍的情况下，美元储备也日趋紧张。综合来看，GPU供应受限是当前最核心的瓶颈。虽然可以采用国产替代方案，如昇腾、寒武纪以及自研芯片，但这些方案也面临挑战。新一代国产及自研芯片普遍开始采用HBM3及HBM3E，而这类高带宽内存的供应渠道自2026年起也变得非常不顺畅。作为参考，HBM的现货价格已从上半年的1,500至2000美元上涨至超过3,000美元，且即便在此高价下依然一货难求。国际原厂的HBM难以进入，而cx虽有产出，但数量有限，其2026年的产量预计仅能支持十几万张国产AI加速卡，远无法满足市场需求。

在GPU和HBM供应受限的情况下，对2027年国内AI相关硬件的交付情况有何预期？

由于供应瓶颈，华为昇腾910B、寒武纪以及阿里PPU等产品的实际交付量均低于预期。预计到2027年，包括英伟达在内的海外品牌GPU进口仍将面临较大困难。尽管cx的HBM产出可能会有所改善，有望支持到大几十万张甚至上百万张加速卡的生产，但这与国内庞大的需求相比仍有巨大缺口。因此，许多AI项目处于停滞状态。作为应对，国内CSP正在寻求替代方案，例如对采用GDDR内存的昇腾910B2以及无需HBM的Radeon Instinct MI300A等产品的采购意愿显著增强。

当前AI服务器产业链的主要瓶颈是什么？

目前整个产业链的瓶颈呈现出清晰的层次：GPU是供应最紧张的环节，其次是DRAM，再次是NAND Flash和CPU。由于GPU的短缺直接限制了服务器的组装和部署，这种上游的制约效应对下游的NAND Flash等部件产生了更为明显的“踩刹车”效应。

当前HBM现货市场价格飙升的原因是什么？

HBM的供应紧张是主要原因。目前现货价格已达到海外大客户采购价的六到七倍。这主要是因为三星策略的调整。此前，三星预留了与海力士相当的HBM产能，但实际出货量大约只有海力士的一半，导致大量产能闲置。这些闲置产能部分通过非官方渠道流入中国市场。但近期，随着三星的HBM3E 12-Hi和HBM4产品通过验证，以及其他基础产品的需求量上升，其产能也已饱和，无法再提供额外的市场供给。

cx在DDR和HBM方面的最新进展如何？特别是在服务器DDR5市场，其产品性能、市场份额、定价策略以及客户反馈是怎样的？

在服务器DDR领域，cx今年的进展显著，其DDR5产品已在国内市场（包括CSP和ODM客户）占据重要地位。2026年，国内服务器DDR市场三家供应商的份额非常接近，均在30%至40%的区间内。其中，三星份额最高，cx位居第二。客户反馈指出，cx的DDR5产品在发热和功耗方面表现稍逊，但其性能和数据指标能够满足使用要求。在当前供应紧缺的背景下，功耗问题并非关键障碍。因此，今年三大CSP已开始大规模采用其产品。定价方面，cx在2025年时会提供约高个位数到10%的价格折让，但现在其报价基本与另两家海外供应商持平。客户接受此价格并非出于经济性考量，而是在供应短缺下的无奈之选，因为不接受就无法获得足够的产品。尽管其生产成本因制程代差和多重曝光工艺可能高出约30%，但在当前市场售价下，其利润率依然非常可观。

cx在国内服务器DDR市场份额的提升，将如何影响全球DRAM供需格局以及海外供应商在中国的市场策略？

cx在国内市场份额的提升，尤其是在服务器DDR领域，将对全球供需关系产生缓解作用。根据其2027年的经营计划，其市场份额有望冲击第一。这一变化已经影响了海外供应商的策略。以公司为例，原计划在2026年为国内服务器客户增加30%的供应量，但考虑到cx的崛起以及部分CSP客户开始控制采购节奏，已将这部分增量转移至北美市场。因此，公司2027年对中国市场的供应量将与2026年持平。尽管在中国市场持平，但公司预测全球服务器DRAM出货量增长主要由北美市场驱动。

在国内客户因供应短缺而不得不接受cx产品的情况下，为何海外供应商反而选择将增量供应转移出中国市场？

这种情况的出现是市场动态平衡的结果。以一个具体客户为例，假设其2025年的采购量为100个单位，2026年需求增长至200个单位，增量为100%。两家海外供应商若按照以往每年20%-30%的增长节奏，最多只能满足130个单位的供应，这就产生了70个单位的供应缺口。如果客户不接受cx的产品，就无法满足其业务增长需求，可能面临市场落后等风险。cx的产品虽然功耗较高，导致运营成本如电费略有上升，但与其业务增长带来的收益相比，这点成本增加是微不足道的。因此，其产品是“能用”的，为国内客户提供了在供应短缺下的可行选择。正是因为cx填补了这部分市场缺口，海外供应商才得以将原计划供给中国市场的增量产能重新分配给供应更为紧张的北美市场。

从近期市场变化来看，存储产品的价格走势如何？

市场预期存储价格在上涨到一定水平后将面临阻力。不过，近期的边界变化显示，特定领域的价格可能继续上行。消费类市场也出现积极信号，例如苹果公司接受了相对较高的报价，其采购价格比当前国内安卓手机厂商高出5%以上，这表明部分消费类客户仍有能力接受价格上涨。总体而言，市场基本面未发生根本性改变，但情况有所好转。

公司主要的利润来源是什么？cx在DDR5市场的突破，长期来看将对其产生何种影响？

最大的利润来源是服务器DRAM，其出货量占比达到40%以上，利润贡献预估在三分之二左右。尽管HBM是市场热点，但2026年才是其盈利的元年。长远来看，如果cx的DDR5产品在海外市场获得成功，例如在非美国地区的数据中心得到部署且未受政策干预，其市场份额的增长将对包括海力士在内的国际三大存储厂商构成冲击。不过预计2027年cx在海外市场仍将处于试水阶段，市场占比会很小。

在当前市场周期下，cx是否会采取主动大幅降价的策略来争夺市场份额？

预计不会。目前cx在技术和成本上仍处于追赶阶段，不具备通过产能或成本优势来发动价格战的绝对实力。此外，当前整个存储行业周期向好，市场参与者普遍经营状况良好，因此没有必要通过激进的降价策略来破坏市场格局。
