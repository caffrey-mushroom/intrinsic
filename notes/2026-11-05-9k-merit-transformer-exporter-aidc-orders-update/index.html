1. 新签订单与全年目标

a) 截至10月，公司新签订单整体情况如何？

  • 截至2026年10月，公司累计新签订单接近120亿元：
  1. 海外订单约66.5亿元；
  2. 国内订单约55亿元。
  • 海外订单明显超出年初预期，国内订单整体保持平稳。
  • 海外订单增长较快，但由于交付周期较长、收入确认节奏偏慢，同时受到汇兑损益和计提损失影响，收入端增速暂时仍可能只有个位数。

b) 2026年全年新签订单预计达到什么水平？

  • 海外订单预计达到80亿—85亿元，高于此前70亿元左右的目标。
  • 国内订单预计约65亿元，表现较好时可能达到70亿元，整体与上年基本持平。

  2. 一季度至二季度上调至60亿—70亿元；
  3. 半年时上调至70亿元；
  4. 三季度后进一步上调至80亿元以上。

c) 海外订单为什么能够超预期？

  • 核心增量来自海外AIDC业务，全年海外AIDC订单预计约45亿元，较此前约35亿元的目标增加约10亿元。

  • 公司产品品类由干式变压器向二级主变、预制化模块、成套设备等方向扩展，提高了单客户订单金额。
  • 弗吉尼亚工厂已具备一定本地化产能，能够承接交付周期在3—6个月的短平快订单，弥补过去无法承接此类项目的短板。
  • 海外新能源、主变、海上风电业务也形成了增量支撑。

2. 海外区域订单结构

a) 北美市场截至10月的订单规模及业务结构如何？

  • 北美市场新签订单约35亿—36亿元，是海外最大的单一区域。
  • 按下游行业划分：
  1. IDC/AIDC相关订单超过24亿元，是最大组成部分；
  2. 新能源及储能配套约6亿元；
  3. 制造业约3亿元；
  4. 电网业务约2亿元。
  • 按产品划分：
  1. 变压器类产品约占70%—75%；
  2. 干式变压器约占北美订单的60%；
  3. 二级主变约占15%，主要为34.5千伏产品；
  4. 69千伏及138千伏产品合计约1亿多元；
  5. 其余约25%为高低压柜、成套设备及储能产品。
  • 美国IDC市场并非没有油浸式变压器订单，IDC项目主要采用二级主变，69千伏以上产品规模目前相对较小。

b) 北美市场2026年全年订单预计达到多少？

  • 美国市场全年新签订单预计约45亿元。
  • 截至10月约35亿元，最后两个月预计再增加约10亿元。
  • 新增订单将主要来自AIDC，但不会全部来自AIDC，也包含新能源、电网及其他业务。
  • 2027年北美订单目标为55亿—60亿元，较2026年增加约10亿—15亿元。

c) 亚非拉市场截至10月的订单结构如何？

  • 亚非拉市场订单约23亿—24亿元，全年预计约27亿—30亿元。
  • 主要业务包括：
  1. 新能源业务约8亿—9亿元；
  2. IDC业务约8亿—9亿元；
  3. 工商业及制造业约4亿元；
  4. 纯电网业务约2亿元。
  • 新能源与IDC业务之间存在交叉，公司正在推广一体化和预制化方案：
  1. 新能源项目可配套主变及升压变电站；
  2. IDC项目可配套主变、变电站及成套设备。
  • 亚非拉订单增长主要来自主变业务，东南亚、中东、中亚是油浸式变压器的重点市场。

d) 亚非拉市场未来订单如何展望？

  • 2025年亚非拉订单基数约十几亿元，2026年预计达到27亿—30亿元，实现接近翻倍增长。
  • 2027年预计约35亿—40亿元，但增长速度可能较2026年有所放缓。
  • 增长放缓的主要原因包括：
  1. 越南等部分项目竞争激烈；
  2. 国内大型厂商已经进入当地市场；
  3. 部分项目落地节奏较慢；
  4. 东南亚主变市场短期表现偏弱。
  • 中东、中亚市场当前表现相对稳定，澳洲、巴西、阿根廷等市场未来也有望由新能源业务向主变业务延伸。

e) 欧洲市场的订单规模和业务结构如何？

  • 截至10月欧洲订单约8.5亿元，全年预计约10亿—11亿元。
  • 其中新能源业务约6.5亿元，全年风电订单预计接近8亿元：
  1. 海上风电约5亿—6亿元；
  2. 其余主要为大型陆上风电。
  • 西班牙、德国等地的制造业项目及部分牵引变电站业务合计约2亿元。
  • 欧洲光伏业务占比较低，当前主要依靠风电，尤其是海上风电拉动。

f) 欧洲市场未来增长空间如何？

  • 2027年欧洲新签订单预计约13亿—14亿元，同比增长约30%—40%。
  • 该目标主要基于西欧风电业务，尚未充分考虑东欧及波兰市场的潜在增量。
  • 英国、西班牙、德国、法国及北欧部分国家未来3—5年海上风电需求仍较强。
  • 到2030年前，欧洲重点海上风电市场有望保持较高增速，公司相关配套业务也有望同步增长。
  • 欧洲市场虽然变压器紧缺，但电网及主变市场准入难度较高，公司短期仍将以风电和新能源项目为主要切入点。

3. 国内市场与业务结构调整

a) 国内订单表现如何？

  • 截至10月国内新签订单约55亿元，全年预计约65亿元，表现较好时可达到70亿元。
  • 2025年官方口径约57亿元，实际业务规模约60多亿元，因此2026年整体与上年基本持平。
  • 国内市场竞争激烈，公司正在主动剥离部分低端、低毛利业务。

b) 国内业务重点聚焦哪些客户和项目？

  • 公司主要聚焦高端市场，包括：
  1. “五大六小”发电集团；
  2. 中国移动、中国电信；
  3. 华为、字节跳动；
  4. 部分电建项目；
  5. 省网及工商业主变项目；
  6. 海上风电及绿电项目。
  • 公司已经入围国网、南网，但总部级项目尚未实现明显突破，目前主要通过省网项目积累业绩。
  • 未来国内增量可能来自海风、主变、绿电、HVDC及SSC等新型直流项目。

c) 公司为何要拓展总包业务？

  • 公司产品已覆盖从主变到配变的完整供电环节，具备由单一设备供应向整体解决方案延伸的基础。
  • 总包业务范围可包括：
  1. 基础建设；
  2. 场地平整；
  3. 主变、配变及成套设备交付；
  4. 整体运维；
  5. 预制化、模块化变电站。
  • 拓展总包业务有助于提升单项目价值量、增强客户黏性，并提高公司对项目交付节奏的控制力。

4. AIDC订单、客户结构与政策影响

a) 2026年海外AIDC订单规模如何？

  • 海外AIDC订单预计约45亿元，占海外订单的一半以上。
  • 美国市场贡献约35亿元，其他区域约10亿元。
  • AIDC订单是海外业务超预期的最主要来源。

b) 北美AIDC主要客户贡献如何？

  • 亚马逊：
  1. 两年累计订单约12亿元；
  2. 2025年约4亿—5亿元；
  3. 2026年预计约8亿—9亿元；
  4. 当前份额基本做满，未来仍有一定超额空间。
  • xAI：
  1. 2026年预计约6亿—7亿元；
  2. 公司由原有供货品类扩展至二级主变和预制化模块；
  3. 2027年预计可达到8亿—9亿元。
  • 谷歌：
  1. 尚未进入正式白名单；
  2. 目前主要通过总包商间接供货；
  3. 2026年已取得约3亿—4亿元订单。
  • Meta：
  1. 尚未进入正式白名单；
  2. 主要通过总包商供货；
  3. 2026年订单约1亿—2亿元。
  • 微软、甲骨文、OpenAI等客户目前单家订单为数千万元至约1亿元。
  • CSP客户合计贡献约22亿元，总包商贡献约6亿—7亿元，其余订单较为分散。

c) 2027年北美AIDC订单预计如何增长？

  • 2027年北美订单目标为55亿—60亿元，其中AIDC预计约40亿元。
  • 增长来源主要包括：
  1. 亚马逊和xAI基本盘持续增长；
  2. 争取进入谷歌、Meta正式白名单；
  3. 争取进入微软、甲骨文、OpenAI等客户基础白名单；
  4. 通过第三供、第四供或尾供身份切入新客户；
  5. 加强与纬创、世纪互联等总包商合作；
  6. 依靠预制化和模块化方案缩短现场调试周期。
  • 相较第三方新创AIDC公司，公司更倾向于选择资金来源稳定、验收体系成熟的大型客户。
  • CoreWeave等新创客户虽可能带来短平快订单，但存在设计、验收和尾款回收风险，因此不会成为公司重点方向。

d) 北美AIDC项目是否已经出现延期？

  • 当前在手订单大多属于此前已完成审批、正在执行和交付的项目，短期受政策影响有限。
  • 新并网项目主要对应2027—2028年，长期可能出现延期、搁浅或停止。
  • 德州、宾州、俄亥俄州受影响可能更明显，尤其是德州：
  1. 当地绿电成本较低，项目集中度较高；
  2. 并网、人工、认证、环保等问题较突出；
  3. 联邦政策与州政策之间可能存在冲突。
  • 客户层面，微软和Meta的项目节奏变化相对较大，亚马逊和xAI则相对稳定。

e) 政策影响何时会真正传导至订单和交付？

  • 行业判断是，实质性影响可能到2027年下半年才逐渐体现。
  • 2027年上半年以前，整体生产和交付节奏预计不会发生明显变化。
  • 2027年下半年至四季度启动的新项目，可能开始受到政策及审批节奏影响。
  • 对2027年的整体影响预计约10%—20%；2028年的不确定性更高。
  • 若AIDC建设放缓，新能源需求只能部分对冲，难以完全抵消：
  1. AIDC前期增速过快；
  2. 新能源短期难以达到同等增量规模；
  3. 新能源业务毛利率低于AIDC。

f) 新能源业务能否对冲AIDC下行风险？

  • 新能源、光储及电网投资有望减弱AIDC放缓带来的影响，但无法完全抵消。
  • 客户对新能源项目的意向有所增加，评估和招投标活动更活跃，但尚未完全转化为书面订单。
  • 四季度本身是新能源旺季，叠加政策催化，光储项目预计环比增长。
  • 纯光伏项目已较少，多数项目会配套储能，以满足IDC、居民用电或制造业用电需求。
  • 北美新能源项目毛利率约35%—40%，虽然低于AIDC，但明显高于普通电网及工业项目。

5. 变压器供需、交期与竞争格局

a) 全球变压器目前是否仍然紧缺？

  • 欧美变压器供应仍然紧张，主变尤其紧缺，配变紧缺程度略有缓解。
  • 主干电网中220千伏、345千伏、500千伏乃至765千伏设备需求较强。
  • 紧缺原因包括：
  1. AIDC新增用电需求；
  2. 已建IDC项目持续消耗电力；
  3. 新能源升压站及并网需求；
  4. 主干电网老化及扩容；
  5. 制造业和居民用电增长。
  • 即使AIDC增速放缓，主干电网及新能源需求仍能支撑行业景气，只是需求结构可能发生变化。

b) 不同产品的交付周期如何？

  • 国内生产并出口美国的常规AIDC干式变压器：约12—15个月。
  • 美国本土生产的配变：约6—9个月，部分订单可缩短至6个月以内。
  • 中压真空开关柜：约18个月。
  • 二级主变：约18个月。
  • 138千伏产品：约24个月或更长。
  • 110千伏以上大型主变：通常约24个月。
  • 345千伏等更大型号主变：可能超过3年。
  • 伊顿等海外厂商交期普遍在18个月以上，现有本土产能基本满负荷。

c) 公司相较海外厂商的竞争优势是什么？

  • 产能释放节奏领先：
  1. 公司北美产能已开始爬坡；
  2. 海外竞争对手新增智能化工厂多数要到2027—2028年才能投产。
  • 交期更短：
  1. 美国本土生产可将交期压缩至6—9个月；
  2. 可承接3—6个月的短平快订单。
  • 性价比更高，产品价格和交付效率优于海外同类厂商。
  • 公司拥有数字化、模块化生产体系，可以快速切换AIDC、新能源及电网产品。
  • 自动化工厂能够更好地保证大批量产品的可靠性、一致性、输出电压精度和偏差率。

d) AIDC放缓后，行业景气是否会明显下降？

  • 整体紧缺程度可能有所缓解，但不会出现大幅逆转。
  • 主干网需求与AIDC政策关系较小。
  • 新能源项目同样需要110千伏、220千伏主变及升压变电站。
  • 需求可能由AIDC配变逐步转向：
  1. 新能源升压变；
  2. 升压变一体机；
  3. 移动式变电站；
  4. 预制化变电站；
  5. 主干电网大型主变。

6. 主变业务与高压产品规划

a) 2026年主变订单规模如何？

  • 按110千伏以上主变口径，国内外合计目标原为20亿元。
  • 截至10月预计可实现15亿—16亿元：
  1. 海外约10亿元以上；
  2. 国内约5亿—6亿元。
  • 系统中可能仍有部分订单尚未录入，最终规模存在一定上修空间。

b) 2027年主变业务目标是多少？

  • 2027年主变及相关高压业务目标约30亿—35亿元。
  • 增长来源包括：
  1. 东欧市场拓展；
  2. 中东由沙特、阿联酋向其他国家扩展；

  • 美国和墨西哥本土化生产毛利率预计可达到50%以上。

b) 三季度毛利率为何下降？

  • 核心原因是铜价波动及成本传导不充分。
  • 公司期铜成本按照约6个月均价核算，部分阶段的高铜价仍造成一定损失。
  • 公司已经采取供应链优化、锁铜等措施，但只能抵消部分影响。
  • 欧美市场价格传导能力较强，亚非拉市场更看重价格，原材料涨价较难完全向客户转移。
  • 三季度大型变压器企业利润普遍承压，属于行业共性问题。

c) 后续毛利率是否还有提升空间？

  • 剔除铜价因素，毛利率仍有上升空间，主要来自：
  1. AIDC占比提高；
  2. 主变及高压产品占比提高；
  3. 国内主动退出低端业务；
  4. 美国本土产能释放；
  5. 产品结构向预制化、模块化和总包方案升级。
  • 若铜价继续高位波动，毛利率提升节奏可能受到干扰。
  • 主要经营风险包括美国AIDC政策变化和铜价上涨。

  • 2027年收入预计达到120亿元以上。

  • 主要风险仍为北美AIDC政策变化、项目延期及铜价上涨。

9. SST产品进展与商业化节奏

a) SST目前处于什么研发阶段？

  • SST目前正在进行DVT实物测试，已开始采集运行数据并开展动态验证。
  • 此前北美送样包括3兆瓦和13兆瓦样机：
  1. 3兆瓦样机可以运行，并已完成部分接口和控制系统测试；
  2. 当前核心问题是功率密度不足；
  3. 北美应用要求调整至5兆瓦，需要进一步解决大容量散热问题。
  • SST采用模块化设计，理论上可以组合到5兆瓦，但热管理和批量一致性仍需验证。

b) SST商业化时间表是否有所推迟？

  • 2027年北美市场基本看不到商业化运行。
  • 2027年可推出2—3台原型机，完成由样机向工程化产品过渡。
  • 2028年有望进入约10台规模的小批量生产。
  • 大规模商业化可能要到2028年底或2029年。
  • 行业普遍认为SST是长期趋势，但产业化时间节点较此前预期更晚。

c) 国内SST业务进展如何？

  • 国内应用可能率先集中在：
  1. 超充；
  2. 重卡充电；
  3. 微电网园区；
  4. 移动能源；
  5. 新型直流供电场景。
  • 公司已100%中标移动能源原型机项目，目前数量为1台。
  • 该原型机具有产品定型意义，后续若批量生产，将重点解决10台、100台规模下的品控和一致性问题。
  • 大规模采购时，客户可能采用公司主供、另一家公司备供的方式控制供应风险。

d) SST未来如何与其他供电架构竞争？

  • 2029—2031年，SST、800伏HVDC和“巴拿马电源”等方案可能长期共存。
  • 各类方案将围绕性价比、效率、可靠性和功率密度展开竞争。
  • SST能否真正放量取决于：
  1. 实际运行数据是否稳定；
  2. 大容量散热问题能否解决；
  3. 批量生产成本能否下降；
  4. 行业标准和架构能否统一；
  5. 能否应对阳光等本土厂商的竞争。
  • SST整合了高压柜和UPS模块功能，单瓦价值量较高；若后续放量，有望部分抵消传统AIDC设备需求放缓的影响。

10. 核心结论与风险判断

a) 公司当前基本面是否持续改善？

  • 新签订单持续超预期，尤其是海外AIDC和主变业务。
  • 海外订单目标已由年初45亿元逐步上调至80亿—85亿元。
  • 北美本土产能开始释放，有助于缩短交期、提高毛利率并增强客户竞标能力。
  • 产品结构向AIDC、主变、高压设备、模块化和总包方案升级。
  • 2027年收入和利润均有望实现较快增长，基本面总体向好。

b) 后续最重要的增长驱动是什么？

  • 北美AIDC客户扩容及新白名单突破。
  • 亚马逊、xAI等核心客户稳定增长。
  • 主变及高压产品由15亿—16亿元向30亿—35亿元扩张。
  • 欧洲海上风电持续增长。
  • 美国和墨西哥本土产能释放。
  • 预制化、模块化及总包业务提高单项目价值量。
  • SST等新产品在2028年以后逐步贡献增量。

c) 后续需要重点关注哪些风险？

  • 美国AIDC政策变化及州、联邦政策冲突。
  • 2027年下半年后部分AIDC项目延期、搁浅或取消。
  • 铜价上涨导致毛利率承压。
  • 亚非拉市场竞争激烈、成本难以传导。
  • 谷歌、Meta、微软等客户白名单突破不及预期。
  • 美国本土工厂产能爬坡慢于计划。
  • SST研发、散热、成本及批量品控进展低于预期。
