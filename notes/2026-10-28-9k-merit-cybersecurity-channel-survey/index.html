专家访谈会议纪要

1. 客户覆盖与行业分布

a) 目前负责多少客户，主要分布在哪些行业？

  • 负责约35—40家客户，绝大多数为大型企业客户。
  • 客户行业分布：
  1. 消费品与零售：约35%。
  2. 制造业：约25%。
  3. 金融服务：约20%。
  4. 医疗、生命科学与制药：约20%。

b) 客户的典型规模和IT环境如何？

  • 客户规模与组织特征：
  1. 企业规模通常约为50亿—500亿美元。
  2. 员工人数约为1.5万—15万人。
  3. 部分客户为跨地区运营的全球性大型组织。
  • IT环境普遍较为复杂：
  1. 广泛采用多云或混合云架构。
  2. 使用SAP、Salesforce等大型企业应用。
  3. 同时部署多个数据平台和安全产品。
  4. 系统复杂度较高，为安全平台整合、身份治理和云安全创造持续需求。

2. 安全预算增长与行业景气度

a) 2026年安全支出预计较2025年增长多少，较年初预期是否上调？

  • 2026年客户安全支出增速预计达到10%—12%。
  • 年初预期约为7%—8%，目前已明显上调。
  • 上调的主要原因包括：
  1. AI智能体应用逐步进入生产环境。
  2. 企业需要提升AI应用及模型的安全保障能力。
  3. SASE、边缘计算、数据安全和云原生安全需求增加。
  4. 基础设施现代化和安全产品更新换代同步推进。
  5. 客户安全项目活动与采购意愿持续增强。

b) 2027年安全支出增速预计如何变化？

  • 预计2027年安全支出增速将在2026年基础上再提高约3—4个百分点。
  • 对应增速可能达到13%—15%。
  • 2027年有望成为安全行业表现较强的一年，主要由AI生产用例扩张、机器身份增长、云与边缘环境复杂化等因素推动。

c) 有多少客户正在增加、维持或削减安全预算？

  • 预算增加：
  1. 约50%—55%的客户正在提高安全预算。
  2. 更乐观估计可达到55%—60%。
  • 预算维持不变：
  1. 约30%—35%的客户维持现有预算水平。
  • 预算削减：
  1. 仅约5%的客户减少安全预算。
  2. 安全预算削减并非普遍现象，整体需求仍然强劲。

d) 少数客户削减安全预算的原因是什么？

  • 年初部分联邦政府客户采取了较保守的预算策略。
  • 部分对宏观环境更敏感的行业可能削减部分产品投入。
  • 部分企业并非削减安全能力，而是利用AI和自动化减少专业服务、咨询服务或常规人工操作成本。
  • 因此，预算结构可能从人员和服务支出转向软件、平台和自动化工具支出。

3. 安全支出占比与整体IT预算趋势

a) 安全预算占整体IT预算的比例是多少？

  • 2026年安全预算约占整体IT预算的12%—13%。
  • 相较2025年，该比例提高约2—4个百分点。
  • 上述数据为专家基于客户情况的粗略估算，实际占比因行业而异。

b) 哪些行业的安全预算占比更高？

  • 金融服务、医疗、生命科学等受监管行业安全投入意愿更强。
  • 消费品、零售等行业相对更偏业务驱动，通常优先推进应用建设，在发生安全事件或风险暴露后再追加安全投入。
  • 行业监管强度、数据敏感程度及企业管理层风险意识，是安全预算差异的核心原因。

c) 预计2027年安全预算占IT预算的比例如何变化？

  • 预计2027年安全预算占整体IT预算的比例将继续上升。
  • 主要驱动因素包括：
  1. 大量AI应用仍处于早期生产阶段，后续规模化将增加安全需求。
  2. 智能体和机器身份数量快速增加。
  3. 物联网、物理设备及边缘计算用例持续扩张。
  4. 漏洞管理、数据治理和物理设备安全需求提升。
  5. IT服务管理与安全能力进一步融合。

d) IT预算占公司整体运营支出的比例如何变化？

  • 访谈未给出IT预算占公司整体运营支出的明确比例。
  • 但从趋势看，整体IT预算正在上升：
  1. 2026年客户IT预算增幅约为15%—20%，更集中估计约为15%—16%。
  2. 2027年预计仍将增长约10%—12%。
  • 增长主要来自应用现代化、数字化转型、云平台建设及AI、生成式AI投入。
  • 客户预计从2027年末或投资周期的第二年至第三年开始，通过AI逐步实现运营效率改善。

4. 云、AI与安全支出增长的核心驱动

a) AI基础设施现代化将如何推动安全需求？

  • 客户正在围绕AI训练、推理和生产应用升级基础设施。
  • 应用现代化及容器化部署增加，将带动以下需求：
  1. 防火墙和安全网关升级。
  2. 云原生应用保护。
  3. 容器与工作负载安全。
  4. API安全及数据访问控制。
  5. 混合云和多云环境下的统一安全管理。
  • 整个安全基础设施市场也进入新一轮更新换代周期。

b) 为什么AI智能体会重新激活身份与访问管理市场？

  • 传统身份与访问管理市场过去增长相对平稳，但机器身份正在成为新的增长点。
  • 每个AI智能体都需要独立的机器身份、访问权限和生命周期管理。
  • 协作型智能体还可以即时创建其他智能体，因此企业需要：
  1. 监控和编排智能体。
  2. 为其分配适当权限。
  3. 管理API密钥、加密密钥及特权访问。
  4. 防止智能体访问超出用户权限范围的数据。
  • 身份访问管理、身份治理及特权访问管理因此获得更多预算。

c) 边缘计算和个性化应用如何带动安全投入？

  • 企业正在通过边缘计算支持实时分析、个性化服务和低延迟AI应用。
  • 边缘节点、传感器和IoT设备数量增加，扩大了安全边界。
  • 企业需要覆盖边缘设备、网络连接、数据传输及终端身份的统一安全方案。

5. 安全平台化与SOC整合趋势

a) 为什么客户开始从单点产品转向安全平台？

  • 安全市场高度分散，企业通常同时使用数十种单点安全产品。
  • 典型组合可能包括：
  1. Cisco防火墙。
  2. Splunk或IBM QRadar。
  3. Okta与Microsoft Entra身份管理。
  4. SailPoint等身份治理和特权访问产品。
  5. CrowdStrike、Trend Micro、Sophos或McAfee终端安全产品。
  6. 电子邮件安全、Web安全和URL过滤等其他产品。
  • 当网络钓鱼、机器身份入侵或API攻击发生时，多个产品和团队需要分别排查，容易出现：
  1. 数据分散在多个仪表盘中。
  2. 跨团队协作效率低。
  3. 各供应商或团队相互推诿。
  4. 缺乏统一事件分析和响应能力。

b) 平台化的核心价值是什么？

  • 平台化的主要目的并不只是降低成本，而是统一数据并提升安全分析能力。
  • 核心价值包括：
  1. 将网络、身份、终端、云和应用安全数据汇集至统一平台。
  2. 在统一数据基础上使用AI或智能体开展分析。
  3. 更快定位攻击路径和根因。
  4. 在安全事件发生前进行预警或自动采取措施。
  5. 减少多团队、多仪表盘带来的调查复杂度。
  • Palo Alto、CrowdStrike等厂商均在推进平台化，但平台整合和数据战略是否已经完全成熟，仍需继续观察。

c) 目前有多少客户正在推进安全平台整合？

  • 约40%—45%的客户已经启动安全平台整合项目。
  • 预计该趋势将在2027年和2028年持续，而非短期内趋于稳定。

d) 为什么平台整合项目落地较慢？

  • 平台整合并非简单更换合同或采购单一产品，而是需要替换Cisco、Splunk、QRadar及其他单点方案。
  • 主要难点包括：
  1. 迁移多个系统中的历史数据。
  2. 重新配置安全策略和工作流程。
  3. 确保新旧系统平稳切换。
  4. 协调多个安全和IT团队。
  5. 验证平台是否能够覆盖原有单点产品能力。
  • 因此，客户兴趣和承诺投入在增加，但实际迁移、生产部署和规模化使用需要较长时间。

6. 安全预算重点投向

a) 哪些安全功能更容易获得预算？

  • 当前预算增长最明显的三大领域为：
  1. 数据安全。
  2. 身份与特权访问管理。
  3. 云安全。

b) 数据安全为何成为首要投入方向？

  • 客户正在建设更大的数据仓库和数据平台，为AI推理提供支持。
  • 企业需要确保智能体只能访问其对应用户有权访问的数据。
  • 重点投入包括：
  1. DLP，即数据丢失防护。
  2. 数据安全态势管理。
  3. 数据治理。
  4. 数据质量。
  5. 数据访问权限和敏感数据保护。

c) 身份与特权访问管理为何获得更多预算？

  • 智能体身份与传统人类用户身份存在显著差异。
  • 随着智能体、API和自动化流程增加，企业需要管理不断增长的：
  1. 智能体ID。
  2. API密钥。
  3. 加密密钥。
  4. 机器账户。
  5. 特权访问权限。
  • 因此，IAM、PAM和机器身份管理成为强制性投入，而非可选项目。

d) 云安全需求为何持续增长？

  • 客户正在从单一云服务商转向AWS、Azure和GCP并用的多云架构。
  • 企业不希望完全依赖某一家超大规模云服务商的原生安全工具。
  • 因此，能够跨多个云平台提供统一覆盖的第三方方案更受欢迎。
  • 重点方向包括：
  1. CNAPP。
  2. CWPP。
  3. 云原生应用安全。
  4. 云工作负载安全。
  5. 多云安全态势管理。
  • Palo Alto、CrowdStrike和Cloudflare等厂商均在扩大云安全产品布局。

e) 除上述三类外，还有哪些领域同步增长？

  • SOC现代化。
  • SOC与NOC整合。
  • SASE。
  • 零信任。
  • 漏洞管理。
  • IoT和物理设备安全。
  • 这些领域部分由AI和自动化驱动，但数据安全、身份安全和云安全的预算增长更直接来自业务需求。

7. 安全预算结构与自动化降本

a) 安全预算是否包含人员成本？

  • 安全预算不仅包括软件、硬件和安全产品，也包括：
  1. 内部安全人员薪酬。
  2. 第三方服务商费用。
  3. 咨询与专业服务成本。
  4. 日常运营及安全管理支出。

b) 外部安全产品占比是否上升、人工成本占比是否下降？

  • 总体方向是软件和自动化工具支出占比上升，人工和服务成本占比逐步下降。
  • 企业正在增加对安全供应商的支出，以减少过去由内部团队或第三方服务商完成的常规工作。
  • 但人工成本下降速度取决于产品类型：
  1. CrowdStrike智能体SOC、Falcon套件和Charlotte AI等产品集成较快，能够较快减少人工操作。
  2. Palo Alto平台化项目通常需要较长的前期整合，可能在8—12个月甚至更长时间后，人工成本才会下降。
  • 因此，人工降本更多体现为多年期投资回报，而非所有项目都能立即见效。

8. 项目签约、部署与AI需求成熟度

a) 从签约到正式投入生产的整体周期是在缩短还是延长？

  • 不同产品的部署周期存在差异：
  1. 面向AI工作负载的专用防火墙，实施周期相对较短。
  2. 替换Splunk、QRadar等系统的下一代AI驱动SOC或SIEM，部署周期更长。
  3. 机器身份等新型IAM项目涉及新的管理模式，实施难度较高。
  • 尽管AI可以加快部分产品实施，但由于新技术较多、工具整合复杂、客户仍在验证用例，整体项目周期仍在延长，尚未缩短。

b) 有多少客户已经明确自身AI安全需求？

  • 约40%—45%的客户已经较为明确自身需求。
  • 约55%—60%的客户仍处于探索、小规模生产或缓慢推进阶段。

c) 哪些行业的需求更加明确？

  • 需求较明确、推进较快的行业包括：
  1. 消费品。
  2. 快餐与连锁服务。
  3. 电商。
  4. 媒体与娱乐。
  • 这些行业需要快速推进营销自动化、个性化和边缘AI等应用，因此安全需求更容易明确。

d) 哪些行业推进较慢？

  • 医疗、生命科学和金融服务行业受监管要求影响，推进相对谨慎。
  • 联邦政府和州政府客户也以小规模生产用例为主，尚未普遍开展大规模实施。
  • 预计相关行业将在2027年扩大采用规模。

9. 主要安全厂商市场表现

a) Palo Alto Networks的市场份额如何变化？

  • 市场份额有所提升。
  • 主要受益于：
  1. 平台化战略。
  2. XSIAM。
  3. SASE。
  4. 防火墙更新。
  5. AI工作负载及混合云安全需求。
  • AI应用带来更多东西向流量，而传统防火墙更多处理南北向流量，这将推动新一代防火墙需求，Palo Alto有望成为主要受益者。

b) Cloudflare的市场份额如何变化？

  • 市场份额有所提升。
  • 主要增长方向包括：
  1. SASE。
  2. 应用安全。
  3. Workers AI。
  4. 边缘计算。
  5. 零信任。
  • Workers AI在媒体、娱乐等需要边缘能力的行业中获得更多关注。

c) CrowdStrike的市场份额如何变化？

  • 市场份额明显提升。
  • 主要驱动因素包括：
  1. 企业终端及IoT设备数量增长。
  2. SIEM和SOC属于企业主要成本中心，自动化需求强。
  3. Falcon套件和Charlotte AI能够较快实现集成。
  4. 企业希望利用智能体SOC减少人工运营成本。

d) Zscaler为何出现一定放缓？

  • Zscaler是受访厂商中唯一出现一定减速的公司。
  • 主要原因包括：
  1. ZIA和ZPA项目实施周期较长。
  2. 产品定位更加聚焦零信任，平台覆盖范围相对有限。
  3. Palo Alto、Cloudflare和CrowdStrike均在推出更广泛的零信任能力。
  4. 客户倾向于选择能够整合更多安全功能的平台型供应商。
  • 部分Zscaler项目可以被Palo Alto、Cloudflare等厂商承接，其垂直型定位因此面临压力。

e) Okta同样是垂直厂商，为什么市场份额仍在提升？

  • Okta虽然聚焦身份领域，但其所处赛道正受到机器身份增长的直接推动。
  • 市场上除Microsoft Entra ID外，成熟的企业级目录和员工身份管理解决方案相对有限。
  • Okta增长的主要原因包括：
  1. 多云客户不希望完全依赖Microsoft体系。
  2. Okta拥有成熟的用户存储库和目录服务能力。
  3. Okta及Auth0可扩展至AI智能体和机器身份管理。
  4. 智能体推广需要IAM和PAM，相关项目难以暂停。
  • 与之相比，部分零信任项目可以延后或由其他平台型厂商替代，因此Okta与Zscaler虽同属垂直厂商，增长表现存在明显差异。

f) Fortinet的业务表现如何？

  • Fortinet业务也在增长。
  • 主要受益于：
  1. 防火墙更新换代。
  2. 面向AI工作负载的防火墙现代化。
  3. 混合云和数据本地化需求增加。
  4. 企业基础设施安全投入提升。

10. 终端设备与安全硬件需求

a) 企业终端设备数量为什么持续增加？

  • 客户通过终端开展的业务活动不断增加。
  • 主要增长来源包括：
  1. IoT设备。
  2. 工业传感器。
  3. 汽车及制造设备。
  4. 医疗扫描仪和生命科学设备。
  5. 能够持续传输数据的实体设备。
  • AI正在改变企业商业模式，使更多实体设备具备联网、分析和流式数据传输能力。
  • 物理AI和机器人尚未真正大规模启动，一旦进入快速发展阶段，终端设备数量可能出现爆发式增长。

b) 哪些安全硬件需求将增长？

  • 主要增长品类为防火墙和安全网关。
  • 主要驱动因素包括：
  1. AI训练和推理基础设施建设。
  2. 混合云环境增加。
  3. 主权云和数据本地化要求提升。
  4. AI应用产生大量东西向流量。

  • 在主要厂商中，Palo Alto和Fortinet拥有较完整的硬件或设备方案，因此受益更直接。
  • Cisco等传统网络安全厂商也具备相关硬件能力。

11. 前沿模型、AI攻击与安全工具有效性

a) 前沿大模型如何创造新的安全需求？

  • Anthropic、OpenAI及其他前沿模型正在识别更多代码、基础设施和应用漏洞。
  • AI模型发现漏洞的能力提升，会自然增加企业对以下产品的需求：
  1. 终端安全。
  2. 应用安全。
  3. 漏洞管理。
  4. 数据安全。
  5. 身份与访问管理。
  • CrowdStrike、Cloudflare等安全厂商将受益于漏洞发现数量和安全事件关注度的上升。

b) AI智能体大规模应用会带来哪些新风险？

  • 企业正在向智能体开放大量数据和系统权限。
  • 潜在风险包括：
  1. 智能体失控。
  2. 权限配置错误。
  3. 机器身份或API密钥被窃取。
  4. 智能体访问超出授权范围的数据。
  5. 自动化攻击快速扩散。
  • 一旦广泛使用的智能体产品出现漏洞，可能对大量企业产生系统性影响。

c) 现有安全工具是否足以防御AI带来的新型攻击？

  • 现有工具能够覆盖部分风险，但尚不足以防范所有新型威胁。
  • 平台化、统一数据、机器身份、IAM、PAM、零信任和SASE能够提高企业的基础防护能力。
  • 对于智能体失控等新问题，市场仍缺乏成熟的即插即用方案。
  • 企业未来可能需要：
  1. 快速识别智能体异常行为。
  2. 配置紧急停止开关。
  3. 支持人工及时介入。
  4. 对智能体执行持续监控和权限收回。
  • Okta、CrowdStrike和Palo Alto等厂商均在讨论相关能力，但现阶段仍需要咨询和实施合作伙伴针对客户环境进行定制。

d) AI安全市场未来将如何演进？

  • 威胁与防御能力将同步演进。
  • 当前工具可能无法完全防范未来出现的新威胁，但供应商会根据新攻击方式快速调整产品方向。
  • 随着AI生产用例增加，AI安全市场预计将在2027年和2028年继续保持高增长和快速变化。
