  1. 文章称英伟达董事会于11月11日接受黄仁勋辞去CEO等职务，CFO Colette Kress兼任临时CEO，Q3 FY2027指引营收1080亿美元、毛利率约74%。

  3. 360亿美元兜底在FY27剩余期间到期额为零，FY28起依次释放60亿、80亿、70亿、60亿和90亿美元，GB300六年平均保底价约2.35美元/卡时，远低于B300当前约5-7美元的市场价。

  5. 2790亿美元锁单中有920亿美元落在FY27剩余两个季度，季均460亿美元，约为单季营业成本的1.64倍，且Q2单季新增1600亿美元、主要与存储采购有关。

  7. Q2营收962.21亿美元环比增18%，但经营现金流从503.44亿美元降至240.77亿美元，DSO从45天拉长到60天，存货升至315.75亿美元。
  8. 作者建议关注承诺附注环比变化、拨备规模、DSO修复情况，以及SK海力士、美光长协条款与台积电月营收的变化。

摘要

  1. 换帅后首份季报为何应关注承诺而非业绩；
  2. 2790亿锁单与360亿兜底的期限与触发条件有何不同；
  3. 租金走软如何经融资与需求预测传导至毛利率和现金流；
  4. 哪些公司承接风险，应跟踪哪些指标。

英伟达的360亿美元算力云兜底近期没有现金到期，保底价远低于市价，作用主要是预警。真正的压力在2790亿美元上游锁单，其中920亿美元半年内到期。只要需求预测下调，拨备就会一次计入营业成本。

英伟达这个季度大概率还会交出一份营收超千亿美元的成绩单。但CEO突然离任后的第一份季报，市场真正该关心的不是营收超预期多少，而是两笔承诺。一笔是2790亿美元上游锁单，一笔是360亿美元算力云兜底。GPU租金已经开始松动，问题是哪一笔会先变成真金白银的损失。

一、季报的看点在两笔承诺

先看时间点。英伟达11月12日向SEC提交8-K：董事会于11月11日接受黄仁勋辞去总裁、CEO和董事职务，立即生效，CFO Colette Kress兼任临时CEO。截至10月25日的Q3 FY2027季报仍按原计划在美西时间11月17日下午1:20发布。指引营收1080亿美元，上下浮动2%，毛利率74%左右。

为什么说业绩本身不是重点？因为指引已经公开，市场对超预期的幅度也有共识，增量信息有限。真正的新信息是：新管理层要第一次对前任签下的承诺做会计判断。负责这件事的财务团队本身也是新的。前首席会计官5月4日卸任，接任的Scott Gawel来自英特尔，直接管存货减值和采购义务拨备；审计委员会7月刚扩容。新团队没有为过去的判断背书的包袱，在审计压力下，会计尺度只会更紧，不会更松。

再看两笔承诺本身。市场的直觉是360亿美元兜底更危险，因为它直接挂钩GPU租金。但Q2 10-Q承诺附注里的两张分年到期表（CFO评述中有相同表格）给出了相反的线索：

→ 360亿美元AI云协议在FY27剩余期间的到期额是零，FY28起才分年释放，依次为60亿、80亿、70亿、60亿、90亿美元。

→ 2790亿美元上游供应与产能承诺有920亿美元落在FY27剩余的两个季度，季均460亿美元；FY28和FY29分别再有870亿和880亿美元。前两年半合计2670亿美元，占95.7%。

拿营业成本做参照：Q2 GAAP营业成本240.79亿美元，按Q3指引倒推约281亿美元。也就是说，未来两个季度上游的季均提货额，是单季营业成本的1.64倍（下图）。

因此，"哪笔先爆"至少要拆成三个问题来回答：

→ 风险信号谁先出现？

→ 现金谁先流出？

→ 损失谁先进利润表？

本文的判断是：信号会先从360亿美元这边出现，现金和会计损失则会先落在2790亿美元上。

有两条口径需要先明确：

→ 2790亿美元不全是不可撤销的订单。10-Q写明，下达确定订单之前，部分协议可以取消、改期或调整，只是可能产生额外成本，公司没有披露这部分的比例。

→ 360亿美元不担保GPU残值。它和290亿美元自用研发云服务协议、1050亿美元SB Energy土地电力担保是分开列示的三个项目，不能合并计算。

二、360亿美元兜底：租金离保底价还远，近期不是风险源

要判断兜底什么时候会被触发，先得弄清楚它是怎么运作的。按10-Q附注的描述，结构分四步：

  1. AI云向英伟达采购数据中心基础设施，英伟达在前端确认销售收入。
  2. 英伟达同时承诺向这家AI云采购云服务，按MD&A的说法，期限通常为6年。
  3. 如果有第三方出价更高，AI云可以单方面停止向英伟达供应，转卖给第三方。
  4. 承诺余额随第三方使用或英伟达自用而递减；满足条件时，英伟达参与收入分成。

这个结构对英伟达不对称：租金高的时候，算力被拿去卖高价；租金低的时候，英伟达接盘。CoreWeave在2025年9月的8-K里披露过一个具体样本：其自有客户没有用满的剩余容量，由英伟达承购到2032年4月13日，前提是满足交付和服务可用性要求。

既然英伟达是最后接盘的人，兜底什么时候会被触发，就取决于保底价和市场价之间的距离。按第三方对合同结构的拆解估算，GB300六年平均保底价约2.35美元/卡时，同期五年期市场长约在4.50到4.60美元之间。再看几组现价：

→ Silicon Data的Neocloud B300指数，11月16日为7.65美元/卡时。

→ Spheron 11月16日的B300 Spot报价为5.84美元。

→ Shadeform以10月为口径的B300按需价，下限约4.70美元，中位数在7.60到7.90美元。

→ 长约更能说明问题：Avian 11月给出的B300整机报价，12个月约5.45美元，36个月约4.65美元。

把这几组数字放在一起，结论很清楚：租金还要再跌一半左右才碰得到保底线。所以，单靠价格下跌，兜底很难被触发，能触发它的是空置，具体有三种情况：

→ 卡租不出去；

→ 旧合同到期后续不上；

→ 设备交付后，客户迟迟不上量。

租金的变化其实是两个方向，近端在走强：Silicon Data的B200指数11月15日为6.87美元，一周上涨12.3%，11月14日还到过7.03美元；B300指数整个11月都在7.55到7.69美元之间。远端在走软：同一机构11月16日的H100曲线显示，即期3.08美元，六个月合约3.00美元，六个月后的隐含远期只有2.82美元，贴水约8.4%；B300三年期长约也比即期指数低约四成。

近端涨、远端跌，这个组合本身就说明了一件事：现在的算力仍然偏紧，但买家不愿意按现价锁定未来。所以，360亿美元兜底眼下最可能变化的是承接的算力时数，金额不会很快放大。FY28全年到期额只有60亿美元，如果全年均匀分布，季度平均约15亿美元。

在这种状态下，360亿美元兜底最先变化的是承接的算力时数，而实际到期流出的现金在短期内有限。具体金额取决于各合同的实际安排。

10月25日的报告中分析，Nvidia的兜底只管'建好了卖不掉'，管不了'没钱建'。这个判断放在本文的框架里依然成立。兜底能消化一时的空置，扛不住需求整体下台阶。

它眼下更主要的作用其实是融资增信。Lambda的9.26亿美元定期贷款获得穆迪Baa2投资级评级，利率只有SOFR加300个基点；据穆迪评级披露，承购方是英伟达。由此可以推出：360亿美元兜底首先是一个卖货工具，它让下游买家借得到便宜的钱，再用这笔钱买英伟达的卡。

三、2790亿美元锁单：需求预测一下调，拨备就进营业成本

如果兜底只是预警，那么压力在哪里？答案在上游，原因有三：规模、刚性和会计规则。

第一，规模涨得太快。英伟达历期10-Q和10-K显示，供应承诺的余额是这样涨上来的：

→ 2024年10月末为289亿美元；

→ 2026年1月末增至952亿美元；

→ 2026年4月末进一步升至1190亿美元；

→ 而到2026年7月末（Q2）已暴增至2790亿美元。

Q2单季新增1600亿美元，期末余额是存货315.75亿美元的8.84倍。CFO评述说，新增部分"主要与存储采购有关"；10-Q则写明，这些承诺主要用于存储和制造产能。

第二，刚性来自卖方。供应商的合同条款决定了英伟达有多大调整空间：

→ SK海力士3Q26财报确认，已与14家主要客户签订长期供应协议，期限通常5年，锁定了2027至2028年一半以上的产能。

→ 美光的战略客户协议属于照付不议性质，带价格上下限。

→ 存储一旦和GPU完成CoWoS封装，基本没法再拆出来另作他用。

→ SK海力士在F-1/A中把按客户需求集成逻辑功能的定制底座，列为HBM4E及之后的方向。

由此可以推出：卖方锁得越紧，英伟达调整的空间越小，风险就越完整地留在英伟达自己的账上。

第三，会计规则决定损失何时入账。很多人以为要等到2028年货到手、卖不出去，才会出现亏损，其实不是。按ASC 330，公司每个季度末都要拿"账面存货加不可撤销采购承诺"去对比"滚动需求预测"。超出的部分当季计提，全额计入营业成本。也就是说，引爆损失的不是租金，是一张需求预测表。

英伟达自己就有先例：

→ Q1 FY2026，因出口限制计提H20相关费用45亿美元，其中存货19亿、超额采购承诺26亿，营业利润率降到49.1%。

→ FY26全年，存货及采购义务拨备合计72亿美元。

→ 即便在Q2这样的景气高点，也计提了存货拨备7.84亿美元、超额采购义务2.01亿美元，合计9.85亿美元，公司披露的净影响约为毛利率0.8个百分点。

→ 截至7月26日，账上还挂着21.38亿美元超额采购义务负债。

现金流已经先给出了信号（下图）。Q2营收962.21亿美元，环比增长18%；经营现金流却从503.44亿美元降到240.77亿美元，自由现金流从485.54亿美元降到213.41亿美元。原因主要在两个科目：

→ 应收账款单季增加223.46亿美元，DSO从45天拉长到60天。CFO评述的解释是，为部分投资级客户的大型跨季度协议延长了账期。

→ 存货升至315.75亿美元，公司解释是为Q3推出Vera Rubin备货。

这两条解释单看都合理，但放在一起看，意思就不同了。连投资级大客户都需要用账期来换提货节奏，说明需求虽然在，付款能力已经开始跟不上提货节奏。这部分客户的信用风险不高，但会占用英伟达的现金，而且恰好叠加在920亿美元近端提货的同一个窗口里。

非投资级的二线算力云，走的是另一条传导路径：

  1. 租金走软；
  2. 偿债覆盖率吃紧；
  3. 融资成本上升；
  4. 提货放缓。

ACIE客群（AI云、工业与企业）Q2营收403.13亿美元，环比增长25%，占总营收41.9%，是增长最快、也最依赖外部融资的一块。缺乏高信用评级支持与电力资源的租客会最先收缩。一旦这部分需求回落，英伟达下调未来几个季度的出货预测，超额锁单拨备就会入账。

两边的损失量级差多少？下图给出了敏感度测算。以Q3营收指引中枢1080亿美元为分母，每10亿美元新增营业成本，大约压低毛利率93个基点：

→ 参照H20先例的采购承诺拨备：单季营业成本增加26亿美元，影响毛利率两个多百分点。

→ 锁单拨备（中等规模）：单季营业成本增加50亿美元，影响毛利率约460个基点。

→ 锁单拨备（较大规模）：单季营业成本增加100亿美元，影响毛利率约930个基点。

→ 兜底承接计入营业成本：单季营业成本增加5到10亿美元，影响毛利率几十到一百来个基点。

需要强调，这些拨备金额都是情景假设，不是预测。

四、投资含义：风险最后落在哪些公司

前面的分析如果成立，接下来要问的是：风险最后由谁承担？

英伟达：换帅季是一次性出清最顺的时点。新的会计负责人、审计师PwC、刚扩容的审计委员会，都有理由把尺度收紧。季报可能出现两种组合，含义相反：

→ 大额一次性拨备，同时承诺余额回落、DSO修复。这相当于提前排雷，估值压力未必更大。

→ 承诺继续上升，经营现金流继续落后于利润，却看不到拨备。这说明风险在往后推，更需要警惕。

还要注意，承诺余额下降本身不能说明问题，必须拆开看：是付款履约，还是取消或改期。

存储厂商：SK海力士和美光有长期协议和价格下限保护，短期利润相对稳。但保护的前提是对方履约。如果英伟达要求改期，谈判的焦点会落在预付款比例和价格区间上。所以季报之后，应当跟踪存储原厂的预付款和长协条款有没有变化，而不只是看单月价格。

台积电：CoWoS产能位于提货链最前端。如果真的发生改期，台积电的月营收和先进封装稼动率会比英伟达的利润表更早出现变化。

算力云：11月11日的报告认为，CoreWeave的风险已经从建设期资金短缺，转成"三十万张旧卡续租的久期错配"。本文的推论与此一致：兜底保护的是项目层现金流，旧卡续租断档时首先受冲击的是股东权益。有英伟达签名的项目债，和没有签名的散租资产，估值会继续拉开。

五、季报当晚和之后四个季度要看什么

判断是否成立，可以按先后顺序验证。

季报当晚，按优先级看四件事：

  1. 10-Q承诺附注的环比变化：2790亿美元是增是减；如果减少，拆开看履约、取消、改期各占多少。
  2. 存货拨备和超额采购义务计提是否分别明显高于Q2的7.84亿美元和2.01亿美元。
  3. DSO能否回到45天附近，延长账期的投资级协议规模有没有继续扩大，经营现金流和净利润的差距是否收窄。
  4. 360亿美元是否有新增签约，是否首次披露承接金额。新增签约本身就说明，需求更多要靠兜底来支撑。

之后四个季度，按顺序看三条线：

  1. H100六个月隐含远期的贴水，是否从11月16日的约8.4%扩大到10%以上；B300长约价格与即期指数之间的差距是否继续拉大。
  2. 存储原厂的长协条款有没有重谈；
  3. 台积电的月营收有没有下修。

只要其中两项同时出现不利变化，拨备入账的可能性就会明显上升。

以上内容不构成任何投资建议，请风险自担。
