味之素ABF膜产能、供需及竞争格局专家访谈纪要

1. ABF膜现有产能与生产模式

a) 味之素目前ABF膜的有效产能是多少？

  • 产能与产量口径
  1. 味之素通常以平方米统计ABF膜产能。
  2. 当前有效产能约为每月300万平方米，此前实际产出约为每月250万平方米，目前已基本提升至每月300万平方米，处于满产状态。
  3. 按当前月产量计算，年化产量约为3,600万平方米。
  4. 公司会持续优化现有产线，能够增加多少产量就尽量增加多少。
  • 产品规格
  1. ABF膜以卷状材料交付，平均幅宽约为0.5米。
  2. 常见规格为0.5米×50米或0.5米×100米，对应每卷约25平方米或50平方米。
  3. 不同载板厂商实际采用的幅宽可能有所差异。

b) 味之素采用怎样的生产模式？

  • 味之素自行生产树脂原液，将涂布环节委托给外部工厂。
  • 当前主要合作的涂布厂商有两家，分别为Zacros和有泽。
  • 现有7条涂布产线并非ABF专线，外包工厂还会生产其他产品，因此味之素能够获得的实际产能需要与合作方持续协商。
  • 由于采取委外模式，不能简单按照“总产能÷产线数量”测算单条产线产能，也不能据此线性推算新增3条产线的产能贡献。

2. 近期扩产计划与2028年新增产线

a) 明年产线数量及供给增量如何规划？

  • 产线数量
  1. 当前共有7条可用于ABF膜生产的产线。
  2. 明年计划增加至10条，即合作涂布厂商从现有产线中额外调配3条给味之素使用。
  3. 这3条产线属于合作方已有产线的调配，并不是真正意义上的新建产线。
  • 产能释放节奏
  1. 新增设备预计从明年1月开始逐步运行，但无法立即形成完整产能。
  2. 初步目标是到明年6—7月实现约10%的供给增量。
  3. 到明年年底，理想情况下供给增量可能达到20%，但仍取决于外包工厂协调、设备效率和产能爬坡情况。
  4. 目前披露的数字偏保守，实际效率可能更高，但现阶段无法作出保证。

b) 为什么产线从7条增加到10条，初期产能仅提升约10%？

  • 新增产线由外包工厂提供，对方还有自己的产品需要生产，无法立即将整条产线的全部产能交给味之素。
  • ABF膜生产需要逐步导入并爬坡，设备数量增加不代表有效产能能够同步增长。
  • 即使是现有7条产线，其可供味之素使用的产能也并非固定，仍可通过协调和效率提升继续增加。
  • 因此，新增3条产线更应理解为获得更多生产资源，而非直接带来约43%的产能增长。

c) 2028年真正的新建产线何时贡献产能？

  • 建设与认证进度
  1. 新建涂布线并非近期才启动，相关规划已于2024年完成，目前已经处于建设过程中。
  2. 从设备导入、线体建设到客户认证，整体周期约为4年。
  3. 预计2028年上半年向客户送样并开展验证，2028年下半年开始贡献有效产能。
  • 客户认证对投产进度的影响
  1. 正常情况下，新产线需要完成客户验证后才能正式量产。
  2. 如果届时ABF材料仍然高度紧缺，部分客户可能选择缩短或跳过部分认证环节，从而加快产能释放。
  3. 若供需相对缓和，客户则可能按正常流程完成验证后再导入量产。

d) 2028年新增产能可能达到什么规模？

  • 日本总部尚未披露具体新建产线数量，相关信息属于内部高度机密。
  • 新建产线可能成为ABF专线，与目前非专线的7条产线存在明显差异。
  • 若最终确定为专门生产ABF膜的产线，新增产能有可能接近当前产能水平，即整体产能较今年水平接近翻倍。
  • “接近翻倍”是以当前约300万平方米/月的产能为基准，并非以明年扩产后的水平为基准。
  • 最终能否按专线运营仍取决于商务谈判、客户保供要求及相关协议安排，因此目前只能视为潜在上限。

3. 产品结构与高端ABF膜紧缺原因

a) 味之素目前主要有哪些ABF膜型号？

  • 主要型号及应用
  1. GL107为目前最高端产品，主要应用于AI芯片，包括英伟达Rubin及AMD最新产品。
  2. GL102是当前使用范围最广、载板厂反馈较好的主力材料，应用于ASIC、服务器、GPU、车载和网络交换机等领域。
  3. T31主要用于CPU，属于基础需求和产能规划中的基本盘。
  4. GN、GZ、GX等系列相对较老，正在逐步被新型号替代。
  • 产线兼容性
  1. T31基本可以由所有涂布机生产。
  2. GL系列对设备能力的要求更高，部分涂布机能够生产，部分无法生产。
  3. 未来涂布线会尽量以具备GL107生产能力为目标，以适应AI需求增长。

b) 当前高端产品占比是多少？

  • 受访者表示，目前订单越来越集中于GL102和GL107两款最新型号，高端需求明显增长。
  • 按具体型号粗略估算：
  1. GL102占比约40%。
  2. GL107占比约25%—30%。
  3. 两者合计约65%—70%。
  • 访谈中亦提到，接近90%的订单正在向两个最新型号倾斜，可能与订单、新增需求或特定统计口径有关，与上述具体占比口径存在一定差异。
  • 年初GL102占比更高，GL107占比较低；随着AI产品导入，GL107占比正逐步提升。
  • 明年预计GL102和GL107同步增长，老型号占比继续下降。

c) 为什么GL107会出现明显紧缺？

  • 旧版本GL107存在量产障碍
  1. GL107有新旧两个版本。
  2. 旧版本量产性较差，在良率、稳定性和生产难度方面存在问题。
  3. 该旧版本已经通过英伟达认证，英伟达相关产品全部使用旧版本GL107。
  4. 由于产品已经进入量产准备阶段，现阶段难以直接切换至味之素改良后的GL107版本。
  • 短期供给受限
  1. 旧版本生产难度较高，限制了有效供给释放。
  2. AI产品需求快速增长，进一步放大了供需矛盾。
  3. 只有待旧版本逐步被改良版本替代后，GL107产能才有望充分释放。
  4. 除旧版GL107外，其他型号的生产良率总体差异不大，并非所有高端型号都存在明显良率问题。

d) 高端ABF材料需求增长为何会显著放大总用量？

  • 高端AI产品不仅芯片数量增加，其载板尺寸和build-up层数也在提升。
  • 因此，一颗高端AI芯片增加所带来的ABF膜需求，明显高于一颗普通CPU。
  • 高端产品需求增长不能简单按照芯片颗数测算，还需同时考虑载板面积和ABF层数增加。
  • 受访者判断，高端ABF载板及高端ABF膜客观上确实存在紧缺。

e) 高端ABF紧缺是单一材料问题吗？

  • 当前紧缺是全产业链问题，并非仅由ABF膜供应不足造成。
  • 主要瓶颈包括：
  1. ABF膜材料供给不足。
  2. 载板厂自身产线和设备能力不足。
  3. 基板等其他上游材料存在瓶颈。
  4. 扩产所需激光钻孔机等关键设备紧缺。
  • 因此，即使ABF膜供给增加，若载板厂设备、基板或其他环节未同步扩张，最终高端载板产量仍可能受限。

4. 市场需求、订单真实性与行业供需判断

a) 当前ABF膜产能利用率和订单情况如何？

  • 当前约300万平方米/月的产能已基本开满。
  • 出货量没有超过实际产能，但客户订单量一度远超产能，部分未交订单持续数月。
  • 客户会同时追问数月前订单和近期紧急订单，导致味之素必须通过配额机制协调交付。
  • 当前标准交期已经基本恢复至8—10周，市场催货情况较高峰期有所缓和。

b) 为什么客户订单会远高于实际需求？

  • 恐慌性下单与备库
  1. 此前市场担忧ABF膜持续紧缺，下游载板厂出现恐慌性下单。
  2. 部分客户希望提前建立库存，以保障自身产品未来能够顺利生产和销售。
  3. 部分厂商可能通过制造材料紧缺预期，推动载板价格上涨。
  4. 因此，订单量并不完全等同于真实终端消耗量。
  • 不同客户差异明显
  1. 大型长期合作客户通常能够获得相对充足的配额。
  2. 国内部分新进入或规模较小的载板厂确实缺货，原因是历史用量较少、配额不足，同时还存在NPI和备库需求。
  3. 部分大厂虽然对外表示缺膜，但自身产能利用率未必很高，其短缺程度需要结合实际稼动率判断。

c) 载板厂给出的明年需求指引是否可信？

  • 多数载板厂给出的需求增长较为激进，部分提出翻倍、增长3倍甚至4倍。
  • 受访者认为，这些数字更多是提前锁定资源、向味之素释放需求信号，并不等同于真实订单。
  • 判断需求真实性的关键，是观察载板厂实际采购了多少设备、建设了多少条生产线。
  • 很多载板厂现有及规划设备并不足以支持其宣称的需求增幅。
  • 随着前期备库逐步完成，当前市场已出现放缓迹象，持续催货的情况有所减少。
  • 受访者认为，全行业较为合理的实际需求增长率约为20%，明显低于部分客户提出的数倍增长诉求。

d) 明年是否仍会出现明显短缺？

  • 高端ABF膜供应偏紧是客观事实，尤其是GL107及AI相关产品。
  • 但客户申报需求中存在较大水分，不能直接用申报需求与新增产能比较得出巨大缺口。
  • 明年味之素供给预计逐步增加10%—20%，行业真实需求可能增长约20%，整体供需可能维持偏紧但逐步趋于平衡。
  • 高端型号仍可能结构性紧缺，尤其取决于旧版GL107的替代速度和AI需求强度。
  • 具体行业缺口及持续时间尚无明确数据，日本总部预计将在年底至明年初分享调查结果，更完整的数据可能在明年3—4月形成。

5. 配额制度与主要客户供货情况

a) 味之素的配额制度如何运作？

  • 配额直接分配给ABF载板厂，与英伟达、华为等终端芯片厂商不存在直接配额关系。
  • 曾有终端厂商要求味之素按终端项目分配材料，但被味之素拒绝。
  • 若按终端客户分配，将显著增加生产和经营复杂度，也可能因差异化供应得罪其他客户。
  • 味之素原则上尽可能平均分配，但会考虑客户优先级：
  1. 长期合作客户优先。
  2. 历史用量较大的客户优先。
  3. 配额主要依据过去3个月的实际出货量动态调整。
  • 市场关于味之素将减少对部分中国芯片厂商配额的说法不准确，因为配额对象本身是载板厂，而非芯片厂商。

b) 欣兴目前获得多少配额？

  • 欣兴目前每月获得约70万—80万平方米ABF膜，为单一客户中最高水平。
  • 该数据涵盖欣兴台湾3个工厂和苏州1个工厂。
  • 由于味之素全球市场份额约95%，该配额基本可视为欣兴主要ABF膜供应量。
  • 欣兴申报需求若以1计算，味之素实际供应约0.9，已经属于最高配给水平，但仍无法完全满足其申报需求。
  • 欣兴给出的明年需求指引较为激进：
  1. 一种口径是到明年年底较当前接近翻倍。
  2. 访谈中也出现需求达到当前约3倍的表述。
  3. 由于不同阶段、不同统计口径存在差异，应将其理解为约2—3倍的申报需求，而非确定订单。
  • 受访者认为，这类需求指引存在明显预留和放大成分。

c) 景硕、南亚及日韩客户的供应规模如何？

  • 景硕当前月度供应量约30多万平方米，不到40万平方米；其申报需求约为当前的1.5倍。
  • 南亚当前月度供应量约20多万平方米；其提出明年需求翻倍，但受访者认为实际可能达不到。
  • 日本和韩国客户合计约占味之素ABF膜出货量的40%。
  • 日本及韩国具体客户数据由当地团队掌握，受访者无法提供更详细拆分。

d) 奥特斯、深南和兴森的需求情况如何？

  • 奥特斯
  1. 当前供应规模约20多万平方米，近期可能增至30万平方米。
  2. 明年同期申报需求可能达到50万—60万平方米，接近翻倍。
  • 深南电路
  1. 过去月均需求约2万平方米。
  2. 今年5—6月开始，需求快速提升至每月5万—6万平方米。
  3. 味之素当前实际供应约3万多平方米，深南基本有多少货就提多少货。
  4. 深南预计明年需求达到12万—15万平方米，约为当前获配量的4倍。
  5. 相比其他国内客户，深南需求确定性相对更高。
  • 兴森科技
  1. 过去月度需求约1万平方米，近期获配约2万多平方米。
  2. 兴森目前提货速度较慢，存在库存或项目进度不及预期的可能。
  3. 兴森申报明年需求约6万—7万平方米，约为当前水平的3倍。
  4. 由于当前尚未充分提货，其需求真实性低于深南。

e) 如何将ABF膜面积换算为载板产能？

  • 一张标准panel尺寸约为510毫米×515毫米，可粗略按0.3平方米计算。
  • 以普通CPU载板约10层为例，扣除2层core后，上下各4层，共使用约8张ABF膜。
  • 每张panel对应ABF膜用量可粗略按0.3平方米×8计算，即约2.4—2.5平方米。
  • 按欣兴每月70万平方米供应量测算，约对应28万张panel。
  • 实际用量仍取决于产品尺寸、build-up层数及载板厂加工损耗，具体损耗数据主要由载板厂掌握。

6. 价格策略与议价机制

a) 味之素今年是否上调过ABF膜价格？

  • 味之素今年没有涨价，第四季度剩余时间也没有涨价计划。
  • 受访者强调，味之素历史上并未因短缺主动涨价。
  • 部分载板厂以ABF膜涨价为理由上调载板价格，属于载板厂自身行为，并非味之素上调材料价格导致。

b) 不同型号的价格区间是多少？

  • ABF膜价格大致为几十美元。
  • 高端型号价格可达到40多美元，低端型号约20美元或低于20美元。
  • 最高端型号与最低端型号的价格可相差约1倍。
  • GL107价格较GL102高约30%，可粗略理解为GL107约40美元、GL102约30美元，具体价格仍因规格和客户用量不同而变化。

c) 在供不应求情况下，味之素为什么不涨价？

  • 味之素维持长期客户合作和稳定定价，不希望利用短期供需紧张主动涨价。
  • 即使需求持续高于产能，公司也倾向于通过配额解决，而非通过涨价调节需求。
  • 年底价格谈判通常由客户发起，客户仍会提出降价要求。
  • 在供给紧张情况下，味之素可能以“不再接受更多订单”或“停止讨论降价”作为谈判回应，但不意味着主动涨价。

d) 味之素采用怎样的降价和议价机制？

  • 公司实行阶梯报价，用量越大，客户获得的价格越低。
  • 价格调整以过去3个月的平均用量为基础，并按单个型号、模具和宽幅分别统计。
  • 客户达到相应用量标准后，味之素会主动降价，不必等到年度议价。
  • 价格一旦下降，通常不会再恢复至原有水平。
  • 集中年度议价一般从12月左右开始，主要由客户提出进一步降价要求。

7. 国内载板厂客户结构与能力判断

a) 深南电路目前的客户结构如何？

  • 深南客户群较为分散，并积极拓展海外高端客户。
  • 海外客户包括Astera Labs等美系厂商。
  • Intel曾与深南接洽，但主要希望深南承接低阶产品，深南对此兴趣不高，更希望发展高阶AI载板业务。
  • 国内客户方面，深南目前未承接海思业务，主要承接海光业务。
  • 海光对深南支持力度较大，并希望味之素为深南增加ABF膜供应。

b) 味之素如何评价深南的载板能力？

  • 味之素日本团队此前对深南能力评价相对保守，但近期实地考察后明显改善。
  • 深南的优势主要体现在：
  1. 产线自动化水平较高。
  2. 各分站的管控体系较完善。
  3. 生产管理标准和现场操作较规范。
  4. 整体ABF载板产线建设情况好于此前预期。
  • 博通近期也对深南和兴森进行了现场审查，但访谈时尚不清楚最终审查结果。

c) 兴森科技业务放量较慢的原因是什么？

  • 兴森主要客户为华为，但相关业务尚未明显起量。
  • 放量受双方因素影响：
  1. 华为是否有足够芯片需求支持大规模载板订单仍存在不确定性。
  2. 兴森自身认证进展、产线能力及量产爬坡速度偏慢。
  • 味之素认为，兴森与深南相比，在自动化、现场管理和工厂管控方面存在明显差距。
  • 兴森早期从奥特斯引进了较多有经验的人才，最初FCBGA团队经验较强，但后续人才流失严重，反映出内部管理和人才使用存在问题。

d) 兴森目前ABF载板产能如何？

  • 兴森目前实际总产能约3万—4万平方米/月。
  • 珠海原有中试线月产能约2万平方米，后续关闭并将部分设备搬至广州。
  • 广州基地原规划产能约12万平方米/月，但部分设备延期、暂停或取消。
  • 若市场需求明显转好、现有产线顺利跑通，兴森仍具备重新启动设备投入和快速拉升产能的可能。

e) 深南为何对华为和Intel等客户较为谨慎？

  • 部分大型fabless客户会深度介入载板厂生产管理，要求监控大量流程，甚至派驻人员进厂。
  • 深南不希望终端客户过多干预其内部运营，因此对相关合作较为谨慎。
  • 深南更倾向于选择能够承接高端产品、同时给予工厂一定自主权的客户。

8. 全球竞争格局与国产替代进展

a) 味之素在全球ABF膜市场的份额是多少？

  • 味之素全球ABF膜市场份额约为95%，处于绝对主导地位。
  • 大部分ABF载板厂难以从其他供应商获得同等性能和稳定性的材料，因此对味之素依赖度较高。

b) 目前最有可能成为第二供应商的是谁？

  • 受访者认为，目前真正具备第二供应商能力的主要是积水。
  • 积水现有ABF类材料产能据称约为每月40万平方米，与味之素约300万平方米/月的规模仍有较大差距。

c) 国内ABF膜厂商的替代能力如何？

  • 国内部分厂商的关键原材料仍需从日本进口，尚未实现完整国产化。
  • 现阶段主要问题包括：
  1. 原材料自主化程度不足。
  2. 产品稳定性不理想。
  3. 高阶产品认证和量产经验不足。
  • 国内厂商可能率先进入低端市场，替代部分旧型号产品，但短期难以进入GL102、GL107等高阶产品市场。
  • 在国内相关厂商中，受访者认为生益的进展相对较好。
  • 华正、纽菲斯、红昌等厂商距离高端产品替代仍有较长距离。
