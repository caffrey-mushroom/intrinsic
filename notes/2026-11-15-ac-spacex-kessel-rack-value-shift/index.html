原标题：SpaceX“Kessel”机柜拆解：只买芯片跳过L6板卡，砍掉铜缆的钱流向了谁？

#pcb #datacenter #materials

AceCamp · 2026-11-15 16:37 · article 70569228

核心摘要

  1. 据SemiAnalysis披露，SpaceX正开发代号Kessel的定制Vera Rubin NVL72机柜，只向英伟达采购芯片封装、跳过L6计算板，并用一块84层M10无源中板取代柜内NVLink铜缆卡匣背板。
  2. 文章认为Kessel的本质是采购权转移：VR200 NVL72整柜估算约780.3万美元、接近GB300的两倍，单柜PCB价值量从3.51万美元升至11.67万美元，但PCB仅占整柜约1.5%。
  3. SpaceX计划2026年新增约66万颗GPU（总规模近144万颗），并有约400亿美元GPU融资租赁承诺，对应九千柜以上，示范效应可能增强其他云厂商对英伟达的谈判筹码。
  4. “156层降到84层”的说法不成立，Kyber是两块78层中板，Kessel单板反而多6层；长走线和NVLink 6双向收发使插损预算仅剩40~50英寸，需要M10覆铜板加HVLP5铜箔。
  5. 良率推演显示：单芯板良率99%时84层单板叠层良率约65.6%，两块78层同时合格约45.7%；72卡中板5184条通道在单通道合格率99.99%下整板直通率约59.5%，144卡则降至35.5%。
  6. 受损方是L6板卡代工（纬创、工业富联/鸿海）、整机OEM（戴尔、超微）及沃尔核材、神宇、兆龙等高速铜缆厂；安费诺、立讯丢线匣但保住224G/448G板对板连接器。
  7. PCB受益排序首推沪电股份（英伟达M10联合测试厂、昆山产能利用率超99%），其次是TTM、华通、深南电路和胜宏科技；M10覆铜板认证从M9时代仅台光一家扩至三家，覆铜板议价能力被稀释。
  8. 真正有定价权的是扩产最慢的上游：日东纺T布/Q布订单排到2027年二季度，三井金属投1900亿日元新建铜箔基地要到2031年才投产，国内对应菲利华和德福科技。
  9. 风险在于M10覆铜板和配套PCB要到2027年下半年才能规模量产，轨道版还面临辐射散热和HBM辐照错误等约束，短期需求主力更可能是地面集群。

摘要

  1. SpaceX自研机柜如何改变AI服务器的采购边界；
  2. 84层中板在良率与成本上能否成立；
  3. 价值链中受损与受益环节如何划分及如何跟踪验证。

Kessel改的不只是层数，更重要的是谁来决定买什么。SpaceX向英伟达只买芯片封装，自己负责板卡、线缆和外围器件的选型。这样，原本属于板卡代工和铜缆的利润被挤出来，部分转给一块84层M10中板。本文想回答的是：这部分利润最后流向了谁？

一、Kessel改了什么

11月11日，SemiAnalysis披露SpaceX正在开发一款定制的Vera Rubin NVL72机柜，代号“Kessel”。Tom's Hardware和Data Center Dynamics随后跟进报道。乍看这只是一个太空算力项目，但它触及一个更大的问题：一台AI机柜里，GPU以外的利润由谁来分？如果最大的买家开始自己定义这部分，原本按英伟达路线图排好的供应链格局会不会松动？

据报道，Kessel同时面向地面的Grok集群和近地轨道数据中心。它的拓扑和标准NVL72一致：72个Rubin GPU封装、36颗Vera CPU、18个计算托盘、9个NVLink交换托盘。变化集中在两处。

→ 互联方式变了。计算托盘和交换托盘围着一块84层M10无源中板背靠背插接，取代了英伟达硬件指南中的“NVLink无源铜缆卡匣背板”。

→ 采购边界变了。SpaceX只向英伟达买芯片封装，跳过L6计算板，PCB、内存、连接器和供电都由自己选型。

第一处改动是技术上的手段，第二处才是商业上的目的。判断谁受益、谁受损，要先看第二处。

为什么是现在

原因是这笔账现在划算了。按行业整柜拆解估算，VR200 NVL72整柜约780.3万美元，比GB300的约400万美元接近翻倍；单柜PCB价值量从3.51万美元增加到11.67万美元。这组数字是估算，不是成交价，也不代表Kessel的实际成本。不过方向很清楚：机柜里非GPU部分的金额已经大到值得买家自己管理。

推理过程如下：

  1. 非GPU部分的价值量在快速上升。
  2. 这部分原本由英伟达及其板卡体系统一定义和打包。
  3. 对采购量足够大的客户来说，自己选型节省的钱，已经超过了自建工程团队的成本。
  4. 因此，最大的买家会把采购延伸到板卡这一层。

所以，Kessel首先是采购权的转移，84层板只是实现它的工程载体。

规模是否撑得起

SpaceX的规模撑得起。Tom's Hardware报道，SpaceX计划在2026年新增约66万颗GPU，总规模接近144万颗。SpaceX在10月下旬披露了约400亿美元的GPU融资租赁承诺，交易对手是Apollo管理的实体。按每柜72颗GPU粗算，66万颗对应九千柜以上。即使只有一部分地面集群改用Kessel，被绕开的L6板卡和柜内铜缆也是一笔可观的金额。

更值得关注的是示范效应。一旦一家超大买家证明“只买芯片封装”可行，其他有自研能力的云厂商在和英伟达谈判时也多了筹码。这样一来，影响就不只局限于SpaceX一家。

证据边界

目前Kessel的工程细节全部来自SemiAnalysis这一条信息链，各家媒体是转述，不算独立确认，也未见SpaceX或英伟达的官方确认。下文涉及Kessel规格的内容都按媒体报道处理，良率和成本只做敏感性推演。

二、“156层降到84层”不能直接比

媒体最常引用的数字是层数从156降到84，降幅46%。这个比较不成立，因为156层不是一张板。SemiAnalysis在GTC 2026的Kyber拆解显示，Kyber有两块中板。另据其他公开资料，单块中板为78层，两块合计才是156层。按单张物理板比较，Kessel的84层比Kyber单板还多6层，而它承载的GPU封装只有Kyber的一半。

这说明，Kessel的价值不在于“更简单”，而在于“用一块更难的板换掉了别的东西”。

为什么封装更少，层数反而更多

原因在于结构和信号。

→ 走线变长。Kyber的计算刀片竖插、交换刀片横插，两者90度正交交叉，每个交叉点上的走线都很短。Kessel保留了水平托盘背靠背的形态，跨托盘走线明显更长。

→ 信号要求更严。NVLink 6在同一对线上同时双向收发，接收端要从信号中减掉自己发出的回波，过孔残桩的任何反射都会造成干扰。

→ 损耗预算很紧。按测算，在50GHz附近，即便用顶级板材，插损也在每英寸0.5dB左右；扣除封装和连接器之后，纯无源走线只剩40到50英寸的预算。

走线长、预算紧，只能靠更好的材料换出插损空间，所以要用M10覆铜板加HVLP5铜箔。也就是说，Kessel的方案会直接增加对高端材料的需求。这一点是后文判断上游受益的基础。

84层不是新档位

层数本身并不新鲜。7月的产业调研显示，正交背板当时有78、84、94、104、112层多条路线在并行验证，试产良率普遍低于五成。84层是供应链里已经打过样的档位，SpaceX是选了一个现成的点，而不是从零开始。

工艺路线决定谁能入场

此前的产业调研还显示，Kyber的78层板由三块26层子板通过铜浆烧结连接，并不是一次压合完成的。按测算，这类超高层板厚度在8到10毫米。厚度接近一次压合的工艺极限以后，“一次压合84层”和“多块子板Z向互联”就成了两套完全不同的产线配方，决定了哪些板厂有资格参与。

目前公开信息没有说明Kessel走哪条路线。判断供应商名单之前，必须先回答这个问题。

三、良率和成本：省下的钱够不够买M10

一块更难做的板能否成立，要看两笔账：良率和成本。

良率账：分两层看

第一层是叠层良率，按单芯板良率的乘积估算。具体而言，在单芯板综合良率为99%的假设下，84层单板（42对芯板）的叠层良率约65.6%，而两块78层板同时合格的概率约45.7%；若单芯板综合良率降至工程打样水平（98%），84层单板的叠层良率将降至约42.8%，而两块78层板同时合格的概率则会骤降至约20.7%。

第二层是通道良率。按72卡中板至少5,184条高速通道建模，在单通道合格率99.99%的假设下，整板直通率约59.5%；换成144卡的10,368条通道，就降到35.5%。

两层合起来看，在这组参数模型下，良率改善更多来自互联域保持在72卡，层数的变化是这个选择带来的结果。这个判断对参数敏感：如果单芯板良率或单通道合格率的假设变了，两种因素的贡献比例也会变化。以上都是参数推演，不是Kessel的实测良率。

和Kyber延期的关系

这个结论和Kyber遇到的问题是对应的。据报道，Kyber推迟到2028年，直接原因是78层正交背板的可制造性；英伟达对此回应称“Our roadmap is intact”。英伟达曾经的替代方案是NVL72x2背靠背机架，据报道被云厂商以运维负担为由否决。

Kessel给出了另一种解法：自用客户自己承担运维，把互联域缩回72卡，用一块板实现背靠背。云厂商不愿意承担的运维负担，SpaceX作为自用客户愿意承担，这是它能走这条路的前提。

成本账：只能判断方向

目前没有任何Kessel报价，只能判断方向。

→ 省掉的部分：柜内铜缆卡匣、装配工时，以及英伟达L6板卡的外围溢价。

→ 新增的部分：一块含废品摊销的84层M10大板，外加几百个高密度板对板连接器。

按前述整柜估算，PCB只占约1.5%（11.67万÷780.3万）。即使中板成本翻几倍，对整柜价格的影响也有限。这是SpaceX敢于押注的原因：用一个占比很小但涨得很快的部件，换取对供应链的控制权。

四、谁丢份额，谁赚钱

采购边界变了，利润就会重新分配。判断方法是看每个环节在Kessel方案里还剩多少附加值。

受损方：被绕开的环节

→ L6计算板代工受影响最直接，主要是纬创和工业富联/鸿海。SpaceX的算力扩张不再自动流向英伟达指定的板卡产线。7月台媒传出鸿海拿到520亿美元SpaceX订单，但已被马斯克本人否认。

→ 整机OEM其次。戴尔和超微在Colossus时代是主要供应商，Kessel意味着SpaceX从买整机转向自研机柜。

铜连接：内部分化

→ 沃尔核材、神宇股份、兆龙互连这类高速裸线厂受影响最大，柜内Scale-up线材在Kessel方案里可能归零。

→ 安费诺和立讯精密丢掉线匣，但保住了224G/448G板对板连接器，一边受损一边受益。

→ 华丰科技主要受益于国内正交背板的同向演进，进入SpaceX体系的门槛较高。

中间地带：有订单，但附加值变薄

纬颖和广达这类做云厂商定制机柜的厂商，本来就习惯按客户图纸做去品牌化组装。如果承接地面版Kessel，它们能赚到组装费，但拿不到原先L6板卡那一层毛利。ODM阵营的分化不在于有没有订单，而在于订单里还剩多少附加值。

受益方：PCB厂看现成产能

PCB受益方的排序标准是：谁有现成的高多层板产能。理由是英伟达对高多层板先认证、后分单，分单看谁能在窗口期交出数量。2026年才启动的扩产，要到2028年才能同时形成产能和折旧，赶不上这一轮。以下排序是基于这一逻辑的推演，不代表Kessel已确认的定点或采购合同。

→ 沪电股份排在第一。供应链信息显示，它是英伟达联合测试M10的PCB厂，也是78层M9背板的主力供应商；昆山基地3月末产能利用率在99%以上。

→ TTM的看点在北美航天与国防资质，符合轨道版对ITAR合规和本土供应的要求。但它10月宣布的4亿美元追加投资投向中国四座工厂和马来西亚槟城工厂，服务对象是AI数据中心与网络客户，不能用来证明北美本土产能增加。

→ 华通是SpaceX卫星板的核心供应商，客户关系最近，但在84层背板上没有公开实绩。

→ 深南电路受益于高端产能紧张带来的外溢。

→ 胜宏科技有100层以上的能力，扩产也早已启动：2025年三季度末在建工程增至约35.5亿元，越南、泰国项目同步推进。但这些产能主要面向HDI和计算板，能否转做84层M10中板，要看具体工艺、客户认证和量产良率。在拿到84层中板的公开实绩之前，它在Kessel上排在沪电之后。

SpaceX自己会不会做

PCB Directory报道，SpaceX在德州的PCB制造基地将成为美国最大的PCB工厂，招聘信息也显示它在扩充SMT和PCBA产线。卫星板、电源板和控制板自制的可能性不小。但84层M10中板需要的超高层压合、背钻和对位能力，和贴片组装完全不同，短期内自制不现实。

比较合理的推演是：中板外采，托盘级板卡和组装逐步转为自制。如果成立，外部板厂从Kessel得到的增量会集中在最难做的那块板上，而不会覆盖整柜。

覆铜板：受益，但议价能力被稀释

覆铜板这一环有一个相反方向的信号。供应链信息显示，英伟达M9世代只认证了台光电一家，M10测试一下扩大到三家：台光电、一家台湾厂商、一家大陆厂商。这家大陆厂商没有公开点名，市场推测是生益科技；南亚新材也在投资者互动中表示，正在推进M10材料的认证与测试。

台光电董事长10月在TPCA Show上确认，M10计划在2026年底到2027年初推出。产业调研显示，台燿的前三大客户是Google、Amazon和SpaceX。

表面上看，这些材料厂都会受益。但判断议价能力要看两个变化：

→ 供应商从一家增加到三家，英伟达的选择更多。

→ Kessel让SpaceX拿到了料号指定权，又多出一个自主选型的大买家。

两个变化叠加，覆铜板厂的议价能力其实在被稀释。目前的格局是：高阶覆铜板长约价格的上限由英伟达每半年确定一次，预付款流向上游设备和铜箔厂，覆铜板厂自己靠寄售和账期垫资。Kessel只会强化这个格局。

真正有定价权的：扩产最慢的上游

沿着产业链往上推，产能补得最慢的环节议价能力最强。

→ 日东纺的T布和Q布订单已经排到2027年二季度。

→ 三井金属11月11日宣布投资1,900亿日元，在马来西亚新建铜箔基地，计划2031年4月起分阶段投产。新产能要到2031年才开始释放，说明现有缺口短期内补不上。

→ 国内对应的是菲利华（石英纤维与Q布）和德福科技。德福科技的HVLP5已完成样品认证，正在推进客户导入。

这里有两个变量会压低需求的放大倍数。一是英伟达和沪电测试M10时，也在评估用Low-Dk2玻纤布替代难钻孔的Q布。二是英伟达在Rubin Ultra交换托盘上另外测试无玻纤的碳氢覆铜板，这条路线独立于沪电的M10测试。所以，Q布需求不能线性外推。

五、主要风险和跟踪信号

前文的判断的前提：Kessel按报道的规格落地，并且按预期的节奏上量。风险主要来自这两点。

时间窗口很紧

供应链信息预计，M10覆铜板和配套PCB要到2027年下半年才能规模量产。首颗Starmind AI1卫星的目标发射时间是2027年四季度，另有报道称可能提前到三季度。材料定型、84层良率爬坡和宇航级热真空测试之间几乎没有缓冲。更长期看，CPO一旦进入Scale-up网络，超高层铜背板的生命周期可能被缩短。

轨道版有柜外的硬约束

按测算，175千瓦算力在真空中只能靠辐射板散热，面板温度在理想工况下也接近49摄氏度，留给HBM4的温度余量很小。参考谷歌Project Suncatcher的质子辐照测试数据外推，大量HBM在近地轨道上每天可能出现几次不可纠正的内存错误。

这些问题不改变对中板的判断，但会影响轨道版的上量节奏。短期内，Kessel的需求主力更可能是地面集群，而不是卫星。

五个跟踪信号

→ SemiAnalysis原文或其他独立信源能否证实84层M10的规格和供应商名单。这是整个判断的基础。

→ 台光电M10能否按2026年底到2027年初的节奏上市。
