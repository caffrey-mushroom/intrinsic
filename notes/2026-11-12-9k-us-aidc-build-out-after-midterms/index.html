a) 美国AIDC项目最早何时可能受到实质性影响？

  • 新政策从宣布到真正影响建设仍需经历法律批准、法规制定和执行流程，因此不会立即反映在项目交付上。

b) 哪些因素会最先改变项目进度？

  • 最需要优先关注的是地方分区决定和公用事业审批。

  • 公用事业审批同样关键，即使建筑已经完工，如果无法获得电力，相关容量仍不能投产。
  • 州级许可政策，特别是环境政策，也可能造成延期，但通常需要更长时间才会显现。
  • 联邦政策同样重要，但相较于地方审批和公用事业决定，其影响通常不会最先出现。

  • 但数据中心项目能够带来大量资本投入、建筑就业和地方税收，经济现实会推动政府与开发商进行协商。

  1. 承担更多电网升级费用；
  2. 降低用水和环境影响；

  4. 避免将基础设施成本转嫁给普通电力用户；

4. 五大厂商的地域及项目风险

a) 哪些超大规模云服务商最容易受到政策变化影响？

  • 风险取决于项目所在州及项目阶段，而不能仅按公司整体判断。
  • AWS：
  1. 俄亥俄州哥伦布周边投资规模较大，当地社区反对声音有所增加；
  2. 得克萨斯州同样是重要市场，但当地在选举前已经存在许可限制；
  3. 更显著的风险预计于2028年而非2027年出现。
  • Oracle：
  1. 对得克萨斯州和新墨西哥州大型开发项目敞口较大；
  2. 当地限制可能影响其扩张进度。
  • Microsoft：
  1. 在佐治亚州和密歇根州有较多开发项目；
  2. 同时对新云服务商的外部GPU产能依赖较高。
  • Google：
  1. 在多个可能受影响州均有项目；
  2. 风险相对分散。
  • Meta：
  1. 项目更多集中在其他市场；
  2. 地域风险敞口与其他厂商有所不同。
  • 当前更应关注尚未获得许可或确定电力保障的项目，而不是笼统地下调某一家公司的全部容量预测。

b) AWS在2028年是否面临显著延期风险？

  • AWS在2028年的风险明显高于2027年。
  • 2027年支撑增长的大部分基础设施已进入建设或后期开发阶段，项目成熟度较高。
  • 2028年容量更多依赖：
  1. 尚处于较早期阶段的项目；
  2. 等待许可审批的项目；
  3. 等待电力接入的项目；
  4. 大型园区后续扩建阶段。
  • 俄亥俄州等市场的社区反对、电力承诺和后续阶段能否独立推进，将决定实际受影响的吉瓦规模。

c) AWS在2027年和2028年超过40%的收入增长是否有足够容量支持？

  • AWS收入增长与数据中心建设进度并不会完全同步。
  • 40%以上的增长主要由以下因素支持：
  1. 已经投入运营的容量；
  2. 未来两年预计上线的新增容量；
  3. 现有云服务需求增长；
  4. 新AI基础设施投产。
  • 支撑2027年增长的大部分基础设施预计已经在建，甚至进入后期开发阶段。
  • 支撑2028年增长的项目成熟度相对较低，更依赖建设执行、许可审批和电力交付。
  • AWS未公开披露具体有多少吉瓦在建、多少仍在等待审批，因此无法进行精确拆分。
  • 若公用事业服务或许可审批延迟，2028年增长目标面临的执行风险将高于2027年。

5. 表后供电与现场发电方案

a) 公用事业供电受限后，是否会有更多项目转向表后供电？

  • 表后供电和现场发电的关注度将继续提升，但这一趋势并非由选举单独驱动。
  • 核心原因是公用事业基础设施难以跟上数据中心用电需求，相关趋势在过去近两年已经出现。
  • 开发商主要评估：
  1. 天然气发动机；
  2. 燃料电池；
  3. 电池储能；
  4. 多种技术组合。
  • 现场供电可能用于在等待公用事业供电期间支持项目初始阶段提前投运。
  • 但现场供电仍需解决天然气供应、空气排放许可、设备采购、冗余架构和调试等问题，不是可以自动落地的替代方案。
  • 在环境政策趋严的地区，现场发电的审批甚至可能比公用事业供电更困难。

b) 燃料电池是否会因民主党执政而获得更高优先级？

  • 燃料电池的吸引力可能上升，主要优势包括：
  1. 本地空气污染物排放低于天然气发动机和涡轮机；
  2. 耗水量相对较低；
  3. 支持模块化部署；
  4. 可以按项目阶段逐步增加容量。
  • Bloom Energy的固体氧化物燃料电池系统是典型方案之一。
  • 但燃料电池不会因民主党控制相关机构而必然成为首选，最终仍取决于：
  1. 具体政策；
  2. 排放标准；
  3. 激励措施；
  4. 设备成本；
  5. 燃料来源；
  6. 项目交付周期。
  • 天然气发动机仍可能更具经济性、技术更成熟且更易扩展。
  • 联邦层面的新激励或限制政策仍需经过立法程序及总统批准。

c) AWS在不同表后供电方案之间如何选择？

  • 首先评估电力需求和项目时间表：
  1. 需要多少兆瓦；
  2. 何时需要；
  3. 公用事业公司何时可以提供相应容量。
  • 之后对不同技术进行比较：
  1. 天然气发动机适合持续负载；
  2. 燃料电池排放较低且支持模块化部署；
  3. 电池适合备用供电、削峰和短时衔接。
  • 核心评估指标包括：
  1. 每兆瓦总成本；
  2. 燃料可获得性；
  3. 许可和排放要求；
  4. 可靠性及冗余；
  5. 设备交付周期；
  6. 与数据中心电气系统的集成难度。
  • 最关键的商业判断是，现场供电能否比公用事业公司更早提供可靠电力。
  • 如果天然气接入、许可和设备采购所需时间与公用事业供电周期相同，现场供电的商业合理性就会明显下降。

6. 电池储能的应用及渗透率

a) 电池是否已经成为数据中心备用电源的标准方案？

  • 短时电池正在成为标准化配置，但多小时大型电池储能系统仍处于新兴阶段。
  • 机架级或UPS级电池：
  1. 备用时长通常以分钟计算；
  2. 主要用于电网中断后弥补短时缺口；
  3. 为发电机启动争取时间。
  • 用户侧大型电池储能系统BESS：
  1. 常见配置为1至2小时；
  2. 特定场景下可能采用4小时系统；
  3. 主要用于削峰、电网支持和临时电力衔接；
  4. 通常不能替代发电机应对长时间停电。
  • 电池更适合短时支持，不适合作为数据中心持续发电的主要能源。

7. xAI建设目标及新云服务商融资风险

a) 马斯克提出2027年实现10吉瓦上线是否可行？

  • 10吉瓦目标极为激进，但不能完全排除其可行性。
  • 马斯克已证明其AI基础设施建设速度可以显著快于传统数据中心开发商。
  • SemiAnalysis识别出的潜在容量超过9吉瓦，其中约3.6吉瓦已经在建，说明目标背后存在实际项目储备。
  • 需要区分：
  1. 规划容量；
  2. 安装的电力基础设施容量；
  3. 已通电容量；
  4. 真正投入运营的AI算力容量。
  • 即使电力基础设施达到10吉瓦，项目仍需要GPU、冷却系统、可靠电力和完整调试。
  • 专家认为，2027年年底向10吉瓦目标取得实质性进展是可信的，但全部10吉瓦完全通电并投入运行仍需谨慎看待。

b) 哪家超大规模厂商对新云服务商融资风险的敞口最大？

  • Microsoft的风险敞口最高，Meta位居第二。
  • Microsoft承诺从新云服务商采购大量GPU产能，如果相关服务商融资困难，可能导致：
  1. 数据中心建设延期；
  2. GPU采购延迟；
  3. 合同约定容量无法按期交付；
  4. AI业务增长受到容量约束。
  • Meta同样存在合作风险，特别是其与CoreWeave之间存在大额合作承诺。
  • 需要将外部合作风险与Meta自有数据中心开发计划区分开来。
  • 融资困难不代表合同必然无法履行，服务商仍可能通过新增融资、重新协商交付时间或引入战略投资者解决问题。

8. 更严格审批带来的成本增量

a) 数据中心项目的主要新增成本来自哪里？

  • 三项最主要的潜在成本增量为：
  1. 电网更新和升级；
  2. 现场发电；
  3. 工期延误。
  • 电网基础设施升级：
  1. 包括新增变电站、输电设施升级和专用公用事业基础设施；
  2. 每兆瓦可能增加50万至100万美元。
  • 现场发电：
  1. 包括天然气发电或燃料电池；
  2. 每兆瓦成本约150万至200万美元；
  3. 如需增加冗余、燃料基础设施和排放控制，成本还会进一步上升。
  • 延期成本：
  1. 若审批或供电导致项目推迟6至12个月；
  2. 每兆瓦可能增加5万至10万美元融资或施工管理费用。
  • 水资源管理、噪声缓解及社区承诺：
  1. 每兆瓦可能再增加5万至10万美元；
  2. 具体取决于当地监管要求。

b) 更严格要求会使项目总成本增加多少？

  • 假设100兆瓦项目开发预算约为10亿美元，不包括服务器和GPU。
  • 在相对温和的情景下，更严格的审批、电力和社区要求可能使项目成本增加约5%至10%。
  • 如果项目需要建设大规模新电力基础设施，成本增幅可能明显高于上述水平。
  • 成本影响高度取决于项目所在地已有电网和基础设施的完备程度。

c) 额外成本最终由谁承担？

  • 前期成本通常由开发商或超大规模云服务商承担，特别是：
  1. 专用变电站；
  2. 现场发电设施；
  3. 项目延期费用。
  • 大型输电设施或电网升级的成本分担取决于公用事业协议及当地法规。
  • 部分成本可能通过电价回收，由其他电力用户共同承担，这也是当地社区反对数据中心建设的重要原因。
  • 主机托管项目可以通过提高租赁费率、电力费用或可再生能源定价，将部分成本转嫁给超大规模云服务商。
  • AWS、Microsoft等云服务商可以通过云服务定价回收部分基础设施成本，但受存量合同和市场竞争限制，无法逐项、完全转嫁给客户。
  • 最终成本通常由开发商、超大规模云服务商、公用事业公司及部分电费缴纳者共同承担。

9. 项目选址优先级及容量迁移

a) 哪些州或公用事业服务区域的选址优先级会上升？

  • 优先级可能上升的地区包括：
  1. 印第安纳州；
  2. 路易斯安那州；
  3. 亚利桑那州部分区域。
  • 印第安纳州和路易斯安那州的主要优势是土地供应和能源资源。
  • 亚利桑那州应重点关注APS或SRP供电服务区域，前提是相关电力公司能够提供可信的交付计划。
  • 对新项目而言，最重要的并非单纯的税收优惠，而是：
  1. 明确的公用事业供电承诺；
  2. 可执行的通电日期；
  3. 可预测的总成本；
  4. 合理税负；
  5. 当地社区的理解与支持。

b) 哪些地区的优先级可能下降？

  • 对新建绿地项目而言，需谨慎评估：
  1. 北弗吉尼亚州；
  2. 俄亥俄州哥伦布地区；
  3. 得克萨斯州部分地区。
  • 主要风险包括：
  1. 公用事业接入队列拥堵；
  2. 基础设施成本上升；
  3. 监管不确定性；
  4. 项目交付日期难以保证。
  • 不能因为选举而排除整个州，具体项目仍需按县、电力服务区域及项目成熟度判断。
  • 已取得扩建许可和电力保障的劳登县现有园区，可能仍比印第安纳州全新绿地项目更具吸引力，因为其已经具备变电站、光纤和相关许可。

c) 美国项目受阻后，容量会转移到其他州还是海外？

  • 大部分容量首先会重新分配至美国其他选址，而不是立即转移海外或取消。
  • 常见应对方式包括：
  1. 转移至同一区域内的其他场址；
  2. 转向供电和审批条件更好的其他美国市场；
  3. 将容量拆分至多个园区；
  4. 延后建设；
  5. 分阶段开发。
  • AI训练工作负载对时延相对不敏感，因此具备转移至海外的可能性。
  • 云服务、推理及存在数据驻留要求的工作负载，更倾向于保留在美国。
  • 直接取消项目是最不可能出现的结果，延期和重新分配更为常见。

d) 开发商是否会缩小园区规模？

  • 开发商未必会缩小园区总体规划，更可能调整首期建设规模。
  • 典型模式是：
  1. 继续获取支持1吉瓦园区的土地；
  2. 保留完整的1吉瓦总体规划；
  3. 首期仅建设200至300兆瓦；
  4. 后续按50至100兆瓦逐步通电。
  • 分阶段建设可以降低前期资本投入，并在电力和许可时间表发生变化时保留灵活性。

10. 远程园区的网络互联需求

a) 园区迁至远离传统枢纽的地区，是否需要大幅增加网络投资？

  • 通常不只是简单延长光纤，但也不需要彻底重建整个网络。
  • 核心需要重新评估整体网络架构及路由多样性。
  • 对独立AI训练园区而言，通常需要：
  1. 高容量骨干连接；
  2. 两条物理隔离的光纤路由；
  3. 足够的光传输设备和冗余。
  • 如果园区需要与其他设施交换大量数据，还需增加站点间带宽和光学设备。
  • 额外互联需求主要由工作负载决定，而非单纯由距离决定。
  • 对紧耦合AI工作负载，时延本身可能成为限制因素，仅增加带宽不能完全解决问题。

b) 北弗吉尼亚州和俄亥俄州同规模园区的网络投资有何差异？

  • 北弗吉尼亚州园区靠近成熟数据中心集群，通常可接入多个现有光纤服务商及骨干路由。
  • 其主要投资是园区接入和光学设备升级。
  • 哥伦布园区需要先确认是否能够接入多条长途光纤路由：
  1. 如果已有条件，只需增加骨干容量和进行光学升级；
  2. 如果条件不足，则需建设更长的支线和第二条物理隔离路由。
  • 哥伦布已经与阿什本建立光纤连接，因此不能简单假设必须新建完整长途网络。
  • 网络支出主要分为：
  1. 新建园区支线及隔离入口；
  2. 增加波长、转发器和光线路容量；
  3. 楼内网络。
  • 在IT负载和工作负载相同的情况下，楼内网络基本不会发生明显变化。
  • 最大增量支出来自园区到骨干网的接入及路由多样性，而不是额外建设大量网络资源。

11. Trainium对AWS资本开支的影响

a) 1吉瓦AI数据中心的资本开支基准是多少？

  • 会议采用的基准假设为每1吉瓦约400亿美元。
  • 该口径包括昂贵的计算硬件，与仅计算土地、建筑、电力和冷却基础设施的开发预算不同。

b) AWS部署Trainium后，每吉瓦资本开支能够下降多少？

  • 最大的潜在节省来自计算硬件本身。
  • AWS自研Trainium后可以更好地控制：
  1. 芯片经济性；
  2. 系统集成；
  3. 单位AI算力成本；
  4. 网络及集群架构。
  • 物理基础设施成本不会因使用Trainium而显著下降。
  • 对相同的1吉瓦IT负载，仍需要大致相同规模的：
  1. 电力容量；
  2. 变电站和变压器；
  3. 开关设备；
  4. 冷却系统；
  5. 建筑基础设施。
  • 若第三方加速器方案为每吉瓦400亿美元，以Trainium为主的园区资本开支可能降至340亿至360亿美元，降幅接近10%。
