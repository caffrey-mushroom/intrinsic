专家访谈纪要

1. DRAM价格走势与采购机制

a) Q3 Server与Non-server DRAM的ASP涨幅分别是多少？

  • Server DRAM
  1. 公司采购均价环比上涨在5%以内，主要涉及HBM、RDIMM等产品。
  2. 涨幅仍为正，但较此前明显收窄，价格上涨动能有所减弱。
  3. 该涨幅是公司自身采购口径，不代表市场新签合约价格；由于公司与战略供应商签有协议，实际涨幅低于中小客户及非战略客户。
  • Non-server DRAM
  1. 主要包括PC、网络设备、消费类笔记本使用的UDIMM等产品。
  2. Q3采购价格环比上涨约8%—10%，明显高于Server DRAM。
  3. 核心原因是部分产能被Server、HBM及高制程产品占用，Non-server产品可获得的产能被挤压。

b) 为什么公司Server DRAM采购涨幅显著低于行业20%以上的涨幅？

  • 公司样本不具备完整行业代表性，主要原因包括：
  1. 公司与核心供应商存在战略合同关系，议价能力和产能保障能力更强。
  2. 原有LTA虽然已不能完全按照历史价格履约，但仍对当前价格形成一定约束。
  3. 行业数据可能包含CoreWeave等near-cloud客户及中小客户，这类客户缺乏战略协议，现货和急单采购比例更高，涨幅也更大。
  4. 公司通过长期采购、供应商合作和产能规划，将自身价格涨幅控制在行业平均水平以下。

c) LTA是否仍能锁定价格和产能？

  • LTA已不能完全按照原条款执行：
  1. 新项目和量产项目均有LTA覆盖，但自年初产能趋紧以来，供应商已无法按照原价格保障全年履约。
  2. 若客户希望确保产能和交期，需要在LTA价格基础上支付额外的Premium。
  3. 当前价格本质上已转为随行就市，但LTA仍可发挥价格约束作用，使公司涨幅低于其他客户。
  4. 27年LTA仍在谈判，目前相对26年的谈判价格已上涨约10%，后续仍可能因季度供需变化追加Premium。

d) 当前Server DRAM每GB采购价格是多少？

  • 专家口径为：
  1. 64GB产品价格接近1,000美元。
  2. 专家据此给出的口径约为20美元/GB。
  • 该数据存在口径差异：若直接以1,000美元除以64GB，约为15.6美元/GB，因此可能还包含模组、规格、服务或其他溢价，建议后续进一步核实。

e) Q4及27—28年DRAM价格如何判断？

  • Q4趋势
  1. Server DRAM价格预计仍会上涨，但涨幅继续收窄。
  2. 急单、非计划订单仍然存在，但数量及发生频率较Q2下降。
  3. 急单与常规订单之间的溢价率较上季度收窄约10%—15%。
  • 27年趋势
  1. Server DRAM价格仍将上涨，但涨幅预计低于当前年度。
  2. 美光、三星等供应商的新增产能逐步释放，预计27年底价格可能逐渐形成阶段性高点。
  3. 当前27年LTA谈判价格较26年上涨约10%。
  • 28年趋势
  1. 28年上半年价格仍有上涨可能，但涨幅将进一步趋缓。
  2. 美光此前希望28年下半年再涨约8%，目前仍在谈判。
  3. 韩系供应商暂未提出类似明确要求，因此28年下半年不同供应商之间可能出现分化。

2. 急单、库存与供需满足率

a) 急单溢价为什么开始回落？

  • 主要不是需求明显减弱，而是客户的采购行为更加成熟：
  1. OpenAI、CoreWeave等客户已建立专门的供应链团队。
  2. 客户开始按照supply schedule提前锁定产能，而非临时通过急单、非计划订单采购。
  3. 大量需求已转为预先规划的capacity，降低了临时抢单频率。
  4. 因此，急单和非急单之间的溢价有所收窄，但整体供给仍然偏紧。

b) Q3 Server和Non-server DRAM的库存分别是多少？

  • 经访谈后续确认，当前库存口径为：
  1. Server库存约8周，较上季度的10周减少2周。
  2. Non-server库存约12周，较上季度的10周增加2周。
  3. Non-server库存增加主要是为北美圣诞季、促销及渠道活动提前备货。
  4. 公司仍持续维持安全库存，不存在因无法采购而导致库存跌破警戒线的情况。
  • 访谈前段曾出现“Server 12周、Non-server 8周”的相反表述，后续已明确更正为“Server 8周、Non-server 12周”，应以后者为准。

c) Q3供货满足率是多少？

  • Server满足率约80%
  1. 仍有约20%的需求无法满足。
  2. 是当前缺货最严重的领域。
  3. Q2满足率同样约80%，供给紧张程度未明显改善。
  • Non-server满足率约90%
  1. Q2约为92%—93%，Q3下降约2—3个百分点。
  2. 下降主要受圣诞季备货，以及产能向Server产品转移影响。
  3. 公司内部不同BU、BG之间也存在产能资源竞争。

d) Q4及明年的满足率如何判断？

  • Server
  1. Q4预计仍约80%。
  2. 明年预计提升至约85%，但仍需逐季度观察。
  • Non-server
  1. 明年预计提升至约95%。
  2. 改善主要依靠引入新供应商，并将Server与Non-server供应链拆分为两套独立结构。
  3. 新供应商承接Non-server需求后，原有供应商可将更多高规格产能配置给Server端。
  • 整体来看，供需格局边际优化，但距离全面宽松仍有较大差距。

3. 交付周期与关键器件供应风险

a) 当前GPU、Memory及其他器件的lead time是多少？

  • GPU与Memory
  1. Q3交付周期仍超过80周，与Q2基本一致。
  2. 客户需要提前约1年半向Nvidia、AMD、美光、三星等提交forecast和需求计划。
  3. Q4预计仍维持极长交付周期。
  • CPU
  1. 至强、EPYC等产品交付周期已达到约86周。
  2. 正常情况下约为56周，本轮持续延长至86周。
  3. 下季度预计维持86周，极端情况下可能再延长约4周，但继续延长的空间有限。
  • Analog IC、MLCC及电感
  1. 交付周期由约48周延长至56周。
  2. 相当于需要额外提前约2个月下单。
  • 其余物料交付周期总体稳定，暂未出现大幅波动。

b) 明年及27年的lead time能否改善？

  • 上游供应商目前未给出明确改善时间表：
  1. 供应商仅表示将维持现有lead time，如有改善会提前通知。
  2. 目前尚无供应商提供明确更新。
  3. 因此，明年上半年大概率仍维持与今年Q4接近的交付周期。
  4. 27年产能和交付周期仍在沟通中，暂时缺乏明确的改善依据。

c) 为什么满足率可以改善，但lead time仍然很长？

  • 满足率改善主要来自供应链结构优化，而非行业产能全面宽松：
  1. 在Non-server领域引入新的供应商。
  2. 将Server与Non-server供应链拆分，避免共用同一产能池。
  3. 释放原供应商产能，使其更多用于Server高规格产品。
  4. 因此，即使行业整体lead time仍长，公司也可通过供应商切换提高自身满足率。

4. 中国存储供应商导入与区域限制

a) 公司是否正在导入中国DRAM供应商？

  • 公司正在与中国存储厂商洽谈合作：
  1. 中国供应商只能进入部分区域和部分产品白名单。
  2. 北美区域仍需使用非中国供应商。
  3. 欧洲、东南亚等区域原则上可以采用中国供应商。

b) 长鑫的技术能力和价格竞争力如何？

  • 技术能力
  1. 可生产UDIMM、RDIMM等产品。
  2. 在笔记本电脑等Non-server应用中已具备供货能力。
  3. 暂时无法供应MRDIMM等更高端产品。
  4. 在高层堆叠、CoWoS等相关工艺方面仍存在能力限制。
  • 价格
  1. 三星通常是三星、海力士、美光三家中价格最低的供应商。
  2. 长鑫价格较三星还低约6%—8%。
  3. 海力士、美光相对三星可能高约10%—15%，其中美光一般处于三星与海力士之间。

c) 为什么仍需采购价格较高的美光产品？

  • 美光的优势主要在监管和本地化：
  1. 美光晶圆位于美国，面向美国客户供应服务器和数据中心产品时审批更便利。
  2. 韩国产品可能受到OFAC、EAR等出口管制影响。
  3. 在美国服务器和数据中心市场，美光能够降低监管与供应链合规风险。

d) 为什么海力士产品价格更高？

  • 海力士优先将产能用于HBM：
  1. HBM、MRDIMM、UDIMM、RDIMM等产品会竞争部分共同产能。
  2. 海力士正在推进HBM4，更希望将有限产能用于高价值HBM。
  3. 这会挤压普通服务器内存条产能，推动相关产品价格上涨。

5. NVMe SSD供需与价格趋势

a) 为什么NVMe SSD是容易被忽略的重要风险？

  • 数据中心不仅需要DRAM，也大量使用NVMe SSD：
  1. 传统SSD更多用于存储cold data，即低频访问的冷数据。
  2. NVMe SSD主要用于warm data，需要频繁存取。
  3. 随着AI服务器和CPU服务器扩张，NVMe SSD需求快速增长。
  4. 当前NVMe SSD供给比DRAM更紧，未来涨价风险可能更高。

b) Q3服务器NVMe SSD价格上涨了多少？

  • 服务器端NVMe SSD市场涨幅接近15%—20%：
  1. 公司将供应商提出的约20%涨幅谈至约15%。
  2. 缺乏战略协议的其他客户，涨幅可能达到20%甚至更高。
  3. NVMe SSD未来出现阶段性大幅涨价的概率高于DRAM。

c) 消费级SSD为什么开始趋稳？

  • 消费端此前上涨主要由HDD向SSD切换驱动：
  1. 大量笔记本电脑由机械硬盘切换至SSD，形成一次性需求增长。
  2. 该轮上涨并非主要由产能受限导致，而是产品渗透率提升。
  3. 随着SSD渗透率达到较高水平，后续需求增长驱动力减弱。
  4. 因此，消费级笔记本SSD继续大幅上涨的空间有限。

d) 27—28年NVMe SSD满足率如何？

  • 预计满足率仅约75%：
  1. NVMe需求从今年Q2才开始集中爆发。
  2. 新增产能从启动扩产到落地通常需要约2年。
  3. 即便从2026年Q1启动扩产，也可能到2028年Q1才完成。
  4. 因此，未来两年NVMe SSD供应紧张程度可能高于DRAM。

e) 长江存储是否已进入服务器供应白名单？

  • 目前尚未进入：
  1. 长江存储主要生产NAND Flash。
  2. 技术迭代较快，已可达到192层，与海外厂商不存在特别明显的代际差异。
  3. 服务器端认证标准高于笔记本电脑，导入难度更大。
  4. 公司仍在评估导入可能性，当前NVMe SSD仍主要由闪迪、海力士等海外厂商供应。

6. 服务器市场份额与产品架构

a) 公司在服务器市场的份额是多少？

  • 全球整体服务器市场份额约25%。
  • AI服务器市场份额约10%。
  • 相关数据仅代表公司自身情况，无法直接代表全行业出货趋势。

b) 服务器配置如何拆分？

  • 服务器存在4U、6U、8U等多种形式，每个U可理解为一个服务器单元。
  • 当前主要有两类架构：
  1. Nvidia HGX/SXSM架构：典型配置为6个GPU搭配3个CPU。
  2. OAM开放式架构：常见于Intel或AMD MI300等方案，典型配置为6个GPU搭配2个CPU。
  • 两种架构主要差异包括：
  1. CPU与GPU配比不同。
  2. PCIe与NVLink配置不同。
  3. SXSM架构需纳入NVLink及相关芯片。
  • 其余基础器件较为相似，包括重定时器、阻容感、ASIC、DSP等。

c) 是否可以获得更细的出货量和产品组合数据？

  • 直接披露具体出货量、利润率和型号占比可能涉及合规风险。
  • 可行方式是：
  1. 分析师先根据物料号、市场价格和公开信息制作测算表。
  2. 专家在不直接披露内部数据的前提下帮助纠偏。
  3. 后续重点观察4U、8U占比，以及不同CPU配置的高端化变化。

7. CPU高端化、AI Agent与ARM替代趋势

a) 当前CPU单核价格大致是多少？

  • 常规Intel产品以128核为例，单核价格约40美元。
  • 特定高端客户的单核价格可能达到：
  1. 80—100美元；
  2. AI Agent定制化产品约100—180美元；
  3. 中位数约140美元；
  4. 极高端产品可超过200美元，但应用非常有限。

b) CPU高端化趋势是否明显？

  • 整体市场存在高端化，但趋势尚不显著：
  1. 普通市场高端化比例每季度可能提升约2—3个百分点。
  2. 当前特殊定制的高端核需求约占整体的2%—3%。
  3. 金融、量化、对冲基金等客户对单核性能要求更高。
  4. 普通北美CSP尚未全面转向高端CPU，GPU仍是AI推理投入重点。

c) AI Agent场景的CPU高端化是否更明显？

  • AI Agent场景明显强于Chatbot：
  1. 北美AI Agent客户初始定制化比例已约20%。
  2. 上季度该比例增长约4%，即提升约1个百分点。
  3. 当前约有21%—22%的AI Agent客户使用定制化高端CPU。
  4. 相关产品以ARM架构为主，单核价格通常为100—180美元。

d) 为什么AI Agent需要更高端CPU？

  • 主要目标是提高GPU利用率：
  1. 部分客户反馈GPU利用率不足30%。
  2. CPU计算逻辑和调度能力不足，无法充分调动GPU。
  3. 提升CPU单核性能和定制化能力，可以降低GPU idle rate。
  4. 在金融计算、复杂Agent任务和差异化纠错场景中，该需求更突出。

e) CPU高端化能否提升Dell和Intel的毛利？

  • 对Intel
  1. 高端产品毛利绝对额更高。
  2. 专家举例：30美元产品毛利约9美元，90美元产品毛利约18美元。
  3. 虽然毛利额翻倍，但收入增长3倍，因此毛利率反而可能下降。
  4. 该测算属于示意性估算，并非正式披露数据。
  • 对Dell
  1. 高端CPU会提升收入规模。
  2. 相关采购成本最终需支付给Intel，因此不会直接提升Dell利润率。
  3. Dell更多承担系统集成和交易流转角色。

f) x86和ARM的市场占比如何变化？

  • 架构正在快速向ARM迁移：
  1. 前一年x86与ARM约为50%：50%。
  2. 今年x86已低于40%，ARM约为60%。
  3. 明年预计进一步变为30%：70%，ARM将占据主导。

g) ARM内部Nvidia与ASIC的比例如何？

  • 当前ARM方案中：
  1. Nvidia Grace、Grace Blackwell等方案约占50%。
  2. 客户自研或定制ASIC方案约占50%。
  • 未来ASIC占比可能超过Nvidia：
  1. AI推理更依赖定制化调度。
  2. 客户希望通过CPU ASIC设计提高GPU利用率。
  3. ASIC可针对working node、带宽、存储和单核逻辑进行优化。
  4. Nvidia方案更标准化，客户无法在“黑箱”中加入过多定制属性。

h) 为什么ARM比x86更适合AI推理？

  • ARM的核心优势是灵活和可定制：
  1. 可规划芯片内部运算、字节和带宽输出方式。
  2. 更容易与GPU、NVMe及其他组件协同。
  3. 可减少所有任务均绕回CPU重新发指令的流程。
  4. 更适合推理场景中的快速编排和低延迟需求。
  • x86在通用计算领域仍有优势：
  1. 软件栈成熟，复杂指令集完善。
  2. 传统服务器中90%以上仍采用x86。
  3. 但其底层结构相对固定，定制化空间小于ARM。

i) x86和ARM能否在同一服务器中混合使用？

  • 公司已储备裸金属异构服务器技术：
  1. 同一服务器可同时植入x86和ARM。
  2. 客户可通过API切换所需架构。
  3. 理论上可由ARM负责调度和推理，由x86处理虚拟机、沙盒等通用任务。
  • 目前市场反馈较弱：
  1. 客户仍倾向采用单一架构。
  2. Meta等客户尚未明确表达对异构方案的需求。
  3. 客户也可能内部自研，不一定需要系统集成商提供支持。

8. Nvidia方案、ASIC方案与GPU利用率

a) Nvidia与ASIC方案的性能差异是什么？

  • Nvidia整体方案的平均响应速度较快，但可能存在长尾延迟。
  • ASIC可从设计阶段针对具体任务优化，减少长尾情况。
  • 两者不能只比较平均性能，还需关注：
  1. 最慢响应时延；
  2. 带宽和吞吐量；
  3. GPU利用率；
  4. 成本投入；
  5. 具体工作负载。

b) 将Nvidia配置全部配齐后，延迟能改善多少？

  • 在不考虑成本的情况下，完整配置可显著降低延迟：
  1. 例如可能从约200毫秒降至几十毫秒。
  2. 大致可实现从100毫秒级降至10毫秒级，约有10倍改善。
  3. 但通常无法直接从毫秒级降至微秒级。
  4. 最终效果取决于GPU、CPU、NVLink及系统架构的具体搭配。

c) 完整配置能否显著提高GPU利用率？

  • 理论上可以，但暂无明确量化结果：
  1. 当前部分客户GPU利用率不足30%。
  2. 更强的CPU和更完整的互联配置可降低GPU空闲时间。
  3. 目前没有客户将所有配置全部配齐，主要原因是成本过高。
  4. 因此，尚不能明确判断利用率最终可由30%提升至何种水平。

d) B300 8卡机柜价格和散热成本如何？

  • 专家提供的北美市场口径：
  1. B300 8卡完整配置约为650万美元，折合人民币约5,000万元。
  2. 若所有高规格组件完全配齐，整体投入可能超过1,000万美元。
  • 中国市场曾出现约1,700万元人民币的口径，专家认为差异可能主要来自散热方式：
  1. 液冷价格约为风冷的7—8倍，极端情况下可达10倍。
  2. 液冷部分约占BOM价值的30%，但占最终售价的比例会更低。
  3. 由于产品通常打包销售，冷却部分无法单独拆价。
  • 上述价格口径差异较大，且与公开市场常见口径可能不一致，建议后续单独核验配置范围、计价单位及是否包含整柜配套设施。

9. CPU缺货与涨价预期

a) CPU紧缺程度是否因高低端型号而异？

  • 当前高端和低端CPU交付周期均约86周，紧缺程度基本一致。
  • 原因在于：
  1. 至强和EPYC等产品均受晶圆产能限制。
  2. 部分晶圆依赖台积电先进制程。
  3. 高端化需求与产品换代周期同时发生，进一步拉长交期。

b) 本轮CPU需求中，换代周期贡献有多大？

  • 专家无法精确拆分客户采购用途。
  • 主观判断是，换代周期带来的需求占比可能低于50%，但没有实际数据支撑。
  • 其他需求来自AI服务器扩张、高端化及数据中心建设。

c) CPU后续是否会继续涨价？

  • 已收到明年继续涨价的预期：
  1. 初步涨幅区间约为8%—18%。
  2. Q4将协商明年初的基础价格。
  3. 最终涨幅可能接近区间上沿。
  4. 明年可能不止涨价一次，年初确定一次，年中可能再次协商。

10. 云厂商CapEx与客户需求

a) 哪些北美客户拿货较为激进？

  • SpaceX并非公司的大型客户：
  1. 其具备较强的自研能力和内部开发团队。

  • 外部行业数据预计整体CapEx规模约为1,000亿美元。
  • 落实到公司的客户CapEx及业务机会，预计同比增长约15%。
  • 行业CapEx并不会全部转化为公司订单，反映AI服务器市场竞争仍然激烈。

d) 国内云厂商与海外客户相比如何？

  • 公司无法对阿里、腾讯、火山等国内云厂商作出准确判断：
  1. 国内云厂商更多与本土服务器厂商合作。
  2. 公司在这类客户中的业务占比较低。
  3. 因此，无法判断其明年CapEx增速是否会高于海外客户。
