  3. C端用户转向Anthropic主因是额度而非模型：OpenAI削减100和200美元套餐额度，同价200美元套餐Anthropic价值约为OpenAI的4倍多，Anthropic ARR在10月环比加速。
  4. 各家都在收紧C端额度，Anthropic大规模封禁号商提供的200美元账号，Gemini则对每次用光额度的用户动态减半。
  5. B端各家功能趋同，选型转向价格、数据源和token额度，Gemini Enterprise推出每月五六十美元可自由选择三家模型的固定价套餐，Fable 5.2升级比例预计有限，金融法律除外。

摘要

1、C 端迁移的真实驱动： OpenAI 砍额度与 Anthropic 同价额度优势， 以及 Anthropic 封号、Gemini 动态减额背后的收紧逻辑2、B 端选型在功能趋同后转向价格、数据源和 token 额度， Gemini 固定价套餐放开跨家模型选择， Fable 5.2 升级比例预计有限3、训练门槛抬高、通用模型取代垂类、数据护城河变浅三股力量下的格局集中， 以及 OpenAI 的资金分歧

Fable 5.2 发布后，笔者围绕 Anthropic、OpenAI 和谷歌三家头部厂商的竞争现状，做了多轮调研。调研对象包括北美头部厂商和国内大模型公司的一线专家，问题从训练投入、算力分配，一直追问到订阅额度、封号规则和企业选型。

这份报告回答四个问题：格局是否继续向头部集中；Anthropic 靠什么抢份额；企业按什么选模型；OpenAI 的钱够不够。其中两处——Anthropic 抢份额的原因、OpenAI的资金——笔者与调研对象看法不同，保留了自己的判断，文中分别说明。

#

总判断

格局向头部集中。用户选模型看额度、价格和数据源，Anthropic 近期抢份额主要靠额度。

笔者的调研支持下面四条结论：

  1. 格局向头部集中，二线通用模型和垂类模型被挤压。
  2. C 端用户转向 Anthropic，主因是额度，不是模型。
  3. B 端选型看价格、数据源和 token 额度，各家功能已趋同。
  4. OpenAI 没有放慢训练，但钱从哪来有分歧。

#

结论 1：格局向头部集中，二线通用模型和垂类模型被挤压

集中来自三股力量：训练投入的门槛升到千亿美元级；通用大模型正在取代垂类模型；企业的数据护城河在变浅。三股力量叠加，二线实验室和垂类模型公司的空间都在缩小。

第一股力量：训练投入，只有头部几家跟得上。 Anthropic 在投资者小会上提到训练预算：2027 年 900 亿美元，2028 年增长非常快。笔者的感受是 Anthropic 各方面的节奏和计划都很好，据此追问：投入这么大，其他公司是不是更难追上。调研的回答是，头部几家基本都能有这么大的投入，OpenAI 和 Gemini 应该没有问题；但二线实验室若还做通用模型就会比较困难，例如 Ilya 的 SSI 和 Thinking Machines Lab，三线公司就更多了。算力也在向头部集中：谷歌现有 TPU 接近 800 万片，其中约 350 万片给了 Anthropic。

第二股力量：通用大模型在取代垂类模型。 调研认为这是当前的大趋势：大模型正在取代所有小的垂类模型。例如 Genie 世界模型虽叫 Genie 4，实际上已没有独立的 Genie 模型——它是用 Gemini 和 Omni Flash 串联出来的。垂类模型的需求越来越少，做通用大模型的公司因此能占据更大的市场空间。

二三线只剩"小而便宜"一条路，且不好走。 笔者不清楚二三线的小模型公司还在训练什么（例如 NVIDIA 支持的 Reflection），甚至认为它们没有必要再训练。调研的回答是：如果能做出小而高性价比的模型，仍有价值，但前提是足够小、足够便宜；这条路很难获得高收入，而且一旦头部公司亲自做小模型，二三线公司就很难竞争——头部做得更好。

第三股力量：数据，企业的护城河在变浅。 二三线公司要竞争，除非拥有大量独特数据，但调研认为现在可用于训练的特殊数据已经不稀缺：CAD、工业模拟、金融和法律的反向工程数据越来越多，数据提供商也越来越多——关键在于企业愿不愿花钱。由此推演，未来企业的数据护城河可能不复存在：企业现有的独特数据，未必能一直保持独特性，因为生成数据的方式越来越多。

#

结论 2：C 端用户转向 Anthropic，主因是额度，不是模型

根据笔者的调研，C 端用户对额度（quota）敏感，对模型差别不敏感。OpenAI 最近大幅削减 200 美元和 100 美元套餐的额度，促使很多用户转向同价位下额度更多的 Anthropic。

OpenAI 在砍额度，Anthropic 的同价套餐更值。 OpenAI 早期为了抢份额，给用户的补贴最多、经常重置额度，如今已很少这样做；也曾暂停 200 美元套餐的新用户注册，重新开放后套餐权益已缩水。有头部厂商的团队专门测试过额度：同样是 200 美元套餐，Anthropic 的价值约为 OpenAI 的 4 倍多。笔者了解到，Anthropic 的年度经常性收入（ARR）在 10 月环比加速，似乎正在抢走 OpenAI 的份额。

用户跟着额度走，因为感受不到模型差别。 大部分 C 端用户会买多个 200 美元账户，主要用来做 vibe coding，自己感受不到模型之间的明显差异；预算有限，就更愿意选额度充足、能薅到更多羊毛的平台。

但额度也在收紧，Anthropic 开始封号。 笔者注意到，Anthropic 最近大规模封禁 200 美元账号——这类账号此前由号商提供、被当作耗材使用，如今重置一次就被封。笔者当时的猜测是，平台可能认为这些用户在薅羊毛，也可能因为用户使用中文而封号。

Gemini 的做法不同：不封号，改动态减额。 约三四个月前，Gemini 上线了新功能：系统发现用户每次重置前都把额度用光，下次就只给一半，以此限制薅羊毛。

判定羊毛党的依据是：用户是否反复在用完 token 额度后停用、等重置再继续——这种用法现在很常见：大任务 token 不够，就设好闹钟，等重置后再提交。

整体来看，各家都在减少给 C 端用户的额度，因为这些用户提供的数据，训练价值已经有限。

#

不同看法：笔者更看重模型本身。 笔者周围的人都觉得 Anthropic 是最好的；此前与另一家国内大模型公司交流，对方也认为 Anthropic 比其他模型好很多，建议不要只看刷分、要看实际使用体验。笔者访谈的专家自己也给出过支持模型优势的事实：Fable 5.2 排在 LMArena agentic 榜单第一，目前基本是 Anthropic 的模型能管理十几到几十个代理。

结论 3：B 端选型看价格、数据源和 token 额度，各家功能已趋同

B 端用户同样分不清模型。各家企业版的功能已经没有明显差距，所以价格、数据源和 token 额度成了选型因素。

多数用户不确定该选哪个模型，业内的使用者也不例外。 通常是公司安排测试哪个模型，员工就去测一下、顺便用一下。选不出模型是企业面临的痛点：有人觉得 Anthropic 好，有人更喜欢其他模型；也有人形成了自己的判断，像大脑里装着一个"路由器"，认为某些任务适合 OpenAI，某些适合 Gemini，某些适合 Anthropic。

Gemini Enterprise 的对策是把选择权交给用户。 据调研，Gemini 最近推出固定价格套餐，用户每月支付五六十美元，即可自由选择 Anthropic、OpenAI 和 Gemini 的模型。相比之下，Anthropic 套餐不能选择 OpenAI 或 Gemini，微软套餐也不能选择 Gemini。

模型难选、功能趋同，价格、数据源和 token 额度成为选型重点。 笔者认为，各家企业版的功能差别不大，客户可能更愿意按价格选择。调研反馈确认价格是重要因素，同时强调推理时能接入哪些数据源也很关键。

例如，Gemini Enterprise 接入了许多金融和法律领域的实时数据源，用户无需额外付费；如果自行通过谷歌搜索法律案例或金融数据，结果未必准确。此外，Gemini Enterprise 提供的 token 额度也比其他厂商多很多，在TPU 上运行时尤其如此。

新模型的升级也不会自动发生。 专家预计，Fable 5.2 上线后的升级比例可能有限。金融和法律行业是例外，这些客户基本上有新模型就会升级。

多数做 coding 的公司则取决于采购决策：公司提供新套餐，员工肯定愿意用；如果公司不采购，员工就可能继续使用原有的 Opus。企业需要先做大量测试，确认 5.2 不会显著增加成本，而且能带来收益，才会升级。

用户评分不仅反映模型能力，也反映任务完成效率。 调研提到，在 harness 方面，Argon 和 Carbon 的“评价速度”较慢，接下来发布的新模型效率会高很多，Hydrogen 这类蒸馏模型也会更快。每一版模型的优先级可能不同，但效率提升虽然无法体现在 Artificial Analysis（AA）榜单上，却能反映在 LMArena 的用户评分中。因此，公司要提升用户评分，就需要兼顾能力和效率。

B 端客户更在意模型的主动性，但并非越主动越好。  Kimi 3.1 只做用户要求的事，不会主动提出下一步，很多人对此有意见。笔者的理解是，Kimi 的定位就是执行层，注重准确性。Kimi 可能在后训练时把主动性排到了后面

对于训练是否会先考虑用户需求，调研回应，通用模型训练都会考虑这些因素。模型也有不同的执行模式，可以通过 prompt 触发不同的行为。目前，coding 用户主要关心模型能否完成任务，对主动或被动没有太多偏好；B端客户则更在意，有些客户只希望模型按既定流程完成自动化任务，并不希望它主动发挥。

结论 4：训练没有放慢，但"钱从哪来"存在分歧

专家和笔者在 OpenAI 的资金问题上看法相反：专家认为 OpenAI 不缺钱、缺的是买得到的算力；笔者则担心其收入撑不起千亿美元级的年投入。

共识：训练节奏没有放慢。 笔者从其他渠道了解到，OpenAI 内部在调整重点，现在的排序是端侧、AI for Science 和具身智能，笔者担心这会拖慢训练节奏——比如 OpenAI 可能不再需要这么聪明的模型。调研的回答是：目前没有听说 OpenAI 放慢训练速度，二线公司也都没有放慢。

分歧：OpenAI 的钱够不够。 专家的看法是，OpenAI 不缺训练的钱：其定位不错，关键约束是能否买到足够的训练资源；头部几家基本都能达到 Anthropic 那样的训练投入，OpenAI 和 Gemini 应该没有问题，Anthropic 也没有特别大的问题。

笔者的担心是收入撑不起投入。依据有三条：

  1. 投入量级。 笔者了解到的 Anthropic 的训练预算：2027 年 900 亿、2028 年增长非常快；那也意味着Anthropic会把一半以上的收入都用于训练。若每家每年都要投 1000 亿，OpenAI

的资金来源在哪里。

  1. 收入不明。 OpenAI 的 ARR 情况并不明朗，听说环比还在下降（被Anthropic抢份额）。
  2. 业务结构。 OpenAI 的 C 端业务都在赔钱；要拿钱做训练，就得把 API 卖得更好——除 API 外其他业务不赚钱或亏损，广告业务又还没起来。

结语

把四条结论连起来看，是一条因果链。用户分不清模型，选择就由额度、价格和数据源决定。笔者据此推断，这三样最终比的是算力和资金，因为额度受算力限制，数据源要花钱买。所以格局才向头部集中，OpenAI 的钱从哪来也才成为关键。

这条链上有两处，本次调研和笔者此前的判断不同，可以留作后续的验证点。第一处是 Anthropic 的份额。如果它继续收紧额度，用户却仍然留下，就说明模型本身才是主因。反过来，如果用户再次跟着额度迁移，额度就是主因。第二处是 OpenAI的资金，要看它的 ARR 能否止跌回升。
