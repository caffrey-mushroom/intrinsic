正文

潮玩行业的底层逻辑，已经从盲盒稀缺炒作切换到IP 持续内容能力 + 实物产品性价比 的长期竞争。2026 下半年泡泡玛特进入高频上新、爆款缺位的结构性周期，二手市场从普涨投机市场转向隐藏款 / 限量联名溢价、常规款普遍破发的二元定价结构。用户群体发生分层：投机玩家大规模离场，留存核心粉丝对 IP 原创性、品控、定价的容忍阈值持续下降。公司用毛绒挂件、礼盒、联名跨界、新 IP 矩阵对冲 LABUBU 热度回落，2027年泡沫出清后，公司成长的逻辑将从爆款引擎到 SKU 工厂。

一、2026 下半年新品发售全景复盘：节奏、品类结构与 IP 策略

2026 年下半年（7–11 月）泡泡玛特维持了固定周度上新节奏，保持每周四晚 22 点线上首发、次日线下门店同步发售的标准化节奏，新品矩阵可以拆分为四大主线：LABUBU 顶流主线、成熟 IP 稳定续作、跨界联名与高单价限量线、低价入门款（萌粒、小挂件），同时叠加圣诞、年终礼盒季节性产品。整体呈现“顶流持续透支、新 IP 试错、价格带全覆盖的特征。

1.1 LABUBU 系列：下半年核心流量盘，但热度逐级衰减

作为泡泡玛特过去两年的增长引擎，下半年 LABUBU 连续推出多套重点系列，是观测市场情绪最重要的标的：

  1. 复古理发店系列（6 月底，7 月起持续流通）：主打 DIY 发型的参与感，定价 159 元 / 盲盒，是本轮行情拐点标志性产品。发售之后，除隐藏款之外，全部常规款在千岛、闲鱼平台快速跌破原价，成为市场共识LABUBU 炒作泡沫破裂 的标志性节点，黄牛群体停止批量扫货，渠道端不再囤货赌溢价。
  2. 8 月 28 日「心底密码 mini」（79 元）、9 月「Wilderness 野外系列」（全球同发，首次把场景地台整合进常规盲盒）、
  3. The Monsters 一喵变猫搪胶毛绒挂件（10 月 15 日）：10 款（9 常规 + 1 隐藏），单盒 129 元，整套 1161 元，隐藏概率 1:72。设计为 LABUBU 叠加双层耳朵（精灵耳 + 猫耳），社交平台讨论热度很高。二手行情出现明显分化：隐藏款缅因喵最高成交价 899 元，约原价 7 倍；常规款中布偶喵是唯一溢价款，最高 299 元；奶牛喵、波斯喵、暹罗喵等半数常规款，未发售阶段预定价就已经低于 129 元发售价，预售阶段就出现破发，市场对普通款的预期已经非常谨慎。
  4. 雪夜狂欢惊喜倒数礼盒（11 月 12 日）：年终圣诞礼盒，定价 599 元，7 格礼盒形式，主打节日礼品属性，面向粉丝送礼场景，而非盲盒抽卡逻辑，主打收藏仪式感，限量属性更强，二手流通以整套为主，单拆流通较少。

LABUBU 下半年新品已经从盲盒手办 向毛绒挂件、礼盒、限定周边倾斜。公司有意识降低常规静态手办上新占比，转向毛绒品类。毛绒的社交传播属性更强、短视频种草更容易出圈，但缺点是工艺同质化、竞品供给多，很难形成长期稀缺。

1.2 成熟 IP 续作：MOLLY、DIMOO、SKULLPANDA、CRYBABY 稳定更新

  • MOLLY：围绕 20 周年、19 周年雕像、Keith Haring 等艺术联名，主打 Mega 大娃、限量雕像，高单价、低货量，面向资深藏家；常规盲盒上新节奏放缓，不再作为流量主力。- DIMOO：11 月推出飞行幻想系列手办、DIY 配饰系列 Popop Bestie，风格回归温柔治愈路线，社群反馈分化明显，老粉评价稳定，但很难出圈吸引新用户；- SKULLPANDA：延续高定联名路线，Robert Wun 巴黎高定周联名 1000%/400%/1/6 BJD 限量款，货量极少（999 体），属于圈层收藏向产品，流通圈子极小，价格由藏家圈层决定，大众二手市场交易量很低。- CRYBABY：持续情感向叙事，“旋转的星光 等系列稳定出货，粉丝粘性强，但受众盘子偏小，属于现金流稳定的小而美 IP，不具备破圈能力。

1.3 跨界联名线：CLOT、艺术家联名，打造独立高溢价单品

下半年最有代表性的是 11 月 CLOT杠上开发 联名系列，产品线覆盖盲盒、摆件、挂件、香炉、1999 元限量麻将。其中限量麻将上线即售罄，二手平台最高成交价 2660 元，较原价涨幅超 30%；后续回落至 2200 元附近，溢价收敛速度快。

这类联名的核心逻辑不是盲盒抽卡，而是潮流圈层跨界，受众是潮牌玩家 + 泡泡玛特核心粉丝，供给严格限量，是少数还能维持正向溢价的赛道，但品类不可持续，属于点状爆款，无法支撑季度级收入增长。

1.4 低价入门线：萌粒、叛桃等新 IP，做流量兜底

泡泡萌粒「快乐开涮」（10 月 15 日）：单颗 15 元，20 常规 + 1 隐藏，主打低价、DIY、拼搭，面向学生、入门玩家，单价低、试错成本低，二手几乎没有溢价，以自玩为主；

新 IP Peach Riot 叛桃「糖果模式」（10 月 29 日）：79 元盲盒，12 常规 + 1 隐藏，年轻化朋克少女风格，是泡泡玛特重点孵化的下一代潜力 IP，属于典型的新 IP 试错，社群讨论热度有限，二手基本平价或微破发。

1.5产品上新的结构

从定价结构看：

  • 79 元档：入门盲盒、新 IP 试错，走量，二手平价 / 破发；- 129–159 元档：LABUBU 毛绒、常规手办主力价格带，是行情分化最明显的区间；- 500–2000 元档：礼盒、Mega 大娃、艺术家联名、限量摆件，高单价、低流通，只有稀缺款维持溢价；- 2000 元以上：高定联名雕像、限量 1000%，圈层收藏，交易量极低。

泡泡玛特下半年的供给策略：用低价盲盒拉新、LABUBU 毛绒维持流量、限量联名、单价礼盒承接高净值藏家，同时孵化叛桃等新 IP，对冲单一 IP 依赖风险。但代价是上新密度极高，用户审美疲劳加速。

二、用户反馈分层：投机者离场、核心粉丝祛魅、新用户观望

整合小红书、潮玩社群、千岛评论区、抖音开箱评论，将用户拆成三类群体，反馈差异极大，也是理解行情分化的底层原因：

2.1 投机 / 黄牛群体：已经战略性退出常规盲盒赛道

2025 年的核心购买盘之一是套利玩家：批量端盒、锁隐藏、囤热门款，等待二手溢价。下半年反馈非常统一：常规盲盒没有安全垫，赌隐藏的风险收益比不划算。复古理发店系列的集体破发是转折点，大量黄牛停止蹲店、小程序代抢，只盯 CLOT 联名麻将、限量大娃这类明确稀缺、圈层认可度高的单品。 黄牛的离场直接改变供需：过去新品上线的秒空很多是囤货，现在很多新品秒空之后，二手立刻放量，价格快速回落，虚假稀缺消失。

2.2 长期核心粉丝（5 年以上老粉）：核心吐槽点

第一，IP 同质化、换皮严重，原创叙事不足。用户集中吐槽 LABUBU 新品很多是换衣服、换材质，世界观、故事线没有新内容；一喵变猫被评价为靠双层耳朵造型博眼球，内核没有新故事，审美疲劳是高频关键词。老粉的核心诉求是 IP 内容，而不是单纯换材质、换涂装的新品。

第二，品控投诉持续上行，瑕疵容忍度下降。毛绒挂件掉毛、缝线瑕疵、大小眼、涂装溢色是高频投诉；很多用户反馈换货依然是瑕疵品，售后体验差。在溢价消失之后，用户不再愿意为赌运气 容忍瑕疵，一旦实物低于预期，直接在二手折价出清，进一步压低二手价格。

第三，定价争议持续放大。在消费环境偏弱、二手没有溢价兜底的背景下，用户对单价敏感度显著抬升。129 元毛绒挂件、159 元手办的定价，被反复讨论材质成本和售价不匹配；直播员工无意吐槽79 元挂件有点贵的事件发酵，本质是用户情绪长期积累的结果，大家不再愿意单纯为情绪溢价买单。

2.3 泛流量新用户：短视频种草转化率下滑，观望为主

2025 年大量用户是刷短视频被 LABUBU 种草，跟风购买，很多本身不是潮玩爱好者，购买动机包含买了能升值的预期。下半年这部分用户显著减少：刷到种草视频之后，先去千岛、闲鱼查二手行情，发现热门款很快破发，升值预期消失，直接放弃下单。 新用户的购买逻辑从跟风抢稀缺变成喜欢再买，不指望转手赚钱，纯自玩需求，决策更谨慎。

正向反馈集中在：CLOT 这类跨界联名、圣诞礼盒、Mega 限量雕像。这类产品的购买逻辑是收藏、圈层社交、礼品属性，和盲盒抽卡是两套逻辑，粉丝认可度更高。

过去盲盒商业模式的根基，一部分建立在潜在升值预期之上。当二手市场不再提供这个预期，盲盒就回归纯粹的玩具和情绪消费品，付费意愿、复购率都会下台阶，这是整个潮玩品类的底层变化。

三、二手市场全景：从普涨牛市，走向二元割裂定价体系

理解二手市场，要先理解一个反直觉的事实：价格崩了，是官方乐见的，甚至可能是官方主动促成的。

图1：隐藏款二手溢价坍缩：峰值倍数 vs 当前倍数

3.1 行情总特征：二元市场，溢价只集中在少数稀缺标的

2025 年是优质常规款普遍溢价、隐藏款天价的普涨牛市；2026 下半年形成清晰二元结构：

  1. 绝大多数常规款：平价流通、上市即破发，没有套利空间 LABUBU 复古理发店、一喵变猫半数常规款、叛桃、萌粒系列常规款，二手成交中枢持续低于发售价。典型例子：一喵变猫常规款，原价 129，闲鱼稳定成交区间 80–110 元；复古理发店常规款普遍在 90–130 元区间，多数低于 159 原价。 整端行情也明显降温：过去新品整端可以溢价，现在大部分新品整端流通价≈原价甚至折价，只有极少数爆款系列整端能平价出。
  2. 隐藏款、稀缺联名、限量大娃：依然维持溢价，但溢价收敛、回撤更快

· 一喵变猫隐藏缅因喵：原价 129，峰值 899，后续回落至 250–350 元区间；

· CLOT 限量麻将：原价 1999，峰值 2660，稳定成交中枢 2200–2300 元；

· 巴黎高定联名 SKULLPANDA/MOLLY Mega：限量 999 体，发售初期溢价高，但流通盘极小，流动性很差，想出手时折价幅度很大；

  1. 老款二手持续阴跌：2024–2025 年的 LABUBU 爆款，二手价格持续下行，早期高价入场的玩家普遍被套，进一步教育市场：潮玩不是保值资产。

3.2 二手定价的新定价因子（已经取代过去的热度溢价）

  1. 货量管控（最核心）：限量编号、固定发售渠道（仅小程序到家、线下限定）、低货量联名，溢价支撑强；常规盲盒持续补货、全渠道放量，价格很快崩盘；
  2. 圈层匹配度：跨界联名（潮牌、高定艺术家）的溢价来自外部圈层，不是泡泡玛特原有盲盒粉丝；纯 IP 盲盒没有外部圈层加持，很难溢价；
  3. 实物颜值与种草素材：毛绒挂件更容易出短视频素材，更容易短期冲高；静态手办种草难度更高；
  4. 流动性折价：即使是隐藏款，热度周期极短，一般发售 7–15 天达到价格峰值，之后持续回落，囤货等升值的策略失效。

3.3 潮玩回收商行为变化

回收商报价体系同步调整：现在只收隐藏、限量联名、Mega 大娃；常规盲盒几乎不回收，或者极低折扣回收，回收商不再兜底常规款，进一步放大二级市场的价格压力。过去玩家可以不喜欢就折价卖给回收，现在常规款流动性枯竭，只能散卖给个人玩家。

四、拆盒经济学：129 元门票的精确定价

潮玩的价格体系重构之后，「抽盒」这个动作本身也该重新定价了。以「一喵变猫」为例可以算得非常精确。

图2：一喵变猫的拆盒经济学：期望值分解与概率曲线

来源：作者

隐藏款概率 1/72，隐藏款二手确认价约 273 元，常规款约 109 元——那么一盒 129 元盲盒的期望回款是 1/72×273 + 71/72×109 ≈ 111.3 元。与 129 元的票价相减，差额 17.7 元就是你为「拆那一下」付的钱，约占票价 14%。这是一张精确的情绪消费价签。

从概率曲线上看会更直观：抽 12 盒（1548 元）只有 15.5% 的概率摸到隐藏款，抽满期望的 72 盒要花 9288 元，而直接去得物买一只拆盒拆袋的确认款只要 595 元、闲鱼更低——赌盒的成本是直接购买的 34 倍。这组数字把「抽一个」和「收一只」彻底分成了两种消费：「要某一款，直接去二手平台搜型号；要拆的那十秒，就按原价买一次体验。」真正需要警惕的是仍把盲盒当投资的人——在溢价坍缩后的市场里，这个决策的期望损失已被精确量化为票价的 14%。

对泡泡玛特而言，这 17.7 元的「拆盒税」反而是商业模式最坚实的部分：它不依赖二级市场行情，只依赖拆盒瞬间的多巴胺，而后者由会员复购率（51.6%）直接背书。二级市场的投机收益从来不在公司的报表里，拆盒体验的价值却一直在。

五、产品设计思路：王宁的三层逻辑

把下半年的产品动作放回王宁的公开表述里，设计思路其实是一个清晰的三层结构。

底层是「无用之用」的价值锚。王宁反复回到这个十几年前提出的概念：不盯着产品「有没有用」，把核心放在内在价值上——博物馆里留下来的是无用的艺术。落到商业上，就是卖情绪价值而非功能价值：孤独感的解药、收藏欲的满足、「我懂这个」的身份认同。这是所有产品决策的第一性原理。

中层是「设计溢出」的扩张逻辑。当艺术家资源和设计能力积累到一定程度，IP 就成了可以复用的「生产资料」：有些品类授权出去（优衣库服饰、华为快闪），有些自己做（麻将、香炉、甜品品牌 POP BAKERY）。下半年的跨界联名密集爆发，正是这一逻辑的第一次成建制落地——把一个 IP 卖给服饰消费者、KPOP 粉丝、潮牌玩家、数码用户，本质是用设计资产摊薄单一品类的风险。公司同时明确「去年高速增长时注重 IP 或热款运营，回归正常经营本质，会深化至全品类，细化到 SKU 经营」。

顶层是「做减法」的克制。与扩张同样显眼的是收缩：LABUBU 最火的时候，王宁选择暂停大量联名和新品，理由是「泡泡玛特还不是大众消费品，服务不了全世界那么多人，与其透支 IP，不如先把核心用户体验做好」。他甚至拒绝用电影明星的框架理解自己的 IP，与索尼合作的 Labubu 电影，目标不是票房，而是用电影工业为乐园、音乐、价值观「集中产出优质元素」。

三层逻辑都自洽，唯一的裂缝在产品本身：四只耳朵的争议暴露了主 IP 设计语言的边际创新递减。王宁说「每一代销售数字都很好」，但销售数字好靠的是渠道密度、会员基数和 IP 惯性，未必是设计突破。对泡泡玛特来说，好设计的标准从来不是「不丑」，而是「值得为它建一套世界观」。

六、展望：从爆款引擎到 SKU 工厂，2027 的三个观察点

站在 11 月底看 2027，泡泡玛特的故事已经从「一个 IP 能涨多快」切换成「一台工厂能培育多少个成熟 IP」。三个观察点值得追踪：

其一，星星人的接棒成色。上半年 26.5 亿、同比 +580.6%，已经成为事实上的第二引擎；毛绒品类整体 98.2 亿、+60%，占集团收入 57%。但毛绒是这一轮泡沫的重灾区——星星人「美味时刻」二手均价从 359 元跌到 143.7 元。星星人能否在二级市场冷静化之后维持零售端的增长，决定了「多引擎」是真的还是 LABUBU 的镜像。全年 50 亿元是第一个里程碑。

其二，海外的二次验证。亚太 -65%—70%、美洲 -70%—75% 的降幅同样是基数与炒作退潮的叠加。司德确认 7-10 月海外已「平稳、稳步往上走」，Q4 旺季是全球分销体系（新加坡 Shopee/Lazada 大促、欧美圣诞档）的第一次大考。海外上半年收入 49.8 亿、占集团 29%，门店仅 221 家，渠道密度远未到顶，2027 年海外的看点是「从爆款分发到本地化运营」：王宁说海外运营标准要快速与国内对齐，这是组织能力的输出。

其三，品类扩张的纪律性。1999 元的麻将、2999 元的香炉、乐园新区域客流环比翻倍、夜游占比超 25%。「全品类」打开天花板的同时也在测试品牌张力。潮玩的品牌势能来自亲昵感，一旦价格带脱离玩具语境太远，情绪价值的算法就会变化。判断标准很简单：扩品类后，会员复购率是否守住 50%。

给投资者和观察者的证伪清单：①Q4 中国线上收益跌幅是否显著收窄至 -30% 以内（验证投机需求出清完毕）；②星星人全年收入能否突破 50 亿（验证第二引擎）；③主流系列隐藏款溢价能否守住 2 倍（验证「玩具溢价」地板）；④2027 年春季新品是否再现大规模首发破发（验证供给纪律）；⑤抽盒机概率核验机制是否落地（验证合规底线）。

泡沫出清不是衰败的注脚，而是成熟的前传。泡泡玛特在 2026 下半年做的事情，是用一份难看的报表换一个能撑三十年的价格体系：把定价权从黄牛手里收回来，把增长引擎从单一 IP 换成四条产品线，把价值主张从「会增值的玩具」换回「值得拆的惊喜」。二手价格崩了，但拆盒的人还在：66.5% 为惊喜感付费的用户、51.6% 的复购率、8244 万会员，才是这门生意的真实底盘。真正的风险只有一个：当市场不再为稀缺性付溢价，设计本身必须变得更好。
