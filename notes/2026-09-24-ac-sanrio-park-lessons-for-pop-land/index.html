泡泡玛特城市乐园是以IP为核心的商业生态的重要延伸。

自2023年9月在北京开园以来，泡泡玛特的城市乐园POP LAND持续优化服务体验、丰富表演内容，推出多场精彩纷呈的主题活动打造沉浸式主题场景，为粉丝及游客构建更具代入感的IP体验空间。

2026年暑期完成部分区域的设备升级，提升游客体验。园区新增更加丰富的主题区域与互动游乐设施，整体游玩体验得到显著提升。预计明年的二期项目在现有位置继续扩建乐园，打造一个更加沉浸、被IP深度包裹的主题世界，让粉丝更近距离地感受IP带来的情感互动。

北京乐园的非亲子家庭游客、非本地游客占比接近60%，并吸引了大量来自全球各地的粉丝前来打卡体验。

对标三丽鸥，泡泡玛特继续探索乐园的角色 IP和体验互动。

迪斯尼以电影和动画等内容为基础，其乐园是内容的场景化延伸，乐园的商品零售则是by product附属品。

与迪斯尼和漫威等内容驱动型IP不同，泡泡玛特的IP核心是角色（character IP）。泡泡玛特通过labubu等IP产品的销售获得成功，但缺乏丰富的内容和可玩性，这是过去面临的最大的痛点。

如果把三丽鸥（Sanrio）和泡泡玛特（POP MART）放在一起比较，会发现两者本质上都是 IP产品向体验经济迁移的案例。但路径不同，泡泡玛特以潮玩商品起家，三丽鸥则是先创造角色人格。

  • 三丽鸥：先创造 角色人格 → 粉丝文化 → 主题乐园 → 全球授权生态
  • 泡泡玛特：先创造 潮玩消费 → IP资产 → 线下门店体验 → 乐园和电影加持内容生态

三丽鸥用了几十年证明：乐园是把IP从商品升级为粉丝互动的场地，从IP产品向体验经济迁移，这正是泡泡玛特未来最值得借鉴的地方。

三丽鸥乐园的核心商业逻辑：不仅仅是游乐园，而是Hello Kitty体验中心

来源：作者

三丽鸥品牌重塑，授权业务和乐园生意都爆发出旺盛的生命力。

2020年7月，时年31岁的辻朋邦临危受命，成为二代社长，开启了三丽鸥的第二次创业。

三丽鸥管理层提出全球IP平台战略，以三丽鸥时代为核心方针，最大化IP对用户的陪伴时长，推动图像、商品、联名、渠道、乐园、影视游戏协同营销，开启了一场彻底的变革。

三丽鸥旗下主要乐园有两家，全室内的Sanrio Puroland彩虹乐园，和户外的Sanrio Harmonyland和谐乐园。三丽鸥乐园最大的特点：游客不是为了玩设施而来，而是为了进入一个自己喜欢的角色世界。这与迪斯尼类似，但三丽鸥更轻资产、更依赖角色情感。

最近三年，三丽鸥乐园业务的收入持续双位数增长，2026财年已经达到日本市场收入的12-13%，在访客数量和人均消费的双轮驱动下持续增长。从乐园的人均消费来看，Puroland的客单价（人均消费额）在27财年1季度达到9,300日元（约合人民币400元），同比增长9%，乐园的人均消费达到普通零售店的3-4倍。1季度（今年4-6月份）的入园人数同比增长6%达到37万人次。

泡泡玛特的城市乐园在占地规模，收入和客流都在接近三丽鸥的彩虹乐园。popland占地4万方，二期还在扩建，作者估计POP LAND今年收入在5-6亿元，年客流140万人次，收入和客流等运营指标都在接近三丽鸥的彩虹乐园。

三丽鸥乐园最值得POP LAND学习的四个能力：IP人格，粉丝互动，限定经济，客户运营。

1. 从“IP形象”到“IP人格”

三丽鸥做对的第一件事：它没有把 Hello Kitty 当成一个猫形Logo。而是创造性格、朋友关系、家庭背景、日常故事、情绪价值。Hello Kitty不是“一个红蝴蝶结的猫”，而是：一个温柔、友善、没有攻击性的朋友。因此消费者购买的不只是产品，而是在购买一种情绪身份。

泡泡玛特的短板：很多IP强视觉，但弱故事。未来泡泡玛特的乐园不能只是这里有一个巨大LABUBU，而应该变成LABUBU的生活场景，朋友和家人，每天发生的事情。

来源：作者

2. 三丽鸥把乐园变成粉丝朝圣地

传统乐园的游玩逻辑是从游客入园 → 游玩娱乐项目 → 离开。

三丽鸥乐园的逻辑是游客与三丽鸥的角色在乐园相遇 → 情感增强 → 收藏消费 → 再次回来。比如，游客去Puroland的核心体验包括：和Hello Kitty合影、看角色演出、买限定商品、参加生日活动，而不是传统游乐园体验的过山车和海盗船。

对泡泡玛特的启示：POP LAND需要平衡粉丝情绪归属和大众化娱乐（嘉年华二次消费），比如降低设备投入，因为它无法和迪斯尼和环球影城竞争大型游乐设备。泡泡玛特乐园的真正的价值在于提供了潮玩粉丝见偶像的地方，类似演唱会和歌迷见面会，应该重点打造LABUBU和众多IP粉丝见面的现场。

3. 三丽鸥最强资产：限定经济

三丽鸥几十年来一直制造各种限定。地区限定、节日限定、联名限定、生日限定，粉丝形成了一生必须去一次，否则错过的限定经济。

泡泡玛特的盲盒商业模式天然适合限定经济。如果乐园产生LABUBU限定版本：森林版本、城堡守护者版本、夜光版本，那么，消费者可能第一次喜欢LABUBU，第二次为了限定回来，第三次收藏完整系列。这就是从乐园客流升级到IP收藏经济。

4. 三丽鸥的女性和年轻消费者运营

三丽鸥长期核心用户是女性消费者，除了单纯的产品功能，Hello Kitty包含可爱、陪伴、自我表达等情绪价值。

泡泡玛特的用户与三丽鸥高度类似，核心消费者是18-34岁女性。所以泡泡玛特乐园不应该完全复制迪斯尼儿童家庭的合家欢模型，更应该发展成年人的童话体验，例如：闺蜜旅行、情侣约会、独自疗愈、社交媒体打卡等消费场景。这点从客群结构就能看出来，泡泡玛 特乐园的非亲子家庭游客占比达59%，非本地游客占比为58%。

泡泡玛特乐园业务的机遇与陷阱

很多人会误解泡泡玛特做乐园，是为了卖门票。实际上，乐园更大的价值是IP孵化器。

三丽鸥的生态系统搭建了50年：从潮玩产品→ 消费者喜欢角色→ 乐园建立情感连接 → 角色人格化 → 影视/游戏/授权 → 全球IP生态。泡泡玛特正在学习三丽鸥前20年的阶段。

泡泡玛特需要避免的3个陷阱。

Ø  陷阱1：不要成为网红打卡园。短期LABUBU的火爆带来大量游客，但长期必须要确保IP角色的持续成长，才能形成复购和多次入园。

Ø  陷阱2：IP数量不要太多，故事不能太少。泡泡玛特IP很多，但乐园需要主角。迪斯尼的主角是米奇，三丽鸥的主角是Hello Kitty，泡泡玛特的主角是LABUBU，未来需要形成IP矩阵的角色宇宙。

Ø  陷阱3：不能只卖商品。乐园的价值不是让游客购买一个玩偶，而是让游客产生喜欢这个角色。商品的零售只是乐园的副产品。

借鉴三丽鸥，泡泡玛特有望成为全球IP品牌的运营公司

泡泡玛特乐园真正的战略意义，是帮助 LABUBU、MOLLY、DIMOO 从潮玩角色进化为中国原创文化IP。

如果泡泡玛特的乐园战略能够成功，它未来竞争的不是传统玩具公司，而是三丽鸥、迪斯尼、任天堂这一类全球IP资产的运营公司。三丽鸥给泡泡玛特最大的启示不是建一个更大的乐园，而是把IP从一个可以买卖的商品，变成一个消费者愿意陪伴十年的朋友。
