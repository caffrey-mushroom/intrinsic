  2. MAIA 300原计划2027日历年出货30-60万颗，若NV出现缺口可上调至60-80万颗，并计划在2027年年中提前对外销售上万颗规模。
  3. 美国本土DC建设从0到1新建转向已有DC扩容，新建审批周期预计延长至少一半，扩张重点转向北欧、南欧及马来西亚、印尼。
  4. 公司对Neocloud的战略重要性正在降级，认为中期不可持续；OpenAI、Anthropic希望将NV卡占比从80%以上降至40%，但砍半可能性不大。
  5. F1Q27 Azure ALL收入332亿美元，2026年目标约1,500亿美元（增长44-50%）；Azure AI中圈约70多亿，其中MaaS约30亿、开源模型占约14-15%。
  6. OpenAI一季度为公司贡献约100亿美元收入，Azure占OpenAI云底层80%多。

【以下为专家观点汇总，具体细节仅供参考。】

从A公司的角度怎么看黄仁勋卸任后带来的影响？

最近这两天市场上各种传闻不断，包括黄仁勋可能会回归等消息，虽然不能说完全没有这种可能，但个人认为概率并不大。实际上，A公司CEO也曾与黄仁勋沟通过，向他抛出橄榄枝，但黄仁勋本人对民主党背后的几家大金主存在一定抵触情绪，因此他并不太愿意回到民主党阵营。与此同时，小马那边这两天也有消息传出，众参院的朋友认为下一个要处理的就是他，这让黄仁勋对自身情况感到担忧。黄仁勋是否回归，最直接的决定因素还是即将发布的财报。如果股价跌得太惨，市值受到影响，不排除会有相关动作。但目前来看，整体概率还是偏低，黄仁勋大概率不会回归。

最近Intel的CEO也被股东起诉，这反映出当前圈子的整体状态。民主党全赢后，对红党原本支持的企业以及华裔企业进行大清洗。站在A公司的角度，蓝党全赢反而是利好，因为A公司的核心元老都是铁杆民主党人，A公司也是民主党的主要金主之一。因此，政策层面会有一些调整。比如最近办公室会议讨论的DC建设规划周期和战略调整，北美的DC新建优先级被往后排，战略重点转向已有DC的扩容，也就是1到99的扩容。审批流程方面，0到1新建涉及土地环评、电力布局等，周期预计比之前至少长一半。整体来看，美国本土DC建设由原来的0~1新建转为1~99扩容，这是第一点。

从A公司对NV卡采购层面的影响来看会有多大影响？

回到黄仁勋下课前NV的卡在A公司算力池中的占比在87%~88%。随着黄仁勋下课，预计对于NV已经签订的合同，无论是B300、GB300还是Rubin，逻辑上判定影响不大。但在明年（2027年）日历年，也就是H2，可能会有一些变化，比如NV新的CEO上台，是否由民主党扶持，以及民主党收紧政策的态度和抗压能力，再包括其他卡商、CSP或frontier lab拿卡的节奏。如果按照相对悲观的预期，可能明年NV的比重会降到84%~85%，影响幅度大约是3%。

这3%左右掉下来的部分，第一点多会分给MAIA 300。据悉A公司近期希望推动MAIA 300尽快落地。剩下的1%点多可能会挪给neocloud，还有一部分可能会补给AMD。预计黄仁勋下课对NV供给A公司的卡的影响不大。所谓影响不大，就是预算和卡的供给节奏有保障。但会产生一些变数，比如拿卡的cadence，原本三季度的高峰期可能因为新CEO上任需要重新谈判，节奏可能挪到四季度。原来已经锁定的LTA价格基本不会大幅变动，锁定到明年（2027年）二季度。但F28如果新CEO上任，无论是CFO接任还是外部空降，下一轮谈Rubin的单价、节奏和供给量可能会有影响，因为之前和黄仁勋有明确的出牌逻辑和底线，新CEO需要重新摸底。

目前对MAIA 300的上量节奏和明年的规模预期的更新？

主要是MAIA 300以及明年（2027年）开始的MAIA 400。从产品技术能力来看，MAIA 300在模型训练能力上，相比Rubin和主流B300还是略弱一些。MAIA 300主打点是底层基于Azure架构，贯穿性较好，能支撑自有和第三方模型，主要追求Token生成效率，在M365 Copilot等推理侧应用上有明显降本和效率提升。MAIA 300原计划是明年（2027年）开始走量，年初需要完成集群化测试和部署，集群规模要达到万颗以上。原定明年（2027年）日历年涵盖F27的H2和F28的H1，MAIA 300的量应该在30-60万颗之间。如果NV家出现3%的gap，MAIA承接的量可能会动态上调到60-80万颗。

目前MAIA 300还有一个较大的依赖，就是与OpenAI和Anthropic两家最大的frontier lab的关系。毫无疑问，和Anthropic走得更近。OpenAI分手后A公司一直在推Anthropic考虑采购MAIA 300。Anthropic表示会考虑，并要求加快集群化测试和部署周期，并需要万颗以上集成化测试报告和评估，作为与NV及其他家（如博通、AMD等）的对比依据。

MAIA300外售的时点是否会提前？

如果仅按照原来的既定roadmap来看，逻辑上其实MAIA 300在明年（2027年）的日历年，至少在年底之前，不会大规模向外销售，因为内部还需要进一步打磨。本来的计划是希望MAIA 400能够形成类似Google那边TPU的逻辑，完全对外销售。但由于内部现在处于紧俏期，尤其是NV黄仁勋下课带来的市场波动，以及可能出现的一些gap。据悉最近A公司管理层一直在推动整个hardware团队，加快MAIA 300的市场化，也就是对外租用、销售的正式能力周期要进一步缩短。目前提及的目标是希望在明年（2027年）年中，也就是F27年底，MAIA 300能够向外销售，而且量级不是几千颗，而是上万颗的逻辑进行推广。

中期选举后A公司对neocloud的依赖是否会发生显著变化？

A公司内部对于neocloud整体租用算力的战略高度和重要性，从最近一个月的观察来看基本都在往降级方向走。Neocloud模式短期没问题，但中期来看，个人不认为它是可持续的。将来算力和AI最终还是会合并到几家巨头手里，不会分散得像现在这样。Neocloud也会分一杯羹，但可能最后只剩一两家，预计趋势都是收缩。

有说法OpenAI和Anthropic在削减对英伟达GPU的需求？靠谱？

关于OpenAI和Anthropic削减NV卡的消息，个人认为有些夸大。原先OpenAI、Anthropic这些frontier lab的NV卡占整体80%以上，现在他们希望降到40%。剩下的份额则由博通、Google TPU、AMD以及AWS等分担。虽然其他加速卡厂商都在追赶，但从效能和功能性来看，至少在未来一年内，其他厂商很难追上NV的GPU。除非出现复合作用，比如民主党全赢后收紧AI扩张和建设节奏，这可能为其他厂商带来机会期。但整体来看，NV砍半的可能性不大，虽然肯定会丢一些份额，这是大概率会发生的情况。

中期选举后A公司是否会加速欧洲和东南亚等区域的算力布局？

由于A公司对北美从0到1类新建项目开始收紧，中心转向扩容，预计算力短缺问题进一步凸显。此前的地理扩张优先级重新提升，主要扩展区域集中在欧洲，尤其是北欧和南欧。西欧因俄乌战争导致电力不足，不适合扩容。亚太方面，除了澳新、日本、印度等亲美发达国家，扩容按原计划推进，当前重点主要放在东南亚。东南亚目前的关注点主要集中在马来西亚和印尼，而新加坡和泰国的情况则随着民主党可能进一步大规模调查而发生变化。

F1Q27 Azure整体收入拆分和今年（2026年）的增长预期？以及毛利情况如何？

首先，按照逻辑，F27年Q1，A公司所有AI产品收入包括今年（2026年）的最新目标。Azure依旧按照之前的逻辑，分为三个圈层：大圈、中圈、小圈。最大圈是Azure ALL，包含传统IaaS（网络计算存储）、PaaS（数据池、数据湖、数据分析、高阶云安全、混合多云）以及中圈Azure AI。一季度Azure ALL按照新财报口径已披露332亿，其中AS占47%，Azure AI占22%，PaaS约占30%。今年（2026年）的目标进一步上调，去年（2025年）全年1020亿，底线目标今年要增长44%~45%，努力目标是49%~50%，即今年目标在1500亿左右。需要强调的是，OpenAI的收入不计入Azure中圈（Azure AI），而是归入IaaS和PaaS。OpenAI租用的不只是云算力，还包括混合多云、高级云安全、数据分析、数据池、数据湖等PaaS层面。

Azure中圈今年（2026年）一季度收入约70多亿，分为四大类别：第一，MaaS（API TOKEN）约30亿；第二，Machine Learning and Other Services（工具链、调用链及其他服务）约10亿多；第三，Other AI（2023年AGI时代前的AI，如大数据认知识别等）约7亿；剩下的20多亿是GPU租赁、裸金属、H或A代卡租给其他B级客户。Azure中圈今年的目标是占最大圈1500亿的22%~23%，一季度达标，进一步目标是24%~25%。

OpenAI今年（2026年）一季度为A公司贡献了100亿收入，其中十几亿来自实际收入分成。现在不能简单按20%的分成比例倒推OpenAI上一季度实际收入，因为A公司不是OpenAI唯一的云服务提供商。目前A公司的Azure占OpenAI云底层的80%多，10%多是AWS Bedrock，剩下的80多亿是其他收入贡献。进一步说一下开源模型的占比。去年（2025年）一年，F26整体的MaaS API token这个小圈，开源模型占到差不多10%左右。今年（2026年）一季度，开源模型基本上占到整个30亿中的14%多，约14-15%。如果从单季度占比来看，确实有所提升。但一季度的数字较小，基数30亿其实也并不大。

怎么看北美企业客户减少国产开原模型使用趋势的可能？

据观察，美国本土的几家巨大型的S500大客户的C-level（CSO、CTO、CIO、CEO）对于中国开源模型的策略是：可以适度使用，但对于企业内部的核心数据、高等级保密数据以及自有IP相关的数据，绝不会用中国的开源模型。原因有两个：第一，他们默认认为中国的开源模型不安全，这也是为什么愿意通过Azure Foundry购买A公司的服务。虽然价格比OpenAI贵，但A公司提供全套的信息安全、网络安全和治理，以及合同明确规定不能调用、调取、上传、下载生成数据。如果发现违规会赔偿。第二，核心原因是现在另外一只靴子已经悬在半空，已经落了一点。对于美国本土所有G级和B级客户，有可能会对中国所有开源模型一刀切。如果这只靴子完整落地，中国开源模型在美国本土企业就无法使用了。

最近，包括美国联邦政府及相关机构，已经对kimi这一类中国开源模型禁止接入。如果之前红党、蓝党各占一院，这只靴子落地的速度会缓和一些，因为Trump会把它作为与中国谈判的筹码。但现在整个国会，包括众参院全输掉，有可能明年（2027年）上半年对Trump那边会有动作。所以在这个层面上，这只靴子落地的速度可能会加快，但按我的分析，中美关系的博弈周期不会完全断，可能会通过加快黑名单、切片的方式推进切割。

财季Q1各Copilot的表现和全年目标？Token消耗收费的提升节奏？

与之平行的是各个Copilot。M365 Copilot在今年（2026年）一季度做了30亿多一点。今年（2026年）全年目标还是定在130亿，但前两周我去伦敦开会时有一些讨论，主要是130亿可能会扩或有所调整。原来按照cadence roadmap，至少到明年（2027年）底之前，M365 Copilot对B级客户还是单一seat收费方式，复合收费方式（seat加API token）可能在2028年才会出现。但现在，预期复合收费方式的节奏周期提前，有可能在2027年中期就开始。因此今年（2026年）的收入可能会受到影响，但目前还是130亿左右的目标。

去年（2025年）M365 Copilot基本是70多亿，增长率至少七八十%。与M365 Copilot平行的还有D365 Copilot（ERP、CRM），一季度差不多3亿，再往下是GitHub Copilot（AI coding），一季度做了6亿，再往下是Security Copilot（云安全合规、红旗预警），一季度做了接近4亿。

怎么判断A公司今年保持正自有现金流的风险？

无论对外还是对内一直强调，今年（2026年）的FCF现金流可以持正。最主要原因是A公司云收入绝大多数比例依旧来源于高利润的云产品，而AI只是云的一部分，类似于2020年疫情黑天鹅元年TEAMS的打法，以AI作为引子让B级大客户进一步在Azure或各个Copilot、SaaS角度续约，增强客户粘性，使高毛利、高利润的PaaS、SaaS本体进一步扩充。这才是核心打法，也就是回到Satya反复强调的那句话：AI is just part of cloud。
