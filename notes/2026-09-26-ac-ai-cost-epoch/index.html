原标题：AI成本降了1000倍，下一轮AI交易靠什么？ ——Epoch测出了旧能力的降价，市场在等待新能力带来多少真实收入

#ai-demand #llm

AceCamp · 2026-09-26 13:47 · 研究文章 · article 70567514

摘要

固定能力的最低成本降得很快，不等于全市场每个 Token 都降了同样的价。 牌价、使用加权价格和公司平均售价，分母不同，走势可以不同。 模型收入看实际发生了多少任务、每项任务有多长，以及每个 Token 卖多少钱。

正文

我们最近同时看到三组看似打架的数据：Epoch 说 AI 是人类历史上成本下降最快的技术；与此同时前沿模型仍能卖出高价，智谱甚至披露 API 平均售价上升；模型公司的收入又在快速增长。三组数据可以同时成立。问题出在相当一部分解读把“达到某种能力需要多少钱”“市场平均每个 Token 卖多少钱”和“客户最终愿意为一项工作付多少钱”当成了同一件事。

一 Epoch到底测量了什么

图 1 Epoch 比较的是在固定测试成绩下能够达到要求的最低成本。AI 曲线 2021—2023 年部分包含外推。来源：Epoch AI。

Epoch 的问题是：给定一张考卷和一个目标分数，当时有哪些模型和推理设置能达到要求，其中最便宜的方案要花多少钱？按它的估算，2025 年的 o3 在 GPQA Diamond 上达到目标水平，每题约需 0.30 美元；不到 18 个月后，GPT-5.6 Luna 达到同一分数门槛，每题约需 0.0004 美元，约为原来的 1/725。横跨五项基准，自 2023 年以来固定分数的最低实现成本平均每季度下降约 47%。

这个结果有价值，但“固定分数”不能直接翻译为“固定商品”。两次测试使用各自历史时点的价格，允许换模型、换推理强度，账单同时受每 Token 价格与完成题目所需 Token 数量影响。客户今天继续购买 o3 或新旗舰，也不会自动享受到那个最便宜的达标组合。何况科学选择题同分，并不保证两款模型能以同样的可靠性完成编程、长时间调用工具或企业工作流。

电池价格按每千瓦时容量计算，有相对稳定的物理分母。AI 的“75% 测试分数”是刻意固定的一条能力切片；今年模型能完成更复杂、更长、过去根本做不了的任务，这部分增量不会出现在那条固定分数的曲线上。它能说明旧能力迅速普及，却不能告诉我们整个 AI 市场正在卖什么。

二 我们真正要跟踪的三种价格

先看牌价。同一款模型、同一计费方式，价格可能下降；新一代强模型仍可能卖得更贵。Anthropic 最近推出的 Opus 5.5，输入和输出牌价分别比 Opus 5 低 20%，并称典型任务账单降低约 40%。这说明前沿也在降本，但幅度与 Epoch 那条跨模型、固定测试分数的曲线完全不是同一个指标。

把视野从单款旗舰放宽，杰富瑞根据 Artificial Analysis 数据整理了中美模型的季度输入、输出报价：从 2025 年第二季度到 2026 年第二季度，图中的中国模型两端价格上行，美国模型两端价格较去年同期略低，中间季度还有明显波动。价格没有一条所有市场和所有产品都同步向下的直线。

图 2 中国和美国模型的季度输入、输出价格，单位：美元／百万 Token。来源：杰富瑞图表，底层价格数据：Artificial Analysis；截图未列模型样本与季度加权方法。

再看成交结构。智谱在 2026 年中期公告披露，截至 8 月 31 日，其 MaaS 平台 Token 调用量较年初超过 40 倍，同期 API 平均售价上涨约 101%。这项“平均售价”是公司口径；公告没有把每个型号、输入输出、客户合同的权重完全摊开。因此解读是对于智谱整体而言，旗下模型的平均售价上涨101%。

最后看 Silicon Data 的 LLM Token Expenditure Index。它把所观察到的渠道用量与相关价格合在一起，估计每百万 Token 的使用加权价格。指数从 5 月 28 日的 2.07 美元降到 9 月 23 日的 0.96 美元，跌幅约 54%；但今年年初到 5 月高点曾上涨约 67%。它记录了样本中产品组合向便宜模型迁移的影响，既不是旧能力的最低达标成本，也不是 OpenAI、Anthropic、智谱或 Google 全渠道的实际收入除以实际销售 Token。

这才是我们对“Token 有没有降价”的回答：旧能力的最低成本降得非常快；一些旗舰型号也在降价；使用加权的市场价格会随模型组合上上下下；个别公司的实际平均售价还可能上升。几件事发生在不同的分母上。

三 收入要按任务求和

把任务分成不同类型 i。对按量计费的模型 API，真正的收入不是拿 Epoch 的旧任务降本倍数乘上全行业 Token，而是逐类任务计算后相加： 模型 API 收入 R = ∑ᵢ（任务数 Nᵢ × 每项任务计费 Token Lᵢ × 实际混合单价 Pᵢ） Nᵢ 是实际付费发生的次数；Lᵢ 是一次任务中所有步骤的计费 Token；Pᵢ 是该类任务的实际平均每 Token 收入，已反映所选模型、输入输出、缓存和合同折扣。

先看任务数 Nᵢ。旧的线上问答、摘要越来越便宜，笔者并不否认这一点。但成本下降和可靠性提高会让一批原本不值得交给 AI 的工作开始发生。过去整理一堆文书可能要花两小时；如果 AI 现在能用几分钟可靠地做完，用户就有理由付费。更大的变化是，过去很多人嫌麻烦，干脆不整理；现在这项工作也可能开始发生。成本下降带来的不只是旧任务多做几次，还有原本没有的任务从零开始出现。

再看每项任务的长度 Lᵢ。模型总结同一份文件所需成本在下降，但客户的要求会从“总结一下”变成“读完整个资料库、核对信息、做出决定、写完材料并执行下一步”。原来的一次调用可能延伸成几十次调用，前沿模型还能接下去年无法交付的更长任务。

最后看任务组合与 Pᵢ。简单的提取和路由可以由便宜模型完成，关键判断交给更强的模型。于是旧任务、简单步骤的每 Token 售价下行，与新任务、高价值步骤维持更高价格可以同时发生。整体混合价可能下降，也可能因为客户转向更高价值的工作而上升。我们需要追的是每类任务的 Nᵢ、Lᵢ、Pᵢ 如何变化，而不是拿一个旧任务的最低成本替整片市场定价。

四 旧能力降价以后 新工作从哪里来

这个框架也解释了 AI 交易为什么会在七月到九月阶段性冷下来。过去编码助手持续拓宽可做的任务，市场看到的不只是写一段代码更便宜，而是越来越多软件工作能被交付。但随着Anthropic的ARR开始放缓或者说没有超出市场预期，以及一段时间里 coding 的进展主要体现为旧能力降本，新任务没有明显出现，市场自然会开始对AI交易表现得更为谨慎。这不是技术进步停了，而是投资者暂时还看不到新一批客户会把什么工作交给 AI。下一步是RSI，还是AI4S，技术上都有进步，市场的争论也非常大。

而Meta 近期推出 Muse，提供了一个很具体的新方向：让个人代理跨应用处理邮件、行程、网页表单和购买等事务，用户提出的是目标，而不只是一句问答。如果个人代理能够稳定完成这些工作，原来没有被模型计入的日常事务会变成新的任务类型，单项任务也会包含更长的操作链。Muse 当前的留存、付费与单位经济仍要继续观察；它带来的交易热度，首先反映的是市场重新看到任务边界扩张的可能，C端Agent被认为可能是潜在接棒coding的下一个Nᵢ 场景。

所以，“AI 成本下降 1000 倍”与“AI 市场还在增长”本来就不矛盾。前一句讲旧能力在固定测试上的最低实现成本，后一句要把社会上实际发生的各类任务逐项求和：哪些工作变得可做，做一次需要多少步骤，最终创造了多少价值，以及谁从中收到了钱。旧能力降价让更多任务越过可用门槛；新能力又把任务推向更长、更难的地方。AI 的增长如果继续成立，需要由这些新工作及其付费来验证，而不需要一个包打天下的 Token 单价故事。

数据核验截至 2026 年 9 月 25 日。以上为个人分享内容，仅供参考，不构成任何投资建议。
