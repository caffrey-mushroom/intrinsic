1. 服务器业务收入与出货拆分

a) 2026年前三季度服务器业务收入表现如何？

  • 服务器业务按照通用服务器、AI服务器和超节点（整机柜）进行拆分。
  • 按出货匹配口径统计：
  1. 2026年Q1收入为82.1亿元。
  2. Q2收入为104.2亿元。
  3. Q3收入为94.4亿元，环比下降约9.4%。
  4. 前三季度累计收入为280.7亿元。
  • 2026年全年服务器收入目标约为360亿元，该目标于上半年结束后重新核定，预计可以完成。
  • 按全年360亿元目标测算，Q4需实现约79.3亿元收入。
  • 受访者表示，360亿元按可与实际出货量匹配的出货口径统计，与到账金额、签约合同金额及年报披露口径可能存在明显差异。

b) 通用服务器收入和出货量如何变化？

  • 通用服务器收入情况：
  1. Q1收入49.3亿元，占服务器业务收入的60%。
  2. Q2收入57.3亿元，占比55%。
  3. Q3收入49.9亿元，占比52.9%。
  4. 前三季度累计收入156.5亿元，占服务器业务收入的55.7%。
  • 通用服务器出货量情况：
  1. Q1出货13.5万台。
  2. Q2出货15.8万台。
  3. Q3出货14.6万台。
  4. 前三季度累计出货43.9万台。
  • Q3通用服务器收入和出货量均较Q2下降，收入占比也呈逐季下行趋势。
  • 通用服务器均价逐季下降，主要原因包括：
  1. CPU涨价向下游价格的传导存在滞后。
  2. 服务器市场价格竞争依然激烈。
  3. 产品结构持续向AI服务器和超节点倾斜。

c) AI服务器收入和出货情况如何？

  • 本次AI服务器数据不包含超节点，以避免重复统计。
  • AI服务器收入情况：
  1. Q1收入30.8亿元，占比37.5%。
  2. Q2收入42.7亿元，占比41%。
  3. Q3收入39.9亿元，占比42.3%。
  4. 前三季度累计收入113.4亿元。
  • AI服务器出货量情况：
  1. Q1出货1.2万台。
  2. Q2出货1.7万台。
  3. Q3出货1.6万台。
  4. 前三季度累计出货4.5万台。
  • 虽然Q3收入和出货量环比略有下降，但AI服务器收入占比由Q1的37.5%提升至Q3的42.3%，服务器产品结构仍在持续升级。

d) 超节点业务收入和出货量如何？

  • 超节点即整机柜业务，收入情况为：
  1. Q1收入2亿元，占服务器收入的2.5%。
  2. Q2收入4.2亿元，占比4%。
  3. Q3收入4.6亿元，占比4.9%。
  4. 前三季度累计收入10.8亿元，平均占比约3.8%。
  • 超节点出货量情况为：
  1. Q1出货70柜。
  2. Q2出货145柜。
  3. Q3出货150柜。
  4. 前三季度累计出货365柜。
  • 超节点是目前增速最快的服务器细分业务：
  1. 前三季度同比增速超过180%。
  2. Q3单季度同比增速超过200%。
  • 但超节点收入与出货柜数倒算出的单柜均价仅约270万—290万元，与市场常见的高卡数超节点价格不匹配。
  • 受访者初步判断，数据明细中可能存在空值或漏算，导致出货柜数、收入或单柜价值出现偏差，相关数据需要重新核验。

e) 2025年与2026年服务器收入为何难以直接比较？

  • 2026年360亿元目标采用的是可与出货量匹配的出货口径，通常低于到账口径或签约合同口径。
  • 长周期合同可能一次签订较大金额，但实际备货、交付和收入确认分多年完成，因此不同统计口径之间存在差值。
  • 若按收到款项等更宽口径计算，受访者预计数据可能比出货口径高15%—20%。
  • 对于2025年服务器收入接近490亿元、2026年目标360亿元是否意味着同比下滑，受访者暂未给出确定结论，主要原因是：
  1. 尚未核对2025年年报数据。
  2. 需确认490亿元究竟属于营收、到账、签约金额还是其他口径。
  3. 需在统一统计口径后重新进行同比测算。

2. 交换机业务表现与Q3环比下滑原因

a) 交换机业务采用什么统计口径？

  • 本次交换机业务仅统计设备本体收入，不包含光模块、软件许可和服务收入。
  • 产品按照端口速率拆分为两类：
  1. 400G及以上：所有端口速率大于或等于400G的数据中心交换机。
  2. 200G及以下：包括企业网交换机、园区网交换机，以及100G、25G等数据中心交换机。

b) 交换机收入如何拆分？

  • 交换机总收入：
  1. Q1为67.5亿元。
  2. Q2为83.4亿元。
  3. Q3为76.2亿元，环比下降约8.6%。
  4. 前三季度累计227.1亿元。
  • 400G及以上交换机收入：
  1. Q1为15.8亿元。
  2. Q2为22.1亿元。
  3. Q3为21.6亿元。
  4. 前三季度累计59.5亿元。
  • 200G及以下交换机收入：
  1. Q1为51.6亿元。
  2. Q2为61.3亿元。
  3. Q3为54.6亿元。
  4. 前三季度累计167.6亿元。
  • 400G及以上交换机收入占比逐季提升，反映数据中心交换机高端化趋势仍然明确。

c) 交换机出货量如何变化？

  • 400G及以上交换机出货量：
  1. Q1为2.1万台。
  2. Q2为2.8万台。
  3. Q3为2.9万台。
  4. 前三季度累计7.8万台。
  • 200G及以下交换机出货量：
  1. Q1为185万台。
  2. Q2为215万台。
  3. Q3为198万台。
  4. 前三季度累计598万台。
  • Q3的400G及以上交换机出货量环比略有增长，但收入环比小幅下降，显示平均销售价格和产品组合可能承受一定压力。

d) Q3交换机收入环比下降的主要原因是什么？

  • 第一，政企项目具有明显的季节性交付特征：
  1. Q2部分政企项目交付有所前置，因此Q2基数较高。
  2. Q3部分项目虽已完成货物交付，但收货确认和款项支付移至Q4，相关收入尚未计入Q3。
  • 第二，400G和200G交换机均面临明显价格竞争，对产品均价和整体毛利率造成压力。
  • 第三，本次统计仅包含设备本体：
  1. 若将光模块、软件及整体解决方案收入纳入，400G及以上方案收入会明显提高。
  2. 交换机数据对统计口径较为敏感，口径变化会导致收入规模快速变化。
  • 整体来看，Q3交换机业务并非需求趋势转弱，更多受到项目确认节奏、政企交付季节性和价格竞争影响。

e) Q3是否出现400G交换机市场份额流失？

  • 根据内部团队初步反馈，公司400G交换机市场份额整体基本持平，没有实现特别明显的份额扩张。
  • 不排除市场份额缓慢下降的可能，但概率较低，目前尚未取得可量化的最新份额数据。
  • 受访者认为，Q3业绩不及预期的主要矛盾仍是收入确认节奏和价格竞争，而非明显的市场份额流失。

3. 存储业务及低价库存影响

a) 存储业务收入和出货情况如何？

  • 存储业务采用广义口径，包括存储硬件、软件许可和技术服务。
  • 存储业务总收入：
  1. Q1为17.2亿元。
  2. Q2为22.8亿元。
  3. Q3为21.5亿元，环比下降约5.7%。
  4. 前三季度累计61.5亿元。
  • 存储硬件收入：
  1. Q1为12.4亿元，占存储业务收入的72.1%。
  2. Q2为16.3亿元，占比71.5%。
  3. Q3为15.3亿元，占比71.2%。
  4. 前三季度累计44亿元。
  • 存储硬件主要为存储服务器，同时包括部分其他小型硬件，具体构成仍需进一步确认。
  • 总出货量分别为Q1的1.05、Q2的1.42和Q3的1.35，但访谈中未明确该指标的具体单位，需后续核验。

b) 低价存储库存还剩多少？

  • 低价库存主要指公司在2023年至2025年存储周期底部采购的HDD和SSD，其中以QLC SSD及大容量HDD为主。
  • 低价库存变化情况：
  1. Q1末剩余成本额为13亿多元，对应约8—9个月销量。
  2. Q2末剩余成本额接近5亿元，对应不足3个月销量。
  3. Q3末剩余成本额约1.5亿—1.7亿元，对应约1个月至不足1.5个月销量。
  • 到Q3末，历史低价库存已经基本消化完毕。
  • 公司正常需要保留约2个月的安全库存，而Q3末库存已低于正常周转水平，因此剩余库存已不能简单视为待清理的低价库存。

c) 低价库存为何没有带动Q3利润进一步提升？

  • Q3存储业务的主要制约并非产品售价，而是库存不足导致供货量受限：
  1. Q2出货量为1.42，Q3降至1.35。
  2. 存储产品价格略有上涨，因此收入降幅小于出货量降幅。
  3. 随着低价库存快速下降，公司为维持安全库存水平，后期主动或被动收紧了供给。
  • 到Q3最后一个月，库存已接近或低于正常安全水平，继续扩大供货将导致库存不足，因此Q3出货未能进一步提升。
  • 受访者表示，10月份存储业务供货量预计也相对较少。
  • 公司计划在Q4采购新库存，由于存储价格处于上行阶段，后续采购成本压力可能明显增加。
  • 因此，低价库存对单台利润仍有正面贡献，但其带来的利润优势被出货量下降部分抵消；随着低价库存基本耗尽，后续毛利率存在回落压力。

4. Q3利润环比下降的核心原因

a) 紫光股份Q3利润端环比下降主要由哪些因素造成？

  • 服务器业务收入环比回落：
  1. Q3服务器收入由Q2的104.2亿元下降至94.4亿元。
  2. 通用服务器和AI服务器出货量均较Q2下降。
  3. 通用服务器均价下行，CPU成本上涨的价格传导滞后。
  • 交换机业务收入确认延后：
  1. Q2部分政企项目交付前置，形成较高基数。
  2. Q3部分已交付项目的验收、收货确认和付款延至Q4。
  3. 交换机价格战加剧，对收入和毛利率形成压力。
  • 存储业务低价库存接近耗尽：
  1. Q3末低价库存仅剩约1个月左右。
  2. 为维持安全库存，公司供货量受到限制。
  3. Q4补充库存时将面临更高采购成本。
  • 产品收入结构虽持续向AI服务器、400G交换机和超节点升级，但相关高端产品的增量尚不足以完全抵消传统业务收入环比下降及价格竞争压力。
  • 此外，部分关键数据尚未经受访者完整核验，整体利润下降原因仍需结合最终毛利率、费用及收入确认明细进一步确认。

5. 各业务毛利率表现

a) 通用服务器毛利率如何变化？

  • 受访者给出的服务器毛利率数据为：
  1. Q1约12%。
  2. Q2约11%。

  • 结合后续对AI服务器和超节点毛利率的单独拆分，上述数据更可能对应通用服务器或相关服务器均值，但具体口径仍需确认。
  • 毛利率逐季下降，主要可能受到产品降价、CPU成本上涨传导滞后及市场竞争影响。

b) AI服务器和超节点毛利率如何？

  • AI服务器毛利率：
  1. Q1约10%。
  2. Q2约10%。
  3. Q3超过11%。
  • 超节点毛利率：
  1. Q1约14%。
  2. Q2约15%。
  3. Q3约17%。
  • AI服务器和超节点毛利率均高于行业部分同类业务，尤其超节点毛利率呈逐季上升趋势。
  • 超节点收入占比仍较低，因此对公司整体利润的拉动暂时有限。

c) 服务器毛利率为何高于行业平均水平？

  • 根据公司调研部门拆分，服务器行业整体毛利率均值约为8%—9%，公司毛利率约为10%以上。
  • 初步解释是公司供应链成本控制能力较强，整体成本压降水平优于行业平均。
  • 对于公司与浪潮信息约5%左右的历史服务器毛利率差异，受访者尚无法确定是客户结构、业务模式还是统计口径造成。
  • 后续需要按照相同口径重新测算浪潮服务器毛利率，才能进行有效对比。

d) 存储和交换机毛利率如何？

  • 存储业务整体毛利率：
  1. Q1为18%。
  2. Q2为19%。
  3. Q3为21%。
  • 存储业务毛利率逐季提高，主要受存储价格上涨及历史低价库存贡献影响。
  • 交换机业务毛利率尚未完成拆分，400G及以上和200G及以下产品的具体毛利率预计在后续核验后提供。
  • 尽管尚无具体数据，受访者确认400G和200G产品价格战已对Q3交换机整体毛利造成负面影响。

6. 超节点客户结构与产能规划

a) 超节点业务的主要客户有哪些？

  • 超节点客户主要分为三类：
  1. 头部互联网客户，占出货量约72%。
  2. 政企智算中心，占比约22%。
  3. 运营商，占比约5%。
  4. 其他定制化、小批量客户，占比约1%。
  • 头部互联网客户主要包括阿里巴巴、腾讯、字节跳动和百度。
  • 互联网客户合作模式包括年度框架协议和项目制交付，两种模式并行。
  • 政企智算中心主要通过项目招投标及整体交付方式开展，并由独立团队运营。
  • 运营商客户主要采取集中采购模式，同时可能开展部分试点项目。

b) 2026年和2027年超节点出货目标是多少？

  • 2026年超节点整体出货目标为580柜。
  • 公司在2026年年初制定的原始计划约为480柜，目前整体出货进度已超过原计划。
  • 2027年暂定目标为620柜，但该目标尚未结合最新需求和供应链情况更新。
  • 受访者个人预计，2027年目标可能上调至650—700柜。
  • 2027年最终出货计划将在Q4结束后重新评估。

c) 超节点出货增速为何明显低于行业需求增速？

  • 当前限制因素不是市场需求不足，而是公司自身的供应能力。
  • 现有产线和供应链条件下，650—700柜可能接近现阶段可支持的产能上限。
  • 若判断公司供应能力明显低于市场需求，公司将考虑：
  1. 提高核心零部件采购量。
  2. 重新签订供应链合同。
  3. 新增产线及配套产能。
  4. 调整整体采购和生产预算。
  • 供应链团队自8月份已开始与供应商接触，预计10月底前完成主要谈判，11月敲定2027年合同。
  • 11月底可形成大致方向，12月初预计完成内部产能与预算决策。
  • 进度相对较慢的主要原因包括：
  1. 供应商增量供给存在困难。
  2. 超节点既需要扩大供应，又需要控制成本。
  3. 市场竞争激烈，供应链合同谈判难度较高。
  4. 单一产品的需求增长不足以独立支撑扩产，需要结合公司整体采购量评估。

7. 自研交换芯片进展与自供目标

a) 自研交换芯片目前进展如何？

  • 实验验证预计于2026年Q4完成，较明确的时间点为12月，也可能延后至2027年1月。
  • 春节后预计进入真正的小批量验证阶段，验证周期约5个月。
  • 2027年上半年可能有少量产品完成小批量验证。
  • 预计到2027年H2初，基本完成小批量验证，随后正式签订合同并启动量产。
  • 若项目推进顺利，2027年可以完成大部分产能爬坡。
  • 理想目标是在2027年年底完成全部爬坡，但存在延迟至2028年Q1的可能。

b) 2027年自研交换芯片自供比例能达到多少？

  • 由于2027年下半年仅有约4—5个月用于产能爬坡，全年自供比例仍将相对有限。
