  4. 谷歌2027年OCS需求因TPU出货由2026年约400万颗翻倍至850万-1000万颗（含Anthropic 400亿美元采购合同）及TPU v9小规模导入6D Torus架构，由4万台上修至5万台以上（按约200张卡配1台300端口OCS测算）；英伟达2027年仅采购约2000台样机测试，2028年20万台Feynman（72端口、36卡配1台即单卡2端口）指引属总包订单，首年按100万-200万颗GPU实际部署约6万-7万台；目前具备万台供应能力的仅Momentum（2027年目标1.5万-2万台、占谷歌40%）与谷歌自研Celestica代工（约1.4万台且约2年后将退出自研），Coherent（5000台+）与德科立（3000-4000台）体量较小，整体供应偏紧，若Calient（320端口MEMS）通过谷歌认证将高度利好其唯一代工厂光库科技。
  5. AOI与AWS签署的20亿美元基础、最高100亿美元长期框架协议超市场预期，对应AWS 2027年超2000万只800G需求的20%-25%份额（约500万只、15亿美元），虽无预付款及违约罚款但因AWS已入股且有北美供应链诉求，履约率预计超85%（2027年Q1起北美交付、台湾主力扩产，年底目标美国本土占30%）；但AOI历史达成率极低，尽管800G出货从2026年Q2约4万只增至Q3的15万-16万只及Q4预计超40万只，相对月产65万只承诺季度达成率仅20%并已下调年底目标至50万只，受熟练工与大规模量产管理瓶颈制约，2027年底月产100万只目标仍存明显不确定性。

光通信行业专家访谈纪要

1. NPO订单、需求规模与产业节奏

1. 英伟达首批500万只NPO订单是否属实，订单性质是什么？

  • 英伟达自2026年5月起与供应商对接NPO需求，首版样品已通过测试，并据此给出首批500万只需求。
  • 500万只代表英伟达提出的总体需求量，并未明确拆分到各家供应商，也不等于2027年一次性交付500万只。
  • 该需求主要配套2027年下半年开始上量的Rubin Ultra。英伟达早期曾给出1000万只需求指引，长期总需求可能达到2500万只，后续最多还可能追加约2000万只。
  • 当前行业采购协议通常覆盖3—5年，部分需求已经谈到2031年。英伟达下单的主要目的包括：
  1. 确认NPO技术路线；
  2. 给供应链扩产信心；
  3. 推动供应商加快产品开发与产能准备；
  4. 为未来数年的交付提前锁定资源。
  • 由于NPO仍处于Beta样品测试和设计优化阶段，尚未进入正式量产版本，任何单一厂商目前都不具备年产500万只以上的成熟交付能力。

2. 英伟达500万只订单对行业的核心意义是什么？

  • 英伟达此前优先推动CPO，NPO更多被视为备选方案。此次明确下单，意味着英伟达正式确认NPO技术路线。
  • 受CPO扩产难度高、供应商数量少等因素影响，英伟达已将明后年的部分供应重心转向NPO。
  • 该订单并非在原有行业预期上突然新增500万只。供应商早在2026年5月已与英伟达对接，因此仍包含在此前市场对2027年500万—700万只出货量的判断中。
  • 短期出货仍受技术成熟度和产业链产能限制，不会因为订单落地就从500万只立即提升至1000万只。
  • 中长期意义更大：供应链正针对2028年扩产，2028年行业出货量可能由原预期的1500万只上修至2500万只。

3. 2027年NPO客户需求指引和实际交付量分别有多大？

  • 客户侧给出的名义需求合计约2000万只，主要包括：
  1. 英伟达：500万只；
  2. 谷歌：400万只；
  3. AWS：400万只；
  4. Meta：约200万只；
  5. Oracle：约150万只；
  6. 微软：约100万—150万只；
  7. 字节、阿里、腾讯合计：约150万—200万只。
  • 名义需求不等于当年实际部署量。受产品验证、硅光芯片供应、封装工艺及AI芯片出货节奏限制，2027年实际部署到机架中的NPO预计仅500万—600万只。
  • 2027年下半年将是NPO确定性开始上量的时间点，但实际规模较难达到市场预期的1000万—2000万只。
  • 到2028年，随着技术定型和产能释放，行业需求有望进入1500万—2500万只的大规模放量阶段。
  • 长期来看，英伟达、谷歌、AWS等头部客户单家需求有望达到400万—500万只，Meta、Oracle、微软也可能逐步提升至相近量级。

4. 2027年实际交付中，英伟达和谷歌分别需要多少NPO？

  • 英伟达2027年下半年Rubin Ultra出货量预计最多约100万颗，NPO实际配比约为1∶1.5，部分版本可能降至1∶1，因此实际需求约150万只。
  • 理论满配情况下，Rubin Ultra单卡14.4TB带宽除以3.2T，对应约4.5只NPO，但实际不会采用1∶4.5满配：
  1. 单只光引擎售价超过1000美元；
  2. 满配后单卡光互联成本约4500美元；
  3. 仅最顶级架构能够承担；
  4. 还需要综合考虑网络架构与成本；
  5. CPO方案也会分流部分NPO需求。
  • 谷歌TPU v9配套比例约为1∶1.2，2027年实际NPO部署量预计约120万—150万只。
  • 谷歌TPU v9近期存在流片延期和重新设计，同时还会采用2.4T CPO与OCS结合的Scale-up方案，因此不会一次性部署名义需求中的400万只。
  • 其他厂商进度普遍慢于英伟达和谷歌，预计合计贡献约200万只左右。

2. NPO供应商竞争格局与产能

1. 中际旭创与新易盛在英伟达供应链中的模式和份额有何差异？

  • 两家公司均需满足英伟达统一规格，包括内置光源、3.2T速率和统一接口，但核心芯片与开发模式不同。
  • 中际旭创：
  1. 由英伟达定义需求规格，旭创自行完成方案开发、芯片设计和封装；
  2. 具备较强的硅光芯片设计及先进封装能力；
  3. 首批500万只订单中，份额可能达到70%；
  4. 随着其他供应商进入，长期在英伟达2500万只总需求中的份额预计回落至约50%。
  • 新易盛：
  1. 自研硅光能力相对较弱；
  2. 主要基于英伟达设计、由台积电流片的硅光芯片进行ODM封装；
  3. 预计未来有望获得英伟达最多约30%的份额；
  4. 2027年出货进度和规模预计仍明显落后于旭创。
  • 市场所传旭创长期占比70%偏高，未充分考虑新易盛、天孚、Fabrinet、Coherent等供应商后续进入。

2. 旭创2027年的NPO产能和实际出货量预计是多少？

  • 旭创已在Tower预订约3万片12英寸硅光晶圆。
  • 单片晶圆理论上可产出约150颗硅光芯片，对应约450万只NPO理论产能。
  • 考虑良率、封装能力和产能爬坡，2027年实际出货量预计约300万只。
  • 旭创在2027年行业实际出货中的份额有望超过50%，是最主要的NPO供应商。

3. 新易盛、Coherent及其他厂商2027年预计能出货多少？

  • 新易盛：
  1. 硅光进展落后于旭创；
  2. 较依赖英伟达及外部硅光工艺；
  3. 早期内部出货计划甚至安排在2027年第四季度；
  4. 预计全年出货难以超过100万只。
  • Coherent：
  1. 内部目标超过100万只；
  2. 实际受供应能力和产品标准未统一影响；
  3. 预计实际出货仅几十万只，较乐观情形约50万只。
  • CPO相关产品内部目标约100万只，参考历史扩产节奏，实际可能为50万—70万只。
  • Fabrinet、天孚通信等其他厂商的出货规模更小，主要承担光引擎代工或零部件供应。

4. 天孚通信如何参与NPO产业链，潜在份额有多大？

  • 过去在英伟达自研800G、1.6T光模块中，天孚负责光引擎代工，再交由Fabrinet组装成光模块，因此天孚超过50%的收入来自Fabrinet。
  • 进入NPO时代后，不再需要传统光模块，产业形态以光引擎为主：
  1. 迈络思负责光引擎设计；
  2. 天孚可直接进行代工；
  3. 未来有望跳过Fabrinet，直接向英伟达供应NPO光引擎；
  4. 同时也可向Fabrinet供应FAU等零部件。
  • 天孚当前有源封装能力和产能仍较小，在英伟达体系中的长期份额上限预计约15%。
  • 2027年天孚可能尚不具备NPO整机出货能力，短期主要供应FAU、ELS等零部件。

5. Tower的硅光晶圆产能如何分配？

  • Tower不会将产能全部集中于旭创和新易盛，以避免单一客户风险。
  • 预计产能分配为：
  1. 旭创约40%；
  2. 新易盛约20%—25%；
  3. 两者合计约65%；
  4. 剩余产能分配给Coherent、Lumentum、AOI等厂商。
  • 按旭创3万片约占40%测算，Tower 12英寸硅光晶圆年产能约7万—8万片。
  • Tower现有美国和以色列的3座工厂主要生产8英寸晶圆，用于传统光模块硅光芯片。
  • 日本工厂为12英寸晶圆产线，主要服务NPO需求，目前仍处于量产爬坡阶段。

3. NPO技术规格、应用场景与光源路线

1. NPO与3.2T可插拔光模块的关系是什么？

  • NPO已进入Beta阶段，客户完成约2轮测试，预计2027年下半年确定性量产。
  • 3.2T可插拔光模块需要基于单波400G开发，预计2027年送样、2028年量产，时间晚于NPO。
  • 两者应用场景不同：
  1. NPO主要配套英伟达、谷歌、AWS下一代AI芯片，用于Scale-up网络，替代机柜内铜缆连接；
  2. 3.2T可插拔模块主要用于Scale-out网络，升级当前1.6T光模块。
  • NPO和3.2T可插拔模块不是替代关系，预计将并行上量，但NPO率先放量。

2. 2027年NPO主要采用哪些速率规格？

  • 行业标准尚未完全收敛，目前包括：
  1. OpenCPO：3.2T、6.4T、7.2T；
  2. OIF：当前以3.2T为主，并定义6.4T、12.8T；
  3. 国内ODCC及华为体系：3.2T、7.2T。
  • 未来主流规格预计为3.2T、6.4T和7.2T，下一代进一步升级至12.8T。
  • 2027年实际出货仍以3.2T为主：
  1. 英伟达、谷歌、Meta、Oracle主要采用3.2T；
  2. AWS采用6.4T，但统计时可折算为2只3.2T产品；
  3. 单个6.4T产品使用2颗16发16收硅光芯片。

3. 内置光源和外置光源分别适合哪些场景？

  • 英伟达选择内置光源，其他CSP首代方案多数选择外置光源。
  • 内置光源的优势：
  1. 更接近算力芯片；
  2. 不需要独立ELS激光模组，可缩小尺寸和占用空间；
  3. CW功率可由外置方案的200—300毫瓦降至120—150毫瓦；
  4. 光源成本、功耗和机柜占用面积均可下降。
  • 内置光源的挑战是散热和维护，英伟达依托较强的液冷能力解决相关问题。
  • 外置光源的优势：
  1. 光源远离高热区域，散热更容易；
  2. 出现故障后可插拔维护；
  3. 更适合空间相对充足、光引擎数量较多的交换机侧。
  • 长期趋势：
  1. GPU及算力侧更倾向内置光源，华为、AMD也在开发相关方案；
  2. 交换机侧更倾向外置光源。
  • 2027年预计500万只实际出货中：
  1. 外置光源、偏交换机侧约300万只；
  2. 内置光源、偏GPU侧约200万只。
  • NPO不使用DSP；CW光源潜在供应商包括Lumentum、住友、源杰等。

4. OCS需求、供给与竞争格局

1. 谷歌2027年OCS需求为何上修至5万台以上？

  • 谷歌此前需求预期约4万台，当前上修至5万台以上。
  • 主要驱动因素包括：
  1. 2027年TPU出货量预计达到850万—1000万颗，较2026年的约400万颗翻倍；
  2. Anthropic与谷歌签订约400亿美元TPU采购合同；
  3. TPU v9将小规模部署6D Torus架构，带来数千台增量。
  • 按谷歌当前约200张卡配置1台OCS测算，850万—1000万颗TPU对应约4万—5万台OCS。
  • 当前测算主要基于TPU网络及Scale-up配比，基本未计入传统数据中心Spine层以OCS替代电交换机的需求。

2. 谷歌OCS在Scale-up和Scale-out中的应用情况如何？

  • 在传统数据中心中，OCS可用于Spine层替代电交换机，该场景渗透率仍较低，约5%。
  • 在AI网络中，OCS可部署于Leaf、Spine之上的新增网络层，部署逻辑不同于传统替代场景。
  • 谷歌14万卡大型集群中，Scale-out侧配比约为700张卡对应1台OCS。
  • 2027年需求测算重点仍是TPU网络和Scale-up需求，并未依赖传统Scale-out渗透率大幅提升的假设。

3. 英伟达OCS的需求节奏如何？

  1. 每机柜配置2台托盘式OCS；
  2. 约36张GPU配置1台OCS；
  3. 相当于每颗GPU配置2个端口。

5. AOI与AWS长期协议及扩产能力

1. AOI与AWS最高100亿美元长协是否超预期？

  • 该协议明显超出市场预期，客户预计为AWS。
  • AWS 2027年800G光模块总需求超过2000万只，计划给予AOI约20%—25%的份额，对应约500万只。
  • 500万只对应约15亿美元订单规模。
  • 协议中约20亿美元是基础框架规模，100亿美元是上限，也接近AWS未来数年的总采购规模，并非全部交给AOI。

2. 该长期协议是否具有强制约束？

  • 协议属于框架性长期采购安排，约束力不强：
  1. AWS未支付预付款或定金；
  2. AOI无法完成交付时不会被罚款，AWS可将订单转给旭创、新易盛等；
  3. AWS需求下调时，AOI也缺乏强制客户采购的手段；
  4. 最终订单将根据AOI交付能力和AWS实际需求动态执行。
  • 尽管缺乏硬性约束，但履约可靠性仍被评估为85%以上，原因包括：
  1. AWS已入股AOI；
  2. AWS需要北美提货和供应链安全；
  3. 双方已对齐约500万只基础目标。
  • 合同要求从2027年第一季度开始在北美交付，但未要求全部由美国本土生产。
  • AOI当前主要在台湾扩产，目标到2027年底将美国供应占比提升至约30%。

3. AOI能否实现2027年底月产100万只的目标？

  • AOI历史上产能目标的实际达成率较低，扩产承诺存在较大水分。
  • 出货改善趋势明显：
  1. 2026年第二季度800G出货约4万只；
  2. 第三季度增至15万—16万只，环比接近4倍；
  3. 第四季度预计超过40万只。
  • 但实际出货仍远低于公司此前承诺的月产65万只：
  1. 月产65万只对应单季度理论产能接近200万只；
  2. 实际第四季度预计仅交付约40万只；
  3. 达成率约20%。
  • AOI已将2026年底月产能目标由65万只下调至50万只，该目标仍可能偏乐观。
  • 2027年月产100万只是否实现仍需观察，核心风险在于：
  1. 大规模量产经验不足；
  2. 设备调试能力有限；
  3. 供应链管理能力尚未达到千万只级别；
  4. 北美光模块生产依赖大量熟练工，扩产难度高。
  • AOI自2023年获得微软约1亿美元订单后，相关交付已拖延超过3年，反映其量产执行能力仍是主要瓶颈。

4. AOI光芯片与CW光源的扩产规划如何？

  • AOI自2016年起采用光模块与光芯片垂直整合模式，具备自研光芯片基础。
  • 当前光芯片年产能储备约2000万—3000万颗，但产量远低于产能，现阶段基本用于内部光模块。
  • 扩产规划：
  1. 2027年产能储备约5000万颗；
  2. 2028年达到1亿—1.5亿颗；
  3. 长期目标为3亿—5亿颗。
  • AOI正在北美采购MOCVD、清洗等设备，并与云南锗业签署衬底供应协议。
  • 大功率CW光源方面：
  1. 已立项开发400毫瓦产品，对标Coherent；
  2. 计划2027年第三季度送样；
  3. 送样不等于当年实现外售；
  4. 真正形成外部销售和多余产能预计要到2028年。
  • 当前生产的70毫瓦、100毫瓦CW光源主要用于内部光模块。
  • AOI签署大规模磷化铟衬底协议，主要是为应对潜在出口限制并为未来3—4年扩产囤货，不代表短期立即形成数亿颗芯片产量。

6. FCC政策影响与中国供应链应对

1. FCC政策预计何时落地，核心限制是什么？

  • 美国政府仍在推动相关FCC政策，预计最快于2026年12月公布，也可能延至2027年第一季度，但进一步推迟的概率较低。
  • 政策主要针对非北美厂商进入北美市场设置认证和供应链限制。
  • 可能配套的豁免条件包括：
  1. 800G及以下产品获得一定豁免；
  2. 北美光电芯片在BOM中的占比超过65%后获得豁免。
  • 光模块核心物料包括DSP、TIA、Driver、激光器、探测器等，价值占比超过70%。
  • 如果政策要求65%以上核心物料来自北美，将显著限制国产光芯片进入北美市场。
  • FA、透镜、隔离器、滤光片等光学器件占整体BOM约15%，海外缺少成熟替代厂商，预计受影响较小。

2. FCC政策对旭创、新易盛等头部光模块厂商影响如何？

  • 对中国光模块厂商的限制大概率会出现，但完全禁止供货的概率较低。
  • 可能的应对路径包括：
  1. 采购美国光电芯片；
  2. 在美国或北美建设产能；
  3. 调整股权或公司架构，降低敏感身份；
  4. 争取产品或客户层面的豁免。
  • 微软、谷歌、AWS等北美大厂仍高度依赖中国供应链，预计将持续向美国政府争取豁免。
  • 当前旭创、新易盛估值已较低，按2027年确定性订单和盈利测算，PE普遍低于10倍，部分仅6—7倍。
  • 低估值已反映市场对2028年需求不确定性和FCC政策的悲观预期。
  • 若FCC政策正式出台并同步明确豁免机制，反而有助于消除不确定性，可被视为阶段性利空落地。

7. 光互联行业后续重点趋势

1. 3.2T与单波400G将带来哪些新机会？

  • 光模块将由1.6T继续向3.2T演进，单波400G成为核心技术方向。
  • 海外Marvell、博通已具备单波400G DSP能力，国内产业链更重视薄膜铌酸锂方案。
  • A股相关产业链可重点关注：
  1. 天通股份；
  2. 光库科技；
  3. 共进股份/共进电子相关方向。
  • 薄膜铌酸锂有望成为下一代高速调制与光互联的重要技术路线。

2. Scale-up“光进铜退”将带来哪些增量环节？

  • 无论NPO还是CPO，都将推动Scale-up网络从铜连接向光连接升级。
  • 主要放量时间预计从2027年下半年开始。
  • 重点增量环节包括：
  1. 可插拔FAU；
  2. 硅透镜阵列；
  3. 其他无源光学器件；
  4. 硅光及光引擎先进封装。
  • 中际旭创已在寻找芯德半导体、晶方科技等企业开展先进封装代工，相关先进封装企业有望受益。

3. 光芯片与上游衬底有哪些结构性机会？

  • 国产光芯片短期受到FCC政策压制，北美市场进入难度上升。
  • 光芯片上游衬底仍存在较强需求：
  1. AOI、Momentum、Coherent等海外企业正在中国寻找供应商；
  2. 海外客户陆续签订长期供应协议；
  3. 供需偏紧下具备涨价预期。
  • 若国内未实施出口限制，云南锗业、光智科技等衬底厂商有望受益。
  • NPO、CPO及大功率CW光源将显著提升单片晶圆需求，相关用量可能实现数量级增长。

提问者：NV为什么选择内置光源？内置方案在散热等方面不是仍存在问题吗？

回　答　者：功率更低后，光源功率和成本也会下降，整个光引擎在机柜内占用的体积和面积也会减少。这是NV选择内置光源最核心的因素。

其他CSPs厂商选择外置光源，主要考虑到光源非常怕热，放在外部更便于散热，而且即使发生故障，也可以通过插拔进行维护。因此，内置光源和外置光源这2种路线各有优缺点。
