CoreWeave债务结构、融资能力与行业展望专家访谈纪要

1. 债务规模与结构

a) CoreWeave当前实际债务规模及构成如何？

  • 截至2026年第二季度末，公司债务本金总额略高于350亿美元，主要包括：
  1. DDTL及项目融资约130亿—140亿美元：采用特殊目的载体（SPV）和项目级融资结构，主要由客户合同及GPU等资产支持
  2. 无担保票据约100亿美元：目前市场全口径收益率已超过14%—15%
  3. 可转换优先票据
  4. OEM厂商支持的软件及设备融资
  • 除债务本金外，公司另有约160亿美元经营租赁负债，主要为向数据中心运营商支付的租赁款项。
  • 经营租赁与融资租赁的会计处理不同，通常更多体现为费用，但部分投资者会将经营租赁负债纳入全口径债务评估。
  • 2026年第三季度末相较第二季度末，主要变化是新增了规模约25亿美元的DDTL 5.5，其他债务项目未出现显著增加。

b) 不同DDTL的融资成本如何变化？

  • DDTL是公司最核心的债务融资工具，通常围绕客户合同、GPU采购及数据中心项目设立SPV，并按贷款价值比进行融资。
  • 主要DDTL融资成本如下：
  1. DDTL 4.0：由Meta合同支持，具有投资级客户信用，成本约为SOFR+225个基点
  2. DDTL 5.0：成本约为SOFR+450个基点
  3. DDTL 5.5：成本约为SOFR+550个基点，综合利率略高于9%
  • DDTL 5.5发行时正处于信贷市场紧缩期，市场波动及相关基金陷入困境，导致利差高于公司理想水平。
  • DDTL 5.5包含约4—5家非投资级客户，客户合同平均期限约3年或更短，短于贷款整体期限，因此投资者需要承担一定续约和再出租风险。

c) 为什么投资级客户支持的项目融资成本更低？

  • 项目融资能否获得投资级定价，核心取决于客户信用质量和合同期限，而不仅是GPU是否作为抵押品。
  • Meta、微软、谷歌属于投资级客户，拥有较强自由现金流和长期偿债能力，因此由其合同支持的项目更容易获得低成本融资。
  • OpenAI、Anthropic及部分中型企业客户属于非投资级客户，以其合同为基础发行项目债务时，投资者通常要求更高回报。
  • 市场最理想的融资结构是：
  1. 投资级客户
  2. 4—5年长期合同
  3. 较高比例预付款
  4. 高端GPU资产作为抵押
  • 如果项目包含2—3年短期合同、非投资级客户或H100、H200等较早代际GPU，融资成本通常会更高。

d) 客户信用风险会影响现有DDTL利率吗？

  • 已完成发行的DDTL 1至DDTL 5.5，其融资利差基本已经锁定，不会因为市场对OpenAI、Anthropic或AI基础设施的担忧而重新定价。
  • 市场风险主要影响的是未来新增融资：
  1. 如果新项目以非投资级客户合同为支持，融资利率可能进一步上升
  2. 市场认购规模可能下降
  3. 项目贷款价值比可能降低
  • Anthropic并非CoreWeave最大的客户，因此其经营或融资变化对CoreWeave现有债务的直接影响相对有限。
  • CoreWeave未来更倾向于拓展美国中大型企业及投资级客户，以提高项目融资的可获得性并降低融资成本。

2. 偿债压力、到期结构与再融资风险

a) 2027年前后CoreWeave面临多大偿债压力？

  • 截至2027年年底，公司预计需要偿还约100亿—110亿美元本金。
  • 截至2027年，公司预计还需支付约50亿美元利息。
  • 上述本金和利息支出构成未来两年最主要的现金流压力之一。
  • 现金是否充足，不仅取决于存量合同产生的现金流，还取决于：
  1. 2027年资本开支规模
  2. 新客户合同预付款
  3. 新增DDTL及其他融资能否持续落地
  4. 项目上线进度和客户回款情况

b) DDTL是否存在集中再融资风险？

  • DDTL通常采用约5年的固定摊还结构，项目现金流、客户合同、GPU资产和本金偿还计划在发行前已经匹配。
  • DDTL原则上可以在期限内实现自我摊还，并不依赖到期时一次性进行大规模再融资。
  • 例如，2026年发行的DDTL通常会在2030年或2031年前后完成本金和利息偿付。
  • 因此，DDTL的核心风险并非传统意义上的到期再融资，而是：
  1. 客户合同期限短于贷款期限
  2. GPU续约或再出租价格下降
  3. 项目上线延期
  4. SLA违约导致收入减少
  5. 客户无法付款

c) 哪些债务存在更大的再融资不确定性？

  • 母公司层面的无担保票据和可转换票据具有更明显的再融资风险。
  • 如果公司产生超额现金流，可以直接偿还部分高成本债务。
  • 如果新增债务成本低于存量债务成本，也可能通过新债置换旧债。
  • 但当前无担保票据收益率已达到14%—15%，在此水平继续举债缺乏经济吸引力。
  • 是否使用股权融资替代无担保债务，将取决于当时股权融资的稀释成本与债务成本之间的比较。

d) 宏观环境会如何影响未来融资？

  • 受通胀、利率政策和AI基础设施融资供给过多影响，市场债务成本正在上升。
  • AI基础设施项目密集发行，CoreWeave、Nebius、Crusoe、Nscale等新云厂商均在竞争有限的信贷资金。
  • Meta、Broadcom、Blackstone等大型机构也在筹集巨额资金用于AI基础设施，进一步挤占市场融资容量。
  • 受访者判断，2026年下半年信贷市场已经趋于饱和，投资者可能要到2027年初才会重新提高配置意愿。

3. 积压订单、项目回报与融资模型

a) CoreWeave当前积压订单规模如何？

  • 2026年第二季度，公司积压订单约为1040亿—1050亿美元。
  • 受访者预计第三季度积压订单还会继续增长。
  • 公司面临的核心问题并非客户需求不足，而是如何为积压订单配置资金、建设数据中心并推动GPU上线。
  • 这一问题并非CoreWeave独有，而是所有新云服务商共同面临的行业性约束。

b) 新项目通常要求达到什么IRR水平？

  • 新云服务商的新项目理想IRR目标约为20%。
  • 较常见的项目层面IRR区间为15%—20%。
  • 项目资本回收期通常约为2—3年，更接近3年。
  • 公司在签署客户合同前会测算：
  1. 客户预付款比例
  2. 合同期限和现金流
  3. GPU采购及数据中心资本开支
  4. 项目债务成本
  5. 项目整体IRR和利润率
  • 原则上，公司只开展能够增厚整体回报的项目，不会长期接受IRR为负或只能盈亏平衡的项目。
  • 对战略性新客户，公司可能在预期未来续约和长期合作的前提下，接受较低的初始项目回报。

c) 新项目通常能够获得多少债务融资？

  • DDTL及项目融资的贷款价值比（LTC）通常为70%—80%，当前可能略低。
  • 例如，项目总成本为100亿美元时，可能只能获得70亿—80亿美元项目债务。
  • 剩余20%—30%的资金缺口需要通过以下方式补充：
  1. 母公司股权融资
  2. 无担保票据
  3. 可转换债券
  4. 优先股
  5. 合作方资本
  6. 客户预付款
  • 随着债务市场供给增加和市场趋于饱和，未来LTC可能下降，意味着公司需要承担更高比例的股权或母公司层面融资。

d) 客户预付款如何影响项目回报？

  • 超大规模云服务商和大型AI实验室通常可能支付约10%—15%的预付款。
  • 部分CSP、中大型企业客户可能支付约20%或更高比例的预付款。
  • 客户通常以预付款换取：
  1. 更低的GPU每小时价格
  2. 更短或更灵活的合同期限
  3. 优先获得算力容量
  • 预付款可以降低项目首日资本开支和外部融资需求，同时提升项目IRR。

4. 债务成本临界点与股权融资选择

a) 当前债务成本对项目回报的影响如何？

  • DDTL 5.5的综合融资成本略高于9%，而新项目IRR通常为15%—20%，目前仍存在一定回报空间。
  • 如果综合债务成本上升至10%—12%，多数新云厂商将面临明显压力，项目利润空间会受到较大侵蚀。
  • 如果担保债务成本上升至无担保债券当前约14%—15%的水平，新项目基本不再具有吸引力，公司不会愿意继续承担此类债务。
  • 在高成本债务环境下，公司可能需要使用：
  1. 股权融资
  2. 优先股结构
  3. 与其他企业共同投资
  4. GPU供应商或大型机构提供的信用支持
  5. 其他形式的兜底担保

b) 什么情况下公司会转向股票市场融资？

  • 如果债务融资渠道已经接近用尽，或者融资利率高到足以侵蚀项目层面的全部回报，公司将转向股票市场。
  • 当前美国市场出现相对反常的情况：债务投资者因违约风险上升而更加谨慎，部分股权投资者反而愿意为长期AI基础设施增长提供资金。
  • Nebius已较多依靠股权融资，后续才逐步进入债务市场。
  • CoreWeave目前尚未认为全面转向股权融资的时点已经到来，因为DDTL投资者与无担保债券投资者不同，前者仍认可：
  1. GPU资产的长期价值
  2. 客户续约和再出租能力
  3. 新云行业的长期需求
  4. CoreWeave的规模和执行能力

c) CoreWeave是否会发行DDTL 6？

  • 是否发行新的DDTL主要取决于新客户合同的落地时间、规模和结构。
  • DDTL提款期通常会与数据中心设施完工进度匹配，并为GPU上线预留约2—3个月。
  • 如果2027年有新客户合同落地，公司可能继续筹集新的DDTL。
  • 对于20亿—30亿美元的小规模融资，私募信贷、保险基金和养老基金具备一定承接能力。
  • 如果融资规模更大，尤其是围绕价格更高的Vera Rubin GPU集群融资，公司可能需要进入公开市场，但公开市场利率和波动性预计更高。

d) GPU供应商是否可能提供担保或信用支持？

  • 英伟达等GPU供应商希望新云市场持续发展，因为新云厂商是其未来GPU、机架和芯片采购增长的重要来源。
  • 市场正在讨论英伟达是否可能与BlackRock、Blackstone等机构建立资金池，为新云厂商的GPU和AI基础设施建设提供支持。
  • 短期内未必会直接落地，但如果信贷市场进一步恶化，GPU供应商或其他产业参与者提供兜底或信用担保的可能性将上升。
  • 其战略目的之一，是支持GPU生态与谷歌TPU、Broadcom定制芯片等替代方案竞争。

5. 现金流、资本开支与产能建设

a) 公司现金何时可能面临最大压力？

  • 公司账面现金目前仍被认为足以支付近期本金、利息和摊销款项，同时也会有客户回款及预付款流入。
  • 现金压力较明显的时间可能出现在2027年上半年至下半年。
  • 具体时间取决于：
  1. 2027年资本开支规模
  2. 新增客户预付款
  3. DDTL融资能否持续落地
  4. 股权市场融资成本
  5. 项目上线和收入确认进度
  • 如果债务和股权融资同时受阻，公司可能不得不推迟或取消项目，对增长、客户关系和积压订单均会产生重大影响。

b) 当前产能和资本开支规划如何？

  • 截至2026年第二季度，公司已有约1.5吉瓦投入运营的电力容量。
  • 2026年年底目标为1.8—1.9吉瓦。
  • 2026年资本开支指引约为350亿—390亿美元，最终可能接近区间高端。
  • GPU、内存、配套设备及数据中心相关零部件价格均在上涨，可能进一步推高2027年资本开支需求。

c) 如果公司停止扩张，现有业务能否覆盖债务？

  • 如果公司立即停止建设、不再部署新增积压订单，现有客户合同和现金流原则上可以覆盖DDTL等融资安排，公司可能实现基本盈利。
  • 但停止扩张意味着：
  1. 收入不再增长
  2. 净利润缺乏增长空间
  3. 大量积压订单无法转化
  4. 资本市场难以接受其成长性下降
  • 因此，公司仍需持续增加新容量，并通过债务、股权和客户预付款支持建设。

d) 如果无法获得融资，产能建设和客户合同会受到什么影响？

  • 融资不足会直接导致项目延期和数据中心建设推迟。
  • 如果延期仅为2—3个月，客户可能愿意接受，因为行业其他供应商也可能面临类似问题。
  • 如果延期达到6个月或1年以上，客户可能：
  1. 取消订单或积压合同
  2. 转向其他供应商
  3. 要求退还预付款
  4. 索取SLA或正常运行时间赔偿
  5. 不再与该供应商开展后续合作
  • 相较合同罚金，最严重的风险是声誉受损，尤其当客户为头部AI实验室或超大规模云服务商时。
  • 微软退出与Nscale的部分交易，被视为新云厂商因项目延期无法按时交付的典型案例。

6. GPU定价、续约能力与资产寿命

a) GPU租赁价格近期如何变化？

  • CoreWeave在2026年第二季度财报中表示，后续GPU采购及新签合同定价整体提高约20%—25%。
  • B200、B300等新一代GPU的合同价格较此前至少上涨20%，部分可能达到25%。
  • H100、H200每GPU小时价格大致为：
  1. 合约型合同低端约2美元
  2. 高端可达到3美元以上
  3. 按需合同价格显著高于长期合约价格
  • 不同SKU、合同期限、预付款比例和客户信用质量均会影响最终定价。

b) 较旧GPU是否仍具备续约和再出租价值？

  • 受访者举例称，公司在2026年第二季度为A100签署了一份新合同，价格较2021年初始合同上涨约20%—25%。
  • 该合同将延续至2028年或2029年，意味着A100的实际使用寿命可能达到7—8年。
  • 市场此前通常按照5—6年对GPU进行会计折旧和经济寿命评估。
  • 较旧GPU仍能以较高价格续约，有助于支持DDTL投资逻辑，并降低投资者对抵押资产快速贬值的担忧。
  • 但这只是单一客户案例，不能完全代表所有GPU SKU及客户合同。

c) 什么情况会破坏DDTL的融资逻辑？

  • DDTL投资者目前最关注的是GPU续约率、再出租率和续约价格。
  • 如果GPU续约率和再出租率保持稳定，甚至继续提高，DDTL仍可能获得合理定价。
  • 如果续约率大幅下降，或GPU再出租价格显著下跌，投资者会重新评估：
  1. GPU资产价值
  2. 项目现金流稳定性
  3. DSCR安全边际
  4. DDTL能否按计划自我摊还
  • 一旦这一逻辑失效，公司通过DDTL市场筹资的难度将明显上升，并可能被迫转向高成本股权或其他融资方式。

7. DDTL模型压力测试与核心风险

a) DDTL项目模型中最重要的风险变量是什么？

  • 初始融资利率、客户合同、预付款和摊销计划在发行时基本已经确定。
  • 模型中最重要的动态变量是GPU续约和再出租价格。
  • 对DDTL 5.5而言，由于客户合同平均期限短于融资期限，投资者需要重点评估：
  1. 合同到期后GPU能否续约
  2. 续约价格下降15%—25%时现金流如何变化
  3. 是否仍能满足DSCR约束
  4. 是否会触发现金限制或财务契约违约

b) GPU价格下跌多少仍可满足偿债要求？

  • 受访者表示，即使GPU续约价格下降约20%—25%，DDTL 5.5融资池仍可能满足DSCR要求，并按计划实现自我摊还。
  • 原因是相关客户合同、预付款、贷款规模和还款节奏已经在发行前完成匹配。
  • 只有在更悲观的极端情景下，GPU价格大幅下降并叠加利用率下滑、上线延期或客户违约，融资池才可能承受重大压力。

c) 除GPU价格外，还有哪些关键风险？

  • 客户信用风险：客户资不抵债或无法付款，将直接削弱项目现金流。
  • 执行风险：服务商无法按时交付算力，或项目长期延期。
  • SLA风险：正常运行时间不达标，导致赔偿或当期收入减少。
  • 电力接入风险：数据中心无法按期获得电力，GPU无法上线。
  • 建设风险：Blackwell、Vera Rubin等高端GPU对冷却、机械设计和数据中心改造要求更高。
  • 合同期限错配风险：客户合同短于融资期限，需要依赖续约或再出租完成后续偿债。
  • 对大型新云厂商而言，由于项目和客户更加分散，单一项目延期影响相对有限；小型厂商则可能因单一站点或单一合同延期而失去大部分收入。

8. 新云行业竞争、整合与长期格局

a) 新云行业是否会因融资收紧而加速洗牌？

  • 受访者判断，2027年和2028年可能成为行业转折点。
  • 部分小型新云厂商可能因以下原因倒闭或被迫出售：
  1. 无法以可持续成本融资
  2. 无法按时建设数据中心
  3. 无法交付客户算力
  4. 客户合同被取消
  5. 单一项目延期导致现金流中断
  • 行业目前尚未大规模整合，主要是因为整体建设仍处于早期阶段，企业仍在等待融资环境改善。

b) 哪些企业可能成为行业整合的买方？

  • 最合理的潜在收购方包括：
  1. CoreWeave
  2. Nebius
  3. Nscale等较大型新云厂商
  4. 超大规模云服务商
  5. OpenAI、Anthropic等前沿AI实验室
  • 潜在收购资产包括：
  1. 已通电土地
  2. 已通电建筑
  3. 已上线GPU算力
  4. 可快速扩建的数据中心设施
  • 对大型新云厂商而言，收购小型厂商现成资产，可能比自行建设更快且成本更低。
  • OpenAI、Anthropic等企业也在招聘选址、建设及自营数据中心人才，未来可能从算力采购者转变为基础设施建设者和对外算力销售方。

c) 大型新云厂商为何更可能成为最终赢家？

  • 新云行业本质上是规模、资本和执行能力的竞争。
  • 大型企业具备以下优势：
  1. 在线收入和电力容量更高
  2. 客户和项目更加分散
  3. 单一项目延期对整体影响较小
  4. 更容易获得评级和市场融资
  5. 更有能力收购退出市场的小型竞争者
  • CoreWeave和Nebius被认为是当前规模较大的参与者。
  • 如果需求持续存在，大型企业有望在行业整合中以较低价格收购优质资产，并进一步扩大市场份额。

d) xAI和SpaceX与一般新云厂商有何不同？

  • xAI同样面临高额基础设施融资需求，市场融资并非毫无难度。
  • 但SpaceX及其相关业务具有更广泛的收入来源，包括卫星通信、连接服务和其他业务，并拥有更强信用资质。
  • 相较计算容量占绝大部分收入的新云厂商，SpaceX的业务多元化程度更高，因此更可能获得较低融资成本。
  • 受访者认同Elon Musk关于部分小型新云厂商可能因融资和执行问题退出市场的判断。
