存储行业专家访谈纪要

1. DRAM价格走势与供需判断

a) 2026年Q4 DRAM价格涨幅如何？

  • 整体价格仍处于上涨通道
  1. 2026年Q4，DDR5较Q3上涨约20%。
  2. DDR4涨幅相对较低，约为10%—15%。
  3. 按应用场景看，消费级DRAM上涨约20%，服务器DRAM上涨约10%—15%，企业级与消费级综合平均涨幅约15%。
  4. 模组厂终端报价与原厂合约价并非完全同步，但方向基本一致。若模组厂报价上涨15%—20%，可推测原厂DRAM报价上涨约10%。
  • 消费级涨幅高于企业级的原因
  1. 三大原厂对消费级产品的提价幅度可能更大。
  2. 原厂主要产能仍向服务器、RDIMM和HBM倾斜，企业级产品获得的产能保障相对更高。
  3. 企业级DRAM绝对单价已经较高，即使涨幅较低，对客户成本的影响也很明显，因此原厂可能适当控制涨幅。

b) 2027年DRAM价格如何演变？

  • 2027年各类DRAM预计持续上涨
  1. 2027年Q1，服务器DRAM、PC DRAM和手机DRAM预计均上涨10%—15%。
  2. Q2、Q3预计每季度继续上涨5%—10%。
  3. 上涨趋势预计持续至Q4，全年暂时看不到明确顶部。
  4. 2027年无论企业级还是消费级DRAM，价格均面临上涨压力。
  • 不同应用场景的趋势
  1. 服务器端：AI服务器、HBM及RDIMM需求强劲，服务器DRAM持续紧张。
  2. PC端：终端需求虽然疲弱，但原厂未增加消费级DRAM产能，因此供给收缩的影响大于需求下滑。
  3. 手机端：与PC DRAM趋势相近，受原厂产能转移影响，预计仍将涨价。
  4. 原厂产能和晶圆仍主要分配给HBM，预计至少持续到2027年Q1、Q2。

c) 为什么消费需求下降后，DRAM价格仍然上涨？

  • 供给端收缩是核心原因
  1. 三星、美光、海力士仍在将较多产能转向HBM和RDIMM。
  2. 原厂没有将额外产能投向普通PC、手机等消费级DRAM，也未向模组厂提供更优惠的价格。
  3. AI服务器需求持续增长，原厂优先保障HBM和服务器相关产品。
  4. 即使消费级终端需求下降，供应量同步甚至更快收缩，市场仍处于紧平衡状态。
  • 原厂定价持续坚挺
  1. 模组厂曾要求采购部门和产品经理降低价格，但得到的反馈是原厂合约价仍在上调。
  2. 模组厂只能采取持续、小幅涨价的方式向终端传导成本，避免一次性大幅涨价导致消费者更难接受。
  3. 自2026年3月以来，在此前已上涨1—2倍的基础上，DRAM价格又累计上涨约20%—30%。

d) DRAM价格何时可能缓解？

  • 受访者判断，DRAM紧缺局面至少需要观察到2028年。
  • 2028年可能出现缓解的条件包括：
  1. 长鑫存储HBM良率明显提升并形成有效供给。
  2. 国内厂商在价格和规模上形成竞争力。
  3. AI投资热度及服务器需求增速有所放缓。
  4. 三大原厂释放更多传统DRAM产能。
  • 在上述条件实现前，2027年DRAM和HBM市场仍偏紧，价格预计维持强势。

2. NAND与SSD价格走势

a) 2026年Q4 SSD价格表现如何？

  • 消费级SSD基本持平
  1. PC端SSD价格在2026年Q4基本没有明显变化。
  2. 从2026年Q2至11月，消费级SSD价格整体相对稳定。
  3. 部分产品甚至需要销售团队向公司申请更优惠的价格，以促进终端销售。
  4. NAND消费级产品在Q3、Q4的涨幅已经明显收敛，未感受到原厂报价出现大幅上涨。
  • 企业级SSD仍在涨价
  1. 2026年Q4企业级SSD预计上涨10%—20%。
  2. 工控及服务器级SSD报价仍在上升，销售较好的型号涨幅更高。
  3. 主要原因是服务器需求强劲，企业级产品的供需明显好于PC、手机等消费市场。

b) 2027年企业级SSD价格如何变化？

  • 上半年继续上涨，下半年趋稳
  1. 2027年Q1预计上涨10%—15%。
  2. Q2预计继续上涨3%—8%。
  3. Q3至Q4预计逐渐趋于稳定。
  4. 2027年全年企业级存储价格累计涨幅预计约20%—25%，主要涨幅集中在上半年。
  • 上涨驱动因素
  1. AI服务器及企业级存储需求依然强劲。
  2. 企业级项目更重视供货稳定性，对价格的敏感度低于消费市场。
  3. 企业级产品需进入服务器厂商AVL名单，一旦通过验证，通常可形成较稳定的项目收入。

c) 2027年消费级SSD价格如何变化？

  • 上半年持平，下半年回落
  1. 2027年Q1、Q2预计持平，部分模组厂为了维持现金流，可能主动降价5%—10%。
  2. Q3预计下跌3%—8%。
  3. Q4预计下跌8%—13%。
  4. 下半年累计跌幅预计约13%—18%。
  5. 手机存储与PC SSD趋势基本一致，除企业级产品外，消费级产品整体将进入降价通道。
  • 价格下跌的主要原因
  1. 消费级PC和手机终端需求疲弱，供需不再紧张。
  2. YMTC产能充足，且产品价格具有竞争力。
  3. 三星、美光、海力士、SanDisk及YMTC的NAND颗粒目前均可采购，市场并不存在明显缺货。
  4. SSD可以通过3.92TB、7.84TB等更高容量产品满足需求，容量提升比DRAM更灵活。
  5. 此前SSD价格上涨较多是跟随DRAM涨价，并非NAND原厂合约价出现同等幅度上涨。

d) NAND本轮价格走势经历了哪些阶段？

  • 价格高点与后续变化
  1. NAND终端价格在2026年3—4月达到阶段性高点。
  2. Q3、Q4面向终端消费者的FOB价格较高点下降约10%—15%。
  3. 从Q3至今价格基本稳定，模组厂仍存在进一步降价空间。
  4. 受访者认为，本轮NAND涨价部分由模组厂推动，实际合约价涨幅没有终端报价那么大。
  5. 模组厂曾借助市场缺货预期，希望将NAND价格拉升至接近DRAM的涨幅，以获取更高利润。

e) NAND价格长期最差可能回落到什么水平？

  • 历史低点可参考2022年：
  1. SATA 256GB SSD最低FOB价格约12美元。
  2. 当前同类产品约33美元，约为历史低点的3倍。
  3. 若市场重新回到极端供过于求状态，价格理论上可能向当前价格的三分之一收敛。
  • 但价格何时回到历史低位尚无法判断，还取决于：
  1. 模组厂库存规模及消化速度。
  2. 三大原厂报价和减产策略。
  3. YMTC等新增产能释放进度。
  4. 企业级需求能否吸收新增供给。

3. 原厂报价、模组厂定价与库存机制

a) 模组厂所参考的价格是什么口径？

  • 受访者提到的原厂价格主要为三星、美光、海力士等厂商提供的合约价。
  • 价格判断会结合：
  1. 原厂实际报价。
  2. TrendForce等第三方数据。
  3. 原厂产能安排。
  4. 市场需求及竞争对手价格。
  • 模组厂与原厂价格短期可能存在差异，但拉长至1—2个季度，价格曲线通常会逐渐趋近。

b) 模组厂如何根据成本确定终端价格？

  • 基本定价逻辑
  1. 假设原厂提供的成本为200美元，模组厂计划获得30%的加价收益，终端售价可能定为260美元。
  2. 模组厂还会对比Kingston、Team Group、Lexar等竞争品牌的市场报价。
  3. 如果库存消化低于预期，模组厂可能主动降低利润要求，例如将售价由260美元降至220美元。
  4. 若模组厂持有较多低价旧库存，短期终端报价可以低于当前原厂采购成本。
  • 库存对定价的影响
  1. ADATA可能持有约300亿—400亿新台币的旧库存，因此具备较强的平均成本调节能力。
  2. 模组厂会综合当前价格、下一季度价格及预计采购量，平衡整体平均成本。
  3. 多供应商采购使模组厂具备更高弹性，可在三星、美光、海力士、YMTC、长鑫存储之间调整采购比例。

4. 模组厂利润水平与后续变化

a) 当前DRAM和SSD利润水平如何？

  • 受访者表示，ADATA因持有较多低价旧库存，当前部分产品利润较高：
  1. 假设售价为100美元，历史库存成本可能只有30—40美元。
  2. 公司内部看到的“利润率”约为200%—250%，DDR4和DDR5约可达到成本的2倍以上。
  3. SSD相关“利润率”约为150%。
  • 该数据更接近售价相对成本的加价率或利润倍数，并非标准财务口径下的毛利率或净利率。
  • 这一水平主要反映ADATA的低价库存优势，不能代表Team Group、Lexar等所有模组厂。

b) 高利润水平是否可持续？

  • 高利润预计难以长期维持：
  1. 旧库存逐步消化后，新采购成本将明显上升。
  2. 消费需求已经大幅下降，模组厂需降低利润空间以维持渠道销量。
  3. 消费级NAND供给趋于宽松，价格竞争将加剧。
  4. 后续定价需在采购成本、库存周转、现金流及市场份额之间平衡。
  • DRAM成本端仍然强势，模组厂降价空间较小；SSD因供给充足，后续降价空间相对更大。

5. 终端需求、价格弹性与规格降级

a) 存储涨价对消费需求产生了多大影响？

  • 价格与销量出现明显反向变化
  1. 自2025年10月开始大幅涨价至2026年3—4月高点，DRAM价格累计上涨约200%，即达到原来的约3倍。
  2. 同期消费级产品销量下降约70%，仅剩涨价前的30%左右。
  3. 尽管销量大幅下滑，渠道销售收入仍增长约30%—40%，主要由单价上涨推动。
  4. 该现象并非单一地区，而是东南亚、欧美、澳大利亚、新西兰等消费市场的普遍情况。

b) 消费者如何应对价格上涨？

  • 主要方式是降低配置
  1. 此前DDR5消费需求主要集中在16GB和32GB。
  2. 涨价后，原本计划由8GB升级至32GB的消费者，可能只升级到16GB。
  3. 消费者会先满足基本需求，等价格下降或资金充足后再购买第二条DRAM。
  4. SSD方面，原计划购买2TB的消费者可能改为1TB。
  5. 因此，涨价不仅压低销量，也会导致平均容量和产品规格下降。

c) SSD下跌10%—15%能否明显刺激PC需求？

  • 受访者判断，单独依靠SSD降价10%—15%，难以显著拉动PC需求：
  1. 组装PC同时需要DRAM和SSD。
  2. 如果DRAM价格持续高位，仅SSD降价，对整机成本改善有限。
  3. 主板、显卡等部件也在涨价，显卡同样受到DRAM成本上升影响。
  4. 当前整机价格对消费者仍不友好。
  • 因此，2027年PC消费市场暂时看不到明显复苏，需求更可能持平或继续下滑。

6. 模组厂业务结构调整

a) 消费渠道需求下滑后，模组厂如何应对？

  • 业务重点转向企业市场
  1. 加大服务器、工控、B2B、系统集成商及政府项目开发。
  2. 积极接触服务器厂商，争取进入其AVL供应商名单。
  3. 企业客户更看重稳定供货，价格只要不明显偏离市场即可。
  4. ADATA已设立专门团队持续开发工控级产品市场。
  • 渠道业务仍需保留
  1. 模组厂不能完全放弃传统渠道客户。
  2. 预计2028年供需缓解、PC需求恢复后，原有渠道仍是重要销售基础。
  3. 若当前退出渠道，未来可能难以恢复市场份额。
  4. 整体策略是维持渠道基本盘，同时重点拓展服务器和B2B项目。

7. LTA长期协议与采购机制

a) 大型客户与存储原厂签订的LTA主要锁定什么？

  • LTA主要锁定供货，而非完全锁定价格
  1. Dell、HP及大型服务器厂商通过LTA确保供应数量和交付稳定性。
  2. 合约通常会约定价格调整区间或涨幅上限，如10%或20%。
  3. 原厂仍可根据供需状况按月或按季度调整价格。
  4. 如果价格完全固定，涨价周期会损害原厂利润，跌价周期则会损害客户利益，因此双方通常保留价格弹性。
  5. LTA的核心价值是避免客户产能被其他客户占用，并逐步消化积压订单。

b) 原厂是否会与普通模组厂签订LTA？

  • 普通模组厂通常较难直接与原厂签订正式LTA。
  • 模组厂主要依赖长期合作关系，按具体项目、数量和价格逐案协商。
  • 只有采购规模极大的客户，才有更强能力与原厂直接谈判长期供应数量和价格机制。

c) 模组厂采购与LTA客户相比有什么特点？

  • 优势
  1. 采购弹性更大，不必严格执行长期承诺数量。
  2. 可以分散供应商，选择三星、美光、海力士、YMTC或长鑫存储。
  3. 可利用旧库存平滑采购成本。
  • 劣势
  1. 采购价格波动可能比LTA客户更大。
  2. 在供应紧张时，供货保障弱于大型服务器和PC客户。
  3. 原厂涨价后，模组厂可能较难获得更好的采购条件。

8. 国产存储厂商对供需格局的影响

a) 长鑫存储对DRAM和HBM市场影响有多大？

  • 长鑫存储正在尝试将部分晶圆产能用于HBM生产。
  • 目前HBM良率约为20%—30%，短期内难以形成大规模有效供给。

b) YMTC扩产对NAND市场影响有多大？

  • 对市场的潜在影响

提问者：今年Q4整体涨幅是多少？您刚才提到价格持续上涨，但没有说明具体涨幅。

回　答　者：您指的是DRAM部分吗？

提问者：对，是今年Q4的DRAM。

回　答　者：DRAM方面，无论是DDR4还是DDR5，从Q3来看，Q2到Q3时已经上涨了1轮。Q3到Q4的涨幅没有达到以前那么夸张，即1个季度上涨100%、200%。目前DDR4、DDR5的价格仍在上涨，其中DDR5在Q4较Q3大约上涨20%；DDR4的涨幅相对较小，可能只有10%到15%。

提问者：DDR5上涨了20%，预计明年Q1还会继续上涨吗？

回　答　者：对，但这要看终端消费者是否接受，也要看我们的库存状况。

提问者：您刚才提到的Q4上涨价格是FOB价格，即我们卖给消费者的价格。可以参考的是否主要是我们的涨幅与原厂报价涨幅是否一致？

回　答　者：对。各家模组厂的库存成本不同，但仍可以参考整体走势。假如我们的涨幅为15%到20%，可以预期原厂在RAM方面可能也有10%的小幅上涨。我们会先贴近原厂价格，让消费者能够接受。

提问者：这里还区分企业级和消费级吗？

回　答　者：我刚才所说的企业级和消费级产品，在明年Q1都会继续上涨。Q4消费级产品已经上涨20%，企业级服务器DRAM大约上涨10%到15%。综合来看，企业级和消费级产品的平均涨幅大约为15%。

提问者：为什么Q4消费级产品的涨幅高于企业级产品？

回　答　者：正如刚才所说，可能是3大原厂对消费级产品的提价幅度更大。企业级产品方面，原厂的主要产能仍在向该领域倾斜。同时，企业级产品本身的单价已经很高，因此涨幅会比消费级产品略低。假设1件产品售价为2000块，上涨15%就已经增加了300美金，这对服务器厂商而言也是一项成本。因此，我认为原厂考虑到了单价问题，企业级产品的涨幅没有消费级产品那么大。

提问者：您是否了解存储原厂与不同客户签订的 LTA？具体条款是怎样的，例如价格上下限如何确定、议价频率如何，以及违约条款、保证金等方面有哪些细节？

回　答　者：这类合约的内容非常机密。Dell、HP 等大型厂商，以及其他服务器厂商，与 3 大原厂签订的合约，主要是为了锁定供应。

价格方面，原厂仍然可以涨价，只是涨幅可能不会像现货价那么大。双方通常会约定涨价幅度的上限，例如10%、20%，同时要求原厂保证相应的供应量。因此，价格区间和供货稳定性是此类合约中较为重要的部分。

签订长期合约并不意味着价格完全不能调整。原厂仍会根据当前供需情况，每季度或每个月重新定价。长期合约主要锁定供货，避免产能被其他客户占用。合约价格仍然可以调整，否则双方承担的风险都会较大。涨价时，如果价格完全固定，3 大原厂的利润会低于原本水平；跌价时，如果仍然固定原有价格，模组厂或服务器厂商也难以接受。因此，价格应当具有弹性。

LTA 最重要的内容，是承诺供货数量，确保客户能够顺利获得交付，并逐步消化积压和累积的订单。

提问者：存储原厂不会与我们签订 LTA，对吗？

回　答　者：您是指与我们模组厂签订 LTA 吗？

提问者：对。

回　答　者：基本上不太会。双方主要依靠长期积累的信任和合作关系，由我们从原厂取得一定的数量和价格，并逐案协商。除非是市场上的超级大厂，才比较有空间直接与原厂协商 LTA 的供应量。

提问者：那么，原厂给我们的合约价与 LTA 价格之间，价差会很大吗？

回　答　者：这方面我不确定价差是否会很大。不过，模组厂的弹性相对更大，因为手上有较多旧库存。例如，Adata 可能有300亿到400亿新台币的旧库存，因此可以与原厂协商。

回　答　者：我们会根据当前采购量、当前价格以及下一季度的价格，预估当前和下一季度的采购量，从而平衡平均成本。模组厂采购价格的波动肯定比签订长期合约的企业更大，但也意味着我们具有更高的灵活性，不一定需要立即采购当初承诺的数量，还可以分散采购比例。

例如，我们有三星、美光、海力士等多个供应商。如果美光当前报价过高，我们可以向YMTC或长鑫存储采购。对模组厂而言，由于供应商较多，采购相对灵活，不一定要向签订合约的供应商采购。

提问者：关于LTA，我们先讨论到这里。对于2028年DRAM和NAND的整体供需情况，您刚才的供需判断既代表模组厂的判断，也代表存储原厂的判断吗？两者之间的差异有多大？

回　答　者：两者差异不大。模组厂相当于3大原厂的客户，模组厂的下游客户包括代理商，代理商的下一层则是经销商。整个产业的价格环环相扣：原厂报价会传导至模组厂或其他品牌商，其价格基本都会随原厂报价变动，之后再依次传导至代理商、经销商和最终消费者。

从各层价格反向推导可以发现，价格变化具有一定规律。因此，模组厂价格的涨幅基本可以代表原厂价格的涨幅，两者趋势相近，不会出现原厂价格上涨20%，模组厂价格反而下跌20%的情况。将时间拉长至1个季度或2个季度来看，模组厂与3大原厂的价格走势差异不会太大。

因此，前述价格走势具有参考价值。DRAM价格预计仍将持续上涨，需观察至2028年，才能判断价格能否回落。SSD方面，目前已经可以看到，从明年的Q1、Q2开始，价格可能较为持平；今年的Q3、Q4已经处于持平状态。明年供需可能得到缓解，甚至出现降价。

提问者：您刚才提到，NAND在今年Q3、Q4也处于持平状态。原厂价格，特别是Q3是否仍有一定涨幅，只不过现货价……？

提问者：关于原厂NAND部分，Q3、Q4是否仍在涨价？

回　答　者：从目前情况来看，NAND消费级产品在今年Q3、Q4的涨幅已经明显收敛，并未感觉Q3、Q4出现太大的价格变动。企业级产品明年可能会小幅涨价，但涨幅不会像DRAM这么大。

提问者：从模组厂对终端客户需求的感受来看，是否存在价格参考线？例如，DRAM和NAND价格上涨多少，会对终端消费者的采购需求产生比较明显的抑制？此前，国内OPPO手机专家给出的参考线是上涨50%、上涨100%到120%，以及上涨200%以上，达到这些幅度后，对企业利润率和终端需求的影响会比较明显。从模组厂的角度看，是否也有类似的参考线？

回　答　者：我认为，这与手机行业的情况有较强的相关性，也比较相似。终端消费者的消费能力有限，无法始终按照原本的规格进行采购。

例如，在去年的10月以前，DDR5的16GB和32GB是市场的主流需求，选择升级8GB的消费者相对较少。此后经历了一系列涨价，价格已经上涨200%。从10月，即去年的10月，到今年的3月，价格上涨200%之后，需求已经下降7成。后续可以按照这一数字逻辑，推算需求可能降低多少。价格上涨200%，需求降低7成。如果价格继续上涨，需求只会越来越少，我们的营收也会相应逐渐降低。

以前的需求主要集中在32GB和16GB。现在，消费者为笔记本电脑升级时，可能会选择安装16GB，原本配置为8GB的产品会升级到16GB，但不会升级到32GB。消费者会根据价格涨幅调整选择。假设需求下降7成，仍可维持原本3成的需求，但消费者可能会考虑降低规格，即先满足基本需求，再追求更好的配置。

SSD也是如此。消费者原本可能认为电脑安装2TB更方便，但也可能因为价格因素降低容量，将规格降至1TB。

回　答　者：价格持续上涨确实会影响销量，也会影响客户对规格的选择。明年Q1、Q2，因为价格回调，SSD的需求可能会有所增加。DRAM方面，终端用户可能会选择降低规格以满足当前需求，等资金充足或价格下降后，再购买另一条DRAM安装在主机上。

目前可以确定的是，按当前价格与原本价格相比，需求已经降低了70%。各个市场大致都面临这种情况。以我负责的东南亚市场为例，目前大约只剩3成的需求。欧美，甚至新西兰、澳洲等市场的需求，相较去年10月以前也只剩不到3成。

目前，这些市场的主要业务来源已经不再是渠道，而是B2B、SI项目或政府项目，我们现在的业务也更多偏向这种形式。当然，渠道业务不能放弃，因为这是我们模组厂起家时积累的客户。如果现在放弃市场，未来PC需求恢复时，可能会失去相应的市场份额，风险较大。

因此，我们目前采取双向发展的方式：一方面尽量维持渠道业务，另一方面开发服务器客户及B2B项目，并尽力争取相关业务。整体方向更偏向这种模式。

提问者：您刚才提到，如果消费级NAND明年下半年价格下跌，您认为跌幅达到多少时，对需求回升的拉动会比较明显？如果像您刚才所说，价格下跌10几个点，但此前已经上涨了几倍以上，那么下跌10几个点对需求的拉动是否也不会特别明显？

回　答　者：我认为这与DRAM价格也是相辅相成的。如果SSD价格下降10%到15%左右，我个人认为终端消费需求不会有太大变化。以PC为例，组装一台主机仍然需要DRAM和SSD。如果DRAM价格持续高居不下，整台PC中只有SSD价格下降10%到15%，消费者需求不会明显上升。

更何况现在不只是DRAM和SSD涨价，主板和显卡也在涨价。显卡中也会使用DRAM，因此价格同样持续上涨。总体而言，目前PC价格对终端消费者并不友好。

回　答　者：明年的PC市场看不到明显曙光。我们内部开会时，也希望明年将更多精力投入B2B和AI客户。渠道方面，预计明年需求不会上升太多，持平或下滑的可能性更大。

提问者：国内长鑫、长存这2家企业大规模扩产，对整个存储市场的供需格局影响大吗？目前如何看待这一情况？

回　答　者：我们看到，CXMT长鑫存储正在尝试将部分产能用于生产HBM。其明年的计划是将一部分晶圆用于HBM生产，但目前HBM良率大约只有2到3成。尽管如此，他们仍计划进入这一市场。

在当前良率较低的情况下，其对整个市场的影响还不会很大。这也是我们仍然看涨2027年HBM和DRAM市场的原因。到2028年，如果长鑫存储能够提高良率，供需可能会达到相对平衡的状态。届时，AI浪潮也可能有所减弱。当前正处于黄金期，各方都在参与竞赛并推动AI发展，因此目前的需求可能比2028年更多。

总体而言，现阶段长鑫存储对市场的影响不会太大，对价格也不会产生较大影响。除非CXMT能够提高良率，同时在价格方面具备竞争力，才会对市场产生相对较大的影响。目前来看，其尚不足以真正影响DRAM市场。

提问者：YMTC扩产对NAND市场的供需会产生影响吗？

回　答　者：YMTC扩产带来的影响会比DRAM更快，因为其影响更加直接。

提问者：从整体工艺成熟度来看，YMTC与海外原厂之间的差距相对更小，是吗？

回　答　者：差距相对更小，因为其技术门槛没有HBM那么高。一旦YMTC扩产，对NAND市场将产生直接冲击。因此，我们判断明年NAND市场将出现供过于求的情况，不会像目前这样保持供需平衡，甚至可能出现降价。

提问者：关于YMTC生产企业级SSD，我有一个小问题。

提问者：YMTC的产品能力怎么样了？

回　答　者：目前Adata也在销售enterprise SSD。我们原本可能采用SanDisk的NAND flash，现在也开始导入采用YMTC颗粒的SSD。因此，YMTC的扩产和供给对整个市场影响较大。

我们开始选择YMTC，主要是因为其供货稳定、价格便宜。采用其产品后，我们可能获得更多订单。在高阶enterprise SSD领域，我认为YMTC的技术和产能都没有问题，并不像此前提到的DRAM，良率问题会那么夸张。因此，YMTC的扩产和供货会直接影响整个市场。

提问者：您提到YMTC的价格便宜，一般会折价多少？

回　答　者：我不确定YMTC与另外3大原厂之间的具体价差，只知道公司内部已经开始导入其产品，其成本相对较低。至于具体便宜的百分比，我不太确定，但可以确认其产品很有竞争力。

我们已经将所有高阶SSD，也就是企业级SSD的颗粒，基本都更换为YMTC的产品。主要原因是YMTC不会缺货，而SanDisk对我们的供货可能不稳定。如果部分项目正在推进，更换颗粒后就必须重新验证。因此，我们需要寻找供货相对稳定的供应商，以便持续推进相关项目。这也是YMTC具备相应实力和影响力的原因。

回　答　者：我没有仔细关注相关消息，因此了解不深。不过据我所知，台湾地区的罢工通常不会很严重，员工仍会正常上班，工厂也会正常运营，不会像部分欧美国家那样因罢工而完全停工。罢工可能持续1—2天，影响不会很大。

回　答　者：您说的是SMC吗？

回　答　者：这部分我不是很了解。但正如我刚才所说，就NAND而言，无论是YMTC扩产，还是其他厂商扩产，我们都认为明年将供大于求。今年已经没有感觉到NAND存在特别短缺的情况，因此，在明年各大厂商持续扩产的情况下，SSD价格将受到影响。如前所述，价格会下跌。从数据分析来看，不太会出现供不应求的情况。

提问者：关于NAND价格下跌，您预计NAND原厂供应过剩会持续多少年？最差情况下，价格会下跌多少？会跌破净利润吗？
