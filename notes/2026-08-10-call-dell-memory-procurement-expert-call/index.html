专家访谈会议纪要

1. 专家职责范围与戴尔服务器业务结构

a) 专家在戴尔主要负责哪些业务？

  • 专家负责戴尔全球范围内的整个存储器品类，并非只覆盖服务器或消费终端。
  • 采购范围包括：
  1. DRAM；
  2. NAND；
  3. SSD，其中SSD归属于NAND板块；
  4. 涉及服务器、企业级存储、PC及其他消费终端的全部存储产品。
  • 戴尔采取自主采购模式，不通过ODM代采存储器。
  • 主要采购渠道包括：
  1. 三星、美光、SK海力士等原厂；
  2. 原厂授权经销渠道；
  3. 市场上的现货经纪商。

b) 戴尔服务器客户中，CSP与其他企业客户分别占多少？

  • 按服务器出货数量计算，CSP客户约占20%。
  • 按销售金额计算，由于CSP服务器配置较高，CSP占比约为40%至60%。
  • CSP与非CSP客户的占比高度依赖统计口径：
  1. 按数量计算，CSP占比较低；
  2. 按金额计算，CSP单机价值量高，占比明显提升。
  • 在戴尔内部统计口径中，英伟达被归入CSP类别。戴尔主要向其供应Server Rack等产品，单机架配置及存储价值量较高。

c) 戴尔AI服务器采用自有工厂还是ODM生产？

  • 两种生产方式均有采用。
  • 部分原型机和早期产品会通过戴尔自有工厂生产。
  • 产品进入规模化量产后，通常会将订单交给ODM生产。
  • 戴尔与多家大型台系服务器ODM厂商均有合作，但专家未披露具体厂商名称。

2. DRAM供给、满足率与价格走势

a) 2026年各季度DRAM需求满足率如何变化？

  • DRAM需求满足率呈逐季改善趋势，但整体供应仍未完全满足需求：
  1. Q1满足率约84%；
  2. Q2满足率约90%；
  3. Q3预计仍约90%；
  4. Q4预计提升至约92%。
  • 每个季度未满足的订单会顺延至下一季度，并由下一季度优先消化。
  • 即使Q4满足率有所改善，仍会有部分需求延后至2027年。
  • 满足率回升的主要原因包括：
  1. DRAM供给持续增加；
  2. 消费端需求偏弱，使部分产能可以向企业端转移；
  3. 需求虽仍在增长，但部分品类的供给增长更快。

b) DRAM整体平均价格的季度涨幅是多少？

  • 消费级和企业级DRAM合并后的平均环比涨幅为：
  1. Q1环比上涨约23%；
  2. Q2环比上涨约15%；
  3. Q3预计环比上涨约8%至10%。
  • 整体趋势是价格继续上涨，但季度涨幅逐步收窄。
  • 涨幅收窄并不代表服务器需求走弱，而是供给增加、消费需求偏弱及价格高基数共同作用的结果。

c) 企业级DRAM的涨幅为何明显高于平均水平？

  • 企业级DRAM季度环比涨幅为：
  1. Q1上涨约42%；
  2. Q2上涨约23%；
  3. Q3上涨约15%。
  • 企业级产品涨幅高于消费级产品，主要因为：
  1. 企业级产品规格、可靠性、带宽和速度要求更高，基础价格更高；
  2. AI服务器对高端DRAM、HBM等产品的需求较强；
  3. 企业客户对价格上涨的承受能力更强；
  4. 高端存储供应最紧张，价格更容易向下游传导。
  • 虽然企业级DRAM价格仍在上涨，但涨幅同样处于逐季收窄状态。

d) 原厂初始报价与最终成交价之间有多大差距？

  • 原厂最初提出的涨幅一般会比戴尔目标高10至15个百分点。
  • 以Q1为例：
  1. 原厂最初要求环比上涨约35%；
  2. 戴尔经过多轮谈判后，将最终涨幅压低至23%；
  3. 最终以环比上涨23%的价格签约。
  • 戴尔压低涨幅的主要方式包括：
  1. 多轮商务谈判；
  2. 依据市场趋势和成本模型进行价格论证；
  3. 支付部分定金或预付款，提前锁定产量；
  4. 以较大采购规模换取规模折扣。

e) 戴尔如何消化DRAM涨价？

  • 消费端难以直接向终端用户转嫁全部涨幅：
  1. PC用户对价格较敏感；
  2. 消费电子市场景气度偏弱，直接涨价可能影响市场份额；
  3. 戴尔主要通过产品组合、配置调整及高低端产品间的利润平衡消化涨幅；
  4. 部分成本会优先转移至价格较高的高端电脑。
  • 企业服务器端具备更强的价格传导能力：
  1. 高端LPDDR5、企业级DRAM及HBM供应紧张；
  2. AI服务器客户对配置和性能要求较高；
  3. 客户对存储价格上涨的接受度较高；
  4. 大部分涨幅可以继续向终端客户传导。

3. SSD供给、价格与降配趋势

a) 2026年企业级SSD的需求满足率如何？

  • SSD满足率整体好于DRAM，并呈逐季改善趋势：
  1. Q2约为88%；
  2. Q3约为90%；
  3. Q4预计约为95%。
  • 上一季度未满足的订单会延续至下一季度，并优先处理。
  • 每个季度遗留的未满足订单规模正在逐步减少。
  • 专家预计，到2027年Q2可以基本处理完历史遗留订单及当季订单。

b) SSD供给改善主要来自哪里？

  • SSD与DRAM不同，供给改善主要由供给端快速扩张推动。
  • 新增供给来源包括：
  1. 海外NAND原厂；
  2. 中国本土供应商；
  3. Kingston、Adata、威刚等模组厂；
  4. 模组厂及其他企业此前储备的晶圆和产品库存。
  • 部分模组厂的企业级SSD产品正在逐步通过验证并进入市场，进一步扩大整体供给。
  • 因此，NAND和SSD的实际紧张程度低于此前市场部分预期。

c) 企业级SSD价格涨幅是多少？

  • 企业级SSD，即E-SSD的价格涨幅较为明显：
  1. Q1上涨约68%；
  2. Q2环比上涨约25%；
  3. Q3环比上涨约25%；
  4. Q4预计环比上涨约14%。
  • 上述数据主要针对服务器使用的高端企业级SSD，并非消费端与企业端的综合均价。

d) SSD整体平均价格如何变化？

  • 消费级与企业级产品合并后的平均涨幅为：
  1. Q1环比上涨约37%；
  2. Q2环比上涨约29%；
  3. Q3环比上涨约16%；
  4. Q4预计环比上涨约7%。
  • 整体涨幅同样持续收窄。
  • 消费端价格已经接近高位顶部：
  1. 后续预计只有轻微上涨；
  2. 大概率维持在当前高位平台；
  3. 消费端进一步大幅提价的空间有限。

e) 消费端涨不动后，企业级SSD是否也会停止涨价？

  • 企业级SSD涨幅会放缓，但预计仍将继续上涨。
  • 核心原因是服务器存储正在从HDD向E-SSD迁移：
  1. E-SSD在单位功耗、性能和速度方面更具优势；
  2. E-SSD与HDD之间的价格差距逐渐缩小；
  3. 原本使用机械硬盘的场景正逐步转向企业级SSD；
  4. Seagate、Western Digital等传统HDD厂商的部分份额可能被E-SSD厂商替代。
  • 因此，即使消费端价格见顶，企业级SSD仍有结构性需求支撑。

f) 企业级SSD是否已经出现实际降配？

  • 企业级SSD已经开始降配。
  • 从上一年Q4至当年Q3、Q4，企业级SSD累计价格涨幅较大，部分企业为控制成本开始降低单条SSD容量。
  • SSD属于模块化产品，降配与后续升级相对容易：
  1. 可以由8TB降低至1.6TB或1.2TB；
  2. 后续仍可以通过增加模组恢复或升级容量；
  3. 降配不会像嵌入式NAND一样涉及大规模软件重新适配。
  • 从AI服务器容量结构看：
  1. 约90%的容量来自可调整的SSD，理论上可以降配；
  2. 约10%属于嵌入设备、与软件深度绑定的NAND Flash，较难降配。

4. AI服务器订单与客户需求变化

a) 2026年CSP服务器订单增速如何？

  • CSP服务器订单保持高增长：
  1. Q1较2025年Q4增长约38%；
  2. Q2较Q1增长约23%；
  3. Q3较Q2增长约30%。
  • Q3较Q2的订单增速重新加快，说明CSP需求并未降温。
  • 增长主要受到以下因素推动：
  1. AI需求持续加速；
  2. 英伟达等客户增加订单；
  3. 新GPU和服务器平台的发布、量产节奏；
  4. Google等客户的新产品发布；
  5. 全球数据中心持续扩建。
  • Q4服务器出货量预计较Q3环比增长8%至10%。
  • 由于距离Q4过近，临时追加Q4订单的空间有限，新增需求更可能转化为2027年订单。

b) 非CSP的AI服务器订单增长如何？

  • 非CSP AI服务器订单增长相对平稳：
  1. Q1较2025年Q4增长约10%；
  2. Q2环比增长约15%；
  3. Q3环比增长约12%。
  • 非CSP订单较为分散，单季度增幅不像CSP客户那样陡峭，但客户基数较大。
  • 从增量角度看，当前AI服务器增长主要集中在CSP客户。

c) 供给改善是否意味着AI服务器需求变弱？

  • 并不意味着需求变弱。
  • 当前供需两端都在增长，但部分品类的供给增速高于需求增速，导致：
  1. 满足率回升；
  2. 价格涨幅收窄；
  3. 交付周期开始下降。
  • 供给增加还来自消费端需求走弱，使部分存储产能能够转移至企业端。
  • 中国供应商、模组厂和库存释放也使供应来源更加多元。

d) 存储高价是否会抑制AI需求？

  • 存储价格上涨已经传导至订单，但加单幅度低于部分市场的乐观预期。
  • 即使AI需求较强，高存储价格仍可能产生以下影响：
  1. 部分训练需求被取消或收回；
  2. 产品发布周期延后；
  3. 原计划Q3发布的产品可能推迟至Q4；
  4. 客户通过SSD降配降低单机成本。
  • 因此，终端AI需求增长并不会无条件转化为同等幅度的存储订单增长。

e) AI服务器中的DRAM是否可能降配？

  • AI服务器中的DRAM基本不会轻易降配。
  • 主要原因包括：
  1. DRAM属于嵌入式配置；
  2. 软件、读写速度及系统架构均与硬件配置深度匹配；
  3. 降配后需要重新调试软件和性能；
  4. 调试过程耗时、耗力，可能影响整机交付节奏。
  • 目前观察到的AI服务器配置中，无论不同平台规格，DRAM均未出现明显降配。
  • 市场参与者更多是竞价争夺有限供应量，而不是降低DRAM配置。

f) 英伟达服务器“HBM降配”应如何理解？

  • 所谓“降配”并非减少单颗GPU所搭载的HBM数量，而是调整整个机架的配置方式。
  • 可能的调整包括：
  1. 减少一个机架中的GPU或Rack数量；
  2. 将原来的72单元配置调整为36单元或更小单元；
  3. 以更小的stand形式出货。
  • 实质上是减少整个机架所消耗的HBM总量，而不是降低单GPU的HBM配置。
  • 主要原因包括：
  1. HBM供应不足；
  2. 新一代HBM性能发展快于部分GPU的实际需求；
  3. 现有HBM产品速率已经能够满足相关GPU平台要求。

5. LTA、预付款与不可取消订单机制

a) 戴尔的存储采购是否全部由LTA覆盖？

  • 戴尔的存储采购原则上均纳入LTA框架。
  • 但LTA并不意味着所有采购都按照原合同价格执行：
  1. LTA主要锁定合作框架及基础采购量；
  2. 原合同价格通常合理且具有竞争力；
  3. 在供需失衡时，戴尔仍需每季度与原厂重新谈判；
  4. 为保障供应，实际采购价可能在LTA价格基础上上浮。
  • 因此，LTA更接近量的框架协议，季度实际价格仍取决于市场情况。

b) 2027年的LTA会如何签订？

  • 2027年仍会采用LTA模式，预计在2026年年中与原厂初步谈妥。
  • 协议会明确“Subject to Market Situation”：
  1. 采购量提前承诺；
  2. 基础价格框架提前确定；
  3. 各季度再根据市场供需重新调整实际价格；
  4. 市场上涨时价格可以向上调整；
  5. 市场下跌时，戴尔也可以要求原厂下调价格。
  • 戴尔在手服务器订单已能够支撑至2028年，因此对2027年订单具有较高可见性和预测准确性。

c) 后续预付款比例会如何变化？

  • 未来仍会存在预付款，但比例预计低于2026年，并逐步收窄。
  • 预付款比例下降的前提是：
  1. Forecast保持较高准确性；
  2. 戴尔能够承诺并实际提走对应采购量；
  3. 双方对长期产能和订单量形成较强共识。
  • 预付款主要用于：
  1. 锁定产量；
  2. 保证交付优先级；
  3. 降低原厂初始报价涨幅。

d) 什么是NCR/NAR类不可取消订单？

  • 会议中将该模式描述为不可取消、不可退货的强绑定订单，可理解为NCR/NAR类安排。
  • 该模式会同时绑定：
  1. 采购量；
  2. 采购价格；
  3. 交付时间；
  4. 不可取消、不可退货条款。
  • 原厂出货后，客户必须全部接收，不能部分拒收或退货。
  • 该模式主要用于在急单、飞单冲击原厂产能时，保障戴尔的供应份额。

e) 为什么已经有LTA，还需要切换部分订单为不可取消模式？

  • 极端紧缺情况下，市场急单价格可能比戴尔LTA协议价高3至5倍。
  • 如果戴尔不通过更强的绑定条款覆盖对应产能，原厂可能将部分产能分配给高溢价急单。
  • 因此，戴尔会将部分LTA订单切换为不可取消、不可退货模式，以确保关键产能。
  • 这类订单不会成为主流，仅用于保护少量关键供应。

f) 不可取消订单占LTA总量的比例是多少？

  • 2026年预计约为18%至20%。
  • 2027年初步预计下降至约12%。
  • 比例通常在上一年年末确定：
  1. 2026年比例在2025年12月确定；
  2. 2027年比例预计在2026年12月最终确定。
  • 当前2027年的12%仅为初步预测，并非最终数字。
  • 比例下降反映戴尔判断2027年供需环境将较2026年有所改善。

6. 存储价格形成机制与未来价格判断

a) 戴尔如何形成可接受的存储采购价格？

  • 价格由三部分共同决定：
  1. 成本模型；
  2. 市场供需；
  3. 商务谈判策略。
  • 成本模型会拆分：
  1. Wafer成本；
  2. 封装成本；
  3. 每GB理论成本；
  4. 最终产品所需容量及规格。
  • 专家以每GB理论成本0.08美元举例，原厂生产成本可能约为0.05美元，剩余部分覆盖利润与市场溢价。
  • 在供需严重失衡时，需要加入MOR，即市场偏差系数：
  1. 普通紧缺情况下可能比理论值高约10%；
  2. 极端短缺情况下可能高出约60%。
  • 在最终谈判阶段，大采购量可形成规模效应，实际价格可能在模型价格基础上获得一定折扣。

b) 2027年价格还会继续上涨吗？

  • 专家预计价格仍有小幅上涨空间，但上涨曲线会继续收窄。
  • 上涨幅度下降的原因包括：
  1. 供给持续增加；
  2. SSD满足率逐步回升；
  3. 消费端价格接近顶部；
  4. 中国供应商及模组厂供给增加；
  5. 部分企业通过SSD降配控制需求。
  • 但企业级DRAM、HBM及E-SSD仍受到AI服务器需求支撑，价格短期内不会快速转为大幅下降。

c) 市场价格下跌时，LTA价格是否也会下调？

  • 可以下调，这正是“Subject to Market Situation”的含义。
  • 可能推动价格下调的因素包括：
  1. 黑天鹅事件导致需求大幅下降；
  2. 长鑫等中国厂商快速扩产；
  3. 中国供应商进入戴尔更高等级白名单；
  4. 新增供给改变原有供应商竞争格局。
  • 若市场价格显著下降，戴尔会重新评估是否继续按原高位价格采购，并要求原厂调整价格。

7. 2027年服务器与存储需求展望

a) 2027年服务器DRAM和SSD订单预计增长多少？

  • 服务器DRAM：
  1. 2027年订单量及出货量预计较2026年增长约15%；
  2. DRAM基本不存在通过单条降配降低容量的情况。
  • 企业级SSD：
  1. 按出货条数计算，2027年预计较2026年增长约30%；
  2. 增长部分受到单条SSD容量下降的影响；
  3. 原来使用1条大容量SSD的服务器，可能改用2至3条小容量SSD；
  4. 因此，条数增长不完全等同于总容量同比增长。

b) 2027年CSP与非CSP服务器出货量预计增长多少？

  • CSP服务器出货量预计较2026年增长约40%。
  • 非CSP企业服务器出货量预计增长约2%至3%。
  • 非CSP增速较低，但存量基数较大。
  • CSP是2027年服务器增量的主要来源。

c) 2027年CSP增长预期为何持续上调？

  • 对2027年CSP服务器增长的预测持续上修：
  1. 2026年Q1时预计增长约30%；
  2. Q2时上调至约33%；
  3. Q3时进一步上调至约40%。
  • 上调主要来自英伟达订单及相关AI基础设施需求增强。
  • 数据中心建设投入持续增长：
  1. 专家提到相关CSP资本支出由约8500亿美元提升至约9600亿美元；
  2. 增量约1100亿美元；
  3. 新建数据中心及部分退役设施替换仍带来较大投资需求。

d) 为什么部分AI企业预计增长3至4倍，但存储订单只增长15%至30%？

  • AI业务收入、Token消耗或模型调用量增长，并不等同于服务器及存储需求同比例增长。
  • 主要差异来自：
  1. 计算和存储利用率提升；
  2. 现有数据中心容量仍可消化部分增量；
  3. SSD单条容量下降，条数增长但总容量增幅有限；
  4. 高价格抑制部分训练需求；
  5. 部分产品发布周期被推迟；
  6. 供给扩张速度高于企业加单速度。

8. Lead Time与存储周期判断

a) 判断存储供需和价格拐点最重要的指标是什么？

  • 专家认为最核心、最具领先性的指标是交付周期，即Lead Time。
  • 相较于订单量、满足率和价格，Lead Time能够更早反映：
  1. 原厂产能利用率；
  2. 实际供需紧张程度；
  3. 订单积压情况；
  4. 未来价格变化方向。
  • 专家调研时，应持续追踪三星、SK海力士、美光等供应商不同DRAM、SSD和HBM产品的Lead Time。

b) 当前不同存储产品的Lead Time是多少？

  • 不同产品的Lead Time差异较大：
  1. 相对标准化、供给较多的产品约46周；
  2. HBM及其他高端紧缺产品最高约84周。
  • 区间较宽的原因是：
  1. 标准化产品可获得国内及模组厂供给；
  2. 高端HBM产品供应商较少；
  3. 不同产品的产能扩张速度存在明显差异。

c) Lead Time在2026年内如何变化？

  • 专家给出的阶段性数据为：
  1. Q1约56周；
  2. Q2一度达到182周，供应极度紧张；
  3. 随后标准化产品回落至约46周；
  4. 高端紧缺产品仍约84周；
  5. Q4标准化产品预计逐步下降至44至45周；
  6. 高端产品预计由84周下降至约70周。
  • Q2的182周属于极端状态，接近3年的等待时间，反映当时供应异常紧张。

d) 2027年Lead Time预计降至什么水平？

  • 当前约46周的标准化产品，预计下降至42至44周左右。
  • 当前约84周的高端紧缺产品，预计下降至约56周，仍接近1年。
  • 行业正常Lead Time约为32周，因此即使2027年下降，整体供应仍未完全恢复至正常状态。

e) Lead Time下降到什么程度，价格才会回到正常水平？

  • Lead Time开始下降时，价格通常会同步走弱，因此它是价格的领先指标。
  • 专家认为：
  1. Lead Time下降意味着涨价动能减弱，价格可能开始明显回落；
  2. 但Lead Time仍在40周以上时，价格尚难完全回到涨价前水平；
  3. 当Lead Time降至40周以下，价格才有望回到涨价前水平；
  4. 若Lead Time进一步降至约4周，则价格通常会回归历史上较为合理的常态水平。
  • 因此，当前46至84周的Lead Time仍显示高端存储供应偏紧，尚不支持价格全面回归正常区间。

f) Lead Time是如何计算的？

  • Lead Time由供应商预测与实际订单数据共同确定：
  1. 供应商根据产能、利用率、在手订单及可满足产量提供预测；
  2. 戴尔统计过去一个季度的实际下单量和实际收货量；
  3. 对比实际下单值与收货值，判断真实供应缺口；
  4. 综合供应商预测、历史准确率及实际履约结果，形成合理的Lead Time判断。
  • 对未来年度的Lead Time预测主要来自原厂：
  1. 原厂根据当前在手订单和产能规划进行测算；
  2. 戴尔再结合原厂过去预测与实际交付之间的偏差进行修正。

分析师：DRAM价格上涨较多，我们如何接受这样的涨幅？终端客户是否可能因为价格上涨而取消订单或放弃采购？

专家：存在这种可能。DRAM分为2种情况，其中1种用于consumer，也就是个人PC领域。该领域使用的是low power DDR4，即低损耗的DDR4内存条。这类内存条的价格同样有所上涨，但终端客户对价格非常敏感，因此我们会尽量将这部分涨价转嫁到价格较高的电脑上。高端电脑使用的DRAM价格也在上涨。

专家：对于支撑度较低的涨幅，我们会用其抵消低端台式机或笔记本电脑采用的LPDDR4等低端部件所受到的影响。因此，我们主要依靠产品组合和不同的产品配置来消化、稀释最终涨幅，而不是直接将其转嫁给终端市场。在今年消费电子市场不太景气的情况下，我们也很难消化市场份额方面的影响，这是第1点。

第2点，在服务器领域，主要涉及较高端的LPDDR5以及HBM等更高端产品。这2类产品的涨价基本可以转嫁给终端客户。大家都知道，目前涨价的主要是高端产品，产能最紧张的也是高端产品，因此客户对最终涨价的接受度相对较高，也给了我们足够的空间来吸收价格涨幅。在这种情况下，涨幅可以向外传导。

分析师：听起来，企业端的涨幅可能比消费端更高，是吗？

专家：是的，一直以来，企业端的涨幅都高于消费端。一方面，企业端所使用产品的基础价格本来就比消费端高，因为产品规格更高，对可靠性的要求更高，带宽及带宽速度也更高。因此，从产品本身来看，企业级产品的价格高于消费级产品。另一方面，企业级客户对最终涨价影响的吸收能力更强，因此价格可以向下游传导。这也回答了您的问题，即企业级产品的涨幅会高于消费级产品。

分析师：42%。
