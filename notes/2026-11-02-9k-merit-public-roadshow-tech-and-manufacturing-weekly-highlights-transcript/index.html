专家会议纪要

1. CSP需求、增长与资本开支趋势

a) 如何看待需求侧CSP的业绩表现及未来趋势？

  • CSP需求增长仍然较强，并处于加速阶段，但从2027年至2028年的早期信号来看，不同公司的增长节奏已经开始分化。
  • 对本季度CSP业绩的判断相对谨慎，但目前尚不能直接推断2027年下半年需求一定转弱，仍存在较大变数。
  • 未来1—2个季度需要重点验证：
  1. CSP能否获得更多订单；
  2. 新增产能上线后，需求能否再次加速；
  3. Anthropic上市后，市场如何评估AI需求、订单和融资情况。
  • 未来几个月市场可能围绕订单、产能、资本开支反复博弈，股票表现可能相对承压。

b) 如何评价谷歌本季度业绩及未来资本开支？

  • 谷歌本季度表现与前瞻判断基本一致，但增速放缓程度比预期更明显。
  • 原本预计同比增长约14%—15%，实际表现可能低于此前预期。
  • 若谷歌能够通过广告变现对冲主营业务压力，整体增速仍有望维持两位数，但主营业务稳定性仍需持续验证。
  • 根据当前backlog测算，谷歌2027年云业务增速可能达到80%以上，其中已考虑一定比例的TPU外售。
  • 该预测仍可能随未来几个季度的backlog、产能和交付节奏变化而调整。
  • 如果2027年下半年云业务增速降至100%以下，同时主营业务问题仍未得到充分解决，则对2028年资本开支进一步上修应保持谨慎。
  • 相比其他CSP，谷歌2028年资本开支的不确定性可能更明显。

c) AWS对未来增长的指引如何？

  • AWS是几家CSP中表态最乐观的一家。
  • 公司预计2027年、2028年增速可以保持在40%左右，这意味着至少2027年不太可能出现明显放缓。
  • AWS CEO表示：
  1. 2027年产能已经全部被预订；
  2. 2028年较多产能也已确定。
  • AWS规模较大，pipeline主要由AI Lab订单驱动，当前需求能见度相对较高。
  • AWS需要自行承担重资本投入，但这与上一轮云计算周期相似：前期重资本开支会形成基础设施壁垒，并在行业进入收获期后体现竞争优势。

d) 如何看待微软AI需求、Azure增速及后续增长驱动？

  • 微软此前已明确表示，AI需求正从AI Lab向各行业、各企业广泛应用扩散。
  • Enterprise AI从今年到明年将持续加速，市场容量也足够大，但其增长斜率可能低于过去1—2年由AI Lab大额订单驱动的增长斜率。
  • 如果微软不希望将全部capacity集中服务少数AI Lab，未来增长驱动必须转向Enterprise AI。
  • 未来4个季度的核心问题是：Enterprise AI的增长速度能否承接AI Lab订单增速的放缓。
  • 本季度Azure环比基本持平。微软解释称，公司不愿承接具有明确上线时间要求、但现有交付能力无法满足的订单。
  • 随着新增capacity上线，Azure在Q4、明年Q1甚至Q2仍可能继续加速。
  • 仅根据当前backlog推算，微软2027年增速可能为40%—45%，低于本季度的48%，因此2027年下半年存在一定不确定性。
  • 微软管理层多次强调需求多元化，整体指引风格仍较谨慎。

e) 如何看待Meta的AI投入和资本开支？

  • Meta当前最大的变量仍是资本开支。
  • Muse Agent仍处于较早阶段，暂不足以支撑Meta在2028年再次大幅扩张资本开支。
  • 但Meta由创始人主导决策，管理层投入决心较强，即使短期商业回报不足，也可能继续维持高投入。
  • 因此，Meta资本开支的持续性不能只依据短期产品变现情况判断。

f) CSP整体趋势的核心结论是什么？

  • 几家大厂本季度的AI相关增速均在加强。
  • 但推演至2027年下半年至2028年，增长斜率、资本开支和需求结构已经出现不确定性。
  • 当前尚不能判断AI基础设施周期一定会转弱，未来仍需要结合订单、产能、Enterprise AI渗透及融资情况动态验证。

2. Enterprise AI、软件市场与Anthropic

a) Enterprise AI是否已经从POC进入生产环境？

  • 通过对IT咨询公司及FDE专家的持续调研，企业从POC走向生产环境的比例确实大幅提升。
  • 多家关键软件公司连续几个季度的业绩，以及微软管理层的公开表态，均验证了这一趋势。
  • 微软全球商业负责人也提到，2026年上半年企业从POC进入生产环境的速度正在加快，因此可以对2026年下半年加速形成预期。
  • 这一变化应被理解为Enterprise软件中期趋势性加速，而不是资金从硬件向软件进行短期高低切换。

b) 当前软件板块的投资机会如何分层？

  • 市场对软件板块的预期已经不低，大量原本配置硬件的资金在8—9月转向软件。
  • 软件公司将出现明显分层：
  1. 核心AI Infra及采用consumption模式的公司，仍具备较强增长潜力；
  2. 大量传统软件公司仍无法真正完成AI交付，只能披露签单数量、渗透率等早期指标；
  3. 后一类二、三流软件公司本季度可能暴露实际兑现不足，股价存在回落风险。
  • 因此，产业趋势仍然看好，但股票交易层面的预期和估值已较充分。

c) Anthropic近期增长情况如何？

  • 根据当前信息，Anthropic 10月ARR环比增速可能为10%—20%，但仍需进一步验证。
  • Claude 5.5反馈较好，对ARR增长形成正向拉动。
  • 如果月度ARR增速达到20%，将属于较强表现，并可能对市场情绪形成支撑。
  • Anthropic在Q4、明年Q1及之后几个季度可能持续成为市场博弈焦点。

d) Anthropic的backlog和RPO较低是否意味着需求不足？

  • IPO披露信息显示，Anthropic的backlog和RPO不算高，可能只能覆盖Q2、Q3收入。
  • 但这不一定代表需求存在问题，因为其约80%的收入来自按用量收费的consumption模式。
  • consumption模式难以预测：
  1. 企业客户通常只签订框架协议；
  2. 基础seat之外的增量按实际用量收费；
  3. 企业会对用量设置上限，但自身也无法提前确定当季实际消耗量。
  • 从模型到应用，未来可能有更多公司采用consumption收费模式，市场需要至少前两个季度逐步适应这种低可预测性的收入结构。

3. AI融资、流动性与市场策略

a) AI基础设施融资需求是否可以满足？

  • 2027年CSP整体融资缺口预计约为3,000亿美元。
  • 从产业角度看，这部分硬融资大概率能够获得，但债券市场在融资过程中的波动会反复影响股票市场。
  • 北美已开始申请的AIDC项目合计约330GW，其中必然有大量项目无法最终落地。
  • 头部大厂的融资需求仍较可能得到满足，但融资成本和市场风险偏好会影响股价表现。

b) 如何理解黄金大跌但美元和美债涨幅有限？

  • 当天黄金跌幅较大，但美元指数和10年期美债收益率涨幅均不明显，市场也没有出现明显的“flight to safety”交易。
  • 欧洲出现问题后，欧洲投资者增持美债，日本和中国仍在出售美债，中国央行继续增持黄金。
  • 在缺乏明显避险交易的情况下，黄金大跌更可能是部分大额投资者短期流动性不足，被迫出售黄金补充现金。

c) 市场是否已经接近流动性危机？

  • 当前距离全面流动性危机仍较远，但流动性正在结构性趋紧。
  • AI数据中心建设周期通常为1—2年，而短期信用增量按季度变化，二者可能发生期限错配。
  • 此前美联储向市场补充了约5,000亿—6,000亿美元资金，加上银行规则调整释放流动性，短期信用增量一度超过融资需求。
  • 当前头部大厂自由现金流已经大量消耗，也开始增加借债，债务增长速度逐步超过短期信用增量。
  • 月底财政部结算会进一步收紧流动性，月初通常有所缓解；本周流动性虽好于上周，但改善幅度有限。

d) 未来几个月应采取怎样的交易策略？

  • 受访者判断，中期选举前市场可能不会出现特别大的政策变化。
  • 地缘冲突若快速结束，可能形成短期利好并推动市场反弹。
  • 但由于流动性结构性趋紧，未来几个月市场突破此前高点的概率不高。
  • 交易策略上应谨慎“buy the dip”，更多考虑“sell the rip”。
  • 若短期发生流动性事件并迫使美联储购买国债、投放流动性，反而可能推动市场快速反弹；如果没有明显事件，流动性偏紧状态可能缓慢延续。

4. AI政策、数据中心建设与开源模型

a) 当前美国AI政策的核心矛盾是什么？

  • 宏观政策、流动性和利率变化均围绕AI领导权展开。
  • 白宫希望将AI上升为国家战略，并由联邦政府统筹发展节奏，但州县政府、联邦机构及部分AI公司并不完全服从统一安排。
  • OpenAI更倾向于与白宫合作，Anthropic则更强调自身独立性。
  • FTC、CIA、商务部、国防部及美联储均有各自诉求，各机构都希望在AI时代保有话语权。

b) 地方政府对AI数据中心的支持是否发生变化？

  • 前两年地方政府主要沿用既有政策配合数据中心建设，但由此承担了较大财政和资源压力。
  • 当前美国两党在地方层面逐步形成共识：州县政府不再普遍让利，而是按照各州实际情况制定政策。
  • 联邦政府未来可能减少对部分基础设施项目的补贴，例如联邦土地上的部分核电项目。
  • 数据中心建设门槛将提高，更多成本需要由企业自行承担。

c) 推理应用元年对融资和资本开支意味着什么？

  • 过去资本开支主要由前沿模型训练需求、大厂自由现金流和自有存款支撑。
  • 进入推理应用阶段后，数据中心建设、企业AI合规和外部融资需求的重要性明显提升。
  • 美联储和其他监管机构开始获得更多话语权，利率、信用供给和融资条件将直接影响建设节奏。
  • 微软提出可延后第三方数据中心资本开支，意味着CSP可根据供需和融资环境灵活控制建设速度。
  • 头部企业仍有能力解决资金问题，缺乏CSP合作或信用支持的第三方主体融资难度更高。

d) 美国开源模型政策可能如何演变？

  • 美国当前开源模型供给相对不足，部分开源模型明显落后于商业前沿模型。
  • 中国开源模型与美国前沿模型的差距被认为约为4—7个月，参数规模已达到万亿级。
  • 较可行的政策方案是按明确时间表开放上一代商业模型，例如在商业发布6—8个月后开源。
  • 该方案仍处于早期讨论阶段，但被认为是填补美国开源模型空白、应对中国竞争的较现实路径。

5. Unity广告业务与AI游戏生态

a) Unity Q3广告业务表现如何？

  • 预计Unity Q3广告业务环比增长接近33%，其中Victor收入环比增速可能达到37%。
  • 公司此前对Q3 Victor环比增速指引约为19%—21%，海外买方预期约为29%—30%；若最终实现37%或更高，将明显超过预期。
  • Q3最主要的增量来自：
  1. 广告主数量环比增长28%；
  2. 单个客户平均支出增长10%；
  3. D28/DRB从测试阶段进入稳定、规模化投放；
  4. Runtime数据投入使用；
  5. 非游戏广告主开始进入平台。
  • Unity Q3 GAAP净利润预计将实现盈利，目前non-GAAP净利润约7亿美元，对应PE约23.7倍。

b) 专家调研对Unity的反馈如何？

  • 本次调研5位专家，其中4位认为Unity Q3广告业务增长超预期，3位认为Unity在客户预算中的份额提升超预期。
  • 一家头部综合游戏公司认为Q3略低于预期，主要原因是自身产品上线节奏后移，大规模投放将在Q4进行。
  • 二次元游戏专家反馈，D28能够识别短期未付费但长期价值较高的用户，ROI由上季度约2.4提升至本季度约2.8。
  • Unity新增预算可能主要来自Meta和AppLovin的迁移。

c) Runtime数据为什么是Unity长期最重要的变化？

  • 市场约70%的移动游戏由Unity引擎制作，Unity能够获取游戏时长、广告观看频率、局内行为和转化间隔等精细数据。
  • 过去受合规政策限制，Unity没有将引擎数据用于广告投放；从上季度末开始，公司正式使用Runtime数据。
  • Runtime数据可以：
  1. 降低对广告主回传和MMP数据的依赖；
  2. 弥补Unity缺少Adjust等MMP资产的短板；
  3. 提升用户分层、广告预测和定向能力；
  4. 持续训练底层模型，提高长期推荐精准度。
  • 一、二季度的改善更多来自增流，但从Q3开始，Runtime数据将成为更重要的长期驱动力。

d) Unity广告主结构发生了哪些变化？

  • 9月份约40家Unity广告主中，有5家属于非游戏类客户，主要包括短剧和电商。
  • Q3约5%—10%的广告支出已来自非游戏客户，而过去约99%的流量与游戏相关。
  • 非游戏客户目前仍以测试和转化投放为主，尚处早期阶段。
  • 广告主多元化能够帮助Unity提高向发布商支付的CPM，从而获取更多广告库存。

e) 如何看待Unity Q4增长？

  • 截至10月，Victor收入环比增速可能已达到19%—20%。
  • 结合圣诞节、美国寒假和游戏广告旺季，旺季环比增速可能达到40%。
  • 出于保守考虑，预计Q4 Victor收入环比增长约30%。
  • Unity正从产品修复阶段转向规模化扩张，商业模式也由单纯IAP推广向广告与IAP混合变现发展。

f) Unity与谷歌合作生成AI游戏有何意义？

  • 谷歌正通过Gemini调用Unity工具，帮助创作者生成AI游戏。
  • 长期价值主要体现在：
  1. 降低游戏制作门槛，扩大Unity引擎用户群；
  2. 增加AI游戏供给和流量；
  3. 缓解Unity广告库存不足的问题；
  4. 为广告业务提供更多下游流量。
  • 短期1—2个季度贡献可能有限，仍需打通内容制作、供给扩张和创作者变现路径。

6. AppLovin经营表现与竞争压力

a) AppLovin Q3表现如何？

  • Q3收入预计同比增长约49%，大致达到公司指引高端。
  • 专家整体反馈为符合预期或略低于预期，主要压力来自：
  1. 获客成本明显上涨；
  2. Unity广告效果改善并分流预算；
  3. 游戏广告算法改善幅度有限；
  4. 电商业务Q3扩张速度低于此前预期。
  • 游戏广告已进入相对成熟阶段，未来增速可能较低但相对稳定，长期增长更依赖应用和电商业务。

b) AppLovin的模型提升是否得到验证？

  • 本次调研中，没有专家反馈AppLovin模型出现明显的大幅提升。
  • Q3算法虽有改善，但实际效果并不显著。
  • 相比之下，Unity受益于Runtime数据和第二代算法渗透，模型提升更加明显。
  • 因此，现阶段对Unity的判断相对更乐观。

c) AppLovin电商业务Q3表现如何？

  • 国内头部代理商反馈，AppLovin电商业务Q3明显降速，算法和ROI均未明显改善。
  • 此前预计日均投放规模可达到200万美元，实际测试约为160万美元。
  • 主要原因包括：
  1. 开户系统调整；
  2. 擦边类产品投放政策收紧；
  3. 电商转化链路比游戏下载更长；
  4. 素材制作要求更高。
  • 电商广告需要完成点击、付款及最终转化，对用户价值判断和算法能力要求更高。

d) 为什么Q4电商业务可能加速？

  • Q4叠加黑五及季节性旺季，电商广告主可能明显增加。
  • AppLovin扩大了国内代理资格，并通过合作伙伴推荐提供更多返现和激励。
  • 离职专家认为，Q4电商业务仍有机会实现同比翻倍增长。
  • 但其核心卡点仍包括：
  1. 激励广告素材通常需要约60秒，明显长于Meta和谷歌常见的短视频素材；
  2. 广告主需要制作并测试大量定制素材；
  3. AppLovin在电商领域的知名度仍不足；
  4. 广告主需要较长时间学习和适应平台。

e) AppLovin低估值是否真实反映便宜？

  • 预计2026年净利润约50亿—55亿美元，对应表面PE约14倍。
  • 但如果AppLovin进入防守阶段，可能需要降低take rate、向客户返还部分收益，以维持广告预算和竞价能力。
  • 当前广告竞价明显提升，不排除公司通过牺牲take rate帮助广告主提高出价。
  • 若毛利率因此下调，实际估值未必像表面PE显示的那么低。
  • 后续最核心变量是Q4电商业务能否超预期，并验证第二增长曲线。

提问者：目前市场是否已经接近流动性危机？流动性结构发生了哪些变化？

回　答　者：整体来看，市场距离流动性危机仍然较远。短期流动性的增加，也就是信用的增加，需要按季度观察；但AI相关债务和资本开支涉及数据中心建设，建设周期通常为1、2年，时间较长，因此周期之间有时会出现错配。

例如，26年上半年可能出现短期错配。去年下半年发生过“repo crisis”，随后美联储向市场增加了大约5、6千亿资金。同时，20年年初银行规则发生变化，释放了更多资金。因此，之前几个季度按季度来看，短期信用的增加，也就是短期流动性的增加，实际上超过了融资需求。

现在的情况已经发生变化。头部大厂的自由现金流已经用完，也需要开始借债。此时债务规模仍在增长，但按季度计算的短期流动性，即信用增量，实际上会跟不上债务增长。从信贷增量以及包括美联储加息在内的各方面指标中，都可以看出这一点。

因此，目前尚未达到流动性危机的程度，但流动性正在结构性趋紧。尤其是上周五恰逢月底，涉及财政部结算。一般而言，月初流动性会有所缓解。本周流动性确实比上周好一些，但改善幅度并不大。
