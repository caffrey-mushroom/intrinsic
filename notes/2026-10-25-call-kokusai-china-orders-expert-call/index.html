纪要总结

专家访谈纪要

1. 国内订单与交付量变化

a) 当前财年及下一财年的国内设备交付量有何变化？

  • 当前财年口径
  1. 公司按照日本财年统计，即每年4月至次年3月。
  2. 当前财年预计交付 450多台12英寸设备，与3个月前的判断基本一致。
  3. 450多台仅包括12英寸设备，不包括8英寸设备。
  • 下一财年口径
  1. 加上8英寸设备后，下一财年国内预计发货量接近 800台。
  2. 其中12英寸设备接近 700台，其余主要为8英寸设备。
  3. 相较当前财年的450多台，下一财年国内设备需求将显著增长。
  • 数据性质
  1. 专家提供的并非单纯销售订单数据，而是内部验机及预计发货数据。
  2. 因此，接近800台更接近预计可完成发货的数量，而非仅停留在意向或订单层面。
  3. 设备发货后，受晶圆厂内部空间和安装节奏影响，部分设备可能先存放在仓库，再逐步移入厂内安装。

b) 当前财年的设备交付节奏如何？

  • 当前财年上半年完成约 150台，下半年任务量约 300台，下半年较上半年翻倍。
  • 下半年300台的季度分布整体较为平均。
  • 下一财年接近800台的交付预计也相对均衡：
  1. 月均约70台；
  2. 高峰月份可达到约92台；
  3. 较低月份约45台。
  • 专家认为，下一财年800台预计发货量后续更可能继续增加，而非减少。

c) 为什么当前财年下半年交付量明显高于上半年？

  • 上半年多座存储晶圆厂仍处于建设阶段，尚未进入大规模设备搬入阶段。
  • 下半年上海长鑫、长存三厂等项目开始Move in，存储设备需求集中释放。
  • 上半年约150台设备主要来自中芯系逻辑产线，包括：
  1. 中芯东方；
  2. 中芯京城；
  3. 永芯科技；
  4. 燕东微旗下相关项目。
  • 下半年约300台设备的需求主体转为长鑫、长存等存储客户。

d) 下一财年800台是否存在无法按期交付的风险？

  • 专家认为，整体不必过度担心无法交付：
  1. 公司正通过扩建工厂、增加班次和跨区域人员支援提升产能；
  2. 历史上也曾出现一年从200多台提升至约600台的情况；
  3. 大规模订单并非公司从未经历过。
  • 主要风险不在总体需求，而在人员招聘、部分关键零部件供应和个别机型的长交期。

2. 装机、验机能力与人员扩张

a) 当前人员配置能否支持450台及未来800台的交付任务？

  • 现有人员基本只能勉强完成当前财年450多台的任务，部分区域仍存在缺口。
  • 若下一财年发货量接近800台，现有人员配置肯定不足，公司正在持续招聘。
  • 公司通常较少采用多班倒模式，因为客户需要为额外班次支付费用。
  • 当前主要通过跨区域调配人员支持装机和验机：
  1. 各地区售后人员协助装机和验机；
  2. 日本、新加坡、韩国等地区人员可能前往中国支援；
  3. 但目前海外业务也较繁忙，可调配人员存在不确定性。

b) 当前中国区人员规模和结构如何？

  • 中国区员工总数约 400多人。
  • 其中约三分之二为售前、售后及装机相关工程师，其余为销售、总务等人员。
  • 售后工程师均为全职员工。
  • 经专家修正，售前人员约 80人。
  • 当前人员需求的重点并非单纯验收，而是设备装机及各地售后支持。

c) 哪些地区的人员缺口较大？

  • 人员需求主要随设备分布确定，当前设备增量集中在长三角及主要存储项目所在地。
  • 重点招聘地区包括：
  1. 上海；
  2. 合肥；
  3. 北京；
  4. 武汉。
  • 北京等地当前至少存在约11—12人的缺口，正在陆续招聘。
  • 大湾区设备量相对较少，目前没有明显人员缺口。

d) 当前招聘难度和人员要求如何？

  • 装机部门招聘速度较慢，最近一个月能招到1人已属较好水平。
  • 各地售后分公司的招聘规模相对更大，但仍需要时间补足缺口。
  • 新员工入职后必须接受培训，无法立即独立承担装机任务。
  • 公司目前提高了招聘门槛：
  1. 硬件装机岗位：原则上要求本科学历，通常没有语言硬性要求；
  2. 工艺装机岗位：硕士起步，并要求日语能力或较强的英语能力。
  • 一至两年前，硬件装机岗位大专学历也可以，但通常需要外包装机或同业工作经验。

3. 客户结构及需求增长来源

a) 下一财年接近800台的需求主要来自哪些客户？

  • 主要客户包括：
  1. 长鑫；
  2. 长江存储；
  3. 大连海力士；
  4. 泉州晋华；
  5. 绍兴UNT；
  6. 南亚Fab 6等。
  • 明年增长最多的客户预计为长鑫，其次为长江存储。
  • 专家粗略判断，长鑫可能占下一财年国内发货量的 约70%，但该比例为经验估算，并非经过逐厂汇总后的正式数据。
  • 长鑫需求同时覆盖上海和合肥工厂，是下一财年设备增长的核心来源。

b) 逻辑与存储客户的需求结构将如何变化？

  • 当前财年上半年仍以中芯系逻辑产线为主。
  • 当前财年下半年开始，需求明显转向长鑫和长存等存储产线。
  • 从下一财年开始，国内逻辑产线扩产基本可以视为阶段性结束：
  1. 逻辑设备出货占比预计明显下降；
  2. 下一财年接近800台的主体将由长鑫和长存贡献；
  3. 国内需求增长将主要由DRAM和NAND扩产推动。
  • 部分逻辑设备虽然已进入厂区，但客户对交付和安装的紧迫性相对较低。

c) 大连海力士订单为何存在变化？

  • 大连海力士最初计划采购60多台Mini Batch设备，之后出现退单，剩余数量可能仅为30多台。
  • 退单大约发生在访谈前3个月，后续是否有进一步变化，专家暂不掌握。
  • 不排除客户将部分扩产安排从大连转移至其他地区或海外。
  • 这是专家首次遇到较明显的砍单案例，其他国内客户过去更多是追加订单。

4. 长鑫各地晶圆厂扩产与设备需求

a) 长鑫北京工厂的产能及设备填充进展如何？

  • 北京共有3个厂，专家提供的规划口径为：
  1. 1厂约5万片/月；
  2. 2厂约5万片/月；
  3. 3厂约10万片/月。
  • 三个厂合计规划产能约20万片/月。
  • 北京工厂采用合肥较成熟的制程，研发工作并不主要在北京进行。
  • 到下一年4—5月，北京工厂的设备填充将基本完成。
  • 后续北京每月约进入2—3台设备，到8月左右基本结束，不再是主要增量来源。

b) 长鑫上海工厂的设备进场节奏如何？

  • 上海一期初步规划约为 10万片/月，但外部土建仍未完全结束，主要是无尘室内部先行建成。
  • 专家根据经验估算，10万片/月规模大约对应50台左右相关机台，但实际数量会受工艺配置影响。
  • 已明确标注的设备进场节奏为：
  1. 4月约7台；
  2. 5月约17台；
  3. 6月约10台；
  4. 7月约18台；
  5. 8月约10台；
  6. 9月接近20台。
  • 上述数据仅为已经明确归属上海厂的设备，仍有部分设备尚未登记具体Fab，因此实际数量可能更多。
  • 10月至12月仍会有设备进场，后续月份目前已标注的数量约为每月6—7台。
  • 到2028年仍预计有设备继续进入，说明10万片/月可能只是阶段性规划，而非最终规模。

c) 长鑫合肥的后续扩产规划如何？

  • 合肥现有工厂仍在持续填充设备。
  • 长鑫还在合肥规划新的Fab，专家听到的远期规划规模较大，但具体产能数字尚未核实。
  • 内部数据显示，新建Fab可能从2028年开始进入设备搬入阶段。
  • 下一财年设备增量主要流向上海和合肥，北京增量将逐步结束。

d) 长鑫是否同时布局DRAM和NAND？

  • 长鑫的核心业务仍为DRAM。
  • 北京正在进行NAND相关尝试，并采购了与长江存储相同类型的Mini Batch设备。
  • 目前北京长鑫大约引进了3台相关设备，仍属于实验线阶段，尚未正式量产。
  • 公司最先进的Mini Batch设备似乎尚未大规模提供给长鑫。
  • 合肥目前尚未明显引进NAND相关Mini Batch设备，因此是否会布局NAND仍无法确认。

5. 长江存储扩产与设备导入

a) 长存三厂目前的设备进场情况如何？

  • 长存当前主要在推进三厂设备导入，整体仍处于初期阶段。
  • 已知的设备进场节奏为：
  1. 8月进入4台普通Batch设备；
  2. 9月没有设备进入；
  3. 10月进入1台普通Batch设备；
  4. 11月预计进入6台Mini Batch设备和4台普通Batch设备。
  • 长存三厂同时需要普通Batch和Mini Batch设备，不能因为普通Batch数量较多就判断其在大规模生产DRAM。
  • NAND生产本身需要不同类型设备共同完成不同工艺环节。

b) 长存是否也在研发DRAM？

  • 长存从上一年开始进行DRAM研发。
  • 相关DRAM实验设备可能主要放置在二期，整体采购量不大。
  • 氮化钛相关设备主要用于DRAM电极工艺，长鑫采购规模较大，长存也采购了同类设备进行实验。
  • 当前长存的主业和三厂扩产重点仍是NAND，DRAM暂未进入大规模量产阶段。

c) 长存三厂的国产化程度如何？

  • 长存三厂强调国产化，采购KE、TEL等海外厂商设备的比例受到一定限制。
  • 专家听说北方华创可能获得约100—120台设备订单，但这些设备大概率主要是Batch CVD或常压管设备，并非与KE直接对应的Batch ALD设备。
  • 北方华创的CVD和常压管产品相对成熟，部分设备已经具备使用条件。
  • 在Batch ALD领域，北方华创与KE相比仍存在较大差距：
  1. 薄膜电性仍需验证；
  2. 长期稳定性存在差距；
  3. 设备颗粒和附生物控制能力仍需提升。
  • 目前国产Batch ALD更多用于实验、验证或满足国产化导入要求，尚未全面替代KE。

6. 产品结构、工艺应用与ASP变化

a) DRAM和NAND分别使用哪些类型的设备？

  • DRAM设备
  1. 主要使用传统Batch设备；
  2. 涉及TiN、SiO₂、SiN等ALD工艺；
  3. 还包括Poly，即多晶硅相关设备；
  4. 相关设备广泛用于电容、电极和薄膜沉积环节。
  • NAND设备
  1. 主要使用Mini Batch双腔设备；
  2. Mini Batch属于KE较先进的设备类型；
  3. NAND层数较多，核心薄膜及电容相关结构对沉积设备要求更高；
  4. 普通Batch和Mini Batch需要配合使用，分别完成不同工艺步骤。

b) Mini Batch设备对收入和ASP有何影响？

  • Mini Batch设备的ASP明显高于传统Batch ALD设备。
  • 分析师提出Mini Batch ASP可能达到普通设备的2—3倍，专家认可产品结构升级将明显推动收入增长。
  • 当前设备价格存在较大差异：
  1. 普通ALD设备价格约在“1000”左右；
  2. TiN等高价值机型可达到“2000多”；
  3. 原始访谈未明确价格单位。
  • 长鑫以DRAM扩产为主，采购设备未必全部是价格更高的Mini Batch。
  • 长存NAND项目对Mini Batch需求更强，但其三厂国产化要求可能限制KE设备份额。
  • 因此，下一财年收入增长既来自设备数量增加，也来自部分高ASP产品占比提升。

c) 下一财年中国区收入是否有望翻倍？

  • 当前财年12英寸设备约450多台，下一财年12英寸设备接近700台、总量接近800台。
  • 在出货量显著增长及产品ASP提升的共同作用下，专家认为中国区收入翻倍具有较大可能性。
  • 但仍需注意：
  1. 日本总部通常给出的经营预期较保守；
  2. 最新预算会议刚结束，正式预算和下一财年预测尚未完全上传；
  3. 最终收入还受产品结构、验收进度和收入确认节奏影响。
  • 专家对完成交付相对乐观，但该判断尚不等同于公司正式业绩指引。

7. 交货周期与收入确认

a) 国内设备目前的交货周期有多长？

  • 大客户订单较少时，过去约2个月即可交付。
  • 目前随着订单增加，大客户交付周期已延长至约4—6个月。
  • 小客户正常情况下约需6个月，部分设备约需7—8个月。
  • 极端情况下，小客户曾遇到1年甚至2年的交货周期。
  • 交期差异主要取决于机台类型及关键零部件材料。

b) 为什么碳化硅部件设备的交期明显更长？

  • 炉管类、Batch类设备内部包括：
  1. 反应腔；
  2. 承载晶圆的晶舟。
  • 普通机台主要使用石英材料，供应能力相对充足。
  • 高温退火常压管的温度可达到1200℃以上，需要使用：
  1. 碳化硅晶舟；
  2. 碳化硅反应管。
  • 碳化硅材料价格高、生产周期长，相关部件交期可能达到1—2年，因此成为部分设备交付的主要限制因素。
  • 设备所用碳化硅为耐高温纯碳化硅材料，与Wolfspeed等企业生产的碳化硅晶圆衬底并非同一类产品。

c) 碳化硅部件主要由哪些供应商提供？

  • 相关部件主要依赖外采，供应商包括：
  1. 贺利氏；
  2. 日本信越；
  3. 韩国金刚及其他韩国供应商；
  4. 杭州大和等国内供应商。
  • 供应商不止上述几家，但专家未能完整列出韩国供应商名单。

d) 设备收入通常在哪个节点确认？

  • 专家不负责营业和销售事务，无法确认具体预付款比例及会计确认政策。
  • 从业务流程看，通常需要完成：
  1. 整机交付；
  2. 设备装机；
  3. 客户验证；
  4. 达到量产条件；
  5. 签署TAC。
  • 客户通常不会在下单时支付全款，签署TAC并满足验收要求后才会完成主要付款。
  • 因此，设备发货量与收入确认时间可能存在一定错位。

8. 日本产能扩张与关键零部件约束

a) 日本工厂如何应对订单增长？

  • 日本工厂已经实行两班倒生产。
  • 中国区也派遣人员前往日本工厂支援生产。
  • 原计划可能在中国西安建设工厂，并安排人员赴日学习，但后续西安建厂消息暂时消失，项目可能取消或调整选址。
  • 相关中国人员目前仍在日本支援。
  • 公司今年在现有厂区附近又购买了一块土地，并已推进新工厂建设。
  • 专家认为，由于设备工厂建设难度低于晶圆厂，下一财年实现产能翻倍存在一定可能。

b) 产能提升的最大零部件瓶颈是什么？

  • 当前较紧缺的关键零部件之一是真空计。
  • CVD和ALD设备需要在低压、接近真空的环境下运行，真空计用于精确检测设备内部压力，是不可缺少的核心部件。
  • 公司使用的真空计主要来自美国MKS。
  • 由于属于美国制造产品并受到出口管控：
  1. 真空计不能直接单独销售至中国；
  2. 必须先与整机组装，再随设备发往中国；
  3. 若下一财年业务翻倍，MKS供应能力可能成为产能瓶颈。
  • 相比之下，日本本土生产的其他零部件更容易通过扩产解决。

c) 明年产能翻倍是否现实？

  • 有利条件包括：
  1. 日本工厂已实行两班倒；
  2. 新购土地和新厂建设正在推进；
  3. 中国人员赴日支援；
  4. 公司历史上已有快速扩产经验。
  • 主要制约因素包括：
  1. MKS真空计等美国部件供应；
  2. 碳化硅部件1—2年的长交期；
  3. 中国区装机和售后工程师招聘速度偏慢；
  4. 新员工需要较长培训周期。
  • 综合来看，专家认为产能翻倍有机会实现，但关键零部件和服务人员能力需要同步扩充。
