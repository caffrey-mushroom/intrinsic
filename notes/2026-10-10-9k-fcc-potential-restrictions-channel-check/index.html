美国潜在光模块限制政策专家访谈纪要

1. 潜在“65%美国来源”限制的整体影响

a) 美国若要求光模块65%的BOM来自美国，对中国光模块产业链的整体影响有多大？

  • 专家判断，整体影响相对有限：
  1. 从光芯片、FAU到光模块组装的整体成本结构看，中国头部光模块企业目前使用的美国来源核心物料占比基本能够达到60%—65%。
  2. 1.6T及传统3.2T EML、硅光路线中，DSP、EML、CW光源、TIA、Driver及PIC等核心光电芯片合计后，基本能够达到65%的要求。
  3. 中际旭创、新易盛等头部企业当前已大量使用海外DSP、EML和硅光PIC，因此潜在限制对其现有业务的直接影响不大。
  • 风险主要集中于部分高端有源器件：
  1. 200G/400G EML、大功率CW光源等国内产能目前仍不充足。
  2. 国内70毫瓦、100毫瓦相关产品已逐步进入批量生产和扩产阶段，但更高功率、更高速率产品仍处于小批量或产能爬坡阶段。
  3. 如果规则要求增加美国来源器件采购，国内EML、CW光源等有源器件厂商可能面临供应链份额被挤压的风险。

b) 这一限制是否可能全面落地？

  • 专家认为全面落地的概率不高：
  1. 更可能针对军工、特殊安全场景或部分高功率、高速率产品实施。
  2. 在数通市场全面实施的难度较大，因为全球高端光器件和无源器件产能高度依赖中国供应链。
  3. 如果对FAU、DFU等中国优势环节实施严格限制，全球光模块供应链可能无法正常出货。
  • 最终影响取决于规则细化：
  1. 是按企业注册地、生产地还是产品原产地认定；
  2. 美国企业在中国、日韩或东南亚生产的产品是否算作“美国来源”；
  3. 封装、测试、组装等环节是否纳入BOM计算。

c) 对中际旭创和新易盛的影响如何？

  • 专家判断目前基本没有明显影响：
  1. 企业尚未收到客户针对相关条款的正式问询。
  2. 现有BOM中，美国来源的DSP、EML、PIC等核心物料占比较高，基本可以满足65%的要求。
  3. 若政策落地，企业可以进一步增加海外器件采购，对光模块组装和交付本身影响有限。
  • 更直接受影响的是上游国内有源器件企业，而非光模块龙头本身。

2. 1.6T光模块BOM结构与供应链情况

a) 1.6T EML路线的主要BOM如何构成？

  • 主要成本构成：
  1. DSP约占30%；
  2. 探测器加TIA约占10%；
  3. FAU约占2%；
  4. 隔离器约占1.5%—1.6%；
  5. 透镜、结构件和连接器约占5%；
  6. 基板约占4%；
  7. 封装测试约占20%。
  • EML与DSP合计可达到约65%，因此若按核心物料成本计算，基本可以满足65%的要求。

b) 1.6T硅光路线的BOM如何构成？

  • 主要成本构成：
  1. DSP约占30%；
  2. PIC约占7%—8%，探测器通常集成在PIC中；
  3. 两颗CW光源约占4%，另有口径估算CW光源占比约7%—8%；
  4. 探测器与TIA相关部分约占6%，具体口径取决于探测器是否合并计入PIC；
  5. FAU约占2.5%；
  6. 隔离器约占0.5%，不到1%；
  7. 透镜、结构件和连接器约占4%；
  8. 基板约占5%。
  • 硅光路线中，DSP与CW光源合计不足65%，但若加入TIA、Driver及PIC等核心光电芯片，基本可以达到65%。

c) 1.6T硅光模块中FAU和PIC的数量及价格是多少？

  • FAU：
  1. 通常采用8芯FAU；
  2. 每个模块使用1套；
  3. 单套成本约25美元。
  • PIC：
  1. 每个模块使用1颗；
  2. 单颗成本约50—55美元；
  3. 成本占比约7%—8%。

d) 1.6T核心芯片目前的国产化水平如何？

  • DSP：
  1. 中际旭创、新易盛并非100%使用美国DSP，也会使用部分国产DSP；
  2. 但目前国产DSP占比仍然较低。
  • EML：
  1. 专家估计约60%来自美国供应商；
  2. 国内100G EML已经开始小批量生产；
  3. 国内200G EML仍处于小批量阶段，尚未形成规模化供应；
  4. 预计下一年度国内200G EML有望逐步进入批量生产。
  • 硅光PIC：
  1. 目前海外产品占比接近70%；
  2. 中际旭创自研PIC尚未实现批量生产；
  3. 新易盛与外部厂商合作开发的PIC也尚未进入批量阶段。

e) BOM成本是否包含封装、测试和人工？

  • 计算口径存在差异：
  1. 企业内部完整成本测算可能包含封装、测试和组装；
  2. 若严格按美国相关规则计算，通常只计算材料成本；
  3. 封装、测试、组装人工等费用可能不纳入BOM来源比例。
  • 因此，前述各项占比需要结合具体规则口径理解，不能简单按完整制造成本直接相加。

3. 3.2T不同技术路线的BOM与合规能力

a) 3.2T EML路线的BOM构成如何？

  • 8通道EML方案：
  1. DSP约占30%；
  2. EML约占15%；
  3. TIA和Driver约占5%—6%，8通道需要8组；
  4. 单组TIA和Driver价格约7—7.5美元；
  5. 8芯FAU约占2%，成本约15美元；
  6. 隔离器使用8颗，单颗约2美元，占比约1.5%—1.6%；
  7. 透镜、连接器和耦合结构件约占5%；
  8. 基板约占4%—5%。
  • 16通道方案：
  1. 整体成本占比与8通道方案较为接近；
  2. 通常采用200G EML方案；
  3. DSP等核心器件的成本占比变化不大。

b) 3.2T EML、DSP的数量和价格如何？

  • EML：
  1. 8通道方案通常使用8颗EML；
  2. 200G EML报价口径约为18—20美元/颗，访谈中亦出现10—15美元的初步估算；
  3. 400G EML海外初步报价约20—25美元/颗；
  4. 国内400G EML目前量较少，价格尚不稳定，可能在30—36美元/颗，接近40美元。
  • DSP：
  1. 每个3.2T模块使用1颗DSP；
  2. 价格约320—360美元；
  3. 1.6T DSP价格约220—280美元，亦有约200美元的估算口径；
  4. DSP通常包含SerDes等相关功能。
  • 近期DSP价格据悉有所上涨，涨幅约10%—15%。

c) 3.2T硅光路线的BOM构成如何？

  • 8通道硅光方案：
  1. DSP约占30%；
  2. PIC约占8%，探测器等相关器件通常已集成；
  3. 两颗CW光源约占4%；
  4. TIA和Driver共8组，占比约5%；
  5. FAU约占2%；
  6. 隔离器约占0.5%；
  7. 透镜、耦合结构件和连接器约占4%；
  8. 基板约占5.5%。
  • 16通道方案的成本结构与8通道方案基本接近。
  • 将DSP、PIC、CW光源、TIA和Driver等核心光电芯片合并计算后，基本能够达到65%的要求。

d) 3.2T薄膜铌酸锂路线的BOM构成如何？

  • 薄膜铌酸锂路线通常采用8通道、单波400G架构：
  1. DSP约占25%；
  2. TFLN光芯片使用1颗，单价约180美元，占比约16%；
  3. CW光源使用4颗，占比约7%—8%；
  4. CW光源单价约20—25美元，功率约200毫瓦或300毫瓦；
  5. 探测器使用8颗，占比约4%，单颗约5美元；
  6. TIA和Driver约占5%—6%，单组约7—8美元；
  7. 高保偏FAU使用1套，单价约50美元，占比约4%；
  8. 隔离器约占1%，通常4颗为1套；
  9. 透镜及相关结构件约占5%；
  10. 基板约占5%。
  • 合规判断：
  1. DSP与CW光源合计约45%；
  2. 加入TIA和Driver后仍不足65%；
  3. 因此该路线相比EML和传统硅光路线，更难仅依靠指定核心器件满足65%的要求。

e) NPO路线的BOM和65%门槛情况如何？

  • NPO取消或弱化DSP后，核心物料占比结构发生明显变化：
  1. PIC约占10%，单价约90美元；
  2. 外置CW光源使用4颗，占比约12%；
  3. TIA和Driver使用16组，占比约30%；
  4. 单组TIA和Driver约18美元；
  5. FAU使用1套，约50美元，占比约5%；
  6. 隔离器占比约7%；
  7. 基板占比约7%—8%。
  • CW光源与TIA、Driver合计约50%，距离65%仍有差距。
  • 如果把硅光PIC等核心光电芯片计入，整体占比可进一步提升，但规则适配仍比带DSP的传统方案更复杂。
  • 外置CW光源和隔离器原则上也会计入BOM材料成本。

f) CPO/光引擎路线的BOM如何计算？

  • 原则上按照光引擎BOM计算，而不是按照整台交换机计算。
  • 以单波200G硅光架构为例：
  1. PIC约占10%，使用1颗，价格约100美元；
  2. TIA和Driver使用16组；
  3. DFU使用1组、1套，采用混合通道模式，占比约16%；
  4. CW光源使用4颗400G产品，占比约45%，单颗价格30多美元；
  5. 隔离器占比约1%—2%；
  6. 其他部分与传统硅光方案基本相近。
  • 将CW光源、PIC及相关光电芯片纳入计算后，核心物料占比约可达到65%，甚至略高。

4. 海内外核心器件供给与产能格局

a) 海外高端EML和高功率光源的市场格局如何？

  • Lumentum：
  1. 在200G EML领域的市场份额约50%—60%；
  2. 在部分高功率硅光光源领域也占据较高份额。
  • Coherent：
  1. 在200G EML领域份额约30%；
  2. 在部分高功率硅光光源领域份额约20%—40%，具体随产品口径变化。
  • Lumentum与Coherent合计占高端、高功率器件市场约70%—80%，市场集中度较高。

b) 海外供应商能否满足潜在限制下的全球需求？

  • 专家判断目前无法满足：
  1. Lumentum、Coherent等现有产能存在明显缺口；
  2. 海外厂商扩产速度相对较慢；
  3. 部分产能还受到铌酸锂等上游材料限制及良率约束；
  4. 即使设置70%甚至更高的海外来源要求，全球供应链仍需依赖中国供应商。
  • 海外厂商扩产更为谨慎，尤其日本企业通常不会一次性进行大规模产能建设。

c) 海外新增产能的时间表如何？

  • Lumentum据悉已在美国北卡罗来纳州建设6英寸铌酸锂工厂。
  • 预计该工厂在2028年左右开始批量生产并进入产能爬坡。
  • 短期内，海外新增产能难以完全弥补高端EML和高功率光源的供需缺口。

d) 国内高端有源器件的产能情况如何？

  • 国内CW光源和EML企业普遍处于扩产阶段。
  • 当前产量仅满足部分头部客户需求，整体供给仍然偏紧。
  • 即使向海外光模块厂商供货是一条潜在路径，短期内也受限于国内自身产能不足。
  • 国内1.6T、3.2T所需高功率、高速率光芯片仍需要时间完成批量验证和产能爬坡。

5. 规则认定、生产地与供应链重构

a) 中国企业将生产环节转移到海外，能否规避限制？

  • 专家认为未必能够规避：
  1. 如果规则按照企业归属或产品原产地认定，仅将封装、组装转移至海外可能无法改变产品属性；
  2. 中国企业即使在海外或美国设厂，也可能继续被纳入限制范围；
  3. 最终需要看法规对“厂家归属地”“生产地”和“原产地”的具体定义。

b) 美国公司在海外生产的产品是否算美国来源？

  • 专家倾向认为：
  1. 美国公司在中国生产的产品可能被认定为中国产品；
  2. 美国公司在日韩、东南亚生产的产品也未必被视为美国本土产品；
  3. 若严格按照美国本土生产口径计算，达到65%的难度将显著提高。
  • Coherent、Lumentum等企业在中国和东南亚均有生产布局，如果这些产品不计入美国来源，相关政策的可执行性会明显下降。

c) 政策执行的核心矛盾是什么？

  • 主要矛盾在于合规要求与实际产能之间难以平衡：
  1. 从供应商企业属性看，头部光模块企业的美国供应商占比较高；
  2. 从实际制造地看，许多美国企业的产品并非在美国本土生产；
  3. 若严格限定美国本土制造，现有供应链可能无法满足要求；
  4. 若放宽到美国企业全球产能，头部中国光模块企业则较容易满足65%的门槛。

6. 产业链受影响环节与关注方向

a) 哪些环节受潜在限制的影响最大？

  • 高端有源器件受影响较大：
  1. 200G、400G EML；
  2. 高功率CW光源；
  3. 高速率光芯片；
  4. 尚未规模化的国产硅光PIC。
  • 国内相关企业可能面临：
  1. 光模块客户增加海外采购；
  2. 供应链重新认证和重构；
  3. 高端产品导入节奏放缓；
  4. 新增产能利用率不及预期。

b) 无源器件企业是否会受到明显影响？

  • 专家判断相对影响较小：
  1. FAU、DFU等无源器件约90%的全球产能集中在中国；
  2. 海外缺乏足够替代产能；
  3. 如果严格限制中国无源器件，整个光模块供应链可能无法正常运行。
  • 因此，政策更可能聚焦CW光源、EML等高端有源器件，而不是全面限制FAU、DFU。

c) 中国光模块企业在全球的份额如何？

  • 中国光模块企业在全球市场占比约80%—90%。
  • 海外光模块厂商占比较低，难以在短期内替代中国企业的供应能力。
  • 这一产业格局决定了美国若实施全面限制，将同时冲击其本土AI算力和数据中心供应链。

d) 当前更值得关注哪些产业环节？

  • 国内方向：
  1. 光纤等材料端；
  2. 衬底材料；
  3. FAU、DFU等无源器件；
  4. 具备高端EML、CW光源量产能力的企业，但需关注政策风险与产能兑现。
  • 海外方向：
  1. Lumentum；
  2. Coherent；
  3. 日本住友；
  4. 日本三菱等高端光器件供应商。
  • 硅光PIC方面，海外主要涉及Tower Semiconductor、GlobalFoundries等厂商；国内已有多家公司布局，但整体仍处于研发、验证或小批量阶段。
