摘要

Claude Code 前产品负责人 Cat Wu 加入 OpenAI，使前沿模型公司的产品人才竞争受到关注。企业 AI 支出仍高度依赖深度用户，大量已经采购 AI的企业，在部门覆盖和任务使用上与领先客户存在明显差距。笔者认为，前沿模型公司的下一轮增长，将更依赖它们把模型进步转化为可靠产品的能力。Coding已经验证了模型突破、产品完善与付费扩张相互促进的路径，更广泛白领工作的采用还需要跨过可靠性、系统连接和组织流程等门槛。产品人才的价值由此进入收入增长的核心环节：让更多企业愿意把更多真实工作持续交给 AI，也让模型公司更早取得收入。

北京时间 11 月 5 日，曾负责 Claude Code 产品的 Cat Wu 宣布加入 OpenAI，领导核心产品（Core Products）的产品管理工作。她在入职声明中强调 OpenAI的用户规模，并提出要构建帮助个人和团队完成工作、让用户保有控制权的智能体。此前，Claude Code 工程师 Thariq Shihipar 和桌面版创建者 Anthony Morris 也相继宣布离开 Anthropic。

Cat 的新岗位延伸到更广泛的核心产品。她在 Claude Code 积累的经验，也与一个正在影响模型公司增长的问题有关：模型已经能够完成越来越多任务，用户真正愿意持续交给它的工作，仍然集中在少数场景和人群。

Claude Code 已经让一部分开发者从偶尔询问代码，走向委派完整任务。把类似变化带给更多企业和非技术员工，将直接影响模型公司的付费客户数量、单客支出和收入扩张速度。

一、AI 支出快速增长，深度使用仍然集中

从使用深度看，当前 AI 用户大致分化为两类。一类已经把 AI持续用于实际工作，包括率先采用的企业、开发者和重度个人用户；另一类仍处于试用或零散使用阶段，尚未找到合适用法，或在流程、安全和投入回报上面临约束。前一类已经贡献了可观支出，后一类的潜在需求需要通过可靠产品和业务部署逐步转化。

同一家企业内部也存在这种差异。大型公司的研发部门可能已经大量使用 coding 智能体，财务、采购和运营部门却仍停留在问答和零散文档处理。

投资 AI 公司的风险投资机构 Menlo Ventures，在 11 月发布的企业 AI 报告中，给出了这种分化的量化证据。基于近 400 位美国企业决策者的调查，受访企业报告的 AI 支出平均达到上年的 4.7 倍，中位数为 2.2倍；报告列示的企业采用率则从 55% 升至 65%。少数用户大幅增加使用，拉高了整体支出增幅。

图1｜企业 AI 支出增长呈现明显分化。来源：Menlo Ventures。

Anthropic 的客户内部也存在类似差距。其招股书显示，截至 9 月底，超过一半的财富 500 强企业已成为过去十二个月付费至少 10 万美元的客户。在其中可取得公开财务报表的上市公司样本里，第三季度向 Anthropic支付的费用，平均不到企业总费用的 0.1%；Anthropic 的头部十家财富 500 强客户，这一比例超过相关客户平均值的八倍，仍低于 1%。

这个差距体现了企业把 AI 用到多深。已经进入客户名单，只完成了采购关系的建立；从少数员工试用走到多个部门稳定使用，还有很大的支出差异。企业总费用包含大量无法直接由 AI 承接的项目，扩张需要落到具体任务和经济回报上。

Anthropic招股书还披露，过去十二个月付费至少 10 万美元的客户超过 11,900 家，贡献同期收入的74%。客户覆盖正在扩大，收入仍然集中在愿意持续投入的群体。后续增长既要争取新客户，也要让已有客户内部更多部门找到可用、可信、值得付费的工作场景。

二、Coding 之后，企业需求正在等待下一个台阶

早期重度用户已经证明了付费潜力，最近的支出变化则提出了新的问题。企业支出管理平台 Ramp 根据客户支付记录发现，按每员工 AI 支出划分的前 1% 企业，9 月人均月支出为 9,568 美元，环比回升 11.7%，仍比 7 月高点低3.1%。其另行跟踪的 token 支出在 8、9 月连续两个月几乎没有增长，同期调用量继续增加。

价格下降、模型切换与效率提升，正在改变任务增加与账单增加之间的关系。企业即使使用更多 AI，也会优化完成同一项工作的费用。依靠原有用户在原有场景中持续扩大消耗，很难长期保持初期的增长斜率。

Anthropic 的老客户仍有较强扩张。截至 9 月底，其净收入留存率约为900%，即纳入统计的同一批老客户，第三季度收入约为上年同期的九倍；前五大客户各自贡献的季度收入也创了新高。同比高增长与近期支出增速回落，分别描述了年度扩张和最近几个月的变化。笔者认为，后续收入增长更需要不断打开新的任务范围，并把低使用强度的客户转化为持续使用者。

摩根大通 11 月 3 日的中国 AI 行业报告，为这种增长节奏提供了一个解释：模型能力持续进步，但企业往往等到模型能够可靠完成一类新工作，才会明显增加委派。因此，需求可能按台阶上升，台阶之间存在等待期。摩根大通认为，目前正处于coding 与更广泛白领工作之间的阶段，后一阶段到来的时间晚于其原先预期。

图2｜模型能力与企业需求的台阶式扩张示意，虚线为预期。来源：摩根大通。

这使早期重度用户的扩张约束有了更具体的含义：一部分已经跑通的任务逐渐成熟，而下一批高价值任务尚未达到稳定交付标准。新的可靠产品既能让重度用户委派更多工作，也能降低其他用户开始持续使用的难度。

三、从偶尔完成，到可靠交付

Coding 成为企业 AI 的重要付费场景，有明确的产品和工作环境基础。Menlo 估算，截至 2026 年 9 月的年化口径下，企业 AI 应用市场约为 773 亿美元，其中 coding 约 340 亿美元、企业聊天与助手约 250亿美元，合计占 76%。其他部门和行业的应用规模仍明显较小。

图3｜企业 AI 应用支出集中在 coding 与聊天助手。来源：Menlo Ventures。

Menlo将智能体容易成功的场景归纳为三个条件：能够采取行动的环境、足够完整的上下文、可以验证的结果。代码库和终端让智能体能够修改文件、执行程序；文档与历史代码提供项目背景；编译器和测试帮助检查结果。围绕这些条件构建的产品，使模型可以反复执行、发现错误并修改。

普通企业工作经常缺少其中几项。以一项需要汇总数据、解释差异并提交审批的财务任务为例，数据可能分散在不同系统中，特殊处理规则保留在员工经验里，最终结果还需要责任人确认。模型即使能写出完整报告，缺少数据连接、规则和验收步骤，员工仍要重新核对，企业也很难放心扩大使用。

多步骤任务还会放大可靠性差异。摩根大通用一个简化计算说明：在各步骤独立、成功率固定且没有纠错的假设下，单步成功率为 95%，20 步全部成功的概率约为 36%；单步提高到 99%，整体成功率就升至约 82%。

图4｜多步骤任务会放大单步可靠性的差异。来源：摩根大通。

模型研究提高基础能力，产品与工程则要处理任务怎样拆分、结果怎样检查、错误怎样恢复，以及何时交回人工。对于企业，少一次返工、少一轮人工复核，可能比生成速度更快具有更直接的价值。这些改进降低完成工作的总成本，也提高用户继续委派任务的意愿。

Anthropic 披露的使用差距与这一机制一致。第三季度，未使用 Claude Code 的企业版用户，月均支出低于 75 美元；使用 Code 的前 5% 用户，支出约为前一群体的二十倍。重度用户的任务需求与使用能力，与 Code提供的执行环境结合，形成了更高的消费强度。

更广泛的白领工作也在出现可交付的产品。Menlo 提到，客服智能体供应商 Sierra 和 Decagon会让客户现场部署工程师或智能体产品经理参与，设计操作程序、连接系统，并把业务流程中的规则写进产品。这样的工作把模型通用能力接到了具体客户的问题上。

摩根大通汇总的法律 AI 公司 Harvey 数据显示，其年化经常性收入从 2024 年末约 5,000 万美元，升至 2026 年 10 月约 4 亿美元，达到原来的八倍。Menlo 则指出，法律 AI产品已经从辅助起草，发展到处理尽职调查和合同审查等完整流程。

图5｜Harvey 的年化经常性收入扩张。来源：摩根大通。

笔者认为，coding之后的扩张更可能由多个可交付场景逐步累积。采购、客服、法务和财务各自有不同的数据、责任和流程，产品团队需要找到能够重复完成、能够验收、节省费用足以覆盖使用成本的任务。使用较浅的用户，正是通过这些具体工作逐步增加使用并转为持续付费。

四、三个增长动力，都要落实到企业使用

Anthropic 在招股书中提出了三个增长动力：将模型进步转化为易用的产品和平台能力，扩张分销，以及获取新客户并扩大已有客户的使用。三者连接着从技术进步到收入形成的连续过程。

产品首先要让用户有能力使用。专业开发者愿意配置环境、整理提示和调试工具，普通员工更希望直接完成手头工作。产品团队需要把复杂操作组织成稳定流程，把必要的权限和人工确认放在合适的位置，使使用门槛随着模型进步一起下降。

分销和交付则决定这些产品怎样进入企业。Anthropic披露，其过去很大一部分增长来自自助使用与自然扩散。随着客户扩大到受监管行业，公司正在投入直销和应用工程团队，并与云平台、系统集成商和咨询公司合作。客户已有的采购渠道、数据部署环境和服务伙伴，会影响产品进入生产流程的速度。

采购以后，还需要把一次试用变成经常使用。一个部门验证了回报，邻近部门才有理由追加预算；只有更多任务能够稳定完成，按用量收费的模型公司才会持续获得收入。这里的单客支出提升，可以来自更多任务、更长流程和更广的部门覆盖，单项任务的价格则可能随效率改善而下降。

这一过程也有明确的组织成本。即使 AI 很快完成报表，审批仍由原有流程决定；如果员工必须逐项复核全部输出，自动化节省的时间就会被重新消耗。可靠产品需要让人工把精力集中到异常情况和关键决策，同时保留企业要求的责任关系。

更多白领工作开始使用 AI，也会扩大企业软件厂商和独立应用公司的机会。Menlo 认为，在 coding 等工作方式被重新组织的市场，AI 原生公司依靠快速产品迭代取得优势；在 IT和人力资源等领域，已有业务系统与客户关系帮助原有软件厂商维持地位。

模型公司因此需要选择直接交付的产品与合作伙伴承担的场景。自己拥有应用，可以更直接地获得用户反馈和收费关系；通过合作伙伴服务企业，则能利用其行业知识、系统连接与客户覆盖。若每增加一个客户都依赖大量高成本定制，收入扩大还会伴随交付费用上升。把已经验证的流程做成更多客户可以复用的产品，才有机会改善扩张效率。

五、产品人才影响模型领先兑现的速度

这也解释了 Cat Wu所代表的经验为何值得争夺。产品负责人需要较早理解新模型能承担哪些工作，组织工程和评测，把能力做成用户能够持续依赖的体验，再从用户反馈中判断下一轮应改进什么。模型迭代越快，产品方向、任务设计与研发配合就越需要及时调整。

Cat 在告别 Anthropic 的声明中，回顾了 Claude Code 从内部工具发展到能够执行大型代码迁移、构建产品的过程，并强调用户反馈对产品的影响。她加入 OpenAI 后，相关经验有机会进入更广泛的核心产品。对Anthropic，关键产品人员离开则会检验这些经验是否已被团队共同掌握，能否通过后续产品持续体现。

笔者认为，产品化能力在前沿模型竞争中的价值正在上升。更强的模型扩大 AI 能做的事情，产品团队扩大真正能够从中获益的人群。研发、产品、应用工程和企业服务之间的配合，影响的是新能力推出后多久能获得持续付费，以及领先窗口内能积累多少客户关系。

对于收入预期，后续更有价值的变化将是：低使用强度客户是否增加经常性任务，已有客户是否扩展到更多部门，非 coding产品是否形成持续付费，以及完成这些扩张需要多少交付成本。能够把一次模型突破做成可重复使用的产品、再把产品带入更多企业的公司，才更有机会延长增长并提高研发投入的回报。
