半导体设备与存储市场专家访谈纪要

1. 全球半导体扩产趋势与周期判断

a）未来几年全球半导体扩产主要集中在哪些领域？

  • 存储领域
  1. 最大的扩产方向来自DRAM，增长主要由HBM（高带宽存储器）及垂直堆叠技术驱动。
  2. 受访者预计，DRAM在整个存储市场中的占比可能由2026年的约30%，提升至2027年的约35%，并在2028年超过40%。
  3. NAND及成熟存储节点的扩产将更具选择性，主要受价格下跌、库存较高和市场趋于饱和影响。
  • 逻辑领域
  1. 资本开支主要流向3纳米、2纳米等先进制程。
  2. AI芯片需求持续增加，推动北美和亚洲进行大规模先进逻辑产能建设。
  3. 整体扩产周期预计从2020年延续至2028年。

b）与6个月前相比，企业扩产意愿发生了哪些变化？

  • 最近6个月的扩产节奏较此前略有放缓，主要原因包括：
  1. 贸易限制和出口管制带来的不确定性。
  2. 数据中心投资受到地缘政治和政治环境影响。
  3. 投资者情绪和终端需求预期发生变化。
  4. 此前预计2027年高速增长的部分需求和设备订单，被推迟至2028年。
  • 受访者原本认为2027年将是较强增长年份，但过去2至3个月AI芯片及HBM需求预期转弱，部分投资时间表后移。
  • 预计2028年设备支出和采购订单高于2027年，主要因为新建晶圆厂项目将由技术开发阶段转入大批量制造阶段。

c）“2027年放缓、2028年回升”的依据是什么？

  • 受访者明确表示，这一判断主要基于：
  1. 设备采购订单和收入确认时间从2027年推迟至2028年。
  2. 部分晶圆厂建设和量产计划延后。
  3. 原计划于2027年末确认的设备收入，可能转移至2028年初。
  • 因此，2028年回升更多是订单和收入确认节奏后移的结果，并不代表对2028年终端需求已经形成明确判断。
  • 从整个行业需求角度看，市场仍可能在2027年迎来资本开支增速高点，而2028年终端需求仍存在较大不确定性。

2. 半导体设备需求的前瞻性指标

a）哪些领先指标可以判断未来设备需求变化？

  • 客户资本开支预算
  1. 台积电、三星、美光等大型晶圆厂和代工厂的资本开支，是最直接的领先指标。
  2. 应重点跟踪客户2027年各季度预算预测及资本开支增速。
  3. 若资本开支预算下调，后续设备采购量通常也会下降。
  • 晶圆厂产能利用率
  1. 需要对比晶圆厂规划产能与实际晶圆投入量。
  2. 例如，工厂规划每月运行2.5万片晶圆，但实际仅运行1.5万至1.8万片，说明设备利用率低于预期。
  3. 产能利用率偏低，通常意味着短期内新增设备需求减弱。
  • HBM长期采购承诺
  1. 美光、三星、SK海力士与英伟达等AI客户签订的长期供应协议，可以反映未来HBM需求确定性。
  2. 结合长期协议、供应预测及客户锁单情况，可判断后续扩产和设备采购需求。
  • 设备采购订单（PO）
  1. 半导体设备交付周期通常为6至18个月。
  2. 如果客户当前尚未下达采购订单，未来12个月内通常无法实现设备交付。
  3. PO数量、下单节奏及交期变动，是判断设备厂商未来收入的重要指标。
  • DRAM、NAND及晶圆代工价格
  1. 产品价格上涨通常意味着供应偏紧、需求相对较强。
  2. 产品价格持续下跌，则可能引发客户延缓扩产、减少采购或优先改造旧设备。
  • 客户交付紧迫程度
  1. 如果客户接受12个月以上交期，说明短期需求紧迫性有限。
  2. 如果客户要求提前或加快交付，说明其逻辑芯片或存储芯片需求较强。
  • 洁净室及新厂建设进度
  1. 新晶圆厂洁净室建设加速，通常意味着产能即将进入设备搬入和爬坡阶段。
  2. 厂房、厂务及洁净室建设进度，可作为未来设备需求的重要先行指标。

3. 不同产品与制程的景气周期分化

a）不同半导体细分市场可能在何时达到投资高点？

  • 先进逻辑
  1. 2027年的重大投资主要集中在2纳米。
  2. 部分先进制程项目正在建设，目标量产时间为2028年。
  3. 3纳米及以下先进制程的设备投资可能在2028年达到更高水平。
  • HBM与DRAM
  1. 2026年至2027年需求表现强劲。
  2. 随着HBM4E、HBM5等产品采用更先进制程，HBM及垂直DRAM相关投资可能在2028年达到峰值。
  • NAND
  1. NAND设备需求可能在2027年达到阶段性高点。
  2. 2027年后，价格可能趋于停滞，叠加库存和市场饱和，扩产动力减弱。
  • 成熟制程逻辑
  1. 成熟制程逻辑投资可能在2027年达到阶段性峰值。
  2. 2028年行业重点将进一步转向3纳米及以下先进逻辑、HBM和垂直DRAM。
  • 总体来看，不同领域的投资高点并不一致：成熟逻辑和NAND偏向2027年，先进逻辑、HBM和垂直DRAM偏向2028年。

b）为什么NAND设备需求明显弱于DRAM？

  • NAND需求放缓并非主要由设备供应限制导致，而是由市场基本面驱动：
  1. NAND现货价格持续走弱。
  2. 市场供给大于需求，库存处于较高水平。
  3. PC和智能手机需求预计下降。
  4. 亚洲主要客户的eSSD需求逐步趋于饱和。
  5. NAND属于相对成熟产品，市场增量不及AI驱动的HBM和DRAM。
  • 与之相比，DRAM尤其是HBM直接受益于AI芯片需求，扩产确定性更高。

c）NAND设备需求可能下调多少？

  • 如果此前某客户对NAND设备的需求预测为100台，受价格走弱影响，预测可能下调约15%至20%。
  • 客户的应对方式包括：
  1. 不再续签部分设备合同。
  2. 与设备厂商协商降低合同价格。
  3. 优先改造现有设备，而非采购新设备。
  4. 缩减或推迟新增产能。
  5. 接收设备后暂时存放，延后开机和保修期起始时间。
  • eSSD在2026年末至2027年中期仍可能有一定增长，但之后预计转弱。

d）当前NAND库存和供需情况如何？

  • NAND库存处于较高水平，市场存在明显供过于求。
  • 供过于求的状态可能持续至2026年末或2027年初。
  • 受访者无法提供具体库存比例，但确认当前NAND需求较弱，企业需先消化库存、恢复价格和利润率，再考虑重新扩产。

4. 主要存储厂商扩产节奏

a）SK海力士、三星、闪迪和美光的扩产趋势有何差异？

  • SK海力士
  1. DRAM和HBM产能可能已锁定至2029年。
  2. 2027年至2028年大部分产能已签订长期协议。
  3. 公司在龙仁拥有新增投资和洁净室空间，短期扩产节奏可能略有放缓，但长期需求仍较强。
  • 三星
  1. 正在美国得克萨斯州扩建泰勒和奥斯汀工厂。
  2. 预计2027年拥有更多产能，因此可能不会明显放缓扩产。
  • 闪迪
  1. 业务主要集中在NAND和SSD，不生产DRAM，因此更容易受到NAND、SSD价格下跌影响。
  2. 与4至6个月前相比，闪迪是扩产预期降幅较大的厂商之一。
  3. 已下达的新设备订单可能不会直接取消，但可能将原定2027年的交付推迟至2028年。
  4. 公司可能等待价格和供需改善后，再恢复更积极的晶圆产能扩张。
  • 美光
  1. 战略重点正转向DRAM和采用垂直堆叠技术的HBM。
  2. NAND业务逐步向新加坡转移，爱达荷州相关业务重点聚焦DRAM和HBM。
  3. 2027年至2029年前景仍较积极，与闪迪明显不同。
  4. 美光近期业绩实现创纪录营收，显示其DRAM和HBM业务需求较强。
  • 铠侠
  1. 受访者未能确认其是否已明显放缓扩产。
  2. 但从NAND整体价格和库存趋势看，其扩产也可能面临一定压力。

b）美光Fab 11E暂停扩建是否意味着主动控制DRAM供给？

  • 受访者无法判断美光是否有意通过暂停扩建控制DRAM供需。
  • 已知情况包括：
  1. 美光于11月暂停了价值约40亿美元项目的部分建设工作。
  2. 主要原因是与工会之间的薪酬协议及劳资纠纷。
  3. 该设施原计划生产DRAM和HBM，并预计在2028年前后启动。
  4. 美光表示中国台湾地区现有业务仍将正常运营，并可能重新分配部分资本开支。
  • 受访者判断，美光并未退出DRAM或HBM，项目可能因预算分配和劳资纠纷延迟数月，之后仍有望重新推进。

5. 中国市场需求、国产替代与出口管制

a）2027年中国半导体设备需求将如何变化？

  • 中国市场需求预计仍会增长，但增速可能略有放缓，原因包括：
  1. 美国出口管制和贸易限制仍然严格。
  2. 中国先进逻辑、先进存储和先进封装所需的部分设备仍依赖美国、日本和欧洲供应商。
  3. 中国晶圆厂正在提高本土设备采购比例。
  • 受访者预计，未来中国设备采购结构可能逐步接近：
  1. 约50%国产设备。
  2. 约50%海外设备。
  • 不同细分市场表现将明显分化：
  1. 表现较好：28纳米及以上成熟制程、功率芯片、模拟芯片和DRAM。
  2. 相对承压：NAND、先进逻辑和先进封装。

b）为什么中国NAND扩产仍可能放缓？

  • 中国NAND扩产放缓主要基于价格、库存和市场饱和，并非设备供应限制。
  • 即使存在自主可控目标，企业仍需考虑商业回报：
  1. 当前市场库存较高。
  2. 产品价格偏低。
  3. 企业需要恢复利润率并收回前期投资。
  4. 2027年初至年中扩产速度可能较慢。
  • 当市场库存逐步消化、供需恢复后，中国企业可能重新扩大产能，并更多采用国产设备。
  • 由于NAND属于相对成熟的技术，中国企业更容易通过国内供应链提升市场份额，但短期仍需优先解决库存和盈利问题。

c）海外设备目前可向中国供应到什么工艺水平？

  • 受访者给出的行业层面判断为：
  1. 成熟逻辑制程方面，28纳米及以上设备相对更容易获得许可。
  2. 部分14纳米及以上逻辑设备可能仍可销售，但需视具体设备和许可情况而定。
  3. DRAM设备限制线可能涉及18纳米半间距。
  4. NAND限制涉及128层及以上等先进规格。
  • 具体设备能否供应，仍取决于技术规格、设备类型、最终用途及BIS许可要求。

d）未来设备出口限制是否可能进一步收紧？

  • 当前先进沉积、蚀刻、清洗和先进光刻设备的限制已经较严格。
  • 未来潜在收紧方向包括：
  1. 更先进的计量和检测设备。
  2. 成熟制程设备。
  3. 设备备件，如光学器件、激光器等核心零部件。
  4. 与先进制程和成熟制程相关的技术规格、研究和知识获取。
  5. 中国企业通过第三国数据中心远程使用AI芯片的方式。
  • 但政策仍取决于美国政治环境。受访者认为，在美国两党分别控制不同机构的情况下，进一步大幅收紧先进设备限制也可能受到制约。

e）《MATCH法案》可能带来哪些影响？

  • 受访者认为，《MATCH法案》主要针对先进半导体设备销售限制，并非完全新增的政策方向。
  • 可能涉及：
  1. 新型浸没式DUV和EUV光刻设备。
  2. 面向7纳米以下先进逻辑制程的沉积、蚀刻等新一代设备。
  3. HBM及先进DRAM相关设备。
  4. 设备备件和关键零部件。
  5. 相关技术规格、研究和知识转移。
  • 关于1980Fi光刻机，受访者不了解具体型号，无法直接确认；但如果属于浸没式DUV或EUV设备，则预计会受到限制。

6. 全球扩产的主要瓶颈

a）未来2至3年晶圆厂扩产面临哪些核心约束？

  • 供应链
  1. 是当前最主要、最确定的瓶颈。
  2. 制程节点越先进，所需零部件越专业，规格和公差要求越严格。
  3. 美光、台积电、三星等客户同步扩产，设备厂商及第三方供应商产能承压。
  • 厂务设施和许可审批
  1. 设备可能已运抵，但电力、水、气体和散热等厂务条件未必及时到位。
  2. HBM、AI芯片及数据中心相关设施需要大量电力和水，并产生较高热量。
  3. 当前许可审批对能耗、供水、散热和电气安全的要求明显提高，审批周期拉长。
  • 熟练劳动力
  1. 市场缺乏足够的熟练工程师和经过培训的人员。
  2. 人员短缺会影响设备安装、调试、维护及晶圆厂产能爬坡。
  • 综合来看，受访者认为未来扩产的三大瓶颈为：供应链、许可审批和劳动力。

b）中东地区是否存在大规模晶圆厂扩产需求？

  • 中东地区目前未观察到广泛的大规模晶圆厂扩产。
  • 以色列存在Fab 28、Fab 38以及射频、硅光子相关业务，但整体进展偏慢。
  • 除以色列外，受访者未观察到其他中东地区出现显著的大规模晶圆厂建设需求。

7. 关键设备零部件短缺情况

a）哪些设备零部件的供应瓶颈最严重？

  • 沉积设备相关零部件是主要短缺领域，包括：
  1. 射频电源。
  2. 精密机械零部件。
  3. 真空阀。
  4. 高温陶瓷等陶瓷部件。
  • CMP相关材料也存在供应约束，包括：
  1. CMP浆料。
  2. 特定化学材料和磨料。
  3. 配方调整和验证所需的研发及实验室资源。
  • 这些零部件及材料专业性较高，认证周期长，难以在短时间内快速扩充供应。

b）设备厂商如何缓解零部件短缺？

  • 建立全球多元化供应商资源池
  1. 通过行业会议、贸易展会、论文、专利和社交媒体寻找新供应商。
  2. 尤其关注交付周期短、价格有竞争力的小型第三方供应商。
  • 加大对供应商的研发支持
  1. OEM厂商投入自有资金，为供应商建设研发实验室。
  2. 加快产品开发、测试和认证，推动后续量产。
  • 延长产品评估和认证
  1. 新供应商通常需要3至6个月评估期。
  2. 评估指标包括功率、沉积速率、晶圆端性能、均匀性、零部件寿命、交付速度和价格。
  3. 只有测试达到规格要求后，OEM才会发出采购订单并扩大应用。

c）中国设备零部件供应商如何进入OEM采购体系？

  • 新供应商最重要的竞争力包括：
  1. 交付周期。
  2. 产品价格。
  3. 是否满足设备厂商要求的技术规格。
  • OEM会重点验证：
  1. 晶圆端性能。
  2. 沉积速率。
  3. 功率水平。
  4. 产品寿命。
  5. 稳定性和重复性。
  • 通常需要经过3至6个月的试用评估，若性能不能满足要求，则不会获得采购订单。
  • 中国供应商具备交期和成本优势，但仍需通过长期验证证明产品一致性、寿命和晶圆端性能。

d）MFC的短缺情况如何？

  • MFC（质量流量控制器）目前存在严重短缺，是沉积和蚀刻设备的重要瓶颈。
  • MFC广泛应用于：
  1. 沉积工艺。
  2. 蚀刻工艺。
  3. 逻辑、存储和先进封装等涉及气体流动的工艺模块。
  • MFC内部最紧缺的三类部件为：
  1. 高精度阀门。
  2. 传感器。
  3. 压电陶瓷。
  • MFC对气体流量的准确性和重复性要求极高，流量不一致会影响薄膜均匀性，造成晶圆报废并降低良率。
  • 日本Horiba是主要供应商之一，MKS也具有较强市场地位；目前部分欧洲供应商正在进入采购体系，以缓解供应瓶颈。

8. 设备交付周期、定价与订单稳定性

a）不同设备的交付周期目前处于什么水平？

  • 沉积设备
  1. CVD、PVD、ALD等设备供应最为紧张。
  2. 交付周期可能超过14个月。
  • CMP设备
  1. 交付周期约为9至12个月。
  • 计量和检测设备
  1. 交付周期相对较短，约为6个月。
  • 设备交期取决于工艺类型、零部件专业化程度及客户需求紧迫性。

b）与此前相比，设备交期延长了多少？

  • 从2025年至2026年的变化看，部分设备交期已接近翻倍。
  • 以沉积设备为例：
  1. 此前交期约7至8个月。
  2. 当前已延长至14个月以上。
  • 交期拉长主要有两个原因：
  1. 先进设备零部件需要满足更严格的规格和公差要求。
  2. 美光、台积电、三星等主要客户同时扩产，供应链难以同步满足全部需求。

c）紧急订单是否需要支付额外费用？

  • 对于采购量较大的一级客户，设备厂商会尝试加快交付，并重新分配预订产能。
  • 原则上，产能分配仍主要依据采购订单日期，但也会考虑：
  1. 客户当年的设备预订量。
  2. 客户未来数年的需求预测。
  3. 客户业务的长期成长性。
  • 客户可以通过以下方式获得更快交付：
  1. 支付更高的零部件和加急费用。
  2. 接受更高价格的服务合同。
  3. 采用设备与服务合同捆绑采购。
  • 受访者估计，紧急订单或优先交付带来的额外收入，可能相当于设备销售价格的约3%至5%。

d）设备厂商会如何决定客户优先级？

  • 设备厂商不仅看当前订单，还会评估客户的长期需求。
  • 例如：
  1. 某客户2027年有设备需求，但2028年后业务前景偏弱，优先级可能下降。
  2. 业务覆盖HBM、DRAM或先进逻辑，且未来需求预测较强的客户，可能获得更高优先级。
  • 因此，客户长期需求确定性、采购规模和战略价值都会影响产能分配。

e）在需求不确定的情况下，客户会取消设备订单吗？

  • 除NAND外，受访者目前未观察到明显设备订单取消。
  • 客户不愿取消订单的主要原因包括：
  1. 一旦取消，短期内可能无法重新获得设备交付时段。
  2. 其他客户会迅速占用释放出的产能。
  3. 当前仍处于扩产和争夺市场份额的关键阶段。
  4. 部分长期订单包含较严格的取消条款。
  • 受访者援引公开信息称，美光相关客户订单的取消损失可能为零，即即便客户在交付前取消，美光仍可能取得全部采购订单金额。

f）NAND设备订单是否也不会取消？

  • NAND市场与DRAM和先进逻辑不同，存在一定取消可能，但更常见的处理方式是：
  1. 推迟采购订单执行。
  2. 延后设备交付日期。
  3. 接收设备后暂时存放。
  4. 推迟设备开机和保修期起始时间。
  • 主要原因是NAND价格偏弱、设备利用率较低、库存较高，客户更倾向于延后产能投入，而不是立即扩大生产。
