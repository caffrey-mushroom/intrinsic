1. 产品定位、技术参数与供货模式

a) 收购Simple后，公司与BE之间的合作模式是什么？

  • 公司收购Simple后，由Simple负责向BE供应连接体产品。
  • 连接体主要用于BE热箱内部隔膜片之间的连接，是燃料电池系统中的关键零部件。
  • 公司采购金属粉末等原材料后，经过高温烧结、涂层及封装等工序，最终以零部件形式直接供应给BE。

b) 连接体的材料配方和性能指标如何？

  • 当前产品源于公司与BE在2018年联合研发的配方，主要成分为铬：
  1. 铬含量约为95%。
  2. 其余为其他金属元素，用于改善耐高温、耐腐蚀等性能。
  • 产品可长期用于高温环境：
  1. 极限耐温可达到约1,200摄氏度。
  2. 使用寿命可达到约10万小时。
  3. 按专家口径，上述指标处于行业最高水平。
  • 产品知识产权分为两部分：
  1. 材料配方。
  2. 生产工艺。
  • 上述知识产权由公司与BE共同拥有。

c) 产品出货量如何从片数换算为GW？

  • 单片连接体对应功率约为25瓦。
  • 按此换算：
  1. 1GW约对应4,000万片连接体。
  2. 0.5GW约对应2,000万片。
  3. 1.2GW约对应4,800万片。
  • 公司与BE之间既可按片数统计，也可按照上述固定比例换算为对应的GW规模。

2. 2025年供货、出货及库存口径

a) 2025年公司向BE的实际供货量是多少？

  • 2025年公司向BE供应的连接体约对应0.5GW。
  • 公司在BE连接体采购中的份额约为45%至50%，实际略高于50%。
  • 竞争对手供货量据估计约为0.6GW，略高于公司。
  • 竞争对手产品价格较公司低约20%，是其获得部分份额的重要原因。

b) 为什么公司供货量与BE对外公布的出货量不一致？

  • BE采购量、内部生产量和对客户出货量属于三个不同口径：
  1. 公司向BE的供货量是零部件采购口径。
  2. BE对外公布的是系统或产品交付口径。
  3. BE采购后还会保留一定安全库存。
  • 受产能和生产瓶颈影响，BE采购的连接体不会全部在当期转化为终端出货：
  1. 实际销售给客户的数量通常约占采购量的70%至80%。
  2. 其余部分主要作为安全库存。
  • 2025年BE对外公布的出货量约为0.8GW。
  • 根据专家掌握的内部数据，BE实际出货量可能约为0.6GW，对外披露口径略高。
  • 专家认为，BE相关出货数据会影响资本市场表现，因此其公开数据可能存在一定程度的积极表述。

c) 2025年BE分季度对外出货节奏如何？

  • 按专家提供的BE对外出货口径，季度规模大致为：
  1. Q1约0.09至0.10GW。
  2. Q2约0.12至0.15GW。
  3. Q3约0.18至0.20GW。
  4. Q4约0.30GW，宽口径约0.30至0.35GW。
  • Q1通常是出货最少的季度，随后随产能爬坡逐季增长。
  • 上述季度数据属于估算值，且存在统计口径差异，与BE全年公开披露的0.8GW未必完全勾稽。

d) 2025年公司向BE的供货节奏如何？

  • 公司供货节奏与BE终端出货节奏并不一致：
  1. Q1供货量较少，仅为0.0几GW。
  2. Q2和Q3为主要供货期，累计约0.25至0.30GW。
  3. Q4供货量约0.15GW。
  4. 全年合计约0.5GW。
  • 公司通常会在BE总装前提前交货，因此不能直接将公司某一季度供货量与BE同季度出货量进行匹配。

e) 为什么BE产能持续爬坡，但公司Q4供货反而下降？

  • BE通常会提前制定未来三个月的生产计划，并将生产排期提供给公司。
  • 连接体从备料到交付的正常周期约为8至12周。
  • 为避免BE总装时缺料，公司通常会提前2至3个月完成生产和交付。
  • 因此，公司Q2、Q3集中供货，可能对应BE后续Q3、Q4乃至下一年度的生产需求；Q4供货下降并不代表BE终端需求下降。

3. 2026年供货进度与BE出货预期

a) 2026年上半年公司向BE供货规模是多少？

  • 截至2026年6月30日，公司累计向BE交付约0.6GW。
  • 2026年上半年供货量已经超过2025年全年约0.5GW的水平，供货增长明显。
  • 按1GW对应4,000万片计算，0.6GW约对应2,400万片连接体。

b) 2026年全年公司向BE的供货目标是多少？

  • 根据BE提供的滚动预测：
  1. 截至2026年9月，公司累计供货可达到约0.8GW。
  2. 截至2026年12月，公司全年累计供货最多可达到约1.2GW。
  • 由此推算：
  1. 2026年上半年已交付0.6GW。
  2. Q3预计新增约0.2GW。
  3. Q4预计新增最多约0.4GW。
  • 公司预计继续占BE连接体采购量的一半以上。

c) 公司1.2GW供货量是否等同于BE当年1.2GW出货量？

  • 不等同。
  • 公司供货后，BE仍需完成内部生产、总装、检测、返工及客户交付等流程。
  • 公司供货通常领先BE总装2至3个月：
  1. Q4交付给BE的连接体，大概率要到2027年Q1才进入生产或实现终端交付。
  2. 因此，公司当年供货量通常高于当年能够转化的BE终端出货量。
  • 按生产期间匹配，约0.2GW的2025年Q4供货加上约0.8GW的2026年前三季度供货，可能主要对应BE在2026年的生产需求，合计约1GW。

d) BE在2026年的实际出货进度和全年目标如何？

  • 根据BE在2026年7月底向公司提供的信息，截至7月底累计出货约0.8GW。
  • BE给出的2026年全年累计出货目标接近1.5GW。
  • 目前限制BE出货的主要因素不是订单不足，而是产能和总装效率不足。
  • BE正在建设新产线，并希望两条生产线同步运行，但短期内仍难以满足全部待交付订单。

e) 为什么公司份额超过50%，BE仍会保留多家供应商？

  • 公司成本目前略高于竞争对手，因此BE仍会进行多供应商采购。
  • 出于质量追溯考虑，BE不会在同一套系统或同一客户项目中混用两家供应商的连接体：
  1. 一个客户项目可能全部使用公司的产品。
  2. 另一个客户项目可能全部使用竞争对手的产品。
  • 这种分项目供应模式有利于后续质量追踪、责任认定和售后管理。

4. BE产能瓶颈、良率与自动化规划

a) BE目前最主要的产能瓶颈是什么？

  • BE当前并不缺少客户订单，核心问题在内部总装生产线。
  • 除连接体外，系统装配还涉及增幅器、BOP辅助件、蒸发器等多个部件。
  • 目前生产方式仍接近单机、独立工位作业：
  1. 每个工位需要人工完成部分组装。
  2. 尚未实现完整的全自动连续生产。
  3. 人工装配效率和质量稳定性较弱。
  • 海外员工受工作习惯、工会及工时制度影响，难以像中国工厂一样通过加班或两班倒快速提高产出。

b) BE当前总装良率处于什么水平？

  • 专家对不同产线或工位给出的良率口径约为65%至75%：
  1. 主体装配线良率约70%。
  2. 部分口径约为75%。
  3. 独立工位模式可能仅为65%至70%。
  • 常见不良问题包括：
  1. 密封不到位。
  2. 螺丝扭矩不符合要求。
  3. 装配间隙异常。
  4. 部件匹配和一致性问题。
  • 不良品无法简单报废，需要全部拆开、返工、重新组装和检测，进一步占用工时并限制有效产能。

c) BE短期如何解决交付压力？

  • 短期可能继续增加独立工位，通过增加人员和工位保障交付。
  • 独立工位的优点是建设相对简单、投产较快。
  • 缺点是：
  1. 良率仅约65%至70%。
  2. 人力成本较高。
  3. 返工率较高。
  4. 会稀释产品利润率。
  • 因此，该方式主要用于短期过渡，而非长期最优方案。

d) BE全自动生产线何时能够投入运营？

  • BE正在推进全自动生产线，单条全自动线的规划年产能约为3GW。
  • 目前线体评审刚刚完成，后续仍需经历建设、调试、验证和爬坡。
  • 专家预计：
  1. 正式投入运营至少要到2027年下半年或2028年。
  2. 初期良率仍可能有限。
  3. 经过持续优化后，到2028年有望达到约3GW的设计产能。
  • 一旦自动化工艺完全固化，BE产能可能出现较快、近似直线式增长，也会同步拉动上游连接体需求。

5. 公司自身产能、扩产计划与本地化生产

a) 公司当前连接体产能是多少？

  • 公司目前拥有1条主要生产线。
  • 在实行两班倒的情况下，最高年产能约为2GW。
  • 现有产线从规划初期即按照2GW设计：
  1. 公司与BE从2018年开始合作。
  2. 除小批量验证外，后续产线均按长期需求进行配置。
  3. 产线包含60多道工序，自动化程度较高。
  4. 高温工序主要由机械臂操作，人员在外部监控。
  • 产线设计已经由BE的SQE、采购和质量团队参与审核并锁定。

b) 为什么现有2GW产能下，公司仍计划继续扩产？

  • BE给出的2028年总需求指引约为3至3.5GW。
  • 公司当前在BE供应体系中的份额超过50%，理论上现有2GW产能可以覆盖较大部分需求，但仍需提前扩产，主要原因包括：
  1. BE要求供应商产能高于当期需求，防止其内部工艺拉通后需求突然释放。
  2. 新产线从建设到认证投产至少需要1年至1年半，无法临时扩充。
  3. 现有产线设备体积大、集成传感器多，中途增加设备会导致数据、工艺和布局全部重新调整。
  4. 公司希望在BE自动化产能释放前完成自身产能准备。
  • 扩产不是单纯基于主观乐观预期，而是以BE提供采购承诺为前提。

c) 新建一条产线需要多少投入，如何控制投资风险？

  • 新建一条连接体生产线固定资产投入约为4亿元人民币。
  • 公司内部对资本开支和投资回报要求较严格：
  1. 原则上希望在2至3年内收回本金。
  2. BE需要承诺一定采购量。
  3. BE需要缴纳一定保证金。
  4. 保证金后续可随订单执行逐步释放。
  • 如果没有采购承诺和保证金，公司不会推进扩产。
  • 主要原因是公司现金流逐年下降，大额资本开支会侵蚀股东权益，因此必须以明确订单保障为前提。

d) 新产线从建设到量产需要多长时间？

  • 新产线并非建成即可投产，每道工序都需要接受BE现场审核。
  • 审核内容包括：
  1. 工艺流程。
  2. 过程能力指数。
  3. 质量稳定性。
  4. 设备和传感器运行情况。
  5. 小批量生产验证。
  • 从建设到验收合格至少需要1年，较长情况下需要1年至1年半。
  • 相关扩产工作已经启动，目标是在2027年5月至6月通过正式验收，之后进入小批量阶段。

e) 为什么当前交付周期长达8至12周？

  • 公司目前生产流程横跨加拿大和韩国：
  1. 部分前段工序在加拿大完成。
  2. 产品随后运往韩国完成最终封装。
  3. 韩国负责外部耐腐蚀涂层和相关封装工艺。
  4. 完成后产品再运回北美。
  • 加拿大当地的涂层资源和工艺成熟度不足，是目前必须跨区域生产的主要原因。
  • 往返运输及跨工厂衔接导致整体交付周期达到8至12周。

f) 公司如何缩短交付周期并提升北美竞争力？

  • 公司计划将韩国的配套工艺及部分管理团队转移至加拿大，实现一体化生产。
  • 本地化完成后：
  1. 物流周期目标至少缩短一半。
  2. 可减少加拿大与韩国之间的往返运输。
  3. 公司在北美的交付速度将明显快于亚洲供应商。
  4. 可同步建设本地售后服务能力。
  • 交付速度和本地化服务有望成为公司相对低价竞争对手的重要差异化优势。

6. BE长期需求、客户结构与订单能见度

a) BE对2028年的需求指引是多少？

  • BE给出的2028年总需求约为3至3.5GW。
  • BE在供应商大会后向公司单独发送框架协议，核心目的是确认和统计公司的可用产能。
  • BE要求公司提前准备足够产能，避免其内部自动化产线投产后，上游零部件供应无法同步。
  • 专家认为BE历史上的产能指引相对激进，但订单储备和市场需求较为充足，主要不确定性仍在生产兑现能力。

b) BE目前主要客户和已知需求有哪些？

  • 目前已知的前三大客户包括Oracle、ADP和Lubix。

Oracle

  1. 是BE目前最大的客户。
  2. 双方框架协议要求在2027年底前交付约2.8GW。
  3. 按专家口径，去年已部署约1.2GW。
  4. 该数据与BE其他年度出货口径存在一定差异，仍需结合框架订单、部署量和确认收入等不同统计口径理解。

ADP

  1. 2020年至2025年累计交付约0.9GW。
  2. 2026年至2027年还需交付约1.5GW。
  3. 属于持续、分期交付的长期客户。

Lubix

  1. 当前已交付约0.30至0.35GW。
  2. 后续预计还有约1GW需求。
  3. 相关需求可能在2027年至2028年上半年完成。
  • 其他客户或潜在客户包括Coreva、Intel、高通及弗莱德等。
  • 按BE提供的信息，2025年至2028年累计需求约为8GW。
  • 其中部分项目尚未签署最终框架协议，仍需完成融资安排、设备订单及合规流程，因此具体客户分解尚未完全披露。

c) AI数据中心相关增量需求有多大？

  • BE除现有客户外，还在推进英伟达及其他AI芯片、AI服务器相关项目。
  • 专家预计相关客户数量可能增加至3至4家。
  • 到2028年，AI相关新增需求可能达到约2至3GW。
  • OpenAI此前曾与BE讨论合作，但由于BE当前产能不足，暂时无法全面承接，只能承诺在特定时间内通过部分项目交付。
  • Anthropic与BE之间也存在接触，但尚未正式签署并公开框架协议。
  • BE通常会在完成内部备案、审计、合规检查和最终签署后才对外披露，以避免合作变化影响股价。

d) 为什么Intel、高通等半导体公司也会产生相关需求？

  • 半导体和AI服务器业务同样需要稳定、快速部署的电力基础设施。
  • 北美电网与中国不同：
  1. 停电和错峰用电情况较常见。
  2. 缺少类似中国特高压体系的跨区域电力调度能力。
  3. AI服务器和算力设施对供电稳定性要求高。
  • 除数据中心外，BE也在与重点医院、机关网络等客户洽谈相关业务。

7. 燃料电池方案的竞争力与市场风险

a) 燃料电池发电方案的核心竞争优势是什么？

  • 与氢燃气轮机等替代方案相比，燃料电池当前在发电转换效率和成本方面未必具备绝对优势，即使北美存在补贴，综合经济性仍有挑战。
  • 其最大优势是部署速度快：
  1. 一般可在45至60天内完成部署。
  2. 燃气轮机等大型发电方案通常需要2至3年。
  3. 部署时间约为传统大型方案的十分之一。
  • 客户可以根据短期算力和电力需求分阶段投资：
  1. 需要多少就部署多少。
  2. 不必一次性投入2至3GW的大型项目。
  3. 初始投资规模更灵活。
  4. 短期更容易形成回报。

b) 当前市场的核心矛盾是什么？

  • 当前不是缺乏需求，而是BE无法按时交付已有订单。
  • 主要矛盾包括：
  1. 总装自动化程度不足。
  2. 人工工位良率偏低。
  3. 返工占用大量产能。
  4. 海外工时制度限制加班和扩产效率。
  5. 部分原材料存在短缺。
  • 如果BE全自动生产线能够顺利投产并改善良率，产能和上游连接体需求均可能快速释放。

c) 公司面临哪些主要竞争和经营风险？

  • 价格竞争：
  1. 竞争对手产品价格约低20%。
  2. 部分供应商通过降低高成本金属含量、采用低价方案争取份额。
  • 技术与质量竞争：
  1. 低价产品质量和寿命可能弱于公司。
