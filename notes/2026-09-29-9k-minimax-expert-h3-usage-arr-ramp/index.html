H3已连续两个月实现月度用量翻倍，当前ARR不足9.5亿元，12月目标为15亿元。M3 Pro承诺10月份推出，定位高阶Agent任务，静态能力可超过K3但Coding仍有短板。

  1. H3虽在大客户拓展上相对滞后，但Kria、ComfyUI和File等大型聚合平台已上线，月度用量连续两个月翻倍；视频收入从7月到8月翻1倍，9月再翻1倍多，9月全方平台加To B业务总收入尚不足8,000万元
  2. 按目前7,000多万元月收入计算，ARR不足9.5亿元，12月份ARR run rate目标为15亿元；公司口径称即使M3 Pro表现平平、收入保持flat也可达标，但目标测算同时已factor in其发布后的收入促进作用
  3. M3 Pro对客户承诺10月份推出，静态判断可超过K3并在国内达到SOTA水平，agentic和Front-end能力提升较大，但frontier coding弱于Opus

4.8、Back-end与GPT和Anthropic仍有差距，K4大概率仍会超过M3 Pro

  1. M3 Pro确切价格尚未确定，最入门级版本目标为每百万Token输入约1美元；M3.1 Flash承担低成本模型定位，M3.1和M3 Pro预计继续按照context window分层定价，512以下与512以上采用不同价格
  2. M3.1 Flash Preview尚未开放API且绑定Code产品，受Code harness能力限制，发布后未明显提升用户量，后续增长仍需等待M3.1完整版、API开放及harness能力改善，模型增强并不会自然转化为产品用户
  3. 国产模型按整体用量计算的市场份额已超过55%、接近60%，客户普遍采用multi-model调用；复杂workflow和debugging仍主要由Top 3到Top

Q:上次访谈提到，H3刚推出时已有许多海外客户积极接入。现在大约过去了一个月，能否介绍H3目前的商业化情况，以及客户侧的实际进展？

A:H3推出至今，进展相对滞后，大客户集中度仍然较高。另外，一些蒸馏或后训练版本实际上是完全不同的模型。例如，File的H7 Max已部署在开放平台上，对收入的带动较多，同时还有License fee分成。9月尚未结束，但从ARR来看，较8月已经增长较多。视频收入从7月到8月翻了1倍，9月又翻了1倍多。9月全方平台加To B业务的总收入尚不足8,000万元；如果无法细分到海螺，按照预估也不足8,000万元。C端尚未完成最终统计，要到下个月初才会有结果。

H7 Max面向不同的场景。由于它是接近实时的模型，可以进入许多过去完全无法覆盖的use case，例如持续互动的游戏、共享绘画等社交场景。

Q:您刚才所说的是整个月的收入吗？按照最新收入计算，目前ARR大概是多少？

A:整个月的收入乘以12，可以得到更准确的ARR。一般对外披露ARR时，会用一周收入乘以52或53。按照目前7,000多万元的收入计算，ARR不足9.5亿元。

Q:此前公司对年底ARR的指引是多少？是十多亿元吗？

A:这一指引调整过多次。目前的口径是，年底ARR run rate，即12月份的ARR run rate，要达到15亿元。

Q:目前来看，15亿元的目标能够实现，还是仍取决于M3 Pro的推出时间？

A:这一目标并不取决于M3 Pro。虽然M3 Pro不可能不推出，但即使假设其推出后表现平平，收入保持flat，也能够达到目标。

Q:假设M3 Pro推出，理论上会对ARR产生较大的促进作用，还是目前应当降低相关预期？

A:M3 Pro会产生促进作用。目前基本每个月都有增长，但按照当前run rate推算，到年底还有两三个月，距离目标仍有一定差距。因此，目标中已经factor in了M3 Pro推出后对收入的促进作用。

Q:上次您判断H3主要会争取可灵的市场。现在过去了一个多月，这一判断是否已经落地？实际情况是否不及当时预期？

A:几个关键的大型聚合平台已经落地，但接入后仍需要时间，并非接入后立即就会产生用量，最终还是按用量计算。视频模型与聚合平台之间仍以批发形式销售。目前争取到的用量较多，例如Kria、ComfyUI和File都已上线。可灵的表现也不错，但其新模型到10月份才会推出，因此H3有两个月左右的时间将较大一部分用量接入。更重要的是，H3还获得了一些原本可能无法覆盖的用量。目前已连续两个月实现月度用量翻倍，表现已经较为不错，也获得了这两个月的大量用量。

Q:可灵昨天发布了新版本的Preview。您是否看过这一版本？其能力有哪些明显提升，会产生哪些影响？

A:该版本没有超出预期，主要是Audio和Visual更加stable，Omni Reference也与我们基本持平，能够做到15个multimodal。但实事求是地说，其表现略低于预期，原本预计它会更强。它没有明显进一步强化这部分模型，更多是延续此前在指令遵循、物理世界理解等方面的能力，但尚未做到那么多的分模组。我们采用较为明确的分模组方式，768K版本就专门处理768K，因为目前更多采用草稿和终稿两阶段形式:先用草稿跑通，最后再用2K版本制作终稿。在商业化方面，他们目前没有做太多。由于该版本刚推出，目前尚未进行非常细致的分析，后续聚合平台或友商会开展更多横向比较。

Q:可灵这次将单次时长升级到30秒，并可能支持4K、1080p和HDR输出。当前视频模型的发展是否遇到了一些瓶颈？每次大版本升级似乎主要集中在提升时长和输出质量。如果未来还有大幅提升，下一阶段会向什么方向发展？目前是否已较难继续提升？

A:下一阶段的明确方向是实时化，相关模型实际上已经指明了这一方向，未来会更多提升实时使用场景的能力。如果这部分用量增加，视频数据也会随之增多，而这种sequence of数据更为重要。视频与Coding不同，其penalty rate相对较低:Coding为50%，视频最多约为15%。视频模型的进步速度没有那么快，主要是因为视频任务不像Coding任务那样verifiable。

不过，视频模型在分module和商业化方面的升级仍然较大。过去各方主要开发闭环模型，开源之后很快出现了许多derivative版本，其中不少版本在小场景或非常specific for you的场景中优于原生模型。这体现了开源社区的力量，主要通过数据切分实现，而且模型规模也不是特别大。开源模型约为33B，尚未计入Context、IR和2K。

如果按照每年升级两次的节奏，视频模型的进步速度会比General Model慢一些，更多进步将来自与真实世界数据的耦合。例如，谷歌相关模型或字节后续将发布的模型，预计会达到类似Seedance 2.0 level的升级，关键在于速度。速度提升不只是生成更快:如果生成速度快于视频本身的时长，就可以实现实时、原生流式的应用，彻底解锁新的场景。由此可以获得更多数据，不再局限于坐在电脑前进行编辑的静态应用形式，新的数据飞轮也会随之运转，进一步提升模型能力。

Q:最近发布的M3.1 Flash Preview是在M3.1基础上进行后训练得到的吗？是否可以将其理解为M3.1的低成本版本？

A:笼统地说，可以这样理解。由于它仍是Preview，没有开放API，而是绑定在Code产品中，一方面更容易控制，另一方面也可以为Code harness引流，因此它并不是完整的M3.1。

Q:M3.1和M3 Pro的时间表如何？此前M3 Pro最早计划于9月、大概率在三季度推出，但现在已经进入四季度。此前业绩会上也提到训练已基本完成，目前延后是因为实测效果未达预期，还是出于其他原因？

A:并非效果未达预期，主要是发布时间表的安排。先发布M3.1，可以降低M3 Pro推出后出现问题的概率。

所谓出现问题，包括像M3一样发生思维链跳点等情况，推理优化也可以先在M3.1上完成。因此，整体安排是先发布M3.1。9月份实际发布的是M3.1 Flash，M3.1完整版尚未发布。M3.1 Flash不是M3 Pro，M3 Pro的能力会更强。整体进度只是略有推迟，至少9月份已经发布了一个模型。

Q:M3.1 Flash发布不久，目前是否已经看到用户量或用户数量有所提升？

A:尚未看到明显提升。Code harness目前并不是最好的harness，仅将模型绑定在M3.1 Flash上，很难促使用户持续使用，很多人只会短暂体验。因此，它尚未带动产品，但这也符合此前预期。后续还要等待M3.1完整版发布、API开放并提高harness能力。模型变强并不意味着产品自然会获得用户。

Q:抛开自身产品，从行业宏观角度看，海外头部模型及Coding产品都在降价。这是否会使面向全球市场的国产Coding模型面临更大的竞争压力？

A:成本端确实存在一定压力，但这并非短期问题。最大的区别仍然在于开源与闭源的关系。海外闭源模型即使降价，也尚未达到国产模型的价格range。

大型企业部署模型时，还会考虑是否会被OpenAI和Anthropic绑定。会接入这两家模型的企业通常早已接入；按照收入口径计算，两者已经占据50%以上的市场，这部分不会发生太大变化。但目前还看不到它们能够进一步覆盖低端或低价模型市场。最大的增量仍然来自每家企业拥有自己的小模型，或者未来获得微调模型的机会。最重要的是积累用户使用产品时的一系列反馈数据和decision sequence，再用于后期调优。许多客户已经在这样做，也有许多客户尚未起步，而开源模型提供了这种potential。

目前几家国产模型的市场份额仍在提高，不仅体现在OpenRouter上，按照整体模型用量计算，份额已经超过55%，接近60%，因此整体情况尚可。主要原因是客户会以multi-model形式调用模型，而非只调用单一模型。例如，大部分客户采用的是OpenAI的API体系。

Q:在几家主要国产模型之间，竞争格局和用量会如何分配？开源场景是否大多会选择能力最强的模型，还是取决于各自在不同领域的harness能力？具体会对模型能力提出哪些要求？

A:这取决于task。按照task比较，主要有推理难度和任务长度两个维度。推理难度越高，例如需要几十步、50步以上甚至上百步，context也会增大，误差会累积并被放大。模型在执行过程中要能够自我监督，最重要的是在发现偏离目标后可以回滚，具备抗污染能力。对于workflow execution，基本上只有排名靠前的模型能够完成。

目前部分模型已经能够完成debugging，智谱可以做到，Kimi可能略弱一些。这类任务要求模型具备建模、planning和分析能力，需要拆解任务，判断各步骤的先后顺序及其依赖关系。因此，此类任务仍然只有Top 3到Top 4的模型能够完成。对于这部分需求，客户通常不会选择能力不足的模型，相关厂商也基本无法进入这一市场。

现阶段需要逐步提升，首先处理中低档任务。多模态模型在customer support等场景具有一定优势，也能够实现cross-sell；之后可通过新模型，包括新的海螺模型，逐渐向更高阶任务拓展。目前前端能力已经较为不错。前端代码正确并不等于视觉正确，而原生多模态模型在front end和UI方面表现较好。对于低难度task，这类模型基本能够覆盖较大比例；客户完成测试并顺利使用后，通常采用两个模型即可覆盖大部分用量。但较难的任务仍然需要更高端的模型。推出M3 Pro，就是希望进入Frontier模型能够处理的task。

Q:未来的竞争格局是否会是:长任务或复杂任务需要更高端的模型，这类模型能够获得较高溢价；而对于各家都能完成的简单任务，价格压力会比较大？

A:简单任务的价格压力会比较大，但模型能力仍须达到一定水平，因为其中存在许多edge case。企业宁可采用性价比较高但并非最便宜的模型，以便处理这些edge case。如果目标完全是cost maximization，理论上可以只选择最便宜的模型，但实操中很少有企业这样做。

企业实际运行一两天后，往往会发现许多bug，需要重新处理，代价非常高。许多任务属于continuous workload或workflow，甚至直接面向customer，错误成本很高。并非每个task之后都有人监督，很多时候是由Agent持续跟进。因此，目前尚未看到真正的地板价、race to the bottom或模型完全commoditized的情况。市场容易将其类比为chat，但大部分能够从模型中获益的客户，其任务仍然比较mission critical，特别是在直接面向客户的情况下。

因此，模型能力达到标准并跨过一条基准线仍然非常重要。目前能够达到基准线且同时具备性价比的模型，可能只有七八家。

Q:能否给出一个直观判断:M3 Pro推出后会对标哪个模型？在哪些能力上能够对标或超过竞品？

A:M3 Pro主要以上一代Opus模型作为benchmark，即Opus 4.7，4.8，这些模型的能力已经较强，并不主要以国内模型为标准。按照当前静态情况判断，M3 Pro推出时应当能够超过K3；但与Opus 4.8相比，其frontier coding能力仍然有所欠缺。

在agentic能力方面，M3 Pro有较大提升。M3 Pro是面向Agent设计的模型，reinforcement learning基本都针对Agent能力的短板，最终表现还不错。

在Web development方面，Front-end能力较好，Back-end仍相对较弱。Back-end表现最好的是GPT，M3 Pro与GPT和Anthropic仍有一定差距，甚至比其他部分模型也略弱。不过overall来看，如果现在推出，可以在国内达到SOTA水平。但模型竞争本质上是在与时间竞赛，最终评价仍取决于推出时点。

Q:网上称M3 Pro拥有2.8T参数。您是否了解这一代模型训练及开展reinforcement learning大约需要多少张卡？

A:具体训练和reinforcement learning使用了多少张卡，我不清楚。

Q:这些卡主要位于内地还是海外？目前主要通过租赁形式获得吗？

A:这些卡位于海外，目前仍主要采用租赁形式。

Q:M3 Pro具体会在什么时间推出？是否要先发布M3.1正式版，再发布M3 Pro，因此可能要等到11月或12月？

A:对客户承诺的时间是10月份。

Q:从国产模型推出新旗舰模型的角度看，新模型通常能否较快提升ARR？这种提升可以持续多久，主要取决于自身能力，还是竞争对手推出更新、更强模型的时间表？

A:两方面因素都有影响。目前Coding的penetration如果按照用户人数计算，已经接近一定水平；但从agentic task来看，由于背后提供服务的是Agent，可以完成的task数量会多得多。模型能力提升后，会经历一段非常陡峭的增长curve。海外现阶段这部分增长已经略有降温，但内地尚未进入这一阶段。至少在Coding能力方面，部分国产模型尚未获得这段增长，智谱已经获得了一部分，主要因为它能够处理相对frontier的Coding和Agent task，并由Agent在后台自动化执行。

因此，更关键的是能否进入这部分市场。竞争对手的能力当然也很重要，因为这是一个动态市场，但核心仍在于模型能够handle多少过去无法处理的additional task。这是一个更大的市场，而且每个月都在增长。只要持续提升自身能力，就已经解决了大部分问题，也会自然获得竞争对手的一部分市场，因为整体市场仍在扩大。

Q:模型在内地训练和海外训练，后续商业化时是否会受到不同限制？

A:训练地点对商业化没有太大影响。行业普遍会在海外训练，再通过Internet将权重传回，文件大小最多约为1T。从新加坡或美国传回并没有明显区别，因为传输的是已经冻结的静态权重，而不是推理过程中的权重。

更重要的是推理部署地点、节点速度以及所使用的推理框架。训练地点主要取决于能否获得所需算力。现在训练与推理往往并行进行。过去训练和推理相对独立；现在训练过程中需要生成大量Token、执行任务并让模型获得反馈，因此相当一部分推理资源需要靠近训练资源。

因此，在更接近内地的新加坡或东南亚节点进行训练，会友好很多。

Q:如果服务内地客户，为避免数据出境问题，推理是否基本需要部署在内地？

A:是的，基本需要部署在内地。

Q:从MiniMax的角度看，目前内地和海外的推理资源是否充足？有些厂商会因推理算力不足而暂停Coding Plan。假设M3 Pro上线，内地和海外的推理资源能否及时承接？

A:目前可以承接。除自有推理资源外，还可以使用云平台、高性能推理平台、New Cloud及部分co-location facilities。

目前推理资源仍然充足。Coding侧虽然毛利率差异较大，但尚未到必须暂停服务的程度。

Q:K4可能在年底或明年年初推出。假设M3 Pro于10月份推出，是否意味着会拥有大约两三个月的窗口期？应当如何理解这一竞争态势？

A:可以这样理解。K3已经推出两三个月，是一个能力较强的模型，在此期间也积累了许多较为规范的数据。因此，短期来看，其在Coding task上的进步速度会略快。理论上预计K4大概率仍会超过M3 Pro。

但M3 Pro推出后，迭代速度也会同步加快，双方差距可能缩小。目前M3与K3之间的差距仍然较大，但到M3 Pro与K4，以及之后的下一代模型，差距会逐步缩小。特别是在多模态能力方面，相关能力能够反哺全模态数据。

此外，原生多模态模型可以handle部分其他模型无法处理的task，特别是在computer use和GUI-based computer use方面。采用此类模型作为底座模型的厂商和大型App正在增加，多模态优势及Agent方面的增长会逐步体现。Coding能力可能无法做到最领先，但如果Agent能够看懂图像并完成多模态推理，相关能力可以达到Top 2。

Q:也就是说，M3 Pro会采取差异化路线，而K4在Coding方面可能仍然领先。M3 Pro在长任务或复杂任务上的实际能力如何？是否有大致的评价或判断？
