核心摘要

  1. Databricks、Datadog、Snowflake在Q3与Nebius签订多年框架加弹性扩容合同，预计最快2027年3月、慢则4-5月才明显放量。
  2. Token Factory收入中托管推理约占七成、增速一倍多，精调后训练约两成、增速两倍多，RAG工具约一成。
  3. 专家认为Token Factory 2027年20亿美元ARR预期偏中性，风险包括Fireworks、Baseten、OpenRouter价格战及开源模型厂自建API。
  4. 10月以来推理负载环比约翻3倍，平台模型从40多款增至60多款，DeepSeek v4.1、千问等首发及Groq 3 LPX内测带动调用量激增。
  5. 国产开源模型已开始按Token流水向Nebius收取分成，预计拉低毛利率约3-4个百分点，并将直接体现在后续季度业绩中。
  6. Zero Data Retention成为金融、医疗和欧盟合规客户的硬性准入标准，Prosus、Revolut等客户因此迁移至Token Factory。
  7. Nebius前五大客户约占75%，Meta自2026年3月、微软自2026年9月开始贡献收入；与Palantir为无最低采购承诺的优先合作框架，Q4仅少量收入。
  8. 专家认为Q4业绩不及预期是新泽西电力和审批延期造成的短期扰动，客户未取消订单，但2027年政策存在不确定性。

【以下为专家观点汇总，具体细节仅供参考。】

管理层提到Databricks/Datadog/Snowflake头一次和公司签了多年合约，对收入贡献规模和时点？涉及的服务？算力需求规模？

现在是属于框架加弹性扩容的模式，不是一次性固定算力的那种。服务方面，Databricks是用Nebius的GPU集群做模型训练和数据预处理。Snowflake是在Nebius上跑Snow Park，包括AI模型的推理。Datadog则是部署自身的AI监测，包括日志的AI推理负载。这三家都已经接入到Nebius Token Factory的托管管理平台。据悉他们是在Q3签的合同，收入现在开始逐步确认，放量的话今年（2026年）不太可能，预计快的话明年（2027年）3月，慢的话可能得4、5月才能有明显的量。当然他们也可以根据自身业务弹性追加，这都没有问题。

Token Factory今年（2026年）收入预计中推理、精调/后训练，RAG/Agent等工具细分的比重？各自的增速情况如何？

现在推理主要是托管推理，占比大约七成，增速基本在一倍多一点左右，这是Nebius的基本盘。精调后训练大概占两成，增速大约两倍多一点，这是增速最高的部分。RAG配套工具，包括检索、embedding和编排等，占剩下的一成左右，环比增速差不多不到两倍。推理绝对是Nebius收入的底盘，这个长期不会变。但像精调和Agent类负载的占比在持续提升。客户也从单纯调模型，慢慢转向端到端的生产链路。

对Token Factory明年（2027年）20亿美元的ARR预期是否保守？核心的增长驱动力？

我觉得这个预期偏中性。现在Nebius的存量客户，比如Sword Health、Prosus、Revolut等，还是持续放大token调用，包括刚提到的三个新客户也在导流过来。Groq 3 LPX低延迟推理产品上线后，也会承担一些Agent的高吞吐需求，包括Eigen AI加上Clarify一体化的后续链，以及整个优化套件，都在提升客户粘性，所以量是有的。无非就是像Fireworks、Baseten、OpenRouter这些在打价格战，压缩Token单价。另外，上游算力如果政策不允许新建，Nebius也担心会不会延期，但目前没有听说会延期，只是有这个顾虑。还有一些开源模型厂可能会直接推出自己的API，可能会绕过Nebius平台，这也不是不可能。

现在推理服务上已经和Fireworks、Baseten有价格战？如果后续数据中心建设放缓，价格是否会有支撑？

我个人认为会的。如果政策不允许新建数据中心，价格战不会打得很激烈。因为需求摆在这里，产能受限的话，市场就会变成卖方市场，而不是买方市场。

Token Factory现在整体Gross Margin或者OP Margin水平？未来两个季度趋势？

推理和毛利最高，Rag工具其次，精调板块稍低。未来两个季度，毛利率预计还会略有提升，主要因为推理单元的Groq 3 LPX硬件和单位token成本在下降。精调板块的毛利率会有一定压力，因为资源消耗较多，目前Nebius也在优化单GPU的token吞吐，客户也更愿意签长期合约，包括通过缓存技术降低成本。风险主要在于国产模型分成抬高成本，或者客户转向自建推理集群。

似乎Token Factory的token调用量从10月以来显著提升？尤其是最近两天涨幅很大有什么特别的原因？

确实，token调用量最近涨幅明显。主要原因是很多企业客户在四季度上线了Agent业务，比如风控和客服等生产链路。同时，很多新模型如DeepSeek、千问等首发都优先在Token Factory上线，吸引了大量流量。Groq 3 LPX集群也在逐步开放内测，带来了更多低价或低延迟Agent需求。DeepSeek v4.1的调用量激增，因为该版本长上下文和代码能力有大幅升级。Nebius第一时间完成了推理优化，并支持zero data retention模式，吸引了金融和风控客户从并模型迁移过来，进行代码和长文本分析。

Groq 3 LPX主要面对哪些客户和需求？与通常的GB300几家的目标需求差异？

LPX不是用于训练，主要用于agent和decoding的生成环节。客户主要是代码agent和IDE厂商，比如Cursor等，涉及长上下文代码检索和生成，对初次速度要求高。还有金融实时推理客户，如交易风控、合规审查、长文档合约agent，这些客户通常要求zero data retention。企业多agent平台和agent编排厂商也会用LPX，比如日志分析和数据查询agent。还有垂类SaaS医疗客户，主要用于高频工具调用和开源模型服务商社区的高交互版本，主要做主权模型实施研判和长文本分析，不是主打纯批量离线推理，更多是批量摘要。

现在在Token Factory做垂类训练的客户数量有显著增加吗？增长速度如何？

有的，推理负载基本环比翻了3倍，十月之后增长尤为明显，主要受DeepSeek和Groq 3 LPX等推动。模型数量从上线初期的40多款增加到现在的60多款，按月上新。DeepSeek、千问、Kimi、MiniMax、GLM等国产模型持续新增，同时Nebius也为模型做专属优化。付费客户的专属endpoint数量也在增加，整体都在增长。

关于zero data retention，是否看到更多有顾虑的客户因此从云厂商或模型厂迁移到如Nebius等平台？

我的感受是，金融、医疗和欧盟合规企业会将Zero Data Retention作为硬性准入标准，这是非常核心的差异化。普通互联网客户对此优先级较低，因此确实会有客户迁移，比如Prosus和Revolut这类受严格数据合规约束的客户，会将原本在闭环API上的数据迁移到Token Factory，核心诉求是输入输出不留存，不用于模型训练。目前这类客户在Nebius整体客户中的占比还可以。

是否看到国产的开源模型开始向Nebius收取分成？对利润的影响明显吗？

已经陆续有国产开源模型开始向Nebius收取分成。现在是按照TOKEN流水进行分成，每家情况不一样。这确实对Nebius的毛利率有一定影响，大致影响在3-4个百分点。

这个分成会不会直接体现在下个季度，或者未来两个季度的业绩上？有没有比较有效的方式去消化这个成本？

我认为应该会直接体现出来。因为这3-4个点的分成影响其实已经不低了，这个影响会比较明显。

是否听说Nebius会不会像Fireworks一样自己后训练一个Ember模型以降低成本？

至少Nebius公司不会去自研基础大模型。Nebius会持续做蒸馏和微调，包括推理侧的自有优化层，主要是在开源底座基础上做定制版本，用来降低单位token的成本。纯自研的话，无论是算力还是人才都很难获取，即使Nebius愿意出高价，别人也未必愿意来。所以Nebius和Fireworks的Ember路线是有区别的。Fireworks主打自研底座，而Nebius定位是基础设施加模型优化层，优先和上游模型厂商合作，这是Nebius一贯的作风。Nebius尽量避免承担基础模型训练的巨额成本，公司也承担不起。毕竟Nebius不像微软、Meta那样资金充裕，没有那么多钱可以投入。

Eigen AI和Clarify的收购整合进展？收购后在训练和推理两个维度，与Fireworks和三大云厂相比有哪些优劣势？

目前Q3底层已经打通，EIGEN AI已经内置到Nebius的Token Factory控制台，客户可以一键调用EIGEN AI做DRPO，包括RF的一些后续功能。输出的模型直接通过Clarify进行推理优化、量化和缓存部署，实现了端到端的闭环。我认为Nebius的优势在于后训练和自有算力的深度绑定，带宽和集群调度优化做得不错。但模型生态方面比不上亚马逊和微软的丰富程度。Fireworks的优势在于自研Ember模型的闭环，而Nebius的优势是算力供给上限更高。推理优化方面，Clarify在长上下文缓存和decoding，以及Agent链路优化上有一定优势。与三大云相比，Nebius在开源模型优化上更专注，比如zero data retention是原生支持的。但Nebius的短板是没有闭源自研模型的底座。Fireworks的推理优化偏向自家Ember系列。

如何展望Token Factory与专注推理服务的Fireworks、Baseten，以及与hyperscalers的竞争和未来一年的份额前景？

大家的主攻场景不一样。比如Baseten主打中小开发者和快速原型，Fireworks靠自研Ember模型绑定流量。Nebius主要面向企业生产级agent、大流量的稳定托管、包括CDR（Consumer Data Right）合规、以及超大算力的兜底。所以说大家的主攻方向不同，不会出现严重的内卷，但市场份额肯定会去抢。Nebius主要去抢合规、稳定性和中大型企业客户需求，中小开发者市场并不是Nebius的主攻方向。Nebius的优势在于底层自有算力，比如Groq 3 LPX是在Nebius首发的、包括zero data retention、EIGEN AI加Clarify一体化。但价格肯定不是最便宜的，对于小客户来说，上手门槛高于Fireworks和Baseten。

Nebius和Palantir的合作进展？形式？是否已经开始贡献收入？

Nebius现在和Palantir的合作，优先还是以AI云伙伴的形式为主。原本这个客户在Nebius这边是运行主权AI模型的微调和推理，他们主要负责上层的AI应用。Nebius主要提供算力支持，同时加上Token Factory这个平台，整体属于渠道联合销售的模式。合同是在Q3签署的，Q4已经有少量收入贡献，但目前短期内体量并不大。整体上限其实并不由Nebius决定，主要还是取决于政企和国防客户的落地节奏。因为整个订单周期相对较长，合规门槛也很高，所以落地节奏不会很快。

Palantir有没有如Nebius签一个算力锁定协议？

目前他们和Nebius签的是优先合作框架协议，也就是preferred partner，但没有承诺最低采购金额，也没有固定MW数的算力锁定，也没有保底值或排他条款。现在是把Nebius南边的算力，通过Foundry嵌入到API平台，由政企和商业客户下单采购算力。可以理解为渠道转单的方式，终端客户是下游的，并不是平台本身。整体就是这样。当然，如果某个终端客户体量很大，也有可能会和Nebius签独立的算力锁定协议，包括容量签约和合约，那部分才是刚性需求。但很多中小客户是按需弹性调用，没有所谓的锁定协议。所以目前只是渠道导流，平台本身不会兜底。具体还是要看客户。

有没有Nebius在Q3前五大客户的收入贡献比重？

Nebius这边前五大客户基本占了75%的量，尤其是微软和Meta这两个客户，基本占据了绝大部分。未来两个季度的环比增速，因为算力交付可能会有延迟，这个影响还不确定，但肯定会有影响。像Meta是2026年3月才开始贡献收入，微软这边是202 6年9月才开始有收入，后续会随着纽捷站点分批上线逐步释放。

怎么看Q4业绩预期的miss？是短期震荡还是长期增长曲线的理性回归？

我觉得没有必要太悲观，这只是一个短期扰动。需求端该怎么样还是怎么样，只是没有以前那么狂热，大家回归理性了。现在客户没有取消订单，至少我没有了解到有客户取消订单。新泽西这边的电力、燃料电池和审批延期，导致算力交付延迟，出现了波动。但客户合同还是照常执行，虽然微软有点不高兴，但也没有终止合作，需求依然存在。以前大家很狂热，认为会有无限高增长，现在则是基于实际交付能力，兑现能力优先。我认为大家已经回归理性。影响波动的主要还是政策，因为Nebius也不知道2027年会怎样，明年1月民主党上台后具体政策还不确定。

怎么评价Nebius的公司文化和管理层执行力？怎么和CoreWeave相比？

Nebius公司整体偏工程导向，技术氛围很浓厚。因为是长周期布局，Nebius愿意同时布局重资产和轻资产第三方全站，两方面都在做。执行力方面，在软件栈和通过Factory这类MaaS产品上，我认为Nebius至少是行业第一梯队。但短板在于美国本土的电力、社区审批和燃料电池供应链的落地和管控，这方面有些弱，所以美国站点延期也暴露了短板。当然，也有政策原因，但不能把所有问题都归咎于政策。对比CoreWeave，他们主要做GPU租赁，与英伟达深度绑定，业务相对单一，交付节奏和管控很稳。Nebius业务更广泛，包括第三方轻资产和多线并行，增长弹性大，但变量和风险点也多。不能简单说谁好谁坏，但我认为Nebius相比CoreWeave还是有优势的。
