一、多少生意，建立在消费者嫌麻烦之上？

研究一家企业的竞争壁垒时，切换成本往往是一个重要因素。

客户更换供应商，需要重新学习、迁移数据、放弃累计权益，或者承担服务中断的风险。这些成本能够保护现有企业的客户关系，也给企业留下一定的提价空间。

但在日常消费里，切换成本还有更普通的一面：忘了取消会员，不愿意比较保险，或者明明觉得宽带太贵，却一直没空联系客服。

这些摩擦同样真实，也同样能够保护企业收入。消费者知道可能有更好的选择，但省下的钱未必值得自己花几个小时去处理，于是继续付费。从企业的经营数据看，这也会表现为稳定续费、较低流失和较长的客户生命周期。

今年 2 月，Citrini 在一篇面向未来的情景推演中，把这一问题推到了投资者面前：如果消费者有了一个不怕麻烦的代理，自动续费、套餐比较和保险续约还会像过去一样吗？文章是情景假设，其讨论给我们留下了一个具体问题：企业的客户黏性，有多少来自客户认可，又有多少来自客户没有采取行动？

过去，即使留存来自惯性，只要这种惯性足够稳定，它也可以构成有价值的竞争壁垒。Agent 出现后，需要重新评估的正是这个前提：原来必须由消费者亲自承担的搜索、比较和沟通，开始有机会交给一个助手完成。

如果委托成本足够低，过去“不值得我花时间”的事情，就可能变成“值得让它去做”的事情。一部分摩擦成本的性质，正在从消费者必须承受的负担，变成可以被技术压低的执行成本。

这也是本文讨论商业模式的起点。接下来最值得观察的，是消费者是否开始检查原来不看的账单、争取原来懒得要的优惠，以及完成原来一直拖延的切换。Muse 已经提供了几个早期窗口。

二、从 Muse 看，消费者正在把哪些决定交给 Agent？

先看使用结构，再看具体消费场景。

FUNDA 在 9 月 21 日的研究中，整理了 654 条来自社交平台等公开渠道的 Muse 使用分享。按其分类，生活事务合计占 62.8%；其中，“省钱、退款和个人理财”为 128 条，占 19.6%，购物为 62 条，占 9.5%。这里的“生活事务”是多个类别的合并口径，包含购物；19.6% 也不是退款单项的占比。

这些是公开分享的样本，不能代表全体用户的任务分布，节省金额也主要来自用户自报。但这一结构值得关注：用户既会让 Agent 寻找和购买商品，也会让它检查已有支出、争取退款、重新议价和调整长期服务关系。

退款则提供了另一个角度。一位用户分享，Muse 找出家人一年多前忘记取消的图书订阅，随后取消订阅、查找退款条款，并称追回了过去一年的订阅费用。报道没有给出具体金额。

这些消费行为过去都可以由人完成，区别在于，现在有人愿意把处理过程委托出去。

对订阅服务而言，消费者不必等到偶然发现扣款，才重新评估是否还需要；对电信服务而言，觉得贵之后，可以进一步要求调整报价；对保险而言，比较和填表不再必然成为放弃切换的理由。

它们对应三个值得持续观察的环节：原来被忽略的支出是否被发现，原来不愿进行的谈判是否发生，原来没有完成的切换是否落地。

当然，消费者省下的钱不能直接等同于企业永久损失的利润。优惠可能有期限，套餐条件可能不同，退款也可能只是一次性处理。对商业模式真正有影响的，是这些行为能否从少数人的主动尝试，变成更多消费者反复使用的习惯。

三、切换成本需要重新拆开

切换成本并不是一种性质统一的护城河。判断 Agent 的影响，需要先看客户留下的具体原因。

第一类，是注意力和操作成本。

检查账单、记住到期日、比较条款、填写材料、联系客服，都需要时间和精力。消费者并非不知道这些事情有价值，只是未必愿意处理。

这部分成本最容易受到 Agent 的影响。尤其对单次金额不大、步骤却很繁琐的事情，自动化可能改变消费者是否采取行动的判断。

第二类，是切换本身造成的实际损失。

提前解约需要付费，换服务可能失去累计权益，迁移系统可能影响业务连续性。这些损失不会因为有人代办就自动消失。

Agent 可以帮助计算得失、安排迁移、降低失误，但无法凭空消除合同费用，也无法让原来不可替代的供给突然变得可替代。

第三类，是现有服务持续创造的价值。

更可靠的交付、更好的质量、稀缺供给和有效售后，本身就可以支持客户留存。消费者充分比较后，仍然可能愿意留下，甚至接受更高价格。

品牌也需要这样看。如果用户重视某种审美、品质或稳定体验，理解用户的 Agent 应当保留这些偏好。自动比较并不等于只选最低价。

同一家企业，往往同时拥有这三种留存来源。分析的重点是弄清楚，它的利润对每一种来源有多大依赖。

因此，研究客户黏性时，可以增加一个问题：

> 如果客户拥有一个可靠的助手，替他完成搜索、比较、沟通和迁移，这家企业还保留哪些让客户留下的理由？

过去，“操作麻烦”也可能形成稳定的壁垒。现在，其中可以被自动化的部分，需要与真实迁移损失、产品和服务价值分别评估。

四、客户未必离开，定价权可能先受到影响

客户流失并不是唯一需要观察的结果。

当消费者借助 Agent 获得更低的续约价，企业可能保住了客户数量，却没有保住原来的收入。对一些业务而言，变化可能先出现在优惠力度和单客利润上。

这背后是议价关系的变化。

过去，客户说“太贵了”，未必意味着他会离开。研究替代服务、重新申请和安排迁移，都有成本。现有企业知道，一部分客户最后还是会接受原来的条件。

如果 Agent 能取得真实的替代报价，并把切换步骤准备好，客户离开的可能性就更可信。即使最终没有切换，企业也可能需要给出更好的条件。

> 高留存率仍然可以存在，但维持高留存率的代价可能提高。

金融股的反应，把这一问题推到了资本市场。

9 月 22 日美股收盘，标普 500 金融指数下跌约 2%，嘉信理财下跌 6.1%，Ameriprise 下跌 4.4%。路透报道提到，Muse 的热度开始引发投资者对财富管理业务竞争的担忧。

与本文场景最相关的，是券商账户里没有被主动管理的现金。一些客户卖出股票后，把钱留在默认现金安排中，没有继续比较收益。嘉信的现金管理披露说明，关联银行可用归集存款支持贷款和投资，从资产收益与付息等成本之间赚取利差；这类业务的收入可能高于管理货 币市场基金所收取的费用。

笔者认为，Agent 可能改变的是客户多久检查一次这些现金、比较替代产品后是否真的行动。如果它能在获得授权后持续提醒并协助调整，客户不必更换券商，也可能把低息现金转入同一平台上的货币市场基金或其他产品。券商仍保有账户和资产，却可能失去一部分低成本资金，收入结构和单客利润随之改变。

这比“客户被另一家券商抢走”更值得留意：账户留存甚至平台总资产都可能保持稳定，但同一笔客户资产给企业带来的收入已经不同。企业若提高现金付息来留住存款，也可能先承受利差收窄。实际影响还取决于资金去向、替代融资成本，以及其他业务收入能否补上。

现金管理也有真实的服务价值。备用资金、交易结算和支付便利都有用途，存款与货币市场基金的保障、风险和流动性安排也不同。Agent 要理解这些条件，不能只比较收益率。此次股价反应说明市场开始重新评估这部分收入；Muse 是否已经造成可观的现金迁移，仍需后续经营数据验证。

同时，企业也会调整应对方式。供应商可能收紧议价空间、重新设计套餐，也可能通过更透明的价格和更好的交付吸引客户。Agent 可以降低比较成本，却不能保证每次比较都能获得优惠。

对价格合理、服务可靠的企业，这种变化也可能带来机会。当消费者更愿意重新选择，原本被忽略的供应商就更容易进入考虑范围。

最终需要判断的是：一家企业能否在客户更充分比较之后，仍然维持有吸引力的利润。

五、新的黏性，是否会向个人 Agent 转移？

如果个人 Agent 长期承担这些事务，新的黏性也可能逐渐形成。

它可能知道用户接受什么价位、重视哪些保障、愿意为哪些品牌付费，知道什么事情可以直接处理，什么事情必须先确认。它也可能保留已经连接的账户、过往的选择，以及此前处理失败的经验。

这些信息的价值在于，用户不必每次从头解释，Agent 就能更准确地完成下一件事。

与此同时，更换 Agent 本身可能开始产生成本：迁移历史记录、重新设置权限、重新交代偏好，以及再次判断它是否值得信任。

底层服务商更容易被替换，一部分黏性可能转移到替用户管理这些选择的个人 Agent。

但这仍是一个需要验证的长期判断。记住更多信息、连接更多账户，并不自动构成护城河。如果偏好和记录可以方便迁移，授权可以快速重建，这部分切换成本也会受到限制。持续的执行质量，才是用户愿意继续委托的基础。

商业化还会带来另一个问题：当 Agent 通过商家佣金或交易导流赚钱时，它推荐的选择，是否仍然符合用户利益？一个靠替用户省钱建立信任的助手，如果后来为了收入影响比较结果，也可能损害最初形成的黏性。个人 Agent 能否建立持久壁垒，取决于它能否在商业化之后，继续让用户相信自己的事务被妥善处理。

切换成本仍然是重要的护城河，但其中依赖消费者时间、注意力和执行意愿的部分，正在发生变化。以后研究客户黏性，除了问“客户为什么没有离开”，还需要问：当比较和切换变得更容易，这家企业还能留下多少客户，又能保住多少定价权？
