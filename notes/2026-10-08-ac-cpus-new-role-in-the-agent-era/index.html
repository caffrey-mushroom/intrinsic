摘要

1、Intel至强的新旧王座；2、鲲鹏、海光，国产双子星的竞争格局；3、国产PC潮的会走向何方；4、谁能突破“Agent内存墙”；5、CPU的记忆控制面优势如何重构算力；

国产算力的“系统战”已经打响。

2026年下半年，国内服务器CPU与AI加速芯片市场正在经历一场结构性重估。

表面上看，驱动力是运营商集采国产化比例创新高、信创PC换机潮、HBM与DRAM涨价缺货；但底层逻辑已经变了——AI Agent工作负载重构了CPU与GPU的职责分工，国产替代从“单芯片替换”升级为“系统级方案竞争”。

一、移动65% ARM集采后，Intel至强在华的基本盘还剩多少？

运营商的服务器新增份额，基本国产化。

移动 2026–2027 年 PC 服务器集采合计 6.29 万台，ARM 路线 40896 台占 65.01%，X86 路线 20815 台占 33.09%（这批里仍混着至强和霄龙，未单独拆分），其他 1000 台；

电信这一轮 4 万台更彻底，百分百国产化；ARM 2.8 万台，合计81.61 亿，占金额 70.7%，C86 1.2 万台，合计33 亿，占金额的29.3%，外资 X86 不再单列新增标包。

联通通用服务器国产占比已到九成，海光约 3.02 万台、鲲鹏 4.82 万台、Intel 仅 8625 台。

ARM路线一侧入围的是华鲲振宇、长江计算、河南昆仑、软通动力这批鲲鹏系厂商。格局很清楚：鲲鹏拿走新增的大头，海光守着 X86 迁移的口子，增量战场上 ，Intel 已经出局。

但 Intel 在华的基本盘不在新增标包里，在存量系统里，撑住它的也不是性能，是"没人敢改"。运营商的 BSS/OSS——营业受理、订单、账务、CRM、结算——连同计费、旧 NFV、VMware 和 Oracle兼容业务，多是十几年前建起来的烟囱式架构，逻辑高度耦合，任何改造都要双轨并行、跑账对账，风险敞口远大于收益，只能保守迁移，这几个板块至今深度依赖至强，生态把存量替换的份额锁死了。同样的逻辑在别处一样成立：互联网的高单线程数据库、老 Java和 Hadoop 栈、PCI 合规要求，以及外企在华的高性能科学计算，都绕不开至强的性能与生态。这是它今年在华最难被撬动的一块。

往后看，2027 年运营商新增通用服务器招标里，至强标包预计仍难有起色：ARM 继续吃掉新建的云原生、大数据和信令预处理，海光 C86 继续主攻政企金融的"无损耗"兼容迁移，互联网的新增通用业务维持 ARM加海光双源，两者份额继续抬升。真正值得记住的是颗数与金额的背离——至强在新增通用里的占比，按颗数可能降到 10%–20%，按金额却仍有 25%–35%，溢价来自高单核、数据库和兼容旧栈这三样。换句话说，它卖的已经不是算力，是确定性。若明年Agent 推理的新建沿着鲲鹏统一内存这条路走，至强会进一步退到"外环控制 + 老业务扩容"的位置：增量指望不上，存量还能收一阵“租金”。这笔租金能收多久，取决于国产替代什么时候啃下那批"不敢改"的系统——那不是 CPU性能的问题，是迁移工程和风险定价的问题了。

二、海光vs 鲲鹏：金融/运营商/腾讯阿里后续怎么双源

海光和鲲鹏的分野，表面是 x86 与 ARM 之争，实质是时间点的产物。2027 年底是国资委要求国资客户完成改造的截止线，存量系统里的 Oracle、SAP、Windows Server 必须在不动代码的前提下搬走，这是一个有明确deadline 的工程。海光 C86手握 x86 授权，能做到近乎无损耗的兼容迁移，客户在"按时交差"这件事上几乎没有别的选择——工行 30 亿、浦发 2.15亿、光大这一串订单，买的不是性能，是零改造成本和确定性。所以海光当下的优势是时间性的，它卖的是截止日期前的那张通行证。

鲲鹏赢在没有历史包袱的地方。运营商侧，它的份额逐年抬升，多次拿下移动、电信的上亿标包；互联网的大数据与数据库建设里也拿下一批标杆项目，按 IDC 口径，2025 年鲲鹏服务器在全国服务器总份额已超过 22%。

把两边的项目属性放在一起看，双源份额真正的分界线其实不是行业，而是"这段代码是旧的还是新的"——旧代码改不动、不敢改的地方归海光，新代码从零写、可以自选技术栈的地方归鲲鹏+openEuler+openGauss。

顺着这条线，三个行业的分布就清楚了。金融的核心账务、老 Oracle、用友金蝶、VMware 这一层改造风险极高，倾向x86和C86；新建的外围云、办公系统、新推理业务、信创全栈和 Agent中台，走鲲鹏加开源全栈反而更顺。运营商的新建通用、均衡型、云平台和大数据项目大份额给鲲鹏，存储、部分 NFV 控制面和旧 x86 业务则加重海光。互联网最典型：自研芯片和鲲鹏做云项目，海光做 x86兼容替代，最核心的老业务存量继续留在至强上。

往前看，2027 年底这个节点会先把海光推到高点——基于兼容迁移的优势，它在国产金融 CPU的金额占比有望提升，运营商的鲲鹏比重继续逐年加重。互联网头部厂商的双源比例都会抬升，但阿里因为有自研倚天，会压低外采鲲鹏与海光的比例，腾讯这条线则维持鲲鹏、海光混用。真正的分水岭在 2028 年之后：按政策导向，新建系统不再编写 x86单体应用，转向微服务加国产后端（openGauss、OceanBase 这一类），新增份额会被 ARM 生态持续蚕食。到那时，海光"省事"的前提——存在大量待迁移的 x86老代码——就不再增长。它的护城河是借来的时间，不是筑起来的技术，红利会随存量迁移的完成而收敛。

三、Agent把CPU:GPU干到1:1：鲲鹏统一内存、海光大核C86，谁更吃香

AI 集群的 CPU 配比已从不到 10% 抬到 15%，海光和鲲鹏都在讲 Agent 会把 CPU:GPU 推向 1:2 甚至 1:1。但 1:1是负载口径，不是插卡口径，真正的算法是按"并发会话×上下文token×沙箱数"反算核时与内存——短问答用不着1:1，长 Agent 加 RAG 加代码执行才需要。

CPU 变重要的根源在于它的活换了：从解码分词这类预处理，变成状态机加内存调度，管的是编排、工具调用、沙箱、长上下文 KV 和向量检索。选型指标因此从主频核数，换成核数与线程、内存通道与容量、有没有 CXL 或统一内存语义；长 KV溢出到主机内存之后，卡的是搬得多快、放得下多少，不是算得多快。这也是 MRDIMM 2.3 倍带宽、八通道 DDR5、单路 4TB 被反复强调的原因。

谁更吃香，看代码是旧的还是新的。老业务叠加 Agent，则海光占优：x86 兼容让Oracle、MySQL、VMware、Java/.NET 免于重编译，DCU 深算系列经 DTK 兼容 CUDA，CPU 编排与 DCU 前向能塞进同一个x86 节点、免掉跨架构调度；金融电信的试点里，老系统叠智能客服、运维助手、报表生成，客户选它图的就是迁移风险低，2027 年在 Java、金融、数据库这几块会拿得比较凶。新建的 Agent 原生负载，鲲鹏占优：统一内存解决 KV容量，CXL 与灵衢解决一跳访问，NPU 管前向，CPU 管编排与安全；只堆 NPU 不堆统一内存，1:1 会卡在 KV 搬移和调度上，而不是矩阵算力——瓶颈在搬不在算，而"搬"恰好是鲲鹏的主场。

2027 年拿单有可能更多的还是海光，因为多数项目停在老业务改造、配比在 1:2 附近；但配比越往 1:1 收敛，越利好鲲鹏。鲲鹏加昇腾的重心落在运营商、政企和互联网，部分 Agent 推理能跑到逻辑 1:1，传统训练仍维持在 1:4 到1:8。

四、2026服务器CPU三轮涨价、DRAM再涨：国内中小IDC会不会改买海光/鲲鹏

这一轮涨价和以往不是一回事。按行业交流口径，Intel 与 AMD 都称 2026 年服务器 CPU 产能基本售罄，计划整体提价 10%–15%；落到国内，部分至强年内已历经多轮涨价，平均涨幅 20%–40%，交期拉到 8–10周以上，高端系列最长能到 5 个月。内存更紧：HBM 把先进产能吸走，普通 DDR5 产量缩水、库存紧张，价格还在往上走，MRDIMM 带宽翻倍却更贵。区别在于，过去的缺货是周期性波动，等一等能回来；这一次是结构性的——产能被AI永久分走了一块。所以客户的反应不是"等降价"，而是开始认真算替换账。

要不要转国产，第一变量不是价格，是业务类型。容器化 Web、缓存、轻推理、私有云、政企合规这类常规负载，鲲鹏和海光都能接，差别不大；老Oracle、用友金蝶、Windows、.NET、旧虚拟化这一层，选海光最省，省的不只是采购价，更是迁移的人力成本；纯推理前置和大数据 Shuffle 这类跑量大、对能耗敏感的负载，鲲鹏在电费上更划算。中小 IDC算的是"采购成本加人力成本"的总和，海光在老栈上赢，赢在不用改代码，不是赢在芯片便宜。

涨价真正改变的是客户愿不愿意试，它把鲲鹏从备选推进了 POC 清单。但从 POC 到批量采购还有三道坎：测试效率、数据库驱动适配、运维人力。中小 IDC恰恰是人力最薄的一群，没有专职团队做深度迁移，所以最终转得动的，还是那部分"插上就能跑"的负载。价格是最直观的转化因素，但不是唯一的，更不是决定性的——它负责把门推开，进门之后走多快，看的是适配。

往后看，2026 下半年到 2027 年，中小 IDC 新增通用服务器里的国产比例会倾斜向上，政府行业、智慧园区、行业自有云这几块走得最快，海光和鲲鹏双管齐下。但也不必把话说满：只要 Intel、AMD的长供协议能提前锁定固定产能，而客户又点名要高单核，中小 IDC依然会买进口高端，应对方式是把备货周期提前到六到九个月，用计划代替应急，而不是临时转国产。这反过来印证了前面的判断——业内已经默认这轮紧张是长期的，不同的只是对冲方式：有能力的用长协锁产能，没能力的用国产换确定性。

五、18A救不了交期：Intel代工在华空窗，中芯+Chiplet接国产CPU盘子

18A 确实在从风险试产往量产爬，14A 也在后面的路线图上，Intel的制程本身没有掉队。但这条曲线和国内 CPU 的交期基本是两条平行线：18A 首先是 Intel 自己的产能，其次 Intel Foundry要接中国客户的先进制程订单，得先过出口管制和实体清单这一关，现实里几乎走不通。市场上"等 18A 上来，国内先进制程的紧张就缓解了"这个期待是错配的——制程追得上是一回事，产能能不能到中国客户手里是另一回事。对国内厂商来说，18A的进展更像一个参照系，而不是一条可以依赖的供给。

所以国产 CPU 真正的解法不是追单 die，而是绕开单 die。眼下主流的组合是"中芯先进制程 + 多 die Chiplet + 长电、通富、盛合晶微这一串本土先进封装"，鲲鹏、飞腾站在 ARM 这一边，海光、兆芯守着x86，各自的授权来源和制程节点不同，工程思路却是一致的：既然单 die 摸不到 18A 的密度和良率，就把大芯片拆成几颗小芯片拼起来，靠 2.5D/3D 互连和 CXL内存池把系统级性能补回去。这条路的收益不在"追平"，而在两件更实际的事——每核成本能压下来，交期能自己说了算。指望国内单 die 追上 18A 来解决交期，既不经济也不现实。

代价同样清楚。多die拼核换来的是吞吐和核数，换不来单核的极致，核间互连的延迟和一致性开销摆在那里，主频和大缓存很难做上去；再加上 GAA 这类器件结构、HBM 配套的成熟度，以及金融核心系统绕不开的 ISV 认证，国产 CPU在顶级单线程这一档短期补不齐。其中最容易被低估的是 ISV 认证，制程可以用钱和时间堆出来，认证周期和生态惯性不行，它往往比制程更能决定一颗 CPU 能不能真正进核心业务。

因此替代会是分层的，而不是一刀切。明年看，海光的中高核 C86 大概率能平掉金融业的中端需求和虚拟化这类负载，这两块对单核极致不敏感，对核数、吞吐和兼容性更敏感，海光的 x86 兼容在这里是加分项；鲲鹏和飞腾用 7nm 级加Chiplet，能吃下均衡型负载和一部分 AI 控制面的活；而顶级至强在高主频、大缓存和全球基准上的位置，国内至少还差一到两代，这一档短期内不会被替代。结论是，18A 救不了国内的交期，真正接盘的是中芯加 Chiplet这条系统级路线，而它的天花板不在制程节点，落在互连、内存和生态这三件事上。往后两年值得盯三个变量：中芯先进节点的良率与产能分配、本土 2.5D/3D 封装的产能扩张、以及海光和鲲鹏在金融与运营商核心系统里的 ISV认证进度——它们决定了"平替"最终能到什么刻度。

六、2027 PC换机潮：党政全国产、消费仍x86，ARM笔记本真实渗透率有多高

2026 年中央直属机关的中标结果，可以看到党政机关的笔记本基本被兆芯、飞腾、龙芯、海光、鲲鹏这五家国产平台包揽，看不到 Intel 和 AMD 的影子。

ARM 笔记本的渗透率，它高只高在信创办公这一块——按台数能过半到七成，集中在党政机关、八大国央企和金融网点，跑的是政策办公、WPS、钉钉、浏览器、打印和国产 ERP 这类已经适配过的软件；而在消费市场，渗透率依然很低。

两种驱动决定了两个市场的天花板。党政是合规驱动，弹性小但确定性极强，份额几乎由政策节奏决定；消费是周期成本驱动，看的是性能与价格的性价比。

国产 ARM 笔记本在消费端输的不是性能——它的卖点本来就是续航、安全和政企集采：游戏、Adobe、工程软件、外设驱动这些东西，仍然会把用户推回 x86。这类适配不是芯片能解决的，也不是一两年能补上的。

2027 年信创 PC 销量有望破千万台级，结构上会分化：鲲鹏、飞腾、龙芯走国产操作系统这条线，生态自主但迁移成本高；海光、兆芯兼容 x86 和Windows，更贴办公场景的平滑迁移，短期内更容易起量。但要看清增长的性质——这千万台主要来自存量换机，不是新增需求，它保证了高渗透率能维持，同时也意味着天花板被存量规模锁死。

未来的增量变量在两方面：行业办公全适配的完成度，以及政策退坡后的留用率。

七、HBM挤占+CPU回春：海光/鲲鹏/Intel谁先解决“Agent内存墙”

Agent 时代的内存墙其实有三层楼板，塌的顺序和训练时代正好反过来。最上面一层是 HBM，给 NPU 前向用，放权重和活跃 KV，最贵也最难扩；中间一层是 MRDIMM 和 DDR5，给 CPU编排用，跑调度、工具调用、沙箱、向量检索，卡的是通道数和带宽；最下面一层是 CXL 和统一内存，接住溢出的冷 KV，用延迟换容量。Agent 推理把负荷从"算"挪到了"搬"，上下文越长、并发越高，KV 越膨胀，编排动作越频繁，于是瓶颈从NPU 前向转移到了 CPU 侧。训练时代只要盯住第一层，因为那确实决定你能不能把模型跑起来；到了 Agent，第一层决定你能跑多大的模型，下面两层决定你能开多少并发、撑多长上下文——后者才是真正的成本项，也是"CPU 回春"的由来。

挤占和回春是同一枚硬币的两面。HBM 吃掉的不仅是先进封装产能，更是通用 DRAM 的位元，同一片晶圆做了 HBM 就少了做 DDR5 的产出，所以内存涨价、CPU 侧内存成本抬升，跟国产卡 HBM 缺货本就是一件事。这也解释了为什么Agent 数据中心的配置单上 CPU 核数和内存条数在往上走——不是 CPU 变强了，是它被推到了搬运工的位置上。

海光/鲲鹏/Intel三条路线卡的位置并不一样。

鲲鹏的统一内存加 MRDIMM/CXL 在架构上最贴 Agent，CPU 和 NPU 共享地址空间，KV 不必反复搬运，天然最省 HBM，代价是生态封闭、迁移成本高，能不能兑现取决于软硬一体的交付完整度和产能。

海光 C86 的多通道加 x86 兼容最贴存量，老业务一行不改就能上，靠更多内存通道和更大容量去补 KV 带宽，它不是最优解，但很可能是最快拿到单子的解决方案。

英特尔至强的 MRDIMM 带宽确实硬，相对常规 RDIMM 提升约 2.3 倍，规格层面不输，问题不在技术而在供给与交期——HBM 和 CPU一起缺，时间点悬；国内大规模 Agent池不会把宝押在它身上，它的角色是性能参照系和高配补位，不是主力。

真正的上限握在长鑫手里。长鑫现有约 30 万片/月的总产能，上海新厂要到 2027 年才进入正式投产。粗算一笔：若 2027 年能出 300 万颗 24GB 等效的 HBM3，对应约 70PB 量级，按 96–144GB/卡配，可支撑50–75 万颗国产 GPU。这个数字的意义不在够不够用，而在于它把国产卡交付的天花板从"设计能力"挪回了"内存产能"——2027 年真正卡脖子的是长鑫的良率爬坡曲线。

八、腾讯星脉NPO超节点+鲲鹏：CPU只干“调度+KV缓存”，Intel至强为何连“控制面”都难进？

超节点把 CPU 的角色重新定义了一遍：算力中心是 NPU，CPU 退到控制面，只管调度和 KV 缓存。2026 年移动的 AI 超节点集采、腾讯星脉往近封装光走，都是要把互连时延压到极致。于是 CPU的考核指标变了——不看核数和主频，看能不能参与全局统一内存编址、让 KV 一跳到达、跟上光互连的调度节奏。鲲鹏超节点的多千节点统一内存、十万级沙箱和数十万 QPS向量检索（行业材料口径，非第三方实测），指向的是同一件事：把整个机群当一台机器来编址。至强进不去控制面，不是性能不够，是它站在总线的外面。鲲鹏配灵衢这类国产总线的内存语义是原生的，CPU、NPU、内存池共用一套地址和一致性协议，跨节点访问接近本地；至强只能走PCIe/CXL 外挂，跨 NUMA、跨厂商总线，每多一跳多一份时延和一致性开销。单机里这点开销可以忽略，拉到数千节点统一内存的尺度上，就会在 Agent 的高频短请求里折损吞吐。结果是分工很清楚：x86老栈还要至强守着接入层，纯新建的超节点里它只能做安全、计量、日志这些外围活。

往 2027 年看，腾讯这类超节点大概率做成内外两层——内构是鲲鹏加自研 NPU，以及昇腾、壁仞、燧原这一档国产算力，负责统一编址和 KV 调度；至强留在 x86 接入层吃存量迁移和运维惯性。若星脉对外交付被要求保留 x86运维生态，就会出现"至强外环 + 鲲鹏内构"的双控制：外层维持习惯，内层拿性能，未必最优，但会是这两年最常见的交付形态。简而言之，谁定了编址权，谁就拿走了控制面。

九、中芯N+2+盛合晶微CoWoS-R：海光6号、飞腾S5000C靠Chiplet绕开EUV，2027能否硬刚至强

市场喜欢把"中芯 N+2"直接等号到海光的某个号、飞腾的某个型号上，但这个对应关系在公开信息里并没有被证实——海光 C86 迭代到四号、五号，公开的只是部分型号，制程未全部披露；飞腾 S5000C 能确认的是 64核这一档。所以更稳妥的做法是看供应链的能力边界，而不是猜单颗芯片的制程。这条链子眼下是这样的：中芯、华虹的等效 N7 产能已经成规模，盛合晶微、长电、通富的 2.5D、类 CoWoS-R 和 XDFOI 能撑住国产 AI 与服务器 CPU的先进封装，长鑫的 HBM3 在推进、与海外仍有代差，18 个月内攻 HBM3E 12 层是内部目标之一。绕开 EUV 需要的每一环——成熟节点做 die、本土封装做拼、国产 HBM 做配套——都已经在位，缺的是精度和时间，不是从零起步。

Chiplet 能补的和补不了的得分开看。用两到四颗小 die 拼出高核数和大内存通道，再配上 CXL 与 2.5D/3D 封装，系统级的吞吐、并发和内存带宽确实摸得到至强中高核的水平，这是国产 CPU 最现实的追赶路径：绕开 EUV这道门，靠工程结构换性能。但单线程、浮点、老 ISV 基准和全局缓存一致性这四样，本质取决于制程节点和微架构，Chiplet 帮不上忙，多 die 反而给一致性增加负担。这就决定了国产 CPU的强项在"堆得起来"的负载，弱项在"跑得够快"的单点。

所以 2027 年的格局是按场景平替，不是全型号跑分平替。海光 C86 的中高核大概率能在金融、虚拟化、数据库这类中端负载上正面顶住至强，x86 兼容让它不动业务就能换；飞腾 S5000C 这一档 ARM芯片在政务、5G、存储和大数据这类均衡型场景里同样够用，功耗和核密度是筹码；而至强 Platinum的高主频单机、顶级缓存配置和全球基准，国产短期内够不着，这一档仍留在 x86手里。判断这个进程只需盯三个变量：中芯等效 N7的良率与产能分配、本土类 CoWoS-R 封装的月产能、长鑫 HBM3E 12 层的进度——它们共同决定国产 CPU 能平替到哪一层，以及什么时候往上顶一层。

十、鲲鹏256TB统一内存+Agent沙箱：CPU从“配角”变“记忆控制面”​

Agent 把 CPU 从配角推成了记忆控制面。传统推理里 CPU 只负责搬数据，现在多了四件硬活：任务编排、沙箱生命周期、长 KV 分层、向量检索。华为全联接 2026公开的那套鲲鹏超节点，等于把这四件事一次性装进架构——基于灵衢全光总线最大 4096 节点，液冷下形成 256TB 统一内存池（风冷当期是百 TB 级）。有了这个池子，KV 就能分三层放：热的留在 NPU 的HBM，温的卸到鲲鹏统一内存，冷的落到 OceanStor M900 做 PB 级缓存，顺带把 SSD 寿命提了 16 倍。CPU 在这里干的不是计算，是决定每一层的路由和准入，本质是记忆管理员。效果也写在数据里：序列到了 256K以上，单卡内存需求超过 300GB，接上统一池之后 NPU 单卡吞吐在 256K 和 1M 下分别提升约 2 倍和 2.6 倍（厂商口径）。

沙箱是另一件 CPU 躲不掉的活，而且它证明了一件更要紧的事——这类能力不是堆核堆出来的。十万级 Agent 沙箱并发启动比传统方案快约 30 倍，靠的是统一内存里的镜像预加载加 RemoteFork，把冷启动压到 10秒级，再用硬件隔离保证互不打扰。这里的关键变量是内存语义和隔离粒度，不是核心数。所以判断一颗 CPU 能不能接 Agent 的活，第一眼不该看核数，该看它有没有一个所有节点都能统一编址的内存池。

按这个标准横着比，三家缺的东西不一样。海光 C86 用 CXL 加 DDR5 补老业务的 Agent 需求，兼容性和性价比都不差，但没有统一总线，温 KV 这一层落不干净；阿里倚天思路接近，自研逻辑相似，KV 存储层不完整；至强的MRDIMM 带宽确实硬，问题是 8–12 周的交期叠加涨价，更根本的是它进不了灵衢这一级的 Scale-up 内核——和上一章的判断一致，它站在总线的外面。鲲鹏的壁垒是"通智存一体"加上从沙箱、KV 分层到国密可信根的一整套 Agent全栈参数（异常行为拦截率宣称 99%），软肋也清楚：生态封闭，非华为云客户的接入成本高。

节奏上分三步看。2026 下半年运营商和政企的 Agent 试点会先落数百到数千沙箱，不会一上来压到十万，验证的是流程而不是极限。2027 年的关键变化在采购口径：从"每颗 GPU 配几核 CPU"改成按"每千并发会话 × 上下文长度 ×沙箱数"反算配置，长上下文多轮 Agent 的物理 CPU 与 NPU 配比可能走到 1:2 甚至 1:1，而传统短问答仍停在 1:4 到 1:8；鲲鹏在运营商新增的 Agent与通智协同超节点里会占多数，金融的强化学习、反欺诈因国密和隔离要求也会优先，海光靠 x86 兼容吃老业务迁移，至强退守高端单线程和存量兼容，纯新增的 Agent 控制面它很难进。到 2028 年，超节点大概率成为 Agent集群的标配形态，只卖 GPU 不搭内存池的厂商会在标书里丢单——那时候卖的不是卡，是"卡 + 内存池 + 控制面"这一整套。
