核心摘要

  1. 海外光模块厂商（AAOI）最新签订的长期供货协议客户为AWS（主打800G，4年最高100亿美元，最低承诺含2027年15亿美元800G及2028-2029年7亿美元激光器二极管），而2026年10月签署的1.6T长协客户为Oracle（目前正常执行未下修，但Oracle 800G订单已基本全部砍完、少量400G亦可能取消）。

  3. 2027年1.6T出货预计超150万只但难达200万只（Oracle月均约12万只，在手单价800美元、新单降至700美元，当前月产能仅8万只），400G产能反扩至20万+/月（全年约240万只）；2027年800G+1.6T合计出货500万-550万只（2026年仅50万-60万只），平均产能利用率升至80%-90%，2028年800G目标550万-600万只、1.6T月产能或达30万只。
  4. 2027年产能交付以台湾为主、宁波次之，美国本土仅产20万-30多万只（客户愿为合规支付10%-20%溢价以覆盖高成本，毛利率与其他基地相当）；德州Sugar Land工厂整体延期约7个月（实际影响量产约1个季度至2027年Q3上量，一期3万/月、二期18万/月）且800G须重新送样认证。
  5. 激进扩产引发严峻资本开支与融资压力：每10万只/月产能仅设备与无尘室即需至少5亿元人民币（1.6T眼图仪250万元/台vs 800G 60万元，电学后端无法共用），美国20万只/月规划总投入近20亿元，叠加前期800G/1.6T未放量的现金流错配，迫使公司持续通过ATM增发股票融资。
  6. 核心物料与良率瓶颈显著：自研CW激光器放大生产后良率跌至20%以下（小批量曾达40%-50%），低功率CW目前仍缺口外采；1.6T DSP较紧缺（向Broadcom付定金锁定2027H1月均10万+、H2近20万，Marvell交期差，仅覆盖一半以上需求），且公司历史上曾因微软AOC物料及Oracle 400G EML缺货未能交付遭砍单。
  7. 长协中7亿美元激光器承诺属此前规划外增量，但AWS在ELSFP尚未送样（2027Q4仅先供AMD约10万只，2028年全年500万只存挑战）、NPO仅在设计阶段（2027年6万只光引擎能见度低）；专家未听说英伟达首批500万只NPO订单传闻，但确认旭创已接约100万只谷歌NPO订单。

专家访谈会议纪要

1. 长期供货协议与客户结构

a) 最新长期供货协议的客户是谁？与此前Oracle长协有何区别？

  • 最新长期供货协议的签约对象为 AWS，现阶段主要针对 800G产品。
  • 2026年10月签订的长期供货协议对象为 Oracle，主要针对 1.6T产品。
  • 两份协议的合同性质基本一致，暂未发现明显的实质性条款差异。
  • Oracle此前下修的是800G订单，其1.6T长期供货协议仍在正常执行，暂未下修。

b) 协议中的最低采购承诺是否具有强约束力？

  • 公告提到最低采购承诺及4年最高采购规模，但目前了解，协议中似乎没有明确的违约责任和赔偿机制，法律约束力相对有限。
  • 若AWS需求不足，或公司产能未能按计划释放，双方似乎均不需要直接承担违约责任。
  • 该协议更接近意向性长期供货安排：
  1. AWS具备相应需求；
  2. 公司具备相应产能；
  3. 产品质量及认证满足要求；
  4. 在上述条件均满足时，AWS按计划采购。
  • AWS对交付要求较为严谨，但不会因单月或单季度交付不达预期立即追责，而是会与公司共同分析问题、确定解决方案。
  • 因此，长协提高了需求能见度，但不能完全等同于无条件、刚性的保底订单。

c) 4年最高约100亿的采购规模如何形成？

  • 该规模主要基于800G产品未来数年的出货增长测算。
  • 2027年预计800G出货约 350万—375万只，基本全部供应AWS。
  • 按当前扩产计划：
  1. 2028年末单季度出货目标约为160万只；
  2. 2029年产能可能提升至月度200万只；
  3. 随着后续年度产能和需求增长，4年累计采购规模明显高于2027年单年水平。
  • 2027年约15亿美元的800G收入并非在原有预期之外新增，而是此前基于AWS长协谈判形成的内部预测。

d) 最新长协是否超出公司此前预期？

  • 整体没有明显超预期。
  • 公司内部约在2026年10月已知晓与AWS推进长协，之前对2027年800G出货量的预测已经包含该合作。
  • 本次公告的主要意义是将此前内部已知的合作计划正式对外披露，而非突然新增一笔完全超预期的需求。
  • 相较之下，协议中涉及的激光器采购承诺更可能属于此前规划之外的增量。

2. 800G与1.6T出货、价格及客户变化

a) 2027年800G预计出货多少？收入是否可以视为保底？

  • 2027年800G预计出货 350万—375万只，全部供应AWS。
  • Oracle需求尚未取消时，公司曾预计800G可出货约500万只；Oracle砍单后，下调至目前的350万—375万只。
  • 按当前价格测算，2027年800G收入约 15亿美元，从目前需求和长协安排看，基本具备较高可实现性。
  • 但由于长协缺乏强制违约条款，该收入更适合视为高能见度目标，而非绝对刚性保底。

b) 2027年800G价格如何变化？

  • 北美市场2027年上半年价格预计仍接近当前水平，约 400美元/只。
  • 下半年及后续年度预计年降约5%，价格可能下降至 370—380美元/只附近。
  • 国内市场800G价格可能下降至300—320美元，但AWS等北美客户的价格预计相对更高。
  • 若产品在美国本土制造，客户可接受约 10%—20%溢价；台湾生产的产品则较难获得明显溢价。

c) 美国本土生产为何能够获得价格溢价？

  • 美国本土生产可满足客户的供应链安全、本土制造及合规要求。
  • 本土生产能够节省部分关税，并通过自动化降低部分人工成本。
  • 美国整体制造成本仍高于台湾和中国大陆，但客户愿意支付一定溢价，因此毛利率预计与其他地区生产基本相当。
  • 溢价主要由客户承担，政府补贴金额相对有限。美国一期项目此前获得的补贴约为数百万美元。

d) 2027年1.6T的价格和出货量如何？

  • 当前1.6T在手订单价格约 800美元/只。
  • 现有订单交付完成后，2027年新增订单价格预计下降至 700美元/只左右。
  • 2027年1.6T出货量预计超过 150万只，但达到200万只的可能性相对较低。
  • 主要判断依据：
  1. Oracle全年平均月度需求可能约为12万只，对应全年约140万—150万只；
  2. AWS后续也可能产生1.6T需求；
  3. 当前1.6T月产能仅约8万只，产能爬坡仍需要时间。
  • 2027年800G与1.6T合计出货预计约 500万—550万只。

e) Oracle、AWS和微软的产品需求发生了哪些变化？

  • AWS
  1. 目前是公司800G产品唯一主要客户；
  2. 2027年预计采购350万—375万只800G；
  3. 后续可能进一步导入1.6T、NPO及激光器产品。
  • Oracle
  1. 800G订单目前基本已全部取消；
  2. 后续可能在2027年一季度重新洽谈，但目前没有明确能见度；
  3. 仍有少量400G订单，单季度约数万只，但也可能取消；
  4. 战略方向已转向1.6T。
  • 微软
  1. 目前主要采购公司400G及以下产品；
  2. 暂未采用公司的800G和1.6T产品；
  3. 微软自身在高端光模块领域具备较强产品能力。

3. 产能爬坡、利用率及区域布局

a) 2027年800G季度出货节奏如何？

  • 2027年出货量预计逐月、逐季度增长：
  1. Q1：约70万只，主要由台湾工厂供货；
  2. Q2：约80多万只，台湾继续爬坡，宁波新增产线开始释放；
  3. Q3：超过100万只，宁波继续放量，美国工厂开始贡献增量；
  4. Q4：进一步增长，美国本土产能逐步提升。
  • 原为Oracle准备的部分宁波产能可能转给AWS，但目前尚未完全转换，原因是Oracle仍希望保留后续重新合作的可能性。

b) 2027年不同地区的生产占比如何？

  • 2027年生产基地排序预计为：
  1. 台湾占比最高；
  2. 宁波排名第二；
  3. 美国占比最低。
  • 美国本土2027年预计仅生产 20万—30多万只，占350万—375万只800G总量的比例较低。
  • 美国800G真正开始上量预计在2027年Q3，Q4可能开始导入少量1.6T产能。

c) 2027年产能利用率能达到多少？

  • 2027年800G与1.6T合计出货约500万—550万只。
  • 按产能线性爬坡测算，全年平均有效产能约600万只，对应产能利用率约 80%—90%。
  • 台湾、宁波和美国各基地在进入稳定生产后，主要产线利用率预计接近满负荷。
  • 2026年800G与1.6T合计出货仅约50万—60万只，因此当前产能利用率仍较低，2027年将出现显著改善。

d) 德州Sugar Land工厂的进展如何？

  • 德州项目整体延迟约7个月，但对实际量产的影响预计约为1个季度。
  • 延迟原因市场传闻与电力审批有关，但访谈中未得到明确确认。
  • 德州工厂预计到 2027年Q3 才能真正上量并贡献收入。
  • 800G需要重新送样认证，原因是德州与台湾属于不同生产基地，产线和管理团队均不同。
  • 德州产能规划：
  1. 一期月产能约3万只；
  2. 二期计划新增约18万只月产能；
  3. 三期已有规划，但具体产能尚未确定。
  • 全部扩建完成后，美国800G产能占比预计：
  1. 2028年前后约30%；
  2. 后续可能提升至40%—45%。

e) 2028年800G和1.6T产能如何规划？

  • 800G方面：
  1. 2028年Q1出货预计接近130万只；
  2. 后续每季度继续增加十几万只；
  3. 2028年全年出货预计约 550万—600万只；
  4. 到2028年Q4，单季度可能达到160万只，对应月度约55万只。
  • 1.6T方面：
  1. Oracle月产能可能达到约20万只；
  2. AWS在宁波和美国合计月产能可能达到10多万只；
  3. 两家客户合计月产能有机会达到约30万只；
  4. 对应年度出货能力约300万只。
  • 具体扩产节奏仍取决于2027年上半年客户需求、送样认证和订单兑现情况。

4. 扩产投入、融资压力与交付风险

a) 新增光模块产能需要多少资本开支？

  • 按月产10万只产能测算：
  1. 前端耦合设备投入约2亿元人民币；
  2. 1.6T测试设备投入接近2亿元；
  3. 加上其他设备及无尘室配套，设备投入至少约5亿元；
  4. 上述金额尚未完全包含基建成本。
  • 美国计划建设约20万只月产能，仅设备投入约10亿元人民币。
  • 加上基建后，美国项目整体投入预计低于20亿元人民币。
  • 若将台湾、宁波及美国的全部扩产计算在内，公司未来资本开支压力较大。

b) 公司为何持续进行ATM融资？

  • 当前800G和1.6T尚未大规模贡献收入，但扩产设备、厂房和原材料采购已产生大量现金支出。
  • 公司现阶段存在“前期支出大、收入释放慢”的资金错配。
  • 持续ATM融资的主要目的之一，就是支持激进的产能扩张。
  • 预计随着2027年800G和1.6T收入放量，资金压力将得到一定缓解。

c) 公司历史上是否发生过无法交付客户订单的情况？

  • 历史上至少出现过两类交付问题：
  1. 微软AOC产品曾因公司生产及物料问题无法完成交付；
  2. Oracle 400G FR/LR产品曾因EML芯片短缺无法交付，之后客户进行了砍单。
  • Oracle当时每月曾提供约5万只400G订单，但公司因EML供应不足未能兑现。
  • 历史问题主要来自关键物料供应，而非单纯设备产能不足。
  • 因此，未来扩产兑现不仅取决于设备建设，还取决于DSP、激光器、EML等关键物料保障和产品良率。

d) 目前DSP供应是否有保障？

  • 800G DSP供应相对有保障：
  1. 终端客户为AWS；
  2. 公司主要采用Marvell DSP；
  3. AWS通过分配机制协调供应。
  • 1.6T DSP仍相对紧张：
  1. 公司已向Broadcom支付部分定金并下达预订单；
  2. 也向Marvell下达了部分订单，但交期可能较差；
  3. 2027年上半年预计可保障月度约10万只；
  4. 下半年保障量可能提升至接近20万只。
  • 按Oracle月度需求10万—12万只测算，现有安排预计可覆盖2027年1.6T需求的50%以上。

5. 400G业务及产线切换能力

a) 扩充800G和1.6T是否会压缩400G产能？

  • 公司不会为扩充800G和1.6T而削减400G产能。
  • 400G是当前400G、800G和1.6T中出货量最大、生产运行最稳定的产品。
  • 原计划将400G月产能稳定在15万只左右，目前可能继续提升至20多万只，预计2027年Q1完成。
  • 届时400G单季度出货量约60万只，主要供应AWS。
  • 出货预测：
  1. 2027年约240万只；
  2. 2028年约270万只或略高。

b) 800G与1.6T产线能否互相切换？

  • 两类产品在光学耦合环节可以部分共用：
  1. 800G与1.6T均为8个光通道；
  2. 光引擎耦合设备可以切换；
  3. 耦合段不区分具体速率。
  • 电学和测试环节无法低成本自由切换：
  1. 800G单波电信号速率约100G；
  2. 1.6T单波电信号速率约200G；
  3. 后端电学设备基本需要全部更换。
  • 1.6T测试设备明显更贵，单台设备可能约250万元，而800G设备约60万元。
  • 公司可以将部分800G光学耦合产能用于1.6T，但不会轻易使用昂贵的1.6T测试设备生产800G。

6. 激光器、ELSFP与硅光路线

a) 长协中的激光器采购是否属于增量？

  • 激光器采购更可能是此前预期之外的新增需求。
  • 公司激光器分为：
  1. 低功率激光器，主要用于自有硅光模块；
  2. 高功率激光器，主要用于ELSFP及外置光源方案。
  • 此前公司并未规划向客户单独销售如此大规模的激光器，因此协议中的相关采购承诺具有一定增量意义。
  • 但目前AWS在ELSFP方面尚未送样，实际订单能见度仍不足，2028年能否兑现协议规模仍存在不确定性。

b) ELSFP的客户和产能规划如何？

  • ELSFP已向AMD、Marvell、Cisco、Arista和Dell送样。
  • 目前尚未向AWS送样，AWS与公司现阶段的合作主要集中在800G和NPO。
  • 2027年ELSFP预计率先供应AMD：
  1. 计划从2027年Q4开始爬坡；
  2. Q4出货达到约10万只具备可行性。
  • 2028年月产能规划约40万—50万只，激进情况下可能达到60万—68万只。
  • 由于2027年Q4才开始爬坡，2028年初难以立即满产，因此2028年全年出货达到500万只存在机会，但仍有一定挑战；600万只目前能见度不足。

c) 高功率和低功率激光器未来如何分配？

  • 到2028年，高功率激光器占全部激光器产能的比例可能约为30%。
  • 高功率产品主要用于ELSFP及潜在外部销售。
  • 低功率产品主要供公司自身800G、1.6T硅光模块使用。
  • 短期内低功率激光器对外销售的可能性较低：
  1. 公司当前自身仍存在缺口，并在外采；
  2. 市场上低功率激光器供应较多；
  3. 高功率产品的外部需求更有潜力。
  • 本轮扩产完成后，低功率70mW和100mW CW激光器理论月产能可接近500万—600万只，但当前良率低于20%，仍处于爬坡阶段。

d) 当前激光器产能和良率如何？

  • DFB激光器月产能约70万—80万只，主要用于微软100G产品。
  • CW光源当前实际月产能约20万—30万只，主要为低功率产品。
  • 高功率CW光源仍处于样品阶段，尚未形成大批量生产。
  • CW光源良率仍是主要瓶颈：
  1. 小批量阶段曾达到40%—50%；
  2. 放大生产后良率可能低于20%；
  3. 产能兑现高度依赖后续良率改善。

e) 公司未来是否会全面转向硅光模块？

  • 预计到2028年，公司光模块产品可能基本实现100%硅光。
  • 目前只有Oracle的400G FR和LR产品采用EML方案，且单季度仅有数万只。
  • 若Oracle后续取消相关400G产品，EML方案占比将接近于零。
  • 公司当前1.6T产品已使用自研CW激光器，早期则曾采购Lumentum高功率激光器。
  • 公司自研激光器的对标对象主要为Lumentum，低功率产品特性与住友相对接近；进度可能快于源杰，但Lumentum整体进展仍领先。

7. NPO业务及潜在行业需求

a) 公司在NPO领域参与哪些环节？

  • 公司可直接制造NPO光引擎并对外销售。
  • 参与环节包括：
  1. ELS IP；
  2. 调制器；
  3. 光引擎制造；
  4. 外置光源配套。
  • 公司目前不参与CPU封装或测试服务，CPU领域主要聚焦ELS IP。
  • 当前NPO方案主要采用外置光源，未来是否采用内置光源仍需评估功耗和散热问题。

b) NPO目前主要面向哪些客户？

  • 公司当前NPO项目仅面向AWS进行设计。
  • 尚处于设计阶段，尚未开始正式送样，产线和产能建设也未启动。
  • 若首版送样顺利，2027年实现约6万只光引擎产量并不困难。
  • 但若首版产品性能不达标、需要重新修改，2027年项目可能无法落地，因此当前能见度较低。

c) 如何看待行业NPO需求和市场传闻？

  • 访谈方尚未听说英伟达首批下达500万只NPO订单的消息，真实性有待进一步核实。
  • 据了解，旭创可能已获得约100万只NPO需求，客户可能为谷歌。
  • 公司进入NPO领域相对较晚，当前才开始设计，对行业总需求尚未形成明确预测。
  • 燧原、芯原等厂商已完成部分首样并开始交付，公司仍处于较早阶段。

8. 核心判断与主要风险

a) 本次AWS长协的核心意义是什么？

  • 明确了2027年800G需求的主要来源，提高了中期收入和产能利用率的可见度。
  • 350万—375万只800G出货基本属于此前内部预期，并非明显超预期增量。
  • 真正可能超预期的部分主要是激光器、ELSFP及后续1.6T合作。
  • 由于合同缺乏强制违约条款，最终兑现仍取决于客户需求、产品认证、良率和产能建设。

b) 公司未来两年的主要增长驱动是什么？

  1. AWS 800G订单在2027年集中放量；
  2. Oracle 1.6T进入规模交付阶段；
  3. 美国本土产能从2027年下半年开始贡献收入；
  4. 400G业务维持稳定增长；
  5. ELSFP从2027年Q4开始爬坡；
  6. 自研CW激光器逐步提高自供比例；
  7. NPO、AWS 1.6T及激光器外销构成潜在增量。

c) 主要风险有哪些？

  1. 长协约束力较弱，客户需求可能调整；
  2. 德州工厂延期及多基地重新认证风险；
  3. CW激光器良率低于20%，量产爬坡存在不确定性；
  4. 1.6T DSP等关键物料仍较紧张；
  5. 历史上曾因EML及其他物料短缺导致无法交付；
  6. 激进扩产带来较大资本开支和持续融资压力；
  7. AWS的ELSFP、NPO合作尚处早期，实际订单能见度有限；
  8. Oracle 800G已基本取消，客户集中度进一步上升。
