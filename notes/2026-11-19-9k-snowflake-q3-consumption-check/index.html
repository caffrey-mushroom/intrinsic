  • 客户愿意签订长期合同，是因为其预计Snowflake使用量将在未来数年持续增长。

e) 为什么Snowflake能获得更多多年期合同，而部分软件厂商的合同期限在缩短？

  1. 客户需要锁定未来价格，规避价格上涨风险。
  2. 客户对未来2-3年的使用量增长具有较高确定性。
  3. Snowflake已被纳入客户长期数据、AI及多云项目。
  4. 客户能够通过更长期的采购承诺，与Snowflake协商更优惠的价格。

  1. 今年整体IT预算承压，很多软件和硬件厂商难以获得多年期合同。

  4. Snowflake的核心数据平台定位、使用扩张确定性及多云能力，使客户更容易作出长期采购承诺。

f) 客户签订多年期合同，具体希望锁定什么价格？

  • 锁定价格也有助于提高下一年度及长期IT预算的可预测性。
  • 随着客户对未来工作负载和使用量的预测更加准确，长期锁价的吸引力进一步增强。

3. 客户长期使用Snowflake的原因及迁移节奏

a) 为什么客户认为Snowflake适合长期使用？

  • Snowflake客户留存率达到97%，客户黏性较强。
  • Snowflake的多云能力和中立平台定位符合大型企业的战略需求。
  • 客户一旦在组织内部围绕Snowflake形成标准化实践，迁移至其他平台的难度较高。
  • 大型客户已围绕Snowflake开展长期项目，并持续扩大工作负载。
  • 即使客户仅签订1年或2年合同，也很难在短期内完成平台替换。
  • 迁移至Databricks等平台还涉及重新谈判合同、重构流程及调整治理体系，转换成本较高。

b) 去年Q4或今年年初迁移至Snowflake的客户，2027年使用量是否可能放缓？

  • 预计不会放缓。
  • 客户迁移通常分阶段进行，不会在第1年立即停用所有原有工具。
  • 第1年主要完成初步迁移，并与原有供应商谈判退出合同。
  • 到第2年续签时，随着更多原有系统停用，Snowflake使用量将明显增加。
  • 因此，部分客户虽然进入合同第2年，但从实际扩张角度看，可能才进入真正的第1个增长年度。

c) Snowflake是否容易被AI实验室复制或逆向开发？

  • 访谈未直接讨论技术被复制或逆向开发的具体风险。
  • 回答重点强调，Snowflake的竞争壁垒主要体现在：
  1. 高客户留存率；
  2. 多云能力和中立定位；
  3. 客户内部标准化实践；
  4. 长期项目及合同关系；
  5. 数据治理和合规体系；
  6. 较高的平台迁移与替换成本。

4. 新增客户与现有客户的增长贡献

a) Snowflake使用量增长中，新客户与现有客户分别贡献多少？

  • 现有客户贡献
  1. 现有客户对整体收入或使用量的贡献约为75%-80%。
  2. 现有客户更加成熟，对平台扩张更有信心。
  3. 现有客户内部获得应用访问权限的用户更多，工作负载也更加丰富。
  • 新增客户贡献
  1. 净新增客户数量同比增长约30%，最高可能达到33%。
  2. 净新增客户对收入的贡献约为7%-10%，部分情况下可能达到12%。
  3. 新增客户增速高于受访者观察到的其他供应商，获客表现较强。
  • 新增客户的后续扩张
  1. 部分新增客户第1年增长较慢，主要进行基础迁移和部署。
  2. 到第2年，随着迁移及应用范围扩大，使用量通常会显著增长。
  3. 因此，当期新增客户还将为未来数年的扩张提供增量。

b) Snowflake新增客户主要来自哪些行业？

  • 客户通常为规模较大的全球性企业，行业覆盖较广，包括：
  1. 高科技；
  2. 制造业；
  3. 银行业；
  4. 保险业；
  5. 零售业；
  6. 油气及能源行业。
  • 高科技行业是Snowflake的传统优势领域，也是最早采用并扩大相关技术的行业。
  • Snowflake部分最大客户来自保险业和全球零售行业。
  • 传统行业虽然本地部署系统占比较高，但其多云使用量和云迁移需求正在明显增加。

c) 为什么油气等传统行业可能带来较长时间的增长？

  • 油气行业通常具有较强的Oracle系统基础，启动云迁移的时间晚于其他行业。
  • 其系统迁移和原有合同退出需要较长时间，因此合同第2年可能才进入实质扩张期。
  • 传统行业仍有大量本地系统和人工流程尚未现代化，未来迁移空间较大。
  • 类似的迁移滞后与后续扩张逻辑也存在于其他传统行业。

a) 制造业、零售业和能源行业主要如何应用AI？

  • 制造业主要应用场景
  1. 生产环节优化；
  2. 供应链效率提升；
  3. 需求和经营预测；
  4. 定价管理；
  5. 物流优化；
  6. 质量控制。
  • 传统行业整体应用方向
  1. 通过内部提效降低成本；
  2. 减少人工输入和重复性流程；
  3. 优化采购、供应链及物流；
  4. 改造产品和生产线；
  5. 推动企业整体数字化和现代化转型。
  • AI应用需要分阶段推进，企业还需同步建立治理框架并满足监管和合规要求。
  • 随着治理和合规体系逐步成熟，传统行业明年的AI采用速度预计会进一步加快。

b) 美国企业AI支出是否会在明年或2028年达到峰值？

  • 受访者认为，AI支出不会在明年或2028年达到峰值。
  • 2029年也预计不会出现明显放缓。
  • AI支出增速可能要到2030年以后才有机会放缓。
  • 主要判断依据包括：
  1. 当前企业只在供应链、质量控制、物流等部分环节完成初步改造；
  2. 产品、生产线及整体运营体系的全面转型仍需长期投入；
  3. 企业数据规模仍在持续增长；
  4. 高科技行业仍在推进大量重大项目；
  5. Snowflake掌握的项目储备和销售机会仍然强劲；
  6. 客户合同期限正在延长，部分客户已讨论5年或6年合同。

  2. 今年储备的大量客户机会将在明年1月至3月转化。

  • Q2
  1. Q2可能出现更加明确、显著的增长。

  • Q3

  2. 整体环比趋势预计逐季改善。

6. Cortex Code渗透率及增长贡献

a) Q3 Cortex Code在客户中的渗透情况如何？

  • 在采用Cortex Code的现有客户中，渗透率约为30%-40%。
  • 在新增客户中，约80%的客户正在使用Cortex Code。
  • 新增客户对Cortex Code的采用速度明显快于现有客户。

b) Cortex Code对Snowflake整体增长贡献了多少？

  • 现有客户和新增客户采用Cortex Code后，相关收入增长整体超过25%。
  • Cortex Code对Snowflake整体使用量增长的贡献难以精确拆分，因为大量现有和新增客户均在使用该产品。
  • 可以确认的是，Cortex Code对整体使用量增长的贡献超过10%-12%。
  • 访谈未披露Cortex Code消耗量占Snowflake总消耗量的精确比例。

c) 为什么难以准确拆分Cortex Code的增长贡献？

  • Cortex Code同时被大量现有客户和新增客户采用。
  • 其使用通常与数据库、AI、分析及其他Snowflake工作负载相结合。
  • Cortex Code既能直接产生使用量，也会间接推动传统数据库和其他产品的使用，因此难以进行完全独立的归因。

7. 其他产品增长动力与AI产品布局

a) 除Cortex Code外，哪些产品是Snowflake使用量增长的主要驱动力？

  • AI是Snowflake当前最主要的增长方向，市场进入策略基本围绕AI展开。

  1. Cortex Copilot；
  2. Cortex AI；
  3. Snowpark；
  4. SQL；
  5. 智能体相关产品及应用。

  • 大量智能体的部署正在持续推动客户使用量增长。

b) Snowflake如何通过产品组合推动客户扩张？

  • 对现有客户主要采用向上销售和交叉销售策略。
  • 新客户在首次采购时，往往会同时部署多款Snowflake产品。
  • AI产品能够带动数据库、计算、数据治理及开发工具等传统工作负载增长。
  • 整体产品组合表现强劲，但AI仍是最受重视的战略方向。

c) Cortex AI Gateway目前的客户采用情况如何？

  • 多家大型客户已在后台使用该产品，并参与产品开发反馈。
  • 大多数大型客户都以某种形式试用或部署过Cortex AI Gateway，市场兴趣较高。
  • 目前尚未完成对全面采用率、主要应用场景及客户反馈的系统分析。
  • 到明年Q1，Snowflake预计能够更清晰地评估：
  1. 产品采用情况；
  2. 对客户整体环境的影响；
  3. 带来的效率提升；
  4. 为客户创造的实际价值。
  • Snowflake最大型客户预计将率先全面部署，多数可能在明年Q1前完成。

d) AI路由和Copilot降低Token成本后，是否会推动更多消耗？

  • Token和任务执行成本下降后，企业会开展更多项目和任务。
  • 开发团队交付速度提升，产品上市周期缩短。
  • 客户环境中的开发项目、智能体数量和相关工作负载明显增加。
  • 客户对AI消耗具备更好的可见性和控制能力，进一步增强了扩张意愿。
  • 因此，单位成本下降并未压低整体消耗，反而推动AI使用总量加速增长。

8. Snowflake与Databricks的竞争格局

a) 企业客户最终是否只会选择Snowflake或Databricks中的一家？

  • 企业客户未必只会选择其中一家，两者适用于不同的数据和应用场景。
  • 大型企业可能根据结构化数据、非结构化数据、数据工程及AI需求，同时部署两类平台。
  • 两家公司虽然能力逐步接近，但各自仍具有明显优势领域。

b) Snowflake更适合哪些应用场景？

  • Snowflake更适合：
  1. 纯分析场景；
  2. 大型SQL环境；
  3. 高科技、金融和零售行业的大型客户；
  4. 高度依赖Tableau等商业智能工具的客户；
  5. 对数据治理、监管与合规要求较高的企业；
