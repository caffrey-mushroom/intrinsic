Q:Q3 AWS 的收入增长是多少，包括同比和环比增长率，是什么推动了这种增长？

A:总体来看，AWS 收入预计约为 462 亿美元，四舍五入约为 460 亿美元。这表示同比增长 39%。Amazon Bedrock 是增长最快的组成部分，产生了 43 亿美元，相当于环比增长 43%，几乎占 AWS 收入的 9%。

AWS 的增长从 17% 逐步推进到 20%、24%、28% 和 37%。具体的季度标注可能有混淆，但意图是说明增长在加速，驱动因素是 Amazon Bedrock 和 AI。另一个主要因素是在手订单：RPO 约为 4,960亿美元。Amazon Bedrock 的收入也出现了环比上升，从 7 月的 13.2 亿美元升至 8 月的 14.3 亿美元和 9 月的 15.6 亿美元。Q3 总收入为 43 亿美元，而 Q2 为 30 亿美元。

在 Q3 的 Amazon Bedrock 收入中，Claude 约占 66%，Amazon Nova 占 17%，开源开权（open-weight）模型占 15%，OpenAI 占 2%。这些数据仅适用于Q3，不适用于年初至今（YTD）期间。

Q:从 Q2 到 Q3，模型分布发生了怎样的变化？Anthropic 在 Amazon Bedrock 收入中的占比是否变大，Amazon Nova 是否获得了份额，或者不同模型之间的趋势是什么？

A:在 Q3，Anthropic 占 66%，Amazon Nova 占 17%，开源开权模型占 15%，OpenAI 占 2%。开源开权类别包括 DeepSeek、GLM、Qwen、Kimi 和 MiniMax。开源开权的收入为 6.5亿美元。其中，五个中国模型占 3.5 亿美元，而 Llama、Mistral 和其他模型占 3.0 亿美元。

Claude 的份额从 Q2 的 68% 下降到 Q3 的 66%，而 Amazon Nova 从 20% 下降到 17%。开源开权模型从 12% 增至 15%。OpenAI 从 0.7%（或不到 1%）上升到2%。因此，开源开权模型是最大的增长杠杆。中国模型录得最强的环比份额增长，而 Claude 和 Amazon Nova 失去份额，OpenAI 则从非常小的基数大约翻了一番。

Q:谁在使用开源开权模型和 Amazon Nova？Amazon Nova 的份额似乎在下降，Anthropic 的份额相对稳定，而 OpenAI 在从很小的基数增长。为什么 Amazon Nova 在下降，为什么开源开权模型在增长，哪些客户在推动它们的使用？

A:Amazon Nova 2 Lite 被用于客户服务聊天机器人、文档处理和业务流程自动化。这些是企业后端的用例，主要出现在大型企业的医疗、金融服务和部分制造业领域。就 Q3 而言，Amazon Nova 的拆分为 11% 图像和 8%视频，涉及 Canvas 和 Reel。这些产品在媒体公司中的使用更为普遍。

开源开权模型环比增长约 82%，有四个主要原因。首先，它们在价格-性能上具有显著优势：一些更大的开源开权模型现在在 API 成本的一小部分下匹配专有前沿系统的性能。AI的一大挑战是许多项目仍停留在概念验证阶段，因为公司无法以经济可行的方式在生产中部署它们。更低的成本使得生产部署更为可行。

第二，编码和 agent 工作负载产生大量 token。agent 流程每个任务可能使用 50 到 100 倍的 token。GLM 4.7 和 MiniMax 2.1 旨在进行自主编码并产生非常大的输出，因此编码需求和 token量是中国模型表现良好的重要原因。第三，AWS 减少了获取和使用这些模型的摩擦：想要特定模型的客户可以通过 AWS 访问该模型，而 AWS 不会干预模型选择。

第四，开源开权模型提供定制化能力。客户可以在 AWS 内部将 Kimi 等模型进行微调并保留其数据。许多来自拉美和亚太地区的客户会为本地需求调整这些模型。使用 Amazon Bedrock还有助于解决数据可能被转移到中国的担忧。中国的开源开权模型公司若希望进一步提升采用率，可以通过雇佣能够直接与 AWS 和 Azure 对接并发展客户关系的人员来改进，因为剩余的一些障碍与文化和商业接触相关。

Q:关于第三点，AWS "不干涉" 的意思是什么？你能更详细地解释吗？

A:以前，在 AWS 上运行开源开权模型需要大量工程工作，包括租用 GPU、搭建服务器和重写代码。AWS 现在通过一个即插即用的 API 提供同一模型，将实现时间从数周缩短到数小时。客户不再需要租用 GPU、搭建服务器或重写部署代码。

最大改变涉及托管。该服务现在是完全托管且无服务器的：客户调用 API 即可，无需预置 GPU 或管理机器学习基础设施。此前，他们必须在 Amazon SageMaker 或 Amazon EC2 上自行托管、预留GPU、部署模型并扩展系统。新方法显著更简便，摩擦也远小得多。

Q:对于中国模型，你有收入或 token 消耗的数据吗？在 AWS 上增长最快的是 Kimi、DeepSeek 还是其它模型？

A:这五个模型都在增长。Kimi 增长最快，其次是 MiniMax 和 GLM。DeepSeek 仍然是收入最大的模型，但增长最慢并且在失去份额。

DeepSeek 在 7 月产生了 3300 万美元，8 月为 3900 万美元，9 月为 4500 万美元，Q3 总计 1.17 亿美元。其 7 月到 9 月的增长为 36%。GLM 在相应月份产生了 2100 万美元、2700 万美元和3200 万美元，总计 8000 万美元，增长为 52%。

Qwen 在 7 月产生了 2000 万美元，8 月 2400 万美元，9 月 2800 万美元，Q3 总计 7200 万美元，环比增长 40%。Kimi 在 7 月产生 1200 万美元，8 月 1600 万美元，9 月 2100万美元，总计 4900 万美元。数据显示其从 Q2 到 Q3 增长了 75%。Kimi 增长最快，但基数较小。

MiniMax 在 7 月产生 900 万美元，8 月 1200 万美元，9 月 1400 万美元，总计 3500 万美元。其增长率为 56%。Kimi 和 MiniMax 是增长最快的模型之一，但两者的基数都较小。

Q:Q3 的 AWS 增长集中度如何？同比收入增长中有多少来自前五或前十大客户，增长是由几家大公司推动还是由更广泛的客户基础推动？

A:前十大客户对 Amazon Bedrock 同比增长的贡献约为 40%。更准确地说，其贡献约为 40% 至 42%。

未提供具名客户名单。基于 AWS 更广泛的客户基础，该群体可能包括媒体和金融公司，例如 Netflix 和 Apple 只作为示例性可能性，而不是确认属于前十大中的成员。可用信息表明，最大客户包括以 AI 为本的应用公司以及编码和agent 平台，但并未提供确定的名单。OpenRouter、Salesforce、Perplexity、Intuit 等是可能的例子，但没有数据证明它们确实位于十大客户之中。

Q:能否将 Q3 的 AWS 收入在 AI 和非 AI 工作负载之间进行拆分？在 AI 收入中，有多少来自训练，多少来自推理？

A:在 Q3，AI 大约占 AWS 收入的 16%，非 AI 工作负载占 84%。在 AI 收入中，约 69% 来自推理。四舍五入后，大约三分之二来自推理，三分之一来自训练。相应的美元金额可以基于总 AWS 收入约 460 亿美元来计算。

按收入来源划分，Amazon Bedrock 完全为推理（100% 推理）。Anthropic 的计算或 IaaS 大约 60% 是推理；OpenAI 大约 40% 是推理；Amazon SageMaker 大约 50% 是推理。

Q:在 Q3 末，有多少 AWS 容量可供客户使用，在 Q4 预计将新增多少容量？

A:截至2026年第三季度末，AWS的已装机电力容量约为21吉瓦，较2025年末的16吉瓦增长。几乎没有未出售的容量；大约有3%仍未售出，这意味着容量基本上已全部承诺。

对于2026年第四季度，AWS预计将新增约2.1到2.15吉瓦，四舍五入约为2吉瓦。最初称这将使AWS在2027年底达到23吉瓦的说法不正确。更正后的数字是到2026年底大约23吉瓦。因此，容量在2026年内从16吉瓦增加到23吉瓦，增长了7吉瓦。

2027年的估算为31吉瓦，意味着较2026年23吉瓦水平再增长约8吉瓦。然而，2027年的数字尚未完全核实，需要进一步验证。因此估算的进程是2025年16吉瓦、2026年23吉瓦，并可能在2027年达到31吉瓦。

Q:亚马逊在2026年和2027年的预期资本支出是多少？

A:对于2026财年，估算为2220亿美元，四舍五入约为2200亿美元。高支出的一个主要原因是内存、SSD和HDD价格上涨。大部分支出与AWS和生成式AI相关。第三季度的CapEx运行率大约为570亿到600亿美元。第四季度大约为625亿到648亿美元，或大致在600亿到650亿美元之间。

2026年的主要估算为2200亿美元，尽管可能达到2300亿美元。这些数字并非基于准确的CFO数据，因此应将2026年的估算视为大约2200亿到2300亿美元的范围。

将8吉瓦乘以假定的每吉瓦300亿美元的简化计算并不能直接映射到年度CapEx。支出可能发生在某一年，而相应的产能在后一年投产。折旧、通胀、定价和其他因素也会影响两者关系。因此，在某一年购买产能或在账面上记录CapEx并不等同于同年该产能就会投产。

Q:亚马逊在2027年会将资本支出提高多少，以及期望这些投资带来怎样的回报？

A:2027年的中心CapEx估算约为2900亿美元。这将相对于以2026年约2200亿到2300亿美元为基数的大约增加28%。更宽泛的估计区间为2840亿到3150亿美元。没有确切的CFO数据，不同系统得出不同数字，因此这些数值应视为估算而非精确金额。

更广的组织背景是，亚马逊在减少员工人数的同时增加基础设施支出，将更多资金投入到芯片和产能上。未提供单独的投资回报率数值估算。

Q:在2026年第四季度和2027年新增的产能中，NVIDIA GPU和AWS Trainium的占比如何？

A:在2026年第四季度，预计将新增约1.5吉瓦的AI产能。分配大约为55% AWS Trainium和45% NVIDIA。

对于2027年，预计将新增约7.3吉瓦的AI产能，分配大约为60% AWS Trainium和40% NVIDIA。这意味着大约4.4到4.5吉瓦的AWS Trainium产能。然而按美元计，分配将更接近50:50，因为NVIDIA系统每吉瓦的成本约为AWS Trainium的1.5倍。

Q:你预计裁员趋势会在2027年和2028年继续吗？

A:我认为这一趋势会继续。公司似乎在使用各种理由减少员工数，同时替换的招聘可能成本约低30%。

尚不清楚该趋势会持续多久。一个担忧是更优秀的员工可能会离开，导致留下的员工队伍变弱。俗话说，A级员工带来A级员工，而B级员工带来C级员工。

Q:在第三季度，AWS的营业收入和营业利润率是多少？考虑到增加的资本支出、折旧和裁员，预计2026年和2027年的营业利润率是多少？

A:在第三季度，AWS的营业利润率约为37.4%。更安全的估计范围是37%到39%。营业收入约为173亿美元，营收大约为460亿美元。

对于2027年，预计的营业利润率范围大约为35%到37%。由CapEx激增带来的折旧可能使利润率降低约三个百分点。GPU价格上涨和相关溢价将带来额外压力。

Q:对于可比的生产工作负载，AWS Trainium相比NVIDIA为客户节省多少费用？对AWS的利润率有何影响？

A:对于可比工作负载，AWS Trainium方案在每单位产出上比AWS上的NVIDIA方案便宜约40%到50%。相对于较旧的NVIDIA H100和NVIDIA H200实例，差距最大。相对于NVIDIA GB300 Blackwell，差距较小：AWS Trainium大约便宜35%，而相对于NVIDIA H100和H200大约便宜50%。其中大部分使用来自像Anthropic这样的大客户，其工作负载为AWS Trainium进行了优化。

AWS在AWS Trainium上的利润率约高出十个百分点，上下约半个百分点。因此AWS Trainium起到了利润保护器的作用。如果没有它，2027年的折旧上升可能会将AWS的利润率推向约32%，而不是大约35%。AWS在每吉瓦的收入上有所放弃，因为AWS Trainium每吉瓦产生的收入低于NVIDIA，但它改善了盈利能力和自由现金流。

Q:哪些工作负载在AWS Trainium上运行？训练和推理的占比分别是多少？

A:大约60%的已装AWS Trainium产能运行推理工作负载，40%运行训练工作负载。推理份额正在增长，并可能在2027年达到70%。许多原生AI客户直接租用产能，Anthropic是主要客户。主要工作负载类别为LLM推理、前沿模型预训练，以及强化学习和后训练工作负载。

Anthropic在大型集群上使用AWS Trainium进行前沿模型预训练和强化学习后训练。亚马逊则将其用于Amazon Nova和前沿模型训练、Alexa、Rufus和广告工作负载。推理份额上升是因为生产部署在增加。许多项目已经超越概念验证阶段，推理的增长速度快于训练。Amazon Bedrock环比增长43%，而AWS Trainium的每token成本大约可以是NVIDIA H200的一半。

训练工作负载预计会迁移到更新的芯片，大型训练任务将在2027年末迁移到AWS Trainium 4集群，尽管没有确切日期。较旧的AWS Trainium 2集群将被改作推理使用。预计2027年的构成大约为70%推理和30%训练。

Q:在AWS与Anthropic和OpenAI的合作方面有什么最新进展？

A:Anthropic仍然是AWS的AI锚定租户，即一个主要锚定客户。该安排覆盖最多5吉瓦以及十年内超过1000亿美元。附注中的营收数字约为168亿美元。计算协议覆盖最多5吉瓦的新产能及AWS Trainium 2到AWS Trainium 4。双方关系依然稳固。

附注还显示Anthropic的营收为168亿美元，并指出其增长正在从147%放缓到45%。最初称增长在加速的说法已更正为在放缓。

OpenAI正在成为第二个锚定客户，但规模仍小，约占Amazon Bedrock营收的2%。自6月以来已进入一般可用状态。在微软对新GPT模型的独家权结束后，AWS开始寻求与OpenAI建立更大势头。与Anthropic相比，OpenAI在企业销售方面仍不够成熟。

大型企业为AI分配了可观预算，但常常不确定该构建哪些应用。有些企业实际上可能有10亿美元可用，但仍在寻求如何部署的指导。AWS的官方立场是支持多模型并让客户选择，但在实际操作中，Anthropic仍然是AWS的主要模型合作伙伴。

Q:AWS在开放权重模型上的利润率是更高还是更低？对于Anthropic，AWS的分成大约占客户收入的8%到10%吗？

A:AWS在开放权重模型上的营业利润率约为45%。Anthropic对应的数字约为41.2%，因此开放权重模型的利润率略高一些。

据描述，Anthropic还产生了约3.5个百分点的营业利润，这部分利润是以多年合约的形式签订的。AWS并非简单地选择开放权重模型而放弃Claude。Claude有助于赢得客户，而开放权重模型有助于客户在采用后管控成本。Anthropic长期合约锁定的利润和其在获取客户方面的作用，解释了为什么即便开放权重模型能带来更高的利润率，AWS仍然继续支持Anthropic。

Q:企业级AI是否正在从概念验证向生产环境转变？这一过渡的主要驱动因素和瓶颈是什么？

A:是的。企业级AI正在从概念验证向生产化转变。生成式AI助手和编码代理已经在生产规模运行，尽管自治代理仍主要处于试点阶段。主要瓶颈是集成、可观测性、治理和成本——而不是模型质量。

可观测性是一个特别重要的瓶颈，这也是为什么像Datadog这样的公司在推出具代理能力的AI和LLM可观测性产品时可能表现良好。如果一个客户在云服务上花费1亿美元，约20%到25%可能会分配给可观测性。企业在衡量代理行为和结果方面仍然存在困难。

德勤的一条数据表明，38%在试点代理，11%在生产中部署了代理。其他证据包括AWS的AI运行率超过250亿美元并以三位数速度增长、Amazon Bedrock在六个月内新增客户、Anthropic收入上升，以及像Claude Code和Codex这样的编码代理表现强劲。这些数据点表明正在发生生产端采用。治理、安全、可观测性以及无法衡量结果仍然是主要制约因素。

Q:截至六月底和九月底，Amazon Bedrock的客户数是多少？如果可能，能否也提供其他期末数据，以便估算每位客户的平均支出并将增长区分为客户增加和单客户支出上升？

A:截至2026年3月底，Amazon Bedrock约有128,000名客户。到6月底，约有195,000名客户；最初的20万的数字已更正为19.5万。

到8月底，Amazon Bedrock约有225,000到230,000名客户。到9月底，约有245,000到255,000名客户。

Q:Amazon Bedrock业务是否存在季节性？

A:没有明显的季节性。Amazon Bedrock还太年轻——于2023年末才开始全面可用——且增长速度太快，尚未形成清晰的日历模式。增长主要由模型发布和生产部署驱动，而非季节性。存在轻微模式，包括工作日与周末差异、夏季放缓以及年终预算周期，但这些尚不足以确立明确的季节性趋势。

Q:有传闻称电力短缺阻止了AWS按预期增加那么多千兆瓦容量。是否属实，即AWS可能有可用芯片但因无法获得足够电力而无法将其投入运行？

A:这是真的，或至少在某种程度上是真的。AWS正在以前所未有的速度扩充算力，但增长速度仍赶不上需求增长。需求超过可用容量，而电力是最大的制约因素。其他瓶颈包括芯片、内存和劳动力，但电力远为最重要。

美国的电力部门监管非常广泛。增加电力供应需要与公用事业公司及NRC、FERC等机构协调。额外电力无法立即获得，因为该过程耗时多年。本来可能需要十年的项目，或许可缩短到四年，但电力可得性仍是一个重大问题。

公共政策上也存在对数据中心的抵制。一些社区反对在其区域内发展数据中心，形成了另一个约束。因此，即便芯片可用，电网容量、许可、监管、公用设施建设周期和地方反对都可能延迟算力上线。
