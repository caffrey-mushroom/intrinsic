专家访谈纪要

1. 表后供电技术路线与方案排序

a) 如果不考虑供应限制，各类表后供电方案的优先级如何排序？

  • 当前技术路线的优先顺序为：
  1. 开式循环燃气轮机（OCGT）
  2. 往复式内燃机
  3. 固体氧化物燃料电池（SOFC）
  4. 联合循环燃气轮机（CCGT），主要作为补充方案
  • 2026年至2027年上半年，当前考虑的方案占比大致为：
  1. OCGT约40%
  2. 往复式内燃机约20%至23%
  3. SOFC约12%至13%
  4. CCGT作为补充，未给出明确占比
  • 上述结构是现阶段判断，后续可能随着供应能力、许可要求及项目区域变化而调整。

b) 决定不同项目供电技术选择的核心变量有哪些？

  • 技术偏好会因芯片类型和项目所在地区而变化，但最大的决定性因素是项目容量及相关约束。
  • 主要评估参数包括：
  1. 电力容量与项目负荷需求
  2. 数据中心园区规模
  3. 公用事业并网时间
  4. 土地可用性及单位容量占地
  5. 水资源可用性
  6. 空气排放及许可要求
  7. 设备交付周期与实现供电的时间
  8. 燃料效率
  9. 项目部署所需的配套生态系统
  • 由于当前多个地区的项目面临许可审批问题，排放、土地、水资源和供电时效的重要性明显提升。

c) 数据中心用于训练还是推理，会影响供电方案选择吗？

  • 训练或推理并不是独立的关键决策因素。
  • 两者的差异最终主要体现在容量需求上，供电技术选择仍取决于总体负荷规模、供电时效和区域限制。
  • 因此，训练或推理只能作为整体评估中的细分因素，不能单独决定采用燃气轮机、往复式内燃机还是SOFC。

2. SOFC的适用场景与区域偏好

a) 在哪些情况下，SOFC会成为第1或第2选择？

  • 当项目面临严格的空气排放要求、土地紧张、并网受限以及较短供电时间窗口时，SOFC的优先级会显著提升。
  • 将SOFC列为首选方案的主要依据包括：
  1. 空气排放许可更容易满足
  2. 单位容量占地相对较小
  3. 可更快满足项目供电时效要求
  4. 燃料效率较高
  5. 用水和噪声等外部影响相对可控
  • 当前燃气轮机交付周期已经明显拉长，也进一步提升了SOFC在部分项目中的吸引力。

b) 为什么北弗吉尼亚是SOFC最具优势的区域之一？

  • 北弗吉尼亚IAD地区是美国最大的数据中心集群之一，也是AWS在美国数据中心项目最集中的区域。
  • 尤其在劳登县等部分县，SOFC近期可被列为第1选择，主要原因包括：
  1. 当地空气排放许可要求明确且严格
  2. 可用土地非常有限
  3. 公用事业并网存在限制
  4. 项目要求在较短时间内实现供电
  5. 燃气轮机交付周期较长
  • 在其他县，往复式内燃机等方案仍会被纳入考虑，但在限制最严格的县，SOFC与当地项目要求的匹配度更高。

c) 北弗吉尼亚是否是唯一面临空气许可问题的区域？

  • 不是。空气排放及许可问题在全美多个地区都受到关注，但具体要求更多由各州和地方政府管理，而非完全由联邦法律统一规定。
  • 区域偏好存在明显差异：
  1. 北弗吉尼亚：空气排放许可、土地和并网时效是核心约束，SOFC优先级较高
  2. 加利福尼亚州：SOFC也可能是首选方案
  3. 俄勒冈州：曾考虑或采用SOFC，但后续未继续推进
  4. 亚利桑那州：关注点更偏向用水问题
  5. 得克萨斯州：同时面临用水、噪声、电价、空气质量和政治阻力
  • 空气许可不能孤立评估；只有当其导致项目无法获批或明显延误时，才会成为压倒其他参数的首要因素。

3. 公用事业供电与表后供电的结构

a) 当前数据中心的主要供电来源如何分布？

  • 公用事业公司的表前供电仍是美国数据中心的主要供电方式。
  • 当前大致结构为：
  1. 公用事业供电约占80%
  2. 表后供电约占20%
  • 这一比例不仅适用于北弗吉尼亚，也大致适用于全美数据中心项目。
  • 北弗吉尼亚的主要公用事业供应方包括Dominion等公司。

b) 表后供电内部，各类技术方案的占比是否均衡？

  • 各类表后供电方案的占比并不完全均衡。
  • 如果只比较往复式内燃机与SOFC，两者的占比相对接近。
  • 具体选择更多取决于不同客户及具体项目要求，而不能简单按地区统一划分。
  • 燃气轮机仍是整体表后供电中的第一选择，SOFC则在排放、土地及供电时效受限的特定区域占据更高份额。

c) 未来5年是否会明显降低对公用事业公司的依赖？

  • 即使在未来5年的战略规划中，预计仍有约80%的电力需求由公用事业公司满足。
  • 公司仍在与Dominion等公用事业公司协商长期供电协议，并评估PJM、ERCOT等区域的电力供应和容量预留要求。
  • 尽管Dominion当前不具备项目所需的全部容量，但长期仍可通过协商补充未来电力需求。
  • 表后供电是对公用事业供电的重要补充，而非短期内完全替代公用事业供电。
  • 表后供电规划具有长期属性，包括：
  1. 逐步推进垂直整合
  2. 与天然气供应商签订长期合同
  3. 提前锁定关键设备与燃料资源
  4. 根据不同区域的电力市场规则进行容量配置

4. Bloom与SOFC采购潜力

a) Bloom产能不足是否是限制亚马逊采购的主要原因？

  • 产能限制确实是一个因素，但不是唯一因素。
  • 不仅Bloom面临产能限制，燃气轮机等其他设备供应商同样存在供应和交付周期压力。
  • 在燃气轮机采购中，可以通过多家供应商实现多元化；但在燃料电池领域，Bloom是最容易被首先考虑的美国本土供应商。
  • 其他新兴SOFC供应商多数来自美国以外，因此本土供应能力和供应链安全是Bloom的相对优势。
  • 除产能外，采购方还会综合评估：
  1. 初始资本支出
  2. 实现供电所需时间
  3. 设备交付周期
  4. 土地可用性及占地面积
  5. 用水量
  6. 空气排放
  7. 部署所需配套生态系统

b) 如果Bloom不存在产能限制，采购份额可能提高多少？

  • 根据当前评估、讨论及对Bloom产能规划的判断，其采购份额可能提高7%至10%。
  • 该比例最高不会超过10%。
  • 需要特别明确的是：
  1. 7%至10%指表后供电总采购或总支出中的份额
  2. 并非全部电力采购或全部电力需求中的份额
  • Bloom当前实际份额可能接近0，但公司并未排除未来将其纳入供应商体系。

c) 能否据此推算Bloom到2030年获得1吉瓦订单？

  • 不能直接按照“总电力部署规模×10%”进行推算。
  • 原因是约80%的长期电力需求仍预计由公用事业公司满足，只有约20%属于表后供电范围。
  • Bloom潜在的最高10%份额，是在表后供电采购范围内计算，而不是在全部电力需求中计算。
  • 因此，即使2030年每年部署10吉瓦，也不能直接推导Bloom可获得1吉瓦订单。

5. 价格比较与长期采购策略

a) 如何评估Bloom的成本和报价？

  • 不会孤立地评估Bloom的价格，而是按每千瓦资本支出与其他技术路线进行横向比较。
  • 主要对比对象包括：
  1. 燃气轮机
  2. 往复式内燃机
  3. 其他SOFC或分布式供电供应商
  4. BorgWarner、TurboCell等寻求差异化的市场参与者
  • Bloom自身降价或涨价并不是最关键的判断依据，核心是相同价格能够获得何种设备性能、交付周期及综合项目价值。

b) Bloom当前报价是否较2024年有所下降？

  • 与2024年获得的书面报价相比，Bloom目前确实降低了价格。
  • 去年双方接洽并不积极，今年才重新展开较深入讨论。
  • 但Bloom降价本身不足以决定采购，仍需比较其他供应商同期价格以及不同技术方案的全生命周期成本。

c) 为什么燃气轮机长期价格可能仍低于Bloom？

  • 燃气轮机市场拥有多家供应商，采购方具备更强的议价能力。
  • 采购方可以签订3至4年甚至5至6年的长期协议，并在合同中设置：
  1. 价格调整条款
  2. 采购数量调整条款
  3. 长期供货保障
  4. 交付节奏安排
  • 即使燃气轮机短期价格上涨，通过长期协议谈判，其长期综合价格仍可能低于Bloom。
  • 公司通常不会以短期现货或短周期协议作为主要采购方式，而是更重视长期价格锁定和供应保障。

6. 社区阻力及对项目进度的影响

a) 美国数据中心面临的社区抵制是否被媒体夸大？

  • 媒体整体上存在夸大倾向，但部分地区的社区阻力确实非常强烈。
  • 社区主要关注的问题包括：
  1. 土地使用
  2. 数据中心噪声
  3. 用水量
  4. 公用事业费用及居民电价上涨
  5. 空气质量下降
  6. 对当地基础设施的压力
  • 全美不同地区的情况差异明显，不能将个别热点地区的问题推广至所有数据中心项目。

b) 大约有多少美国数据中心会受到社区抵制影响？

  • 当前美国数据中心构成大致为：
  1. 云数据中心占70%至75%，目前以改造为主
  2. AI数据中心占25%至30%，主要是过去几年建成或正在扩建的新项目
  • 当前社区抵制主要针对正在建设或扩建的AI数据中心。
  • 在约25%至30%的AI数据中心中，估计约40%会受到社区阻力影响。
  • 折算到全部数据中心，实际受影响比例约为10%至12%，可概括为10%至20%的范围。
  • 因此，直接认为20%的所有数据中心都会受到严重影响，可能略偏高。

c) 社区抵制会导致项目取消还是仅导致延迟？

  • 规划中的部分数据中心项目确实已经出现延迟，但通常不会被完全取消。
  • 公司主要通过协商和信息披露推进项目，包括：
  1. 发布项目用水量说明
  2. 解释项目如何改善当地公用事业基础设施
  3. 说明数据中心带来的就业机会
  4. 调整噪声、排放及用水方案
  5. 与居民、承包商及地方政府持续沟通
  • 部分项目可能只延迟数月，但阻力较大的区域需要更长时间解决。
  • 是否需要采用SOFC等低排放、低噪声方案，要根据当地具体诉求和许可要求决定。

d) 哪些地区面临的阻力最大？

  • 北弗吉尼亚IAD地区
  1. 尤其是劳登县，许可审批面临较大阻力
  2. 即使企业长期在当地经营、拥有良好商业关系和承包商网络，也仍然遇到许可问题
  3. 核心约束包括空气排放、土地和供电时效
  • 得克萨斯州
  1. 被视为下一个阻力较强的新兴热点
  2. 阻力不仅来自当地居民，也涉及较强的政治敏感性
  3. 主要争议包括用水、噪声、居民电费上涨及空气质量
  4. 部分项目选址争议较大，需要较长时间协商，项目计划仍在延迟
  • 加利福尼亚州和亚利桑那州
  1. 关注点更多集中在用水问题
  2. 加利福尼亚州因排放和资源约束，对SOFC的接受度相对较高
  • 俄亥俄州和佐治亚州
  1. 当前面临的社区阻力相对较小
  2. 项目推进环境相对友好

提问者：据了解，您曾与这些公司接触并评估过其产品。如果不考虑供应限制，您会如何对这些表后供电解决方案进行排序？目前的选择包括Bloom、X主要采用的往复式内燃机，以及表后燃气轮机。您会如何排列优先顺序？

回答者：燃气轮机仍是首选，具体而言是开式循环燃气轮机（OCGT）；其次是往复式内燃机，然后是固体氧化物燃料电池（SOFC），最后是联合循环燃气轮机（CCGT），后者可作为补充方案。

从目前考虑的方案占比来看，OCGT约为40%，往复式内燃机约为20%至22%至23%，SOFC约为12%至13%。如果讨论2026年及2027年上半年，整体情况大致如此。后续可能会发生变化，但目前的情况就是这样。

提问者：这些技术偏好是否会因集群用途、芯片类型以及所在州而有所不同，例如位于犹他州或得克萨斯州？不同重要变量会如何影响技术偏好？

回答者：这些偏好确实会发生变化，尤其会受到芯片类型和地区的影响。评估不同可选方案时，主要考虑的参数包括容量情况、园区规模、公用事业并网时间、土地可用性、水资源可用性以及排放要求。

这些因素目前变得更加重要，主要原因是项目在许可审批方面正面临一些问题。

专家：这是最大的决定性参数。

分析师：这一点非常清楚。听起来，无论数据中心用于训练还是推理，都不会影响电力供应方案，对吗？

专家：这主要与容量相关。训练或推理并不是孤立的决定因素，只是整体考量中的一个细分因素，并非关键因素。

分析师：在什么情况下，您会将SOFC燃料电池作为首选？例如，在水资源紧张的社区或规模较小的园区中，SOFC是否更具优势？在哪些场景下，SOFC会明确成为第1或至少第2选择？

专家：我之前提到过排放要求。在某些地区，我会明确将SOFC列为第1选择，特别是ID地区，也就是北弗吉尼亚。在这里，相较于燃气轮机，我们更倾向于采用SOFC，尤其是在劳登县等部分县。

这些地区对排放要求有非常明确且严格的规定，同时留给项目实现供电的时间较短，因此供电时效也非常重要。此外，燃料效率等因素同样具有决定性作用。

具体而言，将SOFC列为该地区第1选择主要基于以下因素。首先是空气排放许可，这是评估该地区不同方案时的首要考虑。其次是土地可用性，当地可用土地非常有限。再次是供电时效，我们会据此评估不同方案。

目前，燃气轮机的交付周期已经很长。综合这些因素，从近期来看，在ID地区，特别是部分县，SOFC是第1选择。其他县也会将RECEP纳入考虑，但在部分县，我们会优先采用SOFC，因为它更符合当地的各项要求。

专家：尤其是在并网限制和供电时间方面，IAD是我们拥有大量数据中心项目的区域，也是AWS在美国数据中心项目最集中的区域，因此采用这种方式更为合理。

分析师：您的意思是，北弗吉尼亚是特别适合采用SOFC的区域。该地区是唯一面临严重空气许可问题的区域吗？从媒体报道来看，这似乎是一个遍及各地的广泛问题。

专家：我特别指出IAD，是因为它是最大的数据中心集群。我们评估不同的表后供电方案时，通常会首先考虑IAD，然后再考虑其他区域。

您说得对，空气相关因素在美国各地都受到关注。但这类要求并非主要由联邦法律规定，而更多由各州法律管理。例如，在加利福尼亚州，我认为SOFC是首选方案。我们也曾在俄勒冈州采用这一方案，但后来没有继续推进。

因此，不能孤立地考虑单一因素。但当我们无法获得许可时，这一因素的重要性就会提升。如果许可问题确实导致项目进度延迟，我们就会比其他参数更重视这一因素。

分析师：以北弗吉尼亚为例，就您的项目或整个区域而言，不同供电类型的市场份额大致如何？我认为目前电网供电仍占多数，而在表后供电方案中，SOFC的占比应该较高。

专家：是的。公用事业公司的表前供电仍是我们在全美国的主要供电方式，不仅限于北弗吉尼亚。目前，我认为主要供电约占70%至80%，更准确地说可能是80%；表后供电约占20%。

在表后供电方案内部，我们会进一步划分不同类别，决定在某些项目中优先采用SOFC，在另一些项目中优先采用燃气轮机或往复式发动机。我们仍会综合考虑这些方案。

专家：公用事业公司作为主要电力供应方，例如北弗吉尼亚州的 Dominion。

分析师：明白。目前约有 20% 的电力来自表后供电，其中 SOFC、往复式发动机和其他方案的占比似乎较为均衡，是这样吗？

专家：不能说各类方案的占比都非常均衡。如果只比较往复式发动机与 SOFC，我认为两者的占比较为均衡，具体情况取决于不同客户，而非不同地区。

分析师：据了解，亚马逊目前并不是 Bloom 的大客户。但 Bloom 表示，如果不存在产能限制，很多大型企业都会成为其客户。从您的角度看，如果 Bloom 没有产能限制，亚马逊是否会显著增加采购量？还是有其他重要影响因素？

专家：我了解这一说法的背景，因为我们也在进行相关讨论。目前面临产能限制的不只是 Bloom。我们非常注重供应商多元化，例如采用燃气轮机时，会选择多家供应商。但具体到燃料电池，人们首先想到的通常只有 Bloom，因为它是唯一一家美国本土供应商，其他新兴供应商大多来自美国以外。

因此，产能限制确实是一个因素，但并非唯一因素。谈到低排放时，首先想到的表后供电解决方案无疑是 SOFC。不过，除了排放，还必须考虑其他因素，包括初始资本支出、达到供电条件所需的时间、交付周期、土地可用性与部署所需土地面积、用水量，以及潜在部署所需的生态系统。这些也是此前提到的主要因素。

分析师：如果简化问题，暂时不考虑其他因素，仅假设 Bloom 不存在产能限制，亚马逊会增加多少采购量？我主要想了解其产能受限的说法在方向上是否准确。

专家：我们可能会将 Bloom 的钱包份额提高 7至10%，不会超过这一范围。

分析师：但 Bloom 目前在亚马逊的份额实际上几乎为零，对吗？

专家：目前，这些供应商的份额可能为0，但我们并非不考虑未来引入。根据当前的评估、讨论以及对其产能规划的判断，我们可能会将其份额提高7%至10%，最高不超过总采购份额的10%。

分析师：假设到2030年，每年部署10吉瓦，那么其份额可能为10%，即1吉瓦，大致是这个规模吗？

专家：我不倾向于采用这种表述。我们的主要电力需求仍由公用事业公司满足。即使在制定未来5年的战略规划时，我们仍预计80%的电力需求由公用事业公司满足。

目前，我们仍在与Dominion等公用事业公司协商相关协议，并评估PJM或ERCOT区域的电力供应情况。每个区域对电力容量预留都有不同要求，ERCOT最近也开展了相关研究。Dominion目前不具备我们所需的容量，但从长期规划来看，我们仍可以与其协商未来的电力需求及其能够补充的容量。

在此基础上，我们还会考虑表后供电方案。我们对表后供电的规划并非着眼于短期，而是明确面向长期，包括进行垂直整合，以及与天然气供应商签订合同等。

分析师：您提到的10%，是指表后供电总支出的10%，还是电力总支出的10%？

专家：是指表后供电总支出的10%。

分析师：他们表示，随着规模扩大，成本每年会下降10%。考虑到这家公司目前规模仍然较小，他们是否表示会相应逐年降价，还是基本维持价格不变？

回　答　者：我们不会孤立地看待Bloom的价格。在按每千瓦资本支出进行评估时，我们会将其与燃气轮机、往复式发动机进行比较。市场上还有一些积极寻求差异化的参与者，例如BorgWarner和TurboCell。因此，我们会综合比较价格，而不是仅关注Bloom提出的具体价格。Bloom降价或涨价并不重要，关键是将其与其他供应商及其他可选方案进行比较。

提　问　者：据我了解，其他供应商实际上都在涨价，至少大客户Amazon面对的情况可能有所不同。您的意思是否是，无论行业价格如何变化，Bloom的成本或价格至少会朝着相同方向变动？如果其他供应商涨价，Bloom也是如此吗？

回　答　者：我不会这样判断。您提到Bloom正在降低价格，这在一定程度上是正确的。至少根据我们了解的市场情报报告，去年我们并未与Bloom进行非常积极的接洽，直到今年才重新展开讨论。不过，与我们在2024年拿到的书面价格相比，Bloom目前确实降低了价格。

但更重要的是，需要比较以该价格能够从其他供应商处获得什么，以及其他解决方案的情况。即使Bloom降价，也不能单独据此作出判断。

以燃气轮机为例，市场上有许多供应商，并非只有1家，因此采购方拥有更多谈判筹码。采购方可以与供应商签订3至4年的长期协议，并在合同中加入价格调整和数量调整条款。即使供应商短期内提高价格，通过长期合同谈判，其长期价格与Bloom相比仍可能更低。

我们通常不会签订短期协议，而是签订长期协议，期限可能为5年、6年。因此，相关方案的价格短期内可能较高，但长期来看会更低。

分析师：关于数据中心引发的社区担忧，媒体是否夸大了这一问题？更直接地说，在美国部署的数据中心中，有多大比例会受到社区抵制的影响？是否有很大一部分项目会因此延迟？

专家：这取决于具体地区。有些地区的抵制情绪非常强烈。关于您前面提到的媒体报道，我们一直看到媒体倾向于以更夸张的方式描述这一问题。

从我们的观察来看，IID和得州的担忧情绪非常强烈，尤其集中在土地使用、噪声以及上涨的公用事业费用等方面。但从全美范围来看，各地的情况并不相同，有些地方并没有如此强烈的担忧。总体而言，媒体确实夸大了这一问题。

分析师：我们听说，大约20%的美国数据中心会受到影响。您认为这一比例合理，还是偏高？

专家：需要从数据中心的构成来考虑。我们仍有70%至75%的数据中心属于云数据中心，目前主要进行改造；只有25%至30%属于AI数据中心，这些数据中心是在过去几年建成或正在建设的。当前的抵制主要针对我们正在扩建的AI数据中心。

因此，如果提到20%，我认为实际受到影响的是这30%的数据中心，其中约有40%会受到影响。

分析师：也就是说，大致处于10%至20%的范围内。项目延迟是否会产生实质性影响？是否只需要进行一些沟通和说服，还是必须调整部署方式，例如采用Bloom，以证明不存在噪声和排放等问题？

专家：规划中的数据中心项目确实出现了延迟，但我们主要是通过协商推进，包括发布有关用水量的说明，解释我们如何帮助改善公用事业基础设施，以及如何在各地创造就业。因此，项目确实会延迟并受到影响，但并不会被完全取消。我们仍在推进。

回答者：目前仍在协商，以确定是否有可能解决这一问题。

提问者：明白了。听起来可能只需要数个月，并不是无论如何都明确禁止在当地开展项目，对吗？

回答者：这取决于具体地区。ID地区已经面临相关问题，尤其是在洛登县，我们遇到了很大阻力。尽管我们多年来一直在ID地区大规模开展业务，已经建立了良好的人脉，并与具备商业合作关系的承包商保持联系，但在许可审批方面仍然遇到了问题。

从下一个新兴热点来看，我认为是得克萨斯州。我们在那里正面临强烈阻力，不仅来自当地居民，也涉及许多政治敏感因素。外界主要担忧用水量、噪声、电费大幅上涨以及空气质量下降。当地已经出现了较大的政治反对声音，我们认为解决这些问题需要较长时间进行协商。

总体而言，具体情况仍取决于不同地区。俄亥俄州和佐治亚州面临的阻力相对较小。加利福尼亚州和亚利桑那州的关注点则更多集中在用水问题上。不同地区提出的担忧各不相同，但得克萨斯州的问题尤其突出。当地存在争议的项目选址需要较长时间才能解决，项目计划仍在延迟。
