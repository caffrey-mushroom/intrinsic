2. Mod 1功率标准、合同要求与客户部署方案

a) Mod 1的持续功率和峰值功率分别是多少？

  • 功率定义
  1. Mod 1可以持续输出23兆瓦，这是设计中的最高持续基础负载。
  2. 发动机具备25兆瓦的峰值负载能力，但不建议长期持续运行在24至25兆瓦。
  3. 23兆瓦可以在避免过度损耗的前提下，满足客户要求的持续运行时长。
  • 峰值功率的使用场景
  1. 25兆瓦主要用于短期应急、临时补偿或系统内其他发动机停机时的功率支援。
  2. 长时间以25兆瓦运行会提高温度、应力和蠕变水平，可能缩短发动机寿命。

b) 23兆瓦基础负载是否满足超大规模云服务商合同要求？

  • 每台发动机的合同基础标准为持续输出23兆瓦。
  • 低于23兆瓦将受到合同惩罚，高于23兆瓦则有机会获得奖励。
  • 25兆瓦峰值能力包含在合同要求和产品能力范围内，但合同核心考核基准仍是23兆瓦持续负载。

c) 客户建设300兆瓦电力容量时，需要配置多少台Mod 1？

  • 极限配置方案
  1. 按每台25兆瓦峰值功率计算，300兆瓦最低需要12台发动机。
  2. 但这一方案要求发动机持续接近峰值运行，不适合作为长期稳态方案。
  3. 高负载会使发动机温度上升，蠕变、高应力和相关劣化可能呈非线性甚至近似平方级增长。
  • 更合理的配置方案
  1. 专家建议配置15台发动机，每台持续以20兆瓦运行，实现300兆瓦总输出。
  2. 如果其中1台停机，可以让其他部分发动机将功率提高至23兆瓦进行补偿。
  3. 该方案能够兼顾发动机寿命、系统冗余和运营灵活性。
  • 客户最终选择的影响因素
  1. 客户预算。
  2. 可用空间。
  3. 项目建设时间。
  4. 对可靠性、备用能力和发动机寿命的要求。
  • 产品设计理念
  1. Mod 1采用模块化设计，客户可以在减少设备数量和延长设备寿命之间进行权衡。
  2. 若单台发动机停机，其余发动机可以通过提高负载补偿部分缺口。

d) 客户实际会选择少量发动机高负载运行，还是增加设备数量降低单机负载？

  • 专家判断，客户更可能额外采购一定数量的发动机，而不是只采购满足理论最低需求的数量。
  • 对于一款新产品，客户通常会更加重视可靠性和冗余，因此合理做法是：
  1. 将总负载分摊到更多发动机上。
  2. 降低单台发动机的持续运行功率。
  3. 在单机故障时保留灵活的功率补偿空间。
  • 如果持续以25兆瓦运行，额外蠕变可能导致发动机无法达到公司公布的寿命上限，因此公司不建议客户采用这一方案。

3. Mod 1长期运行寿命与维修模式

a) 当前连续测试时间有限，公司为何有信心支持长期地面运行？

  • 航空发动机运行数据提供基础
  1. Mod 1采用的CFM56-5B和7B拥有相似核心机，并积累了大量航空运营数据。
  2. Mod 1持续负载工况略高于飞行怠速，但低于飞机起飞时的高温、高应力和高转速工况。
  3. 因此，地面发电运行整体可以类比为相对温和的非严苛工况。
  • 历史寿命数据
  1. 假设窄体飞机每个飞行循环约2小时，CFM56核心机首次核心修复前通常能够运行至少12,000个循环。
  2. 对应运行时间约为24,000小时。
  3. 这一数据来自可能包含严苛航空运行环境的机队记录，而地面发电工况预计更稳定。
  • 寿命评估方法
  1. 公司综合参考整个机队的平均运行时数。
  2. 结合蠕变寿命、部件性能和发动机历史表现进行推算。
  3. 专家表示对Mod 1长期运行能力“100%有信心”。

b) 长期运行最需要关注的技术风险是什么？

  • 最主要的风险是蠕变，而蠕变与运行温度直接相关。
  • 功率越高，需要注入的燃料越多，发动机温度和应力也越高。
  • 25兆瓦工况下，材料性能可能发生变化，而且这种变化并非完全线性或可预测。
  • 因此，公司将尽量把持续运行状态控制在已经完成评估、能够确保使用寿命的基准范围内，即以23兆瓦及以下为主。

c) 如果Mod 1发生故障，公司将采用更换还是现场维修？

  • 具体处理方式取决于合同条款及故障情况。
  • 可选方案包括
  1. 在特定情形下提供新的保修发动机进行替换。
  2. 在客户现场进行维修。
  • 决策因素包括
  1. 故障严重程度。
  2. 发动机当前状况。
  3. 已运行时长。
  4. 维修可行性及合同约定。

d) Mod 1维修业务能否形成较高利润率？

  • 当前尚未确定Mod 1大修或维修后的具体定价，因此无法准确判断维修业务利润率。
  • 公司对气流部分全部部件进行全面大修的现有业务利润率远高于31%。
  • 专家预计Mod 1大修业务仍会盈利，整体模式可能与航空发动机维修业务相近。
  • 最终利润率将取决于维修后的发动机目录价格、零部件成本和具体维修范围。

e) 动力业务使用的零部件是否属于“不适航零部件”？

  • 不是。专家明确表示，动力业务使用的零部件在技术上仍符合航空适航要求。
  • 这些零部件通常只是不符合航空业务当前的商业定位或项目要求，而非技术上不能用于航空。
  • 航空与动力业务需求差异
  1. 航空客户通常要求发动机拥有较高的剩余循环数，例如11,000次或以上。
  2. 部分发动机第2次返厂时，剩余循环数可能降至4,000次或更低。
  3. 这类部件继续投入航空市场的商业价值有限，因为更换寿命限制件的成本较高，且客户不愿使用在翼时间过短的发动机。
  4. 对动力业务而言，剩余约4,000次循环的零部件仍有较高使用价值。
  • 动力业务的寿命管理方式
  1. 除低周疲劳和剩余循环数外，更关注持续地面运行下的蠕变疲劳。
  2. 公司会同时设定小时数限制和循环数限制。
  3. 根据目标剩余寿命，在更窄的范围内对库存部件进行构型匹配。

4. 供应链保障与生产爬坡

a) 当前供应链是否会影响前期交付？

  • 目前未发现明确供应链障碍。
  • 专家每周与CFO协调，以战略方式提前采购物料。
  • 根据当前可见度，前30台发动机预计不会出现供应瓶颈。
  • 中长期需要解决的是建立可持续的零部件获取渠道，并提升部分零部件的维修和再利用能力。

b) 公司将通过哪些方式扩大零部件来源？

  • 供应链保障主要有3条路径：
  1. 扩大可选零部件池，使用更多符合工业发动机构型要求的替代配置。
  2. 在可行情况下直接采购零部件，并推动整批采购交易。
  3. 采购整台发动机后进行拆解，获得所需零部件。
  • 公司也在评估内部制造部分零部件，以提高供应灵活性。

c) 2027年约100台产量目标可能按照怎样的季度路径推进？

  • 专家给出了一组仅用于说明、不可直接引用的示例：
  1. 前一年度末产量达到约10台。
  2. 2027年Q1提升至约15台。
  3. 后续3个季度分别生产约22台、23台和25台。
  • 上述示例合计接近100台，反映的是逐季提升、后期加速的基本思路，并非公司正式产量指引。
  • 实际爬坡速度取决于供应链、测试能力、封装能力和各环节协同情况。

d) 2027年末月产10至15台是否现实？

  • 测试能力约束
  1. 测试1台发动机约需要1.5天，实际排产时至少需要按2天计算。
  2. 如果蒙特利尔工厂不生产任何航空发动机，仅从测试能力看，月产15台存在理论可能。
  • 现实判断
  1. 测试期间可能出现漏油、管路连接不合格等意外问题。
  2. 停机和重启流程耗时较长。
  3. 月产15台属于较高且偏激进的目标，实现概率不高。
  4. 专家认为月产5至10台是更合理、更现实的区间。

e) 月产量从5台提升至10台或15台，主要瓶颈是什么？

  • 第1个瓶颈：供应链
  1. 生产能力建立在所有零部件按时到位的基础上。
  2. 零部件供应在正常情况下容易获得，但一旦出现突发中断，就可能直接影响整机生产。
  3. 当前公司正在提高供应来源的灵活性，但在采购渠道最终落地前仍存在不确定性。
  • 第2个瓶颈：封装能力
  1. 封装不仅涉及机械包装，还包括控制设备、线缆和其他单元的安装与测试。
  2. 如果封装时缺少一根线缆或某个连接部件，就可能推迟整机交付。
  3. 目前Jereh/JERA似乎无法同时处理多台发动机，大量并行封装能力有限。
  4. 如果前序某台发动机延误，可能影响后续整批设备的排期。
  • 生产环节判断
  1. 在全部零部件齐备的情况下，核心发动机组装并非最主要的限制。
  2. 真正影响交付节奏的是原料供应、测试异常、封装及物流协同。

f) Jereh/JERA的封装地点与产能规划如何？

  • 2027年Mod 1的封装工作计划主要在中国完成。
  • Jereh/JERA正在美国得克萨斯州扩建封装能力。
  • 到2028年，联合循环附加系统或后续阶段的封装及集成工作可能转移至得州工厂。
  • 当前尚不能完全确认封装产能不会成为2027年交付100台目标的瓶颈。

5. 联合循环产品的技术方案与客户升级逻辑

a) 联合循环产品如何提升Mod 1功率？

  • 联合循环系统安装在Mod 1发动机后端，利用发动机排气热量驱动CO₂循环发电机。
  • 该系统与Mod 1发动机相对独立，并不是对发动机内部进行重新改造。
  • 可以将其理解为模块化“乐高积木”：
  1. Mod 1发动机是基础模块。
  2. 联合循环系统是后端附加模块。
  3. 两者组合后可进一步提取排气能量。
  • 每台Mod 1预计可以额外增加约8至9兆瓦的基础负载输出。

b) 额外增加的9兆瓦属于基础负载还是峰值负载？

  • 该增量对应基础负载，而非短期峰值负载。
  • 联合循环能够输出多少功率，取决于：
  1. 发动机排气温度。
  2. 发动机当前运行负荷。
  3. 发动机自身效率和健康状态。
  • 如果发动机效率下降，需要燃烧更多燃料，排气温度会上升，联合循环系统获得的热输入也会增加，因此能够在一定程度上补偿主发动机效率下降。

c) 客户目前会如何考虑Mod 1采购数量和未来联合循环升级？

  • 如果客户当前就需要电力，即使知道2028年可以升级，仍可能先采购足够数量的Mod 1，以避免未来1年出现电力缺口。
  • 到联合循环产品推出后，客户可以根据自身需求选择：
  1. 对全部Mod 1进行升级。
  2. 仅升级部分发动机，提高园区总功率。
  3. 停用部分发动机，并将其作为备用设备。
  4. 出售或要求供应商回购多余设备，但具体是否存在回购义务尚不明确。
  • 客户不需要升级整个机组。例如，拥有10台发动机的客户只升级其中5台，理论上可以额外获得约40兆瓦功率。
  • 对分阶段建设的数据中心园区而言，该方案具有较强吸引力：初期使用Mod 1满足第一阶段需求，后期通过联合循环升级支持第二阶段扩容，无需重新购买大量完整发动机。

d) 联合循环系统预计由谁负责集成？

  • Mod 1主发动机由FTAI负责生产。
  • Jereh/JERA负责Mod 1封装。
  • 联合循环合作方负责其专有发电机系统，并将其连接至发动机排气端。
  • FTAI预计主要参与接口协调和系统衔接，而非承担联合循环发电机的全部设计制造。
  • 未来可能形成三级协作模式：
  1. FTAI生产主发动机。
  2. Jereh/JERA完成发动机封装。
  3. 联合循环合作方对封装后的设备进行进一步集成。

6. 联合循环产品定价、利润率与资本投入

a) 联合循环升级系统的价格预计是多少？

  • 行业平均发电设备价格约为每兆瓦100万美元，但联合循环套件预计将低于Mod 1的单位兆瓦价格。
  • 专家判断，联合循环附加系统的整体价格可能约为一套完整Mod 1价格的1/3，甚至更低。
  • 该判断指的是整体价格，而非每兆瓦价格。
  • 公司可能提供一定财务激励，鼓励现有客户升级。
  • 定价必须明显低于重新购买一套Mod 1，否则客户缺乏采用升级方案的动力。

b) 联合循环产品是否可以独立销售？

  • 不能作为完全独立的设备销售。
  • 客户必须先拥有Mod 1，联合循环系统才能利用Mod 1的排气热量进行发电。
  • 因此，联合循环产品既能提升客户升级意愿，也有助于巩固Mod 1的先发优势和客户黏性。

c) 联合循环方案的利润率能否达到Mod 1水平？

  • 专家预计联合循环部分的利润率为正，但可能低于Mod 1。
  • Mod 1利润率优势来源
  1. 公司清楚掌握材料来源、采购成本及最终售价。
  2. 可以使用成本显著低于新件的翻修零部件。
  3. Mod 1利润率远高于31%的MRO平均利润率。
  • 联合循环利润率可能较低的原因
  1. 尚不清楚联合循环发电机的材料来源和采购成本。
  2. 如果使用较多新零部件，成本将高于使用翻修部件的Mod 1。
  3. 联合循环产品本身需要以更有吸引力的价格提供给客户。
  • 示例性成本推测
  1. 小型发电机制造成本可能约为300万至400万美元。
  2. 封装成本可能增加约100万美元。
  3. 总成本可能达到约500万美元。
  • 联合循环产品的战略重点并非追求更高利润率，而是为客户提供灵活扩容方案、促进升级并强化公司市场领先地位。

d) 联合循环方案是否需要大量研发投入和资本支出？

  • 预计联合循环方案的资本支出明显低于Mod 1。
  • 主要原因
  1. CFM56发动机运行和控制系统较为复杂，Mod 1需要制造多台原型机进行概念验证。
  2. 联合循环发电机主要依靠受热CO₂膨胀运行，核心输入压力可通过阀门调节。
  3. 控制系统预计没有CFM56发动机复杂，不需要同等数量的原型机和深度验证。
  4. 联合循环发电机尺寸更小，单台原型成本也更低。
  • 部分资本支出可能由联合循环合作方承担，因此FTAI自身承担的资本负担预计更小。

a) CFM56机队逐步退役是否会影响公司航空业务？

b) CFM56相较新型发动机的经济性如何？

  • 专家举例：
  1. 新发动机采购价格约为1,500万美元，每5年可能还需投入约500万美元维护，折合年均维护成本约100万美元。
  2. 旧发动机采购价格约为800万美元，在推力和可靠性等方面能够提供相近作用，年维护成本可能仅约50万美元。
  • 航空公司倾向于延长旧发动机使用周期，主要因为：
  1. 采购价格更低。
  2. 能够完成相同运营任务。
  3. 维护成本更低。
  4. 新型发动机的可靠性和可预测性暂时不如成熟机型。
  5. OEM目前尚未停止相关零部件生产，未来5年内预计也没有停产计划。

c) 如果未来CFM56-5B机队真正进入退役阶段，公司如何应对？

  • 专家相信公司能够获得参与LEAP发动机合同的机会。
  • 相关转型讨论早在约两年前已经开展。
  • 因此，即使CFM56市场长期收缩，公司也有机会通过扩大市场份额和切换至新发动机型号实现平稳过渡。
