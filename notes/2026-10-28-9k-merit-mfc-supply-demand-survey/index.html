MFC（质量流量控制器）产业及供应链专家访谈纪要

1. MFC断供现状与主要原因

a) 当前HORIBA MFC是否存在断供，具体表现如何？

  • HORIBA（堀场）MFC目前确实存在供应不足：
  1. 小型晶圆厂或客户若仅采购少量、甚至单个MFC，采购难度较大。
  2. 大型半导体设备厂商虽然能够获得供应，但交期较长，且可获得的数量有限。
  • 当前供应紧张并非单一因素造成，主要包括：
  1. 原材料及关键零部件不足。
  2. 生产环节人工紧缺。
  3. 海外订单量较大，部分产能优先配置给海外客户。
  • 如果MFC在国内组装，会受到关键原材料不足影响；如果由日本生产后分配至国内，国内能够获得的数量也在减少。

b) MFC供应链中主要短缺哪些零部件？

  • 当前主要短缺两类零部件：
  1. Blocks（金属底座）：每个MFC均需要一个经过精密加工和抛光处理的金属底座。
  2. PCB板：用于MFC内部控制和通信，是目前最主要的供应瓶颈。
  • 其他原材料也存在一定程度的紧张，但影响明显小于金属底座和PCB板。

c) 金属底座为什么出现紧缺，是否构成长期核心瓶颈？

  • 金属底座的主要供应来源包括日本供应商和沈阳富创，国内目前已承担部分供应。
  • 供应紧张的主要原因包括：
  1. 半导体行业快速发展，精密金属加工件需求持续增长。
  2. 加工程序复杂，对精度、抛光和洁净度要求较高。
  3. 产能扩张受到原材料、产线和人工等因素限制，无法快速匹配需求增长。
  • 但专家认为，金属底座的紧缺具有一定周期性，可通过延长产线、增加设备和扩产逐步解决，并非长期核心卡点。
  • 国内精密金属件产线在扩产、迭代和人员组织方面效率较高，受到跨境运输及海关等因素的影响较小。
  • 从中长期看，金属底座业务甚至可能成为国内供应商的增长点，未来除供应HORIBA外，也可向国产MFC厂商拓展。

d) 当前MFC供应链中最大的卡点是什么？

  • PCB板是当前HORIBA MFC生产的最大限制因素。
  • PCB短缺的主要原因包括：
  1. AI、算力服务器等市场快速扩张，带动PCB及上游原材料需求大幅增长。
  2. 上游供应商自身受到原材料、产线和排产限制。
  3. HORIBA采购规模相对较小，在上游客户体系中的供应优先级不高。
  4. 上游供应商会优先满足采购量更大、报价更高、议价能力更强的服务器及算力客户。
  • 即使HORIBA愿意接受更长交期，短期内仍较难获得足够数量的PCB板。

2. PCB板的技术要求、供应来源与恢复周期

a) HORIBA MFC使用的PCB板有哪些要求？

  • PCB板安装在MFC红色外壳内部，约占外壳内部空间的一半。
  • HORIBA对PCB板的主要要求包括：
  1. 数据处理和响应速度较快。
  2. 稳定性和耐用性较高，不易损坏。
  3. 板卡体积较小。
  4. 需要支持EtherCAT通信。
  • 专家表示，该类PCB未必与服务器PCB存在本质上的巨大差异，但HORIBA对质量、性能和使用寿命的要求较高。
  • 专家不了解具体工艺路线、DK/DF参数、是否使用MSAP工艺及PCB在MFC BOM中的成本占比。

b) HORIBA的PCB板主要从哪些地区采购？

  • 目前主要供应来源为：
  1. 日本本土供应商。
  2. 中国台湾地区供应商。
  • 专家认为，大陆虽然有较多PCB厂商，但HORIBA尚未找到或导入足够多能够满足其质量、性能和寿命要求的供应商。
  • HORIBA当前寻找第二、第三供应商时，仍主要考虑日本和中国台湾地区。
  • 专家关于大陆PCB质量的判断主要来自实际使用体验，但未提供具体技术参数和量化测试结果。

c) 为什么不能快速更换大陆PCB供应商？

  • 新供应商导入需要经历完整验证流程：
  1. 新供应商按照HORIBA要求开发首款产品。
  2. HORIBA需要将该PCB应用到不同MFC型号上分别测试。
  3. 通过性能、可靠性和适配性测试后，才能正式下单。
  4. 新供应商还需要根据订单进行产能扩张。
  • 即使部分供应商已有相关技术能力，也可能因市场订单饱满而无法提供足够产能。
  • 当前既需要培养现有二供，也需要寻找新的合格供应商，因此短期内难以解决。

d) MFC供应紧张预计何时缓解？

  • 专家预计，明年中期以前较难彻底解决。
  • 供应恢复主要依赖两条路径：
  1. 原有PCB供应商提升原材料供应和产能。
  2. 新增合格供应商，并完成不同型号的测试验证和扩产。
  • 单纯完成供应商认证可能就需要半年左右，之后还要经历量产爬坡，因此短期内供应改善空间有限。

3. 其他零部件供应情况

a) 压电陶瓷是否也是MFC的核心卡点？

  • 专家认为，压电陶瓷目前不是HORIBA MFC的主要供应瓶颈。
  • 在其工作期间，并未发现HORIBA因压电陶瓷不足而明显减产，实际减产主要由PCB供应不足导致。
  • HORIBA旗下STEC子公司承担较多压电陶瓷相关组装工作，因此该环节在HORIBA内部的可控性相对较强。
  • 专家不了解更上游压电陶瓷原材料和具体供应商情况，但从实际生产体验看，其紧缺程度明显低于PCB。

b) Blocks和MFC产能之间是什么关系？

  • 每台MFC均需要配套一个金属底座，因此Blocks需求量与MFC产量基本对应。
  • 专家未提供独立的Blocks年产能和市场份额数据。
  • 由于Blocks可通过扩产逐步解决，其对MFC产量的影响预计小于PCB。

4. 断供对半导体设备及晶圆生产的影响

a) HORIBA MFC断供会如何影响下游？

  • 部分半导体设备订单明确指定使用HORIBA MFC，如果产品无法按时到货，下游设备厂商通常只能：
  1. 等待HORIBA交付。
  2. 更换为其他进口品牌。
  3. 使用性能相对较弱的国产MFC进行替代。
  • 如果更换为性能不足的国产产品，可能造成：
  1. 设备流量控制精度下降。
  2. 工艺稳定性降低。
  3. 晶圆良率下降。
  4. 设备交付和下游产量受到影响。
  • 对先进沉积和刻蚀工艺而言，部分国产产品即使接受良率下降，也可能仍无法满足使用要求。

b) 当前供应问题是否源于对中国企业的出口限制？

  • 专家表示，目前较少出现因宏观政策或监管限制而无法向中国企业销售MFC的情况。
  • Brooks、HORIBA、Fujikin和MKS等海外厂商仍可向北方华创、中微公司等国内设备企业销售产品。
  • 当前供应紧张更多是由全球需求、关键零部件短缺和供应优先级导致，而非政策性禁售。

c) 国产高端MFC与进口产品的差距主要体现在哪里？

  • 专家认为，部分国产MFC在以下方面仍与国际先进产品存在差距：
  1. 响应速度。
  2. 小流量控制能力。
  3. 控制范围。
  4. 压电阀稳定性。
  5. 长期精度与重复性。
  • 对纳米级甚至更先进的沉积、刻蚀工艺而言，MFC响应速度和流量稳定性会直接影响薄膜厚度、均匀性及最终良率。
  • 因此，先进半导体设备目前仍更倾向于使用进口高端MFC。

5. MFC产能、价格与市场规模

a) HORIBA在国内的MFC产量大概是多少？

  • 专家提供的国内产量口径如下：
  1. 7500型号月产量不足3,000台。
  2. 初步统计的所有主要型号月产量约5,000—6,000台。
  • 但上述5,000—6,000台并未完整覆盖所有相关产品，后续还需加入：
  1. 其他MFC系列。
  2. Z系列、D系列之外的产品。
  3. 湿法流量计。
  4. 浓度计、干法流量计等相关产品。
  • 国际订单量至少是国内订单量的5倍，实际可能更高，但专家无法提供全球准确数据。

b) 不同层级MFC的价格分别是多少？

  • 产品价格按应用和性能分层明显：
  1. 高端产品：至少3万元以上/台。
  2. 中端产品：1万元以上/台。
  3. 低端产品：数千元/台。
  • 用于高端刻蚀设备的MFC，平均价格约为2万元/台，且通常执行设备厂商年度采购价格。
  • 如果通过代理商采购，价格可能更高。

c) HORIBA及全球MFC市场规模大概是多少？

  • 专家对市场规模未做过系统统计，相关数据主要为现场估算：
  1. 一度提到HORIBA中国市场销售额约20亿元。
  2. 后续估算HORIBA全球面向半导体客户的销售金额约150亿—200亿元。
  • 上述数据与专家同时提供的月产量、产品均价口径存在一定不一致，可能混入了流量计、浓度计、湿法产品及其他非MFC产品。
  • 因此，市场规模和HORIBA收入数据仅适合作为方向性参考，不宜直接用于精确测算。

d) 如何理解产能、产量和销量之间的差异？

  • 企业对外披露或宣传的“产能”不等于实际产量和销量。
  • 国产厂商可能具备一定名义产能，但不一定拥有对应订单。
  • HORIBA的特点是订单较多，但实际产量受到PCB等供应链限制，导致产能难以满足需求。
  • 因此，不能简单按照厂商市场份额与单家公司披露产能进行线性推算。

6. 半导体设备中的MFC用量与价值量

a) 一台刻蚀设备需要使用多少MFC？

  • 以较先进的刻蚀设备为例：
  1. 一台设备可能配置4个腔体。
  2. 每个腔体至少需要约22台MFC。
  3. 4个腔体合计约88台。
  4. 前端吹扫环节还需增加2—3台。
  • 单台刻蚀设备合计使用约90台MFC。

b) 单台刻蚀设备中的MFC价值量是多少？

  • 按平均每台MFC约2万元计算：
  • 90台MFC对应价值量约180万元，接近200万元。
  • 如果单台刻蚀设备售价约4,000万元，MFC价值量占比可接近5%。
  • 该案例对应北方华创较先进的刻蚀设备，并不代表所有设备的平均配置。
  • 低端刻蚀设备可使用国产MFC，整体成本会明显下降。

c) MFC价值量为什么会随设备制程变化？

  • 先进设备需要更快响应、更小流量、更高精度和更稳定的MFC，单价及使用数量均可能更高。
  • 低端设备可采用华诚电子等国产产品，成本显著低于进口高端产品。
  • 因此，MFC在设备BOM中的价值占比取决于具体设备类型、腔体数量、工艺难度和制程水平，不能简单套用统一比例。

7. 不同应用领域的需求与产品层级

a) 半导体是否是MFC最大的应用市场？

  • MFC还广泛应用于：
  1. 光伏。
  2. 光纤。
  3. 面板。
  4. 其他镀膜和流量控制领域。
  • 从出货数量看，半导体不一定是最大的应用市场。
  • 从销售金额看，半导体产品单价最高，可视为最大的细分应用领域。
  • 半导体也是技术要求最高、产品最尖端的应用场景。

b) 半导体与光伏、光纤、面板MFC有什么区别？

  • 光伏、光纤和面板行业更强调：
  1. 大流量供气。
  2. 短时间内实现更高产量。
  3. 对精度和响应速度的要求相对较低。
  • 半导体行业更强调：
  1. 小流量精准控制。
  2. 毫秒级快速响应。
  3. 高重复性和稳定性。
  4. 对原子层沉积等精细工艺的适配。
  • 光伏、光纤和面板用MFC通常为数千元/台；1万元以上的产品主要用于更精密的工艺。

c) 高端与低端MFC的核心参数差异是什么？

  • 响应速度差异
  1. 面板等低端场景可能允许约2秒完成停止或切换。
  2. 半导体场景可能要求800毫秒、450毫秒，甚至100毫秒级响应。
  • 小流量控制差异
  1. 光伏、光纤和面板更需要大流量。
  2. 半导体原子层沉积等工艺要求每次仅沉积极薄的一层粒子，因此需要极小流量的精确控制。
  • 稳定性差异
  • 晶圆价值较高，任一层沉积或刻蚀偏差都可能影响整片晶圆，因此对MFC长期稳定性和重复性要求更高。

d) 光伏、光纤等领域是否也存在MFC短缺？

  • 当前主要短缺的是半导体级高端MFC。
  • 光伏和光纤领域的中低端MFC技术壁垒相对较低，国产厂商已经能够生产，整体供应较为充足。
  • 即使前两年光伏行业快速扩产，也未出现明显的MFC供不应求。
  • 当前光伏行业热度下降，短期内再次大规模扩产的可能性较低。
  • 国内光纤厂采购的MFC也以国产产品为主，但专家无法提供具体厂商和年采购量数据。

8. 国产化率与竞争格局

a) 国内MFC厂商当前整体市场份额如何？

  • 专家估计，国产MFC在国内整体市场的份额可能已超过50%。
  • 该比例主要来自中低端和成熟制程市场，并不意味着国产厂商已在先进半导体MFC市场占据主导地位。
  • 国产份额提升的主要驱动因素包括：
  1. HORIBA、Brooks等进口产品供应数量有限。
  2. 下游设备商存在国产化率要求。
  3. 国产厂商在光伏、光纤、面板和成熟制程领域已具备供应能力。
  4. 设备厂商可通过工艺调整或多个国产MFC组合，替代单个进口高端MFC的部分功能。

b) 国产MFC目前主要能够覆盖哪些半导体制程？

  • 单价约7,000—8,000元的国产MFC，主要供应给工艺要求相对较低的半导体客户。
  • 专家判断，这类产品更多用于约80—90纳米及以上的成熟制程。
  • 国内存在较多成熟制程晶圆厂，为国产中低端MFC提供了较大市场空间。
  • 如果国产MFC能够稳定应用于20—30纳米制程，其需求和产品价值会明显提高，售价通常不会维持在7,000—8,000元的水平。

c) 国产MFC未来的突破路径是什么？

  • 未来国产替代预计将沿两条路线推进：
  1. 在成熟制程及非半导体领域继续扩大份额。
  2. 通过提升响应速度、小流量控制、压电阀稳定性和使用寿命，逐步进入先进制程。
  • 在单台国产MFC暂时无法完全替代进口产品的情况下，下游可能通过多台组合和工艺优化实现部分替代。
  • 进口产品供应不足与国产化率要求，将持续推动设备厂商验证国产MFC。

9. 关键结论与风险提示

a) 本次访谈的核心结论是什么？

  • HORIBA MFC目前确实存在供应不足，PCB板是最核心的限制环节。
  • 金属底座存在阶段性紧张，但可通过扩产解决，不构成长期核心卡点。
  • 压电陶瓷目前未对HORIBA产量形成明显限制。
  • 供应紧张预计至少持续至明年中期，恢复取决于PCB原材料扩产、新供应商验证和量产爬坡。
  • 先进半导体级MFC短期仍依赖进口，中低端应用及成熟制程已具备较高国产替代基础。
  • MFC在先进刻蚀设备中的价值量较高，单台设备可能配置约90台、价值接近200万元。

b) 哪些信息需要谨慎使用？

  • 专家此前主要从事销售工作，对以下内容了解有限：
  1. PCB具体技术参数和生产工艺。
  2. PCB供应商名单及BOM成本占比。
  3. 压电陶瓷上游供应商。
  4. 全球MFC市场规模及HORIBA全球产能。
  • 访谈中关于国内月产量、中国市场收入和全球半导体业务收入的口径存在不一致，部分数据可能包含流量计、浓度计及湿法产品，需进一步交叉验证。
  • “国产整体市场份额超过50%”主要反映全应用、全层级市场，不能直接等同于先进半导体级MFC国产化率。

提问者：专家您好，今天主要想了解MFC，即质量流量控制器的相关情况。请您先介绍一下MFC的断供情况和原因。

回　答　者：断供情况比较复杂。我目前只能介绍Horiba的断供情况。确实存在断供现象。对于小型fab厂而言，如果想购买1个MFC，难度确实很大；对于大型机台厂商而言，1是交期很长，2是能够获得的数量有限。

原因主要有3个方面。1是原材料紧缺，制作MFC所需的原材料不足；2是生产所需的人工比较紧缺；3是海外订单量很大，导致部分产能转向海外客户。如果MFC在国内组装，会面临原材料不足的问题；如果由日本生产并分配给国内，分配数量也会减少。以上是MFC供应量减少的3个原因。

提问者：您提到的原材料具体是什么？

回　答　者：1是零部件，主要是blocks短缺，因为目前生产量很大；2是PCB板不足。其余原材料也存在不足，但困难没有那么大。主要问题集中在这2个方面：1是精密金属加工件blocks的数量不足；2是用于制作电路板的PCB板原料不足。

提问者：您提到的blocks具体是什么？中文名称是什么？

回　答　者：每个MFC都有1个金属底座，是经过抛光处理的金属底座。我们通常称其为blocks，也可以翻译为金属底座。

提问者：这两个产品中，金属基座主要由哪些公司生产？为什么会比较紧缺？

回　答　者：日本供应商和富创均有生产。金属基座紧缺，一方面是因为近几年半导体行业发展，对金属加工件的需求数量不断增加，导致供应趋紧；另一方面，精密金属器件的加工程序比较复杂，对洁净度也有更高要求，其生产会受到原材料、产线和人工限制。一旦需求大幅增长，产能扩张速度有限，因此会出现紧缺。

不过，这种紧缺具有周期性。如果只是短期问题，可以通过延长产线来解决。

此外，PCB板是目前最紧缺的部件。由于原材料紧缺，不仅豪尔巴无法获得足够供应，其上游供应商在产线和排产方面也更加紧张。豪尔巴作为MFC厂商，其PCB板订单的优先级相对更低。随着AI市场扩张，PCB板及其原材料的需求激增，上游供应商同样面临原材料短缺，因此造成MFC断供。

提问者：Blocks主要由哪些企业生产？市场份额是多少？为什么不扩产？

回　答　者：并非不扩产。随着时间延长，产能肯定会增长。国内生产企业包括富创，国外企业的情况我不太了解。
