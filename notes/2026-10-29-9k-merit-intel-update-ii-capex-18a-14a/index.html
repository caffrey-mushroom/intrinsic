1. 资本开支规模与投向

a) 2026年和2027年的资本开支预计分别是多少？

  • 2026年资本开支：截至年底预计约为220亿美元。
  • 2027年资本开支：
  1. 保底约为270亿美元；
  2. 较高情形约为330亿美元；
  3. 当前投资计划仍在制定中，预计基本落在上述区间；
  4. 若按中位数计算，约为300亿美元，较2026年显著增长。

b) 2027年约300亿美元资本开支将如何分配？

  • Intel 3、18A和18AP扩产：约140亿美元，占比约47%。
  • 14A开发及量产设备：约90亿美元，占比约30%。
  • EMIB、EMIB-T及其他先进封装：约35亿美元，占比约12%。
  • 厂区设施及其他投入：约35亿美元，占比约12%。
  • 整体看，资本开支的核心方向仍是：
  1. 18A系列制程扩产；
  2. 14A技术开发及量产准备；
  3. 先进封装能力建设；
  4. 配套厂房和基础设施建设。

c) 资本开支能否直接换算为新增产能？

  • 不能简单按照投资金额换算产能，主要原因包括：
  1. 投资中包含研发、试生产和量产设备；
  2. 实际有效产能高度取决于良率；
  3. 试生产阶段即使设备投入较大，可交付产量仍可能较低；
  4. 相同设备规模在不同良率下对应的有效产出差异较大。
  • 因此，投资金额更多反映产线建设和设备投入强度，不能直接等同于可销售晶圆产能。

2. 先进制程与先进封装产能规划

a) 18A未来几年的月产能规划如何？

  • 按受访者提供的保底口径：
  1. 2026年年底：月产能达到约4万片；
  2. 2027年年底：月产能达到约6万片；
  3. 2028年年底：月产能达到约8万片。
  • 上述“片”主要按照WSPM，即每月晶圆启动量口径理解。
  • 18A产能增长将主要依赖：
  1. 设备持续导入；
  2. 良率爬坡；
  3. 服务器CPU及潜在外部代工订单的需求拉动。

b) 14A的试生产和量产节奏如何？

  • 受访者给出的其中一组口径为：
  1. 2027年上半年试生产阶段，产量可能仅为数千片；
  2. 随着下半年良率提升，产量可能达到约2.4万片/月。
  • 后续回答中又给出另一组口径：
  1. 2027年年底保底产能约为6000片/月；
  2. 2028年年底预计达到约2.4万片/月。
  • 两组数据对2027年产能的表述存在明显差异，可能分别对应试生产产出、名义产能、有效良率产能或不同统计节点，后续需要进一步确认口径。
  • 可以明确的是：
  1. 14A在2027年仍处于试生产和良率爬坡期；
  2. 2028年预计进入更具规模的量产阶段；
  3. 14A产能释放节奏将显著慢于设备投入节奏。

c) 先进封装的投资和产能目标如何？

  • 先进封装重点方向主要为：
  1. EMIB；
  2. EMIB-T；
  3. 其他适用于多Chiplet、多HBM系统的先进封装技术。
  • 2027年相关资本开支预计约为35亿美元。
  • 受访者还提供了一组以“颗/月”为单位的产能目标：
  1. 2027年年底保底约2万颗/月，挑战目标约5万颗/月；
  2. 2028年年底保底约8万颗/月，挑战目标约12万颗/月。
  • 原始交流中该组数据被表述为“Intel 18A”相关产能，但单位为“颗/月”，且上下文处于先进封装讨论中，可能实际指向18A产品的先进封装产能，具体口径仍需确认。

a) 14A目前有哪些潜在客户？

  • 特斯拉：
  1. 当前是14A最主要的潜在外部客户；
  2. 双方合作谈判据称已接近尾声；
  3. 受访者预计可能很快公布相关信息；
  4. 截至交流时点，特斯拉尚未支付定金；
  5. 若协议最终签署，预计将支付较大规模的保证金或定金。
  • 谷歌：
  1. Intel正在与谷歌沟通IPU和TPU的生产合作；

  4. “IPU”中的“I”据受访者理解可能代表“Infra”，但其本人表示仍需进一步确认。

  1. 当前更多讨论18A合作；
  2. 18A合作据称已基本确定；

  • 综合来看，目前重点推进的外部客户主要包括特斯拉、谷歌、亚马逊和微软四家。

b) 管理层所说的14A“内部客户”是指什么？

  • 受访者对内部客户的具体情况并不了解。
  • 尚无法确认内部14A产品究竟是Intel自有CPU、GPU，还是其他内部项目。
  • 当前掌握的信息主要集中在外部客户谈判，而非内部产品设计进展。

c) 外部客户订单能否显著拉动Foundry收入？

  • 短期影响有限，原因是：
  1. 当前Foundry外部客户收入占比很低；
  2. 据受访者了解，外部客户收入占Foundry收入的比例不到2%；
  3. 即使先进制程订单有所增长，对Intel整体收入的影响仍然较小。
  • 中长期若能签下上述四家客户，18A和14A外部收入有望增长，但在业务体量上仍需较长时间才能形成显著贡献。

4. 长期客户保证金与合同机制

a) Intel今年预计获得多少长期客户保证金？

  • 受访者预计，2026年长期客户保证金规模约为20亿至25亿美元。
  • 该数据并非财务部门正式口径，最终应以公司财报披露为准。
  • 同时，Intel也需要向上游供应商支付大量保证金，以保障：
  1. 基板供应；
  2. 原材料供应；
  3. 关键设备与产能预留。

b) Deposit是否等同于客户预付款？

  • 不完全等同。
  • Deposit更接近长期采购协议下的履约保证金，其核心作用包括：
  1. 锁定客户年度采购数量；
  2. 支持Intel按照合同数量安排产能；
  3. 防范客户未按约定提货带来的损失；
  4. 客户若未完成最低采购量，Intel可以从保证金中扣款并收取违约费用。
  • 例如，客户在框架合同中承诺每年采购2万片，若实际采购未达到约定数量，Intel可依据合同进行扣款。

c) 哪些业务会要求客户支付Deposit？

  • Deposit不只适用于EMIB或先进封装。
  • 适用范围可能包括：
  1. CPU；
  2. 通用GPU；
  3. 先进制程代工；
  4. 先进封装；
  5. 其他长期采购协议下的产品。
  • 本质上，Deposit是长期购买协议的履约保障机制，而非某一类产品特有的付款方式。

d) 收到客户保证金后能否全部形成现金净流入？

  • 不能。
  • 受访者举例称，假设收到100元客户保证金，Intel可能需要向上游支付50元甚至60元，以锁定基板和其他关键供应。
  • 因此，客户保证金对现金流有支持作用，但并不等于同等规模的自由现金流改善。

5. 良率提升与成本下降

a) 18A当前良率和成本改善情况如何？

  • Intel对外宣称的18A良率约为60%。
  • 受访者认为，如果后续进展顺利，良率仍有进一步提升空间。
  • 与年初相比，预计截至2026年12月，良率改善幅度约为60%。
  • 受访者将良率提升直接对应为单位制造成本下降，但该口径属于内部简化表达，实际成本变化还会受到产品结构、固定成本摊销和设备利用率等因素影响。

b) Panther Lake的成本是否仍在下降？

  • Panther Lake制造成本仍处于下降通道。
  • 成本下降的核心来源是良率提升，而非：
  1. 材料价格下降；
  2. 硅晶圆价格下降；
  3. 采购成本下降。
  • 受访者判断，2027年全年制造成本至少还可以再下降50%，但该降幅是基于当时成本基数计算，而不是相对于最初成本直接下降50个百分点。

c) 如何理解公司披露的累计成本下降幅度？

  • 受访者举例说明：
  1. 年初制造成本为100；
  2. Q2下降50%，成本降至50；
  3. 后续再下降20%，是以50为基数，成本降至40；
  4. 相较年初累计下降60%，而不是下降70%；
  5. 若2027年再下降50%，则从40降至20；
  6. 最终相较最初的100累计下降80%。
  • 因此，不同阶段披露的降本比例不能直接相加，必须按照前一期成本基数进行复合计算。

d) 近一个月14A、18A良率是否发生明显变化？

  • 受访者表示，距离上次交流约一个月，14A和18A良率均未出现明显变化。
  • 短期内良率变化有限，更多需要按季度观察设备调试和工艺爬坡效果。

e) PDK 0.5和PDK 0.9代表什么？

  • 受访者将PDK理解为内部风险试生产和工艺成熟度的阶段性节点，与良率达到特定阶段有关。
  • 当前披露节奏为：
  1. 14A的PDK 0.5已经完成；
  2. PDK 0.9计划于10月完成。
  • 从业务意义看，PDK版本升级意味着设计规则、器件模型和工艺信息进一步成熟，有利于客户推进芯片设计和流片准备。

6. EMIB-T良率与CoWoS竞争力

a) EMIB-T当前良率水平如何？

  • 基板良率：
  1. 2026年Q2约为30%；
  2. 2026年9月约为45%；
  3. 2026年Q4目标约为50%；
  4. 2027年Q1目标约为60%。
  • 组装综合良率：目前约为40.5%。
  • 整体来看，EMIB-T仍处于明显的良率爬坡阶段，基板良率是影响交付和成本的重要变量。

b) EMIB-T相较CoWoS的优势在哪里？

  • Intel的优势主要体现在：
  1. 结构扩展性更强；
  2. 局部嵌入式硅桥具有潜在材料效率优势；
  3. 可结合TSV实现垂直供电；
  4. 更适合超大尺寸、多Chiplet、多HBM系统；
  5. 在复杂高算力系统中可能具备成本优势。
  • 台积电CoWoS的优势主要体现在：
  1. 良率更成熟；
  2. 客户生态更完整；
  3. 量产经验更丰富；
  4. 在成熟工艺及相对低复杂度产品方面成本更有优势。

c) 双方在不同产品类型上的成本优势如何划分？

  • Intel相对占优的场景：
  1. 超大尺寸封装；
  2. 多Chiplet系统；
  3. 多HBM系统；
  4. 需要局部硅桥和垂直供电的复杂产品。
  • 台积电相对占优的场景：
  1. 成熟工艺；
  2. 手机SoC；
  3. 5纳米、7纳米等工艺产品；
  4. 对成熟生态和量产稳定性要求较高的产品。
  • 上述判断主要是定性结论，受访者暂未提供定量成本对比数据。

d) 如果台积电产能大规模转移美国，其成本优势是否会削弱？

  • 受访者认为，如果台积电工厂大规模迁往美国，其现有成本优势可能显著下降。
  • 主要原因包括：
  1. 从中国台湾向美国派驻管理层和技术骨干的费用较高；
  2. 据受访者听闻，部分派驻工程师的日夜补助可能达到约1000美元/人/天；
  3. 美国本地工会和人员管理成本更高；
  4. 美国本地制造和运营费用高于亚洲；
  5. 台积电目前仍有大量产品在中国台湾生产，历史上也曾利用中国大陆的较低生产成本。
  • 如果Intel和台积电均完全在美国生产，受访者判断双方综合制造成本可能接近“五五开”：
  1. Intel在多芯片、大尺寸产品方面占优；
  2. 台积电在成熟工艺方面占优。

7. 2026年第四季度经营展望

a) Q4收入和毛利率预计是多少？

  • 受访者预计：
  1. Q4收入约为173亿美元；
  2. 毛利率约为44.0%—44.1%。
  • 该数据为受访者了解的内部预估，不等同于正式财务指引。

b) Q4收入增长的主要驱动力是什么？

  • 主要驱动力包括：
  1. 服务器CPU紧缺订单逐步交付；
  2. 18A良率改善；
  3. 单位成本下降；
  4. 良率提升后有效供给量增加。
  • Q4增长更多来自出货量和有效产能增加，而非产品价格大幅上涨。

c) CPU涨价对Q4收入贡献为什么相对有限？

  • 受访者判断，Q4单价上涨对收入增速的贡献最多约为1个百分点。
  • 原因包括：
  1. CPU销售通常采用年度或三年期框架合同；
  2. 合同价格并非按季度重新谈判；
  3. 即使供不应求，短期价格调整空间也较有限；
  4. 部分合同只能按照CPI和PPI平均变化进行调整；
  5. 只有相关指数涨幅超过一定水平，例如5%，才可能触发调价；
  6. 不同客户的合同条件存在差异。
  • 因此，CPU涨价的实际贡献可能更多体现在2027年Q1和Q2。

d) 长期框架合同对Intel有什么保护作用？

  • 当市场价格上涨时，Intel不能立即大幅提价。
  • 但当市场价格下跌时，客户也不能随意压价或取消订单：
  1. 合同价格仍然具有约束力；
  2. 客户必须完成承诺采购量；
  3. 若未完成采购，Intel可以扣除保证金；
  4. 长期合同本质上具有双向风险对冲作用。

e) Q4面临哪些主要供应风险？

  • 主要风险集中在：
  1. 内存供应；
  2. 基板供应；
  3. 上游保证金和预付款需求；
  4. 良率爬坡能否按计划完成。
  • ABF载板的主要供应商、份额及紧缺程度，受访者暂未掌握具体数据，表示后续可以补充头部供应商信息。
  • 原始交流中一度将ABF载板误称为“ABS盖板”，实际讨论对象应为ABF载板/封装基板。

8. 特斯拉资本开支调整及订单影响

a) 特斯拉下调资本开支是否会影响Intel潜在订单？

  • 公司层面的判断：
  1. 不会对双方潜在合作造成明显影响；
  2. 公司对未来合作仍持积极态度。
  • 受访者个人判断：
  1. 特斯拉资本开支指引仍存在较大调整空间；
  2. 其可以在后续重新上调投入；
  3. 目前尚不能确定此次下调是否会影响实际订单。

b) 特斯拉资本开支的实际执行情况如何？

  • 据受访者了解：
  1. 2026年Q2时，特斯拉曾表示全年资本开支可能达到250亿美元；
  2. Q3又将指引下调至200亿美元；
  3. 前9个月实际资本开支约为130亿美元；
  4. 若全年达到200亿美元，Q4单季度需要支出约70亿美元。
  • 受访者个人认为，特斯拉Q4实际支出70亿美元、全年真正超过200亿美元的可能性不高。
  • 该判断仅代表个人观点，并非Intel或特斯拉官方口径。

9. AI行业风险判断

a) 所谓AI“风险沙盘”是什么？

  • 据受访者从采购和财经同事处了解，波士顿咨询、IBM、麦肯锡及部分华尔街分析师建立了相关模型。
  • 模型主要通过以下指标监控AI行业风险：
  1. 财务指标；
  2. 供应链指标；
  3. 销售指标；
  4. 资本开支；
  5. 库存和客户采购情况。
  • Intel、英伟达等大型科技公司据称会购买相关报告，中国部分企业如华为、阿里和字节也可能购买。

b) 模型对AI行业风险的判断是什么？

  • 按受访者转述，目前模型认为若行业按照当前趋势发展，2028年风险较大。
  • 受访者将其描述为AI泡沫可能破裂的潜在时间点。
  • 但该结果仅为基于当前财务模型的情景推演，并非确定性预测，后续会随宏观环境、需求和资本开支变化而调整。
  • 受访者认为，客户对先进制程和AI芯片投资保持谨慎，也与此类中长期风险判断有关。

10. Foundry业务收入与盈利前景

a) Foundry业务明年能否实现增长？

  • 受访者认为，Foundry业务走势取决于TeraFab建设进度：
  1. 若TeraFab顺利建成，Foundry业务占比和收入规模有望高于今年；
  2. 若TeraFab继续延期或没有实质性进展，Foundry业务可能较今年收缩。
  • 成熟制程收入可能继续下滑。
  • 先进制程方面，若签下亚马逊、微软、特斯拉和谷歌，18A及14A收入有望增加。

b) Foundry外部客户收入占比有多大？

  • 当前外部客户收入占比非常低，据受访者了解不到2%。
  • Foundry业务绝大部分仍服务于Intel内部产品部门。
  • 因此，当前Foundry业务本质上仍以内部结算和关联交易为主。

c) Foundry业务明年年底能否实现盈亏平衡？

  • 官方目标仍然是推动Foundry业务改善并争取盈亏平衡。
  • 但受访者个人判断，明年年底实现盈亏平衡的难度很大。
  • 主要原因包括：
  1. 外部客户收入占比过低；
  2. 先进制程仍处于高资本开支和良率爬坡阶段；
  3. 大部分业务来自内部客户；
  4. 内部Foundry与产品BG之间存在业务竞争和结算关系；
  5. 产能利用率和固定成本摊销仍面临压力。

d) 内部组织和补贴因素是否会影响Foundry盈利节奏？

  • 受访者认为，Foundry面向内部客户的交易较多，对Intel集团而言具有“左口袋到右口袋”的特点。
  • 其个人判断是，公司内部可能并不急于让Foundry业务立即转正，可能还涉及：
  1. 内部转移定价；
  2. 税务安排；
  3. 美国制造业和Foundry业务相关补贴。
  • 受访者提到，亏损状态可能有助于获得部分额外补贴，但该说法属于其个人了解，并非公司正式披露，仍需结合官方财报及补贴政策核实。
