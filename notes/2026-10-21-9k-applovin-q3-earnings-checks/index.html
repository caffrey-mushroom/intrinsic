AppLovin广告业务专家访谈纪要

1. 整体广告业务增长表现

a) AppLovin Q3整体广告收入同比增速是否高于管理层此前指引的48%？

  • 受访者表示，Q3数据公开前属于重大保密信息，无法披露Q3整体广告收入的具体增速，也无法确认是否高于48%的指引。
  • 从业务结构看，AppLovin广告业务可分为两部分：
  1. 游戏及消费者应用广告业务：10月同比整体较为稳定，广告支出增长约5%。
  2. 电商广告业务：当前收入约为去年同期的2倍，同比增长约95%至100%。
  • 整体广告业务未来的超预期增长更可能来自电商和消费者应用领域，而非已经相对成熟的游戏市场。

b) 游戏、消费者应用及电商业务是否达到公司目标？

  • 游戏业务
  1. 游戏广告市场已经相对成熟，公司不预期该业务出现大幅增长。
  2. 当前游戏业务保持低个位数、相对稳定的增长，不太可能成为公司超预期增长的主要来源。
  • 消费者应用业务
  1. 仍处于拓展阶段，公司认为还有大量工作需要完成。
  2. 当前增长主要来自网页广告活动增加，以及“网页到应用”“应用到网页”等跨端转化场景。
  • 电商业务
  1. 从内部远期目标来看，当前表现尚未完全达到公司较高的增长预期。
  2. 从业务进展来看，平台广告主数量、市场知名度和行业声量均在提升，因此阶段性进展符合方向。
  3. 公司并未为Q3电商业务设定非常明确的单季目标，重点仍是把握Q4旺季。
  4. 与近期表现及2027年的潜在规模相比，电商业务仍有较大的长期增长空间。

2. 游戏广告业务表现与模型调整

a) 游戏广告业务的同比和环比增速如何？

  • Q2游戏广告收入同比增长约10%至12%。
  • Q3游戏广告收入同比增长约3%至8%，较Q2有所放缓。
  • 10月同比增长约5%，整体表现相对稳定。
  • 环比增速基本保持稳定，约为3%至8%。
  • Q2和Q3通常是季节性相对稳定的季度，因此增长较低具有一定季节性因素。
  • 公司认为应重点观察Q4完整表现，因为Q4是游戏和电商广告需求季节性最强的季度。

b) 游戏广告业务能否维持20%至30%的年度增长？

  • 受访者认为，应以全年最终结果评估管理层的年度预期，不能仅根据Q2、Q3或10月单月表现作出判断。
  • 公司对Q4仍有较高的季节性预期，但今年电商广告主投放增长可能会加剧竞价，并对部分游戏广告主形成竞争。
  • CEO Adam已多次公开表示游戏市场相对成熟，因此公司广告业务的主要新增量预计不会来自游戏。
  • 游戏业务更可能维持低个位数的稳定增长，公司若要实现超预期增长，突破点主要在消费者应用和电商领域。

c) Q2以来游戏广告推荐模型进行了哪些调整？

  • 自Q2以来，公司更加专注于IP广告活动模型，并已连续发布4次模型更新。
  • 模型优化的核心目标是在以下两方面取得平衡：
  1. 降低CPI，让广告主以更低成本获得更多安装和用户。
  2. 保证新增用户的长期价值、留存和ROAS，避免单纯追求低成本用户。
  • 公司会根据模型上线后的数据和合作伙伴反馈持续调整，并等待用户生命周期数据成熟后再判断效果。
  • 最新一次模型调整仍在观察阶段，Q4期间模型大概率会保持相对稳定。
  • 如果当前版本仍未达到为合作伙伴提供良好效果的标准，公司可能在明年Q1或Q2重新评估。

d) 模型调整后CPI和ROAS表现如何？

  • AppLovin的历史CPI通常高于行业水平，部分IP模型的CPI可能处于行业最高水平之一。
  • 模型调整期间CPI波动较大：
  1. 首次发布新模型后，部分广告主CPI下降至原来的1/3或1/4。
  2. 后续模型调整后，部分广告主CPI又上升50%至100%。
  3. 个别情况下，CPI可能上升至原来的2倍或3倍。
  4. 最新一次调整后，部分广告主仍观察到CPI下降40%至80%。
  • 由于游戏、细分品类及广告主之间差异较大，无法给出统一的CPI绝对值。
  • 公司认为CPI已不能单独说明投放质量，实际重点关注：
  1. ROAS；
  2. 收入增长曲线；
  3. 用户留存；
  4. 付费用户转化率；
  5. 留存率随时间的衰减；
  6. 用户长期价值。
  • 模型优化目标不是简单获得更便宜的用户，而是在保持广告主盈利的前提下，获取成本合理、长期价值更高的用户。

3. 游戏广告市场竞争格局

a) Unity游戏广告业务恢复增长是否会威胁AppLovin？

  • Unity此前经历了较长时间的负增长，并连续多个季度未达到季度目标，推出Vector后开始恢复部分收入和市场份额。
  • Unity同时采取了成本削减措施，并放弃部分广告聚合业务。
  • 单独看Unity环比增长20%意义有限，因为其基数较低，当前业务规模约为AppLovin的30%。
  • AppLovin不将Unity恢复增长视为重大威胁，而是认为行业竞争能够推动各公司持续改进模型、团队和产品。
  • AppLovin的重点仍是优化自身游戏广告模型和电商产品，而非针对单一竞争对手制定策略。

b) Meta Audience Network流量增长是否构成威胁？

  • 受访者同样不将Meta的增长视为直接威胁。
  • 其他广告网络增长能够增强市场竞争，促使AppLovin提高模型效率和合作伙伴服务能力。
  • 公司目标仍是成为市场上表现最优秀的广告网络，更多竞争被视为推动自身进步的机会。

4. 电商广告业务增长与Q4驱动因素

a) 电商广告业务当前增长情况如何？

  • 当前电商广告收入同比增长约95%至100%，接近去年同期的2倍。
  • 电商广告收入占AppLovin广告总收入的比例仍不到10%，受访者估计约为5%。
  • 由于收入基数较低，即使保持高速增长，短期内对整体收入的绝对贡献仍相对有限。
  • 受访者预计Q4电商收入可能达到当前水平的约2倍；关于同比增长区间，其最终修正口径为约50%至100%。

b) Q4电商广告高速增长的主要驱动因素是什么？

  • 主要有两项驱动因素：
  1. 新增合作伙伴持续接入：平台广告主数量增加，公司投入更多资源拓展客户。
  2. Q4旺季效应明显：黑色星期五、网络星期一及圣诞购物季推动电商品牌增加投放。
  • Adobe研究显示，黑色星期五和网络星期一所在周末的广告支出预计超过150亿美元，并创历史新高。
  • 电商品牌通常会在Q4：
  1. 显著提高广告预算；
  2. 推出更多折扣和优惠；
  3. 上线新产品；
  4. 启用新网站或新营销活动。
  • Q4增长主要由广告主数量增加和季节性需求推动，不是因为推荐算法发生重大升级。

c) 电商推荐算法在Q4是否会发生重大变化？

  • Q4电商业务仍将使用现有算法，产品层面没有预计中的重大变化。
  • 当前模型已达到可正式运行、能够向合作伙伴展示投放结果的阶段。
  • 随着广告主和投放数据增加，模型表现预计会持续改善，但无法准确预测明显ROI提升的时间点。
  • 电商市场较游戏市场更加分散：
  1. 游戏发行商单日投放可能达到100万至300万美元。
  2. 电商领域存在大量中小广告主，单体预算通常较低。
  3. 因此需要接入更多广告主，才能形成足够的数据规模和模型正向循环。

d) 为什么Q4开始有更多电商广告主加入平台？

  • 主要原因不是算法变化，而是客户拓展和推荐机制开始产生效果。
  • 公司增加了客户拓展团队，并通过代理商、自由职业者和合作品牌持续引入新客户。
  • 推荐计划为广告主尝试AppLovin提供了较强激励：
  1. 现有客户推荐新广告主入驻并开始投放；
  2. 推荐方可在被推荐广告主投放后的第1年内，获得其广告支出3%的返现；
  3. 部分品牌及合作伙伴可获得专属推荐码，并批量引入客户。
  • 相关建设在Q3逐步推进，并于Q4开始体现更明显的广告主增长。

5. 电商自助平台、品牌认知与广告主拓展

a) 为什么Q3自助服务系统GA后，广告主没有立即大量入驻？

  • AppLovin在电商领域的核心问题是品牌知名度和可信度不足。
  • AppLovin在游戏广告行业占据主导地位，但在电商行业仍属于新进入者。
  • 对于过去10年主要在Meta投放的企业而言，很难立即将15%至20%的预算转移至一个相对陌生的平台。
  • 当前AppLovin在电商行业的发展阶段，类似3至4年前在游戏行业的发展阶段：
  1. 市场认知有限；
  2. 大型广告主合作意愿不足；
  3. 需要先通过中小广告主证明投放效果；
  4. 再依靠口碑和成功案例扩大市场。
  • 公司正在通过品牌广告、CEO及CTO参与播客等方式提高电商行业知名度。

b) 早期电商广告主是否在逐步增加投放？

  • 当前合作账户整体稳定性较高。
  • 初期获得良好投放效果的广告主，通常会维持稳定投放，部分客户还会逐步增加预算并扩大规模。
  • 这表明平台对早期电商客户具备一定留存和扩量能力，但总体仍处在验证和拓展阶段。

c) 哪些电商垂直行业在AppLovin上的效果更好？

  • 目前尚未发现某一特定行业或产品类别具有明确、持续的投放优势。
  • 当前模型并非针对某个特定品牌或垂直领域设计。
  • 已接入平台的品牌包括：
  1. 营养补充剂；
  2. 食品及宠物食品；
  3. 医药产品；
  4. 化妆品；
  5. 时尚产品；
  6. 器具及家居品牌。
  • 平台政策会限制部分品牌接入，并非所有电商品牌均符合投放要求。
  • 公司需要积累更多广告主和投放数据，才能总结不同品类的效果规律。
  • 现阶段更重要的是帮助广告主正确接入平台，使投放策略与AppLovin的广告环境相匹配。

d) 明年电商广告业务增速如何预期？

  • 由于电商广告收入基数仍低，受访者预计明年至少可实现两位数增长。
  • 受访者倾向于给予较高增长预期，并判断电商业务将显著增长，但无法提供准确预测。
  • 长期增长取决于：
  1. 品牌认知和可信度提升；
  2. 新广告主接入速度；
  3. 大型品牌预算迁移；
  4. 数据规模扩大；
  5. 算法持续优化；
  6. 创意生产能力提升。

6. 电商创意工具与平台能力差距

a) AppLovin与Meta、Google相比还存在哪些差距？

  • 最大差距之一仍是电商行业的品牌可信度。
  • 另一个重要差距是电商广告主对AppLovin广告环境和创意形式的理解不足。
  • 游戏行业的广告创意生产体系相对成熟，而电商行业的创意制作、测试及规模化能力仍较弱。
  • Meta、Google与AppLovin的广告库存和用户场景存在明显差异：
  1. Instagram或Facebook信息流中的注意力窗口通常只有约3秒。
  2. AppLovin插屏广告的用户停留时间通常至少10至13秒，最长可达60秒。
  3. AppLovin用户处于游戏环境，注意力更集中，需要专门设计适配该环境的广告素材。
  • 长期只在Meta或Google投放的广告主，通常缺乏针对AppLovin制定创意策略的经验。

b) AppLovin正在如何弥补创意侧差距？

  • 公司已在平台中开发创意工作室，广告主可通过UI和UX自行制作互动广告素材。
  • 无论商店是否接入Shopify，都可以使用自动生成的动态优惠内容，也可进行手动设置。
  • 对配有客户经理的重点账户，公司会利用内部工具与客户共同制作：
  1. 产品导向型素材；
  2. 折扣及优惠导向型素材；
  3. 适合插屏广告的长时长素材；
  4. 互动及可玩广告。
  • 这些工具的核心作用是降低广告主进入门槛，使广告主无须先投入大量预算建立独立创意团队，也能开展初步测试。

c) 电商广告主规模化制作创意是否仍有难度？

  • 挑战不在于能否制作单个创意，而在于能否持续、规模化地产出素材。
  • 要扩大投放规模，广告主需要：
  1. 保持稳定且较高的创意上传频率；
  2. 应对广告疲劳；
  3. 持续测试不同产品和优惠；
  4. 尝试不同创意角度；
  5. 为算法提供足够多的素材进行受众匹配。
  • AppLovin算法能够处理大量素材，但广告主必须具备持续生产和测试大量创意的能力。
  • 平台工具更适合降低初期测试门槛；当广告主验证效果后，仍需投入专门人员和资源扩大创意生产规模。

7. 电商广告主与游戏广告主之间的竞价影响

a) 电商广告主增加是否会推高游戏广告主成本？

  • 对IAP付费型或订阅型游戏而言，竞价压力可能有所增加。
  • 电商广告主和IAP游戏广告主均希望获取具有购买意愿的用户，因此目标受众存在一定重叠。
  • 两类广告主的商业模式仍有明显差异：
  1. 电商通常希望用户在初期完成较高客单价购买。
  2. 游戏更依赖用户长期、重复付费。
  3. 两者的ROAS曲线和目标用户价值不同。
  • 最终影响取决于AppLovin模型能否在不同业务之间合理分配广告展示，而非简单地由电商广告主全面挤压游戏广告主。

b) 电商广告主增加对广告变现型游戏是否有利？

  • 对广告变现型和混合变现型游戏而言，电商广告需求增加可能带来正面作用。
  • 更多电商广告主参与竞价，将提高游戏广告库存的eCPM。
  • eCPM提高后，游戏企业的ARPDAU和用户变现能力将上升。
  • 更强的变现能力可以改善游戏企业的ROAS和ROI，进而支持其增加用户获取预算。
  • 因此，电商广告主增加对IAP游戏可能带来竞价压力，但对广告变现型和混合变现型游戏可能形成增量价值。

8. AXON算法与CTV业务规划

a) AXON 3预计何时推出？

  • 受访者认为短期内不会推出AXON 3。
  • AXON 2已对代码基础设施和整体代码体系进行了全面重构。
  • 当前公司内部没有关于AXON 3的讨论，也没有明确开发或发布计划。
  • 如果未来推出AXON 3，预计将成为重大产品消息，但现阶段不存在相关迹象。

b) CTV广告是否会成为近期增长驱动力？

  • AppLovin收购Wurl后已开展CTV业务超过2年，但目前CTV并非主要战略重点。
  • 公司长期希望进入并发展CTV广告业务，并探索电商网站商业化变现。
  • AppLovin的长期目标是覆盖更多广告渠道并在各渠道取得领先地位。
  • 但CTV在未来几个季度不会对广告收入产生显著影响，未来1年内也可能不会成为重要增长驱动力。

9. MAX广告聚合平台发展

a) 接入MAX的App和合作伙伴数量是否持续增长？

  • 接入MAX的合作伙伴和App数量持续增加。
  • 当前游戏广告聚合市场主要有3个平台：
  1. AppLovin MAX；
  2. Unity LevelPlay；
  3. Google AdMob。
  • MAX目前约占游戏广告聚合市场的80%，甚至可能达到85%。
  • LevelPlay已公开表示将减少对聚合业务的资源投入，此后MAX业务持续增长。
  • 当前仍有部分App从AdMob、LevelPlay和Gravite迁移至MAX，但来自Gravite的迁移数量较少。

b) 接入MAX后，App广告收入能够提升多少？

  • 单纯对聚合平台进行一对一比较，各平台的变现效果已经较为接近。
  • 根据App类型及原有聚合平台的不同，接入MAX后ARPDAU通常可提升约5%至15%。
  • MAX仍能带来一定变现收入增长，但其最大价值并不只是聚合效率。

c) MAX的核心战略价值是什么？

  • MAX最大的价值来自其与AppLovin用户获取业务的绑定。
  • App若要在AppLovin开展部分广告活动和混合广告活动，需要使用MAX进行变现。
  • 如果App未接入MAX，则无法开展相关用户获取活动，而其他广告网络通常不存在这一限制。
  • 接入MAX后，App可以获得来自AppLovin的增量用户获取渠道，从而显著改善整体业务表现。
  • 随着AppLovin成为领先的用户获取网络，更多合作伙伴为了在其平台投放广告而选择接入MAX。

d) MAX是否直接推动App用户数量增长？

  • MAX本质上是广告聚合和变现工具，不负责直接获取用户。
  • App用户数量取决于其用户获取投入：
  1. 增加获客投入，用户和日活数量可能增长；
  2. 减少获客投入，日活用户数量可能下降。
  • MAX可以通过开放AppLovin用户获取活动，间接为App提供增量获客能力，但不能将用户增长直接归因于聚合工具本身。
