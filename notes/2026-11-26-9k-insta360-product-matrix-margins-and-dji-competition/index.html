影石创新专家访谈纪要

1.业务分类与产品矩阵

a)公司的业务分类是否完整？

  • 公司业务主要分为三类：
  1. 消费级智能影像设备；
  2. 配件及其他；
  3. 专业级业务。
  • 消费级智能影像设备主要包括：
  1. X系列全景相机；
  2. ACE系列广角运动相机；
  3. GO系列拇指相机；
  4. Luna云台相机；
  5. 全景无人机；
  6. 稳定器、摄像头、麦克风等其他消费级设备。
  • 专业级业务主要面向B端客户，包括空间采集硬件、软件及SDK授权、行业解决方案和项目制服务。

b)公司各产品线的战略定位分别是什么？

  • X系列全景相机：公司规模最大的品类和核心基本盘，优势在于全景算法、配件生态、渠道和用户心智，但长期并非增速最快的业务。
  • ACE系列运动相机：传统广角运动相机赛道的进攻型产品线，也是公司的第二增长曲线，目标是扩大用户池并争夺大疆Action、GoPro的市场份额。
  • GO系列拇指相机：差异化和入门型产品线，主要用于拉新，覆盖亲子、宠物、轻旅行Vlog等轻度记录人群。
  • Luna云台相机：战略新品，进入大疆Pocket占据优势的云台相机市场，定位偏专业创作，预计是未来重要增长方向。
  • 全景无人机：孵化型业务，定位于沉浸式全景航拍，而非直接复制大疆常规航拍产品路线，短期规模和盈利贡献有限。
  • 其他消费级设备：作为影像生态的补充，整体保持稳健增长，不是主力业务。
  • 专业级业务：规模较小、毛利较好，但订单波动较大，交付周期长，预计整体保持稳定。

2.X系列全景相机：核心基本盘与增长趋势

a)X系列目前的产品范围和历史系列情况如何？

  • 当前主推的消费级全景相机为X系列。
  • 历史上还包括ONE、ONE R和RS等系列，但相关产品已经收尾，不再生产。
  • Pro系列归属于专业级设备，不属于消费级X系列。

b)X系列的出货量和均价趋势如何？

  • 会议中关于X系列出货量存在多组口径：
  1. 2025年出货约120万台；
  2. 后续披露口径约为124万—125万台；
  3. 2026年预计约140万台，另有160万台的测算口径；
  4. 2027年目标约180万台；
  5. 2028年按约40%增长测算，可能达到约220万台。
  • 上述差异主要源于渠道保守指引、公司披露口径以及基准/乐观情景不同，正式使用前需进一步核实。
  • 均价方面：
  1. 2025年约2700—2800元；
  2. 2026年约3100元；
  3. 2027年预计约3300元；
  4. 2028年可能稳定在3300元左右。
  • 均价提升主要来自旗舰新机占比提高，而不是老产品直接涨价。

c)旗舰新机未来将占X系列多大比例？

  • 当前旗舰新机占X系列约30%—40%。
  • 预计下一年度占比提升至60%—70%，逐步成为主力机型。
  • 若按照60%的占比测算，旗舰机型年出货有望达到80万—100万台以上。

d)X系列的行业需求和市场份额如何？

  • 2026年全景相机行业需求预计为200多万台。
  • 应用场景结构大致为：
  1. 摩托和骑行约占70%，是行业基本盘；
  2. 房车、自驾和户外旅行约占20%，属于增量场景；
  3. 其余来自滑雪、冲浪等小众运动。
  • X系列在行业中约占70%，其余份额主要由大疆360、理光等品牌占据。
  • 房车市场规模有限，更多是配套延伸需求，不是全景相机的核心增长来源。

e)公司如何形成X系列的销量预测并向工厂排产？

  • 公司采用滚动出货指引，分为保守、基准和乐观三档：
  1. 基准指引用于工厂排产；
  2. 乐观指引用于规划弹性产能和备料上限；
  3. 指引按月滚动更新，大促或海外渠道订单变化时及时调整。
  • 需求预测主要参考四类因素：
  1. 渠道数据：海外经销商意向备货量、亚马逊等平台动销、库存周转、预售及大促转化率；
  2. 场景数据：骑行、摩托、房车等圈层热度以及配件捆绑渗透率；
  3. 产品周期：新品爬坡、老款清尾、首销转化、复购口碑和定价弹性；
  4. 竞争变量：大疆等竞品的新品发布、价格和市场份额变化。

f)X系列的核心竞争优势是什么？

  • 全景底层算法积累：
  1. 双鱼眼无缝拼接；
  2. 防抖；
  3. 隐形自拍杆；
  4. AI导演与自动剪辑；
  5. 摩托、骑行等高速运动场景适配。
  • 场景配件生态：
  1. 已建立支架、车把固定装置、头盔套件和车载配件矩阵；
  2. 在海外骑行、摩托社群中积累了较强的经销商、KOL和用户心智。
  • 产品路线聚焦：
  1. 公司长期聚焦消费级全景运动影像；
  2. 大疆产品线更分散，全景只是其中一条业务线；
  3. 理光偏静态和商用全景，在运动场景体验上较弱。
  • 全球渠道与本地化能力：
  1. 欧美、东南亚圈层运营相对成熟；
  2. 海外经销商备货、动销和售后配合度较高。

g)全景相机行业未来还能维持高增长吗？

  • 短期仍能保持增长，但很难延续过去两年的高增速。
  • 摩托、骑行等基本盘渗透率逐渐接近瓶颈，未来可能维持10%—15%的稳健增长。
  • 旅行、家庭记录、车载和自驾是新增场景，但转化速度偏慢。
  • 2026年仍有望维持相对较快增长，2027年以后行业增速可能回落至约15%。
  • AI自动剪辑和空间影像功能有助于降低使用门槛，但大疆等竞争者加码会分流市场份额。
  • 长期来看，全景相机仍是细分小众产品，较难成为手机影像或普通运动相机级别的大众消费品。

h)X系列的毛利率处于什么水平？

  • X系列毛利率约为42%，未来预计维持在这一水平。
  • 主要优势来自：
  1. 市场份额领先；
  2. 全景算法和配件生态壁垒较强；
  3. 定价主动权高于其他产品线。

3.ACE运动相机：第二增长曲线与竞争压力

a)ACE系列的出货量和价格趋势如何？

  • ACE是公司唯一的传统广角运动相机系列。
  • 出货量方面：
  1. 2025年约50万台，具体口径约为53万台；
  2. 2026年预计约80万台；
  3. 2027年预计约100万台；
  4. 2028年预计约120万—130万台，更可能接近120万台。
  • 均价方面：
  1. 2025年裸机均价约2000元；
  2. 2026年随着ACE Pro 2等高端机型占比提升，均价约2500元；
  3. 2027—2028年预计维持在2500—2600元。
  • 后续均价提升将主要依靠Pro版本占比提高，而不是单机直接涨价。

b)ACE与X系列在使用场景上有何差异？

  • ACE强调清晰、稳定的单视角成片，拍摄后可以直接剪辑和发布。
  • X系列强调全量记录，用户可在拍摄后重新选择视角，进行二次创作。
  • 具体场景差异：
  1. 房车和车载：X系列可以记录车辆周边完整环境，优势更明显；
  2. 摩托和骑行：注重第一视角直出的用户偏向ACE，注重全方向记录和第三人称效果的用户偏向X系列；
  3. 滑雪和冲浪：ACE更主流，X系列主要用于趣味环绕和第三人称效果；
  4. 短视频和随手拍：ACE更符合大众观看习惯，学习成本更低。

c)广角运动相机行业规模和竞争格局如何？

  • 2026年全球广角运动相机行业需求约260万—270万台，不包括GO、云台相机和全景相机。
  • 市场份额大致为：
  1. 大疆Action排名第一，份额约60%出头；
  2. ACE排名第二，公司份额约20%—30%；
  3. GoPro份额持续收缩；
  4. 其他品牌占比较低。
  • 海外成熟市场中的摩托、滑雪等核心圈层渗透率已较高，但国内和东南亚仍有增量空间。
  • 未来2—3年行业增速预计约10%多，难以长期维持当前高增长。

d)ACE系列的战略定位是什么？

  • ACE属于公司传统广角运动相机赛道的进攻线和第二增长曲线。
  • 战略价值包括：
  1. 打破市场对公司“只做全景相机”的认知；
  2. 覆盖更广泛的运动和内容创作人群；
  3. 承接X系列用户的直出成片需求；
  4. 复用现有配件生态和AI剪辑算法。
  • ACE增速预计快于X系列，但所在赛道竞争更激烈，毛利和价格压力更大。

e)ACE系列的毛利率未来如何变化？

  • 当前毛利率约37%。
  • 随着Pro高端机型占比提高，未来可能提升至38%—39%。
  • 由于需要与大疆Action、GoPro竞争，并通过套装及渠道促销争夺份额，毛利率很难达到X系列约42%的水平。

4.GO拇指相机：差异化拉新产品

a)GO系列的定位和用户群体是什么？

  • GO系列是公司开创的拇指微型相机产品线。
  • 主要定位为佩戴式、第一视角随手拍摄，覆盖：
  1. 亲子记录；
  2. 宠物记录；
  3. 骑行头盔拍摄；
  4. 轻旅行Vlog。
  • 用户中有较多此前未购买过运动相机的普通消费者，因此GO主要承担品牌拉新和降低入门门槛的作用。
  • GO既不是核心基本盘，也不是像ACE一样的主力进攻线，而是差异化产品线。

b)GO系列的出货量和增长趋势如何？

  • 会议中GO历史出货量存在明显口径差异：
  1. 一处提到2025年约40万台、2026年约50万台；
  2. 后续营收拆分口径提到2025年约92万台。
  • 该差异较大，可能涉及出货统计范围或型号归类不同，需进一步核实。
  • 未来增速预计约15%，已由早期爆发期转入温和增长阶段。
  • 增长主要来自亲子、宠物和轻Vlog等轻度用户，但产品本身仍属于小众特色品类，市场规模上限低于X系列。

c)GO系列的价格和毛利率如何？

  • 2025年均价约1500多元，2026年约1600元。
  • 未来价格预计稳定在1550—1650元，官方定价不会明显上涨或下调。
  • 大促期间可能有阶段性折扣，但不代表长期降价。
  • GO系列毛利率约39%，介于X系列与ACE系列之间。
  • 公司在拇指相机领域的全球市场份额领先，竞品较少，价格战压力较低。

5.Luna云台相机：战略新品与份额突破

a)Luna的销量目标和成长空间如何？

  • Luna是公司切入云台相机市场的战略新品，对标大疆Pocket系列。
  • 2026年预计销售40万—50万台，但仍处于新品爬坡和用户教育阶段。
  • 2027年目标约100万台。
  • 之后存在较高增长空间，受访者判断每年增长约50%具备可行性。
  • 大疆同类产品年销量约500万—600万台，公司当前规模仅为其约10%，因此仍有较大的份额提升空间。

b)Luna的价格定位如何？

  • Luna套件价格约3399元，对标大疆Pocket 4约3199元。
  • Luna Ultra价格约3999元，对标大疆Pocket 4P约4099元。
  • 整体价格与大疆竞品接近，部分型号略高或略低，综合差距约100多元。
  • 未来综合均价预计维持在4000元左右，不依赖低价竞争。

c)Luna相较大疆Pocket的核心优势是什么？

  • 可拆卸、分离式遥控屏：
  1. 最远支持约20米高清图传；
  2. 自拍、低角度和远距离机位可实时监看；
  3. 屏幕自带收音能力；
  4. 支持快速切换竖拍模式。
  • 影像规格更高：
  1. 采用1英寸大底和徕卡联合调校；
  2. 支持8K 30fps杜比视界、4K 120帧慢动作和专业Log；
  3. 更强调夜景、人像氛围和专业后期空间。
  • 云台与AI追踪能力：
  1. 云台转动范围更大；
  2. 支持多人锁定和智能构图；
  3. 复用公司在全景防抖和追踪算法方面的积累。
  • 专业创作生态：
  1. 支持电影画幅和10 bit素材；
  2. 可对接专业调色流程；
  3. 面向短视频博主、旅行创作者和影视爱好者。
  • 全景技术复用：
  1. 支持更丰富的全景和后期构图玩法；
  2. 与大疆偏大众随手拍的产品定位形成差异。

d)Luna当前市场份额如何？

  • 大疆在云台相机市场的份额约90%。
  • 公司当前份额约7%—8%，主要因为产品上市时间短、仍处于爬坡期。
  • 若下一年度销量达到100万台，公司份额可能提升至约14%—20%，具体取决于行业总量和大疆销量变化。

e)Luna的毛利率如何？

  • Luna硬件BOM口径毛利率约44%，系列综合毛利约40%以上。
  • 报表实际毛利低于硬件BOM口径，主要因为：
  1. 新品爬坡期的渠道折价和套装促销较多；
  2. 走量款占比较高，高毛利Ultra版本占比尚低；
  3. 专项研发和达人投放不包含在硬件BOM毛利中。
  • 随着促销收缩和高端版本占比提升，Luna系列毛利有望逐渐稳定。

6.全景无人机与其他消费设备

a)全景无人机目前的销量、价格和盈利水平如何？

  • 全景无人机于上一年度末上市，2026年预计销量约12万台。
  • 产品售价约6000元。
  • 全球无人机行业年销量接近900万台，公司份额仅为个位数，约1%—2%。
  • 当前硬件毛利率较低，约10%—15%。
  • 低毛利主要源于：
  1. 销量规模较小；
  2. 飞控和供应链能力仍在搭建；
  3. 整机BOM较高；
  4. 新产品研发和用户教育投入较大。

b)公司为何仍将继续投入全景无人机？

  • 产品定位是开辟沉浸式全景航拍赛道，不是与大疆常规航拍无人机直接正面竞争。
  • 公司将继续投入，但会根据产品验证结果控制节奏。
  • 随着销量提升和BOM摊薄，毛利率才有修复空间。
  • 如果市场验证不及预期，公司将放缓投入。
  • 会议中下一年度销量目标存在“4万、7万或8万台”等模糊口径，与当年约12万台数据不一致；2028年目标约20万—30万台，相关数据需进一步确认。

c)全景无人机未来的价格会如何变化？

  • 当前版本的挂牌价预计保持稳定，主要通过阶段性大促促销。
  • 后续新款仍将保持高端定位，并可能通过新品升级实现提价。
  • 老款将逐步清理库存，长期价格提升主要依靠产品迭代，而非当前型号直接涨价。

d)其他消费级设备的规模和定位如何？

  • 其他消费设备包括稳定器、Link摄像头、麦克风和音频产品等。
  • 2026年预计出货30万—40万台，裸机均价约1100元。
  • 下一年度基准销量约40万台，之后预计保持15%—20%的增长。
  • 均价预计维持在1050—1150元。
  • 毛利率约40%。
  • 该业务主要补充产品生态，Follow稳定器承担走量，高单价摄像头和音频产品销量相对较小。
  • 配件不计入该分类；配件均价较低，但毛利率较高，约55%。

7.专业级业务与B端解决方案

a)专业级业务具体包括哪些内容？

  • 商用全景相机和空间采集设备：
  1. 用于工地测绘、房产看房、门店漫游和数字展厅；
  2. 服务于房产服务商、工程数字化企业和VR服务商。
  • 行业解决方案及软件服务：
  1. 包括空间云台、采集套件、空间拼接软件和私有化SDK；
  2. 支持客户搭建看房、巡检系统及进行二次开发。
  • VR沉浸式内容项目：
  1. 包括文旅景区、展馆等固定区域的全景拍摄部署；
  2. 采用项目制交付，而非标准化硬件销售。
  • 车载空间记录方案：
  1. 面向商用车和特种车辆；
  2. 用于车队巡检、渣土车和工程车监控；
  3. 目前仍处于拓展阶段。

b)专业级业务的发展趋势如何？

  • 该业务营收占比较低，预计维持相对稳定。
  • 毛利率较好，但存在两项特征：
  1. 项目订单波动大于消费级产品；
  2. 项目交付周期更长。
  • 短期内不会成为公司最主要的增长来源。

8.综合毛利率、存储成本与库存管理

a)公司2026年综合毛利率预计处于什么水平？

  • 前三季度综合毛利率约38.2%。
  • Q3单季度毛利率约33.7%，压力较大。
  • 全年综合毛利率预计约36%—37%，大概率处于本轮毛利率下行的底部。
  • 毛利率下降主要由三方面导致：
  1. 存储芯片涨价，推高BOM成本；
  2. 高毛利X系列收入占比下降，ACE、Luna和全景无人机等新品占比上升；
  3. 大疆竞争和大促期间渠道折扣增加，实际结算价格承压。
  • 配件毛利率接近55%，可以对冲部分压力，但收入占比较低，托底作用有限。

b)各产品线的毛利率大致如何？

  • X系列：约42%；
  • ACE系列：约37%，未来可能提升至38%—39%；
  • GO系列：约39%；
  • Luna：硬件BOM口径约44%，报表综合口径低于该水平；
  • 全景无人机：约10%—15%；
  • 其他消费设备：约40%；
  • 配件业务：约55%。

c)存储芯片在各产品BOM中的占比如何？

  • 2025年，DRAM加内置UFS占整体BOM约5%。
  • 2026年存储涨价后，占比明显提升：
  1. X系列约10%—20%；
  2. GO系列约17%；
  3. ACE系列约15%；
  4. Luna约18%；
  5. 全景无人机约15%。
  • X系列因实时拼接和高码率录像，对内存带宽要求最高。
  • Luna采用1英寸大底和8K高码率方案，存储规格也较高。

d)公司为何在上半年大规模采购存储芯片？

  • 2026年上半年存储采购规模接近20亿元，上一年度仅约4亿—5亿元。
  • 金额增长由量价共同驱动：
  1. 现货价格上涨，同等采购量需要更多资金；
  2. 公司主动将备货周期由正常的2—3个月延长至约9个月。
  • 公司希望提前锁定价格和货源，库存余额因此由约3亿—4亿元增加至10多亿元。
  • 现有部分存储库存至少可支持8—9个月生产使用。

e)存储库存是否存在减值风险？

  • 下半年公司未继续大规模囤货，主要消耗上半年库存。
  • 公司按季度进行存货减值测试，前三季度已计提约1.3亿元存货跌价损失。
  • 后续策略为：
  1. 若存储价格进入下行通道，缩短备货时间并随用随采；
  2. 不再维持大额前置库存；
  3. 只有供需再次紧张时，才重新考虑锁价备货。

f)Q3毛利率大幅下降的核心原因是什么？

  • Q3存储价格仍在上涨，但涨幅已经收敛：
  1. DRAM环比上涨约13%—18%；
  2. NAND环比上涨约10%—15%。
  • 上半年锁价采购的存储已经在Q3投料，因此现货涨价不是Q3毛利率大幅下降的核心增量因素。
  • 核心原因是产品结构变化：
  1. Luna在6月上市后于Q3集中贡献收入；
  2. 全景无人机进入实际放量阶段；
  3. ACE继续保持高增长；
  4. 上述产品毛利均低于X系列，稀释了整体毛利率。
  • 此外，渠道折扣、套装折价和阶梯返利会冲减收入，进一步压低毛利率。
  • 存货减值计提也对财务报表口径的毛利形成拖累。

g)营销促销支出如何影响毛利和净利润？

  • 直接影响毛利率的项目包括：
  1. 渠道出厂折扣；
  2. 阶梯返利；
  3. 套装捆绑折价；
  4. 直接降价促销。
  • 上述项目会冲减营业收入，从而压低毛利率。
  • 不影响毛利率、但影响净利润的项目包括：
  1. 达人返佣；
  2. 平台广告投放；
  3. 直播坑位费；
  4. 达人样品；
  5. 推广服务费。
  • 这些项目计入销售费用，不计入营业成本。

h)未来几个季度毛利率如何演变？

  • Q4毛利率预计约37%，较Q3有所改善，但只能视为止跌企稳，尚非明显反转。
  • 下一年度Q1有望温和修复至约38.5%。
  • 下一年度Q2修复力度可能更明显，有望达到约39%。
  • 修复逻辑包括：
  1. 上半年锁价存储继续投料；
  2. NAND价格可能逐步松动；
  3. Luna等新品规模扩大后摊薄BOM；
  4. 高端型号占比提高。
  • 压制因素包括：
  1. Luna和无人机等相对低毛利产品继续放量；
  2. DRAM价格仍有韧性；
  3. 大疆新品和渠道促销可能打断修复节奏。
  • 综合毛利率预计呈阶梯式、渐进式修复，较难回到历史上42%—45%的高水平。

9.费用率与经营杠杆

a)研发费用率未来会如何变化？

  • 当前研发费用率约16%—17%，处于阶段性高点。
  • 高投入主要来自：
  1. Luna云台相机；
  2. 全景无人机；
  3. 自研芯片；
  4. AI追踪和端侧算法；
  5. 空间采集B端方案。
  • 未来研发投入绝对金额仍会增长，但随着收入规模扩大，费用率预计回落：
  1. 下一年度约14.5%；
  2. 2028年约14%。
  • 公司不会削减全景、防抖和空间算法等核心底层研发预算，但预计不会同步新增大量全新产品线。

b)销售费用率未来会如何变化？

  • 2026年销售费用率约17%，主要由Luna用户教育、达人种草、海外平台广告和渠道建设拉动。
  • 后续销售投入绝对金额仍可能增加，但将转向ROI考核，压缩低效投放。
  • 2027—2028年销售费用率预计控制在18%以内，不再持续上升。
  • Luna度过导入期后，达人种草的边际需求将下降；X和GO等成熟产品的营销投入也会相对克制。
  • 若大疆推出重磅新品并增加营销，公司可能被迫跟进，销售费用率存在阶段性反弹风险。

10.行业渗透率、竞争格局与价格战

a)行业渗透率是否已经接近天花板？

  • 行业整体尚未达到渗透率天花板。
  • 手持智能影像设备在全球无人机用户中的渗透率不到2%，在国内短视频活跃用户中的渗透率约3%—4%。
  • 各细分赛道情况不同：
  1. 全景相机市场较小、天花板相对清晰，但尚未触顶；
  2. 云台相机渗透率相对较高，且大疆份额接近90%，属于红海市场；
  3. 运动相机和拇指相机仍在向亲子、宠物和轻度创作用户渗透。

b)价格战的根源是什么？

  • 价格战并不是行业总量见顶，而是两家头部企业相互进入对方的优势赛道：
  1. 大疆通过Osmo 360进入公司的全景基本盘；
  2. 公司通过Luna进入大疆占优的云台相机市场；
  3. ACE与大疆Action正面竞争；
  4. GO与大疆同类轻量化产品形成竞争。
  • 行业规模仍在以约10%—20%的速度增长，但双方不仅争夺新增用户，也争夺对方的存量份额。

c)当前价格战是否已经结束？

  • 官方指导价层面的激进价格战基本缓和，双方更倾向于传导存储成本、稳定挂牌价。
  • Q4双11、黑五期间仍存在套装优惠、渠道返利和礼包赠送，但属于季节性促销，不等同于新一轮长期降价。
  • 分产品看：
  1. X系列壁垒较强，促销相对克制；
  2. ACE和Luna直面大疆竞争，促销力度更大；
  3. 全景无人机竞品较少，促销压力相对有限。

d)未来价格竞争是否还会反复？

  • 价格竞争预计呈现“阶段性缓和、再度加剧”的脉冲式特征。
  • 新品集中发布时，竞品可能通过降价、返利和渠道投放进行针对性压制。
  • 新品周期结束后，在存储成本压力下，双方会重新守住挂牌价。
  • 长期行业仍有望保持15%—20%的复合增长，但双龙头份额争夺将长期存在，加权毛利率较难回到过去的高水平。

11.专利诉讼与禁售风险

a)大疆申请停止销售Luna，是否存在全面禁售风险？

  • 大疆诉讼请求中包含停止销售禁令，但在国内全面禁售Luna的概率较低。
  • 当前主要诉讼涉及：
  1. 云台控制；
  2. 可拆卸遥控屏；
  3. 外观相关专利。
  • 美国案件曾程序性撤诉，但未来仍可能重新发起；当前主要案件由深圳中院审理。

b)临时禁令和永久禁令的风险有何不同？

  • 临时禁令：
  1. 要求在审理前立即停止销售；
  2. 申请门槛很高；
  3. 需要证明侵权高度确定且不禁售将造成无法弥补的损失；
  4. 当前获批概率较低，产品正常销售暂不受影响。
  • 永久禁令：
  1. 只有在终审认定侵权且专利有效后才可能出现；
  2. 即使败诉，也更可能通过修改功能模块规避，而非整机直接退市。

c)公司采取了哪些应对措施？

  • 向国家知识产权局提出涉案专利无效宣告请求。
  • 对大疆提起反诉，增加谈判筹码。
  • 准备硬件和固件层面的规避版本，必要时调整云台控制和功能交付逻辑。
  • 最终可能通过交叉授权、和解或功能改版解决。
  • 国内更现实的风险是：
  1. 部分功能受限；
  2. 支付赔偿；
  3. 增加法务、研发和改版成本。
  • 海外市场对禁令的支持概率相对更高，因此海外诉讼风险高于国内。

12.端侧AI与AI眼镜布局

a)公司端侧AI的主要投入方向是什么？

  • 端侧AI主要分为两条路线：
  1. 现有相机产品的算法升级；
  2. 主打第一视角拍摄的AI眼镜。
  • ACE等产品已经搭载自研端侧模型，支持：
  1. AI识别；
  2. 自动挑选精彩镜头；
  3. 智能剪辑；
  4. AI追踪；
  5. 降噪和画质增强。
  • 公司有约2亿—3亿元的端云一体化研发项目，目标是将轻量化生成模型部署至相机端侧。
  • 端侧AI将逐步成为X、Luna、ACE等新品的标配，是确定性最高、优先级最高的投入方向。
  • 空间采集业务初期将对接外部大模型，长期目标是运行自研轻量化端侧模型，实现本地推理。

b)AI眼镜的定位与市场上现有产品有何不同？

  • 公司AI眼镜定位为头戴式影像采集设备，而非通用语音助手。
  • 核心场景是创作者免手持的第一视角拍摄。
  • 产品设计方向包括：
  1. 分体电池；
  2. 可更换镜框；
  3. 第一视角影像采集；
  4. 空间重建；
  5. 端侧全景拼接。
  • 相关能力可复用公司在相机和全景算法方面的积累。

c)AI眼镜何时可能上市？

  • 产品已有样机，但仍处于研发和验证阶段。
  • 最早可能在下一年度末或2028年小批量上市。
  • 初期市场规模预计较小，毛利压力较大，孵化逻辑与全景无人机类似。
  • 公司会持续投入验证，但不会全面铺开；若原型体验不及预期，投入节奏将放缓。
  • 短期内AI眼镜不会成为公司的主要营收来源。

提问者：除营销费用外，是否还有部分支出计入营业成本？Q3单位营业成本有所上涨，但财务报表中的部分支出以费用化形式处理，不计入毛利。促销等支出究竟是费用化，还是实际计入成本？影响毛利的核心因素是什么？

回　答　者：主要涉及以下方面：达人返佣、平台广告投放、直播坑位费、达人样品以及推广服务费，均计入销售费用并进行费用化处理，不影响毛利率，只影响净利率。

给予渠道的出厂折扣、阶梯返利、套装捆绑折价及直接降价促销，会直接冲减营业收入。收入减少会直接压低毛利率，但这些项目不计入营业成本。

平台年框返现、抖音和淘天广告投放、达人佣金及种草推广费，均归类为销售费用，营业收入和营业成本不变，因此毛利率不变，但会在费用端影响利润。

毛利只与营业收入和营业成本相关，研发、营销等费用不计入营业成本，因此不会影响毛利。Q3毛利率下降，一方面是投料所使用的存储现货成本处于高位；另一方面是露娜全景无人机的单位成本更高。随着毛利率更低的新品收入占比提升，整体加权营业成本被拉高。挂牌售价没有变化，但渠道返点后的售价会压低确认的营业收入。
