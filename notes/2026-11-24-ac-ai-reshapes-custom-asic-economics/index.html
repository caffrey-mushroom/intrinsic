正文

随着大模型工程推理、代码生成及工具调用能力持续提升，AI 正在从软件开发走向芯片设计。模型不仅能够辅助工程师编写 RTL、完成验证，还开始参与微架构优化、物理设计以及底层 Kernel 开发。

笔者认为，AI 与 RSI 对自研 ASIC 的影响，可以从开发速度、性能改善、小团队设计和 Kernel 迁移四个维度理解。这些进展共同提高了大模型公司和 CSP 自主开发芯片的经济性，使其能够逐步掌握更多设计、制造采购和软件优化环节。

更长期看，随着模型能力持续进步，芯片设计本身也可能形成新的反馈循环：更强的模型帮助设计更高效的芯片，更高效的芯片又为下一代模型研发提供更多计算资源。这一过程受到制造与量产周期约束，但其长期影响值得动态评估。

一、开发速度：九个月流片，ASIC 产品迭代有望加快

过去，自研 ASIC 面临的重要问题之一，是芯片开发周期与模型迭代速度之间的错配。模型架构及推理方法持续变化，而先进芯片从设计、验证到实际部署通常需要较长时间。即使专用芯片具有潜在成本优势，也可能在量产时落后于新一代 GPU。

OpenAI 的 Jalapeño 提供了一个重要案例。根据 OpenAI 硬件负责人 Richard Ho 的披露，Jalapeño 于2024年10月开始架构构思，2025年2月启动 RTL 设计，同年11月完成 Tape-out，2026年5月获得首批实体芯片。

图表1｜Jalapeño 从立项到实硅的开发时间线

注：九个月指 RTL 启动至 Tape-out，覆盖前后端设计与签核，不包含其后的制造、封装及回片。

Richard Ho 表示，传统同类芯片的设计周期通常需要18—24个月。Jalapeño 将这一阶段压缩至九个月，缩短约50%—63%。这九个月覆盖了芯片的前端和后端设计，而不仅是 RTL 编码。

前端主要包括架构、RTL、逻辑实现及功能验证。由于大量工作涉及代码编写、测试和调试，AI 可以直接参与自动化开发，并通过验证结果形成反馈循环。后端则包括逻辑综合、Floorplan、布局布线、时序及功耗收敛。AI 同样能够调用 EDA 工具，搜索和优化不同的物理实现方案，但仍需要满足工艺和物理签核要求。

Jalapeño 由 OpenAI 负责计算架构和核心设计，Broadcom 提供物理实现、接口 IP 及工程支持。双方借助 AI 与成熟设计平台协同开发，最终实现九个月流片。从开发流程看，AI 最直接加速的是流片前的设计和验证；晶圆制造、先进封装及回片测试仍受到物理工艺与供应链约束。

开发周期缩短能否让 ASIC 追上 NVIDIA 的产品节奏，是另一个问题。NVIDIA 的 Hopper、Blackwell、Rubin 大架构大致以两年为周期演进，中间通过 H200、Blackwell Ultra 等升级保持年度更新，但 NVIDIA 是多个架构并行研发，而不是每年从零开始。与此同时，NVIDIA 也在使用 AI 加速芯片设计和验证。Cadence 披露，在其与 NVIDIA 的特定 RTL 验证流程中，AI agent 将原本约五周的验证循环压缩至不足一天。

因此，九个月流片并不能直接证明 ASIC 相对 NVIDIA 的研发速度优势已经形成。笔者认为，更确定的变化是：AI 缩短了自研 ASIC 的开发周期，降低芯片因模型架构变化而落后的风险，使大模型公司和 CSP 能够更加频繁地迭代专用硬件。

二、性能改善：AI 开始直接优化芯片 PPA

AI 对芯片设计的价值不只是节省研发时间，还包括直接改善功耗、性能和面积（PPA）。

OpenAI 于11月18日披露，在 Jalapeño 的设计中，模型通过重新组织浮点运算、低精度计算和流水线结构，使 Vector Unit 的标准单元面积降低约13%，Matrix Unit 降低约10%。这些优化已经通过实硅验证。

OpenAI 与 AMD 的合作更进一步。在 AMD 经过多年优化的旗舰 GPU IP 上，模型通过重写 SystemVerilog RTL，实现最高14%的局部 PPA 改善，并在不到五个月的时间内取得传统研发约一年的进展。AMD 已将部分改动应用于送交制造的设计，另一些则进入后续产品的正式设计文件。

OpenAI 还使用开源 RISC-V 处理器评估多代模型的芯片设计能力。在优化既有 PicoRV32 RTL 的任务中，GPT-6.2 Astra 在约11.2万个 Token 的可比预算下，平均得分达到 GPT-6 Astra 的约两倍。

图表2｜模型代际与推理预算提高，既有 RTL 优化能力增强

注：横轴为加权 Token 预算（对数轴），纵轴为平均归一化得分。按 OpenAI 原始公开曲线重绘，曲线点位为视觉估读，非公布的原始序列数据。

上述测试反映，在相近推理预算下，新一代模型取得了更好的设计优化结果。随着模型推理能力和可用计算预算提高，芯片工程师能够探索更多实现方案，并对既有计算单元展开更深入的优化。

对于大模型公司和 CSP，自研 ASIC 可以围绕自身模型及工作负载进行设计，例如矩阵运算、片上存储、KV Cache、Prefill/Decode 以及芯片间互联。AI 不仅可能降低研发成本，还可能提高每单位面积与功耗所能提供的计算能力，进一步改善专用芯片的单位经济性。

三、小团队设计：大模型公司和 CSP 可以掌握更多研发工作

先进 ASIC 设计过去需要大量专业工程师，涵盖架构、RTL、验证、物理实现、封装和软件等多个领域。建立完整团队的时间和成本，是自研芯片的重要门槛。AI 正在降低这一门槛。

OpenAI 的硬件团队约100人，通过与 Broadcom 合作完成 Jalapeño。Anthropic 则组建了约15人的芯片设计团队，开始使用 Claude 参与定制芯片研发。这些案例说明，模型公司可以用相对较小的核心团队承担更多架构、RTL 和验证工作，同时通过合作伙伴获得物理实现、关键 IP 和量产交付能力。

OpenAI 的另一项 RISC-V 测试对此提供支持。在这项任务中，模型不再只是优化既有 RTL，而是根据书面设计规格，自行决定处理器的数据流和流水线结构，再生成相应电路设计。在约11.2万个 Token 的可比预算下，五个受测模型在这种从规格出发的任务中，得分均高于修改既有设计的任务。

注：横轴为加权 Token 预算（对数轴），纵轴为平均归一化得分；分数基于测试吞吐量。按 OpenAI 原始公开曲线重绘，曲线点位为视觉估读。

从已有 RTL 的局部优化，到根据规格完成更完整的设计，模型能够承担的工程任务正在扩大。这对大模型公司和 CSP 的意义，不只是减少工程师数量，而是使客户有能力重新划分内部设计与外部采购的边界。

过去需要外部 ASIC 设计服务商完成的部分工作，未来可以逐步由客户自己承担，外部合作伙伴则更多集中于关键 IP、物理实现和量产服务。Google TPU 的长期自研经验已经展示了这种模式，而 LLM 有望降低其他大型客户建立类似能力的时间和成本。

四、Kernel 迁移：CUDA 的软件壁垒开始下降

芯片设计之外，软件一直是自研 ASIC 面临的另一道门槛。NVIDIA 不仅拥有 GPU 性能优势，还拥有 CUDA、编译器、通信库和长期积累的高性能 Kernel。客户即使采购了更便宜的硬件，也需要投入大量工程资源完成迁移、调试和性能优化。AI 正在改变这一过程。

Anthropic 在 IPO 路演中披露，Claude Mythos Preview 约用三天时间，将一个 Anthropic 模型的 Prefill 部分适配到 AMD MI355X，编写或移植几乎全部相关 Kernel，并达到可用性能水平。Anthropic 认为，按照传统方式，类似新硬件适配工作需要数十名工程师工作数月。

OpenAI 同样使用 AI 开展 Kernel 优化和新硬件适配。在生产推理系统中，AI 辅助的 Kernel 优化已经带来实际服务成本下降；在 Jalapeño 上，也帮助更快支持新的模型。

对大模型公司及 CSP 来说，关键在于它们主要需要支持自身的模型和工作负载，而不必复制 NVIDIA 完整的 CUDA 生态。因此，AI 对 Kernel 开发效率的提升，可以更直接地转化为替代硬件的部署能力。当芯片设计更快、PPA 更好、软件迁移又更容易时，自研 ASIC 的投入产出关系就会持续改善。

五、从700亿到200亿美元：更多芯片价值回到模型公司和 CSP

Sam Altman 在10月底的 Cheeky Pint 访谈中，提出了一个长期算力降本目标：希望将每GW算力部署和使用五年的总成本，从约700亿美元的参考水平降至200亿美元，对应约71%的成本下降空间。

实现这一目标，需要芯片、系统架构、软件效率以及基础设施等多个环节共同进步。而大模型公司和 CSP 自主参与芯片设计，正是其中的重要路径。

从实际合作模式看，OpenAI 与 Broadcom、Google 与 MediaTek 已经呈现出不同的价值分配方式。

OpenAI–Broadcom 模式下，OpenAI 掌握计算架构和核心设计，Broadcom 负责物理实现、关键 IP、互联和量产支持。OpenAI 已将更多前端设计能力留在内部，但在后端和系统集成方面仍较多依赖外部合作伙伴。

Google–MediaTek 模式则更进一步。根据产业链调查，Google 在 TPU v8t 项目中完成 Compute Die 的前端及后端设计，并直接采购 HBM、委托台积电制造；MediaTek 主要负责 I/O Die、SerDes、封装整合及相关量产工作。这意味着 Google 从过去更完整的 Turnkey 合作模式，进一步将计算核心设计和采购控制权掌握在自己手中。

两种模式的利润分配也可能不同。根据笔者此前的 TPU 成本情景测算，Broadcom 传统 Turnkey 合作模式的毛利率假设约为55%—60%，而 MediaTek 在 Google 自主设计模式下所承担业务的毛利率假设约为40%。由于双方承担的工作范围不同，这些假设主要体现客户设计与采购自主程度提升后，外部合作模式及价值分配可能发生的变化。

这一过程还可能随着 RSI 持续加速。模型能力提高，使大模型公司和 CSP 能够用更小的团队、更短的时间完成更多设计工作，并持续优化芯片性能与软件效率。随着设计和验证能力增强，客户可以进一步接回过去依赖外部供应商的工作，重新划分设计、IP、制造与封装之间的经济价值。

与此同时，更高效的自研 ASIC 又能够降低模型训练和推理成本，为后续研发提供更多算力。AI 对自研 ASIC 的推动，可能不只是一次性的研发提效，而是随着模型能力进步而持续扩大的动态过程。

对大模型公司和 CSP 而言，长期价值不仅在于用 ASIC 替代多少 NVIDIA GPU，更在于它们能够逐步掌握多少芯片设计、系统优化和采购价值，将原本由外部供应商获取的部分利润留在内部。

笔者认为，随着 AI 与 RSI 持续进步，自研 ASIC 的开发门槛和单位成本有望进一步下降，大模型公司和 CSP 在整个算力价值链中的控制力将持续增强。这是理解未来算力成本从700亿美元向200亿美元演进的重要方向。
