\\*专家观点\\*

鉴于有报道称Anthropic的IPO推迟至11月，从销售角度来看，这对客户沟通以及2026年Q4的签约节奏产生了哪些观察到的影响？

从销售的角度来看，IPO推迟到11月第一周之后并未引发任何动荡。贡献于AnthropicARR的销售目标和预期收入预测均保持不变。数周的延期并未导致任何销售活动停滞。客户的主动咨询兴趣持续增长，他们正通过自助服务门户、LinkedIn以及电子邮件等渠道与Anthropic取得联系。来自客户方面的压力并未显现，Anthropic也没有观察到收入生成曲线出现任何负面变化。

目前客户正在规划2027年的预算，关于支出增长的普遍情绪如何？他们又是如何看待AI投资的，特别是在ROI和模型使用方面？

在通常于10月和11月进行的2027年初期预算讨论中，大型企业客户展现出了增加预算的意向。然而，他们采取的是高度务实的混合策略，而非盲目将支出翻倍。这一策略的核心在于严格聚焦ROI以及具备成本效益的模型路由。企业IT和财务团队正从大额的前期财务承诺转向更为精细化的策略。他们计划在处理复杂任务时采用具备高推理能力的高端模型（如Opus和Sonnet），同时借助中国开源模型等其他选项来应对较为基础的任务。这种混合模式是Anthropic讨论的核心议题，Anthropic也在向客户推介包括Haiku和Sonnet在内的全套模型能力。此外，企业意识到每个季度都会推出性能更强的新模型，从而能进一步实现工作流的自动化，并促进从基础Chatbot向自主Agent的转型，因此他们正在实施季度固定预算。在截至2027年4月的阶段内，客户要求采取务实的方式，为特定工作流分配固定预算，以便更明确地界定未来的ROI。尽管2027年的预算在增加，但这些核心客户在充分利用AI方面变得更加成熟，他们设置了预算上限来控制全天候运行的自主Agent所带来的成本，并审慎评估不同业务的风险因素和投资回收期。

能否详细解释一下企业客户目前采用的“按季度固定预算”这一概念？

按季度固定预算是客户在2026年剩余时间内用于管理和优化其AI支出的策略。例如，一家使用Anthropic模型进行AML（反洗钱）和KYC（了解你的客户）审核的一级银行，希望为10月至12月期间设定支出上限。他们要求建立月度监控和预警系统，以确保不会超出这一预定预算。其主要动机是从今年的预算中节省资金，并将其重新分配给2027年的AI项目。这种在季度内实施月度支出上限的趋势在各个垂直行业中均有体现。它使企业能够确保资金用途得当，防止自主智能体（autonomous agents）无节制地消耗Token，或员工低效使用模型。在遵守合同约定的最低消费的同时，客户计划在2027年1月对其进展进行评估。对2026年最后三个月的评估将为即将到来的一年制定更有条理的规划提供依据。其核心目标是形成一份平衡的ROI（投资回报率）报告，从而为2027年从其他部门重新分配给AI的不断增长的预算提供合理支撑。这一趋势并非Anthropic客户所独有，Mistral AI和OpenAI等竞争对手在其企业客户中也面临类似情况。

考虑到预算上限的实施和ROI等考量因素，预计2027年不同行业客户预算的百分比增长情况如何？

2027年的预算增幅因垂直行业而异。FSI（金融服务业）、医疗保健和制药行业预计将居于领先地位，其次是公共部门、零售、电子商务和法律等其他行业。

在IPO以及引入季度报告义务后，企业客户的采购流程预计将发生怎样的演变？

IPO之后，采购流程将出现轻微但并非剧烈的变化，主要表现为灵活性降低。虽然现有合同不会一夜之间发生改变，但季度报告的要求以及上市公司的监管职责将促使运营层面的调整。在作为一家私有制初创公司时，Anthropic经常会同意定制化的服务等级协议（SLA）、量身定制的法律责任豁免条款以及非标准化的Token定价，以争取知名标杆客户。这种灵活性未来将有所收敛。Anthropic的销售团队将受到更严格的收入确认规则的约束，承销商和财务审计人员也将要求采用标准化合同，以准确预测未来的收益情况。因此，CIO们可能会发现Anthropic的续约流程灵活性有所下降。以往为了吸引关键大客户入驻而提供大幅折扣的做法将受到限制。此外，客户的第三方风险管理团队在批准数百万美元的合同前会进行深入的财务健康状况审查，他们将发现Anthrop ic的财务状况更加透明和稳健，这应会简化他们的尽职调查流程。这些变化——包括更加平衡的谈判地位以及对风险状况的更加重视——目前已经开始推行实施。

您如何拆解 Anthropic 2026年 ARR 增长的核心驱动因素？预计这些因素的贡献在2027年将发生怎样的转变？

在2025年，Anthropic的 ARR 增长主要由现有客户账户内的深度拓展驱动，而非新客户（new logos）拓展。云服务提供商（CSP）发挥了关键作用，带来了60%至70%的新客户，因为客户可以使用现有的云额度，从而绕过冗长的采购流程。其余业务则来自其他渠道，如 ODE、GSI以及Anthropic的直销团队，其中自助服务门户（self-service portal）贡献显著。展望未来，战略转型正在推进。虽然Anthropic预计来自 CSP的客户规模在2027年将保持稳定，但Anthropic正积极提升直销渠道的贡献。Anthropic大幅增加了人员编制，特别是在 GTM 团队中，并从 OpenAI 和 Mistral AI等竞对处招募人才。2027年第一季度的目标是实现新客户拓展渠道的对半开：50%来自 CSP和其他合作伙伴，剩余50%来自Anthropic的直销业务及自助服务门户。随着Anthropic为进入公开市场做准备，这一举措至关重要，Anthropic的目标是建立强大的直销获客渠道，而非主要依赖合作伙伴。Anthropic已经看到直销团队带来的新客户占比开始上升，预计这一趋势在2026年底乃至2027年将持续增强。

就公司规模和行业重点而言，通过直销渠道获取的新客户具有怎样的画像？

直销获取的新客户主要是大型企业级账户，因为Anthropic的中端市场业务对接是由高盛（Goldman Sachs）、黑石（Blackstone）和 H&F等合作伙伴负责的。近期大多数接洽和签约的客户均来自金融服务与资产管理行业。另一个重要垂直领域是法律服务与合规，对于对数据泄露和幻觉高度敏感的客户而言，Anthropic的 Constitutional AI框架是一项核心差异化优势；Anthropic正顺利与全美排名前100的企业律所展开合作。此外，Anthropic在电信、科技和 SaaS领域也见到了强劲的拓展势头。医疗健康、生命科学和制药行业是一个重要的接洽领域，尽管其采购周期较长，但Anthropic预计该垂直领域将成为Anthropic在2027年的一个关键里程碑。

公司的战略重心又是什么？

战略重心在于客户增长，特别是高价值企业账户的扩张以及基于用量的商业 API 消耗，目标是实现超越个人用户增长的表现。该增长战略的核心是由大型机构构建的高密度变现闭环，而非单纯追求消费级用户规模。

继推出 Opus 5.5 和 Sonnet 5.5 之后，企业客户的计费反馈如何？与上一代相比，完成工作流的实际成本表现怎样？

5.5系列收到的反馈非常积极，主要聚焦于单项任务成本效率。这些模型经过专门设计以优化其“思考”方式，使企业客户能够构建生产级智能体工作流，而无需担心账单失控。Opus 5.5的定价为每百万输入Token 4美元、每百万输出Token 20美元，比其前代产品低20%。由于Opus 5.5的速度也提升了30%，并且能以更少的操作步骤完成复杂任务，企业反映在典型工作负载下其运行成本降低了约40%。然而，一个关键发现是，当将超复杂的推理任务分配给能力较弱的模型（如Sonnet 5.5）时，针对该特定任务，其成本可能会变得比Opus 5.5更高。这是因为它在“思考”上消耗了大量的内部Token。例如，在这类任务上以最大算力投入运行时，Sonnet 5.5生成的单任务总账单可能约为7至8美元，而能力更强的Opus 5.5完成同一任务的费用可能要低1至2美元。之所以出现这种情况，是因为能力较弱的模型在得出答案的思考过程中消耗了更多Token。

在Max、High、Medium和Low这些推理层级中，企业客户最常使用的是哪一个？这种使用是出于主动选择还是基于默认设置？

Sonnet系列模型的使用率最高，占企业总用量的60%。它在高阶智能、生产级速度和成本之间实现了最佳平衡，非常适合大业务量的客户支持自动化、日常后端数据管道以及全栈软件开发。以低成本著称的Haiku模型约占总用量的20%，通常用于高频路由分发、分类筛选、元数据标记以及基础SQL数据库查询。自5.5版本推出以来，旗舰级Opus的使用份额已从企业总用量的12%上升至15%。剩余百分比归属于Fable模型，尽管价格高昂，但该模型用于高难度推理任务。客户经理会积极引导企业客户根据任务选用合适的模型，例如在大多数工作中采用Opus或Sonnet，并将更昂贵的Fable保留给需要其特定能力的场景。

客户使用Anthropic模型完成相同任务的成本，与使用OpenAI的GPT-6 Astra相比如何？

从基础API定价来看，Anthropic的模型在每Token单价上显著低于OpenAI的GPT-6 Astra。Opus 5.5大约便宜60%，Sonnet 5.5大约便宜80%。Astra的定价为输入10美元、输出250美元，而Sonnet 5.5的定价为输入2美元、输出10美元。然而，标价并不能完全代表完成任务的总成本。在企业智能体实际基准测试中，最终账单取决于模型消耗的内部“思考”Token数量。据反映，在某些高度复杂的推理任务中，Astra的成本效益更高。尽管如此，在大多数任务中，Astra预计仍会更为昂贵。该公司目前正在开发一款全新的基准旗舰模型，以便在任务完成成本上与Astra展开更有力的竞争。

Anthropic 的客户项目中各行业分布情况如何，特别是金融、法律和医疗保健领域？过去一年中，这些项目有多少比例已投入生产环境？

技术、软件工程和编程垂直领域始终占据最大份额，占整体业务的 35% 至 40%。金融服务业（FSI）是第二大且增长最快的垂直领域，其份额从 2026 年初的 18% 上升至目前的近 25%。这一增长得益于斩获多张大型 Tier 1客户订单，以及与 Goldman Sachs 和 H&F 组建合资企业共同拓展中端市场。医疗保健、生命科学和制药领域同样增势显著，在相继收购数家大型医疗保健公司以及斥资 4 亿美元收购 Coefficient Bio 后，其份额由年初的12% 扩大至目前的 20%。法律与合规监管领域在同期表现出稳定的线性增长，份额从 8% 提升至 10% 到 12% 之间。在战略招聘以及承诺将 2-3% 的 ARR（仅针对医疗保健和生命科学垂直领域的研发投入就可能超过 30亿美元）投入研发的支持下，FSI 和医疗保健是持续迈向 2027 年的核心发力重点。

在 FSI 和医疗保健领域推进 AI 落地的主要瓶颈是什么？Anthropic 开发了哪些解决方案来解决这些问题？

FSI 和医疗保健领域的首要瓶颈是数据，具体涉及严格的数据隐私法规、复杂的遗留数据库架构，以及极高的推理错误代价。在医疗保健领域，核心挑战包括 HIPAA 合规和数据孤岛。为此，公司推出了 Claude for Healthcare 和Claude for Science，具体方案包括正式签署商业合作协议（BAA），并将 Claude 原生部署在客户的云环境（例如 Amazon Bedrock、Google Vertex AI）中，以确保受保护健康信息（PHI）处于隔离状态。另一项挑战是医疗编码体系的复杂性。解决这一问题的方法是将原生数据连接器集成至 Model Context Protocol（MCP）中，使 Claude 能够将输入数据直接映射到类似CMS 医保覆盖数据库的系统中。在 FSI 领域，主要障碍包括跨多系统快速聚合数据的需求、严格的 AML（反洗钱）法规以及提供金融咨询的法律责任。其中一个关键瓶颈是金融透明度法规所要求的“可解释性”。相应的解决方案是与 FIS联合设计一款金融犯罪 AI 智能体，该智能体执行严格的引文跟踪（citation tracking），从而为每一个得出的结论生成完全可供审计的法律依据链路。针对金融分析师面临的数据聚合效率低下问题，Anthropic 推出了专为Microsoft 365 定制的 Claude 插件以及预构建的 MCP 连接器，实现与 BlackRock 和 Charles Schwab 等平台的直接集成，从而实现分析与报告的自动化。

FSI 和医疗保健领域与数据相关的挑战对企业客户的部署周期和成本有何影响？

数据相关问题显著拉长了部署周期并推高了成本。这些领域的企业客户平均年度部署总成本在 200 万至 2,000 万美元不等。在医疗保健领域，大型客户的部署成本通常在 200 万至 800万美元之间。这些开支主要偏向于基础设施安全、法律合规校准以及数据参数隔离屏障。通过私有云部署搭建满足 HIPAA 标准的环境需要花费 100 万至 200 万美元。通过 MCP 集成电子健康档案（EHR）记录和编码引擎需要另外投入 100万至 300 万美元的专业工程费用。其余的 100 万至 300 万美元通常用于处理海量患者数据所产生的 API 调用费用。FSI 的部署通常更为昂贵，开支在 500 万至 1,800 万美元之间。其中一项重大开销在 400 万至 500万美元之间，主要用于审计链路工程，即构建定制化的安全护栏外壳以确保 AI 的可追溯性，从而满足监管合规要求。在编写任何代码之前，耗时三到六个月的采购流程本身就可能因占用法务、合规和 IT 资源而耗费 50 万至 100万美元。其余成本则是由庞大的 API 消耗所驱动，因为自主金融智能体每天可运行成千上万次后台上下文循环，导致每月产生数百万美元的账单。
