1 总体判断

本期最强的新信号是云厂 2027 年的 CPU 采购量。三个独立来源给的增速都在 45-70%：一位北美 ASIC 专家说超大规模厂 2027 年 CPU 出货约 +55% (D273 L137)；阿里云专家说今年采购 55 万台 CPU 服务器，明年至少 80 万台 (D305 L29, L44)；GUC 专家说 Google 的 Arm CPU 今年已超过 120 万颗，明年至少再增 60-70% (D099 L29)。这和 AMD 讲的 "每年约 50%" 是同一量级。上期调研里还没有能对上的数字。

缺货和涨价比上期说的更严重。Dell 供应链专家说至强和 EPYC 交期约 86 周，高端低端一样紧，明年 CPU 初步再涨 8-18%，大概率接近上沿 (D196 L169, L599)。INTC 已把服务器 CPU 官价提 15%，11 月生效 (D273 L128)。上期渠道预期 2027 年 1 月涨 6-10%，本期上限抬到 18%。反向声音只有一条：一位国内 AI 服务器专家说 CPU 供应 "并不十分紧张" (D004 L49)。

份额上，AMD 的领先在调研里继续扩大，Arm 在云厂自研里放量。阿里云 2026 年 x86 采购里 AMD 22 万台，首次超过 INTC 的 16 万台 (D305 L29)。台湾 CCL 专家说 HP、Dell 新平台订单几乎全是 AMD，INTC 新平台要到 2028 年 Q1 (D233 L75-76)。x86 和 Arm 的数字分歧最大：Evercore 说 Arm 拿下约一半的新增超大规模部署 (D503 L94)，上期调研则说 Agent 负载里 x86 约占 95%。两者口径不同，一个是增量，一个是存量。

Agent 拉动 CPU：本周第一次拿到完整的容量模型，但质疑的声音也最多。Muse 的规划口径是：今天 13 万 DAU 部署 6,000-9,000 个物理核；到 2030 年 1 亿 DAU 约需 2,900 万个持续核 (D269 L42, L65)。同一位专家说，单个用户的 GPU 需求增速会高于 CPU (L46-47)。另有四位专家说每个 Agent 的 CPU 强度被高估了，因为一个物理核可以分时跑多个沙箱 (D020、D070、D369、D265)。量主要来自用户数和企业 Agent 的规模，不来自每个用户用多少 CPU。

口径：服务器 CPU 的需求、供给、价格和份额，包括 Agent / RL 拉动的通用算力、AI 服务器里的 head node 和 CPU:GPU 配比，以及 INTC Xeon、AMD EPYC 和 Arm 服务器 CPU (NVDA Vera、GOOGL Axion、AMZN Graviton、MSFT Cobalt、阿里倚天)。GPU、ASIC 本身、内存价格和 ABF 载板价格不算。

本期发生了什么：窗口是 10/15-10/21，共 7 天。528 篇纪要里 156 篇提到 CPU 关键词，26 篇有能用的具体内容，其中 7 篇以 CPU 为主题。事件有三件。10/16 TSM 三季报，管理层说 Agentic AI 用的 CPU 在增加硅需求，而且它 50% 中高段的 AI 加速器 CAGR 不含服务器 CPU (D091 L39, L41)。INTC 服务器 CPU 官价 +15% 在 11 月生效 (D273)。AMD 在 OCP 后推出纯 CPU 的 Helion Agent 机柜，最多 32,768 个 Zen 6 核 (D094、D439)。

最重要的分歧有两个。第一是价格涨多少：Evercore 的渠道调研说服务器 CPU ASP 今年上半年每季涨 10-15%、下半年每季涨 15-20% (D503)，复利下来全年约 +60-90%；Dell 和 INTC 的口径是 +15% 和明年 +8-18%。第二是 Arm 拿走多少：看增量部署接近一半，看存量负载不到一成。

证据限制：Acecamp 专家大多不写身份，视角偏中国和阿里云。Evercore 的数字来自 TMTB 的二手转述。Dell 专家的 x86:Arm 比例口径未说明。本周没有 INTC 或 AMD 财报。
