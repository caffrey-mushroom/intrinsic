今天的主线

选举后的第一轮量化出来了。SemiAnalysis 逐个查许可，认为约 5.8GW 原定 2027 至 2028 年上半年上线的容量会延迟，约 90% 在得州，最大的一块是 SpaceX 的两个园区 (约 3GW)，其次是 Vantage Stargate、Crusoe 给微软的 Abilene 楼和 Anthropic 的 TPU 园区。他们的结论是 "AI 交易下调但没结束"：供给变紧会拉长周期，已有容量的超大云和 Neocloud 受益，GPU 比 ASIC 先被砍，内存、半导体设备和纯美国工业股受损。ERCOT 一位电力合作社副总裁补充说，最先落地的风险是对临时燃气机组的排放限制。

内存是今天信息最密的一层。你自己的 Merit 访谈给出手机长协价路线：DRAM 2026Q4 涨 6–10%、2027Q2 降到 0–5%，NAND 2027Q1 已经开始转负；新增产能 80–90% 先给服务器，低端手机 BOM 里存储从 15–18% 涨到约 40%，需求已经被压住。Third Bridge 两场访谈方向一致：HBM 2027 年 ASP 还要涨 120% 以上、DDR4 缺口超 20%，但消费级 NAND 在 Q3 见顶。SemiAnalysis 则提醒，若数据中心延迟，HBM 晶圆转回通用 DRAM 能多出 3.5–4 倍比特，价格在各情景下都会下降。

需求侧有两条新读数。FUNDA 的 LLM 季报说前沿模型已变成 "4+1" 竞争，次旗舰价格收敛到 $4/$20，实际 token 单价比 3 月低约 40%，头部实验室约 70% 算力不用于付费推理；Anthropic Q3 收入环比 +45%。分销商说服务器 CPU 下季度再涨 10–15%，大容量 HDD 已配额到 2028 年。和硕的人讲 ODM 格局：鸿海每年约 2 万柜英伟达整柜，整柜九成以上价值是英伟达芯片和内存。

你的 Merit 访谈：手机存储长协价、BOM 红线和国产替代 ↗

Merit · 11/05 · 你自己的专家访谈 · MemoryDRAMNAND

把 "内存涨价何时到头" 拆成了季度价格路线和手机厂商的承受红线，和 11/04 的原厂长协访谈可以对照着看。

  • 手机长协价环比：DRAM 26Q3 +8–13%、Q4 +6–10%、27Q1 +4–7%、27Q2 +0–5%；NAND 26Q4 +0–5%、27Q1 -2–2%、27Q2 -5–0%
  • 本轮由需求拉动和产能转向服务器驱动，新增产能约 80–90% 先给服务器，消费电子价格可能高到 2027 年甚至 2028 年上半年
  • Q4 均价：LPDDR5X 约 $1.60–1.70/GB，长鑫比三星低 5–8%；三星 236 层 UFS 3.1 约 $0.27–0.28/GB，长存低 7–10% 且 Q4 基本不涨
  • 低端机 BOM 中存储占比从 15–18% 升到约 40%，国内需求从 26Q2 末开始被明显抑制，厂商在减配 (12+256 改 8+256)、减产
  • 国产品牌用长鑫、长存的比例普遍超过 20%，较往年翻倍；长鑫 G5 良率约 40–50%
  • 苹果传闻以 DRAM $2/GB、NAND $0.33/GB 锁定三星 27Q1 产能：专家认为锁量可信、锁价存疑

SemiAnalysis：蓝色浪潮怎样冲击数据中心建设 ↗

SemiAnalysis · 11/04 · Core Research · Datacenter政策个股影响

第一份把选举结果映射到全产业链的清单，后面几周所有模型都会按这个框架更新。

  • 约 5.8GW (2027 年 4.3GW、2028 上半年 1.5GW) 有关键许可缺失或暂停，约 5.2GW 在得州，最常见的缺口是现场发电的空气许可
  • 从可能过剩转向偏紧，周期拉长；超大云 FCF 更早转正，Amazon 得州敞口最低，Neocloud 首选 Nebius
  • GW 削减先砍 GPU：Anthropic 和 OpenAI 都优先用 ASIC，英伟达是边际供应商
  • 若推迟，约 $3,100–3,650 亿资本开支移出 2027–28 年，约 $2,400–2,850 亿债务不必按原计划融资
  • HBM 首当其冲；ABF 短缺缓和但仍紧 (2027 年供给覆盖约 58%)，Ibiden、欣兴受伤大于 AT&S、SEMCO；Lam、AMAT、KLA 存储敞口最大

SemiAnalysis：5.8GW 推迟的逐个园区清单 ↗

SemiAnalysis · 11/04 · Datacenter Model · DatacenterTexasNeocloud

把上一篇的总量落到具体园区和租户，能直接对应到 SpaceX、OpenAI、Anthropic 和英伟达的敞口。

  • SpaceX Starbase (可能达 2GW) 和 TeraFab (约 900MW) 空气许可未下，是最近期的延迟
  • Vantage Stargate 得州约 700MW、Crusoe Abilene 9/10 号楼 672MW (微软)、Nexus Hubbard 800MW TPU (Anthropic) 部分延后
  • OpenAI 受影响 MW 是 Anthropic 的两倍以上；5.8GW 中只有 600MW 是 TPU，主要是英伟达的问题
  • ERCOT 12/10 完成审查、新州长 1/19 就职，中间约 5 周许可仍可能下发
  • 四大 Neocloud 到 2028 年底有超过 6GW 可用容量，GPU 现货价应上升

FUNDA Deep LLM 26Q4：能力快速进步，近期变现承压 ↗

FUNDA · 11/05 · 季度深度 · LLM定价算力

token 单价和实验室算力去向是需求端最关键的两个读数，这篇两个都给了。

  • 前沿竞争变成 "4+1"：OpenAI、Anthropic、Google、Meta，加上收购了 xAI 和 Cursor 的 SpaceX
  • 次旗舰价格收敛到每百万 token $4/$20，Ramp 样本实际单价比 3 月高点低约 40%
  • Anthropic 上半年收入 $162.9 亿，Q3 约 $168 亿、环比 +45%；降价和换新模型压低了同任务收入，单任务成本降约 40%
  • Google Cloud Q3 +103% 到 $307 亿，积压 $5,610 亿；TPU 供不应求，Q3 末开始用第三方算力
  • 作者估计头部实验室约 70% 算力不用于付费推理，并维持到 2027 年底，投入和收入的错配近期在扩大

服务器 CPU 渠道：下季度再涨 10–15% ↗

Guidepoint · 11/04 · 分销商 · CPUServersMemory

agentic AI 把 CPU 也拉进了短缺，和 11/04 AMD 上调服务器 CPU 增长预期互相印证。

  • 服务器 CPU 需求持续超过供给，Intel 热门 Xeon 交期仍长；PC 需求依然疲弱
  • 约 20–30% 的情况下客户从 Intel 转向 AMD，但 AMD 也受限
  • 下季度服务器 CPU 预计再涨 10–15%，本季度 DRAM 和 NAND 涨 15–20%
  • 大容量 HDD 部分已配额到 2028 年，客户在找 2029 年的货；模拟和功率器件部分季度涨 10–20%

Third Bridge 存储季度回顾：HBM 2027 年还要涨 120% ↗

Third Bridge · 11/04 · 前富士康采购 · MemoryHBMChina

对数据中心端内存给出最激进的 2027 年价格判断，正好和 SemiAnalysis 的 HBM 下行情景对立。

  • HBM 2027 年 ASP 同比涨超 120%，大客户价从约 $11/GB 到 $18/GB 以上，云厂商实际配额只满足约 50%
  • DDR5 2027 年涨 10–20%；DDR4 缺口超 20%，下游配额满足度不足 60%
  • 企业级 eSSD 交期超 16 周；NAND 2027 年涨幅收窄到约 28%
  • 长鑫 4F² 是拿不到 EUV 的被迫选择，即便量产，密度仍比海外 1c 落后 10% 以上；长鑫 HBM 短期不会进海外 AI 服务器
