今天的主线

白天这批量少但都在主线上，重点是 "token 在涨，单价在被路由和价格压"。Funda 认为任务内按步骤选模型 (step-level routing) 会在未来几个季度进入生产：Claude Code、Codex 一个任务要调用模型 20–40 次，读文件、格式化这类步骤可以交给便宜模型。它自己的 20 个金融任务测试里，四模型路由和只用 Opus 一样是 95% 首次正确率，成本低约 28%。全面采用会让前沿模型 API 收入少 20–25%，采用率到 20–30% 时逆风约 5–8%。

云这边，需求强但兑现受供给节奏和单一客户影响。AWS 三季度 +39.3%，低于 Funda 预期的 43.7%，原因是 Trainium 2 到 3 交替期缺卡；但 backlog $5,780 亿，管理层少见地给出 2027、2028 年都 +40% 以上的指引，财富 500 强在 Bedrock 上的支出接近去年 7 倍、token 量约 17 倍。谷歌云 +102.6%、利润率 36.2%，TPU 外售 2027 年显著爬坡，但要先备货再回款，压自由现金流。Funda 的担心是 AWS 和 GCP 越来越依赖 Anthropic，本季 Anthropic 给两家的环比增量只有约 $8.2 亿。

资金面延续早间版的判断。OpenAI 把融资目标从 $300 亿降到约 $200 亿、估值从 $1.4 万亿降到 $1.25 万亿；高盛预计大厂 capex 2026 年 $8,000 亿、2027 年 $1.2 万亿、2028 年 $1.4 万亿，增速从 50% 降到约 17%，Oracle 说 capex 在 FY27–28 见顶。企业支出端 Anthropic 重新拉开：Ramp 样本里 10/23 当周 Anthropic 60.5%、OpenAI 35.1%。

任务内按步骤路由：LLM 实验室的收入逆风 ↗

Funda · 11/02 · 研究报告 · LLMtoken定价

第一次把 "路由" 量化成前沿模型 API 收入的损失，是 token 量和 token 收入分开看的关键一篇。

  • 现在企业路由大多是任务级：每个提示或应用一开始就绑定一个模型，网关只管权限、容灾和成本
  • 47% 受访企业 (N=58) 已在用或计划自建路由；网关专家估计 20–30% 企业在用路由工具，步骤级不到 10%
  • Funda 测试：四模型步骤级路由与只用 Opus 同为 95% 首次正确率，成本低约 28%，比只用 Fable 低约 68%
  • 全面采用时同一实验室内路由让前沿模型 API 收入少 20–25%，跨实验室更大；采用率 20–30% 时逆风约 5–8%
  • 难点：部署调优成本高、ROI 难证明、换模型会让提示缓存失效
2

AWS 3Q26：Trainium 交替期收入低于预期 ↗

Funda · 10/30 · 业绩点评 · CloudASICAnthropic

供给节奏 (Trainium 换代) 而不是需求决定了这个季度的数字，中期指引反而上调。

  • 收入 $459.84 亿、+39.3%，低于 Funda 预期 43.7%；Trainium 2/3 交替缺卡，Anthropic 可能占了部分 GPU 容量
  • Bedrock：财富 500 强支出接近去年 7 倍、token 量约 17 倍；推理已占 AWS AI 收入一半以上
  • backlog $5,780 亿；指引 2027、2028 年收入都 +40% 以上；Graviton、Trainium 收入承诺同比增超过 20 倍，2027 年末开始外卖芯片
  • 2026 年现金 capex 约 $2,200 亿，2027 年明显增加
  • Anthropic 本季给 AWS 和 GCP 的环比增量约 $8.2 亿、两家接近平分，低于预期；业绩越来越像黑盒
3

光模块业绩、capex 见顶讨论和中期选举 ↗

Substack · 11/02 · 投资博客 · Marketscapex融资

把四家 2026 capex、自由现金流和 2027–28 年增速放到一起，正面回答 "capex 什么时候见顶"。

  • 2026 capex：谷歌 $1,950–2,050 亿、亚马逊约 $2,200 亿、微软约 $1,700 亿、Meta $1,350–1,450 亿，都说 2027 年继续增加
  • 高盛：2026 年 $8,000 亿、2027 年 $1.2 万亿、2028 年 $1.4 万亿，增速从 50% 降到约 17%；Oracle capex FY27–28 见顶
  • 自由现金流：微软 +$186 亿，谷歌 -$91 亿，亚马逊过去 12 个月 -$424 亿，Meta -$21 亿
  • OpenAI 融资目标降到约 $200 亿、估值 $1.25 万亿，承诺约 $110 亿；9 月年化收入接近 $500 亿
  • Ramp：Anthropic 企业支出份额 60.5%、OpenAI 35.1% (一个月前 51.3% / 44.2%)
4

GOOG 26Q3：搜索放缓，广告维持谨慎 ↗

Funda · 10/30 · 业绩点评 · CloudTPUAds

谷歌云和 TPU 外售是供给侧增量，搜索放缓说明 AI 对广告的替代已经开始。

  • 谷歌云 $307.09 亿、+102.6%，营业利润率 36.2% (去年 23.7%)
  • TPU 外售四季度继续扩大、2027 年显著爬坡；通过 Oracle 和与 Blackstone 合资的 Crux AI 扩大 TPU 供应
  • 要先备货再回款，压自由现金流；四季度更多用第三方算力 (Funda 认为是租 SpaceX 的 GPU 跑 Gemini 4)，压云利润率
  • 搜索 +12.0%，查询量增速却是五年新高；AI Mode 变现低，OpenAI 广告预算几乎都从谷歌转来
  • 2026 capex 指引维持 $1,950–2,050 亿，2027 年显著增加
