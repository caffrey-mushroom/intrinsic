1 总体判断

OpenAI 的 "收入不及预期" 主要是口径问题：媒体说的 700 亿美元是总额 ARR，FT 和 OpenAI CFO 说的约 500 亿是净额；按净额算，Q3 年化收入环比仍涨 70% 以上，公司对投资人说年底至少到 700 亿净额

Anthropic 是本周市场预期最高、调研分歧最大的一家。买方预期 9 月底 ARR 780-800 亿美元，第三方跟踪 9/24 是 768 亿，但最近一个月只涨 1.8%；OpenRouter 样本里它的花费份额从年初 75% 掉到约 50%，渠道调查把 Codex 排在 Claude Code 前面

最大的预期差在 "token 用量 = lab 收入"：市场按 token 增长外推 lab 收入，但 Cloudflare、Databricks、MSFT 三位专家都说企业开始控成本、把简单任务切到开源模型；Databricks 平台上开源占 60% 的 token，却只占 5% 的 AI 收入

价格上，市场看到的是价格战 (Haiku 5.5 和 GPT-6 Luna 都标 0.10/0.50 美元每百万 token)，调研看到的是算力紧、实际单价在涨：GOOGL 两位前员工说 2026 年不会打价格战，Gemini 4 Argon 的 API 价 11 月底翻倍，Zhipu 的 API 均价比年初翻了一倍

口径：只算模型厂本身，包括收入和 ARR、用户、token 用量、定价、新模型、lab 的算力和财务。云厂 capex 和云收入 (归 CSP Weekly)、GPU / ASIC 芯片 (归 GPU Weekly)、应用软件公司 (归 Software Weekly) 只在能拆出 lab 部分时才算。还没有 thesis，本期用 9 个市场预期问题 (E1–E9) 当基线，见第 2 节末

本周发生了什么：10/8 FT 报 OpenAI 9 月 ARR 约 500 亿美元 (净额)，不是此前的 700 亿，带崩半导体；10/14 OpenAI CFO 说 Q3 接近 500 亿、环比 +70% 以上。Anthropic 10/7 发布 Haiku 5.5，比上一代便宜 75%；投资者日前买方的 9 月 ARR 预期约 780-800 亿。GOOGL 发布 Gemini 4 Argon，第三方榜单排第三，介绍价 2/10 美元，11/30 后翻倍。META 发布 Muse Wonder，AA 智能指数仅次于 Claude Opus 5.5，市场开始讨论前沿从 "双寡头" 变成 "多寡头"。中国这边，Moonshot Kimi K3 带头向云厂商收 20-30% 收入分成，Anthropic 说反蒸馏后被抓取的数据减少 90-99% 并点名 Zhipu

最重要的分歧：市场把 token 用量的高增长当成 lab 收入的领先指标，调研却显示增量 token 越来越多流向开源模型和便宜的小模型。如果这条成立，lab 收入增速会慢于 token 增速，而且慢于算力投入增速；这正是 Anthropic 最近一个月 ARR 只涨 1.8% 和 OpenRouter 份额下滑的一个解释。反方证据也不弱：OpenAI 净额 ARR 两个月涨约 70%，META 28 天在 Claude Code 上花了超过 1.05 亿美元，Ramp 显示 Opus 5.5 占企业 AI 花费的 34%

证据限制：调研口径主要来自专家电话 (GOOGL、MSFT、AWS、Nebius、Cloudflare、Databricks 前员工，和接近 Zhipu、Moonshot、MiniMax、DeepSeek、BABA、ByteDance 的人士)，数字多是个人估计；有四组纪要是同一场访谈的两个版本，已合并计算。市场口径的卖方和媒体数字多是 TMTB 摘要转述，原报告没看到。OpenAI、Anthropic 都不公开披露 ARR 口径，本期所有 ARR 数字都不是已确认事实

Follow-up

1. Anthropic 9 月 ARR (投资者日 / IPO 材料)：买方预期 780-800 亿美元，第三方跟踪 9/24 是 768 亿。低于 780 亿说明 "增速放缓" 的担心成立；到 800 亿以上说明 OpenRouter 份额下滑没传到收入。年底目标 1,000 亿要求此后每月约 +9%
2. MSFT FY27Q1 财报 (10 月底)：专家说 Azure 上按 token 计费的模型收入约 27-28 亿美元，OpenAI 占比从 70% 掉到 60% 多，开源从 10% 升到 14%。财报如果拆出类似数字，可以验证 "开源分流" 的速度
3. GOOGL Q3 财报 (10 月底)：专家说 Gemini API Q3 增速从 38% 降到 24%，原因是 Gemini 4 推迟；TPU 对外销售 Q3 约 10 亿、Q4 约 30 亿美元。看管理层是否确认算力约束和 TPU 外售
4. Gemini 4 Argon 11/30 涨价后的用量：介绍价 2/10 美元，之后 4/20。涨价后调用量不掉，说明前沿模型有定价权；掉得多，说明价格战逻辑占上风
5. OpenAI Q4 净额收入和 Astra 6.1 发布：公司对投资人说年底净额至少 700 亿美元，Q3 约 500 亿。Q4 要再涨约 40%。Astra 6.1 因安全评测暂缓，发布时间影响 Q4 节奏
6. META Q3 财报和 Muse 留存：Muse 的 DAU 有 15 万、36 万、180 万、250 万几种说法，差一个数量级。财报如果给出口径，可以判断消费级 agent 是不是新的 token 需求来源
7. 中国 lab：Kimi K3 收入分成和 GLM-6：K3 分成能否被云厂商接受，决定开源模型能否收费；GLM-6 (1.6T 参数) 计划 2027Q1 发布对标 Fable 5，看反蒸馏后中国追赶周期是不是真的拉长到一年
