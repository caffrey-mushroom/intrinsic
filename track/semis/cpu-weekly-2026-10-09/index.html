1 总体判断

市场预期这周被 AMD 一次抬高了一个量级。Lisa Su 在 10/13 的 OCP 上说，一年前市场看服务器 CPU 只有约 200 亿美元、个位数增长，AMD 九个月里上调了三次，现在看未来四五年每年涨约 50%，2030 年超过 2000 亿美元 (C323、C300)。NVDA 拿出了装 256 颗 Vera 的独立 CPU 机柜，MSFT 把 Cobalt 200 定位成跑 Agent 的 CPU (C300、C380)。这些都是公司自己的预测，不是卖方共识

调研看到的近端现实比预期更紧。一位 AMD 中国区专家说，AMD 中国区今年出货预计 120-150 万颗，比去年约 76 万颗多 58-97%；CSP 订单仍有 10-20% 交不出货 (C330)。渠道专家说 INTC 第六代 Xeon 要等半年，AMD 要等 15-16 周，中国区服务器 CPU 配额今年已经用完 (C001)

最大的预期差在价格和份额。流行的说法是 "CPU 涨价 40%"，但那主要是 INTC 和现货。按 AMD 中国区的官方渠道价，主力 EPYC 从 Q1 到 Q3 只涨了 2-9%，AMD 在用价格换份额 (C330、C298)。一位硬件评测人说，AMD 年底在多数统计里份额不到 50% 才奇怪 (C413)。对 AMD，增长主要来自卖得多；对 INTC，增长主要来自卖得贵，量被产能卡住

Agent 到底多用多少 CPU，企业和个人差很多。阿里云专家说，内部财务部门上 Agent 后 CPU 用量涨了约 60 倍，经验法则是 Agent 数量涨 10 倍、CPU 用量涨 3-5 倍 (C249)。但同一位专家也说，工程优化还能再省 30-70%。另一方的测算是，META Muse 服务 1 亿用户只要约 6.5 万颗 CPU (C383)，个人 Agent 的量不大

口径：服务器 CPU 的需求、供给、价格和份额，包括 Agent / RL 拉动的通用算力、AI 服务器里的 head node 和 CPU:GPU 配比、INTC Xeon / AMD EPYC / Arm 服务器 CPU (NVDA Vera、AMZN Graviton、MSFT Cobalt)、中国 Hygon / Kunpeng。GPU / ASIC 本身、Intel 代工客户、内存价格、手机和终端芯片不算。Caffrey 还没有写 CPU thesis，所以本期不判断 "thesis 对不对"，只把市场预期 (公司指引、管理层说法、卖方) 和调研现实 (专家电话、渠道、产业链) 放在一起，标出两者的差异

本期发生了什么：窗口 10/9-10/15 共 7 天。415 篇纪要里 121 篇提到 CPU 关键词，19 篇有能用的具体内容，其中 7 篇以 CPU 为主题。事件：10/9、10/10、10/14 三篇 Acecamp 服务器 CPU 渠道调研 (中国渠道、INTC 侧、AMD 中国区)；10/10 和 10/13 两篇 Agent CPU 用量调研；10/13-14 OCP 全球峰会，AMD 上调 CPU 市场规模并发布 Helion Agent 机柜，NVDA 发布 Vera CPU 机柜，MSFT 讲 Cobalt 200

最重要的分歧：Agent 拉动的 CPU 需求能不能撑起 "每年 50%" 这个量级。看多的证据是企业内部 CPU 用量涨了几倍到几十倍、CPU:GPU 配比从 1:6-1:8 往 1:4 甚至 1:1 走 (C001)、CSP 在往 192 核和 256 核迁移。看空的证据是工程优化和新一代 CPU 各能省 30-50%，个人 Agent 1 亿用户只用约 6.5 万颗 CPU，INTC 侧专家直说 "2000 亿已经比较夸张" (C110)

证据限制：A/B 级来源大多是 Acecamp 上未写身份的专家，视角偏中国渠道和阿里云；AMD 的出货和价格只代表中国区；本周没有 INTC 或 AMD 的财报；OCP 内容来自 TMTB 和 GuidePoint 的转述。知识库索引最后扫描在 10/15，10/15 只收到 8 篇

4 证据分析

绿色竖线是对 CPU 需求或价格偏多的证据，红色是偏空，灰色是中性。每条先标 "预期" 或 "现实"

4.1 需求：服务器 CPU 还在加速吗

判断：近端需求很强，传统服务器换代和 AI 服务器一起拉。AMD 中国区今年出货可能接近翻倍，但里面有缺货后的补单

  • 现实 · AMD 中国区 2026 年出货乐观约 150 万颗，保守 120-130 万，对比 2025 年约 76 万 (C330 L30)
  • 现实 · 传统服务器没被 AI 挤掉，是 DDR4 停产逼出来的换机大年，可能持续两三年 (C001 L142)
  • 预期 · Ibiden 8 月业绩会：需求比 5 月预测增加的产品包括高端 CPU (C130 L69)
  • 预期 · 作者假设高端 x86 CPU 2025-28 年出货年均 +30% (C130 L78)
  • 现实 · 提问者按 4000 万颗 CPU 测算载板面积仅约 17 万平方米，远小于行业约 170 万平方米出货，说明 CPU 不是载板需求大头 (测算未完成，专家称需 IE 重算)。 (C398 L1586)
  • 现实 · 专家把 2027 年 CPU 用量提升作为 PCIe Retimer 的重要增量来源，侧面说明其看到 2027 服务器 CPU 用量上行。 (C175 L159-L160)
  • 现实 · 中国大客户找 Akamai 主要是为 GPU，CPU 需求只有小幅增量，用于基础算力和网络传输 (C007 L46)
  • 现实 · CDN 节点服务器是定制硬件，CPU 和内存配比较低、存储大，不是 CPU 需求重的场景 (C007 L126)

  • 现实 · 供应链部门 CPU 用量 10-20 倍，渗透率近 40% (C249 L229)
  • 现实 · 经验法则：Agent 数量 ×10，CPU 用量约 ×3-5 (C249 L234)

  • 现实 · 换成 AMD 192 核或 INTC 新一代 CPU，vCPU 配置可降 30-50% (C249 L129)
