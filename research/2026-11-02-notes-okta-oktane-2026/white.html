这场峰会讲了什么

先搞懂这家公司

OKTA 卖的是“数字门禁”。公司员工每天要登录几十上百个软件 (邮箱、Salesforce、Workday 等)，OKTA 让他们只登录一次就能进所有软件 (单点登录，SSO)，并负责多重验证、开通和注销账号、审批谁能看什么 (治理，OIG)、管理员的高危权限 (PAM)，这一块叫员工身份 (Workforce Identity)，主要对手是 MSFT 的 Entra。另一块是客户身份 (Customer Identity，主要是 2021 年 $6.5B 收购的 Auth0)：航空公司、零售商的 App 和网站里，消费者注册和登录那一步由 OKTA 在后台完成。现在新加的是给 AI agent 发“工牌”：把 agent 也登记成一种身份，管它能连哪些系统、用谁的权限 (Okta for AI Agents)。

收钱方式是按年订阅。员工身份按员工人数、每人每月计价，官网标价从 $6 (入门版) 到 $17 (Essentials)，大客户和治理、PAM、agent 等附加模块单独议价；客户身份按月活用户 (MAU) 计价，企业版底价 $3,000/月起。agent 产品目前不按 agent 个数收费，而是在每员工单价上加价。OKTA 财年截至 1 月 31 日，FY27 指 2026 年 2 月到 2027 年 1 月；FY26 收入 $2.92B (+12%)。这场投资者峰会是 Q2 财报 (2026-08-26) 后约一个月、在拉斯维加斯 Oktane 年会期间办的约 1 小时纯问答，没有 CFO 上台，也没有新的财务目标。

  • 组织和打法 (部分新)：Auth0 和 OKTA 的研发已合并到 Ric Smith 手下，研发约 $600M/年；已有客户用 Flex 协议和企业捆绑，Todd 说会做更多 (Q2 没提)；数据安全被视为相邻领域，在考虑自建、收购或合作。销售结构稳定 18 个月，Q2 前 20 大单都有合作伙伴参与 (Q2 已讲)。
  • 要打折扣的地方：AI 收入在 FY27 仍不重要 (Q2 口径未变)，客户都是 Ramp、Yahoo、DELL 这类早期采用者，Todd 自己说“可能比我们想的要久”；Todd 约 80% 的 agent 谈话还在 IT 和安全部门，客户侧 (Auth0) 的 agent 电商还很早期；分析师把 1.5/4 算成 50% 加价，Todd 没纠正，市场容易高估。

术语大白话和收钱的关系
SSO (单点登录)登录一次就能进所有工作软件，像一张能刷开公司所有门的工牌。OKTA 的起家产品，按员工人数每人每月收费，入门版 $6。
IdP (身份提供商)发工牌、验工牌的那个系统，员工登录时由它确认“你是你”。OKTA 和 MSFT Entra 都是 IdP。谁是 IdP，谁就最容易把附加模块卖给这个客户。
MSFT EntraMSFT 的身份产品，原名 Azure Active Directory，是 Office 365 的登录入口。随 M365 捆绑，份额约 40%，是 OKTA 最大对手。
IAM (身份与访问管理)管“谁能进哪个系统、能做什么”的整个市场，包括 SSO、多重验证、治理、特权访问。Todd 认为 5 年内会成为网络安全最大的细分市场。
员工身份 / 客户身份 (CIAM)员工身份管公司自己的人登录内部系统；客户身份管消费者登录公司的 App 和网站，比如航空公司会员登录。员工身份按员工人数收费；客户身份 (Auth0) 按月活用户收费。
Auth0OKTA 2021 年收购的客户身份平台，给开发者用的登录组件。收购价 $6.5B；研发已和 OKTA 合并，归 Ric Smith 管。
Okta for AI Agents给 AI agent 发工牌：登记有哪些 agent、它们替谁干活、能连哪些系统、何时注销。2026-04 GA。目前在每员工单价上加价，几笔大单里约是平台金额的 25% 到 38%。
Agent SSO让 agent 像员工一样一次登录就能访问多个应用，不用一个个点“同意授权”。8 月起放进所有版本免费送，作用是做入口和销售线索。
跨应用访问 (Cross App Access)OKTA 推的开放协议，让一个应用里的 agent 用员工的身份安全地访问另一个应用，Anthropic 的 Claude 已支持。免费；Todd 让大家看支持它的 ISV 数量来判断标准是否成功。
Blueprint / Blueprint 联盟OKTA 牵头、多家安全厂商参与的“安全 agent 化企业”参考架构，讲清各类产品分工，像装修前的统一施工规范。目前不直接产生收入，也没有联合销售分成；目的是让客户敢拨预算。
MCP 网关 / AI 网关MCP 是 agent 连接外部工具和数据的通用接口；网关是放在中间的关卡，实时检查和拦截 agent 的请求。Q2 推出的 Agent Gateway 属于付费的 Okta for AI Agents 升级内容。
OIG (身份治理)定期审查谁有什么权限、审批新权限、自动收回离职人员权限。OKTA 卖得最好的新产品，分析师说附加加价约 30%。
PAM (特权访问管理)管系统管理员这类“万能钥匙”账号，借用要审批、用完要收回。附加模块；Ric 说要开放给非 OKTA IdP 的客户，会和 CyberArk (PANW) 正面竞争。
记录系统 (system of record)某类信息的“唯一权威名册”，比如 HR 系统是员工名册。Todd 想让 OKTA 成为 agent 的名册。谁是名册，谁就最难被替换，能持续收费。
加价 (uplift) / 按用户计价不按 agent 个数，而是在每个员工的月费上多收一笔，像手机套餐加一个流量包。agent 收入因此受员工数限制；Todd 说长期会改成按 agent 收费。
Flex 协议 / 企业捆绑客户先承诺一笔总金额，在里面自由开通各种模块，类似预付卡。CRWD 等同行靠它加快多产品渗透；OKTA 已有客户在用，会做更多，可能伴随折扣。
GA / POCGA 是正式上市、可以签正式合同；POC 是概念验证，客户先小范围试用。Todd 强调 OKTA 是唯一有 GA agent 身份产品的厂商。
FedRAMP High / IL5美国联邦政府和国防部的云安全认证等级，拿到才能卖给相应级别的政府机构。公共部门是今年亮点，但不到 OKTA 收入的 10% (Q2 说法)。
身份安全编织 (identity security fabric)OKTA 对“一个平台管所有人、机器和 agent 身份”的叫法，用来替换多个单点产品。需要更多实施服务，OKTA 把服务交给合作伙伴做。
