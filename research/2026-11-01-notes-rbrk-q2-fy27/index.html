Rubrik FY27 Q2 (2026 年 5–7 月) 电话会初读笔记

逐段英文原文、中文翻译和解读，外加关键数字、术语表和下一季要盯的事。给第一次读这家公司电话会的人。

这一季讲了什么

先搞懂这家公司

Rubrik 卖的是“被黑以后还能把公司救回来”的软件。它定时把企业的重要数据 (机房里的虚拟机和数据库、AWS/Azure 上的应用、Microsoft 365 邮箱和 OneDrive、文件服务器、员工登录用的身份系统 Active Directory/Entra ID/Okta) 拷一份连管理员都改不了的副本，平时盯着副本有没有异常；一旦被勒索软件加密或被 AI 智能体误删，就按正确的顺序把业务恢复到被攻击前最后一个干净的状态。传统叫法是“备份”，Rubrik 把它包装成“网络韧性 (cyber resilience)”，这场电话会又升级成“智能体式网络韧性 (Agentic Cyber Resilience)”。

它有三条产品线。第一条是 Rubrik Security Cloud (RSC)，数据保护和恢复，几乎是全部收入的来源。第二条是身份韧性 (Identity Resilience)，专门备份和恢复员工登录系统，一年多做到 5,000 万美元以上 ARR (Q1 披露)，卖给安全负责人 (CISO)，把 Rubrik 从 IT 运维预算伸进了安全预算。第三条是 Rubrik Agent Cloud (RAC)，监控和管控企业自己的 AI 智能体，并能“撤销”智能体的破坏性操作，目前 15 家以上付费客户，基本没有收入。打个比方：RSC 是银行金库加保险，身份韧性是全公司门禁卡系统的备用钥匙，RAC 是给新来的机器人员工配工卡、监控摄像头和“撤销键”。竞争对手主要是 Cohesity (已合并 Veritas)、CVLT (Commvault)、Veeam (私有)、DELL 的备份产品，以及云厂商自带的备份工具。

怎么收钱：按年订阅，按保护的数据量 (TB)、应用数量或身份人数计费，多数是多年合同。核心指标是订阅 ARR (年化订阅收入，本季 16.6 亿美元，+33%)，而不是报表收入。原因是过去两年公司把老客户从“一体机 + 授权”迁到云版 RSC，迁移时送给客户的抵扣权在会计上叫 material rights，会让报表收入时多时少；FY27 正是这部分收入快速消退的一年，所以报表收入增速 (Q3 指引 +23%) 会明显低于 ARR 增速。另外，客户自托管版 (RSC-P) 的授权收入是一次性确认的，也会放大季度波动。

我们 101 的判断：不买，放观察名单，买点 $65–80 (10 月 29 日股价约 $129)。理由不是增长差，而是：股价已经把 5 年 30% 左右的复合增长算进去了；SBC (股权激励) 约占收入 22–24%，比自由现金流还大，扣掉 SBC 的现金流是负的；撑起这轮股价的 AI 智能体故事 (RAC) 还没有收入。读这场电话会时要带着几个问题：净新增 ARR 靠的是新客户、老客户加量、身份/安全加购，还是涨价和 Flex 打包；NRR 和云 ARR 在怎么走；贡献利润率改善了多少、和 SBC 是什么关系；RAC 有没有实质进展；对 Cohesity、CVLT、Veeam 的竞争；指引是不是又在“故意保守”。财报次日 (8 月 28 日) 股价跌 13%，收 $93。

这一季

一句话：净新增 ARR 约 9,600 万美元、同比 +35%，第 10 次超指引并上调全年；但 CFO 自己承认剔除迁移后核心云业务的净新增只 +20%，加速里有一块来自重新增长的非云 (主权、政府、自托管)，全年指引隐含下半年净新增只比去年高约 6%，Agent Cloud 今年 ARR 里“假设极少”，而电话会只字未提本季约 1 亿美元、高于自由现金流的 SBC。

  • 订阅 ARR 16.6 亿美元，同比 +33% (Q1 +32%)；净新增订阅 ARR 约 9,600 万美元，同比 +35%，环比低于 Q1 的 1.03 亿美元。管理层强调这是上市后连续第 10 个季度超预期，而且净新增 ARR 增速在加速。
  • 加速的成分要拆开看。CFO 主动说剔除迁移后云净新增 ARR 只增长 20%；云占订阅 ARR 的 89%。总体加速里有一块来自非云业务：过去被迁到云而下降，现在迁移结束、主权云和政府需求带动它重新增长，分析师按公司建模参数算今年非云 ARR 约 +10%。这是一次性的基数效应，不会年年重复。
  • 老客户：NRR 超过 119% (Q1 约 120%，去年超过 120%)，在缓慢下降；10 万美元以上客户 3,084 家 (+23%)，贡献 88% 的 ARR；100 万美元以上客户 +57%。管理层没有拆分新客户、加购和涨价各自贡献了多少净新增 ARR。
  • 报表收入 4.273 亿美元 (+38%)，订阅收入 4.072 亿美元 (+37%)，都快于 ARR，原因是自托管授权一次性确认、material rights (本季 470 万美元，Q1 850 万美元) 和亚太硬件涨价。Q2 收入指引是 3.95–3.97 亿美元，超出约 8% 里有不少一次性成分。non-GAAP 毛利率 81.0%，低于去年同期的 81.6%。
  • 利润和现金：贡献利润率 (过去 12 个月) 14%，同比提升 460 个基点；自由现金流 6,570 万美元，同比只多 14%。电话会没提 SBC：按新闻稿本季 SBC 约 1.01 亿美元，约占收入 24%，比自由现金流多约 3,500 万美元。
  • 新产品：身份韧性仍是“增长最快的产品线之一”，签下公司史上最大的国际身份单，但本季没有更新身份 ARR。Rubrik Agent Cloud 超过 15 家付费客户，CFO 说还在找产品市场契合，今年 ARR 里“假设极少”。Flex (一份合同买全平台) 6 月推出，已签“几单”。Strata 收购贡献 ARR 为 0。
  • 指引全线上调：FY27 ARR 18.80–18.85 亿美元 (+29%，原 18.54–18.62 亿)，FCF 3.23–3.33 亿美元 (原 2.93–3.03 亿)，贡献利润率约 15.5% (原约 14%)。但倒推下半年净新增 ARR 只比去年 +6%，Citi 当场追问，CFO 用“全年隐含增速从 7% 提到 14%”回答，没解释下半年为什么这么低。Q3 收入指引 4.29–4.31 亿美元，和 Q2 实际几乎持平。
  • 硬件涨价和供应紧张被问了三次，管理层都说对订阅 ARR 无实质影响，交货周期比年初好转。叙事上 CEO 大量讲 Mythos、Project Glasswing 和“AI 速度攻击”，但被问到 Mythos 带来多少增量需求时没有给任何数字。

怎么读这份笔记

一场电话会通常分三段：主持人和投资者关系负责人的开场套话、管理层的准备发言 (CEO 讲业务和产品，CFO 讲数字和指引)、分析师问答。准备发言是写好稿子念的，偏宣传；问答才是信息量最大的部分，因为分析师会追问管理层不想主动讲的东西。

这份笔记把整场电话会切成 54 段，每段左边是英文原文、右边是中文翻译，下面是我们的解读。每段标了重要程度：必读 25 段，有用，可跳过 (套话，默认折叠)。原文里最关键的一句用底色标出。时间紧就只读"必读"。

订阅 ARR (subscription ARR)把当前所有有效订阅合同折算成一年的金额。像健身房把所有会员的年费加总。Rubrik 最看重的指标，估值通常按 ARR 的倍数看。不含硬件、服务和 material rights。
净新增 ARR (net new ARR)本期末 ARR 减上期末 ARR，也就是这一季新多出来的年化订阅额 (新客户 + 老客户加购 - 流失)。它的增速决定 ARR 往哪走。管理层和销售提成都按全年净新增 ARR 考核。
NRR (订阅净留存率)一年前的老客户今年付的钱是去年的多少倍。119% 意思是老客户平均多付 19%。衡量老客户越买越多。Rubrik 的 NRR 从 FY24 的 133% 降到现在的 119% 以上。
云 ARR / 非云 ARR (cloud / non-cloud)云 ARR 是通过 Rubrik 云控制台 (RSC) 管理的订阅；非云是客户完全自己托管的部分，常见于政府、国防和受监管行业。云占 89%。过去两年老客户从非云迁到云，抬高了云 ARR 增速；迁移结束后，剔除迁移的云净新增只 +20%。
Material rights迁移到云版时公司送给老客户的“抵扣券” (例如旧一体机的升级权、订阅抵扣)。会计上先挂账，客户用掉或过期时一次性记成收入。FY27 正在快速消退 (Q1 $8.5M，Q2 $4.7M，Q3 $2–3M)，所以报表收入增速会被压低，要看“剔除 material rights”的口径。
RSC / RSC-PRubrik Security Cloud 是 Rubrik 的云控制台，一套策略管所有地方的数据；RSC-P (Private) 是装在客户自己机房里的版本。RSC-P 的软件授权在交付时一次性确认收入，自托管卖得多的季度收入会被抬高。
订阅 ARR 贡献利润率 (subscription ARR contribution margin)公司自定义：订阅 ARR 减去维持和获取订阅的 non-GAAP 成本费用，再除以 ARR。像“每 100 美元年费，扣掉运营现金开支后还剩多少”。过去 12 个月 14%，全年指引 15.5%。它不含 SBC，所以比股东真实拿到的回报好看。
SBC (股权激励)用股票而不是现金给员工发的工资。不花现金，但会稀释老股东。Rubrik 本季约 $101M，约占收入 24%，高于自由现金流。电话会没提。
预先恢复引擎 (Preemptive Recovery Engine)平时就预先算好每个系统最后一个干净的恢复点和恢复计划，出事那天直接用。像体检档案，平时存好，生病时一看就知道哪天开始不对。Rubrik 的核心卖点和胜率来源。基于它的 Autonomous Business Recovery 还在私有预览。
身份韧性 / 身份恢复 / 身份前滚 (Identity Resilience / Recovery / Roll Forward)备份和恢复员工登录系统 (AD、Entra ID、Okta)。前滚是只撤销黑客的改动、保留正常变更，避免回滚后新员工账号消失、离职员工账号复活。第二条增长曲线，Q1 时 ARR 超过 $50M，按身份人数收费，卖给 CISO。本季没更新数字。
