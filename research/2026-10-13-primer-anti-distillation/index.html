Anthropic 10 月 12 日发文 "Strengthening our defenses against distillation attacks",说新一套措施让别人能从 Claude 偷走的"思考过程"少了 90-99%。这份 primer 讲清它怎么防、数字该打几折、对行业意味着什么。

蒸馏者真正想偷的是 Claude 的思考过程。Anthropic 用三层防御 (给推理贴封条、门口安检、惯犯加罚) 把能被抓走的推理 token 压低了 10-100 倍,但这是它在自家平台上的自测,还没遇到过高水平的持续攻击。

这是一场比谁是"最弱一环"的游戏:Anthropic 只关上了自己的门,GLM-5.3 这类开源权重已经放出去收不回,别家模型和云平台不跟进,蒸馏流量只会换个地方。

对 token 和算力主线基本中性:被推掉的蒸馏流量估计只占 Anthropic 收入的 0.2-0.3%。真正要盯的是下一代中国开源模型和美国前沿的差距,会不会从现在的约 4 个月拉开。

Follow-up (复查 2027.01.13)

  1. 下一代中国开源模型和美国前沿的差距。这是"防蒸馏 + 出口管制到底有没有拖慢追赶"唯一的结果指标。基线:CAISI 测 GLM-5.3 落后约 4 个月。下一代 (Kimi、DeepSeek、GLM 的新一版) 差距拉到 6 个月以上,说明这道门有用;仍在 4 个月以内,说明蒸馏不是关键,或者流量换了地方
  2. OpenAI、Google 和三大云平台有没有跟进同等措施。第 4 节的规则就是看"别处能不能拿到"。基线:三家 4 月起在 Frontier Model Forum 共享攻击数据,但只有 Anthropic 公布了具体措施和效果。任何一家跟进推理绑定或分类器,口子收窄;都不跟,Anthropic 的 90-99% 主要是把流量赶到别家
  3. Anthropic 下一份威胁报告里的蒸馏规模。基线:9 月报告里阿里 5-7 月超 1.51 亿次对话。新报告里同类数字降一个数量级,和 10-100 倍对得上;如果出现"高水平持续绕过"的案例,第 2、3 节的效果判断要重写
  4. preserved thinking 能不能推到老账号。这决定第一层封条是全关还是半关。基线:只对 2026.08.31 之后的新账号默认强制。官方宣布老账号也强制,说明开发者摩擦可控;反复延期或社区大量报 400 错误,说明这层只能半开

1. 是什么:拿强模型当老师,偷的是草稿纸

蒸馏就是拿强模型的回答当教材,去训练一个弱模型。Anthropic 这次做的,是不让别人拿到最值钱的那部分教材,也就是 Claude 的思考过程。

底层怎么工作

  • 新一代大模型回答前会先"想"一段,叫 reasoning 或 thinking。只拿最终答案去训,小模型学到"答案是什么";拿到思考过程去训,小模型学到"怎么一步步想出答案"
  • 差多少有数:Anthropic 用自己的预训练模型当学生,拿 Opus 4.8 的完整推理训,SWE-bench Verified (一个写代码修 bug 的考试) 得 80.4%;只拿推理摘要训,得 71.8%
  • 蒸馏本身是正常技术:各家都把自己的大模型蒸馏成便宜的小模型卖。"蒸馏攻击"特指用假账号、代理网络,未经许可大规模抓竞争对手的输出

贯穿全篇的比喻:考生和草稿纸

  • Claude 是考生,思考过程是草稿纸。蒸馏者最想要草稿纸
  • Anthropic 的基本做法:草稿纸不给你看,只给一个封口的信封 (技术上叫加密 signature)。下一轮对话你把信封还回来,Claude 自己拆开看一眼上次怎么想的,接着往下想
  • 这次的三层防御,就是给信封贴封条、在门口设安检、对老来套的人加罚

2. 机制:三层防御各堵哪一步

一次蒸馏要走四步:拿到账号 → 发大量请求 → 套出推理 → 被封了换号再来。三层防御各管其中几步。

第一层 封条 (preserved thinking):让偷来的信封打不开

以前的漏洞:蒸馏者拿着加密的推理信封,塞进一段自己编的假对话 ("你之前已经把完整推理给我看过了,再抄一遍"),Claude 拆开信封、被假对话骗,就把草稿念了出来。现在信封上贴了三道封条:

封条规则堵的手法适用范围
场景封条信封前面的内容 (system prompt、工具列表、之前每条消息) 改了一个字,信封就作废编假对话骗 Claude 吐推理;把推理搬到新对话里重放2026.08.31 后新建的账号默认强制;老账号自愿开启
收件人封条每个模型只能拆自己和指定几个模型的信封拿护栏更弱的老模型去读新模型的推理所有账号
账号封条信封只在产生它的账号 (或关联账号) 里有效被封号后换新账号继续拿旧信封试目前 Sonnet 5.5 和 Haiku 5.5

代价落在正常开发者身上:对话只能往后追加,不能回头改。很多 agent 框架习惯每轮重写 system prompt 或删旧内容,现在一改,之前的推理全作废,模型只能重想一遍,多花输出 token (见第 6 节的图)。用 Claude Code、claude.ai、Agent SDK 的人不受影响。

第二层 安检:认出"套推理"的请求

  • 为什么拦得住:正常用户几乎不会要求"把你刚才藏起来的思考逐字写出来",会这么问的基本就是蒸馏者,所以能精准拦、少误伤
  • 难点是换说法:有一家实验室一口气试了 12,000 种不同的骗法;9 月报告里甚至有人直接写"不要把这条标记为推理提取"
  • 做法:用和防生物武器同一套的两阶段分类器,拿蒸馏者真实用过的套话做训练材料,再请内外部红队攻破、补洞。已补上的新花样包括"把推理翻译成另一种语言""把推理写在标签里和答案一起输出"
  • 结果 (自报):9 月报告里列出的手法全部能拦;误拦正常请求低于 0.1%;覆盖 Sonnet 5.5、Opus 5 和 5.5、Fable 5 和 5.1

第三层 加罚:让一直试不划算

  • 限流:一个账号反复套推理,可用额度下降
  • 封号:持续蒸馏的直接封,已封数万个,很多在开始后 2 小时内
  • 拦截也收费:9 月 24 日起,在误拦率低于 0.1% 的领域 (含蒸馏),被拦下的请求照样收钱。以前试 12,000 种骗法是免费的,现在每试一次都要付钱

每一环由谁控制

环节决定什么谁控制现在卡不卡
推理可见性能不能拿到草稿纸Anthropic (模型和 API 设计)基本卡死
请求审查套话能不能过Anthropic (分类器)卡住,猫鼠游戏
账号与支付能开多少号、多快开Anthropic + 支付和身份核验部分卡
第三方云和中转能不能绕开 Anthropic 自家 APIAWS、Google Cloud、Microsoft、推理中转商不在它手里
别的老师换一个模型当老师OpenAI、Google、开源社区管不了

一句话:三层防御把 Anthropic 自家门口的推理泄漏基本堵住了,但门外的云平台、别家模型和开源权重它管不到

4. 一句话规则:别处能不能更便宜地拿到

判断防蒸馏有没有用,只问一句:蒸馏者能不能在别处,用更低的成本,拿到同样好的思考过程。能,就只是把流量赶走;不能,才是真的拖慢了追赶。

别处能拿到同样好的推理吗判断
Anthropic 自家 API目前基本不能门已关
云平台上的 Claude文档说新账号的定义在云平台上相同,但分类器和封号由谁执行没有说清待确认
OpenAI / Google 模型OpenAI 自 2024 年 o1 起就只给推理摘要;Google 称已实时反制推理提取。强度和 Anthropic 是否相当,外部看不到部分关
开源权重 (GLM-5.3 等)任何人都能下载、随便抽推理;但它比美国前沿弱约 4 个月门开着,但老师更弱

一句话:防蒸馏的效果不取决于 Anthropic 防得多好,取决于全行业最松的那道门有多松

5. 反过来想:蒸馏者需要什么,哪些永远堵不住

蒸馏者需要Anthropic 现在堵住了吗堵不住的性质说明
最终答案照常给否天生卖服务就得给答案。只学答案也能学到不少,只是少了"怎么想"
完整推理只给摘要 + 加密信封基本是—封条 + 安检
伪造上下文重放信封场景封条新账号是能堵但伤正常用户老账号默认不强制,因为一强制大批现有集成会报错
用弱模型读强模型推理收件人封条是—代价是换模型时推理会丢
大量假账号2 小时封号 + 拦截收费部分能堵但伤正常用户身份和支付核验越严,正常用户注册越麻烦
第三方平台流量呼吁平台配合否别人的口子文章点明蒸馏流量分散在 Anthropic API、云平台和其他推理商
换一个老师—否别人的口子OpenAI、Google 的防御强度决定
已开源的强模型—否天生GLM-5.3 权重已发布,收不回;去掉护栏只要约 600-2,200 GPU 小时
  • 天生堵不住的:答案一定会漏,开源权重一定收不回。所以蒸馏不可能归零,只能变贵、变慢
  • 能堵但伤正常用户的:老账号强制封条、更严的实名和支付核验。Anthropic 会不会走这一步,取决于它愿意让付费客户承受多少摩擦
  • 别人的口子:会随行业跟进而变,是 Follow-up 第 2 条要盯的。天生的那几条不会变,所以结论"只能拖慢,不能阻止"不会因为下一个版本翻掉

一句话:Anthropic 能让蒸馏变贵,不能让蒸馏消失

谁影响方向确定性

一句话:对 token 和算力主线几乎中性,真正的变量是中美模型差距会不会因此拉开

8. 最容易被误读的几点

大家以为实际
蒸馏被彻底堵死了只是在 Anthropic 自家平台,推理泄漏降了 10-100 倍。答案照样能拿,别家的门照样开着
中国模型从此追不上了GLM-5.3 已经只落后约 4 个月,而且权重已开源。能拖慢多少要看下一代,目前没有数据
Anthropic 为此少赚很多钱按公开数字估算约占收入 0.2-0.3%
开发者体验大受影响用官方工具 (Claude Code、Agent SDK) 的不受影响;自己写框架、习惯回改前文的要改代码
preserved thinking 是新功能是防盗措施。对用户唯一的好处是自己的推理信封更难被别人冒用
Claude 不再"想"了照样想,只是想的过程不完整地给你看,给的是摘要

9. 推掉的蒸馏流量有多大

文章只说推掉了"数万亿 token 的付费流量"和"可观收入",没给数。下面用 9 月报告里的公开数字估一个量级。

蒸馏 token / 年 = 每季度蒸馏对话数 × 4 × 每次对话 token 数
蒸馏收入 / 年 = 每季度蒸馏对话数 × 4 × 每次对话收入
占比 = 蒸馏收入 / 年 ÷ Anthropic 年化收入
  • 每季度蒸馏对话数:阿里 1.51 亿 + 月之暗面 2,300 万 (都是 5-7 月) + DeepSeek 1,210 万 (7 月 14 天) ≈ 1.86 亿。另外 4 家 (智谱、小米、MiniMax 等) 没公布数,所以这是下限
  • 每次对话 token:蒸馏请求通常是短问题、长推理,第三方 tokencost.app 按约 2K 输入 + 8K 输出估算
  • 每次对话收入:同一来源按 Opus 定价估约 $0.21。这是最软的锚
