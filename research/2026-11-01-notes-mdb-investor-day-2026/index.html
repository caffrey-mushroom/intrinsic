MongoDB 2026 投资者日 (2026-09-29，纽约 Nasdaq) 初读笔记

逐段英文原文、中文翻译和解读，外加关键数字、术语表和下一季要盯的事。给第一次读这家公司投资者日的人。

这场讲了什么

先搞懂这家公司

这不是财报电话会，而是 MongoDB 一年一次的投资者日，约 4 小时：CFO 先处理前一天 CEO CJ Desai 辞职去 Meta 的消息 (前任 CEO Dev Ittycheria 回来做临时 CEO) 并做一场短问答；然后 Dev、核心产品负责人 Ben Cefalo、AI 负责人 Pablo Stern-Plaza、新 CRO Ryan Mac Ban、首席客户官 Erica Volini 依次演讲，中间有 Citizens Bank 和 Emergent 两位客户上台；最后 CFO Mike Berry 讲财务和新的三年目标，再做一场 16 个问题的长问答。时间点在 Q2 FY27 (2026 年 5-7 月) 财报之后、Q3 财报 (12 月初) 之前。

背景：MDB 约 3/4 收入是 Atlas (云上托管的 MongoDB，按集群规格 × 小时收费)，约 1/4 是 EA (客户自己机房里的 MongoDB，按年订阅)。Atlas 已经连续 6 个季度 ~29%。市场的三个担心：coding agent 写新应用时默认选 Postgres (入口)、按容量计价让 AI 读写量不直接变成收入 (变现)、CEO 上任 10 个月就走 (管理层)。

这场投资者日的三条主线：(1) 上调目标：新三年目标总收入 20%+ (旧为高十几)、Atlas 中二十几 (旧为 20%+)、EA ARR 10%+；(2) AI 第一次量化：AI 原生公司占 Atlas 收入 3-5%、同比 +165%，有 AI 用途的 Atlas 客户 30% 到 40%；(3) 三个新产品：Atlas Infinite (存算分离、按用量)、Atlas Agent Engine (agent 记忆和运行时)、EA 搜索和向量，但 CFO 明说 Infinite 要到 FY29 才有可观收入。管理层在问答里第一次承认 coding agent“多数时候选 Postgres”。

这一场

一句话：目标上调 (三年 Atlas 中二十几、总收入 20%+) 并第一次量化 AI (AI 原生占 Atlas 3-5%、+165%)，但新产品收入要到 FY28-29，而管理层自己承认 coding agent 多数时候选 Postgres，入口问题靠“长大后迁过来”来补。

  • 新三年目标 (时间框架从 3-5 年缩到 3 年)：总收入 20%+ (旧：高十几)，Atlas 中二十几 (旧：20%+)，EA ARR 10%+ (旧：隐含个位数)，营业利润率每年 +100-200bp (不变)，FCF 转化率 80-100% (不变)，FY27 起 GAAP 盈利；Rule of 40 今年 44，三年后接近 50 (不承诺)。
  • AI 第一次量化：AI 原生公司和前沿实验室占 Atlas 收入 3-5%，Atlas 收入增速三年分别 +67%、+129%、+165%，客户数两年翻倍；有 AI 用途的 Atlas 客户从 30% 到 40%；$100K+ 客户用多产品的比例 34% 到 48%；向量搜索客户两年 4 倍。但 CFO 承认多产品“采用很多，还没产生太多收入”。
  • 客户分层新数据：$5M+ ARR 客户五年复合 +57%，$1M+ 复合 +34%，总客户复合 +23% (7 万+)。CRO 给的一年数据：$100K+ 和 $1M+ 客户同比都是 +17%。Atlas 连续六季同比新增美元创新高，大部分增长来自美国和 EMEA 大企业。
  • 三个新产品和收入时间表：EA 搜索和向量单独收许可费，FY27 小、FY28 多；Atlas Infinite (存算分离、只为用到的付钱) 公开预览仅在 AWS，2028 年初 GA，FY29 才有可观收入；Atlas Agent Engine (agent 记忆、运行时、治理) 所有 Atlas 客户免费可用，通过带动 Atlas 用量变现，FY28 看到势头。
  • 入口问题：管理层用“每季度 50 万个免费集群且逐年增长”、托管 MCP 关注度 8 倍、coding agent 插件和 Vercel v0 接入来反驳；但问答里 Ben 承认 coding agent“多数时候选 Postgres 加 JSONB”，Dev 承认“可能慢了一点，比如 Supabase”，应对逻辑是“长大后迁过来” (Emergent、ElevenLabs、某前沿实验室四周迁完)。
  • 收费方式：Ben 明说 Atlas Dedicated 按选的容量和存储收费，没超出容量时 agent 打 10 万次查询也不多收钱，把它当作“可预测”的卖点；Infinite 是将来按用量的补丁，Ben 不预期现有客户大规模迁过去。
  • 其他：约一半收入经过云厂商市场且增速更快；EA 拐点在 FY26 Q3，ARR 连续三季双位数，$100K+ 的 EA 客户约 2/3 也用 Atlas (不是蚕食)；SBC 占收入从 30% 降到 20%，不给目标；新增 10 亿美元回购；新 CRO 来自 Confluent，之前六个月没有 CRO；AMP 迁移进展慢于预期，新伙伴是 Cognition。

术语大白话和收钱的关系
AtlasMongoDB 自己在 AWS、Azure、GCP 上运营的托管数据库，客户不用自己装和维护，像租一台配好的服务器。按集群规格 × 小时收费，约占收入 3/4，增速 ~29%。
EA (Enterprise Advanced)客户装在自己机房或私有云里的 MongoDB 企业版，像买软件许可自己用。按年订阅，多年合同里许可部分一次性确认，所以收入跳动，公司改用 ARR 看。
Atlas Dedicated / Atlas Core Database现在的 Atlas 主力产品，客户选一个固定规格的集群 (比如 M60 × 3 节点)，现更名为 Atlas Core Database。没超出容量就每月同一个账单，AI 读写量多了不直接多收钱。
Atlas Infinite新的 Atlas 部署选项，把计算和存储分开，计算可以瞬间扩缩，像打车按里程付费而不是按月租车。只为用到的付钱；公开预览仅 AWS，2028 年初 GA，FY29 才有可观收入。
Atlas Agent Engine给 AI agent 用的一整套设施：长期和短期记忆、运行时、安全护栏和治理，不绑定云和模型。所有 Atlas 客户免费可用，靠带动 Atlas 用量变现。
存算分离传统数据库加内存或 CPU 时要连硬盘一起加；分开后可以只加计算或只加存储。降低闲置成本，对突发负载更省钱，也可能让现有客户少付钱。
OLTP / OLAPOLTP 是交易型数据库，处理下单、转账这种一笔笔的读写；OLAP 是分析型，做报表和大规模统计。MDB 只做 OLTP；SNOW、DBX 做 OLAP 并通过收购 Postgres 公司进入 OLTP。
JSON / 文档模型把一条记录存成一个像表单一样可以嵌套的文档，而不是拆进多张固定列的表格。MDB 的根本差异化，管理层称之为“AI 的默认语言”。
JSONBPostgres 里存 JSON 的字段类型，等于在关系型表格里塞一个 JSON 列。coding agent 多数时候选它，是 MDB 入口问题的核心。
向量搜索 / 嵌入 / 重排把文字变成一串数字 (嵌入)，按意思相近来找 (向量搜索)，再把找到的结果按相关性排序 (重排)。MDB 内置向量搜索，Voyage 提供嵌入和重排；客户数增长快，收入还小。
