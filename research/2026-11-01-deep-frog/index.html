结论

一句话：FROG (JFrog) 是软件"成品"的中央库房：开发者和 AI agent 下载的开源包、CI 构建出来的镜像和安装包、AI 模型文件，都要进它、经它、从它发出去。AI 让成品变多，云版按 GB 收费，所以云收入 +53%、总收入从 +22% (1Q25) 加速到 +29%。但现价 $94.39 (2026-10-30 收盘) 隐含"未来 5 年收入每年涨 ~32-38%"，比我们的加速情景 (~25%) 还高；扣掉 SBC 后 FCF 收益率只有 ~0.1%。结论：不买，放观察名单，买点 $50-60。

为什么涨了这么多：2026 年两次"超预期 + 上调指引"，全年收入指引从 $623-628M 提到 $648-652M，"基础云增长" (只算合同承诺) 从 30-32% 提到 41-43%；前沿 AI 实验室客户从 3 家到 4 家 (OpenAI 已是 18 个月的客户)；npm 投毒一波接一波，带来安全大单，RPO +38%。股价从 2 月低点 $34 涨到 8 月历史新高 $105.76。

为什么不买：(1) 加速里有一块不在合同里。客户用超了承诺额就按贵 30-40% 的单价补交 (超额用量)，管理层不拆、不放进指引；CFO 5-19 说"We really, truly don't know" (能不能持续)，8-12 又说 2027 年做预算时客户对超支的"宽容度"会下降。(2) 量最大的客户不按量付钱。前 3 家前沿 AI 实验室全部自托管、按服务器付费、没买安全。(3) 扫描在被商品化。2026-02-20 Anthropic 发布 Claude Code Security，FROG 当天跌 20% 以上。(4) 扣 SBC 后不赚钱：过去 4 季 FCF $170M、SBC $161M，股本每年 +4-5%。

什么会让我们改主意：2027 年 2 月首次全年指引的"基础云增长" ≥30%，同时 cRPO 增速持续不低于收入增速，说明超额在变成合同；或者至少一家 AI 实验室转到云 / 混合并买了安全。价格回到 $50-60 区间也会改变结论。

这只股票在测试什么

一句话：FROG 在测试的是，AI 带来的二进制 (GB) 能不能变成合同里的钱，而且每 GB 的单价不被折扣吃掉。

"量"已经被证明了：Artifactory 里的二进制一年 +136% 到 180 亿个，渠道商说 AI 让每个开发者每小时产生成品的次数从 1 次变成 10-20 次。没被证明的是"钱"：去重和缓存让存储增量"是渐进的不是爆发的" (Stifel 客户调研)；头部 10 个大客户用量只涨 20-40% (MeritForum 专家)；最大的增量客户 (AI 实验室) 按服务器付费；而云上的增量有一部分是不进合同、贵 30-40% 的超额用量。所以问题拆成四条杠杆：

1. 产品：它是什么、怎么运转、凭什么赢

1.1 一句话 + 一个例子

程序员写的是源代码，像菜谱；源代码编译、打包后变成能直接运行的"成品"，叫二进制 (binary) 或软件制品 (artifact)：容器镜像、npm / Python / Java 软件包、手机安装包、车机升级包，现在还有 AI 模型文件和给 AI agent 用的 MCP 工具包、skills。GitHub、GitLab 存菜谱；JFrog 的核心产品 Artifactory 存做好的菜，是一家公司所有"要上线的成品"的正本，并负责把它们送到各个机房。

打个比方：一家连锁餐厅的中央厨房。菜谱在研发部 (GitHub)。中央厨房有冷库 (Artifactory：半成品、成品按批次存放，谁什么时候做的都有记录)、进货质检 (Curation：供应商送来的原料先过一道门，有问题直接拒收)、出货抽检和台账 (Xray 扫描库里的成品，AppTrust 记录每批货过了哪些检查、谁批准出货)。门店 (生产服务器) 只从冷库拿货，不直接去菜市场买。下面这张图把一个开源包从公网到生产服务器拆成 6 站，标出每站怎么收钱、哪站最容易被替代、AI 怎么改它：

1.2 行业背景：为什么需要它

一次构建要下载几百上千个开源包，最笨的做法是每台机器直接从公网 (npmjs、PyPI、Maven Central、Docker Hub) 下载，成品放网盘。这样会遇到四个问题，每个都有真实事件：不稳定 (2016 年有人从 npm 删掉一个 11 行的小包 left-pad，全世界成千上万个项目当天无法构建)；有毒的零件 (2025-09 起 Shai-Hulud 蠕虫三波感染 npm 上数百个包，偷开发者密钥再自我传播)；不知道生产上跑的是什么 (2021 年 Log4Shell 爆出时，很多公司花几周才查清哪些系统用了 log4j)；网盘不懂"包" (npm、pip、Docker 各有协议和元数据，网盘只能存文件)。Artifactory 的做法是让所有工具都指向它一个地址，它会说 60 多种包格式的"方言"，第一次去公网拉、之后全公司从缓存拿，自己的成品带构建记录入库，按内容校验和去重 (同一个文件全公司只存一份)。难点是几十种格式都要原生、每天几百万次下载、挂了全公司停工，以及云和自托管要完全一样还能混合。

1.4 逻辑上：AI 是受益还是受损

方向机制证据我们的判断
受益：二进制变多agent 写代码 → 构建次数、镜像、包都变多 → 云版 GB 变多二进制一年 +136% 到 180 亿个；每个开发者每小时产生成品从 1 次到 10-20 次 (渠道 04-17)；云 +53%核心一行：AI 让 GB 这个收费单位变多，但去重、缓存、阶梯折扣让收入涨得比量慢
受益：新的二进制种类模型、MCP 服务器、agent skills、插件都是要存、要扫、要审批的文件"模型是最大的二进制，旧版本不能删" (CFO 8-12)；MCP Registry (03-18)、Cursor 插件 (04-15)、Claude Code 插件 (06-10)方向对；Hugging Face 也在推自家企业网关抢模型这一块
受益：攻击变多AI 让黑客更强、供应链攻击更频繁 → CISO 在门口加 Curation2026-05 是有记录以来供应链攻击最密集的月份 (第三方统计)；80% 新 $1M 客户带安全真实，但按人头收费、和量无关；有"恐慌性购买"成分 (IR 5-27)
受损：收费单位接不住AI 实验室自托管按服务器；安全按开发者人头，开发者如果因 AI 变少，单位就变少前 3 家实验室全部自托管、只买 Artifactory (IR 5-27)；"此类客户的用量与订阅费用不直接挂钩" (MeritForum 专家)AI 带来的量里最大的一块，FROG 吃不到；CFO 说定价"可能变，但我们不会主导"
受损：扫描商品化模型能读代码、找漏洞、给补丁2-20 Claude Code Security 发布当天 FROG 跌 20%+；前 GitLab 销售："开源扫描 + AI 降低了付费安全的必要性"伤安全的定价，不伤库房
受损：自托管变成攻击面agent 在沙盒里找到自托管 Artifactory 的零日并逃逸OpenAI 事件 (07-21 披露)；8-9 个 CVE；3,000+ 自托管客户"不能确定都打了补丁" (CFO 8-10)短期伤信誉，长期可能推迁云 (公司口径)

和 DDOG、NOW 的类比：DDOG 受益于软件系统更复杂 (host 和 GB 变多)、受损于存储便宜；NOW 受益于要派活和验收的事变多、受损于干活的人变少；FROG 受益于软件成品变多，受损于"最大的量在自托管"和"扫描变便宜"。三家里 FROG 的收费单位和 AI 最直接挂钩，但只挂了一半收入。

1.5 核心竞争力

先说它不是最强的地方。扫描这一站，Snyk 起家就做开发者安全，GitHub Advanced Security 扫源代码，模型自己 (Claude Code Security) 越来越便宜，FROG 的 Xray 只是"够用、而且捆绑"；进门这一站，Socket 在 AI 原生公司里很强 (自称 Anthropic、xAI、Cursor 是客户)。它强在进门、库房两站和分发，而且是唯一这四站都最强的厂商：

为什么只有它做成了统一库房：Artifactory 从 2008 年起就是"通用仓库"，一个产品原生支持 60 多种包格式 (管理层说 36 种主要语言)，老对手 Sonatype Nexus 卡在约 15 种；云厂商的 registry 各管一种 (AWS ECR 只管容器、CodeArtifact 只管语言包)，还只在自家云上。云、自托管和混合用同一套代码，CFO："There's no other company in our space that's hybrid" (8-10 KeyBanc)。第 4 家前沿 AI 实验室就是因为"原来的对手撑不住这个量"换过来的，用 JFrog 云当"母舰"，在各数据中心放自托管节点 (CEO，Q2 电话会)。

为什么它记下的东西最全：所有二进制都必经它。Artifactory 管理的二进制 180 亿个 (+136%，2026-06)；83% 的 Fortune 100 是客户，科技和金融前十全部在用；$1M+ ARR 客户 40 家 (1Q24) → 97 家 (2Q26)；Fortune 100 车企 ARR 从 2016 年 $1,000 涨到 2025 年 >$1,020 万。安全"不用另接数据"：Fortune 100 金融公司不到 8 小时就给 2 万开发者上线了 Advanced Security + Curation。

为什么可持续：靠下面这个飞轮，加上"换掉 = 全公司停工"的切换成本 (GRR 97%，两年没动)。也要看清它保护不了什么 (右下框)。

巨头为什么不能自己做：AWS、微软为什么不做一个一模一样的？

先核对前提：巨头其实都做了。AWS 有 ECR (容器) 和 CodeArtifact (语言包，2020 年 GA)，微软有 Azure Artifacts、ACR，还有 GitHub Packages 和免费的 ghcr，Google 有 Artifact Registry。结果是：它们赢了单云、单格式的小团队 (CFO 承认云厂商"有价格优势")，但没拿下大企业的库房。写代码解决不了的壁垒有四个：

  1. 中立。大企业多云 + 自有机房，不想把所有软件成品的正本交给其中一家云；JFrog 自称"二进制的瑞士"，客户可以通过三家云的 marketplace 买它、抵扣各自的云承诺消费。
  2. 格式和混合部署。云厂商的 registry 各管一种格式、只在自家云上；要在自有数据中心、隔离网络、多个云区域之间同步同一批镜像和模型，目前只有 JFrog 现成。
  3. 迁移 = 停工。几千条流水线、几百万个二进制和多年的构建记录绑在 Artifactory 上，换的成本不是许可费而是停工风险 (PANW 云安全顾问，GuidePoint 07-16)。
  4. 不值得。仓库这一层全行业一年 ~$1.1B (我们的估算)，对云厂商来说是卖计算和存储的附送品，没有动力为大企业的多云需求投入。这一条是我们的判断。

所以巨头的真威胁不是替换大企业库房，而是"够用 + 免费"：新公司、小团队从第一天就用 ghcr 或 ECR，长大后也不一定迁过来；加上模型把扫描做成商品，FROG 往上卖安全的空间被压缩。

用了 Artifactory 的企业还会用 GitHub 或云厂商 registry 吗？会，并存是常态

  • 反方向的整合：Camunda 2021 年从自建 Nexus 迁到 Artifactory SaaS (运维负担、磁盘反复出问题、要多区域复制)；第 4 家前沿实验室替换掉"撑不住量"的对手 (Q2)。公开的大客户流失给 GitHub 或云厂商的案例：没有查到。

5. Invert：Bear case

把多头逻辑倒过来，问"什么情况下 FROG 3 年后让人后悔"。最大的那条 (超额回落) 先画成传导链，再逐条展开：

  1. 超额用量回落，转承诺时单价降。2027 年预算季客户 CFO 开始管 AI 相关开支，超额被砍一部分；剩下的转成承诺，单价降 25-40%。早期信号：云 q/q 从 +11% 降到 +7% 以下；cRPO 增速低于收入；NDR 从 121% 回到 117-118% (就是"剔除超额"的 NDR)。
  2. AI 实验室的量永远在自托管里。最大的增量客户按服务器付费、不买安全，第 5、6 家也照此办理；"AI 让二进制暴增"变成"FROG 卖了几台服务器"。早期信号：新实验室客户仍是纯自托管；管理层不再提"moonshot"。
  3. 扫描被模型商品化，安全卖不上价。Claude Code Security 这类工具进入企业流水线，CISO 认为"模型扫过就够了"；Curation 被 Socket 等低价方案和平台自带功能替代。早期信号：安全 ASP 下降；80% 新 $1M 客户带安全的比例下滑；管理层开始强调"捆绑"而不是"加购"。
  4. 长尾被平台自带吃掉，客户数继续减少。新公司从第一天就用 ghcr、ECR，FROG 只剩大企业，而 83% 的 Fortune 100 已经是客户。早期信号：总客户数继续下降；$100K+ 客户增速 <15%。
  5. SBC 降不下来，稀释吃掉 FCF。股本每年 +4-5%，SBC 停在收入的 20% 以上，FCF Margin 到 30% 也只剩 ~10% 给股东。早期信号：SBC / 收入 >25% 持续；回购授权不用。

Bear case 的数字：5 年 CAGR ~13% (20/15/12/10/9%)，FCF Margin 30%、SBC 18%、退出 25x (A) / 22x (B)、股本每年 +5%，每股 $24 (口径 A) / $37 (口径 B)，比现价 -74% / -60%。现价买入 5 年年化 -20% / -11%。和 NOW 不同，FROG 的 bear case 下行很大 (~60-74%)，因为现价里既有高增速、也有高倍数。

什么能证明 bear 错了：4.2 的续约测试及格 (续约后合同总额 ≥ 续约前承诺 + 超额的 ~110%)；2027 年初始基础云指引 ≥30%；cRPO 增速连续两季 ≥ 收入增速；至少一家前沿实验室转到云或混合并买安全；SBC / 收入降到 20% 以下。
