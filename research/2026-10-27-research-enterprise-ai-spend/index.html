企业 AI 支出：2025 年到现在

企业到底在用 AI 做什么、钱从哪来、节奏怎样、ROI 如何。合并 62 篇企业调研、专家纪要、业绩会和我们 11 家软件公司的季度数据，并对照 Anthropic、PLTR、埃森哲。

48%Anthropic 收入经云市场 (S-1)
50/50订阅/API，一年前 90/10
7-8%客户做到全企业部署 (2026Q3)
~5%企业建好了 AI 评估体系

一页结论

一句话：2025 年到现在，企业花在 AI 上的钱，最先、最多的部分花在了自己的工程师身上。钱大多不是新增的，而是从外包、软件许可、招聘计划和已经承诺的云预算里挪出来的。节奏是"试点慢、爆发快、治理更快"：2026 年初 coding agent 一放开，有的公司 4 个月就花完了全年预算；一个季度之内 CFO 就开始设上限、做模型路由。单个用例的 ROI 已经算得出来，公司层面的财务 ROI 还普遍没有被证明。

做什么：用量第一是写代码。95% 的工程师在用 AI 写代码，深度使用 agent 的约 20-30%；Anthropic 的爆发主要来自 Claude Code。第二梯队是客服、知识检索和文档处理，这几类的单次成本已经降了 70-90%。理赔、采购、销售这些业务 agent 正在上线，但做到全企业部署的客户只有约 7-8% (微软 FDE 团队看到的客户，2026Q3)。

怎么花钱：IT 预算总盘子基本不动 (埃森哲：客户"花法变了，但总量没涨")。AI 占 IT 预算的比例，试点企业不到 1-2%，领先企业到 10-20%，靠"拆东墙补西墙"凑出来。买的渠道先走云市场：Anthropic 48% 的收入经 AWS Bedrock、Google Vertex、微软 Foundry。计价一年内从订阅为主变成订阅和 API 各一半 (从 90/10 到 50/50)。

节奏：分五段。2025H1 试点；2025H2 coding 起量；2026Q1 爆发 (token maxing)；2026Q2 CFO 介入；2026Q3 价格战和路由。到 2026Q3，token 用量涨 3 倍时，支出只涨 50-80%。2027 年预算方向仍向上，但增速放缓，要到 2027 年 1-2 月才看得清。

ROI：可以量化的集中在客服、文档、审批流和代码。公司层面，不到 25% 的组织追踪明确 KPI，只有约 5% 的企业建好了评估体系。省下的时间没有变成裁员，而是变成少招人、把外包收回内部、在续约时让利给客户 (IT 服务续约普遍让利 10-15%)。一条经验规则：一类工作的工作量降不到 30%，省下的时间就腾不出一个人，也就进不了预算。

六条规律

  1. AI 先自动化了买 AI 的人自己。IT 部门是每家企业最早、用得最深的部门，因为代码能跑测试，对错可以马上验证；理赔、法律、金融缺少这样的中间验证步骤，落地就慢。所以 2026 年的钱先流向模型公司、数据平台和观测，业务软件晚一拍。
  2. AI 预算是挪出来的，不是加出来的。IT 总盘子不变，钱从外包合同、低优先级软件项目、空缺岗位和年末剩余的云额度里挤。所以每个 AI 赢家旁边都站着一个输家：IT 服务 (埃森哲 FY27 有机增速约 2-2.5%)、按席位收费的 SaaS、BPO 外包。
  3. 用量和支出在脱钩。2026Q3 起模型降价、换开源、做路由同时发生：Ramp 数据里 Anthropic 客户每 token 的价格 7 月底到 10 月初降了约 40%。按量计费的公司要看的是"量涨多少、价降多少"的剪刀差，不是用量本身。
  4. 试点慢、爆发快、治理更快。从测试到大规模投入通常 12-24 个月，但 coding 一放开，用量几个月内就能翻倍；CFO 的反应时间只有一个季度。企业 AI 支出的曲线是台阶加平台，不是平滑的指数。
  5. 省时间不等于省钱。节省 5-10% 的工时什么都不会改变，要某类工作量降 30% 以上才能腾出人。所以 ROI 先表现为"不招人"和"外包回迁"，这在财报上看不出来，CFO 也就很难认账。
  6. 钱分给谁，取决于怎么买。平台捆绑的大单 (微软给 EY 的 $10 亿交易) 里，服务只占 10-15%；第一次定制落地的项目里，实施和咨询能占 70-85%。随着数据连接和权限被复用，实施占比会下降 (PLTR 首次部署之后的毛利从 80% 升到 87%)。

通过谁买：先走云，后直签

原因是走云厂商可以省掉新供应商的准入、采购和法务流程，还能消耗已经承诺的云额度；规模上去以后再直签，是为了拿到更高的速率额度，不一定更便宜。S-1 披露 Anthropic 48% 的收入经 CSP 市场产生，和这个路径一致。另一条路是 SaaS 内嵌：埃森哲说过去 12 个月客户"越来越多通过已经在用的 SaaS 获取前沿模型"。

计价：从席位到 token

GitHub Copilot 和 Microsoft Cowork 已改为按用量计价；Salesforce 从 credit 转向按动作 (AWU) 收费，因为反复调用让客户投诉账单 (10 家客户里 8 家上线头两个月账单约为预算的 2 倍)。反例也有：一家制药集团订阅占比从年初 20% 升到 75%，一家支付公司 3-6 月新增的 $20 万/月全部是订阅。席位适合"人用 AI"，token 适合"AI 自己跑流程"，后者是增量的主体。

钱流向谁

三个发现：

  • 拐点集中在 2026Q1。SNOW、DDOG、Databricks 的加速都发生在 2025Q4-2026Q1，与 Claude Code 和 Cortex Code 起量、Anthropic run-rate 从 $90 亿到 $300 亿是同一个季度。这是 coding agent 带动的，不是业务 agent。

为什么公司层面的 ROI 还证明不了

障碍数据
没有度量不到 25% 的组织追踪明确定义的 KPI (Acecamp，2026-04)；约 5% 的企业准备好了 eval (Hamel Husain，2026-09)；欧洲车企只有 10-20% 的项目被严格量化和审计；大规模发许可后多数只统计登录和日活，是"虚荣指标"
省时不转成钱省 5-10% 工时不会降成本，要某类工作量降 30% 以上才能腾出人 (Funda Vol.2)；AI 只提升了约占 20% 工作时间的编码效率，其余 80% 没缩短 (Google 模型训练专家)；AI 产出约 20% 需要返工 (印度 HR 服务 A)
非 token 成本高POC 到生产第一年成本至少 3 倍，通常 3-4 倍；律所 2027 年 AI 工具约 $60 万，开发人力 $300-400 万，是工具费的 5-7 倍；汽车案例一次性构建约 $100 万，6 个月 AI 基础设施只要 $7.2 万
价值被别人拿走客户要求 IT 服务降价 10-20%，服务商只能承受约 5%；按交易计费的 bot 一个月 $10 万，不如一年付 $10 万请一个人 (前埃森哲资深人士)
广泛采用、少数获益88% 的组织在用 AI，只有 6% 获得实质企业价值；Gartner 预计约 40% 的 agentic AI 项目到 2027 年会因成本、价值不清或风控不足失败

这对财报意味着什么：少招人和外包回迁不会出现在 AI 的 ROI 表里，而是出现在"人数增速低于收入增速"和"外包供应商收入下滑"上。所以要验证企业 AI 的 ROI，与其看企业自己的报告，不如看 IT 服务商 (埃森哲、Cognizant、TCS) 的有机增速和定价。

成本治理和价格战

我们原来以为成本治理是 2026 年中才开始。证据显示它更早、也更不均匀：AI 原生和科技公司一年前就在换模型，传统企业到现在还没感到痛。

时间发生了什么
约 2025-09一家数字营销公司通过选模型把约 $10 万/月的 token 账单砍掉一半以上
2025H2 → 2026 春AI 原生企业开始用中国开源模型，2026 年春季指数级增长
2026Q1Uber、湾区团队耗尽全年预算；Salesforce 财务发现连 HR 都在用高端模型做基础任务
2026Q2Salesforce 人均 AI 花费 $700-1,000 → $500-700，员工个人预算 $1 万 → $5,000，目标 40% 前沿 / 60% 低成本模型；Uber 每人每月 $1,500-2,000、取消 token 排行榜；埃森哲推出 Tokenomics 业务 (类比云 FinOps)
2026-08Portkey 网关上的企业支出：前沿 70%、开源 20%、旧模型 10%；中国开源份额 3 个月从 10% 到 20%；Funda Vol.1 的 12 家中约 7 家已有明确预算管理，只有 1 家接近 token maxing
2026-09/10OpenAI Luna 降价 80%、Anthropic Opus 5.5 降价；一家制药集团自托管开源模型处理约 50% 的 API 调用，成本比外部 API 低约 90%；埃森哲 Tokenomics 研究：只有 10-20% 的企业工作流值得用前沿模型

但传统企业还没走到这一步

Harvey 的开源模型占比是 0，ServiceNow 的开源模型不到生产负载的 5%，一家物流企业出于合规禁止员工用开源模型。分界线很清楚：AI 支出到了每周或每月 $100 万以上的公司才认真做路由和换模型 (Portkey 专家)；传统企业的 AI 成本占总预算很低，管理层不关注。这意味着今天 AI 原生公司在做的事，是 1-2 年后传统企业的样子。

对四个假设的检验

假设证据计数结论
H1 最大的变化是 coding agent，AI 先自动化了 IT；业务 agent 是第二波124 条支持 / 19 条反对基本成立。收入拐点 (Anthropic、SNOW、DDOG) 都在 coding 起量的季度；IT 是最早、最深的部门。需要修正的是：业务 agent 在 2026Q2-Q3 的增速最快 (跨部门部署 4-5% → 12-18%)，只是基数小；传统行业连 coding 都还没普及。
H2 付给模型公司的钱很多不是新增 IT 预算85 条支持 / 14 条反对成立。来源依次是：已承诺的云额度 (48% 经云市场)、人头和招聘计划、外包、软件项目。新设预算存在 (英国支付 £450 万、B2B SaaS $4,000-5,000 万)，但多是小公司或单一项目。
H3 模型和算力拿大头，软件拿回声，实施费是软件费的好几倍；按量收费长得快，按席位/人时的被通缩93 条支持 / 31 条反对后半句成立，前半句要改。按量 vs 按席位的分化很清楚 (SNOW 37% vs GTLB 21%，埃森哲有机 2-2.5%)。但"实施费是软件费好几倍"只在第一次定制落地时成立；平台捆绑的大单里服务只占 10-15%。
H4 直接财务 ROI 难证明；非 token 成本抬高门槛；2026 年中开始成本治理202 条支持 / 30 条反对成立，时间要提前。ROI 难证明和非 token 成本高都有大量证据；但成本治理在 AI 原生公司里 2025H2 就开始了，传统企业到现在还没开始。

最有分量的反面证据

  • 价值链里模型只拿 10-15%。前 C3 AI 高管估计基础设施 30-35%、软件约 30%、实施约 30%，模型 API 只有 10-15% (ThirdBridge，2026-07-03)。这与"模型拿大头"相反，但他算的是企业生成式 AI 的全部支出，包括预测式 AI。
  • 席位型 AI 还在扩张。Office 365 Copilot 在中小企业的采用仍在加速；ServiceNow 内部没看到收入下降或席位减少；Harvey 认为 Slack、Notion、Glean 这类席位制 SaaS 不会被自建替代。
  • AI 增量没有流到观测和数据库。欧洲保险公司没有因此多买 Datadog、Snowflake、MongoDB；Snowflake 一线也说客户的 AI 部署不额外增加公有云采购。数据平台受益的是 coding 和数据工程，不一定是每一个业务 agent。
