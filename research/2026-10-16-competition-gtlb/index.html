回答三个问题：GitLab 和 GitHub 是什么格局；会不会有新进入者；这个行业的 winner pattern 是什么

GitLab 和 GitHub 不是对称竞争。GitHub 是开发者的默认入口，GitLab 是大企业里唯一能整套替代它的第二平台，靠“能装在自己机房 + 一套产品管到上线 + 不绑定任何一家 AI 公司”在受监管客户里赢。今年格局对 GitLab 边际变好，因为 GitHub 被并进 Microsoft 的 AI 部门、迁 Azure 迁到一半、频繁宕机。新进入者是真的：Cursor 8 月上线了自己的代码仓库，OpenAI 在做给 agent 用的 GitHub 替代品，Anthropic 自己换掉了 Git。但它们是从“写代码的入口”往下吃，先咬的是 GitHub 的云上和新团队，不是 GitLab 的自托管合规客户。这个行业的规律是：每次范式切换，入口会换手，但入口下面的代码仓库很少换手；贴着仓库的功能会被平台吸收；企业市场最后是“一大一小”。GitLab 当不了赢家通吃的那个，它能做的是 agent 时代绕不过去的治理层，值多少钱仍然看用量收入。

1. GitLab 和 GitHub：不对称的两家

一句话：GitHub 卖的是“开发者都在这里”，GitLab 卖的是“一家供应商管完整条流水线，而且可以装在你自己的机房”。两家的产品越来越像，但赢单的理由完全不同。

两家对照

维度GitHub (Microsoft)GitLab
规模2.25 亿用户；2024.07 年化收入 $20 亿，之后不再单独披露；Copilot 用户 5,000 万 (含免费)FY27 指引收入 $1,129–1,133M；年付费超 $10 万的客户 1,571 家

今年哪些地方在变。

  • 实际数据 GitHub 被 agent 流量压垮了一部分。2026 年 9 月一个月在 GitHub 上有 73.8 亿次提交；Actions 每天跑 7,000 万个任务，2024 年初是 2,300 万。8 月一次宕机近 8 小时，10 月初迁 Azure 只完成约 60% (GeekWire 采访 GitHub COO)
  • 实际数据 GitHub 在想办法多收钱。2025.12 宣布从 2026.03 起对自托管 Runner 按每分钟 $0.002 收费，一周内因反对而推迟；2026.06 Copilot 改成按用量收费，Microsoft CFO 说这样做之后毛利率改善
  • 管理层口径 GitLab CEO 在 Q2 电话会说“我们仍然只有一个主要对手，我们对它的位置比任何时候都强”，首单和扩张的赢单率都在上升，理由是对手“在可靠性和 agent 时代的需求上有困难”。没有给数字
  • 推断 GitHub 的问题是执行问题，不是结构问题。分发优势和开发者心智没有变，迁移完成后这一轮顺风会消失。GitLab 要在这一年里把赢回的客户锁进多年合同
格局一句话：开发者入口 GitHub 赢，没有悬念；受监管大企业里 GitLab 是“必须有的第二选择”，部分客户是第一选择。两家真正正面打的，是中型企业和云上团队，这一块 GitLab 4 月自己承认承压。

2. 会有新进入者吗：已经来了

过去两年，开发者花钱最多的地方从“存代码和流水线”变成了“AI 写代码”。写代码这一层长出了比 GitLab 大得多的公司，它们现在开始往下做代码仓库。原因很直接：agent 写的代码越多，仓库和 CI 就越是瓶颈，也越是数据和锁定点。

为什么新进入者先打 GitHub，而不是 GitLab。

  • 它们的用户就是 GitHub 的用户：个人、创业公司、云上团队。Cursor 的 Origin 连“和外部分享”都要同步回 GitHub
  • GitLab 核心客户要的东西，新进入者都还没有：装在自己机房、断网运行、权限和审计一体、流水线和安全扫描在同一个产品里
  • 推断 中立性在变成卖点。Cursor 现在属于 SpaceX 和 xAI，OpenAI 和 Microsoft 互相既合作又竞争。一家大银行不太愿意把全部代码放在某一家模型公司的服务器上，GitLab 的“不绑定模型、不绑定云”在这时候有价值

真正的长期风险不是“多一个 GitLab”，而是仓库降级。如果 agent 平台 (Cursor、Codex、Claude Code) 变成工程师每天工作的地方，代码仓库就可能退化成后台存储，像今天的对象存储一样按量便宜收费，值钱的上下文、审查和审批都留在 agent 平台里。GitLab 的回应是 Orbit (把整个软件生命周期做成 agent 可查询的知识图谱) 和按用量收费的 credits。Orbit 测试版 2,200 家组织开通、80% 查询来自外部 agent，方向对，但还没有收入数据。

3. 这个行业的 winner pattern

历史上几次换手

时期发生了什么谁赢，为什么
2008–2012从集中式版本管理 (SVN) 换到分布式 Git；SourceForge、Google Code 让位给 GitHubGitHub。新范式下最好用的协作入口 (PR、个人主页、开源社交)，网络效应一旦形成就没人追上
2012–2018GitHub、Bitbucket、GitLab 三家争企业GitHub 拿开发者心智；Bitbucket 只靠和 Jira 捆绑，份额一路流失；GitLab 靠自托管 + 一体化 CI 在企业站住。2018 年 Microsoft 收购 GitHub，GitLab 迎来一波迁移
2015–2022CI 从独立工具 (Jenkins、Travis CI、CircleCI) 变成仓库自带 (GitLab CI 2015、GitHub Actions 2019)贴着仓库的 CI。独立 CI 公司大多衰落，Jenkins 留在老系统里。离仓库越近的功能，越容易被平台吸收
2019–2025安全扫描：Snyk、Checkmarx 等单点 vs GitHub Advanced Security、GitLab Ultimate平台吸收了“够用”的那部分，GitLab Ultimate 因此占到 ARR 59%；最强的单点仍活着，但增长放慢 (记忆，未核实)
2021–2026AI 写代码：Copilot 先发，带着 GitHub 和 Microsoft 的分发入口层被新公司抢走一大块：Cursor 两年做到数十亿年化收入，Claude Code、Codex 跟上。分发优势挡不住产品代差。但代码仍然放在 GitHub 和 GitLab 里

归纳出四条规律

  1. 范式切换时，入口换手；入口下面的“系统记录”很少换手。SVN 换 Git 时托管平台换了人，但 AI 这一轮，写代码的入口换了人，代码还在原来的仓库。仓库里有十几年的历史、权限、审批和审计记录，搬家成本是数据和流程，不是软件本身。GitLab 毛留存 90% 以上就是这个原因
  2. 贴着系统记录的相邻功能，最终被平台吸收。CI 被吸收了，安全扫描被吸收了一半，代码审查正在被吸收 (Cursor 买 Graphite、GitHub 和 GitLab 都做了 AI 审查)。下一个是 agent 的编排和治理：谁批准 agent 的改动、谁对它负责、记录放在哪
  3. 开发者心智赢家通吃，企业采购是“一大一小”。开源和个人开发者有网络效应，只会有一个 GitHub。企业不一样：大客户要一个能压价的第二供应商，受监管客户要能自托管。第二名有结构性的位置，但必须靠一个不同的维度赢 (GitLab 是自托管 + 一体化)，只靠捆绑会像 Bitbucket 一样慢慢流失
  4. 钱跟着计量单位走。收费从“每个开发者”变成“每次 agent 运行、每个 token、每分钟 CI”。2026 年 6 月 GitHub 和 GitLab 同月改成按用量收费。谁掌握计量点 (agent 在谁那里跑、CI 在谁那里跑)，谁拿到 AI 带来的增量

套到 GitLab 身上：它不会是赢家通吃的那一个，入口在 GitHub 和 AI 编码公司手里，不会回来。它的天花板是“受监管大企业的第一平台 + 其他大企业的第二平台”，这个位置在 agent 时代反而更稳，因为 agent 改代码越多，企业越需要一个中立、可自托管、能审计的地方来批准和记录。

它能不能变成更大的生意，看第 4 条：agent 的 CI 和审批在 GitLab 上跑，并且按用量收到钱。这就是 Initial Review 里盯的 Paid CRR ($40M → 年底目标 >$100M)。竞争分析不改变 Initial Review 的结论：值得 deepdive，不追 $53，合理区间 $38–72，$45 以下更舒服。

Deepdive 补充

要核实的数据

  • GitHub 现在的收入规模：Microsoft 2024.07 之后没有单独披露，Copilot 用量收费后的收入只有“环比 +60% 以上”这种说法 (FY26 Q4 电话会，未说明是哪个 Copilot)
  • Cursor 的年化收入：二手来源从 $30 亿到 $40 亿不等，没有一手披露
  • OpenAI 代码托管项目的最新进展：3 月之后没有查到新的报道
  • GitLab 新客户里有多少是从 GitHub 迁过来的，有没有数据

专家访谈要问的

  • GitHub Enterprise 大客户的平台负责人：今年的宕机有没有让你们考虑第二平台，考虑的是 GitLab 还是别的
  • 用 Cursor 的企业：会不会把仓库搬到 Origin，卡在哪 (CI、合规、权限)
  • Bitbucket Data Center 客户：2029 年停服后去哪，上 Atlassian 云还是换 GitLab 自托管
  • 银行或政府的采购：代码放在模型公司旗下的平台上，合规上能不能过
