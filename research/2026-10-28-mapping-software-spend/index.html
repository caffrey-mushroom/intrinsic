这张图怎么读

1. 应用层碎，平台层集中

ERP 一年 $1,460 亿，但排第一的 Oracle 只有 6.7%，前十加起来 32%。每个国家、每个行业都有自己的会计和库存系统。CRM 集中一些，Salesforce 占 26%。平台层反过来：可观测性 DDOG 一家约 35%，数据平台 Snowflake + Databricks 加起来只占 DBMS 的 8%，大头在云厂商和 Oracle 手里。

2. 横向扩张有三种路

  • 同一个买家，卖更多东西。ServiceNow 先卖给 CIO 做 IT 工单，再拿同一套工单系统卖给 HR (员工服务)、客服、安全团队，今年又买了 Veza 做身份。Salesforce 买 Slack、Informatica 也是这条路。
  • 同一份数据，换个用法。Datadog 已经在每台服务器上装了采集器，同样的日志拿去做安全分析 (Cloud SIEM) 就是第二笔钱。Elastic 一个搜索引擎做搜索、日志、安全三件事。CrowdStrike 从端点数据往日志和身份走。
  • 沿着技术栈上下走。Oracle 从数据库往上做 ERP、往下做云；Snowflake 和 Databricks 从分析往下做交易数据库 (Postgres)；模型公司往上做 coding (Claude Code、Codex) 和部署。

垂直软件也会横向，只是在一个行业里横向：Toast 卖餐厅点单系统，再顺手做收单和排班发薪，把一家餐厅的 IT 预算全吃下。

3. 微软和云厂商在每一格

点"微软"就能看到：协作、开发、安全、身份、数据、CRM、ERP 都有它的产品。独立厂商的护城河，主要是要比"打包送"的版本好到值得单独买。

4. 叠上我们的框架

切到框架视图。平台层多数是受益 (按用量收费，agent 越多用得越多)，应用层多数中性或受压 (按席位或员工人数收费)。最受压的是最底下那一格：IT 服务 $1.57 万亿的人力预算，正是企业买 AI 的钱的来源。但受益的品类估值也最贵，和我们 three-theses mapping 的结论一致。
