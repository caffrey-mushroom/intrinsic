结论

一句话：Databricks (DBX) 是企业的"数据厨房"：各个系统的原始数据被搬进来、清洗加工，存在客户自己云账户里的开放格式文件中，再给分析师、数据科学家和越来越多的 AI agent 用，按"每跑一次计算"收钱。基本面是这批软件公司里最好的之一 (run-rate >$7B、+80%、NRR >140%、FCF 打平)，但 +80% 很可能就是这一轮的顶点，而私募和二级市场的价格已经按"高增速再维持很多年"定价。结论：二级市场不追 (Forge $288/股，隐含 ~$217B)；IPO 或二级市场的买点是 $150-170/股 (约 $113-128B，13-15 倍 NTM 收入)。

为什么基本面是真的：run-rate 从 $40 亿 (2025-07，+50%) 到 $48 亿 (+55%)、$54 亿 (+65%)、$70 亿 (2026-07，+80%)，连续四季加速；数仓产品 DBSQL >$15 亿、+100%；$1M+ 客户 650 → 1,000+，$10M+ 客户 100+。和 SNOW 一样按计算收费，agent 查数据比人勤、要的数据更新鲜，账单变大；而且它在三个最热的地方都最强：数据工程 (把原始数据加工成 AI 能读的表)、机器学习和 AI 平台、统一的数据目录 (Unity Catalog)。

为什么还不买：(1) 加速的质量要打折。按我们的拆解，+80% 里 DBX 自己的核心 DBU 只贡献 ~20pt；DBSQL 里有一大块是一次性的迁移潮 (微软 Synapse 退役、BigQuery 合同到期，迁移工程师常由 DBX 和微软出钱)；AI (~25% 收入) 大部分是按原价转卖 Anthropic、OpenAI 的 token，60-70% 的 token 已换成便宜 ~6 倍的开源模型，8 月 token 翻倍、收入只 +3%；serverless 把客户原来付给云厂商的机器钱并进收入，抬高增速、拉低毛利率 (80%+ → ~74%)。(2) 放缓已经开始。6 月 $6.9B、7 月 $7.0B 几乎持平；内部人说 8、9 月环比只有 2-3%；我们估 Q3 run-rate ~$7.6B (+58%)，Q4 ~$8.4B (+56%)。(3) 价格。Forge 价 = 25 倍 NTM 收入 (31 倍当前 run-rate)，按我们的 NTM 增速 (+47%) 算，倍数 / 增速和 SNOW、DDOG 一样，不再有 101 里说的"增速调整后便宜一半"；而 FCF 只打平、SBC 估计 ~30% 收入，股东经济学比这三家都弱。

和 10-26 的 Databricks - 101 比：结论方向不变 (二级市场不追)，买点从 $180-200/股 ($1,350-1,500 亿) 下调到 $150-170/股。原因是两点：(1) 把 Q3 放缓写进了 NTM (101 按延续 80% 算 NTM $9.1B，现在 $8.6B)；(2) 和 SNOW、FROG - Deep 统一口径，只用 5 年后的终值折现。Forge 价在这一周里还涨了 ~7% (1 个月)。

1. 产品：它是什么、怎么运转、凭什么赢

1.1 一句话 + 一个例子

DBX 是企业的"数据厨房"。一家饮料装瓶商的门店销售、库存、ERP、App 日志、客服录音散在几十个系统里；要回答"这家便利店上周哪几款饮料卖得不好、该推什么"，得先把原始数据搬进来，清洗、合并成干净的表 (这叫数据工程或 ETL)，然后分析师写 SQL 出报表、数据科学家训练预测模型，现在越来越多是 AI agent 自己来查数据、给建议。DBX 就是做这些事的平台。

一个好记的比喻 (来自 DBX vs SNOW 研究)：DBX 像中央厨房，原料、刀具、灶台都给你，厨师想做什么都行，但得有厨师 (工程师)；SNOW 像出餐很快的餐厅前台，菜单定好了，按按钮就出餐，不需要懂厨艺。下面这张图把一份数据从进来到被用掉拆成 6 站，标出每站怎么收钱、谁最强。

它的技术核心是"湖仓" (lakehouse)：数据以开放格式 (Delta Lake 或 Iceberg) 存在客户自己的 S3、ADLS 里，DBX 不占有数据，只提供在上面跑计算的引擎 (Spark、Photon、DBSQL) 和管理这些数据的目录 (Unity Catalog)。好处是一份数据可以同时被 SQL、Python、模型训练、agent 使用，不用搬来搬去；代价是 DBX 不能像 SNOW 那样靠"数据在我这里"锁住客户。再拿一个具体问题走一遍，看 agent 怎么改变账单：

1.2 行业背景：为什么需要它

数据库分两类：操作型 (App 的"收银台"，每笔下单实时写进去，Oracle、Postgres、MongoDB) 和分析型 (公司的"财务部"，把所有收银台、App、日志的数据汇到一起，一次扫几十亿行)。分析型过去 30 年走了三代：一体机 (Teradata、Oracle Exadata) → 大数据 (Hadoop，自己搭集群，难用) 和云数仓 (SNOW、BigQuery，存算分离、按用量付费) → 开放湖仓 (数据以开放格式放在客户自己的云存储上，多个引擎都能读)。DBX 是从 Hadoop 那一支长出来的：2013 年 Apache Spark 的作者们在 UC Berkeley 创办，卖点是"比自建 Hadoop 好用的 Spark"；之后补上数仓 (DBSQL) 和治理，把"开放湖仓"做成了第三代的代表。AI 让这件事更重要：模型要用企业自己的数据，而大部分数据 (文档、日志、图片) 不是整齐的表，先要被加工。行业全貌见 数据平台行业入门。

1.3 怎么收费

收费单位是 DBU (Databricks Unit)。可以理解成"算力电表"：一台机器跑 1 小时消耗若干 DBU，机器越大、功能越高级，每小时 DBU 越多；不同工作负载每 DBU 单价不同。谁算一个单位：不看人数、不看座位，只看"计算跑了多久、开了多大"。传统模式下 (classic) 机器开在客户自己的云账户里，机器费客户另付给 AWS、Azure，DBX 只收软件费，所以早年毛利率接近 90%；serverless 模式下机器开在 DBX 的账户里，一张账单全包。AI 部分另按 token 或 GPU 小时收。存储不收费 (在客户自己的云上)。

巨头为什么不能自己做：云厂商不是早就有托管 Spark 了吗？

先核对前提：巨头不但做过，而且比 DBX 产品还早。AWS EMR (托管 Hadoop / Spark) 2009 年上线，Google Dataproc 2015 年，微软 HDInsight 2013 年、Synapse 2019 年、Fabric 2023 年。结果是：DBX 在它们的地盘上长成了 $70 亿的生意；微软干脆把 Azure Databricks 做成自己的一方产品来卖。巨头做出来了但没赢下这一块，原因不是写代码：

  1. 引擎和人。Spark 的作者在 DBX；Photon (C++ 重写的引擎) 和 serverless 让同一个作业在 DBX 上更快更便宜，这是持续的工程投入，不是托管开源就能追上的。
  2. 跨云中立。大企业的数据在三朵云上都有；EMR 只在 AWS、Dataproc 只在 GCP、Fabric 绑 Azure 和 Office。Unity Catalog 跨云管一份目录。
  3. 统一平台。云厂商的数据工程、数仓、ML、治理是几个独立产品 (EMR、Redshift、SageMaker、Lake Formation)；DBX 是一套目录、一个界面。
  4. 激励不同。对云厂商，客户在 DBX 上跑一样买它的机器 (classic 模式下机器费直接付给云厂商)；微软还按 Azure Databricks 拿分成。所以云厂商一边做竞品，一边帮 DBX 卖。这一条是我们的判断。

所以巨头真正的威胁不是"做出一样的产品"，而是两件事：(1) 捆绑和补贴：微软把 Fabric 和 Office、Power BI 打包；三家云厂商都在用数百万美元补贴把客户迁回原生服务，补贴从 $10-20 万涨到包揽整个迁移 (Thoughtworks 05-08)。(2) 入口被模型厂商截走：OpenAI、Anthropic 的企业 agent 直接读客户湖里的数据 (开放格式让这件事更容易)，DBX 的 Genie、Agent Bricks 前端就被绕过，只剩底层 DBU。第二条对 DBX 比对 SNOW 更要紧，因为 DBX 把 AI 当作第二增长曲线。

用了 SNOW 的企业还会买 DBX 吗？会，并存是常态

  • 并存是常态。大企业典型分工：DBX 负责加工和建模，SNOW 负责存放整理好的表、给分析师和看板用。"大客户都是双平台、按用途分预算，两家之间整体迁移非常少" (多位渠道和咨询专家，101 的 E04)。生命科学咨询商 Axtria (GuidePoint 10-30)："某个负载在 DBX 上增长，不一定意味着替换 SNOW"。
  • 正面交锋发生在新预算和大数据量客户上。Thoughtworks 美洲数据与 AI 负责人：新增平台预算 DBX:SNOW 约 60:40，但"不是因为正面赢了 SNOW"，全市场他按 50:50 建模 (GuidePoint 08-20)。DBX 员工：数据量超过 2PB、慢查询 ~15% 的 SNOW 客户成本急剧上升，DBX 专门去接触 (Acecamp 10-13)。
  • 双向的真实案例：向 DBX：前员工称去年 ~200 家客户从 SNOW 迁来，包括 SNOW 前 6 大客户的部分负载 (Merit 08-13，DBX 立场)；10 人 AI 初创 CTO 选 DBX 做主平台 (GuidePoint 04-27)；Tavant 代客户选了 AWS + DBX (价格)。向 SNOW：Dairy Farm 从 DBX 迁回 (集团统一 Iceberg + AWS 26% 折扣 + 易用，Acecamp 10-22)；大型药企把 DBX 降为遗留平台 (Merit 08-10)。

6.5 结论：什么情况下在 IPO 或二级市场买

二级市场不追；买点 $150-170/股 (约 $113-128B，13-15 倍 NTM 收入)。基本情景每股 $93 (口径 A) 到 $184 (口径 B)，Forge 价 $288 买入 5 年年化 -12% / 1%，L-2 价 $253 也只有 -10% / 3%；只有加速情景的口径 B ($331) 高于 Forge 价。买点取口径 B 基本情景 12-15% 年化；口径 A 对应 $74-85，只当参考。
