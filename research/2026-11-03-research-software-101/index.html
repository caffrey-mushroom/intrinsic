结论

一句话：2026 年软件有 beta，但 beta 只给了数据层和用量龙头。分化比 beta 重要，好生意都已经定价。

  1. Beta 从哪来：数据加速上云，AI 把迁移成本打下来；AI native 在花实验室的钱；2023-24 降本周期结束。吃到的是 DDOG、SNOW、Databricks，不是整个软件。
  2. Beta 会退：量涨价跌；迁移是补课，一次性。券商已经让 DDOG、SNOW 2027 年回到 26-30%。2026 年的增速不能线性外推。
  3. 用量型：量 > 价。龙头拿份额，被 agent 绕开的丢份额 (MDB)。最大风险是 ASP 撑不住、大客户压价，增速 miss。
  4. Seat 型骨架：客户不会走，seat 会掉。现在靠提价撑。提价一次性，seat 下滑是复利，按动作收费的钱还只有几个点 (CRM Agentforce ~3% 收入)。
  5. 单薄工具：重置成本最低，Claude 两周能搭个够用的。MNDY 增速 30% → 15%。
  6. Moat 和利润率结构性变弱：OpenAI 把日志搬到自建 ClickHouse；转售 token 毛利 ~55%。可搬走的那块收入永久折价，不是整个公司打折。
  7. 企业 AI 落地慢：POC 到生产 5-10%。NOW AI ACV +65%，但有机 cRPO 在减速，是替代不是叠加。业务 agent 的钱 2027 年以后才进报表。
  8. 怎么做：买 NOW (低于买点)；CRM、HUBS 小买 1/3；DDOG、SNOW 等板块砸；MDB 等 Atlas 过 30%；MNDY 等 Q3 NDR。

1. 2026 年软件的结构性 beta

1.1 数据加速上云，整个机房没有

  • 数据层在加速：MSFT Fabric 收入 +60% (>$2B)，Azure Postgres +55%，Cosmos DB +50%；SNOW 迁移收入 FY26 1.9 倍。
  • 应用和整机房没加速：SAP 当期云订单增速平在 25-26%，~50% 客户还在 ECC；Kyndryl 云厂商业务 +59% → +34%；MSFT 剔除 OpenAI 的 RPO 增速 28% → 25%。
  • 为什么是现在：(1) 之前投资不足、数据散在各处，要还技术债；(2) 更关键，AI 让迁移成本大幅降低。迁移贵在人工 (重写 SQL、改管道、测试)，coding agent 把这块打下来了。银行从 Teradata 迁到 SNOW 用了 ~2 年，一家制造业客户用 Cortex Code 不到 3 个季度迁完。

1.2 数据流速提升，用量计费受益：受益的是龙头，不是行业

两处修正：

  • "监测大盘显著快于软件总盘"不成立。可观测性整体 ~12%/年，比软件慢。快的是 DDOG 一家：大客户里胜 DT 的比例在升，某 GSI 渠道里 DT 转售额 $20M → $16M → $6M。真正"大盘快于软件"的是数据平台。
  • "Teradata 迁出加速、业绩崩"只对一半。2025 年收入 -5%，但 2Q26 总 ARR 还是 +2% (cc)，公有云 ARR $686M (+9%)，全年 ARR 指引 +2-4%；3Q26 收入指引 -4% 到 -6%。迁出在发生，没塌：大客户一块一块搬，Teradata 也在把客户迁到自己的云版。SNOW、Databricks 的增量大部分是新负载，不是抢 Teradata 存量。11-05 Q3 验证。

1.3 收入确实显著加速 (图 1)

  • DDOG ~25% (2025 初) → ~34-36% (2026 年中)，全年指引 18-20% → ~30%。SNOW ~27% → ~40%，指引 27% → 36%。
  • 四个来源：数据上云；工程活动 (coding agent 写更多应用、跑更多查询)；AI native 客户 (DDOG 收入 ~15%)；降本结束 (SNOW 消费增速回到 23%+，Databricks ~12% → ~20%，渠道专家)。
  • 钱来自工程预算：11-01 预算研究，工程类 9 家增速 20.6% → 29.2%，业务类只 16.6% → 19.2%。
  • Beta 会反转，量涨价跌：Databricks token 一个月翻倍，收入只 +3%；MDB token 3-4 倍，Atlas AI 收入 ~2 倍。迁移积压有限，AI native 的钱跟着实验室融资走。

1.4 Reward 龙头

  • 好产品拿份额：DDOG 大客户里胜 DT；Databricks 2026 年 DBMS 份额超过 SNOW (我们估 4.3% vs 4.0%)；SNOW 在可见池里 45% → 42%。SNOW 的加速不少是 beta，它在丢份额给 Databricks。
  • 选工具的从人变成 agent：agent 默认选最 AI native、文档最多的。MDB 是反例：管理层承认 coding agent "大多数时候在 JSONB 上选 Postgres"；Claude Code 测试选 Mongo 0/125 次；Stack Overflow 使用率 24% → 19%。SNOW 反过来把 Cortex Code 插件放进 Claude Code 插件市场，主动抢默认位。

3. 分化二：seat 型工作流 (骨架和部门级)

共性：按 seat 或员工数收费。客户不会走，这是他们组织公司的方式 (治理、安全、审计、多年定制)。Seat 有长期风险，现在靠提价、新套餐、推上云撑增速。

核心是时间错配：提价一次性，跟 3 年合同慢慢滚完；seat 下滑是复利。按动作收费的新钱能不能在提价滚完前接上，决定这一类。

分两层：全公司骨架 (NOW、CRM，管整个公司的流程和客户记录)；部门级工作流 (TEAM、GTLB 管研发，VEEV 管药企销售和研发)。部门级的 seat 风险看 agent 替的是不是这个部门的人。

NOW买

Set up：全公司流程骨架，agent 越多要派发和核验的活越多。10-29 Q4 cRPO 指引一天跌 27%，现价低于买点。

产品 & 商业模式
"谁要什么、谁批、谁做、做完没有"的流程系统，典型是 IT 服务台。收费 (估)：seat ~76%、按资产或员工 ~20%、用量 ~1%。档位 Standard → Pro (+50%) → Pro Plus (+60%) → AI 档 (+20-30%)，加 assist 超额。
Seat 风险对冲 / 重新变现 / 实际交付
对冲：档位提价 15-25%，一次性，~2029 年滚完；收费单位挪到 assist、资产、员工；扩新部门。Option：AI Control Tower (管企业里所有 agent，按资产)、Action Fabric (按调用)、Armis 安全 (按资产)。实际交付：AI 净新增 ACV +65%，生产 agent 用量 13 倍，AI ACV ~10% 订阅；但有机 cRPO 在减速，大部分是续约时换成贵 20-30% 的新套餐，替代不是叠加。客户"完全没有要求按结果收费"。
增速轨迹 & 预期
Q3 订阅 +20.5%，小超指引，Q3 没坏。杀预期的是 Q4 cRPO 指引 18.5% (买方要 19.5-20%)，扣 Armis 有机 ~16.5-17%。券商 2027 年 16-17%。订阅毛利 83% → 80%，SBC 15.3% 收入。
估值
$106 (11-02)，EV/NTM 收入 6.3x，扣 SBC FCF 收益率 2.9%，买点 $110-130。现价隐含 5 年增长 ~7-9%，我们基本情景 14.6%。1 月 FY27 订阅指引 ≥18% 加仓。

4. 分化三：单薄工具

5. Moat 结构性变弱 → 永久折价

5.1 最强的产品，弱的那一环也在被大客户拆走

  • OAI → ClickHouse vs DDOG：OpenAI 2025 年 Q3 把日志搬到自建 ClickHouse，2026 年上半年把基础设施指标 (我们估 ~40% DDOG 账单) 搬到 Chronosphere；APM、前端监测留在 DDOG。DDOG CFO 自己说"指标存储不一定要实时"。影响 ~$100M ARR，拖 ~2-3pt，4 个季度。Anthropic 也在用 ClickHouse 做存储，有复制风险。
  • 边界：自建经验线是账单 >$2-5M/年 才划算 (COIN 2022 年 $65M 账单试过自建，最后拿降价留下)。风险集中在最大的几个技术型客户，被拆的是"不要求实时的存储"，不是每天在用的流程。
  • 处理：收入拆成"可搬走的存储"和"搬不走的流程"，只给可搬走的那块永久折价。

5.2 转售 token 的收入质量不高

  • 是经常性收入，但毛利跟着模型价格走：SNOW AI credits ~55%，核心仓库高得多；NOW 订阅毛利 83% → 80%，部分是 AI 成本；MSFT Cloud 毛利每年 -300bp。
  • 含义：AI 收入占比越高，越要按毛利润估值，不按收入。SNOW：FCF 利润率 +1pt ≈ 5 年增速 +1pt 对每股价值的影响，毛利率和增长一样重要。
