这一季讲了什么

先搞懂这家公司

Cloudflare 是一张覆盖全球 330 多个城市的网络。你打开一个网站、或者一个 AI agent 去调用某家公司的 API，请求先到离你最近的 Cloudflare 机房：它判断这是人、正常的 bot 还是攻击，能从缓存直接回答的就直接回答，需要计算的就在这台机器上跑客户写好的代码 (Workers)，最后才去客户自己的服务器。每台机器都跑全部服务。

公司自己把业务分成四“幕” (Act)：Act 1 应用服务 (CDN、WAF、DDoS 防护、bot 管理，帮网站挡攻击和加速)；Act 2 SASE / Zero Trust (员工上网和连内网都先经过 Cloudflare，替代 VPN，按人头收费)；Act 3 开发者平台 (Workers、R2 存储、Workers AI，让开发者直接在这张网上写应用和跑 agent)；Act 4 给互联网建新的商业模式 (让 AI 爬虫和 agent 为内容付费)。

怎么收钱：小网站按域名付固定月费 ($20 / $200)；大企业主要签“请求量档位”合同 (按每月请求量签一个上限，超了就买更大的一档，公司叫 T-shirt sizes)；员工安全按人头；开发者平台按请求和 CPU 用量收，大客户用预付的“资金池” (pool of funds) 抵扣。所以 AI agent 让请求变多，会先在档位和资金池里变成更大的账单，但有续约滞后，单价也会随承诺变大而下降。

这一季

一句话：收入 +36%，一年从 +28% 加速上来，开发者一个季度新增近 200 万、非人流量第一次超过 50%；但 CEO 也说恶意的 agent 流量照拦不多收钱，CFO 说合同越来越像用量制、季度更难预测，Workers 有多大仍不拆。

  • 收入 6.961 亿美元，同比 +36% (上季 +34%)，比指引上沿 6.65 亿高约 4.7%。大客户 (年付 >10 万美元) 4,698 家，+27%，一年净增 986 家创纪录；DNR 120%，环比 +2pt、同比 +6pt。
  • AI 是本季主线：第二季度经过 Cloudflare 的流量里，第一次超过 50% 不是人；CEO 预计 5 年后非人流量会是人类的 1,000 倍。开发者达到 740 万，Q2 一个季度新增近 200 万，超过 2025 全年的 150 万。付费客户一个季度新增 8 万多，同比 +74%。
  • 但非人流量不等于收入：CEO 说恶意的 (包括“拿内容不付钱”的 AI 爬虫) 流量会被拦下，而且“不多收客户钱”；愿意被访问的那部分，Cloudflare 想通过 cloudflare.pay、Monetization Gateway、Wallets 向 agent 收“不到一分钱”的费用，这还是 Act 4 的规划，没有收入数字。
  • 毛利率 73.1%，8 个季度来第一次环比回升 (+30bp)，但同比仍降 320bp；CFO 说毛利率会稳在这个水平，要看“总单位经济”。网络资本开支本季只占收入 7%，全年指引 14–15%。
  • 合同结构在变：CFO 说业务在从按比例确认的 SaaS 转向资金池、用量和 T-shirt 档位的混合，客户“烧”得越快续得越快，单个客户的波动 (标准差) 变大，季度更难预测，所以指引继续保守。
  • 大单：一家 AI 生成公司签 1 年 750 万美元资金池 (因为 R2 不收出口费)；一家科技公司 600 万资金池跑 AI agent；一家数字媒体 5 年 3,180 万美元 (应用服务 + Zero Trust，打败了现有云厂商)；美国联邦机构 5 年 770 万；F100 科技公司 3 年 520 万全套 SASE，打败两家第一代 Zero Trust 厂商。
  • 利润：non-GAAP 营业利润 9,610 万美元 (13.8%)，自由现金流 5,640 万 (8%)；重组费用 1.51 亿 (Q1 裁员)，全年最多 1.65 亿，其中现金 1.3 亿。剔除重组，GAAP 净亏损约 1,800 万，CFO 说 2028 年 GAAP 盈利的目标“明显超前”。
  • 指引：Q3 收入 7.36–7.37 亿 (+31%)、营业利润 1.29–1.30 亿；全年从 28.05–28.13 亿上调到 28.64–28.70 亿 (+32%)，营业利润 4.43–4.45 亿。CEO 解释为什么不做 GPU 出租：“不是所有收入都一样”，出租商品化的服务器是坏生意。

怎么读这份笔记

术语表

术语大白话和收钱的关系
Act 1 / 2 / 3 / 4公司对四块业务的叫法：应用服务、SASE、开发者平台、给互联网建新商业模式。像一部戏的四幕，一幕接一幕加上去。CFO：每进一幕，最大单子大一个量级 (Act 1 百万级、Act 2 千万级、Act 3 上亿)。
非人流量 (non-human traffic)不是人在浏览器里点出来的访问，而是 bot、AI 爬虫、AI agent 发出的请求。请求是企业合同的主要计费量，但恶意的会被拦下且不多收钱。
DNR / NRR (净美元留存率)一年前的老客户今年付的钱是去年的多少。120% 表示多付 20%。NET 加速的主要来源。
大客户 (large customers)年付超过 10 万美元的客户。贡献 73% 收入，增速 +27%。
T-shirt sizes (请求量档位)企业合同按每月请求量签一个尺码，像衣服 S、M、L；用超了就换大一号。请求变多要等升档才变成收入，有滞后。
资金池 (pool of funds)客户预付一笔钱，在 Cloudflare 所有产品里按标价扣，像预付卡。进 RPO，但按消耗确认收入；大客户承诺越大单价越低。
Workers在 Cloudflare 网络上直接跑代码的服务，代码离用户最近，启动以毫秒计。按请求和实际 CPU 时间收钱；不收等待时间。是 Act 3 的核心。
Isolates (隔离区)比容器更轻的沙盒：一台机器上能同时跑成千上万个，每个启动几乎不花时间。CEO 的论点：如果每个知识工作者都在容器里跑一个 agent，全世界的 CPU 不够，isolate 才够。
KV / Durable ObjectsWorkers 配套的数据存储：KV 是全球同步的键值表，Durable Objects 是带状态的小对象，适合做路由和多租户配置。开发者平台的一部分，按用量计费。
R2 与出口费 (egress)R2 是 Cloudflare 的对象存储；出口费是把数据从云里拿出去时云厂商收的流量费。R2 不收出口费。AI 公司拉大量图片、视频时出口费很贵，这是 750 万资金池大单的原因。
SASE / Zero Trust员工上网、连公司系统都先经过一个云上的安全网关，按身份和设备判断能不能访问，替代 VPN。Act 2，按人头收费；大单多经渠道。
Magic Transit / Network Firewall把一整个机构的网络流量 (不只是网站) 引到 Cloudflare 上过滤 DDoS 和做防火墙。联邦机构 770 万合同买的就是这个；帮客户关掉了一个数据中心。
Monetization Gateway / Wallets / cloudflare.payAct 4 的三件套：网站可以对网页、API、数据集、MCP 工具定价；agent 用钱包自动付钱；买卖双方用 cloudflare.pay 确认身份。还没有收入；CEO 说每笔“不到一分钱”，需要每秒上千万笔交易。
Content Independence Day / Agents WeekCloudflare 的两个产品发布周：前者 (7 月) 推出默认拦截 AI 爬虫和付费爬取，后者 (8 月) 发布 agent 相关的产品。产品节奏和营销节点。
Cloudflare OSCloudflare 内部给全员 (不只是工程师) 用的 AI 工具平台，接入公司的记录系统、可审计；8 月开源。公司说它让财务、法务、采购更高效 (Q1 裁员 20% 的背景)；系统集成商想拿去给企业部署，可能带动开发者平台。
PLG (产品驱动增长)用户先自己注册、用免费版或刷信用卡，再慢慢变大客户，不靠销售上门。付费客户 +74% 就是 PLG；千万美元级合同仍靠企业销售。
RPO / cRPO已经签了还没确认成收入的合同金额；cRPO 是其中 12 个月内要确认的部分。RPO +38% 快于收入，说明资金池和多年合同在变多。
单位经济 (unit economics)CFO 用来代替毛利率的口径：把网络成本和相关费用放一起算每单位的利润。CFO 说毛利率会稳住，单位经济会在下半年继续改善；投资者日给的数是 ~44%。
network is the computerSun 公司的老口号“网络就是计算机”；Oracle 收购 Sun 后没续注册商标，现在归 Cloudflare。CEO 用它讲 agent 需要整张网当一台计算机用。
