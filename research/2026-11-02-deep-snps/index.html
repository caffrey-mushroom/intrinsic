结论

一句话：不买，放观察名单；买点 $360-400，现价 $467.61 (2026-10-30 收盘) 比买点上沿高 ~17%。SNPS (Synopsys，新思科技) 卖芯片设计的全套软件、现成电路模块 (IP) 和 2025 年买来的 Ansys 仿真软件，和 CDNS 一起占全球芯片设计软件的 2/3。基本面不差：Q3 FY26 (5-7 月) 收入 $2,477M，non-GAAP 营业利润率 41.6%，Design IP 从去年的坑里爬出来 (+11%)。问题是三件事叠在一起：(1) 不含 Ansys 的内生增长只有 ~7% (Q3)，全年 ~9%，而 CDNS 同期 +22%，SNPS 在丢相对份额；(2) Investor Day (9-30) 之后股价两天涨 ~18%，FY27 指引 $11.1-11.2B (一致预期原来 $10.73B)、FY30 收入 15% 复合和 50% 利润率已经部分计入；(3) AI agent 对 license 用量是加项还是减项还没有数据，管理层和 SNPS 一侧的专家说是加项，独立专家说 CDNS 的 agent 领先。现价隐含未来 5 年收入复合 ~12% (口径 B；口径 A ~15%)，我们的基本判断 ~12%：基本情景现价买入 5 年年化 ~10% (口径 A ~7%)，不到 12% 的门槛。

增长分型：A 类为主 + B 类为辅。主引擎是 A (用量)：客户每年开多少颗芯片 (design starts)、每颗多复杂，决定要买多少份 license、多少台硬件仿真器、多少个接口 IP；AI 芯片越大越复杂，用量越大 (图 9)。第二引擎是 B (新产品带提价)：Ansys 打包交叉销售 (管理层：FY27 退出时收入协同 >$1 亿、FY29 $4 亿)，加上 IP 的新模式 Factory 2.0 (定制 IP + 版税，AWS 一单 $10 亿授权费) 和 AI agent 按结果收费 (还没有收入)。

它怎么收钱 (取自 1.3)：四类。EDA 软件 (FY26E 收入 ~50%)：按 license 收，一份 license = 同一时间能开一个工具，大客户 3 年一签，按月确认，续约时每年涨价 ~3-5%；硬件仿真器 (ZeBu、HAPS，EDA 里 ~1/6，估算)：一次性卖，交付当季确认，波动大；Design IP (~19%)：PCIe、DDR、UCIe 这类现成接口电路，按每个芯片项目收授权费，部分收量产版税；Ansys 仿真 (~31%)：热、应力、电磁、流体仿真，年租 + 维护。收入里"按期许可"占 ~40%、一次性确认 ~27%、维护和服务 ~32% (图 4)。

为什么不买 (估值没有给错)：(1) 不便宜：P/E FY27 24.5x、EV / NTM 收入 8.6x，比 CDNS (34x、12.6x) 便宜，但 CDNS 增速是它的 2-3 倍；扣 SBC 的 FCF 收益率 FY27 只有 2.3%；(2) 现价已经押在管理层计划附近：现价隐含 ~12%/年，我们基本 ~12%，管理层 FY30 目标 ~15%；按管理层模型 (15% 增长、37% FCF margin) 每股 $559 (口径 A $506)，比现价高 ~20%，这是要全部兑现才有的上行；(3) bear 有真实的机制：agent 让一颗芯片少跑验证、云厂商自研 IP、中国份额 (17% → 10%) 继续掉，bear 每股 $218，较现价 -53%。按 25 / 50 / 25 加权，期望值 ~$462，和现价差不多。

什么时候买 / 认错：跌进 $360-400 (口径 B 基本情景年化 13-15%) 开始买；52 周低点是 $362.55，这个价位过去一年到过。如果 Q4 (12 月上旬) EDA 同比 ≥ +15%、FY27 指引维持并且 RPO 止跌，说明 AI 用量真的在加 license，基本情景往管理层路径上调，买点可以上移到 ~$420。

框架三问

核心问题我们的答案证据强弱
1. 韧性 + 长坡厚雪：需求会不会持续会。芯片设计软件 + IP + 仿真是 ~$30B、每年 ~10% 的市场，芯片越复杂需求越大；客户几乎不会停用 (不签 license 就不能流片)。SNPS 收入从 FY22 $4.6B 到 FY27E $11.2B，Ansys 之外内生 ~9-15%。但 2025 年 IP 下滑 8%、中国份额掉一半，说明它不是完全没有周期强 (历史 + 结构)

1. 产品：它是什么、怎么运转、凭什么赢

1.1 一句话 + 一个日常例子

一句话：SNPS 卖的是"造芯片之前的一切"：把工程师写的电路代码变成台积电能直接生产的图纸 (EDA 软件)，顺便卖现成的电路模块 (IP)，现在还卖芯片和整机的物理仿真 (Ansys)。一颗芯片在送去晶圆厂之前，要在电脑里被设计、反复验证、变成几百亿个晶体管的版图、再检查几千遍；流片一次 $3,000 万以上，错一次就要重来半年。所以芯片公司在这一步几乎不省钱，SNPS 和 CDNS 两家拿走了这个市场的 2/3。

日常例子：AMD 最新的 MI455X GPU 是好几颗小芯片封在一起的。AMD 用 SNPS 的 3DIC Compiler 规划这几颗芯片怎么摆、怎么连，用 SNPS 的接口 IP 让它们互相通信，用 PrimeTime 检查每条线路的时序，用 (原 Ansys 的) RedHawk 检查供电会不会掉压、封装会不会过热变形。这些检查通过之后，台积电才接单生产 (Q3 电话会 CEO 举的例子)。

1.2 行业背景：芯片公司为什么离不开它

设计一颗 3nm 的 AI 芯片要 18-24 个月、几百名工程师，设计成本 $5-7 亿。芯片太复杂，没有人能手画，每一步都靠软件；而且每一步的工具都要拿到台积电、三星、英特尔的工艺认证 (PDK)，晶圆厂只认认证过的签核结果。下图是芯片设计的 6 个站点，SNPS 在每一站都有工具：

1.3 怎么收费

1.4 AI 让它受益还是受损

受益的逻辑：AI 让写代码变便宜，生成的设计更多、要验证的东西更多；agent 不替代 EDA 工具，而是代替人去调用它们，所以 license 用量会上升。管理层这样说，中国本土竞争对手的产品总监 (GuidePoint) 也这样看：

受损的逻辑：(1) 收入 = 份数 × 单价，agent 跑得快，同一颗芯片需要的工程师-小时变少，如果客户按"项目做完"而不是"开着工具的时间"来谈价，份数不一定涨；(2) 模型公司 (OpenAI) 学会调用工具链之后，议价权可能从工具方移到模型方；(3) AI agent 的平台层 CDNS 领先：

我们的判断：加项，但加给整个行业，不一定加给 SNPS。AI 芯片的复杂度上升是实打实的 (FY27 指引 +14.6%、Q4 EDA 回到双位数)；但同样的需求下，CDNS 过去一年增长 +22%，SNPS 内生 ~7%。SNPS 能不能拿到 AI 的好处，要看 Q4 和 FY27 的 EDA 增速，不是看管理层的说法。

1.5 核心竞争力

三层护城河，越往下越硬：(1) 签核和工艺认证：PrimeTime (时序签核) 是业界标准，台积电每个新工艺先和 SNPS、CDNS 一起认证工具，新进入者没有这些数据就不能交给晶圆厂；(2) 最全的接口 IP：80 个工艺节点、3,000 多个 IP 产品，任何新芯片项目都会先找 SNPS 买接口，所以 SNPS 能最早看到行业的设计项目 (管理层原话："没有一个新芯片项目我们不是最早通过 IP 接触的")；(3) 换工具的成本：工程师训练、脚本、历史数据都绑定在一家的工具链上；挑战者至少要好 20% 才会被考虑 (专家)。

1.6 对比最核心对手 CDNS，以及大客户为什么不自己做

CDNS 和 SNPS 是对称的寡头：SNPS 强在数字前端 (综合、验证)、签核和接口 IP；CDNS 强在模拟和定制电路、硬件仿真器 (Palladium) 和 PCB / 系统分析。过去两年 CDNS 增速一直更快：

为什么 CDNS 更快：(1) 硬件仿真器 Palladium 是 AI 芯片验证的首选，SNPS 的 ZeBu 偏原型验证；(2) CDNS 没有做大并购，管理层精力在产品上，SNPS 这两年在整合 Ansys、出售 3 个业务、裁员 ~10%；(3) SNPS 的 IP 2025 年踩了英特尔和中国的坑 (英特尔是最大客户之一，FY24 一个客户占收入 12.6%)；(4) agent 平台 CDNS 先一步 (收购 ChipStack)。大客户为什么不自己做 EDA：没有人做过，Google、Nvidia 也都是 SNPS / CDNS 的大客户；能自己做的是 IP (见 3.5)。

3. 行业：TAM、格局、哪层粘、哪层会流失

3.1 TAM 和每年增速

SNPS 能卖的市场是两块：EDA + 半导体 IP (ESD Alliance 统计，2025 年 ~$20B，过去 5 年 ~11%/年) 和仿真软件 (CAE，Ansys 所在的市场，~$10B，~8%/年)。合起来 ~$30B，SNPS 占 ~30% (Ansys 并表后)：

EDA 市场为什么能每年长 10%：芯片设计复杂度 (晶体管数、多芯片、3D 封装) 每代都在上升，而芯片公司的研发预算大概占收入的 15-20%，其中 EDA 只占芯片公司总成本的 <10% (专家)。AI 芯片让这个市场加速：设计项目更多、单个项目更大。管理层把 EDA 的长期增速从"双位数"上调到"中双位数" (地板 13%)。

3.5 客户自建

EDA 没有人自建：从 Google 到 Nvidia 都是 SNPS / CDNS 的大客户，原因是工艺认证和几十年的流片数据。IP 是真的有自建风险：云厂商的芯片进入量产、按颗付的版税变大之后，就会问"能不能自己做"，或者找博通、Marvell 打包设计服务。SNPS 的应对是 Factory 2.0：主动给大客户做定制 IP，按版税分成，换取不被替代。
