monday.com Elevate '26 投资者问答 (2026-10-28，纽约) 初读笔记

逐段英文原文、中文翻译和解读，外加关键数字、术语表和下一季要盯的事。给第一次读这家公司管理层发言的人。

这场问答讲了什么

先搞懂这家公司

这不是财报电话会，而是 monday.com 年度用户大会 Elevate '26 (2026-10-28/29，纽约) 期间给投资者开的一场 55 分钟问答。没有准备发言，全程是分析师和线上投资者提问，两位联席 CEO (Roy Mann、Eran Zinman)、CFO Eliran Glazer 和 CRO Casey George 回答。因为 11-09 要发 Q3 财报，IR 一开始就说不谈近期数字，只谈战略和产品。2025 年 9 月那次是正式的投资者日 (给了 2027 年 $18 亿收入目标)，2026 年没有开投资者日，这场问答就是今年唯一一次管理层集中讲战略的场合。

背景：monday.com 卖的是一张“会自己动的表格”，团队在上面管项目、销售线索、工单。按“席位档位 × 套餐档位”收订阅费，2026-05 起新客户还要买 AI credits。增速从 2025 年的 +27% 降到 Q3 指引的 +16–17%，股价从 2025 年 $300 以上跌到 $90 左右，被市场归入“AI 输家”。

这场问答的三条主线：(1) 新成立 monday Frontier (托管服务 + 前置部署工程师)，帮大企业落地 AI agent，这是 monday 从“自助好上手”转向“有人陪着卖”的最大一步；(2) 收费从纯席位走向“席位 + 用量”混合，credits 统一成一个池，明年开始对超量 API 调用收费；(3) 上探大企业是主战略，$5 万+ 客户已占 ARR 40% 以上，企业客户的 agent 采用率是 SMB 的 3 倍。

这场问答

一句话：管理层把 2027 年的增长押在“大企业 + AI agent + 有人陪着落地 (monday Frontier)”上，收费往“席位 + 用量”混合走 (明年开始对超量 API 收费)；但没有任何数字，付费搜索获客“没有变化”，回购不再继续。

  • 新组织 monday Frontier：托管服务加前置部署工程师 (FDE)，2027 年“大规模扩张”，会提供给“大多数新老订单”。理由是客户买了很多 AI 授权但效率提升有限，需要有人帮着找用例、推动组织变化。只服务中型和大企业客户，$5 万以下的小客户交给渠道伙伴。
  • 大企业是主战略：企业客户的 AI agent 采用率是 SMB 的 3 倍；$5 万+ 客户已经占 ARR 40% 以上 (2021 年上市时客户数占比只有个位数)。企业客户的定义是员工 1,500 人以上。
  • 收费模式：明确说“不再只是席位模式，而是混合模式”。credits 统一成一个池 (Vibe、agents、AI 列、AI 工作流都扣同一个池)；API 一直有按套餐的调用上限，现在超了会通知客户，明年开始卖 API 加购包。管理层承认客户想要“可预期”的账单，这和按用量收费天然矛盾。
  • 混合模式的意义：一个 1,000 人全员部署的客户，过去席位买满了就“到顶了”；现在可以靠 agent 和 Vibe 的用量继续扩，“一个中型客户可能付出以前只有大企业才付的年合同额”。
  • 获客：和 Anthropic、ChatGPT 有合作，MCP 带来的发现和转化在逐月快速增长，但“没有抵消之前感受到的压力”，付费搜索的情况“和之前报告的一样，没有变化”。
  • 资本配置：$8.7 亿回购已做完，“目前没有考虑新的回购”；现金主要用于运营 (至少 6 个月不中断) 和并购，并购规模是“几千万美元，不是几亿美元”。
  • 其他：Harmony (语音销售 agent，来自收购的 OneAI) 独立网站、独立销售，主打中型和大企业；monday 换新品牌 (logo)，定位“团队的 AI 工作空间”；研发约 30% 的代码由 AI 自动写；销售人数“不再需要线性增长”。

术语表

术语大白话和收钱的关系
monday Frontier这次大会新成立的组织：托管服务加前置部署工程师，帮企业客户找到 AI 能用在哪、搭好 agent、推动员工用起来。像买了一套健身器材再配一个私教。帮 monday 签更大的企业单；但它是人力服务，毛利率低于软件，规模化慢。
前置部署工程师 (FDE)公司派工程师驻在客户那里，和客户一起把方案搭起来。Palantir 最早这么做。同上。
托管服务 (managed services)客户把一部分运营交给厂商代做，比如由 monday 的人帮客户维护和优化 agent。通常按服务收费，是新的收入类型，但电话会没说怎么收。
上下文 (context)AI agent 干活需要知道的背景：这个团队做过什么、项目到哪了、你是谁、要完成什么。monday 说这些都已经在它的看板里。monday 对“AI 会绕过它”的核心回答：agent 要在有上下文的地方干活。
护栏 (guardrails) 和治理 (governance)谁能看哪些数据、agent 能做什么、做了什么都有记录。每个 agent 都有一个负责的人类主人。大企业愿意付钱的理由之一，也是 Enterprise 档位卖的东西。
MCP (模型上下文协议)让 Claude、ChatGPT 这类外部 AI 读写其他软件的一套标准接口。通过它，用户可以在 Claude 里直接查 monday 的看板。双刃剑：带来新的发现渠道，也可能让用户不再打开 monday。
API 调用上限和 API 加购每个套餐每天能被程序调用多少次是有上限的。agent 跑得多，调用就多。现在超了会通知，明年开始卖加购包。一个新的按用量收费点：agent 越多越要买。
统一 credit 池 (unified credit pool)不管用 Vibe、agent、AI 列还是 AI 工作流，都从同一个 credits 池里扣，不再分开算。简化计费，让客户更容易多用；也在试“个人额度 + 公司总池”。
混合模式 (hybrid model)席位费 + 用量费。席位按人头，用量按 AI 跑了多少。让收入第一次可以不随客户员工人数增长。
全员部署 (wall-to-wall deployment)一家公司所有员工都在用 monday，席位已经买满。过去意味着这个客户“到顶了”，现在还能靠用量扩。
Harmony语音 AI 销售 agent：能自动打电话给潜在客户，也能接听来电并按脚本处理。来自 2026 年 5 月以 1,410 万美元收购的 OneAI。独立网站、独立销售，价格未公布；处于“创业公司”阶段。
Agent directory (agent 目录)公司内部的 agent 商店：有人搭了好用的 agent，可以发布给全公司用。推动 agent 在企业里扩散，从而多用 credits。
供应商整合 (vendor rationalization)大企业手里有很多同类工具，要砍到一两家。monday 说它通常是赢家，扩张大多来自替换对手；但迁移过程慢。
SEM 和 GEOSEM 是搜索引擎营销 (在 Google 买广告)；GEO 是“生成式引擎优化”，让 ChatGPT、Claude 这类 AI 在回答时推荐你。monday 过去靠 SEM 获客，现在要转向 GEO 和 agent 推荐，但还没补上缺口。
BigBrainmonday 内部的数据平台，存着所有销售和业务数据。管理层说连到 monday 平台后，销售自己搭 agent，提升了人效。
