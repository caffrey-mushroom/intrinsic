用 11 家公司检验软件框架

拿 SNOW、DDOG、DT、ESTC、MDB、TEAM、NOW、CRM、FROG、GTLB、PLTR 的业绩会、投资者日、专家访谈和渠道 check，逐条检验"agent 给软件带来的变化"这套框架：哪条成立，哪条要改，漏了什么。

一页结论

结论：五条里两条成立，两条要改说法，一条方向对但时间没到。还要补一条：量涨价跌。

最站得住的是"coding 先落地"。SNOW、DDOG、FROG、GTLB 的业绩会都看到代码和应用量在涨，按用量收费的已经收到钱。要补一句：coding 同时在帮客户省钱 (SNOW 自己的 coding 工具里，前十大技能之一就是成本优化)。

"agent 驱动上云"要改成"AI 让上云更急、也更便宜"。DDOG 的 CFO 确实说 AI 提高了上云的紧迫性，SNOW、MDB、PLTR 都说迁移时间砍了一半以上。但迁移是一次性的 (TEAM 前高管："搬到马路对面")，迁完消费会走平，开放格式也让"上了云"不等于"锁在你这"。

"agent 需要新 infra"成立，但要拆开看收不收钱。门被用得很多：TEAM 经 MCP 建的工单是原来的 4 倍，DDOG 的 MCP 调用是原来的 22 倍。但只有按用量计费的门收到钱 (DT 的 agent 调用直接扣额度)，按席位计费的门白给 (TEAM："价值最终会回到我们")。治理这道门 (NOW AICT) 有了第一批收入，但客户在多家之间分着买。

"业务 agent 慢、要部署层"成立。CRM 生产部署的客户只有高个位数比例，SNOW CoWork 账户环比 +11%。但一旦进生产，消费是 POC 时的约 6 倍。部署层谁拿，还没定：PLTR、模型公司 (Anthropic 900 多人的 FDE 团队)、数据平台都在抢。

"钱从人工和席位来"方向对，但还没变成现金。席位没掉 (CRM、TEAM、GTLB 管理层都说席位在涨)，省下的时间也没变成省下的钱 (NOW 保险客户：每人每月省 15 小时，还没转成现金)。反而看到另一件事：席位厂商在先涨价。NOW 新套餐涨 20-30%，CRM 升级涨 60-80%，TEAM 的 DC 版两年涨了两次。这是框架里漏掉的风险：等省下的人变成现金，涨上去的价能不能守住。

怎么读：每条框架后面放这 11 家里最有分量的证据，分成"支持"和"挑战"两边。证据来自我们给每家公司做研究时整理的业绩会、投资者日、行业会议、专家访谈和卖方 check，都是原话，旁边是说话人身份。非管理层专家附背景和局限。

支持：AI 让上云更急、更便宜

判断：要改说法。"agent 驱动上云"没有证据；但"AI 让上云更急、coding 让迁移更便宜"有 DDOG、SNOW、MDB、PLTR 四家管理层的说法和 DDOG 非 AI 客户 18%→20% 多的数字支撑。要记住三点：这是存量释放，TEAM 这种强制迁移会用完；迁完之后消费会走平；开放格式让上云不再等于锁定。

判断：要加进框架。量涨价跌是这一轮的共同规律：token、存储、日志单价都在降，最大的客户会把非实时、高量、低价值的数据搬走。所以"受益"要拆成两个数：机器调用量涨多少，单价降多少。目前 DDOG、SNOW 是量赢了价；如果哪个季度用量还在涨但收入增速掉了，就是价追上来了。

修正后的框架

  1. Coding 先落地 (现在，最强)：写软件便宜了，代码、应用、制品的量在涨，按用量收费的平台先收到钱 (SNOW、DDOG、FROG)。但同一批工具也在帮客户省单位消耗。按人收费的输家先表现为增速放缓 (GTLB)，席位还没掉。新应用的起点由 agent 的默认选项决定 (Postgres)。
  2. AI 让上云更急、更便宜 (底盘，有限)：迁移时间砍半，AI 提高了现代化的紧迫性 (DDOG 非 AI 客户再加速)。但这是存量释放：强制迁移会用完，迁完消费会走平，开放格式让上云不等于锁定。
  3. Agent 运行要过几道门 (下一波)：数据、身份权限、记录系统、监控、安全。门的调用量已经成倍涨。按量计费的门已经收到钱，按席位计费的门还在白给。治理是新门，会被几家分着买。人从干活变成验收：客户还不肯给 agent 生产权限。
  4. 量涨价跌 (新增)：token、存储、日志单价都在降，最大客户会把高量低价值的部分搬走。每家都要看两个数：机器调用量涨多少，单价降多少。
  5. 业务 agent 慢，但进了生产量会跳：大多数客户还在试点。进生产后，消费是 POC 的 2-6 倍。部署层是治理成熟前的窗口期，PLTR 最强，但模型公司、数据平台、SI 都在抢。
  6. 钱从人工和席位来 (方向对，2027 年以后)：机制已经看到 (L1 请求 80-85% 不用人)，但省下的时间还没变成现金，席位还在涨。席位厂商正在趁机升档涨价。等客户真的少人，这块涨价最先受压。

一句话：机器干活的量在涨，按量收费的先收钱，按人收费的先涨价。量涨赢不赢得过价跌，人工省下的钱什么时候流过来，决定下一轮谁赢。
