Microsoft FY27 Q1 (2026 年 7–9 月，财年 6 月底结束) 电话会初读笔记

逐段英文原文、中文翻译和解读，外加关键数字、术语表和下一季要盯的事。给第一次读这家公司电话会的人。

这一季讲了什么

一句话：Azure 在第三方 GPU 延期交付的情况下仍然 +48%，下季指引 49-50%；增长来自把现有机群榨得更满 (效率) 和更贵的 token，而不是新产能。真正的变量是 capex：本季 $45.2B，占收入 49%，自由现金流只剩 $18.6B。

  • 总收入 $92.3B，同比 +19%；Microsoft Cloud $63.9B，增速加速到 30%。新的分部口径下，Agents and Infra (Azure、M365 商业云、Dynamics、GitHub 等) $76.8B，+25%；Devices and Consumer (Windows、Xbox、搜索广告) $15.5B，-3%。
  • Azure +48% (买方期望约 47%)，而且是在部分第三方 GPU 租赁 (3P GPU-as-a-Service) 延期到下半年的情况下做到的。Amy Hood 拆了三个来源：工程优化让 GPU 和 CPU 机群多挤出了可卖的产能、Foundry 拿到更多配额、以及每个 token 的价格高于预期。后两项她自己说下季不一定可预测。
  • 下季 Azure 指引 49-50% (cc)，管理层再次说需求大于供给。但指引里有一部分要靠“再找到一些效率”，这是第一次明说指引依赖还没发生的工程优化。
  • M365 商业云 +18% (调整后)/+17% (报表)，比预期好，主要靠 GitHub Copilot 的使用量；但 E3 和单品的销售执行偏弱，付费坐席增速放慢到 5%。管理层没有更新 Copilot 坐席数，被 BofA 当面问到时明确说“没有披露”。
  • 商业模式在变：从“按人头订阅”扩到“订阅 + 用量”。Copilot 按用量消费 credit 的客户环比 +75%，GitHub 改用量计费后 agent 功能的 credit 消费翻倍。Nadella 的说法是订阅由 IT 预算出钱，用量由业务部门出钱。
  • capex $45.2B (低于预期，因为第三方产能延期)，约四分之三是 GPU、CPU 等短寿命资产。下季 capex 超过 $50B，日历年 2026 约 $170B，下半财年继续加速。自由现金流 $18.6B；CFO 说 FY27 会保持自由现金流为正，并会在合适时“使用额外资金来源”(BofA 追问：租赁、发债等)。
  • OpenAI 占本季收入 11% (Goldman 分析师在提问中说出，管理层没有反驳)。Nadella 用很长的篇幅讲“企业的广度”，原话是只靠“四个买很多算力的客户”撑几个季度增长“在我看来不是一门生意”，对大客户的态度是“价格合适就卖一些”。
  • 零提问的地方：商业 bookings -12%、Windows OEM -27% 且库存仍高、自愿离职计划 (已计入下季成本指引)、OpenAI 合同条款。这些是我们自己需要补的功课。

怎么读这份笔记

一场电话会通常分三段：主持人和投资者关系负责人的开场套话、管理层的准备发言 (CEO 讲业务和产品，CFO 讲数字和指引)、分析师问答。准备发言是写好稿子念的，偏宣传；问答才是信息量最大的部分，因为分析师会追问管理层不想主动讲的东西。

Azure微软的公有云：租 CPU、GPU、存储、数据库给企业和 AI 公司，按用量收费，像水电表。用量计费 (A 类)。增速 48%，是公司增长的主要发动机，也是 capex 的主要去处。
FoundryAzure 上的“建 agent 工作台”：企业在里面挑模型 (OpenAI、开源、微软自研 MAI 等)、接数据、部署和评估 agent。按 token 和调用收费。收入 3 倍以上，是 Azure AI 增长的关键入口。
token / 每 token 收入模型处理文字的计量单位，大约一个英文单词的 3/4。客户按 token 数付费，像出租车按公里计价。本季每 token 价格高于预期 (更贵的新模型被大量使用)，直接推高 Azure 收入；但这项会随模型组合波动。
3P GPU-as-a-Service (第三方 GPU 租赁)微软向 CoreWeave、Nebius 这类 neocloud 租来的 GPU 产能，再转卖给自己的客户。算在 capex (融资租赁)。本季部分交付延期到下半年，压低了 capex，也限制了 Azure 可卖的产能。
fungible fleet (可互换的机群)同一批机器可以随时分配给 Azure 客户、Foundry、Copilot 或内部研发，哪里回报高就给哪里，像一个可以调度的车队。让微软在需求波动时少浪费产能，是管理层解释效率提升的核心说法。
M365 E3 / E5 / E7Microsoft 365 企业版套餐的档位：E3 是基础办公 + 安全，E5 加高级安全和语音，E7 再把 Copilot、Entra 身份和 Agent 365 打包进来。按人头每月收费 (B 类)。提价主要靠客户往高档升级。
M365 Copilot / Copilot credits嵌在 Word、Outlook、Teams 里的 AI 助手，按人每月 $30；agent 干超出套餐的活时按 credit (用量点数) 另外扣钱。坐席由 IT 预算付，credit 由业务部门预算付。消费 credit 的客户环比 +75%，但公司没给坐席数。
GitHub Copilot / Copilot Fusion写代码的 AI 助手。2026-06 起超出套餐的部分按用量收费；Fusion 会在多个模型之间自动路由，用更便宜的模型完成同样质量的任务。M365 商业云超预期的主要来源。Fusion 让客户每个 credit 干更多活，短期可能压单价，长期拉用量。
Agent 365 / Perception / Purview管 agent 的工具：Agent 365 是 agent 的登记和监控台 (5,000 万个 agent 在册)，Perception 负责 agent 的安全隔离，Purview 负责审计和合规。属于“治理层”，大部分包含在 E5/E7 坐席里，是微软最难被替代的部分之一。
Work IQ / Microsoft IQ把 M365 里人、邮件、会议、文档之间的关系整理成 agent 可以用的“上下文”。Microsoft IQ 把 Work IQ、Fabric IQ、Foundry IQ 合在一起。目前不单独收费，但是让 agent 留在微软生态里的关键。
Fabric微软的数据分析平台 (数据湖 + 数仓 + BI)，和 SNOW、Databricks 竞争。按容量收费。付费客户 4.4 万，+50%。
MAI 模型微软自研的模型系列 (MAI-Code Flash、MAI-Transcribe、MAI-Base-2 等)。目标是在前沿模型发布 3-6 个月内做到接近的能力，训练成本只要一小部分。降低对 OpenAI 的依赖和推理成本；也让大客户可以用自己的数据训练专属模型。
RPO / bookingsRPO 是已签合同里还没确认成收入的总金额；bookings 是本季新签的合同金额。RPO $677B (+73%) 显示远期需求，但高度集中在少数大合同；bookings -12% 是高基数造成的。
finance lease (融资租赁)长期租用数据中心或 GPU 的合同，会计上在租约开始时把整笔本金计入 capex。本季 $7.4B。也是一种融资方式，CFO 在问答里点名。
dock-to-liveGPU 机柜运到数据中心到真正上线卖给客户之间的时间。缩短 20% 意味着同样的 capex 更早产生收入。
Maia / Cobalt微软自研芯片：Maia 是 AI 加速器 (对标 GPU)，Cobalt 是通用 CPU。降低每 token 和每 CPU 小时的成本，是 capex 效率的长期来源。
FDE / Frontier Co.前线部署工程师 (Forward Deployed Engineers)：派驻客户现场帮企业把 agent 真正搭起来的团队。说明 agent 在企业里落地需要人帮忙，用量计费的推广会比 GitHub 慢。
cc (constant currency)固定汇率增速，剔除汇率波动的影响。微软指引大多按 cc 给，比较时要用同一口径。
