一颗 XPU 分两半：中间的计算核心决定"算得对不对路"，外围的高速接口、HBM 连接、2.5D 封装和量产决定"造不造得出来"。OpenAI、Anthropic、Google 自研做的是前一半 (定义架构、写计算核心、配编译器)，后一半要靠十几年攒下的 IP 和 TSMC / CoWoS / HBM 的产能关系，目前只有 AVGO、MRVL、MediaTek 这类公司能稳定交付。所以"自研 ASIC"不是甩掉设计服务商，而是重新分工：客户越成熟，分工边界越往客户那边移，服务商每颗芯片拿到的钱 (content/chip) 越少，但颗数越多。四种主流合作 (Jalapeño、TPU×AVGO、TPU×MediaTek、Trainium×Alchip) 的差别，归结为两件事：关键 IP 由谁提供 (决定毛利率)，谁替客户采购并出货 (决定收入规模)。

Follow-up

  • OpenAI Jalapeño 能否在 2026 年底按时上量：这是第一颗"实验室从 0 做到量产"的 XPU，2026.06.24 才出样片。按时上量 → 说明实验室 + AVGO 全包模式约 2 年可以走通，其他实验室会跟；延期或良率问题 → 说明后一半比想象难，AVGO 的议价权更强
  • Google TPU 8i (MediaTek) 在 TSMC 2nm 上的进度，目标 2027 年底：这是"客户自己做大部分、服务商只做 IO"模式的大考。做成 → AVGO 在 Google 的 content/chip 有下行压力，MediaTek 拿到第二个大客户的筹码；做不成 → 回到 AVGO 全包
  • Anthropic 芯片团队选谁做 partner、何时首次 tapeout：团队 2026.08 才公开，据报道和三星谈过 2nm。选 TSMC 系 (AVGO / MRVL / Alchip) → 走成熟路线，2028 年前难有量；选三星代工一体化 → 说明 TSMC 先进封装产能是真约束，愿意拿技术风险换产能
  • AVGO / MRVL 的 custom 收入增速 vs 客户芯片出货量增速：收入增速 > 出货增速 → 服务商还在多拿 content (代采 HBM、加网络芯片)；收入增速 < 出货增速 → 分工边界在往客户移，看毛利率是否同步上升 (卖 IP 毛利高、转手 HBM 毛利低)
  • MediaTek 在 TPU v9 的份额能否被确认：据报道它靠 336G SerDes 拿下 v9 的主要份额，2028 年初量产。坐实 → MediaTek 从"只做接口"升级为 Google 主力伙伴，AVGO 在 Google 的份额会出现真正的下滑，而不只是被压价；落空 → AVGO 在 Google 的地位维持到 2031 年
  • CoWoS 和 HBM 的配额分给谁：ASIC 最终能出多少颗，卡在封装和 HBM，不在设计。TSMC CoWoS 扩产和 HBM 厂长约里 ASIC 客户的占比上升 → GPU 之外的 XPU 真的在放量，对内存是纯加项

1. 先把名词对齐：GPU、ASIC、XPU

  • GPU：通用 AI 加速器。NVDA 设计一颗，卖给所有客户，什么模型都能跑。代价是通用性占面积、占功耗，而且 NVDA 的毛利率约 70% 以上，客户付的钱里大部分是 NVDA 的利润
  • ASIC (Application-Specific Integrated Circuit，专用芯片)：为一类任务专门设计的芯片。比特币矿机芯片就是 ASIC，只会算一种哈希，但算得最省电
  • XPU：行业对"大客户定制的 AI 加速器"的统称 (AVGO 带起来的叫法)。Google TPU、AWS Trainium、Meta MTIA、Microsoft Maia、OpenAI Jalapeño 都算。它比矿机芯片通用得多 (能跑各种 Transformer 模型)，但比 GPU 窄 (只为自己的模型和框架优化)
  • 真正的区别不在"能不能做矩阵乘法"：大家都能。区别在取舍。只服务自己的模型，就可以砍掉用不上的功能，把省下来的面积和功耗花在自己最缺的地方，比如推理最缺的 HBM 带宽和片上缓存

部件做什么难点在哪 / 谁擅长
计算 die真正做乘法加法的地方：一大块矩阵乘法阵列 (TPU 叫 systolic array，NVDA 叫 tensor core)、向量单元、片上 SRAM、控制逻辑面积逼近光刻机一次能曝光的上限 (约 26×33mm ≈ 858mm²)，所以旗舰都拼两颗。架构取舍是客户最懂的部分
HBM把 DRAM 芯片垂直叠 8–12 层，紧贴计算 die 放，提供每秒数 TB 的带宽HBM 本身买 SK Hynix / 三星 / MU 的；难的是 HBM PHY (连接电路) 和 interposer 上上千根走线。推理 decode 速度基本由 HBM 带宽决定
对外接口 (SerDes)把芯片内部的并行数据变成高速串行信号发出去：连同机柜里的其他 XPU (scale-up)、连网络 (scale-out)、连 CPU (PCIe)全球最难的模拟电路之一。当前前沿是单通道 224Gbps，能量产的只有 AVGO、MRVL、MediaTek、Synopsys、Cadence 等少数几家
Die-to-die让两颗计算 die、或计算 die 和 IO die 之间像在一颗芯片里一样通信要做到带宽极高、延迟和功耗极低；有 UCIe 等标准，但旗舰多用自有方案
封装把以上所有东西放到一块硅中介层上 (TSMC 叫 CoWoS)，再装到基板上翘曲、散热、信号完整性；产能几乎全在 TSMC，要提前一年以上抢配额
芯片之外还有一块：软件
编译器、算子库 (kernel)、运行时。芯片造出来但模型跑不起来、跑不满，等于白造。NVDA 的 CUDA 就是这块的护城河。这块完全是客户自己的事，服务商不管

3. 一颗 XPU 的钱花在哪 (可调估算)

改下面任意参数，成本拆分实时重算。默认值是行业经验值，不是任何公司的披露数据，用来看量级和结构，不用来算某家公司的利润

  • 默认参数下，HBM 占制造成本六成以上：8 堆 × 600 美元 ≈ 4,800 美元，而两颗 N3 计算 die 合计只有一千美元出头。这就是为什么"谁替客户采购 HBM"会大幅改变设计服务商报出来的收入
  • 面积和良率是非线性的：die 面积从 800 降到 600mm²，每片晶圆能切的颗数多三成以上，良率通常也更高。这是架构师拼命省面积的原因
  • 制造成本不等于售价：服务商在这上面加自己的毛利卖给客户；NVDA 同类 GPU 的售价是制造成本的数倍。两者的差，就是客户自研想省下来的钱

4. 从想法到量产：2–3 年、约 5 亿美元

阶段做什么说人话
架构定义拿自己的模型跑性能模拟，决定算力、HBM、SRAM、互联带宽各配多少相当于盖楼前定户型。实验室自研的价值几乎全在这一步：它最清楚自己的模型 2 年后长什么样
RTL 设计用硬件描述语言 (Verilog 等) 写出电路逻辑画施工图。计算核心客户可以自己写；SerDes、HBM PHY 这些模块一般直接买现成 IP
验证用仿真、硬件仿真器 (emulator) 和 FPGA 证明电路行为和设计一致最耗人的一步，通常占设计人力一半以上。芯片不能打补丁，漏一个 bug 就可能重来
物理设计把逻辑变成几百亿个晶体管的摆放和连线，满足频率、功耗、面积 (PPA)施工。高度依赖 EDA 工具 (SNPS / CDNS) 和对 TSMC 工艺的经验
DFT + Tapeout埋入测试电路，然后把最终设计交给 TSMC 做光罩交图纸开工。N3 一套光罩约数千万美元 (经验值)
流片 + Bring-up晶圆厂生产约 3–4 个月，芯片回来后点亮、调试、跑模型第一次通电。出问题要改设计重新流片 (respin)，多花一套光罩和约半年
量产爬坡拿 CoWoS 和 HBM 配额、提良率、做系统 (板卡、机柜、散热)从"能做出来"到"能做出几十万颗"。供应链关系在这一步决定成败
  • 成本：Reuters 引用的业内估算，设计一颗先进 AI 芯片约 5 亿美元，主要是工程师、验证和测试。对年收入几百亿美元的实验室，这笔钱不大；难的是人和时间
  • 人：一个完整项目通常要几百名工程师 (经验值)，其中验证和物理设计占大头。实验室招来的多是架构、RTL 和编译器的人，后端和模拟电路的人最难招

四条边界

  • 边界一：关键 IP 由谁提供，决定毛利率。AVGO 和 MediaTek 都有自研 SerDes，卖的是技术；Alchip 主要卖后端人力和产能，所以同样是 3nm AI 芯片，Alchip 毛利率只有约 10–15%，AVGO 的 XPU 反推在 60% 以上
  • 边界二：谁是卖方，决定收入规模。四种合作里服务商都替客户买晶圆、HBM、CoWoS，再以成品芯片卖给客户，所以收入里含大量转手成本，也承担库存和良率风险。看服务商收入时，要先拆掉这部分转手
  • 边界三：服务商有没有系统和渠道。AVGO 对 Google 不只是代工：它直接把整柜 Ironwood 卖给 Anthropic，订单合计 210 亿美元。AVGO 已经从芯片供应商变成 TPU 的一个销售渠道，MediaTek 和 Alchip 都没有这个角色
  • 边界四：客户能力越强，服务商越容易被换。AWS 自己做了几乎整颗芯片，Trn2 到 Trn3 就从 MRVL 换成 Alchip；Google 用 MediaTek 压 AVGO 的价；OpenAI 第 1 代离不开 AVGO。所以服务商在一个客户身上的定价权，和客户的代数成反比
一句话
Jalapeño 是"AVGO 帮你造一颗芯片"，TPU×AVGO 是"AVGO 替 Google 造芯片、还替它卖"，TPU×MediaTek 是"Google 只外包接口和生产协调"，Trainium×Alchip 是"AWS 自己设计，Alchip 只负责落地生产"。从左到右，客户做得越来越多，服务商每颗芯片拿到的毛利越来越少

7. 实验室为什么离不开 AVGO 们

  • SerDes 是十几年的积累，买不来也招不来：224G SerDes 能量产的公司一只手数得过来。XPU 的价值越来越取决于芯片之间连得多快 (几十到上千颗芯片当一台机器用)，这块做不好，计算核心再好也白搭
  • 第一次就要成功：一次 respin = 多花一套数千万美元的光罩 + 约半年。AVGO、MRVL 每年 tapeout 几十颗先进制程芯片，踩过的坑都写进了流程和 IP 里。实验室第一颗芯片，最怕的就是时间
  • 产能是关系，不是钱：TSMC 的 N3 / N2 晶圆和 CoWoS 封装要提前一年以上分配，HBM 要签长约。AVGO 是 TSMC 前几大客户，拿配额的能力远强于一家第一次下单的实验室
  • 系统和网络打包卖：OpenAI 的方案用 AVGO 的以太网交换机做 scale-out。服务商在芯片上让一点利润，在网络芯片上赚回来
  • 后端人才极度稀缺：模拟电路、物理设计、封装工程师的培养周期以十年计，全球大部分集中在这几家公司和 TSMC 生态里

8. 那为什么还要自研

  • 省中间商毛利：客户每颗芯片省下的钱 ≈ 售价 × (NVDA 毛利率 − 服务商毛利率)。NVDA 毛利率约 70% 以上，服务商的定制芯片业务远低于此，差额在百万颗级别的出货量下就是每年数十亿美元
  • 只为自己的模型优化：推理占的算力越来越大，Google 第 8 代 TPU 第一次拆成训练 (8t) 和推理 (8i) 两颗，OpenAI Jalapeño 也是推理优先。通用 GPU 做不了这种取舍
  • 第二供应源 = 谈判筹码：GPU 给谁、给多少由 NVDA 决定。手里有一颗能用的自研芯片，买 GPU 的价格和配额都好谈
  • 软件门槛对实验室反而低：云厂把芯片租给外部客户，需要 CUDA 级别的生态；实验室只要跑通自己的几个模型、一个框架。这是实验室比普通企业更适合做 XPU 的根本原因
  • 风险：架构押错 (模型结构 2 年后变了)、延期、第一代通常打不过同期 GPU。所以没有一家只押自研，全部是"GPU + 别人的 XPU + 自研"并行

10. 对我们的含义

  • 服务商收入 = 客户芯片颗数 × 每颗 content：颗数看客户的部署 GW；content 看服务商包了多少。同一颗 TPU，AVGO 全包和 MediaTek 只做 IO，每颗收入可以差好几倍，所以不能只看谁"拿到了客户"
  • 分工边界只会往客户那边移：Google 已经在移；OpenAI、Anthropic 第一、二代大概率全包，第三代以后会开始拆。AVGO 的长期问题不是丢客户，而是每个成熟客户的 content/chip 会下降，要靠新客户和网络芯片补
  • 不管 GPU 还是 XPU 赢，HBM 和 CoWoS 都是必经之路：默认参数下 HBM 占 XPU 制造成本六成以上。XPU 放量对内存是纯加项，而且 XPU 为了推理往往配更多 HBM。这和我们内存的主线是一致的
  • 实验室自研的真正门槛是时间，不是钱：5 亿美元对年收入几百亿的实验室不算什么；但从组队到量产至少 2–3 年。Anthropic 2026 年才组队，2028 年前它的算力仍然来自 TPU、Trainium 和 GPU
