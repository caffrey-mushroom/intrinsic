结论：模型格局分散化是真的，但它打的是“中间层”，不是“顶层”。数据已经在走 Apple 的路径：Claude 在 OpenRouter 的 token 份额一年从 29% 掉到 13%，同期 Anthropic run-rate 从 $9B 涨到 $65B+，毛利率从 33% 爬到 50%+。量份额丢、钱份额拿，这一段类比成立。

类比真正断掉的地方在资产负债表：Apple 是 asset-light、每年发一代就能吃十年的生态；Anthropic 的领先半衰期以月计，还要先签 $518B（约 9 倍 2026 收入）的算力承诺。所以它更像 Apple 的定价权 × TSMC 的资本强度。Buffett 式的 10x 机会不在现在（IPO 传言 >$2T，约 20–35x 收入），而在市场哪天开始按“大宗商品”给它定价的时候。

Follow-up：接下来盯什么

  1. “量份额 vs 钱份额”的剪刀差。 Ramp 7 月：Fable 5 拿 6% token、11.4% 花费，spend/token 1.9x；GPT-5.6 Sol 是 0.9x。这个倍数收窄到 1.3x 以下，说明溢价在被侵蚀。
  2. 顶层价格带是否守住。 现在 $10/$50（Fable 5.1、GPT-6 Astra）和 $4/$20（Opus 5.5、Gemini 4 Argon 正式价）两档对齐。哪家先在顶层降价，就是 oligopoly 纪律开始松动。
  3. S-1 公开版的四个数： 毛利率（尤其 cloud partner 渠道）、前两大客户占比（FY25 近 25%）、承诺的分年度节奏、Claude Code / Enterprise 的 net revenue retention。
  4. Fast-follow 的时差。 中国开源模型追平某个 frontier 能力用了几个月。anti-distillation（推理摘要化、preserved thinking）能否把时差从约 3–6 个月拉长。
  5. OpenAI 的产能填充压力。 它的长期承诺约 $665B，对比 2026 内部预测收入约 $36B。承诺越重，越有动力在中间层用价格换量，这是结构性的，不是一次性的。
  6. Meta 何时把 Muse Wonder Full 开 API。 现在只开放较弱的版本，它主要打 consumer；一旦开放 API 并低价，是对企业 API 价格带最直接的冲击。

1. 量份额在丢，钱份额在拿：Apple 路径已经出现

你的出发点是对的：1H 那种超级集中不可持续。3Q 发生了三件事：中国开源模型通过蒸馏把 OpenRouter 上美国模型的 token 份额从约 70% 打到约 30%；OpenAI 用 GPT-5.6 Sol / 6.1 Sol 的“同价更好、或更便宜”打回企业市场（Ramp 季度增速 82 vs Anthropic 76）；Meta 10 月 13 日发布 Muse Wonder，自报 benchmark 在 coding 和 memory 上超过 GPT-6 和 Fable 5.1。

但把“量”和“钱”拆开看，图形和 2015 年的手机行业很像。Apple 当年出货量份额约 16%，拿走了行业约九成的经营利润。今天 Fable 这一层 token 占比很小，花费占比是 token 占比的两倍。

这说明分散化首先发生在“够用就行”的 token 上：分类、摘要、简单 agent 步骤、批量生成。这一层的价格以 10 倍、20 倍的速度下沉，Anthropic 本来就没拿多少钱。真正决定 frontier lab 生死的，是“只有最好的模型能做成”的那部分任务，它们按 cost per successful task 定价，不按 cost per token。

2. 价格变成哑铃：顶层在提价，中间层在塌

如果 frontier 正在被商品化，你应该看到顶层价格往下走。实际看到的是相反：Opus 4.8 的输出价是 $25/M，新一代顶层 Fable 5.1 和 GPT-6 Astra 都定在 $50/M，Google 的 Gemini 4 Argon 介绍期 $2/$10，之后要涨到 $4/$20，正好对齐 Opus 5.5。被打穿的是中间：GPT-6.1 Sol $10，Qwen3.7-Plus $1.6，DeepSeek V4-Flash $0.28。

这就是 iPhone Pro / Pro Max 的打法：在安卓把均价打下来的同时，Apple 往上开新价格带，ASP 不降反升。差别在于 Apple 的上探靠工业设计和芯片，可以持续很多年；模型的上探靠下一代 training run，每一代都要重新买。

4. 更贴切的组合：Apple 的定价权 × TSMC 的资本强度

TSMC 的结构几乎可以逐条映射：每个 node 是一代模型；leading-edge node 有溢价且产能集中；成熟制程份额被追赶者（中芯、联电）拿走，但成熟制程本来就不赚大钱；赢家要先于需求投入巨额 capex，而且一旦停下来，两代之内就会掉队。“蒸馏”在这里对应的是成熟制程的扩散，挡不住，也不需要挡住。

区别在于 TSMC 的客户锁定来自 tape-out 成本（一颗芯片换代工厂要重新流片，数亿美元），模型的对应物只是一套 eval 和 prompt 的迁移成本，低一个数量级。Anthropic 正在用 Claude Code、企业 agent 平台和 seat 型收入去补这块，这是它最像 Apple 的地方，也是决定结局的地方。

终局更可能长成云计算的样子：三到四家寡头，各自有资本强度，价格随成本下行但维持合理毛利（AWS / Azure 长期 25–40% 经营利润率），其中一家靠品牌和工作流拿到明显溢价。

5. 竞争：谁在追，用什么追，为什么停不下来

OpenAI：降价是承诺结构逼出来的

OpenAI 的长期算力承诺约 $665B，2026 年内部预测收入约 $36B，2026 年现金消耗约 $27B。固定成本这么重的时候，边际定价的理性下限接近边际成本，这和航空业满座率逻辑一样。所以 Sol 系列的“同价更好”不是阶段性打法，而是会持续的结构性压力。它在 Ramp 上的回升（7 月 39.7% vs Anthropic 43.5%）主要来自现有客户用量，说明打的是价格敏感的中间层。

Google：在顶层守纪律

Gemini 4 Argon 目前只开放给可信的网络安全防御方，正式价 $4/$20，和 Opus 5.5 对齐，没有在顶层压价。Google Cloud backlog 很大，本身也是 Anthropic 的分销渠道和 $111B 的算力供应商，竞合关系让它倾向维持价格带。

Meta：追得最快，但先打消费者

Muse Wonder 在 Vals 的网络安全任务排第一，2026 capex $145B。但最强的 Full 版本不开 API，变现方式是 $20 / $100 订阅。对 Anthropic 的企业 API 收入暂时是间接威胁，对 OpenAI 的 ChatGPT 是直接威胁。

SpaceX / xAI：更像在变成 neocloud

你提到 SPCX 追得快于预期。模型能力上也许如此，但 SpaceX 的 IPO 文件给出的经济信号相反：xAI 2025 年收入 $3.2B、经营亏损 $6.4B，Grok 用量下滑，Colossus 1 整栋 300MW 以每月 $1.25B 租给了 Anthropic（到 2029.05，90 天可退）。一个 tier-2 把自己的算力卖给领先者，是产能过剩和格局向头部收敛的信号。

中国开源：挡不住，但被限制在中间层

Anthropic 9 月披露 7 家中国实验室的蒸馏活动，并用推理摘要化和 preserved thinking 提高蒸馏成本。这能拉长时差，不能消灭时差。好在美国企业对中国模型有数据合规折价，开源的主战场是 OpenRouter 这类价格敏感的开发者流量，而不是 Anthropic 78% 的企业收入。

6. UE：毛利在改善，但改善来自效率，不来自定价

第三方估算的季度毛利率从 1Q25 的 21% 一路走到 3Q26 的 57%，每 $1 收入对应的算力成本（含训练）从 $2.41 降到 $0.54。驱动是推理效率和规模，而不是涨价，这一点很重要：它意味着即使中间层价格继续塌，只要 Anthropic 的成本曲线下降得比价格快，毛利还能守住。

值得注意的是，最像 Apple 的两块（Claude Code 与订阅）毛利反而偏低，因为重度用户是按包月吃算力的。Apple 的 Services 毛利约 75%，是生态成熟之后的收割；Anthropic 现在还在用生态补贴拉 installed base，收割要等 seat 与 workflow 收入占比上来。

7. Runway：短期不是问题，问题是 $518B 预设了多快的增长

短期现金不紧：累计融资约 $125B（含 5 月 $65B Series H，$965B post），2Q26 起报道为调整后经营利润为正，11 月左右 IPO。真正的约束是承诺结构：约 80% 不可撤销，等于把未来几年的算力成本变成固定成本。增长够快，这是护城河（别人买不到这么多算力）；增长不够快，就是航空公司的固定成本陷阱。

8. 估值：Buffett 的 10x 时刻还没到

Buffett 2016 年买 Apple 的时候，市场按约 10–11x P/E、不到 3x 市销率给它定价，隐含的是“硬件见顶、会被安卓商品化”。他赌的是 installed base 和 Services 会把一家硬件公司变成一家消费特许经营权。

今天的定价是反过来的：IPO 讨论的估值 >$2T，对 2026 年收入约 35x，对年底 run-rate 约 20x，隐含的是“它会继续集中利润池”。也就是说，你的 Apple 类比本身已经是市场共识的一部分，不是预期差。

真正的预期差窗口会在这种时候出现：增速放缓到 30–40%，中间层价格战上新闻，OpenRouter 份额继续掉，市场开始按情景 C 定价；而同时 spend/token 溢价、顶层价格带、enterprise seat 留存都还守着。那时候的 Anthropic 才是 2016 年的 Apple。
