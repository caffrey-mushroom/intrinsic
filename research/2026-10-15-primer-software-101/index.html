软件公司卖的是"把一个岗位或一条流程搬进电脑"的工具，大多按年收订阅费。看懂一家软件公司只要回答三个问题：它替谁干哪件活，按什么收钱（人头、用量还是交易抽成），客户为什么换不掉。这一页先借半导体的概念打个底，再用一家大公司的一天把 40 多个名字串起来，最后每家公司给一句大白话。

1. 用半导体的眼光看软件

你最熟的 Synopsys 和 Cadence 本身就是软件公司，而且是这个行业里最好的那一类：工程师离不开，换工具要重新训练整个团队、重新验证流程，按年收 license 费，毛利 80% 以上。拿 EDA 当尺子去量别的软件公司，大部分判断都能套上：这家公司是不是也"长在客户的工作流程里"，客户换掉它要付出多大代价。

你熟悉的概念软件里对应的是说明
Backlog / 在手订单RPO / cRPO已经签约、还没确认成收入的合同额。cRPO 是未来 12 个月内要确认的部分，最接近"下一年收入的能见度"。
按 wafer starts 收钱的产能按用量收费Snowflake、Datadog、MongoDB 按客户用了多少算力和存储收钱，客户业务一涨它就涨，像 foundry 的稼动率。AI agent 跑得越多，这类公司越受益。
同一客户的钱包份额增长NRR 净收入留存去年的老客户今年付了多少钱。120% 意味着老客户平均多买了两成，不靠新客户就有 20% 增长。GRR 则只看流失，好公司在 95% 以上。
Design win → 量产Land and expand先卖给一个部门（land），再扩到全公司、加卖新模块（expand）。软件销售的主要增长方式。
库存周期、砍单几乎没有订阅制没有库存。坏情况是续约时客户少买 seat、要折扣，或者干脆换供应商，所以反映得慢，但一旦发生也很难逆转。
Capex 密集度SBC（股权激励）软件公司几乎不花 capex，最大的"隐藏成本"是给员工发的股票，常占收入 10–30%。我们的框架总是看扣掉 SBC 之后的 FCF。
工艺代际切换平台迁移本地部署 → 云（2010 年代）→ AI agent（现在）。每次切换都会洗牌，这次市场在赌谁会被 agent 绕过。

2. 行业结构：八个子行业在一家公司里的位置

把一家公司用到的软件从下往上叠，就是我们 mapping 里的八个子行业。越往下越"技术"，买家是 CTO 和工程师；越往上越"业务"，买家是 HR、财务、销售这些部门负责人。

3. 软件公司怎么收钱

收费方式决定了 AI 对一家公司是加项还是减项，所以这是 mapping 里最重要的一个维度。市场今年的分化，很大程度上就是按这张表在分。

收费方式怎么算钱例子AI 带来的影响
按 seat每个使用者每月付一笔钱Salesforce、Adobe、Atlassian、monday、HubSpot、GitLab最直接的风险：员工少了 seat 就少。这一组今年跌得最深，好几家都在改成按用量收费。
按员工总数按公司员工人数收，不管谁登录Workday、ADP、Paychex、Paycom只有公司整体裁员才受影响，比按 seat 稳。发薪类还能赚客户存款的利息。
按用量按算力、存储、数据量、调用次数Snowflake、Datadog、MongoDB、Cloudflare、Elastic正面：agent 产生更多数据和调用。这一组今年大多已经涨上去了。
交易抽成经手的每笔交易收一个很小的费率Adyen、PayPal、Shopify、Toast、Block看交易量，和 AI 关系不大。担心的是 AI 购物助手绕过某些付款按钮（如 PayPal）。
内容订阅按年订阅独家数据库Thomson Reuters、RELX、Wolters Kluwer、Verisk市场担心 AI 律师、AI 医生助手取代它们；我们的判断是独家内容反而是 AI 的原料。
硬件 + 订阅卖设备，再按年收服务和更新费Fortinet、Check Point、Palo Alto、Axon中性，跟着企业安全和网络开支走。
按人天按投入的工程师时间计费Accenture、TCS、Infosys最直接的通缩：AI 让同样的活需要更少的人。

4. 一家大公司的一天：40 多个名字串起来

假设一家 3 万名员工的美国制造企业，有工厂、有销售团队、有自己的软件部门，也在网上卖货。下面是它一天里会碰到的软件，基本覆盖了 mapping 里的大部分名字。

08:30 上班开电脑
员工用 Okta 登录，一个账号就能进所有系统，手机上再确认一次。他能进哪些系统是 SailPoint 在后台决定的：入职自动开通，转岗收回，离职全部关掉。电脑上装着 CrowdStrike，相当于升级版的杀毒软件，记录每个进程的行为。员工上网和访问公司内部系统的流量，都先经过 Zscaler 的云端检查，不再需要 VPN。总部和工厂机房门口的防火墙来自 Palo Alto 或 Fortinet。
09:00 开会写文档
会议用 Teams（Microsoft）或 Zoom，文档在 Microsoft 365 里，和外部合作方共享文件用 Box。项目进度记在 monday.com 或 Atlassian 的 Confluence 上。
09:30 销售和市场
销售团队打开 Salesforce 看客户和商机，每一通电话、每一次报价都记在里面。市场部用 Adobe 做广告素材和官网，设计师用 Figma 画 App 界面。
10:00 IT 和内部请求
电脑坏了、要开新系统权限、新员工要配电脑，都在 ServiceNow 提工单。它从 IT 工单起家，慢慢变成全公司的流程平台，HR、法务、客服的请求也在上面流转。
11:00 工程师设计产品
机械工程师用 Dassault 的 SolidWorks 或 PTC 的 Creo 画零件，产品的所有版本和物料清单存在 PTC 的 Windchill 里。新厂房由建筑师用 Autodesk 的 Revit 设计，施工方用 Procore 管工地。如果公司自己做芯片，用的就是 Synopsys 和 Cadence。
13:00 软件团队写代码
程序员在 GitLab（或微软的 GitHub）上写代码、互相审代码、自动测试、发布上线，任务记在 Atlassian 的 Jira 里。打包好的软件存放在 JFrog。上线后，Datadog 或 Dynatrace 盯着每台服务器和每个服务，出错就告警。
14:00 数据
公司官网和 App 的实时数据（用户、订单、设备读数）存在 MongoDB 这样的业务数据库里，这是应用"写入"数据的地方。每天这些数据和 SAP、Salesforce 里的数据一起汇总进 Snowflake，分析师在上面做报表、训练模型。Elastic 负责站内搜索和日志检索。
15:00 HR 和发薪
HR 在 Workday 里管员工档案、招聘、绩效、调薪和请假。每两周发工资由 ADP 代办：算工资、代扣税和社保、把钱打到员工账户。规模小一些的公司会用 Paychex、Paycom 或 Paylocity。
16:00 财务
采购、库存、生产计划、应收应付和总账都在 SAP 或 Oracle 的 ERP 里，月底在上面关账。它的小供应商多半用 Intuit 的 QuickBooks 记账，欧洲的小客户用 Sage。
17:00 法务和合同
和客户签合同用 Docusign。律师查判例和法规用 Thomson Reuters 的 Westlaw（TRI）或 RELX 的 LexisNexis，查税法用 TRI 的 Checkpoint 或 Wolters Kluwer。
全天 线上卖货
直营网店搭在 Shopify 上，海外顾客的关税和币种由 Global-e 处理。顾客刷卡或用钱包付款时，交易由 Adyen、PayPal 或 Fiserv 处理，每笔抽一点。网站本身挂在 Cloudflare 后面加速并抵御攻击。
背后 实施
当初上线 SAP 和 Workday 时，是 Accenture 或 Infosys 派了上百名顾问干了一年多。这类项目又贵又慢，也正是这些系统难换的原因之一。

7. 术语表

术语意思
SaaSSoftware as a Service。软件跑在供应商的云上，客户用浏览器访问、按订阅付费；对应的是老式的"买断 license，装在自己机房"。
ARR年化经常性收入，当前所有订阅合同折成一年的金额。软件公司最常用的规模指标。
ACV一份合同平均每年的金额。"新增 ACV"类似新签订单。
NRR / GRR老客户今年付的钱 ÷ 去年付的钱。NRR 包含加购，GRR 只扣流失和降级。
RPO / cRPO已签约未确认的合同额 / 其中未来 12 个月的部分。
Rule of 40收入增速 + FCF 利润率 ≥ 40% 算健康。
SBC-adj FCFFCF 减去股权激励。我们框架的主估值指标，因为 SBC 是真实的股东稀释。
EV/GP企业价值 ÷ 毛利。软件之间毛利率差异大，用毛利比用收入更可比。
SoR（记录系统）某类数据的"唯一正本"在哪里。员工数据的正本在 Workday，客户数据的正本在 Salesforce，总账的正本在 SAP。
Write path改动正本数据必须经过的那个系统。AI agent 要真正办成事（发工资、关工单、下订单），最终得写进 SoR，所以掌握 write path 的公司更难被绕过。
Seat 压缩AI 让同样的工作需要更少员工，按 seat 收费的软件收入随之下降。今年市场最大的担心。
ERP / HCM / CRM / ITSM财务和运营系统 / 人力资本管理（HR）/ 客户关系管理（销售客服）/ IT 服务管理（工单）。
IAM / IGA身份与访问管理（管登录，如 Okta）/ 身份治理（管权限，如 SailPoint）。
EDR / SASE / 零信任端点检测与响应（电脑和服务器上的防护，如 CrowdStrike）/ 云端安全网关（如 Zscaler）/ 默认不信任任何访问，每次都验证。
可观测性监控软件系统的健康状况：指标、日志、调用链。Datadog、Dynatrace。
DevOps把写代码、测试、发布、运维连成一条自动化流水线。GitLab、JFrog、Atlassian。
BIM / PLM / AEC建筑信息模型 / 产品全生命周期管理 / 建筑、工程与施工行业。
Take rate支付和平台公司从交易额里抽的比例。
SMB / Mid-market / Enterprise小企业 / 中型企业 / 大企业。大企业的合同更大、更难换，小企业流失率高。
