结论

一句话：OKTA 是企业里"谁能进哪个系统"的中立总账：员工每天用它一次登录所有 SaaS 应用 (员工身份，~59% ACV)，企业自己的 App 用它的 Auth0 给消费者做注册登录 (客户身份，~41% ACV)。增长分型是 B 类 (钱包阶梯) 为主：在同一批员工上加卖治理 (OIG)、特权 (OPA)、登录后威胁检测 (ITP)，现在再加 Okta for AI Agents，全部按"每个员工加价"收；客户身份按月活收。收入 +10.6%，但未来 12 个月合同 (cRPO) Q2 加速到 +14%，NRR 107%；SBC / 收入降到 14%，FCF Margin 31% (过去 4 季)。现价 $208.24 (2026-10-30 收盘)，EV / FY27E 收入 11.1x，P / FCF 40x，扣 SBC 后 FCF 收益率 1.19%，隐含"未来 5 年收入每年 ~29%" (口径 B)。结论：不买，放观察名单，买点 $85-95。

为什么涨了这么多：股价从 2026-04 的 ~$63 涨到 10 月的 ~$218 (3.5 倍)。两个台阶：Q1 FY27 (5 月) 收入 +11%、cRPO +12%、NRR 升到 107%，加上 4-30 Okta for AI Agents 上市，财报后 +28%；Q2 FY27 (8 月) cRPO 加速到 +14%、非 Q4 纪录订单，财报后 +18%。市场在给"agent 时代谁管 agent 的身份"定价，OKTA 是中立身份平台里唯一已经上市卖货的。

为什么不买：(1) 加速和 AI 无关：CEO 自己排序，cRPO 加速第一靠大企业 ($1M+ 客户 +22%)、第二靠新产品 (占订单 ~30%)，AI "太小，数字里看不到"；CFO 说 AI 对 FY27 "不重要"，FY28 以后才"可能"重要。(2) agent 不按个数收钱：Okta for AI Agents 按每个员工加价 (平台 4 : agent 1-1.5)，一家客户的 Claude agent 几周从 50 个涨到 1,500 个，OKTA 一分钱不多收；最基础的 agent 身份 (Agent SSO、Cross App Access) 还免费送。收入天花板仍然是员工人数。(3) 核心不在拿份额：员工访问管理 MSFT ~40%、OKTA ~30%，CEO 说"相当稳定"；渠道说 E5 客户在把标准登录迁回 Entra。(4) 价格：10.2x NTM 收入配 ~12% 增长，在 0.5x 增速线上方；即使给加速情景 (每年 ~14%、FCF Margin 33%、SBC 10%)，5 年年化也只有 3-6%。卖方 52 家 43 家买入，平均目标价 $217 ≈ 现价。

什么会让我们改主意：价格回到 $85-95；或者 2027 年中第一批一年期 AI 合同续约时出现按 agent 或按用量的计费，同时 FY28 指引给出收入 ≥+12%，这会把加速情景的权重提高，买点可以上移到 ~$140-160 (加速情景 12-15% 年化)。

和 10-29 的 OKTA - 101 (买点 $95-115) 差 ~14%，原因见 6.5 前面的对账段：101 用口径 B 基本情景 8-12% 年化，Deep 统一用 12-15%。对公司的看法没有变。

1. 产品：它是什么、怎么收钱、凭什么赢

1.1 一句话 + 一个例子

OKTA 卖的是"企业里谁能进哪个系统"的总账和闸门。一个员工早上打开电脑，只登录一次 OKTA (用户名 + 手机或指纹确认)，之后 Salesforce、Workday、Slack、AWS 控制台这几百个应用都能直接点开，不用再输密码；入职那天 HR 系统一录入，OKTA 就自动给他开好所有账号，离职那天一键全部关掉。企业自己做的 App (比如保险公司的客户 App)，用 OKTA 的 Auth0 来做"注册、登录、忘记密码"。创始人 Todd McKinnon 2009 年从 Salesforce 出来创办 OKTA，到今天还是 CEO。

打个比方：一栋写字楼的前台和门禁卡系统。OKTA 是前台：登记谁是员工 (目录)，发一张门禁卡 (登录)，这张卡能刷开哪些门由公司定 (授权)，而且楼里 8,000 多种门锁它都能接。后来前台又加卖服务：定期查谁的卡权限太大 (治理 OIG)、机房这种重地发一次性钥匙并录像 (特权 OPA)、进门以后还盯着，发现有人拿着偷来的卡就立刻作废 (威胁检测 ITP)。现在楼里来了很多机器人 (AI agent) 帮员工跑腿，前台也要给它们登记、发卡、限定能去哪层。下面这张图把一次访问拆成 6 站：

1.2 行业背景：为什么需要它

三件事让"统一身份"变成每家公司的标配：(1) 应用搬到了云上：一个大公司用几百个 SaaS 应用，每个都有自己的账号密码，没人管得过来；(2) 员工不在楼里了：防火墙那道墙没用了，"你是谁、用什么设备"成了新的边界，这叫零信任；(3) 入侵大多从身份开始：CEO 说 80% 的入侵是身份类攻击，偷密码、偷会话令牌比攻破防火墙容易得多。OKTA 赶上了这一波，FY22 收入 +56% (含 Auth0 并购)。到 2026 年，大企业的"统一登录"大部分已经装完了，增速降到 ~11%；下一波是 AI agent：每个 agent 都要有身份、要拿令牌去连别的应用，"1 个员工背后 8-10 个机器身份，会到 20-30 个" (Capgemini 离职专家，2026-06)。

1.3 怎么收费

一句话商业模式：OKTA 是 1-3 年的年度订阅，员工身份按员工人数、客户身份按月活用户；新产品和 AI Agents 都是在每个员工的价格上加价。员工身份按套餐卖：Starter (SSO + MFA，$6 / 人 / 月)、Core Essentials ($14)、Essentials ($17)，再往上是询价的 Professional 和加购模块 (okta.com 标价，2026-10)；特权 (OPA) 按管理员人数；客户身份 (Auth0) 按月活用户和功能档位。专业服务收入很少。

一张日常账单。一家 1 万名员工的保险公司，另有一个 200 万月活的客户 App，签 3 年：1 万员工 SSO + MFA + 目录每人每年约 $96，$96 万；治理 (OIG) 每人约 $36，$36 万；300 个管理员的特权 (OPA) 每人约 $600，$18 万；威胁检测 (ITP) 每人约 $24，$24 万；Okta for AI Agents 每人约 $40，$40 万；客户 App 200 万月活每人每年约 $0.24，$48 万。合计约 $2.62M (示意)，其中按员工人头的部分 ~75%；平台对 AI 的比例 ~4.3 : 1，和 CEO 在 Oktane 说的"平台 4 : agent 1-1.5"一致。

收费单位是什么、怎么计数：

收入按收费方式拆分：按员工的核心从 ~50% 降到 ~46%，新产品在变大，客户身份稳定：

承诺 vs 超额。OKTA 几乎全是年度承诺：按人数签 1-3 年，按月平摊确认收入，所以收入增速滞后 cRPO 2-3 个季度。RPO $4.86B (+17%)，比收入涨得快，说明合同在变长、变大。真正"用超了多收"的地方只有客户身份的月活超档。AI Agents 的一年期合同 2027 年中开始第一批续约，那是"按人加价"能不能改成"按 agent / 按用量"的第一个窗口。

1.4 逻辑上：AI 是受益还是受损

方向机制证据我们的判断
受益：agent 数量暴涨每个 agent 都要身份、令牌、权限 → OKTA 管的对象变多一家客户几周从 50 个 Claude agent 到 1,500 个；一家金融客户 2,000+ 个生产 agent；"身份公司平均 ~90 个 agent 对应 1 个员工" (前 PANW 产品经理)核心一行：量涨，但 OKTA 按员工收，agent 部分也按员工加价。量涨价不涨
受益：AI 当敲门砖客户来谈 AI，最后买的是治理和客户身份CEO 把它排在 cRPO 加速的第三个原因；Q2 一单被收购公司的员工身份迁移就是这样拿下的真实但难量化，AI 恐慌降温时会减弱
受益：中立的标准地位Cross App Access 让 agent 跨应用拿令牌，OKTA 发证Claude 支持 XAA，26 家 SaaS 厂商在资源端支持；CEO 让投资人盯"6-12 个月里有多少软件厂商支持 XAA"方向对，但协议是开放的，钱在基础层之上
受损：员工变少员工身份全部按人收；AI 让企业少招人、裁员"客户减员 10% 不会按比例减少 10% 支出" (埃森哲离职专家)；"按席位不适用 AI，因为 AI 数量太多" (前 Cloudflare 侧专家)最大的风险，速度取决于白领裁员的节奏
受损：agent 身份变成免费功能基础 agent 身份被平台捆绑OKTA 自己把 Agent SSO 免费送；前微软身份高管："基础 agent 身份会低价或几乎免费"；MSFT Agent 365 按管理 agent 的员工收费钱只在治理、网关、检测这些上层
受损：PANW 说 agent 归特权管理agent 是"机器身份"，要 PAM 管PANW 收购 CyberArk 的逻辑；"OKTA 管人，CyberArk 管 agent" (Merit 6-04)；CEO 反驳："agent 大多代表普通员工"各说各话，看竞标结果

6.4 计算器

为什么和 101 的买点不同

10-29 的 OKTA - 101 买点是 $95-115，本文是 $85-95，低 ~14%。原因是口径，不是对公司的看法变了：(1) 要求回报：101 的区间对应口径 B 基本情景 8-12% 年化 (下沿 $95 ≈ 11-12%)；Deep 统一用 12-15% 年化。OKTA 的 SBC 占收入 ~16%，低于 20%，按 Deep 规则直接取口径 B 基本情景 15% / 12% 年化的价格 ($84-94，取整到 $5)。(2) 起点：Deep 从 FY27E 收入 $3.25B (比指引中值高 ~1%) 起算，101 从 FY27 指引起算，差别很小。口径 A 在 12-15% 年化下是 $68-76，作为下沿参考。如果你愿意接受 ~10% 的年化，101 的 $95-115 仍是合理的买点。

6.5 结论
