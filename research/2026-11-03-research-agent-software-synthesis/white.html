Agent 之后的软件：变了什么，我们怎么选

把这两个月看过的 34 家软件公司 (Deep 结论) 和跨公司研究收成一份：agent 让软件行业变了什么、钱往哪流、按工作流分的五类公司、我们的立场、喜欢和回避的产品、10 个问题的选股 checklist，以及 34 家对号入座。

v1.0 · 2026.11.03 · 价格 IBKR 11-02 收盘 · 买点来自各 Deep (11-01/02)

34个 Deep 的结论放在一起看 (11-01 到 11-02)
1 + 4买 1 家 (NOW)，小买或分批 4 家，其余观察或不买
+27%按量收费那组，现价离买点上沿的中位数
22xDDOG 的 MCP 调用量，2Q26 对比 4Q25；人用的量没变

结论

一句话：Agent 没有消灭软件，它改的是"谁在用软件"和"软件按什么收钱"；能留住客户的从功能变成了工作流，更准确说是工作流里的权威记录、权限和审计。用户从人变成机器，干活变便宜了，管活变值钱了。按"电表"收钱 (数据量、计算量、请求量、交易笔数) 的公司收到了 agent 带来的量；按"工位"收钱 (seat、员工数) 的公司要么白给，要么只能靠涨价和打包撑一段时间。

但这不是选股结论，因为市场已经知道了。我们 34 个 Deep 里，按量收费那组现价离买点上沿的中位数是 +27%，按人收费那组是 +9%，按交易抽成那组是 +26%。真正落到"买"的只有 NOW，"小买 / 分批 1/3"的是 CRM、HUBS、INTU、TOST，全部不是电表型生意。

我们的打法分两个篮子。第一篮是电表型好生意 (DDOG、SNOW、NET、CRWD 这类)：只在板块恐慌、而加速已经写进报表的时候买，平时等。第二篮是便宜的"关口"：agent 绕不过去的记录系统和审批流程 (NOW、CRM、SAP)，市场把它们当 AI 输家定价，我们只按"收费单位转不过来"的悲观价格买，把"转成按动作收费"当免费期权。

回避五类：给人点的单点工具 seat、编程工具 seat、转卖 token 的低毛利收入、SBC 超过收入 20% 而扣完 SBC 没有 FCF 的公司、被 agent 默认选择绕开的产品。还有一条估值纪律：一次性的迁移提价和并购，不给经常性增长的倍数。

1. Agent 改变了什么：8 条

把这两个月看过的 34 家公司 (加上 Databricks、Anthropic、Accenture 这些对照) 放在一起，agent 带来的变化可以收成 8 条。前 3 条讲"量和钱"，中间 2 条讲"节奏"，后 3 条讲"护城河和分销"。每条后面是证据，以及它在选股时变成哪个问题。

#变化证据 (我们研究里的数字)强度选股时问什么
1用户从人变成机器。Agent 通过 API 和 MCP 读写系统的次数在指数级增长，人点界面的次数基本不变DDOG MCP 调用 2Q26 是 4Q25 的 22 倍以上；TEAM 的 MCP 调用一个季度 +400%，web 和手机端人用的量持平；CRM 每季度 ~1 万亿次 API 调用，AWU 同比 7 倍；SNOW 一家保险客户算力因为查询次数涨了 5-8 倍强公司披露机器调用量吗？调用量和收入增速差多少？
2收费单位决定谁收到钱。同样多出来的 agent 使用，按量收费的收到钱，按人收费的白给2026 年反弹回 2025 年高点以上的只有 SNOW、DDOG、NET、CRWD，全部不按人头收费；按 seat 收费的大盘股还在前高下方 30-70%。TEAM 的 MCP 调用 4 倍增长不产生 seat；CRM 的 Agentforce ARR ~$1.5B，只占收入 ~3%强Agent 干的活越多，你的计费单位变多还是变少？
3量涨价跌。用量在涨，每单位的价格降得也快；按量收费的天花板是客户自己做的成本Databricks token 一个月翻倍，收入只涨 3%；MDB token 涨 3-4 倍，Atlas AI 收入 ~2 倍；厂商主动卖 20-70% 的 token 降本。OpenAI 把日志和指标从 DDOG 拆走；COIN 2022 年 $65M 账单试过自建，最后拿到降价留下。经验是账单超过每年 $2-5M 才值得自建强量涨得比价跌快吗？最大客户的账单离自建线多远？
4Coding agent 先到，业务 agent 后到。2026 年软件的增量几乎都来自工程活动：写代码、搬数据、重写管道SNOW 指引上调主要靠 Cortex Code (9,100 个账户)，迁移收入 FY26 1.9 倍，Teradata 迁移从 2-3 年缩到不到 3 个季度；DDOG 传统企业加速归因于 coding agent 让应用变多。业务侧：Deloitte 调查只有 15% 企业把多 agent 规模化，卡在数据 (72%)、治理 (70%)、集成 (67%)；NOW 内部人说 POC 到生产 5-10%；Databricks Genie 90% 空间不活跃强这家的 AI 增量来自工程师还是业务部门？别把 coding 的钱算成业务 agent 的
5买转自建。写软件变便宜，企业更愿意自己搭，单点 SaaS 工具被替代SNOW 自己用 Cortex Code + Streamlit 取消了 BI 合同；小企业用 vibe coding 搭 agent 替代 Salesforce 许可；GTLB 按开发者 seat 收费的单位被打破，编程工具厂商 10 倍提价也亏钱。自建的东西不付 seat，但要用数据平台、云和监控中客户能不能用 coding agent 两周搭一个替代品？搭出来的东西还要不要用你？
6钱先流到上游。Agent 的钱大头先到模型和算力，软件拿到的是回声Anthropic Q2 2026 收入 $11.56B，同比 +1,368%，其中 ~48% 经云厂商 marketplace；粗算 Anthropic 每多 $1 收入，DDOG、SNOW 各拿到 ~3 美分。增速按收费单位排成梯子：token > 产品化 FDE (PLTR) > 用量 (DDOG、SNOW) > seat (NOW、CRM) > 人天 (ACN)中这家在 AI 收入链条上离 token 多远？
7护城河从"功能"换成"数据 + 权限 + 流程"。每个 agent 都绕不过两件事：以谁的名义、被允许做什么 (身份)，以及改了哪条权威记录 (记录系统写回)SAP 的 Muhammad Alam：数据搬进 DBX/SNOW 就丢了权限；Iceberg 等开放格式让存储不再锁定，锁定移到目录和权限层；NOW 的 CMDB、审批、Action Fabric 按调用收费；OKTA 的 Agent SSO 目前免费中Agent 必须经过你才能动权威数据吗？经过时你收不收钱？
8新的分销渠道是 agent 的默认选择。技术选型从人决定变成 coding agent 默认决定MDB 管理层承认 coding agent "大多数时候在 JSONB 上选 Postgres"；Claude Code 测试里选 Mongo 0/125；Stack Overflow 调查 MDB 使用率 24% 降到 19%。反过来，SNOW 把 Cortex Code 插件放进 Claude Code marketplace，主动争默认位中让 coding agent 从零搭一个应用，它会选你吗？

还有一条供给侧的变化：软件公司自己的成本从人换成 token。SNOW 开始招 AI 原生的初级工程师，SAP 研发人数 +3% 而研发费用 +14%，说要"在 token 和人头之间平衡"。这对 SBC 是长期利好 (少招人、少发股票)，但短期会把毛利率往下拉，尤其是 AI 收入里转卖模型的那部分 (SNOW AI credits 毛利 ~55%，核心仓库毛利更高)。

2. 钱往哪流

把上面 8 条压成一条规律：AI 让"智能"变成一种按量计价、价格一直在降的投入品；价值流向它的互补品。干活的那部分越来越便宜 (人工、seat 界面)，管活的那部分越来越值钱 (算力、数据、身份、记录系统、部署和问责)。我们之前排过的受益顺序是：模型实验室和云厂商 > 数据和可观测性 > PLTR > 记录系统 > seat 工具 > IT 服务。

3. 五类公司：工作流才留得住客户

Caffrey 11-03 提出的框架：让企业留下、持续付钱的不再是功能，而是工作流。按这个标准把软件公司分成三类：按量收费的份额获得者、企业工作流骨架、单薄的工具。我们同意这条主线，补了两处、推了一处，再加两类。

主线再拆一层：留得住的是工作流里的"权威记录 + 权限 + 审计"

工作流有两层：给人看的界面，和底下的记录、权限、留痕。Agent 不看界面，所以界面层正在被拿走：NOW 的入口被 Teams 和 Serval 拿走，但没有一家大企业拆掉 NOW 的底座 (CMDB、审批)。SMB 能用 Claude 复刻一个 CRM，是因为 SMB 没有复杂的权限、合规和系统集成；大企业的 CRM 还会在，是因为 agent 要以某个人的名义、在权限内、写回同一条客户记录，还要留下审计。所以 SMB 客户为主的工作流公司 (HUBS) 比大企业的 (CRM、NOW) 更容易被复刻，HUBS 要盯净增客户 ≥5.5K。

数据迁移变便宜，是双向的

同一个 coding agent 让 SNOW 把 Teradata 迁移从 2-3 年缩到不到 3 个季度 (迁移收入 FY26 1.9 倍)，也让客户把不重要的日志从 DDOG 搬去 ClickHouse 系方案 (OpenAI 分两步拆走日志和指标)。所以"数据在你这"不再是锁定，锁定移到了每天在用的流程上 (DDOG 的告警、仪表盘、排障)。读 DDOG 这类公司，要把收入拆成"可以搬走的存储"和"搬不走的流程"两块。自建的经验线是账单每年超过 $2-5M，风险集中在最大的几个客户。

类型留住客户靠什么增长公式关键风险要看的数字例子和我们的结论
1. 按量收费的份额获得者数据管道 + 每天在用的流程 (告警、排障、查询)用量 - 单价下降 + 同一条管道上多卖产品单价降得比量快；最大客户自建；转卖 token 拉低毛利用量增速 vs 收入增速；剔除最大客户后的增速；毛利率；多产品渗透DDOG、SNOW、NET、CRWD：不买，等板块回调；MDB、ESTC、DT 便宜，但在丢默认选择、单价或份额

推一处：按量那一类的 alpha 不是涨价

按量收费的公司几乎都在降单价：Databricks token 一个月翻倍、收入只涨 3%；ESTC 自家的 LogsDB 压缩把单价压下去；COIN 用自建威胁换到 DDOG 降价。客户控预算的方式是年度承诺额度，量超了就谈折扣。所以第 1 类的 alpha 来自份额 (大客户里 DDOG 赢 DT) 和同一条数据管道上的新计费项 (DDOG 用 4 个以上产品的客户从 51% 到 56%)，而不是单价。

"ARPU 提升 vs seat 放缓"的错配，是时间错配

提价是一次性的，跟着 3 年合同慢慢滚完；seat 下滑是复利的。所以前 2-3 年报表看起来没事，滚完之后才露出来，除非按量收入能接上 (图 1)。证据：CRM 的"量" (新客户和 seat) 已经是负的，有机 ~6-7%；WDAY 的增长拆分里员工数贡献是 0；Ocado 的 Barry Tyson 说上了 agent 之后净账单 -25%。这就是为什么 NOW、CRM 我们只按悲观价格买 1/3，最该盯的是 NOW 净新增里非 seat 的占比 (管理层说 ~50%)。

4. 我们的立场

Caffrey 问的是"你怎么想"。以下是我们的立场，每条都给反方。

1. 最好的生意都已经被定价，现在不追

按量收费、AI 是加项的公司 (DDOG、SNOW、NET、CRWD、PANW、ZS、PLTR、FROG、RBRK) 全部"不买"。NET 现价离买点 +212%，CRWD +303%，隐含未来 5 年 50% 以上的收入复合增长。这些公司扣掉 SBC 之后的 FCF 收益率都在 0% 附近 (SNOW、NET、FROG 是负的)。赢家研究里最有用的一条是时间：DDOG、NET 在 2026 年 2 月 10 日的财报里已经加速到 29% 和 33.6%，之后股价又跟着板块跌了 15-16%，从那周买到现在涨了 52-113%。所以电表型好生意的买点不是"故事出来时"，而是"加速已经在报表里、而板块一起被砸"时。

反方：好生意贵是常态，等不到。我们的回答：等不到就不买，用第二篮子赚钱；另外 SNOW、DDOG 离买点只有 +24-27%，一次板块回调就够。

2. 预期差在"关口"，但只按悲观价格买

NOW 是最清楚的例子：10-29 因为 cRPO 指引 18.5% 一天跌 27%，现价隐含 5 年 ~7-9% 增长，而有机增速还有 ~17%。我们的框架是：NOW 从"要派发和核验的工作变多"里赚钱 (CMDB、审批、Action Fabric 按调用)，从"干活的人变少"里亏钱 (处理工单的 seat)。2026 年是价涨、量不明。我们买它，不是因为确定能转成按动作收费，而是因为现价连"转不过来"的情景都快打折完了。CRM (EV/NTM 4.4x、FCF 收益率 ~8%)、HUBS (~2.7x) 同理，只给 1/3 仓位，等有机增速验证。

反方：seat 收入会被慢慢掏空 (Ocado 的 Barry Tyson 说上了 agent 之后净账单 -25%)，便宜可以更便宜。我们的回答：所以只买 1/3，并给每家写了"失败线" (CRM 有机 ≤6% → 买点下调到 $185-200；NOW 订阅 ≤17% → $85-95)。OKTA 是身份层的逻辑，但现价离买点还有 +95%，身份这个关口还没便宜。

3. 业务 agent 是最大的增量，但别提前付钱

论规模，业务 agent 替代的是业务部门的人工和外包，按笔数经常性收费，远大于 coding。但它慢 (POC 到生产 5-10%，Agentforce 的 POC 十个里一两个上线)，而且钱分得更散 (记录系统、云厂商数据库、身份安全、FDE 和 SI、模型都分一份)。Ascott 的案例里 agent 软件费不到 S$1M，整个项目 S$6M，软件和实施服务大约 1 : 4-5。所以 2026 年的业绩不要归因给业务 agent，估值里也不给它溢价。第一个检查点是 2026 年 Q4 到 2027 年上半年 POC 转生产的比例。

4. SBC 是软件最被忽略的成本

我们的 quality × growth 回归里，增长和 FCF 利润率能解释约 40% 的估值差异，换成扣 SBC 后的 FCF 只能解释约 6%：市场基本不扣 SBC。我们一直扣。SBC 超过收入 20% 的公司 (CRWD 24%、ZS 25%、SNOW 30%、FROG 27%、TEAM 24%、GTLB 22%) 买点用口径 A 和口径 B 的中点，所以都比卖方低一截。这是我们和市场分歧最大、也最一贯的一点。

5. 跟 AI 关系不大的好公司，是不错的配置

TOST (餐厅线下支付 + SaaS)、INTU (税务和小企业账本)、IOT (实体资产传感器)、V、FICO 都不是 agent 主线。它们的风险在别处 (DoorDash POS、监管、agent 结账)，但不会因为"AI 替代人"被重新定价。现在落到小买的是 TOST 和 INTU；V (+33%)、FICO (+26%) 还贵。

6. 便宜的按量公司通常有原因

MDB、ESTC、DT 都按量收费，现价都贴着买点。原因各不相同：MDB 被 agent 默认选择绕开 (Postgres)，ESTC 自家压缩技术把单价压下去，DT 在大客户里被 DDOG 拿份额、有机增长只有 ~15.6%。所以"按量收费 + 便宜"不是自动买入信号，要先回答它为什么便宜、这个原因会不会变。MDB 的拐点是 Atlas 过 30%，这是它第一次满足"加速在报表里"。
