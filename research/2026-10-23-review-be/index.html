收入再超预期，利润率没跟上我们的 model。3Q26 收入 $1,236MN，比 consensus 高约 17%，和我们 model 基本一致（−0.4%）。但 GAAP 毛利率 33.8%，比 model 的 38.0% 低 4.2pp，EBIT 因此比 model 低 17%。净利润反而高 9%，原因是几乎不交税、利息收入也更多，这部分不是经营质量。

全年指引第三次上调到 $4.4–4.6B，non-GAAP 毛利率维持约 34%。这意味着 4Q 毛利率没有阶跃。我们 model 的 4Q26 收入 $1,591MN、GAAP 毛利率 39.4%，两项都在指引隐含区间之上，是这次最需要动的地方。另一个要盯的点是现金：经营现金流转负，合同资产年内从 $179MN 涨到 $793MN。另外，model 里 1Q26 以前是 non-GAAP、2Q26 起是 GAAP，建议统一口径。

2. 驱动拆解

收入：量继续超，结构偏安装

Product 首次单季超过 $1B（$1,073.6MN，+179% YoY，+15% QoQ），比 model 低 1.7%。差额被 Install 补上：Install $84.9MN，比 model 高 $21MN，QoQ +66%。管理层说安装收入跟项目节奏走，会波动。Service $67.6MN，比 model 低 8%，QoQ 基本持平。

公司仍不披露 MW 出货量。Model 里 3Q26 出货是估计值 353MW（每季净增 75MW）。按这个估计算出的 Product ASP 是 $3,038/kW，比 2Q 低 10%。这更可能是出货量估计偏高，而不是降价，因为 CFO 说 pricing "remains strong"。如果 ASP 和 2Q 持平（$3,360/kW），3Q 出货大约 320MW。

毛利率：这是 miss 的主因

GAAP 毛利 $417.1MN，比 model 少 $54MN。拆开看，差额几乎都在 Product：

Model 原来假设 Product 毛利率一个季度跳 5pp（36.5% → 41.5%），实际只升了 1.4pp。 Model 里的单位成本假设是 YoY −10%（$1,809/kW），按估计出货量倒算实际是 $1,887/kW，约 −6%。管理层给的解释有三条：新产线爬坡的启动成本、为赶交付付出的加急费用，以及降本项目要过一段时间才能体现在 COGS 上。这三条在 4Q 都不会消失，而且公司还在扩 Fremont / Newark 产能。

费用：低于 model

R&D $64.1MN / S&M $52.4MN / G&A $75.1MN，合计比 model 少 $9MN，主要是 R&D（model 假设 QoQ +20%，实际 +9%）。GAAP opex 同比约 +33%，non-GAAP opex +26%，本季 SBC 合计 $60.1MN，其中约 $51MN 在 opex。Model 里 G&A 从 1Q 的 $35MN 跳到 2Q 以来的 $71–75MN，主要是口径切换（见第 6 节），不是费用真的翻倍。

线下：净利润 beat 来自税和利息

营业外净收入 $24.3MN（model 只放了 $2.1MN），主要是 $2.5B 现金的利息收入，另有约 $9.3MN 的资产回购和 repowering 收益（公司在 non-GAAP 里剔除了）。所得税只有 $0.8MN，有效税率 0.3%，model 假设约 16%。这两项合计让 EBT 到 NI 多出约 $66MN，把 EBIT 的 $45MN miss 变成了 NI 的 $21MN beat。Non-GAAP EPS 大超 consensus（$0.94 vs $0.68）有很大一块是这个低税率，不全是经营面。

  • 收入：指引中值 $4.5B，隐含 4Q 约 $1.45B（+86% YoY，+17% QoQ）。管理层说落在区间哪一端取决于年底少数几单交付的时间。Model 4Q 的 $1,591MN 比区间上沿还高 $43MN，2026E 收入 $4,643MN 也略高于指引上沿。考虑到公司今年三次上调，指引本身偏保守，但 model 现在没有留余地。

  • EPS 指引上调幅度大于 OI：说明公司也在用接近零的税率和较高的利息收入，这和 3Q 的 beat 结构一致。

4. 电话会要点

  • 需求和 backlog：不披露订单额和 backlog。管理层说 backlog 增速快于收入，客户、行业和地区都更分散。Mizuho 追问 backlog 增速，被推到 4Q 业绩时再说。2027 指引年初给。
  • 客户和项目：Oracle 犹他站点不到两个月就供上电；Nebius 新泽西（共 300MW）签约后三个月拿到规划批文，再两个月第一块就绪；AEP 给 Google 做 700MW 带碳捕集的项目；通过合作方 Indelible 拿到美国陆军设施的有条件长期租约；本季首次向德州发货。管理层说需求正从 hyperscaler 扩散到 utility（表前部署）、C&I、政府和海外。
  • 产能：接近 5GW 年产能，Fremont 正在扩厂房，为超过 5GW 做准备，但没给时间表，也不确认 10GW 目标。管理层强调会按需求"像调旋钮一样"逐步加，不会一步到位。JPM 和 Baird 问到的每季 250–300MW 节奏，管理层没有确认。自动化方面，一条原来 100MW/年要 ~600 人的电堆线，现在同样人力可以做到 1GW。
  • 利润率：CFO 把利润率说成"long game"：现在承担新线启动和加急交付的成本，规模效应会随产线成熟体现。定价强是 Product 毛利率上行的主因之一。
  • 现金流：3Q 经营现金流 −$27MN，capex $153MN，FCF −$181MN（年初至今 +$42MN）。原因是存货、合同资产和应收的增加；开票节点和收入确认不在同一季度。管理层说这"不是趋势的开始"，业务可以自我造血。
  • 新方向：碳捕集（CCS）被称为"超过 $1 万亿"的机会，几乎所有 hyperscale 客户都在问 CCS-ready，很多人能接受 10–15% 的全成本溢价。800V DC："不是会不会，而是多快"，节奏取决于 hyperscaler。海外因为气价更高被视为有吸引力的市场，"会有更多消息"。
  • 股价：10/22 常规交易时段已跌 8.7% 至 $217.77，盘后再跌约 5% 至 ~$206。我们的理解是市场在已有高预期下，对毛利率没有加速和现金流转负更敏感。

6. 对 model 的影响

先说一个口径问题

Model 里 1Q26 及以前的季度是 non-GAAP 口径，2Q26 起是 GAAP。 我核对了两个季度：1Q26 列的毛利 $236.2MN、EBIT $129.7MN 对应公司 non-GAAP（GAAP 是 $225.5MN 和 $72.2MN）；3Q25 列的毛利率 30.4%、EBIT $46.2MN 也是 non-GAAP（GAAP 是 29.2% 和 $7.8MN）。2Q26 和这次的 3Q26 按 GAAP 填。结果是 2026E 年度数一半 non-GAAP 一半 GAAP，YoY 和费用率也会被口径切换扭曲（例如 G&A 1Q→2Q 翻倍）。1st Take 页的 2Q26a 用的是 non-GAAP。建议统一成一种口径，你定用哪个，我来改。

已经发生的机械变化

3Q26 填入实际后，假设格原样保留，只有从最近实际季度往下滚的几行（费用、Install / Service ASP、利息）跟着动。结果如下：

建议调整（还没改，等你确认）

  1. 4Q26 Product 毛利率：现在 43.0%，建议降到 38–39%，和本季 37.9% 及指引隐含一致。影响 4Q GAAP 毛利约 −$60–70MN。
  2. 4Q26 收入：现在 $1,591MN，高于指引上沿 $1,548MN。可以下调到 ~$1.50–1.55B（指引偏保守，放在区间上半段），主要压 Product。
  3. 2027 单位成本假设：Product avg COGS 一直按 YoY −10% 滚，3Q 实际降幅约 −6%（基于估计出货量）。2027E 毛利率 39.3% 的核心依赖这个假设，值得用更保守的 −6~−8% 做一版敏感性。
  4. 税率：model 从 4Q26 起用约 17.5% 的有效税率，但公司仍在用 NOL，3Q 实际 0.3%。如果 4Q 和 2027 上半年也接近零，NI 会被低估；这一项正好部分抵消毛利率下调。
  5. 利息收入：model 4Q26 营业外只有 $3MN，实际季度跑在 $18–24MN。建议改成按现金余额乘利率。
  6. MW 出货：公司不披露，model 每季 +75MW 的估计让 3Q 隐含 ASP 掉 10%，和"定价强"的说法矛盾。可以考虑把 3Q 出货下调到 ~320MW，让 ASP 持平。

把 2026E EBIT $941MN 换到 non-GAAP（加回 2Q、3Q 和 4Q 的 SBC，约 $178MN），大约是 $1,120MN，比指引上沿 $1,030MN 高 9%。第 1、2 条做完后约 $1,030–1,050MN，落在指引上沿附近。考虑到今年已经三次上调，这个位置是合理的乐观，而现在的 model 是明显超出。

Follow-up

  1. 4Q 业绩：合同资产是否开始转化为现金，经营现金流能否回正。
  2. Backlog 数字：管理层答应 4Q 时给 backlog 增速，看是否支撑 model 2027E $10.2B 收入（+119%）。
  3. 2027 指引（年初）：毛利率路径和产能节奏，是否给出 5GW 以上的时间表。
  4. 10-Q：分部 SBC、存货结构、前五大客户集中度，以及 NOL 余额和预计用完的时间。
  5. Nebius 300MW 和 AEP / Google 700MW 的交付节奏，判断 2027 年的出货能见度。
