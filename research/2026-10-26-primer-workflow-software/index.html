Workflow Software · Industry Primer · 2026.10.26

工作流软件行业入门

给第一次看这个 sector 的人：ServiceNow、Atlassian、Salesforce、Workday、HubSpot、Monday 都在卖"让事情在人之间流转"，都按人头收费。它包含哪些产品市场、谁在哪打、怎么演化、钱在价值链哪一环、规模和增速、席位怎么收费、竞争的本质、AI 对席位的影响，以及要跟踪什么。

一页看懂工作流软件

这个行业叫什么：没有统一叫法。卖方常叫"应用软件" (Application Software) 里的工作流 / 协作软件 (Workflow & Collaboration)。Gartner 按具体产品分成很多小市场：ITSM / ESM (IT 和企业服务管理)、CRM、HCM (人力)、敏捷研发管理、协同工作管理、知识管理等。

它们卖的是同一种东西：一件"事" (一张工单、一个销售线索、一个 bug、一个入职申请) 在人与人、部门与部门之间流转，软件负责记录它、分派它、追踪它、自动化它，并且成为这件事的"权威记录" (system of record)。

它们收钱的方式也相同：按"处理这些事的人"收席位费 (per seat / per user)。这是它和 Datadog、Snowflake 这类按用量收费的公司最根本的区别，也决定了 AI 对它是威胁还是机会：agent 替人处理事情以后，席位会不会变少？

现状：这是软件里最大的一块 (Salesforce 一家年收入超过 $400 亿)，但增速在放缓 (CRM、Workday 约 10–12%)，2026 年初"AI 取代 SaaS"的担忧让整个板块大幅杀估值。NOW 和 TEAM 增速仍在 20% 左右，是板块里的高增长者。

下面依次讲：这个 sector 包含哪些产品市场、各家在哪打 (矩阵)；怎么演化；价值链；主要玩家和估值；规模和增速；席位怎么收费；竞争的本质 (自上而下 vs 自下而上、平台 vs 单品、谁拥有记录)；AI 对席位的影响；要跟踪什么。

2024Salesforce 推出 Agentforce (9 月)；Atlassian 宣布本地部署的 Data Center 版本停售时间表AI agent 时代开始；TEAM 迫使客户上云，带来一次性加速
2025ServiceNow 收购 Moveworks (AI 员工助手)；Salesforce 收购 Informatica；Atlassian 收购 The Browser Company、DX大厂用并购补 AI 和数据能力
20261–4 月"AI 取代 SaaS"杀估值；ServiceNow 一年内并购约 $112 亿 (Armis 等)；Salesforce Agentforce ARR 超 $15 亿；Atlassian 开始对 AI credit 设上限收费市场在重新定价席位模式；各家推 AI 定价 (按次、按 credit、按 agent)

三代演化，一句话：第一代是本地部署的单品 (按许可证)；第二代是 SaaS 平台 (按席位订阅，平台化扩张，这是今天所有龙头的来源)；正在发生的第三代是 agent 化：部分"处理事情的人"被 AI agent 替代，收费单位从"人"转向"处理了多少事"。这一代的赢家还没有定。

价值链：钱在哪一环

环节是什么谁掌握在 AI 时代的价值
记录层 (system of record)这件事的权威记录：工单、客户、员工、bug 的数据和历史ServiceNow (IT/员工服务)、Salesforce (客户)、Workday (员工)、Jira (研发任务)最值钱的护城河。agent 要干活，必须读写这些记录；谁拥有记录，谁就能决定 agent 在哪跑
流程和规则层审批流、分派规则、SLA、权限、合规同上，加上低代码平台 (Power Platform、NOW App Engine)同样重要：企业多年积累的规则很难迁走，agent 需要在规则内行动
界面层 (人在哪里干活)工程师、客服、销售每天打开的界面各家应用；Slack / Teams 越来越成为入口被 AI 削弱：如果 agent 直接干活、人只在 Slack 或 Claude 里提问，应用界面的重要性下降
集成和自动化层连接几百个系统的接口和自动化MuleSoft (Salesforce)、Workato、Zapier、IntegrationHub (NOW)、MCP变成标准化：MCP 让任何 agent 都能调用任何系统
AI agent 层自动处理工单、回答问题、执行操作的 agent平台自带 (Agentforce、Now Assist、Rovo)，加上独立 agent 公司 (Sierra、Decagon) 和模型公司新的利润池，也是新的战场：平台想在自己的记录上卖 agent，独立公司想跨平台卖

钱在往哪挪：从"界面和席位" (人在应用里点来点去，按人头付费) 挪到"记录、规则和 agent" (agent 读写记录、按规则完成工作，按处理量付费)。拥有记录层的公司 (NOW、CRM、WDAY) 处在更有利的位置；主要靠界面和人数的产品 (纯协作工具) 风险更大。

规模、增速和份额

这个 sector 没有一个机构口径的总 TAM，各个产品市场 (ITSM、CRM、HCM……) 的机构数字口径差别很大、多在付费墙后。下面用"把主要公司的收入加起来"的方式看规模和增速；具体产品市场的份额只能定性判断。

结论：主要上市和私有工作流软件公司 2025 年合计收入约 $82B，2026 年约 $93B，增速约 14%，明显低于数据平台 (约 18%) 和可观测性 (约 19%)。Salesforce 一家占一半；拿掉 Salesforce，其余增速约 16%。这还不含微软、SAP、Oracle 在这些市场里的大量收入。

席位怎么收费

怎么收费：基本是"按人头 × 版本"，越高级的版本单价越高。AI 功能正在从"免费捆绑"转向"另外收费"。

公司席位定义标价举例AI 怎么收费
ServiceNow处理工单的"fulfiller" (IT 工程师、HR 专员)；提交请求的普通员工免费不公开，按合同；新的 Foundation / Advanced / Prime 版本在续约时提价约 20–30%Now Assist 主要捆在 Pro Plus 等高级版本里，附带一定数量的"assist"，用超了再买
Atlassian每个使用 Jira / Confluence 的用户Jira Standard 约 $7.5、Premium 约 $13.5 每用户每月 (云版标价)Rovo 原先捆绑，2026 年起对 AI credit 设上限、超出收费
Salesforce销售、客服坐席Service Cloud Enterprise 约 $175 每用户每月Agentforce 按对话或按动作 (flex credits) 收费；也有按员工数的企业无限许可 (AELA)
Workday按客户的员工总数 (不是按 HR 用户)不公开AI agent 另外收费

席位模式的逻辑：收入 = 客户数 × 每个客户的席位数 × 每席位单价。过去 20 年三个变量都在涨：客户上云、员工数增长 (席位)、升级到更贵的版本 (单价)。AI 的威胁直接打在中间那个变量上：如果 agent 替代了一部分客服、IT 工程师、销售，席位数就会减少。

各家的防守办法：

  • 提价和版本升级：把 AI 捆进更贵的版本，用"每个席位更值钱"抵消"席位变少"。NOW 管理层原话是"fewer seats, more value"。
  • 改计费单位：按 agent 处理的对话数、动作数、credit 收费 (Agentforce、Rovo credits)。
  • 按员工总数收费：Workday 一直这样做，Salesforce 的 AELA 也是。只要客户总人数不降，就不受部分岗位被替代的影响。

竞争的本质

战场发生了什么谁占优
自上而下 vs 自下而上NOW、CRM、WDAY 靠大客户销售团队卖给 CIO / CFO，签多年大合同；TEAM、Monday、Notion 靠团队自己注册、刷卡、口碑扩散，再往上卖给 IT 部门大企业核心流程是自上而下的天下；团队协作工具是自下而上的天下。TEAM 正在两边都做：JSM 打 NOW，同时加强大客户销售
平台 vs 单品平台型 (NOW、CRM) 把同一套数据和流程复制到更多部门；单品 (Zendesk、Freshworks) 在一个市场里做到最好、最便宜大企业倾向平台 (少一个供应商、数据打通)；中小企业倾向单品 (便宜、上手快)
谁拥有记录agent 要读写工单、客户、员工的权威记录才能干活。拥有记录的平台可以在自己的数据上卖 agent，独立 agent 公司要通过接口调用记录拥有者占优，但前提是接口不能被完全商品化 (MCP 让外部 agent 更容易调用任何系统)
微软的捆绑Teams、SharePoint、Planner、Dynamics、Copilot、GitHub 都捆在 M365 和 Azure 里，"已经付过钱了"在"够用就行"的格子 (工作管理、知识库) 里威胁最大；在大企业的复杂流程 (ITSM、CRM) 里威胁较小
AI 原生的新进入者Sierra、Decagon 等直接卖"自动解决客服问题"，按解决的工单收费；Linear、Notion 在 AI 时代重写协作工具在客服这个格子里最激烈；它们没有历史包袱，但也没有记录层

和前两个行业对比：可观测性和数据平台是"按量收费"，AI 带来的量越多收得越多，担心的是单价被压；工作流软件是"按人收费"，AI 替代的人越多收得越少，担心的是量 (席位) 本身。所以 AI 对这三个行业的方向是不一样的：前两个是"量涨、单价跌"，工作流是"人少、单价要涨"。

AI 对席位的影响

方向发生了什么对行业
1. agent 替代处理事情的人L1 IT 工单、简单客服问题、销售线索初筛被 agent 自动处理。ServiceNow 自己用 agent 处理 90% 的内部 IT 请求、IT 人数持平；客户 Robinhood 70% 的员工请求在人介入前就被分流，每月省下 2,200 小时人工席位减项。客服和 IT 服务台最先被冲击；研发协作 (Jira) 相对慢
2. agent 让每件事更值钱同样一张工单，平台可以收"agent 处理费"；高级版本附带 AI，续约提价 20–30%单价加项。但目前大部分 AI 收入是捆绑在版本里的，独立按量收费的部分还小 (NOW 的 AI 年合同额超 $10 亿，多数是捆绑预付)
3. agent 的工作量远超人Atlassian 的 MCP 调用量增长 400%，同期人的使用量持平；Salesforce 的 agent 工作单元 (AWU) 一个季度 32 亿次新的计量单位，但能否收到钱取决于定价设计 (TEAM 从 2026 年 12 月起对 credit 设上限)
4. 界面不再重要员工在 Slack、Teams 或 Claude 里提问，agent 在后台调用 ServiceNow / Jira 完成，员工不再打开这些应用对"界面型"产品是减项，对"记录型"平台影响较小
5. AI 让自建变容易中小企业可以用 AI 很快搭出简单的工单或项目管理工具对低端、简单的产品是减项 (工作管理格子)

到目前为止的证据：各家的 AI 收入数字都在快速增长 (Agentforce ARR $15 亿+、NOW AI 年合同额 $10 亿+)，但相对于总收入还小，而且多数是捆绑或预付，还看不到真正按量消费的拐点。另一边，席位减少也还没有在财报里大规模出现。NOW 和 TEAM 2026 年的加速，我们的研究认为主要来自提价、版本升级、强制上云和并购，而不是 AI。所以这个 sector 现在的状态是："AI 威胁"已经反映在估值里，"AI 收益"还没反映在收入里，两边都还没被证明。

我们目前的看法：这是软件里最大、现金流最好、但 AI 争议最大的 sector。最好的位置是拥有"记录层"并且能改计费方式的平台 (NOW、CRM、WDAY)；最危险的是靠界面和人头、产品容易被复制的格子 (工作管理、简单客服)。估值上，CRM 和 WDAY 已经很便宜 (扣 SBC 后 FCF 收益率 3–6%)，NOW 和 TEAM 仍然要求证明增长是可持续的。详见 NOW 完整研究、TEAM 席位 thesis、CRM 完整研究。
