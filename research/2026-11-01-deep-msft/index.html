结论

一句话：MSFT 是全世界企业的"办公室 + 机房"：4.9 亿企业员工每人每月付 $39-99 用 Office、Teams 和安全套件 (按人头)，企业和 AI 实验室在 Azure 上按用量租算力。现价 $523 (10-30 收盘) 隐含未来 5 年收入每年 ~14% (口径 B)，正好等于我们的基本情景 (~14%)，基本情景 5 年年化回报 ~10% (加上 ~0.7% 股息)。结论：不买，放观察；买点 $420-480 (较现价低 ~8-20%)。

分型：混合型，主引擎是 A 类 (用量)。Azure 按用量收费，占收入 ~38% (FY27E)，却贡献了 FY27E 总增速 20% 里的 ~15pt；M365 是 B 类，靠新产品带动每人提价 (E3 $39 → E5 $60 → E7 $99 + Copilot 用量)，贡献 ~5.6pt；其余业务 (授权、Windows、Xbox) 合计在拖后腿。

为什么增长是真的：FY27Q1 Azure +48% (买方 bar ~47%、Street 44.9%)，下季指引 49-50%，管理层说"需求仍大于供给"；Foundry (企业建 agent 的平台) 收入 3 倍；M365 商业云同口径 +19%，Copilot 收入增速环比加速；商业 RPO (已签未确认的合同) $677B，+73%。

为什么还不买：(1) 现金没跟上利润。营业利润率 50% 是历史最高，但 capex (含融资租赁) 占收入从 31% 涨到 49%，过去 4 个季度 FCF 只有 $60B (收益率 ~1.5%)。现价要成立，FY32 年 capex 要回落到收入的 ~22% (AI 之前 ~15%)；如果停在 28%，每股只值 ~$410 (见 6.2)。(2) 最大客户是 AI 实验室。OpenAI 一家占本季收入 ~11% (电话会上 Goldman 分析师引用，管理层没有反驳)，而且 OpenAI 已经在 ORCL、AMZN、GOOGL 上同时买算力。(3) M365 的人头在放慢。付费商业坐席 +5% (上季 +6%)，E3 和单品"销售执行偏弱"；员工桌面上的 ChatGPT、Claude 是 Copilot 真正的对手。

和其他几份 Deep 对照：NOW 是"人头被 AI 压缩、靠提价补"；SNOW、DDOG 是"agent 把用量放大"；MSFT 两样都有，而且是这两种趋势的主要受益者之一 (agent 不管在哪家的界面里跑，Azure 和 Entra 都有一份)。它的问题不在需求，在价格：好消息已经在 25.8x 的 FY27E P/E 和 ~1.5% 的 FCF 收益率里了。

它怎么收钱 (一句话)：FY26 收入 $332B 里，~35% 是按坐席订阅 (每个员工每月一份 M365、Dynamics 或 LinkedIn 招聘账号，大多是 3 年合同、每年预付)，~32% 是按用量 (Azure：跑多少 GPU、CPU、存储和 token 收多少，大企业先签 3 年"承诺消费额"再按月扣)，~17% 是一次性授权 (服务器、Office 买断、Windows 预装)，其余是广告、游戏和服务。FY27E 用量会第一次超过坐席 (~40% vs ~34%)。详见 1.3。

这只股票在测试什么

一句话：MSFT 在测试的是，每年 $170B+ 的 capex 能不能变成同样快的 Azure 收入，并在 5 年后回到 ~28% 的 FCF Margin；同时 AI 是让 M365 的 4.9 亿个坐席"每人多付钱"，还是让坐席变少。

前半句是 A 类问题 (用量和 capex 回报)，后半句是 B 类问题 (提价 vs 人头)。前半句更重要：Azure 贡献了 ~3/4 的增量收入，capex 强度是估值里最敏感的变量。

1. 产品：它是什么、怎么收费、凭什么赢

1.1 一句话 + 一个例子

一句话：MSFT 卖两样东西：员工每天用的办公软件 (Office、Teams、Outlook、Windows，加上安全和身份管理) 和租给企业的机房 (Azure：GPU、CPU、存储、数据库和 AI 模型)。前者按人头收月费，后者按用量收钱。

一个例子：一家 2 万人的银行。每个员工早上打开的电脑 (Windows)、邮箱 (Outlook)、开会 (Teams)、写文件 (Word) 都是 MSFT 的，每人每月 $60 (E5)；员工登录用的身份、谁能看哪份文件、离职时一键收回权限，也是 MSFT 的 (Entra)。银行的网银后台、风控模型、数据仓库跑在 Azure 上，按用量每月扣钱。今年银行开始让 agent 自动处理信用卡争议，这个 agent 用 OpenAI 的模型、跑在 Azure 上、权限登记在 Agent 365 里，每处理一单 MSFT 都收一份钱。

1.2 行业背景：客户为什么需要它

企业 IT 有两类刚需。第一类是"让员工能干活"：邮件、文档、开会、身份和安全。这件事没有差异化，CIO 要的是"一家搞定、出了问题有人负责、合规能过审计"，所以 MSFT 靠 Office 的历史地位和一张企业协议 (EA) 把全家桶卖进了几乎所有大企业。第二类是"让业务系统跑起来"：以前买服务器放在自己机房，现在租云。AWS 先做起来，Azure 靠"企业本来就用 Windows Server、SQL Server、Active Directory，搬到 Azure 最顺"追上来。

AI 把这两类需求连在了一起：agent 要读员工的邮件和文件 (第一类的数据)，要跑在算力上 (第二类)，还要被管住 (身份和权限)。这正是 MSFT 想讲的故事："Copilot 是新的工作操作系统"，下面是同一套 Azure 基础设施。

3. 收费单位：(1) 坐席 = 一个有名有姓的员工账号，按月计，买 E5 就是 E5 的坐席，Copilot 另算一个 "$30 服务计划"；(2) Azure 用量 = vCPU 小时、GPU 小时、GB 月、百万 token、API 调用次数；(3) credit = Copilot 和 GitHub 的用量点数，agent 干一件事扣多少点；(4) 授权 = 每台电脑、每个服务器核心一次性付费。容易混的两个词全文统一："Copilot 坐席"指给员工的 $30 月费账号；"agent"指自动干活的程序，按 credit 或 token 收钱。

5. 承诺 vs 超额：Azure 的大客户先签 3 年的承诺消费额 (MACC)，拿到折扣，再按实际用量每月扣；用超了按标价补，用不完通常也要付。AI 实验室签的是多年的算力合同 (OpenAI 2025-10 追加了 $2,500 亿 Azure 承诺，Anthropic $300 亿)。这些都进 RPO：商业 RPO $677B (+73%)，加权平均期限 2.3 年，~30% 在未来 12 个月确认 (+29%)，12 个月以后的部分 +98%。M365 主要是 3 年 EA，每年预付，续约集中在每年 4-6 月 (MSFT 的 Q4)，所以 E5 → E7 的升级也集中在 Q4。含义：(1) bookings 波动极大 (本季 -12%，因为去年有 OpenAI 的大单)，不能当增长指标；(2) Azure 的季度增速主要取决于 GPU 能不能按时到位，而不是需求。

6. thesis 押在哪种收费方式上：押在用量上 (Azure 贡献 FY27E ~15pt)；坐席这条腿靠提价而不是人头 (坐席 +5%、ARPU +~13%)；一次性授权和 Windows 在拖后腿。所以结论里的杠杆表以 Azure 为主、M365 提价为辅。

提价是一次性的还是能持续？两部分。E5 → E7 和 Copilot 坐席是一次性的台阶：E5 约 1.3 亿坐席 (专家)，多数是 3 年合同、集中在每年 Q4 续约，2026 年 Q4 开始换档，大约要到 FY29 年中 (2029 年 6 月) 才能把存量走完一轮；每年贡献总收入增速 ~3pt (FY27E 3.3pt，和图 bridge 对上)。按专家的目标 (FY27 末 Copilot 1 亿坐席、E7 2,500 万)，Copilot 年收入从 ~$140 亿涨到 ~$300 亿，渗透率从 ~8% 到 ~20%。能持续的是用量：GitHub 和 Copilot credits 按 agent 干的活收钱，没有上限，但现在只有每月 ~$1.2 亿 (年化 ~$14 亿，占 M365 商业云 ~1.5%)。所以 M365 的增速在 FY27-28 会靠换档维持在 ~18-19%，FY29 以后能不能守住，看用量能不能接上。

1.4 AI 让它受益还是受损

方向机制证据我们的判断
核心一行：收费单位变多还是变少Azure 的收费单位 (GPU 小时、token、CPU 小时) 被 agent 放大；M365 的收费单位 (员工人头) 可能被 agent 压缩。MSFT 用"坐席 + 用量"(credit、GitHub 用量计费) 来接住人头的下降Azure +48%；M365 付费坐席增速 6% → 5%；按用量消费 credit 的客户环比 +75%净受益：Azure 的放大 (每年 +$40-50B) 远大于人头压缩的风险 (每少 1% 坐席 ≈ -$1B)
受益：算力所有 agent 都要跑在 GPU 和 CPU 上；MSFT 是全球第二大云需求 > 供给；Foundry 3 倍；CPU 也在被 agent 拉动强受益，但受产能限制
受益：治理agent 越多越需要登记、限权、审计；企业不会让 agent 绕过 EntraAgent 365 登记 5,000 万 agent；Purview 审计 76 亿次 (环比 5 倍)；MXC 让 Claude Code、Codex 在 Windows 里受控运行受益，且是 MSFT 独有的位置
受损：员工入口员工直接打开 ChatGPT、Claude，把结果贴进 Word；Copilot 变成"有也行"前员工："人们在旁边用 ChatGPT 甚至 DeepSeek，再复制粘贴进 Word" (Third Bridge 10-16)；"Claude 是科技公司默认的工作操作系统" (Third Bridge 10-13 客户提问)真实风险，但目前没有反映在续约里 (94-95%)
受损：人头客户用 agent 替代客服、初级分析师 → M365 坐席变少MSFT 自己也在做自愿离职计划；E3 销售偏弱慢变量，5 年维度要盯
受损：AI 实验室的议价OpenAI、Anthropic 规模大到可以多云比价甚至自建OpenAI 同时用 ORCL、AMZN、GOOGL；OpenAI 占 MSFT 收入 ~11%集中度风险，见 2.2

1.5 核心竞争力：分发和身份，不是模型

先说它在哪儿不是最强。模型和员工体验上，ChatGPT 和 Claude 更好：一位前微软数字化转型高管说自己"很久没用 Copilot 了"，员工"在旁边用 ChatGPT，再复制粘贴进 Word" (Third Bridge 10-16)；算力规模上 AWS 比 Azure 大 ~40%；TPU 让 GCP 在成本上有自己的牌。

为什么只有它能做"六层全栈"：一张企业协议 (EA) 买全家桶，CIO 不用比 6 家供应商；身份 (Entra，前身 Active Directory) 管着几乎所有大企业"谁是谁、谁能看什么"；Work IQ 是员工邮件、会议、文档、组织关系的图谱，只有 MSFT 有。对手要么只有一两层 (OpenAI、Anthropic 有模型和界面，没有身份和数据)，要么企业应用里没有入口 (AWS)。

用数字证明集成在发生：Foundry 客户 12 万 (收入 3 倍)，Fabric 付费客户 4.4 万 (+50%)，同时用 Foundry 和 Fabric 的 1.9 万；用 Microsoft IQ 拿上下文的客户 ~6 万 (环比 +25%)；用 PostgreSQL 的客户里也用 Foundry 的增速 90%。这些都是 FY27Q1 电话会披露。

对手卡在哪里：AWS 技术和规模都强，但没有员工每天打开的应用，也没有身份目录，企业 agent 要接 M365 的数据还得过 MSFT 的权限；OpenAI、Anthropic 体验好，但企业部署时要接 Entra、要过 Purview 审计、要进 EA 采购流程。所以 MSFT 的护城河不在"做出更好的 AI"，而在"不管谁的 AI，都要从它这里过"。

核对分型的说法：协调线程把 M365 定为 B 类、Azure 为 A 类，这和数据一致；补充一点：MSFT 的"A 类"里有一大块是 AI 实验室的 GPU 租赁，它的粘性和毛利都比企业 Azure 低 (Nadella 本季自己说"几家大买家撑几个季度的增长，在我看来不算生意")，所以 A 类引擎的质量要分开看。
