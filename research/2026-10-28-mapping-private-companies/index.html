一页结论

一句话：有，而且不少，但最符合框架的不是"AI 应用"，而是 agent 每多跑一步就多付一份钱的底座：Modal (agent 执行代码的沙箱，按秒收费)、Temporal (agent 长流程的每一步)、Supabase 和 Vercel (agent 做出来的应用的数据库和部署)、Cribl (日志和监控数据的分流)、Databricks，再加上身份层的 Saviynt。它们同时满足三条：计费单位随 agent 增长、自己拥有被计量的东西、暂时不容易被模型厂商捆绑。

第一个发现：符合框架的私有公司已经很贵，但有几家相对便宜。底座公司普遍 16-60 倍 ARR (Temporal 50 倍、Supabase 约 60 倍、VAST 60 倍、Cyera 80 倍)。按契合度看相对便宜的是：Modal 约 16 倍 (run-rate 5 个月涨约 3 倍)、Grafana 约 15 倍、Vanta 约 14 倍、Saviynt 约 10 倍、Cribl 按 2024 年老估值约 9 倍。和上市公司一样，市场已经把"谁受益"定了价，预期差只能从受益的程度和速度里找。

第二个发现：框架说最该值钱的两层 (身份权限、观测评测)，在一级市场几乎被买光了。一年内 PANW 买了 CyberArk、Chronosphere、Koi、Protect AI；ServiceNow 买 Veza，CrowdStrike 买 SGNL，Cisco 买 Astrix 和 Galileo，Snowflake 买 Natoma，SailPoint 买 Entro，Dynatrace 买 Arize，OpenAI 买 Promptfoo 和 Statsig。巨头把这些当成"功能"买进平台。这对上市公司是好消息 (PANW、DT、CRWD、NOW 用并购补齐 agent 时代的能力)，对想在一级市场找独立赢家的人是坏消息：这一层剩下能独立做大的不多，Saviynt 是少数。

第三个发现：Coding 收入最大，但应用层不拥有被计量的东西。Cursor run-rate 约 $30 亿，截至 2026 年 1 月的季度毛利却是 -23% (用户越用 Claude Opus，它付给 Anthropic 越多)，最后以全股票约 $600 亿卖给 SpaceX，理由之一是缺算力。Claude Code 2026 年 2 月 run-rate 已约 $25 亿，用补贴价格正面竞争；KB 里的保险客户说 Claude Code 有 Factory 80-90% 的功能、便宜 10-15%。Coding 层里更符合框架的是拥有运行环境的 (Vercel、Supabase、Replit 的托管) 和做验证的 (CodeRabbit)。

第四个发现：部署层 (FDE) 有按结果收费的样本，但模型厂商正在亲自下场。Sierra 按"成功解决一次"收费，Distyl 按创造价值的 7-10% 收费、只接能创造 $1 亿价值的项目，都是框架里 PLTR 那一层的私有版本。但 OpenAI 2026 年 5 月成立 Deployment Company (超过 $40 亿支持，收购约 150 名 FDE 的 Tomoro)，Anthropic 和 Blackstone、H&F、高盛成立 $15 亿的服务合资公司。

第五个发现：算力和推理层增长最快，"量涨价跌"也最剧烈。Fireworks 年化收入 >$10 亿、Modal >$10 亿、Together bookings >$11.5 亿、Baseten 约 $6 亿 (估计)。Baseten 前员工说推理量一年涨 40 倍、收入只涨 20 倍；推理商之间价差 10-20%，量产时大企业常回到 Bedrock。这一层最受益，也最像在卖被商品化的原料。

怎么用：(1) 这些私有公司是上市公司的定价锚 (趋势 5)：Grafana、Cribl、ClickHouse 压 DDOG 的单价，Supabase/Neon 压 MDB，Sierra/Decagon 压 CRM 的 Service Cloud 席位。(2) 能投的窗口：Nscale 已递交 S-1，Lambda 在做上市前融资，Vercel 说已具备 IPO 条件，Deel 在准备上市，Databricks 说 2026 年不上市。(3) 跟踪：Modal、Temporal、Supabase 的下一次 ARR，Saviynt 和 Cribl 的新估值，以及 OpenAI/Anthropic 的服务公司拿走多少部署层的单子。

怎么筛

每家公司过五个测试，都来自我们之前的框架和 winners pattern：

  1. 计费单位随 agent 增长吗？按用量 (token、算力秒数、工作流步骤、数据量、交易额) 收费的，agent 越多收得越多；按席位、按员工收费的，agent 替代人时反而缩小。表里记作 ↑ / ~ / ↓。
  2. 它拥有被计量的东西吗？Cursor 的用量很大，但被计量的 token 在 Anthropic 手里；Supabase 拥有数据库本身，Vercel 拥有部署和流量。
  3. 量涨价跌的压力有多大？推理、向量搜索、日志存储的单价跌得快；工作流步骤、身份数、交易手续费跌得慢。
  4. 会不会被捆绑？云厂商 (Bedrock、Azure Foundry、Vertex)、模型厂商 (Claude Code、Codex、ChatGPT 企业版) 或者大平台 (PANW、微软 Entra、GitHub) 能不能把它做成免费功能。最近一年的收购本身就是证据。
  5. 客户集中吗？很多 AI infra 公司的大客户就是 OpenAI、Anthropic 或几家 AI 原生公司，一家客户自建就会掉一大块 (OpenAI 先后把日志、指标从 Datadog 搬走就是例子)。

综合成四档：A 高契合：五项基本都过；B 部分契合：方向对，有一两项明显风险；C 方向对但有硬伤 (按席位收费、规模太小、客户太集中)；D 不契合或反例。这是定性判断，不是打分模型。

分层判断

算力与推理

框架里价值流向的第一站：每个 token、每次 agent 调用都要烧算力。按 GPU 小时或 token 收费，用量随 agent 涨，但单价跌得最快。

判断：最受益，也最像卖原料。这一层的四家推理商 (Fireworks、Modal、Together、Baseten) 2026 年都跨过或接近 $10 亿 run-rate，是一级市场里收入增长最快的一组。但它们卖的东西正在被商品化：同一个开源模型在各家价差只有 10-20%，前沿模型厂商也只能在托管成本上加 10-30% (T-Mobile 的专家)。按框架，真正稀缺的是电和机房 (Crusoe、Nscale)，但那一层的客户高度集中在 OpenAI、微软和 Anthropic。

Modal 是这一层里最特别的一家：它的增长有一块直接来自 agent 本身 (沙箱 $3 亿 run-rate)，不只是"替别人跑模型"，所以给 A。

数据与运行底座

agent 每一步都要读写数据、跑代码、记状态。按用量收费的数据库、工作流引擎、沙箱、数据管道，计费单位直接随 agent 次数长。

判断：这是框架最干净的一层。agent 每一步都会读写数据库、跑一段代码、记一次状态、吐一堆日志。按用量收费的底座公司，计费单位直接跟着 agent 的步数涨，而且被计量的东西 (数据库、工作流、数据管道) 在它们手里。Supabase 超过 60% 的新库是 AI 工具建的；Temporal 年化收入增长超过 200%；Cribl 受益于"大客户把不关键的数据搬去便宜的地方"。

反例同样清楚：Pinecone (向量搜索变成所有数据库的标配功能)、Fivetran + dbt (合并后收入基本不长，搬数据这一步被平台吸收)。区别在于：被计量的东西是不是只能在你这里跑。

身份与权限

每个 agent 都要回答"以谁的名义、被允许做什么"。绕不开，但目前多数按身份数或席位收费，而且一级市场的标的大多已被巨头买走。

判断：最绕不开，但一级市场里几乎没剩下。我们的"agent 最大公约数"结论是：每个 agent 都要回答"以谁的名义、被允许做什么"。这一层一年内被买走了 CyberArk ($250 亿)、Veza、SGNL、Astrix、Entro、Natoma。剩下有规模的独立公司主要是 Saviynt (>$3 亿 ARR，约 10 倍)，其余都在早期 (Oasis、Keycard、Aembit)。

KB 里的身份专家给出另一个提醒：非人身份 (agent 身份) 是需求增量，但已经重度用 Okta 或微软 Entra 的客户，可能直接在身份提供商里把治理整合掉。

AI 与数据安全

AI 写的代码更多、agent 碰的数据更多，要保护的东西变多；但模型厂商和安全平台都在把这一层做成功能。

判断：需求真实，但最容易被做成功能。AI 让需要保护的东西变多 (Aikido 的前高管说 AI 编程让软件产品数量 12 个月翻倍)，但这一层同时面对两股捆绑：安全平台 (PANW、CRWD、Zscaler) 一年内买了 Protect AI、Koi、Lakera、Prompt Security 等，模型厂商开始卖自己的安全模型。按数据量收费的 Cyera、按公司收费的 Vanta 相对稳；按开发者席位收费的 Snyk 是反例。

观测·评测·验证

执行变便宜，验证变值钱：看 agent 做了什么 (观测)、做得对不对 (评测、代码审查)、以及雇真人专家去验收 (专家数据)。

判断："验证变值钱"在一级市场有三种形态，钱只流向其中两种。(1) 监控 agent 做了什么 (Grafana、Braintrust、Arize)：按用量收费，但同类公司一年被买走五家；(2) 检查 agent 做得对不对 (CodeRabbit 等代码审查)：瓶颈确实在这里，但仍按席位收费，GitHub 和 Cursor 在做内置；(3) 请真人专家验收 (Mercor、Surge、Handshake、Scale)：字面意义的"验证"，收入涨得很快，但客户是几家模型厂商，毛利约 30%。

Coding

第一个进 P&L 的场景，收入最大的一层；但应用层不拥有被计量的东西 (token 在模型厂商手里)，和 Claude Code / Codex 正面竞争。

判断：收入最大、最先进 P&L，但应用层不拥有计量表。Coding 是我们框架里证据最强的一条，钱确实在流：Cursor 约 $30 亿、Claude Code 约 $25 亿 (2 月)、Cognition 约 $9 亿、Lovable >$6 亿、Replit 约 $5 亿。问题是这些应用的成本就是模型厂商的收入：模型厂商可以用补贴价格直接竞争。KB 里的穆迪前 SVP 说 Claude Code 是"要打败的那个"，大企业正在把编码工具合并到一两家。

符合框架的是两头：拥有运行环境的 (Vercel 约 30% 的应用由 agent 部署；Replit 的托管；底层的 Supabase) 和做验证的 (代码审查、测试)。

部署层与结果定价

把 agent 放进真实流程的人 (FDE)，以及按结果收费的 agent 应用。框架里 PLTR 那一层；模型厂商正在亲自下场。

判断：PLTR 式的部署层有私有样本，但会和模型厂商的服务公司正面竞争。两种打法：Sierra、Distyl 按结果收费、派工程师驻场 (服务重、价格高)；Decagon、PolyAI 把配置推给客户 (毛利高、服务轻)。T-Mobile 的专家认为"平台 + FDE"的公司会是赢家，因为模型越来越像，价值和 IP 流向定制落地；但 Distyl 自己的前高管也承认，OpenAI 自建服务公司后，大客户可能更信任 OpenAI 或 Palantir。

按席位收费的横向 AI 工具 (Glean、Writer、Hebbia) 是这一层的反例：客户和 OpenAI/Anthropic 并用，流失的多半去自建。

新的系统记录 (SoR)

记账、发薪、花钱这类"权威记录"。按交易额收费的受益于 agent 花钱，按员工数收费的会被 agent 压缩。

判断：看按什么收费。Ramp 按花出去的钱收手续费，agent 替公司采购越多、交易额越大；Deel、Rippling 按员工收费，agent 压缩招聘时计费单位缩小。两类都是"权威记录"，但对 agent 的弹性方向相反。

契合度 vs 估值

横轴是契合度，纵轴是估值 / 最新 ARR (对数刻度)。只放了能算倍数的公司。

读法：A 档里倍数从约 9 倍 (Cribl，老估值) 到约 60 倍 (Supabase)，和契合度关系不大，主要看增长速度和最近一轮的时间。左下角 (高契合、低倍数) 是 Cribl、Saviynt、Grafana、Modal；它们共同的问题是估值数据较旧或来自报道，需要看下一轮定价。D 档的 Snyk 只有约 12 倍，是按席位收费、增长 11% 的结果。

比较口径：私有公司用最近一轮投后估值 (或报道的洽谈估值) 除以最近的 ARR / run-rate，和上市公司的 EV/NTM 收入不可直接比较：私有公司的估值是优先股价格，二级市场常有折价 (例：Glean 二级比 F 轮低约 20%)。
