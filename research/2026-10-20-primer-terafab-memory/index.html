SPCX 按 SpaceX 理解 (2026.06.12 在 Nasdaq 上市，代码 SPCX)。它和 Tesla 合搞的 Terafab 是一个"逻辑芯片 + 存储 + 封装测试"一体的自用晶圆厂，Intel 是技术伙伴。存储这一块今天只有一个 DRAM 工艺整合岗位的招聘，没有产线、没有工艺、没有合作方。

Musk 做存储在 2030 年前不会成为供给侧变量：Terafab 的正式厂 2026.12 才开工、2028 年底才盖完，存储部分连合作方都没有，SpaceX 自己的招股书都写着 IP、资本承诺和 Intel/Tesla 是否留下"都没定"。

你列的三道门里，钱最不卡 (IPO 募了 $75B)，专利其次 (CXMT 当年花约 €30M 就拿到了 7,000 件 Qimonda 专利的授权)。真正卡的是工艺手艺和时间：CXMT 有专利、有人、有国家兜底，从成立到第一颗 DDR4 用了 3.5 年，到第一次全年盈利用了 9 年，今天工艺仍落后约 3 代。

对我们的 memory thesis，2026–29 年 Musk 是加项不是减项：他在锁 Micron 长约、给设备商下单，自己一颗都造不出来。2030 年后的尾部风险，只在"三星 / 海力士 / 美光之一替他在 Terafab 里运营产线"这一种情况下才成立，到那时这其实是原厂的产能，只是换了出资人。

1. 是什么

一句话：Terafab 是 SpaceX 和 Tesla 合建的自用晶圆厂，想在一处同时做 AI 逻辑芯片、存储芯片和封装测试，给 Tesla 的车和机器人、SpaceX 的太空数据中心供货。

先讲存储是怎么造出来的，因为后面所有判断都从这里来：

  • DRAM 每一位数据存在一个极小的电容里，电容旁边一个晶体管当开关。一颗 16Gb 的 DRAM 里有 160 多亿个这样的电容，每个都要在一样的位置、一样的形状、漏电一样少，否则这一位就坏了
  • 做法是在硅片上反复沉积、光刻、刻蚀几百到上千步。设备可以买，但每一步的参数 (温度、气体配比、时间) 怎么配、哪一步出问题会在第 600 步才暴露，这些是靠几十年"做坏了再改"攒出来的
  • HBM 是把 8–16 颗 DRAM 叠起来打孔连通，再贴在 GPU 旁边。每多叠一层，整叠的良率就再乘一次单层良率，所以对单颗良率要求更高

贯穿全篇用一个比喻：造存储像开一家要做出米其林水准的餐馆。钱是买地盖厨房，设备是灶台和锅，专利是菜谱 (公开登记、可以买、可以授权)，真正难的是老师傅的手艺：同一份菜谱，新厨房做出来十盘坏九盘。存储这一行的"手艺"就是良率曲线。

2. 机制：要过的五道门，谁卡在哪

造出能卖的存储，是五道门串联，最难过的那道说了算。你提的 capital、time、IP 是其中三道，但它们的难度差很多：

门比喻谁定义这道门Musk 现在的位置难度
1 钱买地盖厨房资本市场IPO 募 $75B，市值约 $2T；UBS 预计 SpaceX 五年 capex $1T、其中约 20% 给 Terafab不卡
2 设备灶台和锅ASML / AMAT / LRCX / TEL / KLAC 的交期和排队能买，美国企业不受出口管制；但 EUV 等关键设备要提前 1 年以上排队，原厂扩产也在抢卡一段时间
3 专利菜谱三大原厂 + 授权公司 (Polaris、Rambus、Netlist 等)DRAM 全球约 7,500 个有效专利族，海力士 / 三星 / 美光合计近一半。可以买授权，也可以买废弃公司的专利包花钱能过
4 手艺 (良率)老师傅只在三大原厂和 CXMT 的工程师脑子里零。没有工艺来源，没有成建制的团队最卡
5 经济性开了店有没有客人存储价格周期只给自己用，没法在下行期把产能卖给别人；而 2030 年前后投产时，多数人预计供需已经平衡很卡

为什么专利不是最硬的那道门。专利是公开登记的，本身就是拿来授权换钱的。CXMT 的底子是 2009 年破产的 Qimonda：WiLAN 旗下的 Polaris 在 2015 年花约 €30M 从 Infineon 买下约 7,000 件 Qimonda 专利，2019 年和 CXMT 签了 DRAM 专利授权。对一家美国公司来说，从 Micron 或授权公司那里买一张授权，比 CXMT 当年容易得多。

专利真正咬人的时候，是你已经做大、且对方能把你和"偷手艺"挂钩。福建晋华的例子：2016 年成立，投了约 $6B，2018 年离量产只差几个月时，美国以涉嫌窃取 Micron 商业秘密为由把它列入实体清单，设备买不到，工厂就停了。刑事案 2024 年判无罪，Micron 和晋华 2023 年和解，但工厂已经没了。所以真正的风险是"挖人带来的商业秘密官司"，不是专利墙本身。这对 Musk 是现实的约束：他最快的路是挖三星 / 海力士 / 美光的工艺团队，而这正是最容易惹官司的路，韩国对存储技术外流管得很严，2023 年就有前三星员工因涉嫌向中方泄露 DRAM 技术被捕。

为什么手艺最难。手艺不在专利里，也不在设备说明书里。看两个参照：

  • 老玩家在老地方加一座新楼 (海力士 M15X)：从董事会批准到量产 1.6 年。因为工艺、人、供应链全是现成的，只是换个厨房
  • 老玩家在新地方建厂 (Micron Idaho)：约 4.8 年才出第一片晶圆，而且 Micron 是有 40 多年历史的 DRAM 厂
  • 新玩家带着买来的专利和挖来的人 (CXMT)：3.5 年出第一颗产品，9 年才第一次全年盈利，2026 年主力工艺仍是 1z 级，比领先者的 1c 落后约 3 代；HBM3 8 层整体良率被估在 25% 左右

一句话：钱和专利 Musk 都买得到，买不到的是良率曲线。CXMT 有国家兜底、有 Qimonda 遗产、有挖来的工程师，用了 9 年才赚钱，今天还落后 3 代。

4. 一句话规则：看谁运营产线

判断 Terafab 存储算不算新增供给，只看一件事：存储产线由谁运营。

  • Musk 自己的团队运营：按 CXMT 的节奏，2031 年前不算有效供给，2033 年前不算有竞争力的供给
  • 三星 / 海力士 / 美光之一运营：可以算供给，最早 2029–30 年，但这是原厂的产能和原厂的手艺，只是厂房和钱来自 Musk。对行业来说等于原厂多扩了一座厂，纪律仍在原厂手里
  • 没人运营，只做研发和新型存储 (MRAM / RRAM)：不算 DRAM / HBM 供给，影响为零

这条规则和 TSMC 的态度是同一个逻辑。2026.10.15 魏哲家在 Q3 电话会上说可以和 Terafab 合作，但厂必须由 TSMC 来运营；Musk 前一周说 TSMC 最多只能租产能，厂要自己建、自己运营。逻辑这边谈不拢的点，到了存储一样会出现，而且存储原厂比 TSMC 更不愿意把手艺交出去。

一句话：钱谁出不重要，产线谁运营才重要。Musk 坚持自己运营，就等于选了最慢的那条路。

5. 他到底需要多少存储

Musk 的论点是"外面的厂不够我用，所以必须自己造"。先按他自己的目标算一下需要多少 HBM、相当于多少 DRAM 晶圆、要多少钱。

月需晶圆 = 每年新增算力 (GW) × 每 GW 的 HBM (PB) ÷ 每片晶圆产出的 HBM (TB) ÷ 12
建厂资本开支 = 月需晶圆 ÷ 10,000 × 每 1 万片月产能的建厂成本
  • 每 GW 的 HBM：GB300 NVL72 一柜约 135kW、72 颗 GPU × 288GB = 20.7TB，1 GW 约 7,400 柜 → 约 150PB。Rubin 一代每柜功率更高，约 110PB；Rubin Ultra 每颗 1TB，约 240PB
  • 每片晶圆的 HBM：一片 1β DDR5 晶圆约产 2.5TB 好的 DRAM，HBM 每 bit 吃约 3 倍晶圆 (die 更大、要打孔、叠层有损耗)，约 0.8TB / 片
  • 建厂成本：海力士 M15X 投 20 万亿韩元 (约 $14.6B) 建约 10 万片 / 月，约 $1.5B / 万片，这是韩国、老厂区、现成团队的价格。美国新厂区按 1.5–1.7 倍算，约 $2.5B / 万片 (我们的估计)
  • 全球 DRAM 晶圆产能：2026 年底约 205 万片 / 月 (三星 72 万、海力士 60 万、美光 39 万、CXMT 35 万，SemiAnalysis 估计)

  • 按 10 GW / 年 (SpaceXAI 自己的数据中心节奏)，要约 16 万片 / 月，大约等于一个半海力士 M15X，建厂约 $400 亿。这个量他确实很难只靠买，所以他着急是真的
  • 但同样的 $16.8B 一期，即便全给存储、良率追平原厂，也只够约 4 GW 的 HBM。按新厂真实良率 (0.4TB / 片) 只够 2 GW
  • 按 1 TW，要约 1,600 万片 / 月，是全球 DRAM 产能的 8 倍。这不是"自建能不能做到"的问题，是"这个目标本身不成立"

一句话：Musk 缺存储是真的 (10 GW 就要约 16 万片 / 月)，但 Terafab 一期全给存储也只够 2–4 GW，自建解决不了他的问题，只能买。

招聘描述里写了 MRAM、RRAM 和 3D DRAM，这说明团队在看"跳过平面 DRAM 直接做下一代"的路。理论上可以绕开今天最拥挤的专利区，实际上三大原厂在 3D DRAM 上同样领先，而且三星和海力士自己都还没量产，所以这条路目前没有任何产品数据支撑。

Semiecosystem 的建议很实在：别建存储业务，嵌入式存储 (MRAM / RRAM / 嵌入式闪存) 用授权，封装找有经验的伙伴合资。我们同意。

一句话：最可能的路径是"买"和"出钱让原厂造"，这两条路对原厂都是加项；"自己造 HBM"排在最后。

9. 最容易被误读的几点

大家以为实际
Musk 招了 DRAM 工程师，所以要做 DRAM 了招的是一个工艺整合岗位，描述里还包括 MRAM / RRAM。做一条 DRAM 线需要几千人的工艺和良率团队
Terafab 会把存储价格打下来2030 年前它一片都产不出来，反而是在抢设备、签长约，2026–29 年是需求方
专利是最大的壁垒专利能买。真正的门槛是良率手艺，以及"挖人带来的商业秘密官司"
SpaceX 有 $75B，钱不是问题，所以能做成钱确实不是问题，但钱买不到良率学习的时间。CXMT 也不缺钱
Intel 加入了，Terafab 就有技术了Intel 带来的是逻辑工艺 (14A)。Intel 1985 年就退出了 DRAM，存储帮不上
Musk 骂三星 / 海力士，说明他要甩开它们自己做他同时在夸 Micron 并签长约。这是选供应商，不是自己做

一句话：Terafab 存储在 2026–29 年对行业是需求，不是供给；把一个招聘岗位读成"进入存储"是最常见的错。

10. 对我们 memory thesis 的影响

时间段方向大小理由
2026–28加项小SpaceX / Tesla 是新的大买家 (10 GW 自用就要约 16 万片 / 月的 HBM 晶圆)，而且在用预付长约锁量
2029–30中性—Terafab 正式厂刚盖完，存储最多是试产；如果原厂代运营，算原厂扩产
2031+可能减项取决于运营方只有自己运营且做成，才是第五家供应商；按 CXMT 的路径，到那时也只是几个点的份额
原厂之间Micron 加，三星 / 海力士轻微减小Musk 公开表态把配额往 Micron 倾斜
Semicap加项中一期 $16.8B 大部分会变成设备订单，逻辑为主

Terminal value 会被压多少

对股价影响 = 做成的概率 × 中枢 EPS 降幅 × terminal value 占股价比例
  • Terminal value 占股价比例 ≈ 50%：假设 CY27–28 赚峰值 E、CY29 赚 0.7E、2030 起回到中枢 0.4E，折现率 12%。2026–29 年现值约 2.2E，2030 年以后约 2.1E，合计约 4.3E；MU 现在约 5.5x CY27e，所以价格里约一半押在 2030 年后
  • 中枢 EPS 降幅 ≈ 30%：自己运营并做成，规模约等于自用的 16 万片 / 月，约占 2033 年全球产能 (约 300 万片 / 月) 的 5%。自用不外卖，效果是原厂少一个大客户，相当于多出 5% 供给。commodity 下 5% 过剩可把中枢价格压 15–25%，加上经营杠杆，EPS 约 −30%
  • 做成的概率 ≈ 20%：自己运营、2033 年前做成
  • 代入：20% × 30% × 50% ≈ 股价 −3%。原厂看到 Terafab 起量会少扩产，实际影响更小。作为对照，CXMT 2027–28 年就到全球约 17% 产能，是这个尾部情景的 3 倍以上，而且已经在发生
  • 真正的渠道是估值倍数：bull case 如果是"存储周期性变弱、从 5x 重估到 10x+"，Terafab 是空头最好用的反驳，哪怕一片晶圆都没产出，也能压住重估
  • 更大的风险是示范效应：Musk 一旦做成，hyperscaler 可能跟进 (就像 TPU 之于 NVDA)。几家合计内部化 15–20% 需求，才是改变格局的情景。要盯的是第二个大买家开始招 DRAM 工艺团队，或者入股新厂

一句话：不改变"26–28e 持续短缺、ASP 维持高位"的主线。Terafab 存储在现金流上只值股价的约 −3%，真正的压力在估值倍数和示范效应，盯住第 4 节那一个问题和"第二个大买家"就够了。
