结论

一句话：不买，放观察名单，买点 $65-80 (现价 $124.15，2026-10-30 收盘)。Rubrik 的基本面是这轮软件里最扎实的之一：在一个每年只增 ~9% 的数据保护市场里，订阅 ARR 连续 30%+ 增长，靠的是从 Dell、Veritas、CVLT 手里抢份额，再向老客户加卖安全版本和身份恢复。但现价要求未来 5 年收入复合 ~32% (口径 B) 到 ~41% (口径 A)，我们的基本判断是 ~19%；同时 SBC 占收入 ~22%，比 FCF (19%) 还高，扣掉 SBC 的现金流约为 0。

增长分型：混合型，主引擎是 A 类的"量"，第二引擎是 B 类的"新产品带动提价"。主引擎 = 份额转移 (新客户 + 老客户把更多数据和系统交给它保护)，按 TB 和按用户收钱，跟着企业数据量走；第二引擎 = 老客户升级到 Enterprise 安全版本、加买身份恢复，CFO 说 NRR 里 >45% 来自安全产品 (见 1.3b)。Agent Cloud 是第三条曲线，今天几乎没有收入。

它怎么收钱 (取自 1.3)：~95% 是多年期订阅，按年付、按比例确认，没有"超额用量"。收费单位是"保护了多少东西"：机房和云上的数据按 TB 收 (占订阅 ARR ~70%)，M365 等 SaaS 按用户收 (~19%)，身份恢复按"活跃的人类身份"收 (~4%)；同样的 TB，Enterprise 版标价是基础版的 1.75 倍。一家 5,000 人医院的标价账单约 $1.0M / 年。

为什么不买：(1) 估值已经把"增速几乎不减"定价进去：EV / NTM 收入 13.1x，高于 SNOW、DDOG，增速却比它们低；(2) 拉动股价的 "AI agent 会搞坏数据、需要 Rubrik 撤销" 今天只有 15+ 付费客户，CFO 说今年 ARR 里 "假设极少"，而 CVLT 也在讲同一个故事；(3) 全年指引隐含下半年净新增 ARR 只 +6%，剔除迁移的云净新增 ARR 只 +20%；(4) 我们的基本情景按口径 B 只值 $76，按口径 A $55。

什么会让我们改主意：FY28 首次指引 (2027-03) ARR ≥ +25% 且 SBC / 收入降到 18% 以下；或 Agent Cloud 开始单独披露 ARR 并在 FY28 过 $50M；或股价回到 $65-80 (2026-05 初和 9 月低点附近都到过)。

1. 产品：它是什么、怎么运转、凭什么赢

1.1 一句话 + 一个日常例子

Rubrik 卖的是"被黑以后还能把公司救回来"的软件。它把企业所有重要数据 (机房里的虚拟机和数据库、AWS / Azure 上的应用、M365 邮箱、文件服务器、员工登录用的身份系统) 定时拷一份黑客改不了的副本，平时盯着副本有没有异常；一旦被勒索软件加密或被 AI agent 误删，几小时内恢复到被攻击前的干净状态。传统上这叫"备份"，Rubrik 把它包装成"网络韧性 (cyber resilience)"。

打个比方：老式备份是"每天晚上把文件复印一份锁进柜子"。可勒索团伙进门第一件事就是找到柜子、把复印件也烧掉；就算柜子没事，你也不知道哪天的复印件里已经混进了小偷的钥匙。Rubrik 的柜子连管理员都改不了 (只追加的文件系统)，而且每份复印件都附了一张清单 (谁的、何时变、有没有身份证号)，出事那天直接告诉你"第 17 号是最后一份干净的，先恢复门禁系统"。

1.2 行业背景：客户为什么需要它

备份是 IT 里最老的品类之一，过去是"维持运行"的成本项，买家是基础设施团队，按价格比。三件事把它变成了董事会话题：(1) 勒索软件专门先删备份再加密，"能不能备份"变成"被攻击当天几小时内能不能恢复干净"；(2) 数据散到机房、两三家云和十几个 SaaS，每家原生工具只管自己那块；(3) 2026 年 Anthropic 的 Mythos 证明 AI 能把低危漏洞串成高危攻击，CEO 的说法是"入侵到泄露之间已经没有时间差，预防和检测不够了"。所以安全预算 (CISO) 开始为恢复买单，这正是 Rubrik 想要的位置。

1.3 怎么收费

1. 一句话商业模式：订阅，~95% 收入是订阅 (Q2 FY27 $407M / $427M)，其余是服务和亚太少量硬件。合同大多 3 年 (可到 5 年)，按年付款，收入按月平摊确认。没有"超额用量"：用超了下次续约补买，所以收入很平滑，看订阅 ARR (年化合同额) 就够了。

3. 收费单位："前端 TB (FETB)" = 被保护的原始数据量 (不是备份占的存储)；机房设备 (Scale) 和 Cloud Vault 有时按后端 TB；M365 / Salesforce / Google Workspace 按用户，每用户含 100GB；身份按 180 天内活跃的人类身份；代码仓库按仓库；Agent Cloud 逐客户谈 (按 agent 数或支出比例)。版本 (Foundation / Business / Enterprise) 是乘在 TB 单价上的系数。

4. 承诺 vs 超额：几乎 100% 是承诺。2026-06 推出的 Rubrik Flex 是一种"总承诺池"：客户签一个多年总额 (例子是一家 G2000 保险公司 5 年 $3,000 万+)，在池子里按统一费率随时开通任何产品 (机房、云、身份、Agent Cloud)，不用每次重新采购。对 RPO 是加项 (RPO ~$2.62B，53% 在 12 个月内确认)，对 ARR 中性。风险是 Flex 变成"大折扣换长承诺"。

5. thesis 押在哪种收费方式上：按 TB 的部分是"份额转移 + 数据增长"，在慢慢减速；在加速的是安全版本溢价和身份。AI 对两边不同：数据变多对 TB 是加项，但按用户和按人类身份收费的部分会随 AI 减少员工而缩，agent 身份还没有计价方案 (CEO 在 GS 大会："向市场学习")。

方向机制证据我们的判断

1.5 核心竞争力

先说它在哪一步不是最强：采集和存储四家差不多 (Gartner 2026 魔力象限里 Veeam、Cohesity、CVLT、Rubrik 都在领导者象限，Veeam 略领先)；中端市场和自己买硬件的客户 Veeam 更强；价格敏感的场景 Cohesity 常赢；单点 DSPM 输给 Cyera；纯 AD 恢复 Semperis 起步更早。

为什么只有它能做成统一平台：老方案是"备份软件 + Data Domain 类备份存储 + 媒体服务器"三件拼起来，每件只看到一部分数据；CVLT 是 25 年的代码栈；Cohesity 合并 Veritas 后在整合两套产品。Rubrik 从零写成一个软件栈 (自研 Atlas 文件系统 + SaaS 控制台 RSC)，从第一天就同时存数据和元数据，形成"企业资产、身份、用户的时间序列地图"。CTO 在 Analyst Day 说，同一个应用在不同企业有成千上万种配置，恢复到生产"不能错一个 bit"，这只能靠 12 年、几千家客户迭代。

1.6 对比最核心对手，以及巨头为什么不能自己做

用了 A 还会不会买 B：同一家大企业里两家并存很常见，但这是过渡状态：40-60% 的大客户还在跑至少一套老平台 (Veritas NetBackup、Dell Data Domain)，因为老备份要留到保留期满。正面交锋发生在"整合到一家"的那一刻，通常由一次勒索事件或董事会要求触发。Q2 的例子：一家美国州政府机构"因为担心恢复时间"替换了老厂商；一家 G2000 金融客户替换老厂商、同时打赢了"一家新一代对手"；一家大型医疗系统用 Flex 从机房扩到 M365、云和身份，赢的是云原生工具。反方向：渠道说 IT 能力强、想自己买硬件的客户选 Veeam，价格敏感的选 Cohesity。

"巨头为什么不能自己做"：先核对前提，巨头其实做了：AWS Backup、Azure Backup 和 Microsoft 365 Backup (2024 年推出) 都在卖，而且更便宜；CVLT 说第三方工具只保护约 30% 的云工作负载，其余用原生工具或干脆不保护。写代码解决不了的壁垒是：(1) 中立性，备份不能和被攻破的那个云账号放在一起；(2) 跨云和机房的一套策略、一个恢复按钮；(3) 恢复正确性和保险担保；(4) 巨头的激励是卖存储和算力，不是让客户随时能走。所以巨头真正的威胁不是做出同样的产品，而是"够用就好"的默认选项截走单一云客户和 AI 原生公司，这部分客户本来就不是 Rubrik 的核心。

按五个维度看：账单规模 (中位 ~$150K / 年，大客户 $1M+)、应用种类 (机房 + 多云 + SaaS + 身份，越杂越需要第三方)、实时性 (恢复要几小时内)、人才 (备份工程师稀缺)、数据是否已在自己湖里 (备份副本不能放在被攻破的同一处)。结论：自己写备份软件的门槛极高，几乎没人做；真正的"自建"是用云厂商原生工具。原生工具划算的门槛大约是：全部工作负载在一朵云上、没有机房、Rubrik 年账单 < ~$10 万。这类客户 (AI 原生初创、云原生中小企业) 本来就不是 Rubrik 的核心，丢了是低质量收入。伤 moat 的情况只有一种：大企业把新的 AI 工作负载全放在一朵云上并用原生工具，Rubrik 只剩老系统，份额随老系统退役而萎缩。今天没看到这个迹象 (Q2 赢单里两单是打赢原生工具)。

和第 1 节连起来：客户真正买的不是"备份"，而是"出事那天几小时内恢复干净，并能向董事会和监管证明"。Rubrik 的优势正好在这里 (元数据 + 恢复编排 + 身份)，而它弱的地方 (存储、价格) 恰好是客户最不在乎的大企业场景以外。所以它的增长上限由"大企业里还剩多少老平台"和"中端市场愿不愿付溢价"决定。

什么能证明 bear 错了：NRR 连续 4 个季度 ≥ 119% 同时标价第二次上调落地；Cohesity 招股书显示它没有用价格换份额；Agent Cloud 单独披露且 FY28 ARR ≥ $50M。

6. Risk / Reward

这家公司的 play：和 DDOG、SNOW 一样，核心是收入增速 (ARR) 加速还是减速；但 Rubrik 还要加一条，SBC 能降多快，因为今天 FCF ≈ SBC，口径 A 的价值几乎全部取决于 SBC 率。
