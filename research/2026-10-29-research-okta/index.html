Okta：agent 的身份闸门是真的，但它今天还按人头收钱

这一篇回答一个问题：OKTA 是拥有 agent 身份闸门的便宜办法，还是披着 agent 外衣的 seat 生意？内容依次是：身份为什么成了安全的中心、员工和 agent 每天怎么经过 Okta、怎么收钱、cRPO 加速从哪里来、微软和 PANW 在抢什么、现价要求什么。原文在前，分析在后。

总体判断

这份是什么：按 RBRK、DDOG 的路径把 Okta 走一遍。先讲清楚产品：员工每天怎么用它登录，被钓鱼那天它怎么止损，AI agent 来了它管什么。再写市场在定价的 thesis 和我的假设，然后逐条验证。证据来自 6 场管理层发言 (两次业绩会、Evercore、7 月产品投资者会、GS 大会、Oktane 投资者峰会)，以及 Knowledge Base 里的渠道商、集成商、前微软身份高管、前 SailPoint 高管、SailPoint 和 Palo Alto 管理层、一位大客户买方和卖方材料。之后反过来想怎么会错，最后落到估值和买点。每条引文都用脚本对原文逐字核对过，并补成完整段落，带文件名和行号。

Executive Summary

一句话：先回答 "OKTA 是不是拥有 agent 身份闸门的便宜办法，还是披着 agent 外衣的 seat 生意"：到 FY28 之前它是 seat 生意，而且已经不便宜。闸门的位置是真的。Okta 是中立的身份平台里唯一已经 GA 的那个，2 万家客户，Anthropic 的 Claude 第一个接它的协议。但管理层自己选择了按 "每用户价格的加价" 收 agent 的钱，签一年期。基础的 agent 身份 (Agent SSO、Cross App Access) 免费送进每个产品。CFO 说 AI 对 FY27 "仍不重要"，2028 年以后才可能重要。与此同时，股价从 4 月的 $63 涨到今天的 $218 (3.5 倍)：EV/FY27 收入 11.8 倍，P/FCF 44 倍，扣掉 SBC 后的 FCF 收益率只有 1.2%。项目里 8 月底那条 "身份是便宜的预期差 (8.7 倍 EV/S)" 的结论，在这个价格已经不成立。不买，放观察名单。买点 $95–115，现价 $218。

增长确实在变好，但不是 agent 带来的。Q2 FY27 cRPO (未来 12 个月要确认的合同收入) +14%，比上季加速 2 点，大幅超出街上的 10.8%。这是非 Q4 季度的 bookings 纪录。$1M+ 客户 +22%，新产品 (治理 OIG、特权访问、身份威胁防护) 占 bookings 30%，含新产品的单子 ACV 高约 40%。CEO 给 cRPO 加速的原因排序是：大企业、产品广度、AI 讨论带动其他产品成交。也就是说，AI 的作用是 "敲门砖"，打开门后卖出去的是老产品。收入增速仍是 11%，NRR 107%。渠道口径也是 10–12%：EMEA 集成商说 11–12% 持平，美国顶级合作伙伴说 ACV +10.8%，埃森哲前专家预计 "保持 10–12%，AI 不会带来近期加速"。

agent 没有变成新的计费单位，至少现在没有。(1) 定价按人头：Q2 电话会上 CEO 说 "我们的定价是每用户的，Okta for AI Agents 是每用户价格的加价"。Oktane 上他给的大单比例是平台 4、agent 部分 1–1.5，和 OIG 的加价差不多。(2) 怎么数 agent 还没人知道：Okta 内部的 agent Dex 被 7,000 人用，算 1 个还是 7,000 个？(3) 最基础的一层免费：Agent SSO 进了基础版，Cross App Access 进了每个产品，按消费收费只是 "脚手架"。(4) 客户侧的钱很小：一家美国大型电信公司的战略高管说，agent 身份只占他们整体安全预算的 1–2%；埃森哲前专家说 AI 今天对 Okta 合同增长贡献 ≤3%，不到 5% 的客户在生产里付费，"还没有独立的 AI 身份预算"。(5) 对手的说法：前微软身份高管认为基础 agent 身份最终会 "低价或几乎免费"，钱在高级安全和治理。好的一面是，agent 数量的增长速度确实惊人：一家客户的 Claude agent 几周内从 50 个变成 1,500 个，Okta 定价时假设大客户有 20 个 agent，实际有客户 2,000 个。但这些数量今天不进账单。

竞争：平台化对 Okta 是双刃剑。Microsoft Entra 占员工访问管理约 40%，Okta 约 30% (CEO 在 Oktane 的说法)。渠道里能看到 M365 E5 客户把标准认证迁回 Entra、只把复杂应用留给 Okta。PANW 收购的 CyberArk (现名 Idira) 增长 21%，正在抢 "非人身份" 预算。反过来，Okta 自己也在做身份平台化：一家客户用 Okta 换掉 SailPoint+Ping+CyberArk，省 40%；多云客户和 "不想把身份交给安全平台" 的客户在增加 (前 PANW 渠道人)。SailPoint CEO 说 Okta 做 IGA 五年 "没在我们的业务上留下凹痕"，但 Okta 的 OIG 客户已经超过 2,000 家。

估值要求 5 年 19–35% 的收入复合增长。现价 $218，按非 GAAP 稀释股数 1.844 亿股算，市值 $402 亿，无负债，现金 $23 亿，EV $379 亿。FY27 FCF 指引 $9.2 亿，SBC 约 $4.6 亿 (收入的 14%)。我的基本情形是 5 年收入复合约 10%、FY32 FCF 率 30%、SBC 11%，价值按口径 A (SBC 当成本) 约 $85，按口径 B (每股 FCF) 约 $104。乐观情形 (agent 变成真计费单位，复合 14%) 约 $148 / $179，也低于现价。要在 $218 拿到 10% 年化，口径 B 需要收入复合 19–29%，口径 A 需要 24–35%。今天的 11% 增速离这个要求很远。卖方 52 家里 43 家买入，10 月初平均目标价 $217，和现价相同。

公司基础

它是做什么的

一句话：Okta 卖的是 "谁可以进哪扇门" 的软件。员工早上打开电脑，只登录一次 Okta，就能进 Salesforce、Slack、Workday、AWS 等几百个系统，这叫单点登录 (SSO, Single Sign-On)。登录时再确认一次是不是本人，比如手机推送或指纹，这叫多因素认证 (MFA, Multi-Factor Authentication)。入职那天账号自动开好，离职那天所有账号自动关掉。这一层叫员工身份 (workforce identity)，约占 Okta 收入 59%。另一层叫客户身份 (customer identity，CIAM)，来自 2021 年 $65 亿收购的 Auth0：开发者用几行代码，就能给自己的 App 加上 "用 Google 登录"、注册、密码重置和防机器人，按每月活跃用户 (MAU) 收费，约占收入 41%。在行业里 Okta 被叫作 IdP (Identity Provider，身份提供方)：它是公司里 "谁是谁" 的那本总账。

先有体感：身份为什么成了安全的中心

20 年前公司有一道围墙，也就是机房防火墙，进了墙就算自己人。今天员工在家办公，应用在几百个 SaaS 上，围墙不存在了，唯一能拦人的地方就是 "登录那一下"。所以黑客也改了打法：不再撬墙，而是偷账号。CEO 在业绩会上说 80% 的入侵是身份类攻击。最常见的三种：

  1. 钓鱼拿密码，或者打电话骗客服重置 MFA。2023 年 MGM 和 Caesars 被勒索，就是黑客打电话给 IT 服务台冒充员工，骗到了重置。
  2. 偷 "会话令牌" (session token)。登录完成后浏览器里有一张临时通行证，偷到它就不需要密码。Okta 自己 2023 年 10 月被入侵也是这个路数：黑客进了 Okta 的客户支持系统，拿到客户上传的诊断文件 (HAR 文件) 里的令牌，再去登录客户的系统，1Password、Cloudflare、BeyondTrust 都受到波及。Okta 起初说影响很小，11 月 29 日改口：所有客户支持用户的信息都被拿走了。这是公司历史上最大的信任危机，2024 年 2 月它推出 "Secure Identity Commitment" (把一部分工程力量转去加固自己和客户的身份安全)。
  3. 权限过大、没人管的账号。离职三年的员工账号还开着，测试用的管理员账号从来没关，或者一个服务账号 (给程序用的账号，非人身份 NHI 的一种) 拥有整个数据库的权限。

Okta 的产品就是沿着这三条路线一层层加上来的：先是登录 (SSO/MFA)，然后是管账号的整个生命周期 (Lifecycle、治理 OIG)，再管高危权限 (特权访问 PAM)，最后是登录之后持续盯着 (身份威胁防护 ITP，行业叫 ITDR)。

客户买回去之后的一天：以一家 8,000 人的保险公司为例

  • 入职：HR 在 Workday 里录入新员工。Okta 的 Lifecycle Management 读到这条记录，按 "理赔部、上海、经理" 这个角色自动开好 40 个系统的账号。没有 Okta 时，这是 IT 工单排队三天。
  • 每天早上：员工打开电脑，用 Okta Verify (手机 App) 或指纹登录一次，之后点哪个应用都直接进。Okta 在背后看这次登录是否异常 (新设备？凌晨 3 点？从另一个国家？)，有风险就多问一步，这叫自适应 MFA。
  • 每季度：合规要求每个经理确认 "我手下的人还该有这些权限吗"。Okta Identity Governance (OIG，身份治理，属于行业说的 IGA) 自动给每个经理推一张清单，经理点 "保留" 或 "撤销"，审计报告自动生成。以前这件事靠 Excel 和 SailPoint 这类专门软件。
  • 数据库管理员：要上生产数据库时，通过 Okta Privileged Access (OPA，特权访问，行业叫 PAM) 申请。批准后拿到 2 小时有效的临时凭证，全程录屏，用完自动作废。以前这块是 CyberArk 的地盘。
  • 离职：员工最后一天下午 5 点，HR 标记离职，Okta 在几秒内关掉他所有账号，包括他自己私下注册、但用公司邮箱登录的 SaaS。

被攻击那天

周二上午，一个理赔员点了钓鱼链接，黑客偷到他的会话令牌，从另一个国家登录了 Salesforce。没有 ITP 时，令牌有效期内黑客畅通无阻，直到几天后安全团队在日志里发现。装了 Identity Threat Protection (ITP) 时：Okta 发现同一会话的 IP 和设备指纹突然变了，同时 CrowdStrike 报告这台笔记本有可疑进程 (Okta 也接收 CrowdStrike、Palo Alto 的风险信号)，于是把风险分拉高，执行 "全局登出" (universal logout)，这个人所有应用的会话一起作废，并要求重新做强认证。CEO 承认，大部分客户还没买这个模块。2026 年 8 月收购的 Permiso 把风险检测从 90 种扩到 400 种，也能盯 agent 的会话。

AI agent 来了：Okta 管什么

还是这家保险公司。开发团队用 Claude Code 写代码，让它去读 GitHub、改 Jira 工单、查测试数据库。今天大多数公司的做法是把开发者自己的长期密钥 (静态 token) 存在笔记本上让 agent 用，这等于给 agent 一把万能钥匙，而且没人知道它用钥匙干了什么。CEO 说这是他见过最常见的情况。Okta 的方案回答三个问题：我的 agent 在哪？它能连什么？它能做什么？

  • 登记 (Agent SSO / Universal Directory)：每个 agent 在 Okta 目录里有一条身份记录：谁创建的，替谁干活，什么时候过期。2026 年 8 月起，这一层对所有 workforce 客户免费。
  • 跨应用授权 (Cross App Access，XAA)：agent 要连 Jira 时，不再拿开发者的长期密钥，而是由 Okta 按策略签发一个短期、限定范围的令牌，比如只能读不能删、只能在今天用。Anthropic 的 Claude 是第一个支持这个协议的 agent (Anthropic 称之为 Enterprise-Managed Auth)，Okta 是第一个支持它的 IdP，另有 26 家 SaaS 在资源端支持。这一层也免费放进了每个 Okta 产品。
  • 付费层 (Okta for AI Agents，2026-04-30 GA)：发现公司里所有 agent，包括员工私自用的；对 agent 做治理 (定期复核、到期关闭)；通过 Agent Gateway 和 MCP 网关在运行时执行策略；给 agent 做特权控制和威胁检测。按每用户加价收费。
  • 真实案例：一家财富 50 强医疗公司在评估开始时检测到 50 个 Claude agent，几周后变成 1,500 个，于是签了数百万美元的合同。一家大型资产管理公司在生产里跑着几千个来自不同厂商的 agent。

常见疑问

  • 微软 Entra 随 Office 365 一起送，为什么还要买 Okta？Entra (原 Azure Active Directory) 在 M365 E3/E5 套餐里基本是免费的，这是 Okta 最大的结构性压力。客户选 Okta 的理由有三个：(1) 中立：公司同时用 AWS、Google、Salesforce、Workday，不想让微软管所有门；(2) 集成数量 (8,000+) 和体验；(3) 稳定性：Okta 说自己 3 年停机约 69 分钟，微软超过 2,000 分钟。专家的共识是 "多云的大企业选 Okta，纯微软的中小企业选 Entra"。
  • AI 让员工变少，Okta 是不是会少收钱？直接受影响的是按人头收费的 workforce。埃森哲前专家说，客户裁员 10% 并不会少付 10%，因为平台还得用，而且现在的大客户净新增席位已经放缓。但长期看，如果 agent 替代了员工，而 agent 不按个数收费，计费基数就会变小。这正是本文的核心问题。
  • 非人身份 (NHI) 是什么？所有不是人的 "账号"：服务账号、API 密钥、机器证书、云上的工作负载身份，现在又加上 AI agent。各方估计非人身份是人的 8–100 倍。过去这块主要归 CyberArk (管密钥和机器证书)，现在 Okta、SailPoint、PANW、CrowdStrike、微软都在抢。
  • Okta 自己被黑过，客户还信它吗？2022 年 (Lapsus$，最多 366 家客户) 和 2023 年 (支持系统) 各一次。我们读到的专家里，有一位说他所在的公司 (推断是 Cloudflare) 因此换掉了 Okta。但从数据看，2024–2025 年 NRR 一路下滑主要是 COVID 时期过度采购的出清，管理层说这一轮已经出清。专家普遍认为替换身份系统非常痛苦，所以客户大多选择留下。
  • Auth0 现在怎么样？Auth0 卖给开发者，用于 B2C、B2B SaaS 和 "agent 版本的 App"。customer identity 的 ACV 增速在 Q2 升到 13%，高于 workforce 的 11%。Auth0 for AI Agents 的管道比 Okta for AI Agents 小，管理层认为是 "更远期的机会"。

收入结构：FY26 (截至 2026-01) 收入 $29.19 亿 (+12%)，其中订阅 $28.55 亿，专业服务正在转给 GSI 合作伙伴 (GSI 指全球系统集成商，如埃森哲、德勤)，Q2 只占约 1%。workforce : customer ≈ 59 : 41。公司不按产品披露收入，只说新产品 (OIG、OPA、ITP、ISPM、Device Access、AI 产品) 占 Q2 bookings 约 30%。一位前 SailPoint 高管估计 OIG 约 $4 亿 ARR (未经核实)。2 万多家客户，大客户占 ACV 85%，$1M+ ACV 客户超过 600 家，公共部门不到 10%。

Thesis：市场在定价什么 vs 我的假设

市场现在在定价什么

"Okta 是 agent 时代的身份闸门。每个 agent 都需要身份、权限和审计记录，Okta 是唯一中立、已经 GA 的身份平台，2 万家客户就是分发渠道，Anthropic 第一个接它的协议。agent 会让计费单位从 '人' 变成 '人 + agent'，治理、PAM、ITDR 让每个客户的钱包变大，cRPO 已经加速。所以增速会从 10% 走向 15% 以上，同时保持 30% 的 FCF 率和回购。"

这是今天的主流说法 (CEO："身份五年内会是网络安全最大的市场，agentic 可能比整个身份市场还大")。股价从 $63 到 $218 的过程，就是市场从 "被 AI 压缩席位、被微软捆绑的 10% 老软件" 切换到 "AI 安全的直接受益者" 的过程。

我的假设 (Caffrey 框架：AI 让计费单位变多还是变少，谁拥有被计量的东西)

Okta 的计费单位是 "员工人头 + 月活用户 + 模块"。AI 时代的两股力量：

让计费单位变多让计费单位变少或不变
agent 数量爆炸 (50 → 1,500；预计 20 → 实际 2,000)，每个都需要身份、凭证、审计agent 今天挂在人头上，按 "每用户加价" 收费；数量增长不进账单
agent 让客户重新审视身份栈，带动治理、PAM、ITDR 的加卖 (新产品 30% bookings，ACV +40%)AI 让员工变少或增长停滞，workforce 人头基数缩
Okta 计划在续约时加入消费部分 (Agent SSO 的用量上限是 "脚手架")基础 agent 身份 (Agent SSO、XAA) 免费送；对手预计 "低价或几乎免费"
CIAM：agent 代表消费者购物 (agentic commerce) 需要新的身份标准agent 代人访问网站，可能减少消费者的 MAU 和直接流量 (管理层承认 "流量在漂移")

我在之前的框架讨论里说过两句话。第一句是 "干活变便宜了，管活变值钱了"，钱流向权限、记录和可撤销。第二句是 "身份/记录系统是 agent 绕不开的必经层，但它的计费单位不一定会增长"。Okta 是第二句话最直接的检验。所以问题不在 "身份重不重要"，而在两件事：(1) 今天 11% 的增长和 cRPO 加速里，有多少来自 agent，有多少来自 "大企业 + 治理加卖 + 渠道 + 销售执行"？(2) 如果 agent 要到 FY28 以后才进账单，而且是按人头加价、基础层免费，那么 $218 (11.8 倍收入，扣 SBC 后 FCF 收益率 1.2%) 给了多少余地？

1. agent 不按 agent 收钱：Okta 自己选了 "每用户加价" → 冲击 E02

这是全文最重要的一条。多头的核心逻辑是 "agent 会成为新的计费单位"。但管理层在 Q1、Q2、GS、Oktane 四次场合说的都是同一件事：Okta for AI Agents 按每用户价格加价，签一年期。CEO 自己预判了反驳 ("大家第一反应是：这太疯狂了，seat 在消失")，他的回答是 "客户现在就想这么买"。Oktane 上给的大单比例是平台 4、agent 1–1.5，相当于 25–40% 的加价，和 OIG 差不多。这说明 agent 今天是 "又一个加卖模块"，和治理、PAM 同类，而不是一个随 agent 数量增长的新单位。好的一面：CEO 明确说 "它不会一直是按用户的，会变成按 agent"，并且已经在基础版里埋了用量上限。

2. 最基础的一层 agent 身份被免费送出去了 → 冲击 E02

Agent SSO (在目录里给 agent 建身份) 进了 workforce 基础版，Cross App Access (agent 跨应用拿短期令牌) 进了每个产品。CEO 说内部有过争论，"我们本可以收费"，最后为了让协议成为行业标准而选择免费，因为每个 ISV 都会问 "多少客户能用？"。这是正确的战略 (推标准、做漏斗)，但它也意味着 "agent 需要身份" 这件事本身不会直接变成收入，要靠上面的治理、网关、威胁检测加卖。前微软身份高管的预判是一样的：基础平台功能 "会低价或几乎免费"。

产品理解

身份安全全家桶和 agent 架构

s21 是讲给第一次接触的人的。这一节补充产品和架构的细节，回答 "到底比别人强在哪、弱在哪"。

身份安全全家桶 (按攻击发生的时间)：登录之前，ISPM (身份安全态势管理，来自 Spera) 扫描几百个 SaaS 的配置，找出闲置的管理员账号和权限过大的身份，OIG 发起复核并收回权限。登录那一刻，SSO 和自适应 MFA 认证，Device Access 让设备登录和应用登录用同一套流程，OPA 为高危资源 (数据库、EC2) 签发短期凭证并录屏。登录之后，ITP 持续评估会话风险，接收 CrowdStrike 和 PANW 的信号，可以全局登出或要求加强认证。这些产品之间有现成的联动 (比如 ISPM 发现闲置管理员，自动触发 OIG 复核)，也可以用 Workflows (低代码) 自己拼。

agent 分类 (Okta 自己的口径)：嵌入式 agent，比如 Zoom 助手，Okta 管不到，因为没有 API；独立 SaaS agent，比如 Devin；自动化平台里的 agent，比如 Boomi、Tines；自建 agent，比如 LangChain、Bedrock。另一个维度是委托链 (是人直接指挥，还是 agent 再派生子 agent) 和存续时间 (几分钟还是常驻)。Okta 的设计是 "agent 代表某个人"，用户的令牌带着可追溯性沿调用链传下去。这和 SailPoint 的 "agent 更像员工" 不同，也和网络厂商的 "在网络层控制 agent 能连什么" 不同。

竞争对手眼中的弱点：前微软身份高管说，Okta 是 "把现有的应用模型扩展了一点"，Auth0 的细粒度授权要客户重写 API 才有用；SailPoint CEO 说 Okta "从没深入过应用的权限结构"；这些都是 "治理深度" 的问题。Okta 的回应是平台广度、中立、上线速度 (几周 vs 几个月) 和可用性。

可用性：官方 SLA 99.99%，今年 100%，过去三年累计约 69 分钟停机；公司说微软同期超过 2,000 分钟。身份系统一停，全公司都登不上，所以这是大企业真正在意的指标。

放进 "agent 最大公约数" 框架

我们之前的结论是：agent 时代所有路径都要经过两个必经层，身份/权限和记录系统 (SoR)。"干活变便宜了，管活变值钱了"，钱会流向权限、审计和可撤销。Okta 是这个框架里身份层最纯的标的，所以 8 月底被列为 "候选预期差"。这次研究的结论是：必经层的位置被验证了，但必经层不等于收费站。Okta 主动把最基础的一层 (Agent SSO、XAA) 免费送出去，换取标准地位；收费的部分按人头加价，和治理、PAM 一样是 "又一个模块"。这和框架里 "必经层今天还没被计费" 的判断一致。所以 Okta 适合放在 "控制点已验证、收入弹性待验证" 那一类，和 4 月时的定位相同。区别在于，4 月的价格给了这个期权，今天的价格要求期权已经兑现。

结论：OKTA 不是 "便宜的 agent 闸门"，而是 "一个执行在改善、现金流很好、带一个 agent 期权的 seat 生意"。这个期权的行权日大约在 2027 年中 (第一批 AI 合同续约)。在那之前，合理的估值应该按 10–12% 增长的身份平台来给。
