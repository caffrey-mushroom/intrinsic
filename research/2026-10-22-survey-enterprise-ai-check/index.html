企业 AI 支出还在涨，但二阶导已经转负：主流预期从"未来半年 +40–50%"收敛到"+10–30%"，同时 token 用量增速明显快于美元支出增速。

驱动力从员工席位转向生产 API 和智能体工作流；路由、降档、开源自托管和缓存让每美元买到的 token 越来越多。

所以 token 量 (和推理算力) 的需求比企业 AI 账单更强、更耐久，但结构在向中端、小模型和开放权重下沉，前沿模型只占企业预算约 5–15%。账单端的压力主要压模型厂商的单价和结构，不是 token 量本身。

未来半年支出增速 vs 过去半年。 现在普遍降速，多数 +10–30%。重新加速的样本增多，意味着新一轮智能体生产化。

前沿模型支出占比。 现在 5–15%。突破 20% 说明长时程智能体打开了市场。

开放权重占 API 费用。 少数企业 25–50%，多数为 0。看强监管行业有没有开始生产部署。

节省重新投入的比例。 从 60–70% 滑到约三分之一。低于三分之一，说明 token 的价格弹性在减弱。

ROI 门槛和暂停案例。 已开始出现 (车贷、美国医药)。暂停样本超过三分之一是警戒线。

自建替代 SaaS。 零散但增多。看是否从外围工具扩展到记录系统。

数据平台 / 传统云带动比。 现在 $1 模型带动 $0.30–0.50 云 + $0.15–0.25 数据库。看智能体规模化后是否上升。

2. 八条核心趋势

2.1 支出仍在增长，但增速普遍回落，分化加剧

同一家企业的"过去半年 → 未来半年"对比几乎都在降速，少数企业已开始主动压低账单。

企业 (期次)过去未来
超大型制药 (V6)半年 +400%半年 +200%
超大型啤酒 (V6)半年 +35% ($2.84M/月)半年 +25%
超大型药房健康险 (V6)半年 +30%半年 +27%
中型车贷 (V6)半年 ~+20%半年 ~+10%
二手车平台 (V5)半年 +40–60%半年 +30%
薪酬人力 (V5)年初至今 +100%至年底 +25%
新加坡顾问 (50–60 家客户，V2)过去 12 个月翻倍到 2027.07 再翻倍，之后 +20–30%

Source: DeepLLM Vol.2 / Vol.5 / Vol.6，受访者估算。

主动收缩的样本：亚洲游戏公司付费 API 从 $14.3M/月压到 $11.4–12.9M (积分制 + 本地模型分流，V3)；全球公关公司平台迁移后月费 −40% (V4)；东南亚制造子公司额度预算可能砍半 (V2)；美国医药公司半年 +225% 后被 CEO/CFO 要求持平 (V2)。

分界线很一致：绑定具体生产用例的继续加码，只是人均额度的被削。

2.2 增量从席位转向 API 和生产工作流

这是六期里最稳的一条。席位在大企业已近饱和，新增美元主要来自生产工作流的持续调用。

  • 订阅 / API 结构：美国电信 50/50 → 40/60 → 目标 35/65 (V1)；顾问口径一年前 90/10 → 50/50 (V2)；公关公司 90/10 → 50/50 → 年底 20/80 (V4)；亚太营销 60/40 → 50/50 → 30/70 (V4)；欧洲物流 2027 年 API 占 ~60% (V3)。
  • 未来半年增量里 API 的贡献：金融科技 85–90%、啤酒 83%、药房健康险 63% (V6)；支付、多元控股的增量预计全部来自 API (V5)。
  • 反例：覆盖率还低的企业仍在买席位 (新加坡电信订阅贡献 80% 增量，V5)；制药集团因 M365 Copilot 铺开，订阅占比从 20% 升到 75% (V6)。
  • 啤酒集团的一句话很关键：招聘放缓会压低订阅增长，而 API 随核心流程、多模态和智能体继续增长。新加坡顾问也说智能体流程 "is where tokens are consumed"。

2.3 Token 量与美元支出脱钩

企业用路由、降档、缓存和自托管压单位成本，但省下的钱大多又变成更多 token。

  • 金融科技：培训按任务选模后，部分团队"美元减半，token 反而上升" (V6)。
  • 制药集团：自托管开放权重模型处理约 50% API 调用，单位成本比外部 API 低约 90%，调用量月环比 +20% (V6)。
  • 可优化空间：美国电信 API 账单 20–30% (V1)；药房健康险 20–30% (V6)；物流内部缓存已省 20–25%、目标 40% (V3)；美国电信 35–45% 的输入可缓存 (V1)。
  • 节省去向：美国电信说降价 50% 时 60–70% 重新投入 AI (V1)；新加坡顾问约一半 (V2)；亚太营销只有三分之一 (V4)；汽车制造商更倾向返还客户 (V1)。越到后期，留作利润的比例越高。

2.4 前沿模型不是预算跳升的驱动力，模型分层已成共识

六期都得出同一结论：新前沿模型主要抬高已有场景的上限，没有带来整体预算跳升。

  • Fable / Astra 占支出：美国电信 5–8% (贡献增量 10–15%，V1)；新加坡电信 ~10%、广告 ~15%、工业软件 ~5% (V5)；金融科技 5%、啤酒 5–10%、车贷 <5% (V6)。
  • 开放后的回落：东南亚制造 Fable 一度占 70–90% token，培训后降到 10–20% (V2)；法律公司月支出一度到预算 1.8 倍，收回默认模型后 1.2 倍 (V3)；薪酬公司开放 Fable 14 天即停用 (V5)。
  • 三层结构成为默认：Opus 做编排和复杂任务，Sonnet / Haiku / 开放权重做摘要抽取。啤酒集团估计 70–80% 任务中端或小模型即可，药房健康险估计真正需要最强模型的只有 10–20% (V6)。
  • 例外是长时程智能体：啤酒集团用 Astra 做跨系统商业分析，是六期里唯一清晰的前沿模型新用例。

2.5 开放权重两极分化，但大企业自托管在提速

技术型和超大型企业在快速加仓，强监管和采购驱动的企业几乎为零。

  • 决策门槛：成本至少便宜 4 倍才值得迁移；自建集群 GPU 利用率低于 ~80% 成本优势消失 (V2)；推理层便宜 40–70%，全 TCO 只便宜 20–40% (V1)；自托管安全成本高 15–20% (电信专家)。
  • 部署方式：美国电信 60% 走三大云、25–30% 走专业推理平台、10–15% 自建 (V1)。V6 的变化是制药、金融科技开始在自有数据中心或云服务器上自托管，按服务器付费替代按 token 付费。

2.6 预算管理制度化：Budgeting 取代 Tokenmaxxing

约 50 家样本里只有两三家偏 Tokenmaxxing，其余都在管控，并且措施越来越精细。

  • 个人额度：编程 $70–200/人/月、$400–600、$1,000 (含 API)、$100/天、积分制每天 7,000 分 (高价模型倍率 80–100 倍，本地模型免费)。
  • 网关 / 路由从"正在建"变为"已运行"：V2 四家无一落地；V6 金融科技、啤酒、制药已用网关自动选模，啤酒集团甚至对员工隐藏模型选项。
  • 衡量单位：从每百万 token 价格变为 cost per successful outcome / cost per agent workflow。

2.7 ROI 开始反向约束投入，AI 预算挤占其他 IT 和 SaaS

早期"工程能力比钱更稀缺" (V1)，到后期变成"先证明回报再给钱"。

  • 门槛：加拿大消费品 $1 投入要 $2.5 回报 (V2)；欧洲物流 4 年 3 倍 (V3)；澳洲医药流通 2 年回本 (V3)；工业软件单项 ROI 30% (V5)；啤酒集团 $1 要 $2–3，并要业务部门承诺改造流程和减少用工 (V6)。
  • 工时门槛：零散节省 5–10% 工时不产生经济价值，要节省 30% 以上才能重新分配人力 (V2)；客户还在要求 10–20% 降价 (V2、V4)。
  • 放缓信号：车贷企业表示易落地用例覆盖完后若仍无明显收入贡献，管理层可能暂停追加 (V6)。
  • 预算来源与替代：由业务部门出资、计入运营费用；部分领先企业已把 ~40% IT 预算转向 AI (V2)。自建应用替换 $200–250k/年的营销自动化平台 (V5)、用 Claude 自建替换 $80–100k/年专用软件 (V6)、削减 Atlassian (V6)、评估削减 ServiceNow / Salesforce (V2)。但电信专家认为被削的是外围薄应用层 (10–20%)，Salesforce / ServiceNow 等记录系统支出 2026 年反而加速。

2.8 智能体生产化仍窄，瓶颈是数据和流程而非模型

有账号与有产出之间仍是数量级差距，token 真正大量消耗在少数重度用户和生产智能体上。

  • 集中度：欧洲保险全员 Copilot，创造业务价值的不到 2–3% (V2)；前 10% 用户花费是普通用户的 8–20 倍 (V1)；10–15% 重度用户贡献 50–55% 用量 (V3)。
  • 已生产化案例：15 个智能体把 3 小时销售流程缩到几分钟 (V1)；理赔质检准确率 70% → 85% (V2)；客服智能体自动处理 30% 咨询 (V3)；制药采购、工单、拜访准备智能体规模化 (V5)；复杂理赔处理时间 −20% (V6)。
  • 瓶颈：数据权限、安全合规、流程重设计、组织责任；多位专家明说模型再升一档不是决定因素。啤酒集团仍把大量投资放在 ERP 简化和 SAP 标准化，视为 AI 的前提。

一句话：账单在降速、token 在加速；增量来自 API 和智能体，流向便宜档位和开放权重，被 ROI 和数据准备度卡住节奏。

3. 对 token / 算力 / 内存需求的含义

以下是基于上述材料的推论，不是材料原文结论。

Token 量：偏强，且弹性为正。企业美元支出增速在回落，但"美元减半、token 上升"和"降价省下的 50–70% 重新投入"说明 token 需求对价格有弹性。生产 API 占增量 60–90%，这部分是持续运行的工作流，比席位里的闲置额度更实。所以企业 token 量增速大概率显著高于企业 AI 账单增速。

推理算力：总量增长，但每 token 算力在下降。Token 结构向 Sonnet / Haiku、开放权重小模型下沉，前沿模型只占支出 5–15%。实验室专家给的单芯片吞吐：8B 模型 1–2 万 tok/s，70B 约 2,000 tok/s，超大模型 10–50 tok/s。若 token 结构继续下沉，同样的 token 增长对应的 GPU 需求会少于线性外推；反向力量是智能体循环和长上下文 (一次浏览器点击 2 万+ token、10 步流程 20 万、研究类流程 100 万+)。

算力归属在分散。开放权重的主流路径是超大云托管 (Bedrock / Foundry / Vertex) 和专业推理平台，自建仍小；但制药、金融科技、工业软件已开始在自有或租赁算力上跑。这会把部分推理需求从模型实验室的集群转到云、neocloud 和企业自有 GPU，对整体 GPU 需求中性偏正 (80% 利用率门槛意味着自建效率较低)。

CPU、内存与数据层：被低估的带动效应。电信专家估计每 $1 模型支出带动 $0.30–0.50 传统云 (计算 10–15 美分、存储与数据传输 8–12 美分) 和 $0.15–0.25 数据库 / 数据平台；传统云支出增速从 2025 年 8–12% 加速到 2026 年 12–18%，其中 70–80% 来自用量和架构组合。智能体的编排、检索、前后处理提高了每个工作负载的 CPU 与内存消耗。药房健康险的 Databricks / Snowflake 月费从 $2–2.5 万升到 $3.5–4 万，预计半年后 $5–6 万。

另外，缓存成为企业主流控费手段 (35–45% 输入可缓存)，智能体需要持久化状态与记忆；这两点都把需求从"重算"推向"重存" (KV cache、DRAM、SSD 层)，是内存线的加项。

模型厂商收入与 token 量的差距会拉大。实验室专家认为最贵模型利润率最高 (输出 $50/M vs Haiku $5/M)，但用量有限。企业正在系统性地把流量压到便宜档位和开放权重，所以前沿实验室的企业收入增速可能低于 token 量增速；编程 (Claude Code / Cursor) 和长时程智能体是保住高价 token 的主要场景。

主要风险：席位饱和加招聘放缓让订阅进入平台期；ROI 门槛在易落地用例覆盖完后可能让部分企业暂停追加；智能体生产化受数据和流程改造限制，节奏可能慢于市场预期。

需求线方向依据
Token 量加项，强于账单美元减半 token 上升；节省 50–70% 再投入；API 占增量 60–90%
推理算力 (GPU)加项，弱于 token结构下沉到小模型和开放权重；智能体长上下文是反向力量
CPU / 传统云加项$1 模型带动 $0.30–0.50；云增速 8–12% → 12–18%
内存 / 存储加项缓存成主流控费手段；智能体状态与记忆；数据平台费用上升
前沿实验室收入增速低于 token前沿模型占支出 5–15%；网关自动降档

Source: 作者基于 DeepLLM Vol.1–6 和两份专家纪要的推论。

一句话：对 token 和内存是加项，对 GPU 是弱一些的加项，对前沿实验室的单价是减项。
